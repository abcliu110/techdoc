### 2.2 现有菜品发布机制

菜品发布使用 `GroupDishBookReleaseService`，核心流程：

```
品牌管理员 → 创建菜品发布计划 → 选择目标门店 → 选择发布规则
                                                    ↓
                                          GroupDishBookReleaseService.release()
                                                    ↓
                                    ┌─────────────────┼─────────────────┐
                                    ↓                 ↓                 ↓

                                    ↓                 ↓                 ↓

```

## 三、实施方案

### 3.1 方案选择

**采用方案：复用菜品发布机制 + PosDept Lid 映射**

理由：
1. 复用现有 `GroupDishBookReleaseService` 策略模式，改动最小
2. PosDept 发布规则与菜品发布规则一致（MERGE/ONLY_UPDATE_SAME/COMPLETE_REPLACE/ONLY_REMOVE_SAME）
3. 菜品已验证的发布逻辑可复用于 PosDept

### 3.2 核心差异：PosDept Lid 处理

| 实体 | 发布时 Lid 处理 | 说明 |
|------|---------------|------|
| 菜品 | 品牌和门店 Lid 一致 | 雪花算法全局唯一，无需映射 |
| PosDept | 品牌和门店 Lid 不同 | 门店端需新生成 Lid，建立映射关系 |

**原因**：菜品 Lid 用于内部关联，风险较低；PosDept.prnQueue 引用门店打印机 Lid，如果使用品牌 Lid 会导致门店打印错误。

// nms4cloud-pos4cloud-biz/.../service/app/GroupDishBookUtilService.java
public GroupDishBookData queryDishData(Long mid, Long sid, Long brandLid) {
  GroupDishBookData data = new GroupDishBookData();

  // 现有菜品相关查询...

  // 新增：查询品牌出品部门（通过 GroupDishBookHook 获取品牌级 sid）
  Long brandSid = Optional.ofNullable(groupDishBookHook)
      .flatMap(hook -> hook.getBrandLidByDishBookLid(mid, sid))

      Wrappers.lambdaQuery(PosDept.class)
          .eq(PosDept::getMid, mid)
          .eq(PosDept::getSid, brandSid)

  // 新增：查询品牌菜品与部门映射
  data.posDishToPrnDeptMap = posDishToPrnDeptMapper.selectList(
      Wrappers.lambdaQuery(PosDishToPrnDept.class)
          .eq(PosDishToPrnDept::getMid, mid)
          .eq(PosDishToPrnDept::getSid, brandSid)
  ).stream().collect(Collectors.toMap(PosDishToPrnDept::getLid, Function.identity()));

### 4.2 GroupDishBookReleaseService 修改

#### release() 方法扩展

参考现有代码（行 658-712），在 release() 方法中增加 PosDept 和 PosDishToPrnDept 发布逻辑：

```java
@Transactional(propagation = Propagation.SUPPORTS, rollbackFor = Exception.class)
public void release(PosGroupDishBookRelease request) {
  // ... 现有菜品发布逻辑 ...

  GroupDishBookData srcData =
      utilService.queryDishData(request.getMid(), request.getBookLid(), request.getBrandLid());

  switch (request.getBookReleaseRule()) {
    case MERGE -> {
      mergeDish(srcData, request, sidList);              // 现有
      mergePosDept(srcData, request, sidList);           // 新增
      mergeDishToPrnDept(srcData, request, sidList);    // 新增
    }
    case ONLY_UPDATE_SAME -> {
      onlyUpdateSameDish(srcData, request, sidList);
      onlyUpdateSamePosDept(srcData, request, sidList);
      onlyUpdateSameDishToPrnDept(srcData, request, sidList);
    }
    case COMPLETE_REPLACE -> {
      completeReplaceDish(srcData, request, sidList, false, true);
      completeReplacePosDept(srcData, request, sidList);
      // PosDishToPrnDept 在 mergePosDept 后由 updateDishToPrnDeptMapping 更新
    }
    case ONLY_REMOVE_SAME -> {
      onlyRemoveSameDish(srcData, request, sidList);
      onlyRemoveSamePosDept(srcData, request, sidList);
      onlyRemoveSameDishToPrnDept(srcData, request, sidList);
    }
  }

  // ... 现有清理缓存逻辑 ...
}
```

### 4.3 PosDept 发布策略实现

#### 4.3.1 MERGE - 合并到门店

```java
private void mergePosDept(GroupDishBookData srcData, PosGroupDishBookRelease request, List<Long> sidList) {
  Map<Long, PosDept> srcPosDeptMap = srcData.posDeptMap;
  if (CollUtil.isEmpty(srcPosDeptMap)) {
    return;
  }

  for (Long sid : sidList) {
    // 查询门店已有 PosDept
    Map<Long, PosDept> destPosDeptMap = utilService.queryPosDeptMap(request.getMid(), sid);

    List<PosDept> toInsert = new ArrayList<>();
    for (PosDept srcDept : srcPosDeptMap.values()) {
      // 同名同类型部门已存在则跳过
      PosDept existing = findByNameAndType(destPosDeptMap, srcDept.getName(), srcDept.getType());
      if (existing != null) {
        continue;
      }
      // 创建门店副本，新生成 Lid
      PosDept storeDept = cloneAndAssignLid(srcDept, sid);
      toInsert.add(storeDept);
    }

    if (!toInsert.isEmpty()) {
      posDeptMapper.batchInsert(toInsert);
      // 更新 PosDishToPrnDept 映射
      updateDishToPrnDeptMapping(request.getMid(), sid, srcPosDeptMap, toInsert);
    }
  }
}
```

#### 4.3.2 COMPLETE_REPLACE - 完全替换

```java
private void completeReplacePosDept(GroupDishBookData srcData, PosGroupDishBookRelease request, List<Long> sidList) {
  Map<Long, PosDept> srcPosDeptMap = srcData.posDeptMap;

  for (Long sid : sidList) {
    // 删除门店所有出品部门
    posDeptMapper.deleteBySid(request.getMid(), sid);

    // 插入品牌出品部门（新 Lid）
    if (CollUtil.isNotEmpty(srcPosDeptMap)) {
      List<PosDept> toInsert = srcPosDeptMap.values().stream()
          .map(dept -> cloneAndAssignLid(dept, sid))
          .toList();
      posDeptMapper.batchInsert(toInsert);

      // 更新 PosDishToPrnDept 映射
      updateDishToPrnDeptMapping(request.getMid(), sid, srcPosDeptMap, toInsert);
    }

    // 清理缓存
    posDeptServicePlus.clearCache(request.getMid(), sid);
  }
}
```

#### 4.3.3 ONLY_UPDATE_SAME - 仅更新同名

```java
private void onlyUpdateSamePosDept(GroupDishBookData srcData, PosGroupDishBookRelease request, List<Long> sidList) {
  Map<Long, PosDept> srcPosDeptMap = srcData.posDeptMap;
  if (CollUtil.isEmpty(srcPosDeptMap)) {
    return;
  }

  for (Long sid : sidList) {
    Map<Long, PosDept> destPosDeptMap = utilService.queryPosDeptMap(request.getMid(), sid);

    for (PosDept srcDept : srcPosDeptMap.values()) {
      PosDept existing = findByNameAndType(destPosDeptMap, srcDept.getName(), srcDept.getType());
      if (existing == null) {
        continue;
      }
      // 更新已有部门的属性（保留 prnQueue）
      existing.setProfitDept(srcDept.getProfitDept());
      existing.setWmsDeptLids(srcDept.getWmsDeptLids());
      existing.setCashierDeptNames(srcDept.getCashierDeptNames());
      posDeptMapper.updateByLid(existing);
    }
  }
}
```

#### 4.3.4 ONLY_REMOVE_SAME - 删除同名

```java
private void onlyRemoveSamePosDept(GroupDishBookData srcData, PosGroupDishBookRelease request, List<Long> sidList) {
  Map<Long, PosDept> srcPosDeptMap = srcData.posDeptMap;
  if (CollUtil.isEmpty(srcPosDeptMap)) {
    return;
  }

  for (Long sid : sidList) {
    Map<Long, PosDept> destPosDeptMap = utilService.queryPosDeptMap(request.getMid(), sid);
    List<Long> toDelete = new ArrayList<>();

    for (PosDept srcDept : srcPosDeptMap.values()) {
      PosDept existing = findByNameAndType(destPosDeptMap, srcDept.getName(), srcDept.getType());
      if (existing != null) {
        toDelete.add(existing.getLid());
      }
    }

    if (!toDelete.isEmpty()) {
      posDeptMapper.deleteByLids(request.getMid(), sid, toDelete);
      // 清理相关映射
      clearDishToPrnDeptMapping(request.getMid(), sid, toDelete);
    }
  }
}
```

### 4.4 Lid 映射与关联更新

#### Lid 映射核心逻辑

| 实体 | 发布时 Lid 处理 | 说明 |
|------|---------------|------|
| PosDept | 品牌 Lid → 门店新 Lid | 雪花算法全局唯一，门店需新生成 Lid |
| PosDishToPrnDept | 品牌 Lid → 门店新 Lid | 同上，且 prnDeptLid 需指向门店部门新 Lid |

**关键**：品牌发布 PosDept 后，必须同步更新 PosDishToPrnDept 中的 prnDeptLid，指向门店部门的新 Lid。

#### Lid 映射实现

```java
// 发布时记录 Lid 映射
Map<Long, Long> lidMapping = new HashMap<>(); // brandLid -> storeLid

// 创建门店 PosDept 副本时建立映射
PosDept storeDept = cloneAndAssignLid(srcDept, sid);
lidMapping.put(srcDept.getLid(), storeDept.getLid());

#### PosDishToPrnDept 映射更新

品牌发布 PosDept 后，需同步更新菜品与部门的映射关系：

```java
private void updateDishToPrnDeptMapping(
    Long mid, Long sid,
    Map<Long, PosDept> srcPosDeptMap,
    List<PosDept> storePosDepts) {

  if (CollUtil.isEmpty(storePosDepts)) {
    return;
  }

  // 建立 name+type -> storeLid 的映射
  Map<String, Long> nameTypeToLid = storePosDepts.stream()
      .collect(Collectors.toMap(
          dept -> dept.getName() + "_" + dept.getType().code(),
          PosDept::getLid
      ));

  // 查询菜品与品牌部门关联
  List<PosDishToPrnDept> dishToDepts = posDishToPrnDeptMapper.listByMidSid(mid, sid);
  List<PosDishToPrnDept> toUpdate = new ArrayList<>();

  for (PosDishToPrnDept mapping : dishToDepts) {
    // 根据菜品 lid 找到对应的品牌部门，再映射到门店部门
    PosDept srcDept = srcPosDeptMap.get(mapping.getPrnDeptLid());
    if (srcDept != null) {
      String key = srcDept.getName() + "_" + srcDept.getType().code();
      Long storeLid = nameTypeToLid.get(key);
      if (storeLid != null) {
        mapping.setPrnDeptLid(storeLid);
        toUpdate.add(mapping);
      }
    }
  }

  if (!toUpdate.isEmpty()) {
    posDishToPrnDeptMapper.batchUpdatePrnDeptLid(toUpdate);
  }
}
```

### 4.5 prnQueue 过滤处理

门店打印机组与品牌可能不同，发布时需过滤无效的 prnQueue：

```java
private PosDept cloneAndAssignLid(PosDept srcDept, Long sid) {
  PosDept storeDept = new PosDept();
  storeDept.setMid(srcDept.getMid());
  storeDept.setSid(sid);
  storeDept.setLid(snowflakeIdGenerator.nextId()); // 新 Lid
  storeDept.setName(srcDept.getName());
  storeDept.setType(srcDept.getType());
  storeDept.setProfitDept(srcDept.getProfitDept());
  storeDept.setWmsDeptLids(srcDept.getWmsDeptLids());
  storeDept.setCashierDeptNames(srcDept.getCashierDeptNames());

  // 过滤无效的打印队列
  storeDept.setPrnQueue(filterPrnQueue(srcDept.getMid(), sid, srcDept.getPrnQueue()));

  return storeDept;
}

/**
 * 过滤掉门店不存在的打印队列
 */
private String filterPrnQueue(Long mid, Long sid, String prnQueueStr) {
  if (StringUtils.isBlank(prnQueueStr)) {
    return "";
  }

  Set<Long> validQueueLids = posPrnQueueMapper.listLidsByMidSid(mid, sid);
  return Stream.of(prnQueueStr.split(","))
      .filter(StringUtils::isNotBlank)
      .filter(lidStr -> {
        try {
          return validQueueLids.contains(Long.parseLong(lidStr));
        } catch (NumberFormatException e) {
          return false;
        }
      })
      .collect(Collectors.joining(","));
}
```

|------|------|----------|
| Lid 映射丢失 | 发布后菜品与部门关联失效 | 发布后同步更新 PosDishToPrnDept |

| 事务一致性 | PosDept 和 PosDishToPrnDept 更新非原子 | 使用同一事务包裹 |
