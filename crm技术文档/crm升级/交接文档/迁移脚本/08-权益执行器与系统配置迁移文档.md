## 1. 执行器类型字段

**文件名**：`V20260523__crm_actuator_type.sql`
**目标库**：CRM 数据库

```sql
ALTER TABLE `crm_actuator`
  ADD COLUMN `actuator_type` tinyint NOT NULL DEFAULT 0 COMMENT '执行器类型：0历史未知，1批量赠券，2批量充值' AFTER `name`;

CREATE INDEX `idx_mid_type_deleted` ON `crm_actuator` (`mid`, `actuator_type`, `deleted`);

-- 根据关联数据回填 actuator_type
UPDATE `crm_actuator` a
LEFT JOIN (
  SELECT `actuator_lid`, COUNT(*) AS `coupon_count`
  FROM `crm_actuator_coupon`
  WHERE COALESCE(`deleted`, 0) = 0
  GROUP BY `actuator_lid`
) c ON c.`actuator_lid` = a.`lid`
SET a.`actuator_type` =
  CASE
    WHEN IFNULL(c.`coupon_count`, 0) > 0 THEN 1
    WHEN IFNULL(a.`recharge_amount`, 0) > 0
      OR IFNULL(a.`give_amount`, 0) > 0
      OR IFNULL(a.`points`, 0) > 0 THEN 2
    ELSE 0
  END
WHERE COALESCE(a.`deleted`, 0) = 0;
```

### 1.1 字段说明

| 值 | 含义 |
|----|------|
| 0 | 历史未知 |
| 1 | 批量赠券 |
| 2 | 批量充值 |

## 4. 支付订单来源字段

**文件名**：`V20260519__pay_order_order_source.sql`

```sql
ALTER TABLE `pay_order`
  ADD COLUMN `order_source` TINYINT NOT NULL DEFAULT 1 COMMENT '支付订单来源：1-业务订单，2-门店收款码' AFTER `deal_type`;

UPDATE `pay_order`
SET `order_source` = 1
WHERE `order_source` IS NULL;

ALTER TABLE `pay_order`
  MODIFY COLUMN `order_source` TINYINT NOT NULL DEFAULT 1 COMMENT '支付订单来源：1-业务订单，2-门店收款码';
```

### 4.1 字段说明

| 值 | 含义 |
|----|------|
| 1 | 业务订单 |
| 2 | 门店收款码 |

历史数据统一归为业务订单（1），保持旧支付单兼容。
