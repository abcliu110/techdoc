# CRM 统一消费积分链路迁移文档

日期：2026-08-29
作者：guoyun_liu

## 1. 新建表：`crm_consume_points_task`

**文件名**：`V20260509_crm_consume_points_task.sql`
**目标库**：CRM 数据库（对应 `nms4cloud-crm` 数据源）

### 1.1 建表语句

```sql
CREATE TABLE IF NOT EXISTS `crm_consume_points_task` (
  `pid` BIGINT NOT NULL AUTO_INCREMENT COMMENT '物理主键',
  `company_id` BIGINT NOT NULL COMMENT '商户ID',
  `shop_id` BIGINT DEFAULT NULL COMMENT '门店ID',
  `lmnid` BIGINT NOT NULL COMMENT '业务逻辑主键',
  `source_` TINYINT NOT NULL COMMENT '积分来源：1-POS，2-云端订单',
  `task_lid` BIGINT DEFAULT NULL COMMENT 'CRM消费任务LID，仅储值消费链路存在',
  `bill_lid` BIGINT DEFAULT NULL COMMENT 'POS账单LID',
  `order_id` VARCHAR(64) NOT NULL COMMENT '消费订单号',
  `card_lid` BIGINT NOT NULL COMMENT '会员卡LID',
  `card_no` VARCHAR(64) NOT NULL COMMENT '会员卡号',
  `grant_points` DECIMAL(18,2) NOT NULL COMMENT '本次消费赠送积分',
  `grant_points_record_lid` BIGINT DEFAULT NULL COMMENT '赠分积分流水LID',
  `revoke_points_record_lid` BIGINT DEFAULT NULL COMMENT '撤销积分流水LID',
  `status_` TINYINT NOT NULL COMMENT '状态：1-已赠分，2-已撤销',
  `operator` VARCHAR(64) DEFAULT NULL COMMENT '赠分操作人',
  `comment` VARCHAR(255) DEFAULT NULL COMMENT '赠分备注',
  `grant_time` DATETIME DEFAULT NULL COMMENT '赠分时间',
  `revoke_time` DATETIME DEFAULT NULL COMMENT '撤销时间',
  `revoke_operator` VARCHAR(64) DEFAULT NULL COMMENT '撤销操作人',
  `revoke_comment` VARCHAR(255) DEFAULT NULL COMMENT '撤销备注',
  `revision` INT DEFAULT 0 COMMENT '数据版本',
  `created_by` VARCHAR(64) DEFAULT NULL COMMENT '创建人',
  `created_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_by` VARCHAR(64) DEFAULT NULL COMMENT '修改人',
  `updated_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '修改时间',
  `deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-否，1-是',
  PRIMARY KEY (`pid`),
  UNIQUE KEY `uk_crm_consume_points_task_order_card` (`company_id`, `source_`, `order_id`, `card_lid`, `deleted`),
  KEY `idx_crm_consume_points_task_lmnid` (`lmnid`),
  KEY `idx_crm_consume_points_task_task` (`task_lid`),
  KEY `idx_crm_consume_points_task_bill` (`bill_lid`),
  KEY `idx_crm_consume_points_task_status` (`status_`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='CRM统一消费积分任务';
```

### 1.2 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `company_id` | BIGINT | 商户 ID |
| `source_` | TINYINT | 积分来源：1-POS，2-云端订单 |
| `task_lid` | BIGINT | 仅储值消费链路存在，当前固定为 0 |
| `bill_lid` | BIGINT | POS 账单 LID |
| `order_id` | VARCHAR(64) | 消费订单号，幂等键组成部分 |
| `card_lid` | BIGINT | 会员卡 LID |
| `card_no` | VARCHAR(64) | 会员卡号 |
| `grant_points` | DECIMAL(18,2) | 本次消费赠送积分 |
| `grant_points_record_lid` | BIGINT | 赠分积分流水 LID |
| `revoke_points_record_lid` | BIGINT | 撤销积分流水 LID |
| `status_` | TINYINT | 状态：1-已赠分，2-已撤销 |

### 1.3 幂等键

唯一键：`uk_crm_consume_points_task_order_card` = `(company_id, source_, order_id, card_lid, deleted)`
