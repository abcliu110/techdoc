# 小程序商品券核销迁移文档

日期：2026-08-29
作者：guoyun_liu

## 1. 新增字段：`order_food` 券菜品核销凭证字段

**文件名**：
- Oracle/达梦版：`V20260529__order_product_coupon_columns.sql`
- MySQL 版：`V20260529__order_product_coupon_columns_mysql.sql`

**目标库**：`a_order`（订单库）

### 1.1 MySQL 建表语句

```sql
ALTER TABLE `order_food`
  ADD COLUMN `coupon_no` BIGINT NULL COMMENT '优惠券编号',
  ADD COLUMN `coupon_write_off_trace_no` VARCHAR(64) NULL COMMENT '券核销追踪号',
  ADD COLUMN `platform_certificate_id` VARCHAR(128) NULL COMMENT '平台券凭证ID(certificate_id)，POS作为DwdCoupon.couponNo',
  ADD COLUMN `platform_write_off_id` TEXT NULL COMMENT '平台券撤销凭证:MP存verify_results JSON,DP存逗号分隔verify_id',
  ADD COLUMN `product_coupon_business_type` VARCHAR(16) NULL COMMENT '商品券业务类型:WP会员券,MP美团/餐道,DP抖音',
  ADD COLUMN `platform_price` DECIMAL(18,4) NULL COMMENT '平台券面额,供POS DwdCoupon.faceAmount',
  ADD COLUMN `platform_paid_amount` DECIMAL(18,4) NULL COMMENT '平台券实收金额,供POS DwdCoupon.paidAmount',
  ADD COLUMN `write_off_channel` VARCHAR(64) NULL COMMENT '平台券核销渠道,供POS DwdCoupon.writeOffChannel';

ALTER TABLE `order_bill`
  ADD COLUMN `coupon_items` TEXT NULL COMMENT '券维度核算明细JSON',
  ADD COLUMN `product_items` TEXT NULL COMMENT '商品维度核算明细JSON',
  ADD COLUMN `product_coupon_items` TEXT NULL COMMENT '商品券与商品关系核算明细JSON';
```

### 1.2 order_food 新增字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `coupon_no` | BIGINT | 优惠券编号（会员商品券领券记录ID，平台券为空） |
| `coupon_write_off_trace_no` | VARCHAR(64) | 券核销追踪号（唯一定位券菜品行） |
| `platform_certificate_id` | VARCHAR(128) | 平台券凭证ID（prepare 返回的 certificate_id）；写入 POS DwdCoupon.couponNo |
| `platform_write_off_id` | TEXT | 平台券撤销凭证：MP 存 verifyResults JSON 数组，DP 存逗号分隔 verifyId |
| `product_coupon_business_type` | VARCHAR(16) | 商品券业务类型：WP/MP/DP |
| `platform_price` | DECIMAL(18,4) | 平台券面额；供 POS DwdCoupon.faceAmount |
| `platform_paid_amount` | DECIMAL(18,4) | 平台券实收金额；供 POS DwdCoupon.paidAmount |
| `write_off_channel` | VARCHAR(64) | 平台券核销渠道；供 POS DwdCoupon.writeOffChannel |

### 1.3 order_bill 新增字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `coupon_items` | TEXT | 券维度核算明细 JSON |
| `product_items` | TEXT | 商品维度核算明细 JSON |
| `product_coupon_items` | TEXT | 商品券与商品关系核算明细 JSON |

---

## 2. 幂等性

所有字段均使用幂等加列方式，每个字段独立检查存在性，可重复执行。
