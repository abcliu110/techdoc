## 三、票据状态机（必背）

```
开立(0) ──背书──▶ 背书中(1) ──到期──▶ 到期(2) ──兑现──▶ 已兑现(3)
   │                                              ▲
   │                                              │
   └────────────── 作废(5) ◀──(拒付)──────────────┘
```

| 状态 | 值 | 说明 |
|---|---|---|
| 开立 | 0 | 票据刚收到/开立 |
| 背书中 | 1 | 正在背书转让中 |
| 到期 | 2 | 到期等待处理 |
| 已兑现 | 3 | 已托收/已付款 |
| 拒付 | 4 | 银行退票 |
| 作废 | 5 | 人工作废 |

---

## 四、票据与AP/AR的关系

**票据是AP/AR核销的支付工具**

```
应收流程:
AR应收单 → CN应收票据 → 到期托收 → 收到钱 → 核销AR

应付流程:
AP应付单 → CN应付票据 → 到期付款 → 付出去 → 核销AP
```

**关键规则**:
- 应收票据金额 ≤ 关联AR未核销金额
- 应付票据金额 ≤ 关联AP未核销金额

## 六、CN vs AP/AR 的关键区别

| 维度 | AP/AR | CN票据管理 |
|---|---|---|
| 业务性质 | 债权债务记录 | 信用工具管理 |
| 支付方式 | 直接付款 | 延期+银行信用 |
| 生命周期 | 发生→核销→结清 | 开立→背书→到期→兑现 |
| 法规要求 | 会计法规 | 票据法 |
| 风险等级 | 中 | 中高（银行信用） |

## 八、一句话总结

> **CN票据管理 = 管理企业收付的信用凭证（银行承兑汇票、商业承兑汇票、支票），通过票据状态机追踪票据从开立到兑现的全过程，与AP/AR模块联动完成往来核销。**
