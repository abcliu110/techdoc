## 一、业务切面定义

### 1.1 切面边界

CN票据管理切面覆盖企业票据业务的完整生命周期：

```
CN切面边界
├── 前置依赖域    — AP/AR单据、GL账簿、CB银行账户
├── CN核心域      — 票据开立/收票、背书、到期、核销
└── 后置影响域    — GL凭证、CB资金、AP/AR核销
```

### 1.2 切面特征

| 特征 | 描述 |
|---|---|
| 业务性质 | 信用工具 + 资金管理 |
| 触发模式 | 事件驱动（收票/开票） + 定时驱动（到期提醒） |
| 参与者 | 财务部、销售部、采购部、银行 |
| 风险等级 | 中高（涉及银行信用） |
| 法规要求 | 票据法合规 |

## 三、业务分类（4业务）

### 3.1 应收票据业务

**业务定义**: 管理企业收到的银行承兑汇票、商业承兑汇票

**业务场景**:
- 客户以票据支付货款
- 票据背书转让给供应商
- 票据到期托收

**关键数据**:
| 字段 | 说明 |
|---|---|
| CN_RECEIVEBILL.FBillNo | 票据号码 |
| CN_RECEIVEBILL.FDrawerBank | 出票银行 |
| CN_RECEIVEBILL.FDrawer | 出票人 |
| CN_RECEIVEBILL.FPayee | 收票人 |
| CN_RECEIVEBILL.FAmount | 票据金额 |
| CN_RECEIVEBILL.FDueDate | 到期日期 |
| CN_RECEIVEBILL.FBillStatus | 票据状态 |
| CN_RECEIVEBILL.FEndorser | 背书人 |

**业务规则**:
- BR-CN-001: 应收票据金额必须等于或小于关联AR应收单的未核销金额
- BR-CN-002: 应收票据到期日不得早于当前日期
- BR-CN-003: 已背书票据不得再次背书

### 3.2 应付票据业务

**业务定义**: 管理企业开立的银行承兑汇票、商业承兑汇票

**业务场景**:
- 企业以票据支付供应商货款
- 票据到期付款
- 票据作废

**关键数据**:
| 字段 | 说明 |
|---|---|
| CN_PAYBILL.FBillNo | 票据号码 |
| CN_PAYBILL.FPayeeBank | 收款银行 |
| CN_PAYBILL.FPayee | 收款人 |
| CN_PAYBILL.FDrawer | 出票人（企业） |
| CN_PAYBILL.FAmount | 票据金额 |
| CN_PAYBILL.FDueDate | 到期日期 |
| CN_PAYBILL.FBillStatus | 票据状态 |
| CN_PAYBILL.FPayBillType | 票据类型 |

**业务规则**:
- BR-CN-004: 应付票据金额必须等于或小于关联AP应付单的未核销金额
- BR-CN-005: 银行承兑汇票需要银行授信额度
- BR-CN-006: 票据到期前必须有足够资金

### 3.3 票据背书转让业务

**业务定义**: 票据权利的转让操作

**业务场景**:
- 应收票据背书转让给供应商抵债
- 背书撤销（有限情况）

**关键数据**:
| 字段 | 说明 |
|---|---|
| CN_RECEIVEBILL.FEndorser | 当前持票人 |
| CN_RECEIVEBILL.FEndorseDate | 背书日期 |
| CN_RECEIVEBILL.FEndorsee | 被背书人 |

**业务规则**:
- BR-CN-007: 背书转让必须在票据到期日前
- BR-CN-008: 背书记录需完整保留（票据法要求）
- BR-CN-009: 银行承兑汇票可多次背书，商业承兑汇票受限

### 3.4 票据到期兑现业务

**业务定义**: 票据到期后的收款/付款处理

**业务场景**:
- 应收票据到期托收
- 应付票据到期付款
- 票据逾期处理

**关键数据**:
| 字段 | 说明 |
|---|---|
| CN_RECEIVEBILL.FCashDate | 兑现日期 |
| CN_RECEIVEBILL.FCashAmount | 兑现金额 |
| CN_PAYBILL.FPayDate | 付款日期 |
| CN_PAYBILL.FPayAmount | 付款金额 |

**业务规则**:
- BR-CN-010: 票据到期自动提醒
- BR-CN-011: 兑现时生成对应GL凭证
- BR-CN-012: 逾期票据需单独追踪处理

## 四、用例分析（6UC）

### 4.1 UC-CN-01: 应收票据登记

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-01 |
| 用例名称 | 应收票据登记 |
| 业务分类 | 应收票据业务 |
| 触发者 | 出纳(R-CN-01) |
| 前置条件 | 收到客户票据 |
| 后置条件 | CN_RECEIVEBILL记录创建，关联AR应收单 |

**基本流程**:
```
1. 出纳录入票据信息（票号、金额、出票人、到期日）
2. 系统校验票据号码唯一性
3. 出纳关联AR应收单（部分或全部核销）
4. 应收会计审核票据
5. 系统生成应收票据凭证
6. 更新AR应收单未核销金额
```

**分支流程**:
- 票据金额大于AR应收金额 → 提示超额
- 票据号码已存在 → 提示重复

### 4.2 UC-CN-02: 应付票据开立

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-02 |
| 用例名称 | 应付票据开立 |
| 业务分类 | 应付票据业务 |
| 触发者 | 应付会计(R-CN-03) |
| 前置条件 | 需付款给供应商，供应商接受票据 |
| 后置条件 | CN_PAYBILL记录创建，关联AP应付单 |

**基本流程**:
```
1. 应付会计录入票据信息（收款人、金额、到期日）
2. 选择开票银行（银行承兑/商业承兑）
3. 系统校验银行授信额度
4. 财务主管审批
5. 生成应付票据凭证
6. 更新AP应付单未核销金额
```

**分支流程**:
- 银行授信额度不足 → 提示额度不足
- 供应商不接受商业承兑 → 提示选择银行承兑

### 4.3 UC-CN-03: 票据背书转让

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-03 |
| 用例名称 | 票据背书转让 |
| 业务分类 | 票据背书转让业务 |
| 触发者 | 应收会计(R-CN-02) |
| 前置条件 | 持有未到期应收票据 |
| 后置条件 | CN_RECEIVEBILL背书人更新 |

**基本流程**:
```
1. 选择待背书应收票据
2. 录入被背书人信息（供应商）
3. 系统校验背书条件（到期日、未背书）
4. 生成背书记录
5. 更新票据当前持票人
```

**分支流程**:
- 票据已背书 → 提示不可重复背书
- 票据即将到期 → 提示背书风险

### 4.4 UC-CN-04: 应收票据到期兑现

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-04 |
| 用例名称 | 应收票据到期兑现 |
| 业务分类 | 应收票据业务 |
| 触发者 | 应收会计(R-CN-02) |
| 前置条件 | 应收票据到期 |
| 后置条件 | CN_RECEIVEBILL状态更新，生成收款凭证 |

**基本流程**:
```
1. 系统提示到期票据
2. 应收会计发起托收
3. 银行确认收款
4. 系统更新票据状态为"已兑现"
5. 生成收款凭证（借：银行存款 / 贷：应收票据）
6. 如有关联AR，核销处理
```

**分支流程**:
- 银行退票 → 标记逾期，更新状态
- 部分收款 → 生成部分核销记录

### 4.5 UC-CN-05: 应付票据到期付款

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-05 |
| 用例名称 | 应付票据到期付款 |
| 业务分类 | 应付票据业务 |
| 触发者 | 应付会计(R-CN-03) |
| 前置条件 | 应付票据到期 |
| 后置条件 | CN_PAYBILL状态更新，生成付款凭证 |

**基本流程**:
```
1. 系统提示到期应付票据
2. 财务主管审批付款
3. 出纳执行付款
4. 银行确认扣款
5. 系统更新票据状态为"已付款"
6. 生成付款凭证（借：应付票据 / 贷：银行存款）
7. 如有关联AP，核销处理
```

**分支流程**:
- 资金不足 → 提示资金不足，需融资
- 延期付款 → 需重新审批

### 4.6 UC-CN-06: 票据报表查询

| 属性 | 值 |
|---|---|
| 用例ID | UC-CN-06 |
| 用例名称 | 票据报表查询 |
| 业务分类 | 报表分析业务 |
| 触发者 | 财务主管(R-CN-04)、审计人员(R-CN-06) |
| 前置条件 | 存在票据数据 |
| 后置条件 | 报表展示 |

**基本流程**:
```
1. 选择报表类型（余额/执行流水/收发存）
2. 设置筛选条件（客户/供应商、状态、日期）
3. 系统查询CN_RECEIVEBILL/CN_PAYBILL
4. 计算余额和汇总数据
5. 展示报表，支持导出
```

**报表类型**:
| 报表 | 文件 | 说明 |
|---|---|---|
| 应收票据余额表 | ReceivableBillBalRpt | 按客户/票据状态汇总 |
| 应收票据执行流水 | ReceivableBillExcReport | 票据状态变更记录 |
| 应收票据收发存 | ReceivableBillTransactReport | 票据增减变动 |
| 应收票据使用流水 | BillRecReport | 票据核销使用记录 |
| 应付票据余额表 | PayBillBalReport | 按供应商/票据状态汇总 |

## 五、业务规则汇总

| 规则ID | 规则内容 | 业务分类 |
|---|---|---|
| BR-CN-001 | 应收票据金额≤关联AR未核销金额 | 应收票据 |

| BR-CN-006 | 票据到期前需有足够资金 | 应付票据 |

| BR-CN-008 | 背书记录需完整保留 | 背书转让 |
| BR-CN-009 | 银行承兑可多次背书，商业承兑受限 | 背书转让 |
| BR-CN-010 | 票据到期自动提醒 | 到期兑现 |
| BR-CN-011 | 兑现时生成GL凭证 | 到期兑现 |
| BR-CN-012 | 逾期票据单独追踪 | 到期兑现 |
