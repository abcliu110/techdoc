## 二、票据登记规则

### 2.1 BR-CN-101: 应收票据金额约束

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-101 |
| 规则名称 | 应收票据金额约束 |
| 规则类型 | 业务约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 登记应收票据 THEN
  票据金额 ≤ AR_RECEIVABLE.FUnWriteOffAmt
  AND 关联AR应收单状态 = 已审核
```

**违反处理**: 提示"票据金额不能大于关联应收单未核销金额"

### 2.2 BR-CN-102: 应付票据金额约束

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-102 |
| 规则名称 | 应付票据金额约束 |
| 规则类型 | 业务约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 开立应付票据 THEN
  票据金额 ≤ AP_PAYABLE.FUnWriteOffAmt
  AND 关联AP应付单状态 = 已审核
```

**违反处理**: 提示"票据金额不能大于关联应付单未核销金额"

### 2.3 BR-CN-103: 票据号码唯一性

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-103 |
| 规则名称 | 票据号码唯一性 |
| 规则类型 | 数据约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 登记票据 THEN
  CN_RECEIVEBILL.FBillNo NOT EXISTS IN CN_RECEIVEBILL
  OR CN_PAYBILL.FBillNo NOT EXISTS IN CN_PAYBILL
```

**违反处理**: 提示"票据号码已存在，请核实"

## 三、票据状态规则

### 3.1 BR-CN-201: 票据状态机

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-201 |
| 规则名称 | 票据状态机 |
| 规则类型 | 状态机 |
| 优先级 | P0 |

**状态机定义**:
```
状态值:
  0 = 开立
  1 = 背书中
  2 = 到期
  3 = 已兑现/已付款
  4 = 拒付
  5 = 作废

状态转换:
  开立(0) → 背书中(1) [背书转让]
  背书中(1) → 到期(2) [到期日到达]
  开立(0) → 到期(2) [到期日到达，无背书]
  到期(2) → 已兑现(3) [托收成功/付款成功]
  到期(2) → 拒付(4) [银行退票]
  开立(0) → 作废(5) [人工作废]
  背书中(1) → 作废(5) [人工作废，需收回票据]
```

### 3.2 BR-CN-202: 状态变更前置条件

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-202 |
| 规则名称 | 状态变更前置条件 |
| 规则类型 | 业务约束 |
| 优先级 | P1 |

**规则内容**:
```
IF 状态变更 THEN
  当前状态 = 允许变更状态
  AND 操作人具有相应权限
```

| 操作 | 要求状态 | 权限 |
|---|---|---|
| 背书 | 开立(0) | 背书权限 |
| 托收 | 到期(2) | 托收权限 |
| 付款 | 到期(2) | 付款权限 |
| 作废 | 开立(0)或背书中(1) | 作废权限 |

### 3.3 BR-CN-203: 应收票据状态变更约束

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-203 |
| 规则名称 | 应收票据状态变更约束 |
| 规则类型 | 业务约束 |
| 优先级 | P1 |

**规则内容**:
```
IF 应收票据兑现 THEN
  FBillStatus = 2(到期)
  AND FDueDate ≤ 当前日期
```

### 3.4 BR-CN-204: 应付票据状态变更约束

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-204 |
| 规则名称 | 应付票据状态变更约束 |
| 规则类型 | 业务约束 |
| 优先级 | P1 |

**规则内容**:
```
IF 应付票据付款 THEN
  FBillStatus = 2(到期)
  AND FDueDate ≤ 当前日期
  AND 银行账户余额 ≥ FAmount
```

## 四、票据核销规则

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-301 |
| 规则名称 | 票据核销关联 |
| 规则类型 | 业务约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 票据核销 THEN
  票据金额 = 关联AP/AR未核销金额
  OR 票据金额 ≤ 关联AP/AR未核销金额 [部分核销]
```

```
IF 票据核销 THEN
  生成核销凭证
  AND 更新AR/AP未核销金额
  AND 创建WRITEOFFRECORD
```

## 五、票据背书规则

### 5.1 BR-CN-401: 背书前置条件

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-401 |
| 规则名称 | 背书前置条件 |
| 规则类型 | 业务约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 背书转让 THEN
  FBillStatus = 开立(0) OR 背书中(1)
  AND FDueDate > 当前日期 [未到期]
  AND 票据未拒付
```

### 5.2 BR-CN-402: 背书记录完整性

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-402 |
| 规则名称 | 背书记录完整性 |
| 规则类型 | 合规约束 |
| 优先级 | P0 |

**规则内容**:
```
IF 背书转让 THEN
  创建CN_BILLENDORSERECORD
  AND 记录: FEndorser, FEndorsee, FEndorseDate, FAmount
```

### 5.3 BR-CN-403: 背书次数限制

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-403 |
| 规则名称 | 背书次数限制 |
| 规则类型 | 业务约束 |
| 优先级 | P2 |

**规则内容**:
```
IF 银行承兑汇票 THEN
  背书次数无限制
IF 商业承兑汇票 THEN
  背书次数 ≤ 3次 [企业信用风险控制]
```

## 六、票据到期规则

### 6.1 BR-CN-501: 到期提醒规则

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-501 |
| 规则名称 | 到期提醒规则 |
| 规则类型 | 提醒规则 |
| 优先级 | P1 |

**规则内容**:
```
IF 当前日期 = FDueDate - 7天 THEN
  发送到期提醒通知
  AND 更新票据状态 = 到期(2)
```

### 6.2 BR-CN-502: 逾期处理规则

| 属性 | 值 |
|---|---|
| 规则ID | BR-CN-502 |
| 规则名称 | 逾期处理规则 |
| 规则类型 | 业务约束 |
| 优先级 | P2 |

**规则内容**:
```
IF 票据状态 = 到期(2)
  AND FDueDate < 当前日期 - 30天
  AND 未兑现/付款 THEN
  标记为逾期
  AND 生成逾期报告
```

## 七、异常矩阵

| 异常场景 | 检测规则 | 处理方式 |
|---|---|---|
| 票据金额超AR未核销 | BR-CN-101 | 阻止登记，提示调整金额 |
| 票据号码重复 | BR-CN-103 | 阻止登记，提示核实 |
| 过期票据背书 | BR-CN-401 | 阻止背书，提示到期风险 |
| 已兑现票据再次核销 | BR-CN-303 | 阻止核销，提示状态异常 |
| 商业承兑超次背书 | BR-CN-403 | 阻止背书，提示次数限制 |
| 资金不足付款 | BR-CN-204 | 阻止付款，提示充值 |
| 背书记录缺失 | BR-CN-402 | 阻止背书完成，强制记录 |
