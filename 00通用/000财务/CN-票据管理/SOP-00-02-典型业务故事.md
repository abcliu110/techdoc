# CN票据管理SOP-00-02-典型业务故事

## 故事一：收到银行承兑汇票

### 故事背景

华新公司向深圳科技公司销售了一批设备，合同金额50万元。客户以银行承兑汇票(B/A)支付，票据3个月后到期。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 出纳 | 小王 | 收票登记 |
| 应收会计 | 小李 | 票据审核、关联AR |
| 财务主管 | 老张 | 复核 |

### 业务时间线

```
T日 ──────────────────────────────────────────────────────────────────
│
├─ 事件1：收到银行承兑汇票
│   角色：小王
│   操作：收到客户交付的银行承兑汇票
│   票据信息：
│     - 票号：3010XXXX/XXXX/XXXXX
│     - 出票人：深圳科技公司
│     - 收款人：华新公司
│     - 票面金额：50万元
│     - 出票银行：招商银行深圳分行
│     - 到期日：3个月后
│   结果：票据物理件已收到
│
├─ 事件2：应收票据登记
│   角色：小王
│   操作：在系统中录入应收票据信息
│   系统响应：
│     - 创建CN_RECEIVEBILL记录
│     - 校验票据号码唯一性
│     - 关联AR应收单（销售设备50万元）
│   结果：CN_RECEIVEBILL已创建
│
├─ 事件3：关联AR应收单
│   角色：小李
│   操作：关联应收票据与AR应收单
│   系统响应：
│     - 查询AR_RECEIVABLE未核销金额=50万
│     - 校验票据金额≤AR未核销金额
│     - 更新AR关联票据金额
│   结果：AR应收单已关联票据
│
├─ 事件4：票据审核
│   角色：小李
│   操作：审核应收票据
│   系统响应：
│     - 生成收票凭证
│     - 借：应收票据 50万 / 贷：应收账款-深圳科技 50万
│     - 创建BAS_BusinessVoucher映射
│   结果：票据审核通过
│
└─ 事件5：票据复核
    角色：老张
    操作：复核票据登记
    结果：复核通过
```

## 故事二：应收票据背书转让给供应商

### 故事背景

华新公司需支付材料供应商顺风材料款48万元，手头有一张即将到期的银行承兑汇票（金额50万元），决定背书转让。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 应收会计 | 小李 | 执行背书转让 |
| 财务主管 | 老张 | 大额背书审批 |

### 业务时间线

```
T日 ──────────────────────────────────────────────────────────────────
│
├─ 事件1：准备背书转让
│   角色：小李
│   操作：选择待背书应收票据
│   系统响应：
│     - 查询票据状态=开立(0)
│     - 校验到期日>当前日期
│     - 查询背书次数=0
│   结果：票据符合背书条件
│
├─ 事件2：录入被背书人信息
│   角色：小李
│   操作：选择供应商"顺风材料"
│   系统响应：
│     - 校验供应商状态=有效
│     - 提示背书金额将全额转让
│   结果：被背书人已选择
│
├─ 事件3：大额背书审批
│   角色：老张
│   操作：审批48万元背书转让
│   结果：审批通过
│
├─ 事件4：执行背书
│   角色：小李
│   操作：在票据背面签章，执行背书
│   系统响应：
│     - 创建CN_BILLENDORSERECORD记录
│     - 更新CN_RECEIVEBILL.FEndorser=顺风材料
│     - 更新CN_RECEIVEBILL.FBillStatus=背书中(1)
│   结果：背书完成，票据转让给供应商
│
└─ 事件5：背书复核
    角色：老张
    操作：复核背书记录
    结果：背书复核通过，记录符合票据法要求
```

### 背书转让的影响

```
背书前:
- 华新公司持有应收票据50万（客户欠华新的钱）

背书后:
- 顺风材料持有应收票据50万（客户欠顺风材料的钱）
- 华新公司不再持有票据，但获得了材料

会计分录（背书时不入账，仅在票据到期时）:
- 顺风材料到期托收：借：银行存款 50万 / 贷：应收票据 50万
```

## 故事三：应收票据到期托收

### 故事背景

华新公司有一张应收银行承兑汇票（金额30万元）今天到期，需要发起托收。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 应收会计 | 小李 | 发起托收 |
| 银行 | 招商银行 | 确认收款 |

### 业务时间线

```
到期日 ────────────────────────────────────────────────────────────────
│
├─ 事件1：系统到期提醒
│   角色：系统
│   系统响应：
│     - 查询FDueDate=今天的所有票据
│     - 更新CN_RECEIVEBILL.FBillStatus=到期(2)
│     - 发送到期提醒通知
│   结果：票据状态已更新为到期
│
├─ 事件2：发起托收
│   角色：小李
│   操作：选择到期票据，发起托收
│   系统响应：
│     - 校验票据状态=到期(2)
│     - 校验FDueDate≤当前日期
│     - 选择收款银行账户
│   结果：托收申请已提交
│
├─ 事件3：银行确认收款
│   角色：银行（系统对接）
│   操作：银行确认票据真实性，划拨资金
│   系统响应：
│     - 创建CN_BILLCASHRECORD记录
│     - 更新CN_BILLCASHRECORD.FCashStatus=成功
│     - 更新CN_RECEIVEBILL.FCashedAmount=30万
│     - 更新CN_RECEIVEBILL.FBillStatus=已兑现(3)
│   结果：资金已到账
│
├─ 事件4：生成收款凭证
│   角色：系统
│   系统响应：
│     - VoucherGenerateServiceHelper生成凭证
│     - 借：银行存款 30万 / 贷：应收票据 30万
│     - 创建BAS_BusinessVoucher映射
│   结果：凭证已生成
│
└─ 事件5：核销关联AR应收单
    角色：系统
    系统响应：
      - 查询关联的AR_RECEIVABLE
      - 更新FUnWriteOffAmt=0
      - 创建AR_WRITEOFFRECORD
    结果：AR应收单已核销
```

## 故事四：应付票据开立与到期付款

### 故事背景

华新公司向供应商大明设备采购设备，需支付货款80万元。供应商接受银行承兑汇票，华新公司申请开立银行承兑汇票。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 应付会计 | 小李 | 录入应付票据 |
| 财务主管 | 老张 | 审批开票 |
| 出纳 | 小王 | 执行付款 |
| 银行 | 招商银行 | 承兑付款 |

### 业务时间线

```
T日 ──────────────────────────────────────────────────────────────────
│
├─ 事件1：录入应付票据
│   角色：小李
│   操作：开立银行承兑汇票
│   票据信息：
│     - 收款人：大明设备
│     - 票面金额：80万元
│     - 出票人：华新公司
│     - 出票银行：招商银行
│     - 到期日：6个月后

│     - 创建CN_PAYBILL记录

│   结果：应付票据已录入
│
├─ 事件2：关联AP应付单
│   角色：小李

│   结果：票据状态已更新为到期
│
├─ 事件6：审批付款
```

## 故事五：商业承兑汇票的信用风险

### 故事背景

华新公司收到客户顺达公司开具的商业承兑汇票(30万元)。到期后发起托收，但顺达公司账户余额不足，银行退票。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 应收会计 | 小李 | 处理退票 |
| 财务主管 | 老张 | 制定催收方案 |

### 业务时间线

```
到期日 ────────────────────────────────────────────────────────────────
│
├─ 事件1：发起托收
│   角色：小李
│   操作：对应收商业承兑汇票发起托收
│   系统响应：
│     - 托收请求已发送至银行
│   结果：等待银行处理
│
├─ 事件2：银行退票
│   角色：银行（系统对接）
│   系统响应：
│     - 更新CN_BILLCASHRECORD.FCashStatus=失败
│     - 更新CN_RECEIVEBILL.FBillStatus=拒付(4)
│     - 发送退票通知
│   结果：票据拒付
│
├─ 事件3：标记逾期
│   角色：系统
│   系统响应：
│     - 30天后更新逾期标记
│     - 生成逾期报告
│   结果：票据标记为逾期
│
└─ 事件4：制定催收方案
    角色：老张
    操作：联系顺达公司，制定还款计划
    结果：催收方案已制定，款项逐步收回
```

### 商业承兑 vs 银行承兑的关键区别

| 维度 | 银行承兑汇票(B/A) | 商业承兑汇票(C/A) |
|---|---|---|
| 信用担保 | 银行信用，银行必须付款 | 企业信用，可能拒付 |
| 风险等级 | 低（银行兜底） | 中（依赖企业信用） |
| 背书次数 | 无限制 | ≤3次（风险控制） |
| 融资难度 | 易（可贴现） | 难（银行不愿贴现） |
| 使用场景 | 大额交易 | 中小额交易 |

## 故事六：票据报表分析

### 故事背景

华新公司财务部需要在季度末分析票据情况，了解应收/应付票据的余额、到期分布。

### 业务角色

| 角色 | 姓名 | 操作 |
|---|---|---|
| 财务主管 | 老张 | 查看票据报表 |
| 应收会计 | 小李 | 解读报表数据 |

### 业务时间线

```
季度末 ────────────────────────────────────────────────────────────────
│
├─ 事件1：查看应收票据余额表
│   角色：老张
│   操作：打开ReceivableBillBalRpt
│   系统响应：
│     - 按客户汇总应收票据余额
│     - 按票据状态分组
│   结果：应收票据余额报表
│
│   报表数据示例：
│   ┌─────────────┬────────┬────────┬────────┬────────┐
│   │ 客户        │ 开立   │ 背书中 │ 到期   │ 拒付   │
│   ├─────────────┼────────┼────────┼────────┼────────┤
│   │ 深圳科技    │ 50万   │ 0      │ 30万   │ 0      │
│   │ 顺达公司    │ 0      │ 0      │ 0      │ 30万   │
│   │ 顺风材料    │ 0      │ 48万   │ 0      │ 0      │
│   └─────────────┴────────┴────────┴────────┴────────┘
│
├─ 事件2：查看票据执行流水
│   角色：老张
│   操作：打开ReceivableBillExcReport
│   系统响应：
│     - 查询本季度票据状态变更历史
│     - 按时间轴展示
│   结果：本季度执行流水报表
│
├─ 事件3：分析到期分布
│   角色：小李
│   操作：按到期日期分析票据分布
│   发现：
│     - 未来30天到期：20万
│     - 31-60天到期：50万
│     - 61-90天到期：30万
│     - 90天以上到期：10万
│   决策：提前安排资金
│
└─ 事件4：制定资金计划
    角色：老张
    操作：根据报表制定下季度资金计划
    结果：资金计划已制定
```
