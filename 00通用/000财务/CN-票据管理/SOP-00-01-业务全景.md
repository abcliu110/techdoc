### 1.2 CN的核心职责

| 职责 | 说明 |
|---|---|
| 应收票据管理 | 记录企业收到的银行承兑汇票、商业承兑汇票 |
| 应付票据管理 | 记录企业开立的银行承兑汇票、商业承兑汇票 |
| 票据背书转让 | 管理票据权利的转让（票据法合规） |
| 票据到期处理 | 应收票据托收、应付票据付款 |
| 票据核销关联 | 与AR/AP模块联动完成往来核销 |
| 票据报表分析 | 余额、执行流水、收发存、使用流水 |

## 五、切片分级与优先级

### 5.1 切片分级矩阵

| 切片ID | 切片名称 | 深度级 | 分值 | 业务重要性 | 技术风险 |
|---|---|---|---|---|---|
| SC-P0-01 | 票据登记与审核 | P0 | 18 | 核心业务，不可替代 | 金额校验复杂 |
| SC-P0-02 | 票据状态机 | P0 | 15 | 状态转换逻辑复杂 | 状态一致性 |
| SC-P1-01 | 票据背书转让 | P1 | 14 | 票据法合规要求 | 背书记录完整性 |
| SC-P1-02 | 票据到期处理 | P1 | 12 | 高频，到期提醒 | 自动状态更新 |
| SC-P1-03 | 票据报表 | P1 | 10 | 重要非第一焦点 | 数据准确性 |
| SC-P2-01 | 票据作废 | P2 | 6 | 低频边缘场景 | 状态一致性 |
| SC-P3-01 | 期初开账 | P3 | 4 | 初始化场景 | 历史数据处理 |

### 5.2 优先级说明

```
P0: 票据登记与审核 + 状态机（核心中的核心）
    ↓
P1: 票据背书转让 + 到期处理 + 报表（高频重要）
    ↓
P2: 票据作废（边缘但有价值）
    ↓
P3: 期初开账（初始化场景）
```

## 六、与相关模块的交互

## 八、CN vs AR/AP业务对比

| 对比维度 | AR应收管理 | AP应付管理 | CN票据管理 |
|---|---|---|---|
| 核心职责 | 记录客户欠款 | 记录企业欠供应商款 | 管理延期付款信用凭证 |
| 信用性质 | 无信用（直接付款） | 无信用（直接付款） | 银行/企业信用担保 |
| 支付方式 | 即时付款 | 即时付款 | 延期付款 |
| 生命周期 | 发生→核销→结清 | 发生→核销→结清 | 开立→背书→到期→兑现 |
| 法规要求 | 会计法规 | 会计法规 | 票据法 |
| 银行角色 | 无 | 无 | 银行承兑汇票涉及银行 |
| 核销关联 | - | - | 与AR/AP联动 |
