## 二、API设计（15个核心API）

### 2.1 应收票据API

| API ID | API名称 | 路径 | 方法 | 说明 |
|---|---|---|---|---|
| API-CN-01 | 应收票据登记 | /api/CN/ReceivableBill/Create | POST | 创建应收票据 |
| API-CN-02 | 应收票据查询 | /api/CN/ReceivableBill/Get | GET | 按ID查询票据 |
| API-CN-03 | 应收票据列表 | /api/CN/ReceivableBill/Query | POST | 条件查询票据 |
| API-CN-04 | 应收票据审核 | /api/CN/ReceivableBill/Audit | POST | 审核票据 |
| API-CN-05 | 应收票据作废 | /api/CN/ReceivableBill/Cancel | POST | 作废票据 |

### 2.2 应付票据API

| API ID | API名称 | 路径 | 方法 | 说明 |
|---|---|---|---|---|
| API-CN-06 | 应付票据开立 | /api/CN/PayBill/Create | POST | 创建应付票据 |
| API-CN-07 | 应付票据查询 | /api/CN/PayBill/Get | GET | 按ID查询票据 |
| API-CN-08 | 应付票据列表 | /api/CN/PayBill/Query | POST | 条件查询票据 |
| API-CN-09 | 应付票据审核 | /api/CN/PayBill/Audit | POST | 审核票据 |
| API-CN-10 | 应付票据付款 | /api/CN/PayBill/Pay | POST | 执行付款 |

### 2.3 票据背书API

### 2.4 票据兑现API

## 三、服务类设计

### 3.1 CN模块ServiceHelper

| 服务类 | 职责 | 关键方法 |
|---|---|---|
| CNBillServiceHelper | 票据核心服务 | CreateBill, UpdateBill, CancelBill |
| CNReceivableBillServiceHelper | 应收票据服务 | ReceiveBill, CashBill, EndorseBill |
| CNPayBillServiceHelper | 应付票据服务 | IssueBill, PayBill |
| CNEndorseServiceHelper | 背书服务 | Endorse, QueryEndorseHistory |
| CNCashServiceHelper | 兑现服务 | Cash, QueryCashHistory |
| CNReportServiceHelper | 报表服务 | GetBalanceReport, GetFlowReport |
| CNOpenServiceHelper | 期初开账 | GetReceivableBillBalance, GetPayBillBalance |
