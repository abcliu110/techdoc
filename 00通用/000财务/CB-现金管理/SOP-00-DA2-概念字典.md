## 二、概念全景卡

### GC-01 现金账户
```
① 身份：企业存放现金的账户，用于零星收支
② 结构：账户编码 + 账户名称 + 余额 + 币别
③ 关系：被收款单/付款单引用；关联现金日记账
④ 行为：余额增加（收款）、余额减少（付款）
⑤ 交互：出纳操作、会计查询
⑥ 生命：创建账户 → 日常收付 → 余额变动 → 期末对账
⑦ 实现：CB_CASHACCOUNT表
⑧ 失败：余额不足导致付款失败
⑨ 证据：E-DOC-001 §5.1
⑩ 未知：账户限额配置
```

### GC-02 银行账户
```
① 身份：企业在银行开设的账户，用于大额收支
② 结构：账户编码 + 账户名称 + 银行名称 + 账号 + 余额 + 币别
③ 关系：被收付款单引用；关联银行日记账；与CN票据联动
④ 行为：余额增加（收款）、余额减少（付款）、银企互联
⑤ 交互：出纳操作、银企互联
⑥ 生命：开户 → 日常收付 → 余额变动 → 期末对账 → 销户
⑦ 实现：CB_BANKACCOUNT表
⑧ 失败：余额不足、网银接口异常
⑨ 证据：E-DOC-001 §5.1
⑩ 未知：支持哪些银行
```

### GC-03 日记账
```
① 身份：按时间顺序逐笔记录资金收支的账簿
② 结构：日期 + 凭证号 + 摘要 + 收入 + 支出 + 余额
③ 关系：关联收付款单、凭证、银行账户
④ 行为：记录每笔收支、自动计算余额
⑤ 交互：出纳录入、会计查询、审计追溯
⑥ 生命：收款/付款 → 生成日记账 → 定期对账
⑦ 实现：CashJournal.cs/BankJournal.cs
⑧ 失败：数据不一致、重复记录
⑨ 证据：E-DOC-001 §5.1
⑩ 未知：历史数据清理规则
```

### GC-04 收付款流水
```
① 身份：每一笔收付款的详细记录
② 结构：流水号 + 日期 + 金额 + 方向 + 对方单位 + 关联单据
③ 关系：关联账户、业务单据、凭证
④ 行为：记录流水、汇总日报
⑤ 交互：系统自动生成
⑥ 生命：收付款发生 → 生成流水 → 汇总日报 → 历史归档
⑦ 实现：CB_RECEIVEFLOW/CB_PAYFLOW表
⑧ 失败：数据丢失、重复流水
⑨ 证据：E-DOC-001 §5.1
⑩ 未知：流水号生成规则
```

### GC-05 银行对账
```
① 身份：账面余额与银行流水的核对过程
② 结构：对账期间 + 账面余额 + 银行余额 + 差异
③ 关系：关联银行账户、银行对账单、日记账
④ 行为：核对收支、标记已达/未达、生成调节表
⑤ 交互：出纳执行、财务主管复核
⑥ 生命：期末对账 → 差异分析 → 余额调节 → 对账完成
⑦ 实现：FinalReconReport.cs
⑧ 失败：大量差异无法解释
⑨ 证据：E-DOC-001 §5.2
⑩ 未知：对账单导入格式
```

### CB-01 资金日报
```
① 身份：每日资金收支汇总报表
② 结构：日期 + 账户 + 昨日余额 + 今日收入 + 今日支出 + 今日余额
③ 关系：关联账户、日记账
④ 行为：日末自动汇总、生成报表
⑤ 交互：出纳查看、会计汇总
⑥ 生命：日末汇总 → 生成日报 → 历史存档
⑦ 实现：CashDailyReport.cs/BankDailyReport.cs + DailyDataHelper
⑧ 失败：数据不完整
⑨ 证据：E-DOC-001 §5.1
⑩ 未知：汇总时间点配置
```

### CB-02 余额调节表
```
① 身份：反映未达账项的调节表格
② 结构：账面余额 + 加：银行已收企业未收 + 减：银行已付企业未付 + 调节后余额
③ 关系：关联银行对账结果
④ 行为：计算未达账项、生成调节表
⑤ 交互：财务主管查看
⑥ 生命：对账后生成 → 查看 → 存档
⑦ 实现：BalAdjustmentReport.cs + CalculateAdjustAmount
⑧ 失败：差异无法调节
⑨ 证据：E-DOC-001 §5.2
⑩ 未知：历史调节表保留期限
```

### CB-03 资金头寸
```
① 身份：企业可用的资金余额及未来预测
② 结构：账户 + 当前余额 + 未来收款 + 未来付款 + 预测余额
③ 关系：关联账户、应收应付到期数据
④ 行为：实时查询、预测未来、预警缺口
⑤ 交互：财务主管查询
⑥ 生命：实时监控 → 数据预测 → 缺口预警
⑦ 实现：FundPositionReport.cs（INSERT临时表+小计）
⑧ 失败：预测偏差
⑨ 证据：E-DOC-001 §5.2
⑩ 未知：预测周期范围
```

### CB-04 银企互联
```
① 身份：银行与企业系统的直连对接
② 结构：银行接口配置 + API地址 + 授权信息
③ 关系：关联银行账户、付款单
④ 行为：余额查询、流水下载、付款提交
⑤ 交互：出纳操作、系统自动
⑥ 生命：配置 → 日常使用 → 银行接口调用
⑦ 实现：WBOpenServiceHelper
⑧ 失败：接口超时、认证失败
⑨ 证据：E-DOC-001 §5.4
⑩ 未知：支持银行数量
```

### CB-05 网银付款
```
① 身份：通过网银系统完成的付款
② 结构：付款单 + 银行接口 + 付款状态
③ 关系：关联银行账户、付款单
④ 行为：提交银行 → 执行付款 → 回写状态
⑤ 交互：出纳发起 → 银行执行
⑥ 生命：发起 → 提交银行 → 执行 → 回写状态
⑦ 实现：SubmitToBankPay
⑧ 失败：余额不足、网银拒绝
⑨ 证据：E-DOC-001 §5.4
⑩ 未知：付款重试机制
```

### CB-06 银行余额
```
① 身份：银行账户的实时余额
② 结构：账户 + 余额 + 查询时间
③ 关系：关联银行账户
④ 行为：实时查询、定时同步
⑤ 交互：出纳查询、系统自动
⑥ 生命：定时查询 → 更新余额 → 预警
⑦ 实现：QueryBalanceForBankAcct
⑧ 失败：查询超时
⑨ 证据：E-DOC-001 §5.4
⑩ 未知：查询频率配置
```

### CB-07 未达账项
```
① 身份：已记账但银行未达，或银行已记账但未记账
② 结构：类型（收/付）+ 金额 + 日期 + 说明
③ 关系：关联银行对账结果
④ 行为：记录差异、生成调节表
⑤ 交互：系统自动识别
⑥ 生命：对账发现 → 记录 → 调节 → 到达
⑦ 实现：CB_BALANCEADJUSTMENT表 + CalculateAdjustAmount
⑧ 失败：长期未达
⑨ 证据：E-DOC-001 §5.2
⑩ 未知：未达账项清理规则
```

### CB-08 出纳凭证
```
① 身份：收付款业务生成的GL凭证
② 结构：凭证号 + 借方科目 + 贷方科目 + 金额
③ 关系：关联收付款单、日记账
④ 行为：收款生成凭证、付款生成凭证
⑤ 交互：会计复核
⑥ 生命：收付款 → 生成凭证 → 过账GL
⑦ 实现：GlVoucherForCNServiceHelper + RecordBillVchInfoServiceHelper
⑧ 失败：凭证生成失败
⑨ 证据：E-DOC-001 §6.1
⑩ 未知：凭证模板配置
```
