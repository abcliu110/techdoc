# DA3 关系分析 — K3Cloud CB现金管理

## 一、业务对象识别

### 1.1 核心业务对象清单

| 对象编号 | 对象名称 | 业务定义 | 生命周期 | 边界 |
|---|---|---|---|---|
| BO-01 | 现金账户 | 企业存放现金的账户 | 创建→使用→余额变动→注销 | 只能关联现金日记账 |
| BO-02 | 银行账户 | 企业在银行开设的账户 | 开户→使用→余额变动→销户 | 可关联银行日记账和票据 |
| BO-03 | 收款单 | 记录收款业务的单据 | 创建→审核→生成凭证→核销 | 关联AR应收单 |
| BO-04 | 付款单 | 记录付款业务的单据 | 创建→审核→生成凭证→核销 | 关联AP应付单 |
| BO-05 | 日记账 | 逐笔记录资金收支 | 记录→汇总→对账→存档 | 按账户类型区分 |
| BO-06 | 银行对账 | 账实核对 | 对账→差异分析→调节→完成 | 按期间组织 |
| BO-07 | 资金头寸 | 可用资金及预测 | 实时监控→预测→预警 | 按组织维度 |
| BO-08 | GL凭证 | 总账记账凭证 | 生成→审核→过账 | 关联收付款单 |

### 1.2 业务对象之间的关系

| 关系编号 | 对象A | 对象B | 关联类型 | 业务意义 |
|---|---|---|---|---|
| OR-01 | 现金账户 | 日记账 | 结构 | 日记账按账户类型分类 |
| OR-02 | 银行账户 | 日记账 | 结构 | 日记账按账户类型分类 |
| OR-03 | 收款单 | 银行账户 | 归因 | 收款登记到指定账户 |
| OR-04 | 付款单 | 银行账户 | 归因 | 付款从指定账户支出 |
| OR-05 | 收款单 | GL凭证 | 轨迹 | 收款生成凭证 |
| OR-06 | 付款单 | GL凭证 | 轨迹 | 付款生成凭证 |
| OR-07 | 银行账户 | CN票据 | 结构 | 票据付款使用银行账户 |
| OR-08 | 日记账 | GL凭证 | 轨迹 | 日记账与凭证关联追溯 |

## 二、关键业务路径

### 2.1 核心业务路径图

```
收款单审核 ──▶ GL凭证生成 ──▶ 日记账记录 ──▶ 资金余额增加
     │                              │
     │                              ▼
     │                       资金日报汇总
     │
     ▼
关联AR应收单核销

付款单审核 ──▶ GL凭证生成 ──▶ 日记账记录 ──▶ 资金余额减少
     │                              │
     │                              ▼
     │                       资金日报汇总
     │
     ▼
关联AP应付单核销

期末 ──▶ 银行对账单导入 ──▶ 日记账核对 ──▶ 余额调节表

银行账户 ──▶ 银企互联 ──▶ 网银付款 ──▶ 付款单完成
```

### 2.2 路径与业务场景映射

| 路径编号 | 路径 | 跳数 | 关键业务场景 | 为什么需要这条路径 |
|---|---|---|---|---|
| BP-CB-01 | 收款单→GL凭证→日记账 | 2跳 | 收款业务全流程 | 凭证是日记账的数据源 |
| BP-CB-02 | 付款单→GL凭证→日记账 | 2跳 | 付款业务全流程 | 凭证是日记账的数据源 |
| BP-CB-03 | 银行账户→日记账→对账 | 2跳 | 期末对账 | 日记账是对账的基础 |
| BP-CB-04 | 银行账户→银企互联→付款 | 2跳 | 网银付款 | 银企互联提高效率 |
| BP-CB-05 | 收款单→AR应收单 | 1跳 | 收款核销 | 收款用于核销应收 |
| BP-CB-06 | 付款单→AP应付单 | 1跳 | 付款核销 | 付款用于核销应付 |
| BP-CB-07 | 银行账户→CN票据→付款 | 2跳 | 票据付款 | 票据到期通过银行付款 |
| BP-CB-08 | 日记账→GL凭证→追溯 | 2跳 | 凭证追溯 | 从日记账追溯到凭证 |

## 四、关联关系详细契约

### REL-01：收款单 ↔ GL凭证

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-01: 收款单 ↔ GL凭证                                         │
├─────────────────────────────────────────────────────────────────┤
│ 【关系定义】                                                      │
│   类型：1:1（一个收款单生成一张凭证）                             │
│   方向：收款单 → GL凭证                                          │
│   关联路径：直接（0跳）                                          │
│                                                                 │
│ 【字段连接】                                                      │
│   收款单.凭证号 ←→ GL_VOUCHER.FVOUCHERID                        │
│                                                                 │
│ 【建立时机】                                                      │
│   配置时建立：收款单审核时自动触发凭证生成                        │
│   运行时路由：凭证模板方案 BuildVoucherByScheme                  │
│                                                                 │
│ 【约束条件】                                                      │
│   ✓ 收款金额必须大于0                                            │
│   ✓ 借贷必须平衡                                                  │
│   ✓ 科目必须合法                                                  │
│                                                                 │
│ 【使用方式】                                                      │
│   出纳审核收款单 → 系统自动生成凭证 → 会计复核凭证                │
│                                                                 │
│ 【修改影响】                                                      │
│   修改收款单：不影响已生成凭证                                    │
│   删除收款单：需先反审核，凭证一并作废                            │
│                                                                 │
│ 【异常场景】                                                      │
│   场景1：凭证生成失败 → 提示错误，人工重试                        │
│   场景2：借贷不平衡 → 提示错误，修正后重试                        │
│   场景3：科目不合法 → 提示错误，重新选择                          │
│                                                                 │
│ 【代码位置】                                                      │
│   后端：VoucherGenerateServiceHelper.BuildVoucher                 │
│   凭证关联：GlVoucherForCNServiceHelper                          │
│                                                                 │
│ 【证据】                                                          │
│   E-DOC-001 §6.1                                                 │
└─────────────────────────────────────────────────────────────────┘
```

```

├─────────────────────────────────────────────────────────────────┤
│ 【关系定义】                                                      │

│   方向：GL凭证 → 日记账                                          │
│   关联路径：直接（0跳）                                          │

│                                                                 │
│ 【建立时机】                                                      │
│   配置时建立：凭证生成后自动写入日记账                            │
│   运行时路由：按账户类型分别写入现金/银行日记账                  │
│                                                                 │
│ 【约束条件】                                                      │
│   ✓ 凭证科目必须为现金或银行存款                                  │

│   场景2：日记账缺失凭证 → 补录或重新生成                          │
│                                                                 │
│ 【代码位置】                                                      │
│   后端：RecordBillVchInfoServiceHelper回写凭证信息               │
│                                                                 │
│ 【证据】                                                          │
│   E-DOC-001 §6.1                                                 │
└─────────────────────────────────────────────────────────────────┘
```
