## 三、DEC决策卡

### DEC-CB-01：为什么日报使用临时表汇总？
```
┌─────────────────────────────────────────────────────────────────┐
│ DEC-CB-01: 为什么日报使用临时表汇总？                             │
├─────────────────────────────────────────────────────────────────┤
│ 决策点：日报数据汇总方式                                          │
│                                                                 │
│ 当时约束：                                                       │
│   - 日报需要按账户+日期汇总大量流水数据                           │
│   - FastReport模式需要中间数据                                   │
│   - 实时查询性能要求                                            │
│                                                                 │
│ 可选方案：                                                       │
│   A. 直接查询流水表实时汇总（每次查询计算）                      │
│   B. 预计算并存入汇总表（INSERT临时表）                         │
│   C. 使用物化视图或缓存                                          │
│                                                                 │
│ 选择：B（INSERT临时表）                                          │
│                                                                 │
│ 理由：                                                          │
│   - 性能最优：日报是高频查询，提前汇总减少计算量                  │
│   - 兼容FastReport：临时表可直接作为报表数据源                   │
│   - 实现简单：无需额外缓存机制                                   │
│                                                                 │
│ 成因分类：性能优化                                               │
│                                                                 │
│ 当前合理性：仍然合理，因为日报查询频率高                         │
└─────────────────────────────────────────────────────────────────┘
```
