### 1.2 核心价值

| 价值维度 | 具体说明 | 业务指标 |
|---|---|---|
| 资金监控 | 实时掌握现金和银行存款余额 | 余额准确率100% |
| 收支管理 | 逐笔记录每笔收支流水 | 日记账与凭证一致 |
| 账实核对 | 账面与银行流水定期核对 | 对账差异及时查明 |
| 资金预测 | 预测未来资金收支 | 支持30/60/90天预测 |
| 效率提升 | 银企互联减少手工操作 | 网银操作时间减少80% |

## 二、能力矩阵

### 2.1 核心能力

| 能力 | 能力级别 | 功能描述 | 关联模块 |
|---|---|---|---|
| 日记账管理 | 核心 | 现金/银行日记账的查询和维护 | GL凭证 |
| 收支登记 | 核心 | 收付款单的录入和审核 | AR/AP |
| 日报汇总 | 核心 | 资金日报的生成和查询 | 系统定时 |
| 银行对账 | 核心 | 账面与银行流水核对 | CN票据 |
| 余额调节 | 核心 | 未达账项的计算和调节 | 对账结果 |
| 资金头寸 | 增强 | 未来资金收支预测 | AR/AP到期 |
| 银企互联 | 增强 | 直连银行系统 | 银行接口 |
| 期初开账 | 基础 | 启用时余额初始化 | 系统配置 |

| 报表 | 类型 | 数据来源 | 更新频率 |
|---|---|---|---|
| 现金日记账 | 明细 | CB_RECEIVEFLOW | 实时 |
| 银行日记账 | 明细 | CB_BANKACCOUNT | 实时 |
| 现金流水账 | 明细 | CB_RECEIVEFLOW | 实时 |
| 银行流水账 | 明细 | CB_PAYFLOW | 实时 |
| 现金日报 | 汇总 | CB_RECEIVEFLOW + 临时表 | 日末 |
| 银行日报 | 汇总 | CB_BANKACCOUNT + 临时表 | 日末 |
| 期末对账 | 对账 | CB_RECONCILIATION | 期末 |
| 余额调节表 | 对账 | CB_BALANCEADJUSTMENT | 对账后 |

## 三、业务边界

### 3.1 边界定义

| 边界类型 | 边界内容 |
|---|---|
| 上游边界 | 收付款单据（收款单、付款单） |
| 下游边界 | GL总账凭证、日记账 |
| 平行边界 | AR应收、AP应付、CN票据 |

## 四、关键角色

| 角色 | 主要操作 | 关注报表 | 权限级别 |
|---|---|---|---|
| 出纳 | 收付款录入、日记账查询、银行对账 | 日记账、日报 | 日常操作 |
| 会计 | 凭证复核、日记账审核 | 日记账、凭证 | 复核 |
| 财务主管 | 资金头寸分析、对账审核 | 头寸表、调节表 | 管理 |
| 账套管理员 | 账户配置、期初开账 | - | 系统 |
| 审计人员 | 日记账查询、凭证追溯 | 全部报表 | 只读 |

## 五、与周边模块的协作

| 周边模块 | 协作方向 | 协作内容 |
|---|---|---|
| GL总账 | 双向 | 出纳凭证→GL；GL可追溯CB日记账 |
| AR应收 | 单向→ | 收款单核销AR应收单 |
| AP应付 | 单向→ | 付款单核销AP应付单 |
| CN票据 | 双向 | 票据收付使用CB账户；CN提供对账单数据 |
| CM资金 | 单向→ | CM使用CB账户信息 |

## 六、启用前提

| 前置条件 | 说明 |
|---|---|
| 基础资料 | 现金账户、银行账户已完成配置 |
| 期初余额 | 启用时余额已录入（CNOpenServiceHelper） |
| 凭证模板 | 收付款凭证模板已配置 |
| 银行接口 | 银企互联接口已配置（如需） |
