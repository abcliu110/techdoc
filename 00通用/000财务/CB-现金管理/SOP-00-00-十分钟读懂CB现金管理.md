# 十分钟读懂CB现金管理

## 模块定位

CB现金管理是金蝶K3Cloud财务系统的核心模块，负责管理企业的**现金**和**银行存款**收支，以及与银行的往来对账。

```
┌─────────────────────────────────────────────────────────────┐
│                    金蝶K3Cloud财务体系                         │
├─────────────┬─────────────┬─────────────┬─────────────────┤
│     AR      │     AP      │     GL      │       CB        │
│   应收管理   │   应付管理   │   总账管理   │    现金银行     │
│   客户的钱   │   欠人的钱   │   账本核心   │   真金白银     │
└─────────────┴─────────────┴─────────────┴─────────────────┘
```

## 一句话理解

> CB现金管理就是管好企业的"钱包"：记录每笔收支、定期和银行对账、预测未来资金够不够用。

## 核心能力矩阵

| 能力 | 说明 | 典型场景 |
|---|---|---|
| 日记账 | 逐笔记录现金和银行存款的收支 | 出纳录入收款/付款，生成日记账 |
| 日报 | 每天汇总收支情况 | 日末查看今日收支合计 |
| 银行对账 | 账面余额与银行流水核对 | 期末确认账实相符 |
| 余额调节表 | 计算未达账项 | 对账后解释差异 |
| 资金头寸 | 预测未来资金收支 | 判断是否有资金缺口 |
| 银企互联 | 直连银行系统 | 网银付款、余额查询 |

## 核心业务流程

### 收款流程（钱进来）

```
客户付款 → 收款单 → 凭证 → 日记账 → 余额增加
     │
     └─→ 核销AR应收单
```

**关键点**：收款必须生成凭证，凭证自动更新日记账。

### 付款流程（钱出去）

```
供应商收款 → 付款单 → 凭证 → 日记账 → 余额减少
     │
     └─→ 核销AP应付单
```

**关键点**：付款不能超过账户余额。

### 对账流程（账实核对）

```
银行对账单导入 → 系统匹配收支 → 标记差异 → 余额调节表
```

**关键点**：差异必须查明原因，未达账项要追踪处理。

## 关键概念解释

| 概念 | 通俗解释 | 举个例子 |
|---|---|---|
| 日记账 | 按时间顺序的收支流水账 | 今天收了1万、付了5千 |
| 资金日报 | 每天收支的汇总表 | 今日收入10万，支出8万 |
| 余额调节表 | 解释账面和银行差异的表 | 银行多收了1万（对方未到账） |
| 资金头寸 | 未来一段时间能用的钱 | 预计下月有50万可用 |
| 银企互联 | 系统直连银行 | 在软件里直接操作网银 |

## 报表体系

| 报表 | 看什么 | 谁能用 |
|---|---|---|
| 现金/银行日记账 | 每笔收支明细 | 出纳、会计、审计 |
| 现金/银行日报 | 每天收支汇总 | 出纳、会计 |
| 期末对账报告 | 对账结果 | 出纳、财务主管 |
| 余额调节表 | 未达账项 | 财务主管 |
| 资金头寸表 | 未来资金预测 | 财务主管、高管 |

## 常见问题

**Q：为什么日记账要关联凭证？**
A：保证账账相符，日记账是凭证的明细账。

**Q：什么情况下会产生未达账项？**
A：时间差，比如企业已记账但银行还未收到款项。

**Q：银企互联有什么用？**
A：省去手工网银操作，在系统内直接完成付款、查余额、下流水。

## 十分钟后你学到了

1. CB模块管的是现金和银行存款的真金白银
2. 核心流程：收款→凭证→日记账；付款→凭证→日记账
3. 对账是确保账面和银行一致的关键
4. 资金头寸帮助预测未来资金够不够用
5. 银企互联让网银操作更便捷
