## 一、常见问题与解决方案

### 1.1 收付款问题

#### 问题1：付款时提示余额不足
```
┌─────────────────────────────────────────────────────────────────┐
│ 【症状】                                                          │
│   付款单保存时提示："账户余额不足"                                  │
│                                                                 │
│ 【原因】                                                          │
│   付款金额超过账户当前余额                                         │
│                                                                 │
│ 【检查步骤】                                                       │
│   1. 查询账户余额：银行日记账 → 当前余额                          │
│   2. 确认付款金额：付款单 → 金额                                  │
│   3. 检查是否有未记账的收款                                       │
│                                                                 │
│ 【解决方案】                                                       │
│   ✓ 减少付款金额                                                 │
│   ✓ 先收款增加余额后再付款                                        │
│   ✓ 更换付款账户                                                 │
│                                                                 │
│ 【预防措施】                                                       │
│   - 付款前先查询账户余额                                         │
│   - 大额付款分批处理                                             │
│   - 设置余额预警                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 日记账问题

### 1.3 对账问题

#### 问题5：对账差异无法消除
```
┌─────────────────────────────────────────────────────────────────┐
│ 【症状】                                                          │
│   银行对账后仍有差异，无法完成对账                                  │
│                                                                 │
│ 【原因】                                                          │
│   可能是：未达账项、银行手续费、时间差、错误                        │
│                                                                 │
│ 【检查步骤】                                                       │
│   1. 导出差异明细：对账报告 → 差异清单                            │
│   2. 逐笔核对：账面vs银行流水                                     │
│   3. 常见差异类型：                                               │
│      - 银行已收企业未收（时间差）                                 │
│      - 银行已付企业未付（手续费）                                 │
│      - 企业已收银行未收（支票未兑现）                             │
│      - 企业已付银行未付（付款未到账）                             │
│                                                                 │
│ 【解决方案】                                                       │
│   ✓ 等待银行到账后再次对账                                       │
│   ✓ 使用余额调节表记录未达账项                                    │
│   ✓ 手工调账处理错误                                              │
│                                                                 │
│ 【规则】                                                          │
│   BR-CB-401：对账差异必须查明原因                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 二、数据恢复指南

### 2.1 凭证反审核恢复
```
场景：凭证生成后发现错误需要修改

步骤：
1. 反审核凭证
   路径：凭证管理 → 反审核

2. 修改凭证
   路径：凭证管理 → 修改

3. 重新审核
   路径：凭证管理 → 审核

4. 验证日记账同步
   路径：日记账查询 → 核对金额

注意：
- 必须按顺序操作
- 反审核需要权限
- 修改后日记账会自动同步
```

### 2.2 日记账调账
```
场景：日记账金额需要调整

步骤：
1. 新增调账单
   路径：CB现金管理 → 调账

2. 填写调账信息
   - 账户
   - 调账金额（正数调增，负数调减）
   - 调账原因

3. 审核调账单

4. 验证日记账更新
   路径：日记账查询 → 查看调账记录

注意：
- 调账需要审批
- 调账会影响账户余额
- 保留调账记录备查
```
