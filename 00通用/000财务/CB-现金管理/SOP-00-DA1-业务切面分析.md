### 1.2 业务价值
| 价值维度 | 说明 |
|---|---|
| 资金监控 | 实时掌握企业现金和银行存款余额 |
| 日记账管理 | 逐笔记录资金收支，便于追溯 |
| 银行对账 | 与银行流水核对，确保账实相符 |
| 资金预测 | 预测未来资金收支，合理安排头寸 |

## 二、核心角色

| 角色 | 操作 | 接触系统 |
|---|---|---|
| R-CB-01 出纳 | 收付款操作、日记账录入、银行对账 | 现金日记账、银行日记账、收款单、付款单 |
| R-CB-02 会计 | 凭证生成、账务处理 | 凭证系统、总账 |

| R-CB-05 审计人员 | 资金审计、日记账查询 | 日记账、对账报表 |
| R-CB-06 银行 | 银企互联、余额查询、流水下载 | 网银接口 |

## 三、业务分类

### 3.1 日记账业务
| 业务项 | 触发时机 | 说明 |
|---|---|---|
| 现金日记账 | 现金收付款时 | 按现金账户逐笔记录收支 |
| 银行日记账 | 银行收付款时 | 按银行账户逐笔记录收支 |
| 现金流水账 | 任何现金变动 | 逐笔查询 |
| 银行流水账 | 任何银行变动 | 逐笔查询 |

### 3.2 日报业务
| 业务项 | 触发时机 | 说明 |
|---|---|---|
| 现金日报 | 日末 | 现金账户日汇总 |
| 银行日报 | 日末 | 银行账户日汇总 |

### 3.3 对账业务
| 业务项 | 触发时机 | 说明 |
|---|---|---|
| 期末对账 | 期末 | 账面余额与银行对账单核对 |
| 余额调节表 | 对账后 | 计算未达账项 |
| 资金头寸表 | 任意时间 | 预测未来资金收支 |

### 3.4 银企互联业务
| 业务项 | 触发时机 | 说明 |
|---|---|---|
| 网银付款 | 付款申请 | 提交银行执行 |
| 余额查询 | 需要时 | 查询银行账户余额 |
| 流水下载 | 对账前 | 下载银行流水 |

## 四、核心用例

### UC-CB-01：收款登记
```
用例编号：UC-CB-01
参与者：出纳
前置条件：收到客户/供应商款项
基本流程：
  1. 录入收款单（金额、账户、对方单位）
  2. 选择收款账户（现金/银行）
  3. 关联业务单据（AR应收单等）
  4. 生成收款凭证
  5. 更新日记账
后置条件：日记账记录已更新
异常处理：
  - 账户余额不足：提示错误
  - 关联单据不存在：提示错误
```

### UC-CB-02：付款登记
```
用例编号：UC-CB-02
参与者：出纳
前置条件：需要对外支付款项
基本流程：
  1. 录入付款单（金额、账户、对方单位）
  2. 选择付款账户（现金/银行）
  3. 关联业务单据（AP应付单等）
  4. 生成付款凭证
  5. 更新日记账
后置条件：日记账记录已更新
异常处理：
  - 账户余额不足：提示错误
  - 关联单据不存在：提示错误
```

### UC-CB-03：银行对账
```
用例编号：UC-CB-03
参与者：出纳、财务主管
前置条件：期末或需要时
基本流程：
  1. 导入银行对账单
  2. 系统自动匹配收支记录
  3. 生成余额调节表
  4. 标记已达/未达账项
后置条件：余额调节表已生成
异常处理：
  - 数据不匹配：手工调整
  - 差异无法解释：待查
```

### UC-CB-04：资金头寸分析
```
用例编号：UC-CB-04
参与者：财务主管
前置条件：需要了解资金状况
基本流程：
  1. 查看当前资金余额
  2. 查看未来到期应收应付
  3. 预测资金缺口
  4. 制定资金计划
后置条件：资金计划已制定
异常处理：
  - 预测偏差：多维度校验
```

### UC-CB-05：银企互联付款
```
用例编号：UC-CB-05
参与者：出纳
前置条件：开通银企互联
基本流程：
  1. 发起网银付款申请
  2. 提交至银行系统
  3. 银行执行付款
  4. 回写付款状态
后置条件：付款完成
异常处理：
  - 银行拒绝：撤销申请
  - 网络异常：重试
```

### UC-CB-06：日记账查询
```
用例编号：UC-CB-06
参与者：出纳、会计、审计
前置条件：需要查询资金流水
基本流程：
  1. 选择账户类型（现金/银行）
  2. 选择时间范围
  3. 查询日记账/流水账
  4. 联查相关凭证
后置条件：查询结果已展示
异常处理：
  - 数据量大：分页查询
```

## 五、业务规则汇总

| 规则编号 | 规则内容 | 约束级别 | 证据 |
|---|---|---|---|
| BR-CB-01 | 收款金额必须大于0 | MUST | 业务规则 |
| BR-CB-02 | 付款金额不能超过账户余额 | MUST | 业务规则 |
| BR-CB-03 | 现金日记账只能关联现金账户 | MUST | 业务规则 |
| BR-CB-04 | 银行日记账只能关联银行账户 | MUST | 业务规则 |
| BR-CB-05 | 日记账必须关联业务单据 | SHOULD | 业务规则 |
| BR-CB-06 | 对账差异必须说明原因 | MUST | 业务规则 |
| BR-CB-07 | 银企互联付款需要银行余额充足 | MUST | 业务规则 |
| BR-CB-08 | 日记账借贷必须平衡 | MUST | 业务规则 |
