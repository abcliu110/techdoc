# 03-失败恢复手册 — K3Cloud GL总账模块

---

## 一、凭证管理失败场景

### 1.1 凭证保存失败

| 失败代码 | 失败描述 | 根因 | 自动恢复 | 人工介入 |
|---|---|---|---|---|
| GL-E001 | 借贷不平衡 | 分录金额录入错误 | 无 | 修改分录金额 |
| GL-E002 | 凭证日期超出期间 | 日期录入错误或期间已关闭 | 无 | 调整日期或申请反结账 |
| GL-E003 | 科目不在科目体系 | 科目编码错误或已被禁用 | 无 | 更换为有效科目 |
| GL-E004 | 核算维度不匹配 | 分录配置了科目不允许的维度 | 无 | 移除错误维度 |
| GL-E005 | 凭证已被锁定 | 其他用户正在编辑 | 等待锁释放（最长5分钟） | 联系锁定用户释放 |
| GL-E006 | 凭证号重复 | 并发生成同一凭证号 | 事务回滚，自动重试生成新号 | 无需介入 |
| GL-E007 | 网络中断 | HTTP请求超时 | 草稿自动保存 | 重新提交 |

### 1.2 凭证审核失败

| 失败代码 | 失败描述 | 根因 | 自动恢复 | 人工介入 |
|---|---|---|---|---|
| GL-E010 | 凭证未保存 | 尝试审核草稿 | 无 | 先保存凭证 |
| GL-E011 | 凭证已被其他人审核 | 并发审核冲突 | 无 | 刷新列表，确认状态 |
| GL-E012 | 凭证已过账 | 重复审核已过账凭证 | 无 | 无需重复审核 |
| GL-E013 | 审核超时 | Floating窗口超时 | 凭证可能未生成 | 检查凭证是否生成 |
| GL-E014 | 借贷不平衡 | 审核时复检发现不平衡 | 无 | 反审核后修改 |

### 1.3 凭证过账失败

| 失败代码 | 失败描述 | 根因 | 自动恢复 | 人工介入 |
|---|---|---|---|---|
| GL-E020 | 凭证未审核 | 尝试过账未审核凭证 | 无 | 先审核凭证 |
| GL-E021 | 余额表更新失败 | 数据库写入异常 | 事务回滚 | 重新过账 |
| GL-E022 | 期间被关闭 | 过账期间被其他操作关闭 | 事务回滚 | 联系账套管理员 |
| GL-E023 | 死锁检测 | 并发过账导致死锁 | 自动回滚，稍后重试 | 稍后重试 |
| GL-E024 | 表锁等待超时 | 余额表被长时间锁定 | 事务回滚 | 联系DBA检查锁 |
| GL-E025 | 余额表与凭证不一致 | 之前过账异常遗留 | 无 | 运行余额核对任务 |

## 五、并发场景处理

### 5.1 凭证号并发

| 场景 | 风险 | 处理机制 | 用户感知 |
|---|---|---|---|
| 同一用户快速保存多张凭证 | 凭证号可能重复 | 数据库唯一约束 + 失败重试 | 无感知 |
| 不同用户同时保存凭证 | 凭证号可能重复 | 分布式锁 + 失败重试 | 无感知 |

### 5.2 凭证状态并发

| 场景 | 风险 | 处理机制 | 用户感知 |
|---|---|---|---|
| 用户A和B同时审核同一凭证 | 重复审核 | 状态检查 + 行锁 | B收到"已被审核"提示 |
| 用户A过账时B反审核 | 状态冲突 | 乐观锁 + 刷新重试 | B收到"状态已变更"提示 |

## 七、升级路径

### 7.1 问题升级标准

| 级别 | 场景 | 升级到 |
|---|---|---|
| 一线处理 | 权限不足、数据录入错误 | 立即处理 |
| 二线处理 | 并发锁、余额不一致 | 财务主管 |
| 三线处理 | 数据库故障、死锁 | DBA/运维 |
| 四线处理 | 代码缺陷、系统异常 | 开发团队 |

### 7.2 升级触发条件

- 同一问题超过3次未能解决
- 涉及数据一致性问题超过30分钟未解决
- 引发其他模块异常
- 用户情绪激动或业务影响扩大
