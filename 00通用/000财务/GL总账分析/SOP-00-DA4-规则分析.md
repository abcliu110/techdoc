## 六、异常与恢复责任矩阵

每个核心失败场景必须输出以下矩阵（覆盖硬件/网络/协议/系统四层异常）：

### 6.1 凭证保存/审核场景

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|---|---|---|---|---|---|
| **凭证借贷不平衡** | 服务端校验 | 无 | 凭证录入员 | 修改分录金额使其平衡 | 无需升级 |
| **凭证日期超出期间** | 服务端校验 | 无 | 凭证录入员 | 调整凭证日期或申请打开期间 | 账套管理员 |
| **科目不在科目体系中** | 服务端校验 | 无 | 凭证录入员 | 更换为有效科目 | 账套管理员（需新增科目） |
| **凭证已被其他用户锁定** | 行锁检测 | 无 | 当前用户 | 等待或联系锁定用户释放 | 财务主管（强制解锁） |
| **并发保存导致凭证号重复** | 数据库唯一约束 | 回滚事务 | 凭证录入员 | 重新保存（系统重新生成凭证号） | 无需升级 |
| **网络中断导致保存失败** | HTTP响应超时 | 草稿自动保存 | 凭证录入员 | 重新提交保存 | 无需升级 |

**覆盖要求**：
- 硬件层：服务器宕机、存储故障（→数据库事务回滚）
- 网络层：HTTP超时、连接中断（→前端超时提示+草稿保存）
- 协议层：数据序列化失败、JSON解析错误（→服务端参数校验）
- 系统层：并发锁冲突、内存溢出（→行锁检测+错误提示）

### 6.2 凭证过账场景

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|---|---|---|---|---|---|
| **凭证未审核** | 状态校验 | 无 | 财务人员 | 先审核凭证 | 无需升级 |
| **余额表更新失败** | 事务回滚 | 完整回滚 | 财务人员 | 重新过账 | DBA（数据修复） |
| **过账过程中期间被关闭** | 状态校验 | 回滚事务 | 财务人员 | 联系主管反结账 | 财务主管 |
| **并发过账同一凭证** | 行锁检测 | 无 | 当前用户 | 等待或重新操作 | 无需升级 |
| **AccountBalance表锁等待超时** | 锁超时检测 | 回滚事务 | 财务人员 | 稍后重试 | DBA（锁分析） |

**覆盖要求**：
- 硬件层：存储I/O错误（→事务回滚）
- 网络层：数据库连接超时（→连接池重连）
- 协议层：SQL执行错误（→错误日志+回滚）
- 系统层：死锁检测（→死锁回滚+重试）

### 6.3 报表钻取场景

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|---|---|---|---|---|---|
| **方案ID已耗尽（-1）** | 状态校验 | 无 | 用户 | 无法继续钻取，需重新打开报表 | 无需升级 |
| **会话丢失，钻取路径断裂** | Session检测 | 无 | 用户 | 重新从总账开始钻取 | 无需升级 |
| **用户无明细账权限** | CheckViewDetailRight | 无 | 用户 | 联系管理员申请权限 | 财务主管 |
| **钻取后过滤参数失效** | 参数校验 | 无 | 用户 | 刷新报表后重新钻取 | 无需升级 |
| **多Tab钻取状态覆盖** | 无检测 | 无 | 用户 | 每个Tab独立会话，禁止多Tab钻取 | 无需升级 |
| **IUserParameterService服务异常** | 服务心跳检测 | 降级为URL参数传递 | 用户 | 提示会话功能不可用 | 系统管理员 |

**覆盖要求**：
- 硬件层：应用服务器宕机（→用户需重新登录）
- 网络层：Session同步失败（→本地Session优先）
- 协议层：参数编码错误（→URL重编码）
- 系统层：Session服务不可用（→降级方案）

### 6.4 凭证联查场景

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|---|---|---|---|---|---|
| **用户无GL凭证权限（两级检查均失败）** | 权限校验 | 无 | 用户 | 联系管理员申请GL凭证权限 | 财务主管 |
| **凭证已被删除，映射仍存在** | 数据一致性检测 | 无 | 财务主管 | 清理脏数据映射记录 | DBA（数据修复） |
| **BAS_BusinessVoucher查询超时** | SQL超时检测 | 无 | 用户 | 缩小查询范围或重试 | 系统管理员（索引优化） |
| **凭证映射为多对多，部分映射无权限** | 权限降级 | 仅返回有权限的映射 | 用户 | 申请其他凭证权限 | 财务主管 |

**覆盖要求**：
- 硬件层：数据库连接池耗尽（→连接池扩容）
- 网络层：查询超时（→查询优化）
- 协议层：SQL语法错误（→代码检查）
- 系统层：权限服务不可用（→降级为允许访问）
