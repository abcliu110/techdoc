## 故事一：采购入库生成凭证

### 场景描述

仓库管理员在INV模块审核一张采购入库单，系统自动生成对应的财务凭证。

### 参与者

- 仓库管理员（业务录入员）
- 采购会计（财务审核员）

### 前置条件

- 采购入库单已保存
- 物料已关联科目映射规则
- 当前会计期间已打开

### 主流程

```
1. 仓库管理员打开采购入库单列表
2. 选择待审核入库单，点击【审核】
3. 系统弹出Floating窗口，显示"正在生成凭证..."
4. 后台执行：
   a. 根据物料+供应商获取借贷科目
   b. 按汇率转换外币金额
   c. 检查借贷平衡
   d. 生成凭证号 GJ-2024-0156
   e. 写入GL_VOUCHER和GL_VOUCHERENTRY
   f. 建立BAS_BusinessVoucher映射
   g. 更新AccountBalance余额
5. Floating窗口显示"凭证生成成功"
6. 仓库管理员关闭Floating窗口，继续其他操作
```

### 成功结果

- 凭证号GJ-2024-0156已生成
- 借贷平衡：借方=贷方=11700元（含税）
- 业务单据与凭证已建立映射
- 科目余额已更新

### 失败场景

| 失败点 | 表现 | 恢复动作 |
|---|---|---|
| 科目映射缺失 | Floating窗口显示"物料[XXXX]未配置科目映射" | 管理员配置映射规则后重试 |
| 借贷不平衡 | 窗口显示"借贷不平衡：借方11700，贷方10000" | 财务人员调整分录 |
| 期间已结账 | 窗口显示"当前期间已结账，无法生成凭证" | 申请反结账后重试 |
| 凭证号重复 | 保存失败，提示"凭证号已存在" | 系统自动重试生成新号 |

## 故事二：跨系统凭证联查

### 场景描述

采购会计在AP模块查看采购发票的付款状态时，需要联查已生成的财务凭证。

### 参与者

- 采购会计（业务人员，有AP权限，无GL权限）
- 财务主管（有GL权限）

### 前置条件

- 采购发票已审核并生成凭证
- 凭证号GJ-2024-0156已生成

### 主流程

```
1. 采购会计登录AP模块
2. 打开应付发票列表
3. 点击发票号"INV-2024-0892"的【联查凭证】按钮
4. 系统执行两级权限检查：
   a. 检查采购会计是否有GL凭证权限 → 无
   b. 降级检查是否有AP发票权限 → 有
   c. 降级成功，允许查看
5. 系统查询BAS_BusinessVoucher映射表
6. 展示关联的凭证列表：
   - GJ-2024-0156（采购入库）
7. 采购会计可点击查看凭证详情
```

### 成功结果

- 业务人员可查看关联凭证
- 财务权限保持隔离
- 凭证与业务单据可双向追溯

### 失败场景

| 失败点 | 表现 | 恢复动作 |
|---|---|---|
| 无降级权限 | 提示"您没有查看凭证的权限，请联系管理员" | 管理员授权或联系财务主管 |
| 凭证已删除 | 列表显示凭证[已删除] | 联系DBA清理脏数据 |
| 多对多映射歧义 | 显示多张凭证（价税分离场景） | 财务人员确认关联关系 |

## 故事三：报表钻取追溯

### 场景描述

财务主管发现总账报表中"管理费用-办公费"科目余额异常，需要钻取到明细账和凭证查明原因。

### 参与者

- 财务主管（报表分析权限）

### 前置条件

- 总账、明细账、凭证均有查询权限
- 钻取路径会话未过期

### 主流程

```
1. 财务主管打开总账报表
   - 筛选：2024年1月，管理费用-办公费
   - 显示：借方发生额 15,600元，贷方发生额 12,000元，余额 3,600元

2. 鼠标双击"管理费用-办公费"行
   - 系统记录当前方案ID=0（总账入口）
   - 打开明细账报表
   - 显示：1月5日办公费2,000、1月12日办公费3,500、1月20日办公费10,100

3. 鼠标双击"1月5日 办公费 2,000元"行
   - 系统记录当前方案ID=1（明细账入口）
   - 打开凭证列表
   - 显示：GJ-2024-0102（管理费用-办公费）

4. 鼠标双击凭证GJ-2024-0102
   - 系统记录当前方案ID=2（凭证列表入口）
   - 打开单张凭证
   - 显示：办公用品采购

5. 点击【返回】
   - 系统使用方案ID=1重新打开明细账

6. 再次点击【返回】
   - 系统使用方案ID=0重新打开总账
```

### 成功结果

- 财务主管追溯到具体凭证GJ-2024-0102
- 通过凭证日期（1月5日）可进一步追溯业务单据
- 钻取路径可逐级返回

### 失败场景

| 失败点 | 表现 | 恢复动作 |
|---|---|---|
| 会话过期 | 点击双击后提示"会话已过期，请重新打开报表" | 重新打开总账报表 |
| 方案ID耗尽 | 点击双击无反应或提示"已到达最深钻取级别" | 从头开始钻取 |
| 无明细账权限 | 钻取后提示"您没有查看明细账的权限" | 联系管理员申请权限 |

## 故事四：凭证审核反审核循环

### 场景描述

录入员发现已审核凭证的金额有误，需要修改后重新审核。

### 参与者

- 录入员
- 审核员

### 前置条件

- 凭证GJ-2024-0156已审核（未过账）

### 主流程

```
1. 录入员发现凭证金额错误
2. 录入员联系审核员

3. 审核员登录GL模块
4. 找到凭证GJ-2024-0156
5. 点击【反审核】
   - 系统检查凭证状态是否为"已审核" → 是
   - 系统检查凭证是否已过账 → 否
   - 凭证状态变更为"保存"
   - BAS_BusinessVoucher映射保留

6. 录入员修改凭证金额
7. 录入员保存凭证
   - 借贷不平衡检查
   - 保存成功

8. 审核员再次审核
   - 检查借贷平衡
   - 检查科目有效性
   - 检查期间有效性
   - 凭证状态变更为"已审核"
```

### 成功结果

- 凭证已修改并重新审核
- 业务钩稽关系保持

### 失败场景

| 失败点 | 表现 | 恢复动作 |
|---|---|---|
| 凭证已过账 | 提示"已过账凭证无法直接反审核" | 先执行反过账 |
| 被其他用户锁定 | 提示"凭证被用户[XXX]锁定" | 等待或强制解锁 |
| 凭证已结账 | 提示"当前期间已结账，无法修改" | 申请反结账或做调整凭证 |

## 故事五：期间结账控制

### 场景描述

账套管理员在1月31日执行期间结账，确保1月凭证全部入账后锁定期间。

### 参与者

- 账套管理员

### 前置条件

- 2024年1月所有凭证已完成审核和过账
- 1月无未处理业务单据

### 主流程

```
1. 账套管理员打开期间管理
2. 查看2024年1月状态：已打开
3. 检查是否有未审核凭证：
   - 运行"未审核凭证检查"任务
   - 结果：0张未审核

4. 检查是否有未过账凭证：
   - 运行"未过账凭证检查"任务
   - 结果：0张未过账

5. 点击【结账】
   - 系统再次校验
   - 期间状态变更为"已结账"

6. 结账后尝试新增凭证：
   - 提示"2024年1月已结账，请填写2月凭证"
```

### 成功结果

- 1月期间已锁定
- 无法新增或修改1月凭证
- 历史数据保持可查询

### 失败场景

| 失败点 | 表现 | 恢复动作 |
|---|---|---|
| 有未审核凭证 | 提示"有3张凭证未审核，请先审核" | 审核或确认是否结转 |
| 有未过账凭证 | 提示"有5张凭证未过账，请先过账" | 过账或确认是否结转 |
| 余额表不一致 | 提示"余额表与凭证分录不一致" | 运行余额核对任务 |

## 故事六：多对多钩稽场景（价税分离）

### 场景描述

采购一张含税发票，系统生成两张凭证：一张是物资采购（不含税），一张是进项税额。

### 参与者

- 采购会计

### 前置条件

- 采购发票配置了"价税分离"生成规则

### 主流程

```
1. 采购会计审核采购发票
   - 发票金额：价税合计11,700元（不含税10,000 + 税额1,700）

2. 系统生成凭证1（物资采购）：
   借：原材料      10,000
       进项税额    1,700
   贷：应付账款    11,700

3. 系统创建两条BAS_BusinessVoucher映射：
   - 发票A → 凭证1（物资采购分录）
   - 发票A → 凭证1（进项税额分录）

4. 采购会计在发票页面【联查凭证】：
   - 显示：GJ-2024-0156（物资采购+进项税额）
   - 提示：此发票生成2条凭证分录（价税分离）
```

### 成功结果

- 发票与凭证精确关联到分录级别
- 财务可追溯物资采购和税额来源

### 业务价值

多对多映射表支持复杂的业务场景：
- 一张发票 → 多张凭证（价税分离、多用途礼品卡）
- 多张发票 → 一张凭证（合并付款）
- 分录级别精确钩稽（区分物资和税额）
