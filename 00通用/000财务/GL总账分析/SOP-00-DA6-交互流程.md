## 核心交互场景

### 场景一：业务单据审核后自动生成GL凭证

```
参与者: 业务操作员、GL总账系统、凭证生成服务、浮动窗口
前置条件: 业务单据已保存，科目映射已配置，业务子系统审核权限
后置条件: GL凭证已生成，凭证号已分配，业务凭证映射已建立

流程:
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  业务操作员   │    │ 业务子系统   │    │ 浮动窗口     │    │ 凭证生成服务 │
│              │    │              │    │ (Floating)  │    │              │
└──────┬───────┘    └──────┬───────┘    └──────┬───────┘    └──────┬───────┘
       │                   │                   │                   │
       │ 点击"审核"按钮     │                   │                   │
       │──────────────────▶│                   │                   │
       │                   │                   │                   │
       │ 审核成功触发事件   │                   │                   │
       │◀─────────────────│                   │                   │
       │                   │                   │                   │
       │                   │ 创建契约(Proposed)│                   │
       │                   │─────────────────────────────────────────▶│
       │                   │                   │                   │
       │                   │ 打开Floating窗口   │                   │
       │                   │──────────────────────────────────────────▶│
       │                   │                   │◀──────────────────│
       │                   │                   │                   │
       │ 显示"凭证生成中..."│                   │                   │
       │◀─────────────────│                   │                   │
       │                   │                   │                   │
       │                   │                   │    生成凭证表头     │
       │                   │                   │◀─────────────────│
       │                   │                   │                   │
       │                   │                   │    生成凭证分录     │
       │                   │                   │◀─────────────────│
       │                   │                   │                   │
       │                   │                   │    建立业务映射     │
       │                   │                   │◀─────────────────│
       │                   │                   │                   │
       │                   │                   │    确认契约         │
       │                   │                   │◀─────────────────│
       │                   │                   │                   │
       │                   │ 关闭Floating窗口   │                   │
       │                   │◀─────────────────────────────────────────│
       │                   │                   │                   │
       │ 显示"凭证已生成"   │                   │                   │
       │◀─────────────────│                   │                   │
       │                   │                   │                   │

异常分支:
  异常1: 科目映射缺失
    浮动窗口显示错误"科目映射不存在，请先配置"
    契约状态变为Failed
    操作员需配置映射后重新审核

  异常2: 借贷不平衡（自动生成场景）
    凭证生成失败
    浮动窗口显示错误"借贷不平衡"
    契约状态变为Failed
    操作员需调整业务单据后重新审核

  异常3: Floating窗口被手动关闭
    凭证生成中断
    契约状态保持Proposed（未确认）
    后台任务继续执行（如果用户关闭窗口）
    用户可手动触发凭证生成

  异常4: 凭证号重复（并发场景）
    数据库唯一约束触发
    重新生成凭证号
    重试保存（最多3次）

正常分支:
  正常1: 凭证生成成功
    显示凭证号和凭证日期
    契约状态变为Confirmed

  正常2: 用户不等待窗口关闭
    用户关闭业务单据界面
    浮动窗口继续后台运行
    凭证仍会生成（异步）
```

### 场景三：总账报表钻取到明细账再到凭证

```
参与者: 财务人员、总账报表、明细账报表、凭证联查界面、方案ID服务
前置条件: 凭证已审核、已过账，用户有报表查看权限
后置条件: 用户到达凭证联查界面，可追溯业务来源

流程:
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐

│              │    │GL_RPT_General│    │IUserParamSvc │    │GL_RPT_SubLed │
│              │    │    Ledger    │    │              │    │              │
└──────┬───────┘    └──────┬───────┘    └──────┬───────┘    └──────┬───────┘
       │                   │                   │                   │
       │ 打开总账报表       │                   │                   │
       │──────────────────▶│                   │                   │
       │                   │                   │                   │
       │                   │ 查询AccountBalance │                   │
       │                   │──────────────────▶│                   │

       │◀─────────────────│                   │                   │
       │                   │                   │                   │
       │ 双击某科目单元格   │                   │                   │
       │──────────────────▶│                   │                   │
       │                   │                   │                   │
       │                   │ 检查用户权限       │                   │
       │                   │──────────────────▶│                   │
       │                   │                   │                   │
       │                   │ CheckViewDetailRight返回true?          │
       │                   │◀──────────────────│                   │
       │                   │                   │                   │
       │                   │ 获取下一方案ID     │                   │
       │                   │──────────────────▶│                   │
       │                   │                   │                   │
       │                   │ GetNextEntrySchemeId返回非-1?         │
       │                   │◀──────────────────│                   │
       │                   │                   │                   │
       │                   │ 打开明细账，传入AutoSchemeId          │
       │                   │──────────────────────────────────────▶│
       │                   │                   │                   │
       │                   │                   │ 更新方案ID为-1     │
       │                   │                   │──────────────────▶│
       │                   │                   │                   │
       │                   │                   │ 显示明细账数据     │
       │                   │◀──────────────────────────────────────│
       │                   │                   │                   │
       │ 显示明细账         │                   │                   │
       │◀─────────────────│                   │                   │
       │                   │                   │                   │
       │ 双击某行分录       │                   │                   │
       │◀─────────────────────────────────────────────────────────│
       │                   │                   │                   │
       │                   │                   │ 获取凭证方案ID     │
       │                   │                   │──────────────────▶│
       │                   │                   │                   │

       │◀────────────────────────────────────────│                   │
       │                   │                   │                   │

  异常1: 用户无明细账权限
    CellDbClick事件中Args.Cancel = true
    钻取被取消
    用户需要申请明细账查看权限

  异常2: 方案ID已耗尽（值为-1）
    无法继续钻取到凭证
    用户需要重新从总账开始钻取

  异常3: 会话丢失（浏览器关闭后重新打开）
    GetNextEntrySchemeId返回默认值
    方案ID状态已丢失
    钻取路径断裂，无法恢复

  异常4: 凭证权限降级失败
    凭证联查界面打开
    但用户无凭证查看权限
    显示"无权查看凭证"错误

  异常5: 多Tab并发钻取
    两个Tab同时修改方案ID
    状态互相覆盖
    钻取结果不可预测

正常分支:
  正常1: 完整钻取链（总账→明细账→凭证）
    用户到达凭证联查界面
    可查看凭证详情和分录明细
    可继续联查到业务单据

  正常2: 钻取中断后重新开始
    从总账重新钻取
    方案ID重新初始化
    钻取流程重新开始
```
