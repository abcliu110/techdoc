## 一、核心概念（C系列）

### C-01：信用额度（CreditLimit）

| 属性 | 值 |
|---|---|
| 定义 | 授予客户在一定期限内的最高赊销金额 |
| 类型 | 核心业务对象 |
| 主属性 | 客户、总额度、可用额度、有效期 |

**属性列表**：
| 属性名 | 类型 | 说明 | 约束 |
|---|---|---|---|
| 客户ID | FK | 客户档案引用 | NOT NULL |
| 总额度 | DECIMAL | 授予的最高额度 | > 0 |
| 可用额度 | DECIMAL | 当前可用赊销金额 | >= 0 |
| 额度类型 | ENUM | 临时额度/永久额度 | NOT NULL |
| 生效日期 | DATE | 额度生效时间 | |
| 失效日期 | DATE | 额度失效时间 | > 生效日期 |
| 状态 | ENUM | 正常/冻结/失效 | NOT NULL |
| 授信人 | FK | 授信操作员 | |
| 授信日期 | DATE | 授信时间 | |

## 二、过程/转换概念（PT系列）

### PT-01：信用检查（CreditCheck）

| 属性 | 值 |
|---|---|
| 定义 | 在交易前检查客户信用状况的过程 |
| 输入 | 客户ID、交易金额 |
| 输出 | 是否允许交易、可用额度 |
| 关键规则 | 可用额度 >= 交易金额 |

### PT-02：额度计算（CreditCalculate）

| 属性 | 值 |
|---|---|
| 定义 | 计算客户可用额度的过程 |
| 输入 | 客户ID |
| 输出 | 可用额度金额 |
| 公式 | 可用额度 = 总额度 - 已占用 - 已冻结 |

### PT-03：额度占用（CreditOccupy）

| 属性 | 值 |
|---|---|
| 定义 | 交易发生时占用信用额度的过程 |
| 输入 | 客户ID、交易金额、关联单据 |
| 输出 | 占用成功/失败 |
| 关键规则 | 原子性更新额度 |

### PT-04：额度释放（CreditRelease）

| 属性 | 值 |
|---|---|
| 定义 | 收款确认时释放信用额度的过程 |
| 输入 | 客户ID、释放金额、关联单据 |
| 输出 | 释放成功/失败 |
| 关键规则 | 释放金额 <= 已占用金额 |

### PT-05：预警评估（WarningAssess）

| 属性 | 值 |
|---|---|
| 定义 | 评估是否触发信用预警的过程 |
| 输入 | 客户ID |
| 输出 | 预警类型、预警级别 |
| 触发条件 | 逾期天数超限/额度使用率超限等 |

## 三、枚举定义（F系列）

### F-01：评级等级（RatingLevel）

| 值 | 说明 | 额度系数 |
|---|---|---|
| AAA | 极高信用 | 1.0 |
| AA | 高信用 | 0.9 |
| A | 良好信用 | 0.8 |
| BBB | 一般信用 | 0.7 |
| BB | 较低信用 | 0.5 |
| B | 差信用 | 0.3 |
| C | 高风险 | 0.1 |
| D | 极高风险 | 0 |

### F-02：额度类型（LimitType）

| 值 | 说明 |
|---|---|
| TEMPORARY | 临时额度 |
| PERMANENT | 永久额度 |

### F-03：额度状态（LimitStatus）

| 值 | 说明 |
|---|---|
| NORMAL | 正常 |
| FROZEN | 冻结 |
| EXPIRED | 已失效 |

### F-04：占用状态（UsageStatus）

| 值 | 说明 |
|---|---|
| OCCUPYING | 占用中 |
| PARTIAL | 部分释放 |
| RELEASED | 已释放 |

### F-05：预警级别（WarningLevel）

| 值 | 说明 | 响应时间 |
|---|---|---|
| INFO | 提示 | 72小时 |
| WARNING | 警告 | 24小时 |
| CRITICAL | 严重 | 4小时 |

- 额度释放 (PT-04) → 收款时释放额度

## 五、DA2分析结论

- C-01 信用额度
- C-02 信用评级
- C-03 额度占用
- C-04 额度冻结
- C-05 信用预警
- C-06 额度调整申请

**过程/转换概念**：5个
- PT-01 信用检查
- PT-02 额度计算
- PT-03 额度占用
- PT-04 额度释放
- PT-05 预警评估

**枚举定义**：5个
- F-01 评级等级
- F-02 额度类型
- F-03 额度状态
- F-04 占用状态
- F-05 预警级别

**进入DA3的输入**：
- 需建立概念之间的关系
- 需梳理核心业务流程路径
- 需定义关键业务契约
