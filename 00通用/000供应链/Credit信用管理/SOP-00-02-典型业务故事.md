# 典型业务故事 — K3Cloud Credit信用管理

## 故事一：新客户首次授信

### 背景
某新客户"诚信商贸"首次与公司交易，需要为其设置信用额度。

### 角色
- 信用管理员：为客户设置信用额度
- 风控专员：审批超额额度
- 销售员：为客户创建订单

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 步骤1：客户信用评级                                                │
├──────────────────────────────────────────────────────────────────┤
│ 信用管理员评估"诚信商贸"：                                         │
│   - 企业资质：注册资本500万，运营3年                               │
│   - 财务状况：年销售额2000万，资产负债率60%                        │
│   - 历史交易：无交易记录                                          │
│   - 评级结果：B级（系数0.8）                                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤2：设置信用额度                                                │
├──────────────────────────────────────────────────────────────────┤
│ 信用管理员为客户设置信用额度：                                     │
│   - 客户：诚信商贸                                                 │
│   - 币种：人民币                                                  │
│   - 总额度：¥500,000                                              │
│   - 额度类型：永久额度                                             │
│   - 生效日期：2026-08-07                                          │
│   - 可用额度：¥500,000                                            │
│ 提交审批                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤3：额度审批                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 风控专员审批额度申请：                                             │
│   - 审核客户资质材料                                               │
│   - 确认评级结果                                                   │
│   - 审批通过                                                       │
│ 额度生效                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤4：首次交易                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 销售员为诚信商贸创建订单：                                         │
│   - 订单金额：¥80,000                                             │
│   - 系统自动执行信用检查：                                         │
│     可用额度 ¥500,000 >= 订单金额 ¥80,000 ✅                       │
│   - 检查通过，允许创建订单                                         │
└──────────────────────────────────────────────────────────────────┘
```

## 故事二：额度不足超额审批

### 背景
老客户"宏达贸易"信用额度¥200,000，当前已占用¥150,000，尝试下单价¥100,000订单。

### 角色
- 销售员：创建订单
- 风控专员：审批超额申请
- 信用管理员：处理额度调整

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 当前状态                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 客户：宏达贸易                                                     │
│ 总额度：¥200,000                                                  │
│ 已占用：¥150,000                                                  │
│ 可用额度：¥50,000                                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤1：创建订单触发信用检查                                         │
├──────────────────────────────────────────────────────────────────┤
│ 销售员创建订单：                                                   │
│   - 订单金额：¥100,000                                            │
│   - 系统执行信用检查：                                             │
│     可用额度 ¥50,000 < 订单金额 ¥100,000 ❌                        │
│   - 检查不通过，提示：额度不足                                     │
│   - 系统提示：可申请超额审批                                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤2：申请超额审批                                                │
├──────────────────────────────────────────────────────────────────┤
│ 销售员发起超额审批：                                               │
│   - 申请金额：¥100,000                                            │
│   - 超额金额：¥50,000                                             │
│   - 申请原因：客户订单紧急，需追加额度                             │
│   - 提交审批流程                                                   │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤3：审批流程                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 风控专员审批：                                                     │
│   - 审核客户历史交易记录                                           │
│   - 评估客户还款能力                                               │
│   - 决定：临时追加额度¥50,000                                      │
│ 审批通过，临时额度生效                                              │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤4：订单创建成功                                                │
├──────────────────────────────────────────────────────────────────┤
│ 系统重新执行信用检查：                                             │
│   - 总额度：¥200,000                                              │
│   - 临时追加：¥50,000                                             │
│   - 已占用：¥150,000                                              │
│   - 可用额度：¥100,000                                            │
│   - 检查通过，订单创建成功                                         │
└──────────────────────────────────────────────────────────────────┘
```

## 故事三：出库触发额度占用

### 背景
客户"诚信商贸"订单已审核，现在需要出库，系统自动占用额度。

### 角色
- 仓库员：审核出库
- 系统：自动执行额度占用

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 出库前状态                                                        │
├──────────────────────────────────────────────────────────────────┤
│ 客户：诚信商贸                                                     │
│ 总额度：¥500,000                                                  │
│ 已占用：¥80,000（订单1）                                          │
│ 可用额度：¥420,000                                                │
│ 待出库订单：订单2，含税金额¥60,000                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤1：创建出库单                                                  │
├──────────────────────────────────────────────────────────────────┤
│ 仓库员创建出库单：                                                 │
│   - 关联订单：订单2                                               │
│   - 出库金额：¥60,000（含税）                                     │
│   - 提交审核                                                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤2：出库审核触发额度占用                                         │
├──────────────────────────────────────────────────────────────────┤
│ 出库审核时系统自动执行：                                           │
│   1. 生成AR应收单（金额¥60,000）                                   │
│   2. 执行额度占用：                                               │
│      占用金额 = ¥60,000                                           │
│      创建占用记录：T_CR_CREDITLIMITUSAGE                          │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤3：占用后状态                                                  │
├──────────────────────────────────────────────────────────────────┤
│ 客户：诚信商贸                                                     │
│ 总额度：¥500,000                                                  │
│ 已占用：¥140,000（订单1¥80,000 + 订单2¥60,000）                   │
│ 可用额度：¥360,000                                                │
└──────────────────────────────────────────────────────────────────┘
```

## 故事五：额度冻结与解冻

### 背景
客户"宏达贸易"连续逾期，系统自动触发预警并冻结额度。

### 角色
- 风控专员：处理预警
- 信用管理员：执行冻结/解冻

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 预警触发                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 系统定时检查客户信用状态：                                         │
│   - 客户：宏达贸易                                                 │
│   - 逾期天数：35天（超过30天阈值）                                 │
│   - 触发预警：逾期预警（CRITICAL级别）                             │
│   - 创建预警记录：T_CR_CREDITWARNING                              │
│   - 通知风控专员                                                   │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤1：预警处理                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 风控专员处理预警：                                                 │
│   - 评估客户还款能力                                               │
│   - 联系客户催收                                                   │
│   - 客户表示暂时无力还款                                           │
│   - 决定：冻结该客户信用额度                                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤2：额度冻结                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 信用管理员执行冻结：                                               │
│   - 冻结金额：全部冻结                                             │
│   - 冻结原因：逾期冻结                                             │
│   - 创建冻结记录：T_CR_CREDITLIMITFREEZE                          │
│   - 更新额度状态：FROZEN                                          │
│   - 客户可用额度：0                                               │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤3：后续影响                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 额度冻结后：                                                       │
│   - 新订单创建时：直接拒绝（BR-Cred-204）                         │
│   - 客户信用检查：返回"额度已冻结"                                 │
│   - 催收持续进行                                                   │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤4：客户还款解冻                                                │
├──────────────────────────────────────────────────────────────────┤
│ 客户偿还逾期款项后：                                               │
│   - 风控专员确认还款                                               │
│   - 信用管理员执行解冻                                             │
│   - 恢复可用额度                                                   │
│   - 客户恢复正常交易                                               │
└──────────────────────────────────────────────────────────────────┘
```
