## 一、业务规则（BR-Cred系列）

### 1.1 额度管理规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-Cred-101 | 额度唯一性 | 同一客户同一币种只能有一个生效额度 | 强 |
| BR-Cred-102 | 额度计算 | 可用额度 = 总额度 - 已占用 - 已冻结 | 强 |
| BR-Cred-103 | 额度类型 | 临时额度必须设置失效日期，永久额度可不设置 | 强 |
| BR-Cred-104 | 额度调整审批 | 超过调整阈值的额度调整需审批 | 强 |

### 1.2 信用检查规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-Cred-201 | 检查时机 | 销售订单创建/修改时触发信用检查 | 强 |
| BR-Cred-202 | 检查通过条件 | 可用额度 >= 订单含税金额 | 强 |
| BR-Cred-203 | 检查缓存 | 短时间内重复检查使用缓存结果 | 弱 |
| BR-Cred-204 | 冻结客户检查 | 冻结客户直接拒绝交易 | 强 |

### 1.3 额度占用规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-Cred-301 | 占用时机 | 销售出库审核时触发额度占用 | 强 |
| BR-Cred-302 | 占用金额 | 占用金额 = 出库单含税金额 | 强 |
| BR-Cred-303 | 占用原子性 | 占用操作必须原子完成，失败回滚 | 强 |
| BR-Cred-304 | 部分占用 | 支持部分占用（分次出库） | 弱 |

### 1.4 额度释放规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-Cred-401 | 释放时机 | 收款审核/应收核销时触发额度释放 | 强 |
| BR-Cred-402 | 释放金额 | 释放金额 = 本次核销金额 | 强 |
| BR-Cred-403 | 释放上限 | 释放金额不能超过未释放金额 | 强 |
| BR-Cred-404 | 释放顺序 | 按占用时间顺序释放（FIFO） | 弱 |

### 1.5 预警规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-Cred-501 | 逾期预警 | 应收逾期超过N天触发预警 | 强 |
| BR-Cred-502 | 额度预警 | 额度使用率超过阈值触发预警 | 强 |
| BR-Cred-503 | 评级预警 | 评级下调触发预警 | 强 |
| BR-Cred-504 | 预警升级 | 预警未处理超过时限自动升级 | 中 |

## 二、状态机分析

### 2.1 信用额度状态机

```
                    ┌─────────────────┐
                    │    申请中      │
                    │  (Applying)    │
                    └────────┬────────┘
                             │ 审批通过
                             ▼
                    ┌─────────────────┐
          ┌────────▶│    生效中      │
          │         │   (Active)    │
          │         └────────┬────────┘
          │                  │
    审批拒绝│          ┌─────┴─────┐
          │          │           │
          │          ▼           ▼
          │   ┌───────────┐ ┌───────────┐
          │   │  冻结中   │ │   失效   │
          │   │ (Frozen) │ │ (Expired) │
          │   └───────────┘ └───────────┘
          │          │           │
    解冻审批│    手动解冻   │   到期/取消
          │          ▼           │
          │   ┌───────────┐     │
          │   │   正常    │◀────┘
          │   │ (Normal) │
          │   └───────────┘
          │
    取消(Cancel)
    └───────────────────────▶ [结束]
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 申请中 | 额度申请待审批 | 审批通过/审批拒绝 |
| 生效中 | 额度已生效可用 | 冻结/调整/失效 |
| 冻结中 | 额度被风控冻结 | 解冻 |
| 失效 | 额度已失效 | - |

## 三、异常场景

### 3.1 额度管理异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 重复授信 | 同一客户已有额度时再次申请 | 提示已有额度，拒绝或建议调整 |
| 超额调整 | 调整后额度超出客户信用评估 | 需上级审批 |
| 额度冲突 | 临时额度与永久额度冲突 | 临时额度优先或合并 |

### 3.2 信用检查异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 检查超时 | 信用检查响应超时 | 降级为允许（配置可调） |
| 额度不足 | 可用额度不足 | 拒绝交易或提交超额审批 |
| 客户冻结 | 客户额度被冻结 | 直接拒绝交易 |

### 3.3 占用释放异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 超额释放 | 释放金额超过已占用金额 | 校验拒绝 |
| 占用不存在 | 应收单无对应占用记录 | 异常日志+人工处理 |
| 并发占用 | 多笔出库同时占用 | 乐观锁/悲观锁保证 |
| 释放失败 | 释放操作失败 | 事务回滚+重试 |

| DEC-Cred-04 | 额度不足处理 | A=拒绝，B=审批流程 | B |
| DEC-Cred-05 | 冻结策略 | A=手动冻结，B=自动冻结 | A+B |
