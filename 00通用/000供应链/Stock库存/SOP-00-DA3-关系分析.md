## 一、关系分析概述

Stock库存模块的关系分析揭示：Stock是供应链的**枢纽账本**，8个核心业务对象、12个核心关系、8条关键路径。与财务账类（GL/CB/AR/AP）以及其他供应链模块（PO/MO/SE）形成复杂的网状关系。

## 四、关键路径（8条）

### 路径1：采购入库完整路径
```
PO下达 → 物料到货 → 到货检验 → 采购入库单 → 审核 → 过账引擎 → 库存行MERGE → 现存量增加 → 在途量减少 → GL凭证生成 → AP应付单生成
```

### 路径2：销售出库完整路径
```
SO下达 → 可用量检查 → 锁定量增加 → 仓库拣货 → 销售出库单 → 审核 → 过账引擎 → 库存行MERGE → 现存量减少 → 锁定量释放 → GL凭证生成 → AR应收单生成
```

### 路径3：生产投料完整路径
```
MO下达 → BOM展开 → 预留量增加 → 仓库领料 → 领料单 → 审核 → 过账引擎 → 库存行MERGE → 现存量减少 → 预留量释放 → 生产入库（新产品）
```

### 路径4：盘点账实核对路径
```
制定盘点计划 → 实地盘点 → 记录实盘数量 → 账面vs实盘对比 → 生成盘点差异清单 → 确认盘点 → 盘点损溢单 → 库存调整单 → 审核 → 调整库存行
```

### 路径5：批次效期管理路径
```
物料入库 → 批次创建（批号/效期） → FEFO分配策略 → 出库时按批次拣货 → 效期预警 → 过期批次隔离 → 过期处理（报废/降价）
```

### 路径6：负库存检查路径
```
出库单录入 → 系统检查AvailQty → 如果出库量>AvailQty → 强控：拒绝 / 弱控：预警 → 记录负库存日志 → StockCheckNegative
```

### 路径7：期末关账路径
```
检查未审核单据 → 生成期末库存快照 → 库存行固化 → 触发GL期末协同 → 生成期末库存报表
```

### 路径8：跨组织调拨路径
```
调拨申请 → 组织A库存减少 → 组织B库存增加 → 生成内部交易凭证 → GL内部往来记账
```

## 六、REL详细契约（2个）

### REL-01详细契约：入库单 → 库存行

**前置条件**：
- 入库单已审核（FAuditStatus = True）
- 物料/仓库/批次有效
- 关联PO（如有）在途量充足

**操作语义**：
```
FOR EACH 入库明细行:
  stockLine = FIND OR CREATE T_STK_INVENTORY (
    ForgId = 入库单.组织ID,
    FStockId = 入库单.仓库ID,
    FMaterialId = 入库单.物料ID,
    FBatchNo = 入库单.批号（可选）,
    ...15个维度键
  )
  MERGE stockLine (
    FSTOCKQTY += 入库数量,
    FAVAILQTY += 入库数量
  )
  IF 关联PO:
    PO_TRANSITQTY -= 入库数量
```

**后置条件**：
- 库存行现存量增加
- 库存行可用量增加
- PO在途量减少（如关联）
- 生成库存变动日志

---

### REL-02详细契约：出库单 → 库存行

**前置条件**：
- 出库单已审核
- 可用量充足（出库量 ≤ AvailQty）
- 批次未过期

**操作语义**：
```
FOR EACH 出库明细行:
  stockLine = FIND T_STK_INVENTORY (
    ForgId = 出库单.组织ID,
    FStockId = 出库单.仓库ID,
    FMaterialId = 出库单.物料ID,
    FBatchNo = 出库单.批号,
    ...15个维度键
  )
  ASSERT stockLine.FAVAILQTY >= 出库数量, "可用量不足"
  MERGE stockLine (
    FSTOCKQTY -= 出库数量,
    FAVAILQTY -= 出库数量,
    FLOCKQTY -= 锁定释放量（如有）
  )
```

**后置条件**：
- 库存行现存量减少
- 库存行可用量减少
- 锁定量释放（如有关联锁定期）
- 生成库存变动日志

**异常处理**：
- 可用量不足：BR-ST-201约束触发
- 批次过期：BR-ST-102约束触发
