## 一、规则分析概述

Stock库存模块的规则体系包含12条核心规则（BR-ST-*）、3个状态机、4个异常场景。规则体系与GL/CB财务账类高度同构——守恒律、不变量、跨期防护、凭证联动——同时增加了批次效期管理和负库存校验的特有规则。

---

## 二、核心业务规则（12条）

### BR-ST-101：现存量不能为负（强控）
| 属性 | 内容 |
|---|---|
| 规则描述 | 库存行现存量（FSTOCKQTY）不能小于零 |
| 触发时机 | 入库单/出库单审核时过账引擎执行MERGE |
| 控制级别 | **强控**（硬约束，违反则拒绝操作） |
| 类比GL | BR-GL-101：凭证借贷不平衡则拒绝过账 |
| 异常场景 | ⚠️ 反证#1：批次过期后未处理导致表面为负 |

### BR-ST-102：批次有效期约束
| 属性 | 内容 |
|---|---|
| 规则描述 | 已过期批号的物料不能参与出库 |
| 触发时机 | 出库单审核时批次校验 |
| 控制级别 | 弱控（可配置是否允许过期批次出库） |
| 类比GL | BR-GL-302：凭证日期不能早于启用期间 |

### BR-ST-103：仓库启用后才能使用
| 属性 | 内容 |
|---|---|
| 规则描述 | 仓库未启用（FCREATEDATE > 当前日期）时不能进行出入库 |
| 触发时机 | 入库单/出库单保存/审核 |
| 控制级别 | 强控 |
| 类比GL | BR-GL-103：科目未审核不能记账 |

### BR-ST-201：出库量不能超过可用量
| 属性 | 内容 |
|---|---|
| 规则描述 | 出库数量不能超过库存行可用量（AvailQty） |
| 计算公式 | AvailQty = StockQty - LockQty - ReserveQty |
| 触发时机 | 出库单保存或审核（可配置） |
| 控制级别 | **强控**（默认），可配置为弱控 |
| 类比CB | BR-CB-202：付款金额不能超过账户余额 |
| 异常场景 | 锁定量异常时可用量计算错误 |

### BR-ST-202：入库必须关联来源单据
| 属性 | 内容 |
|---|---|
| 规则描述 | 采购入库必须关联PO，生产入库必须关联MO |
| 触发时机 | 入库单保存 |
| 控制级别 | 弱控（可手工拆分允许无来源） |
| 业务意义 | 保证供应链追溯性 |

### BR-ST-203：出库必须关联用途单据
| 属性 | 内容 |
|---|---|
| 规则描述 | 销售出库必须关联SO，领料必须关联MO |
| 触发时机 | 出库单保存 |
| 控制级别 | 弱控 |
| 业务意义 | 保证物流与信息流一致 |

### BR-ST-204：批次号必填控制
| 属性 | 内容 |
|---|---|
| 规则描述 | 启用批次管理的物料，入出库时批号必填 |
| 触发时机 | 入库单/出库单保存 |
| 控制级别 | 可配置（部分物料无需批次） |

### BR-ST-205：审核后生成GL凭证
| 属性 | 内容 |
|---|---|
| 规则描述 | 入库单/出库单审核后同步生成GL凭证 |
| 触发时机 | 单据审核通过 |
| 账类同构 | 与CB收款单→GL凭证（BR-CB-205）完全同构 |
| 类比AR | AR收款单审核后核销应收单（BR-AR-205） |

### BR-ST-301：借贷平衡（库存账）
| 属性 | 内容 |
|---|---|
| 规则描述 | 库存账的入出库必须守恒——入库总量=出库总量+当前库存 |
| 触发时机 | 期末关账时校验 |
| 账类同构 | 与GL借贷必相等（BR-GL-301）同构 |
| 核心意义 | 守恒律是库存账类的本质约束 |

### BR-ST-302：期末关账后不能修改历史数据
| 属性 | 内容 |
|---|---|
| 规则描述 | 库存账期固化后，该期间的单据不能修改/删除 |
| 触发时机 | 期末关账执行后 |
| 控制级别 | 强控 |
| 特殊授权 | 需"反关账"权限才能修改历史数据 |
| 类比GL | BR-GL-302：期末结账后不能修改历史凭证 |

### BR-ST-401：对账差异必须查明原因
| 属性 | 内容 |
|---|---|
| 规则描述 | 盘点发现账实差异，必须查明原因并生成调整单 |
| 触发时机 | 盘点单确认 |
| 控制级别 | 强控（未处理差异不能关闭盘点单） |
| 类比CB | BR-CB-401：对账差异必须查明原因 |

### BR-ST-402：锁定释放必须与订单状态一致
| 属性 | 内容 |
|---|---|
| 规则描述 | 锁定量释放必须与SO/MO的状态变更同步 |
| 触发时机 | SO/MO关闭/取消时 |
| 控制级别 | **待增强** |
| 异常场景 | ⚠️ 反证#2：订单关闭后锁定未自动释放 |

## 三、状态机（3个）

### SM-01：库存行状态机

```
                    ┌──────────────────────────────────────────────┐
                    │                                              │
                    ▼                                              │
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  空库存  │───▶│  正常   │───▶│  锁定   │───▶│  预留   │───▶│  冻结   │
│  (新建)  │    │ (正数)  │    │(Lock>0) │    │(Resrv>0)│    │(期末)   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     │              │              │              │              │
     │ 入库         │ 出库减少     │ 锁定释放     │ 预留取消     │ 反关账
     │ 批次创建     │ 锁定增加     │              │              │
     ▼              ▼              ▼              ▼              ▼
  现存量>0     现存量=0      LockQty=0      ReserveQty=0    可修改
```

**状态说明**：
- **空库存**：现存量=0，锁定量=0，预留量=0
- **正常**：现存量>0，锁定量=0，预留量=0
- **锁定**：锁定量>0（被SO/MO占用）
- **预留**：预留量>0（被MC计划预留）
- **冻结**：期末关账后，禁止修改

---

### SM-02：批次状态机

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  新建   │───▶│  正常   │───▶│  预警   │───▶│  过期   │───▶│  已处理  │
│(创建批号)│    │(在有效期)│    │(效期<30天)│   │(已过效期)│    │(报废等) │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
                    │              │              │
                    │ 效期递减     │ 继续递减     │ 生成调整单
                    ▼              ▼              ▼
               可出库         限制出库         禁止出库
```

**状态说明**：
- **新建**：批号创建，录入生产日期和有效期
- **正常**：在有效期内，可正常出入库
- **预警**：效期不足30天，提示优先出库（FEFO）
- **过期**：已超过有效期，系统禁止出库（或需特殊权限）
- **已处理**：过期批次已通过调整单处理

---

### SM-03：锁定期状态机

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  占用   │───▶│  部分释放 │───▶│  完全释放 │───▶│   归档  │
│(SO/MO)  │    │(部分出库) │    │(全部出库) │    │(订单关闭)│
└─────────┘    └─────────┘    └─────────┘    └─────────┘
     │              │              │
     │ SO/MO关闭    │ 异常释放     │ 手动释放
     ▼              ▼              ▼
   ⚠️ 未释放      ⚠️ 差异追溯    审计记录
  (反证#2风险)
```

**状态说明**：
- **占用**：SO/MO审核后，锁定量创建
- **部分释放**：关联出库单审核后释放部分锁定量
- **完全释放**：全部出库完成
- **归档**：订单关闭后

⚠️ **风险**：订单关闭时未触发自动释放，导致"僵尸锁定"

## 四、异常场景（4个）

### 异常1：负库存产生
| 属性 | 内容 |
|---|---|
| 场景描述 | 出库后现存量变为负数 |
| 触发条件 | BR-ST-101被绕过或批次过期未处理 |
| 影响 | 账实不符，守恒律破坏 |
| 处理方式 | StockCheckNegative日志记录，排查负库存原因 |
| 根本原因 | ⚠️ 批次过期后表面为负（反证#1） |

### 异常2：锁定未释放
| 属性 | 内容 |
|---|---|
| 场景描述 | SO/MO已关闭，但锁定期未释放 |
| 触发条件 | BR-ST-402未强制执行 |
| 影响 | 可用量虚减，误导物控决策 |
| 处理方式 | 手动释放锁定期或重新审核/关闭订单 |
| 根本原因 | ⚠️ 订单关闭事件未触发锁定释放（反证#2） |

### 异常3：盘点账实差异未追溯
| 属性 | 内容 |
|---|---|
| 场景描述 | 盘点发现差异，生成调整单，但未追溯原账目变更 |
| 触发条件 | BR-ST-401未要求追溯 |
| 影响 | 账目历史不完整，无法追溯差异来源 |
| 处理方式 | 调整单备注说明原因，审计追踪 |
| 根本原因 | ⚠️ 盘点调整未生成完整溯源链（反证#3） |

### 异常4：期末跨期数据
| 属性 | 内容 |
|---|---|
| 场景描述 | 期末关账后，仍有单据日期在历史期间 |
| 触发条件 | 单据日期早于关账期间 |
| 影响 | BR-ST-302被违反 |
| 处理方式 | 反关账后修改单据日期，或删除跨期单据 |
