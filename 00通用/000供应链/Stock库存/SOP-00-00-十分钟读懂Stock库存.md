# 十分钟读懂Stock库存

## 什么是Stock库存？

Stock库存是金蝶K3Cloud供应链的**核心账本系统**——它记录了企业有多少物料、放在哪里、批号是什么、还能用多久。简单说：**库存就是物料的"银行账户"**。

---

## 一句话理解库存

> **库存 = 账类系统 = 物料的银行账户**
>
> 你在银行有多少钱（余额），对应库存有多少物料（现存量）
> 你取钱有限额（余额不足），对应物料出库有限制（可用量不足）
> 银行流水记录每笔交易，库存日记账记录每笔出入库

---

## 库存的核心概念

### 五量模型（库存的5个关键数字）

```
┌────────────────────────────────────────────────────────────────────┐
│                         库存五量模型                                │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│   现存量（StockQty）  ──────────  你现在实际有多少                 │
│         │                                                        │
│         │ 减去                                                    │
│         ▼                                                        │
│   锁定量（LockQty）  ──────────  被订单锁住不能动                 │
│         │                                                        │
│         │ 减去                                                    │
│         ▼                                                        │
│   预留量（ReserveQty） ─────────  计划预留还没锁                   │
│         │                                                        │
│         ▼                                                        │
│   可用量（AvailQty）  ──────────  现在能用的数量 ←【最重要！】     │
│                                                                    │
│   在途量（TransitQty）  ─────────  采购在途中还没到                │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

**关键公式**：`可用量 = 现存量 - 锁定量 - 预留量`

**为什么重要**：销售出库时，系统检查的是"可用量"而不是"现存量"。如果可用量不足，出库会被拒绝。

---

## 库存的15维账页

GL总账按"科目"记账，Stock库存按**15个维度**记账：

| 维度 | 说明 | 示例 |
|---|---|---|
| 组织 | 哪个公司 | ABC公司 |
| 仓库 | 哪个仓库 | 上海仓/北京仓 |
| 物料 | 什么东西 | 螺丝M10/钢板 |
| 批号 | 哪一批 | B20240115 |
| 序列号 | 哪一个（可选） | SN123456 |
| 单位 | 什么单位 | 件/千克/米 |
| 辅助属性 | 颜色/尺寸等 | 红色/L码 |
| 有效期 | 什么时候过期 | 2025-12-31 |
| ... | 还有11个维度 | - |

**理解**：想象一个Excel表格，15个维度就是15个筛选条件，相同条件的数据会合并到同一行。

---

## 库存的"过账引擎"

库存的每笔变化（入库/出库/调整）都通过**过账引擎**处理，类似银行的转账系统：

```
  业务单据（采购入库单）  ──▶  过账引擎  ──▶  库存台账更新
                           │
                           ├── 校验：可用量够不够？
                           ├── 计算：新的现存量是多少？
                           ├── 记录：写入库存日记账
                           └── 联动：生成GL凭证
```

**核心操作**：`MERGE`——找到对应的15维库存行，把数量加上去（或减掉）

---

## 批次管理：库存的时间维度

库存账本比银行账户多了一个**时间维度**——批号和有效期：

```
批号 B20240115：生产日期2024-01-15，有效期1年，剩余180天 → 正常
批号 B20231201：生产日期2023-12-01，有效期1年，剩余-30天 → 已过期！
```

**FEFO策略**：先进先出（First Expired First Out）——快过期的先出库

**风险**：过期批次如果没有及时处理，会导致"表面负库存"——看似数量不足，实际是过期物料没清理。

---

## 锁定机制：订单与库存的联动

当销售订单（SO）或生产工单（MO）审核通过时，系统会自动"锁定"一部分库存：

```
SO下单（锁定100个螺丝）
    ↓
库存锁定量+100，可用量-100
    ↓
仓库实际发货
    ↓
出库单审核，释放锁定，可用量恢复
```

**风险**：如果订单关闭了但锁定没释放，就会产生"僵尸锁定"——库存被锁住但永远不会再用了。

---

## 期末关账：库存的年末结算

和GL总账一样，库存也有期末关账：

| GL期末 | Stock期末 |
|---|---|
| 凭证不能改 | 入出库单不能改 |
| 科目账固化 | 库存行固化 |
| 结转到下年 | 结转到下期 |

---

## 库存与财务的联动

```
  采购入库  ──▶  库存增加  ──▶  GL凭证（借：原材料）
  销售出库  ──▶  库存减少  ──▶  GL凭证（贷：主营业务成本）

  库存  ←→  GL  ←→  AR/AP
```

库存是供应链的枢纽，一头连着采购（AP），一头连着销售（AR），中间过账到GL总账。

## 快速问答

**Q：库存和GL账本有什么区别？**
A：GL按科目记账，库存按物料+仓库+批号等15个维度记账；GL只有借贷平衡，库存有五量状态机。

**Q：什么是负库存？**
A：现存量变成负数（账上记录的数量比实际多），说明有漏洞——可能是过期批次没处理或操作失误。

**Q：为什么要有"锁定量"？**
A：保证订单能按时发货——订单审核后锁定库存，防止别人把货拿走。

**Q：批次管理有什么用？**
A：食品/药品等有时效要求，FEFO确保先入库的先出库，防止过期浪费。

**Q：期末关账后还能改库存数据吗？**
A：不能，需要"反关账"权限才能修改历史数据，和GL一样严格。

---

## 核心洞察

1. **库存是账类系统**：和GL/CB/AR/AP共享"守恒律+溯源+维度+时间轴"四大抽象
2. **五量模型是状态机**：现存量/锁定量/可用量的转换构成库存的核心逻辑
3. **过账引擎是核心机制**：类似银行的转账系统，处理每笔库存变动
4. **批次是时间维度**：库存比银行账户多了"有效期"这个维度
5. **供应链枢纽**：上游采购，下游销售，中间GL记账
