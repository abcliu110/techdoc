## 一、业务切面总览

Stock库存模块的业务切面揭示：这是一个**多角色协作的账类系统**，核心角色6类，业务分类4种，典型用例6个。与GL/CB等财务账类的根本区别在于：库存账本的时间轴维度（批次/效期）远比财务账本复杂，且与实物的紧耦合程度更高。

---

## 三、业务分类（4大类）

### 3.1 库存交易类（出入库）
| 特征 | 描述 |
|---|---|
| 典型单据 | 采购入库单、生产入库、销售出库、领料单 |
| 账类操作 | 库存行MERGE（现存量+/-） |
| 触发事件 | 单据审核→过账引擎→库存更新 |
| 财务关联 | 同步生成GL凭证（库存账→GL账） |
| 核心规则 | BR-ST-201：出库量不能超过可用量 |

### 3.2 库存调整类（盘点/损溢）
| 特征 | 描述 |
|---|---|
| 典型单据 | 盘点单、库存调整单、盘点损溢单 |
| 账类操作 | 库存行修正（增/减现存量） |
| 触发事件 | 盘点确认→账实差异→调整记账 |
| 核心风险 | 盘点账实差异未追溯原账目变更（🔴反证#3） |

### 3.3 库存占用类（锁定/预留/在途）
| 特征 | 描述 |
|---|---|
| 典型单据 | 销售订单（SO锁定）、生产投料单（MO预留）、采购在途 |
| 账类操作 | 五量模型状态机转换 |
| 核心风险 | 订单关闭后锁定未自动释放（🔴反证#2） |

### 3.4 库存管理层（配置/关账）
| 特征 | 描述 |
|---|---|
| 典型操作 | 安全库存设置、批次策略配置、期末关账 |
| 账类操作 | 账期固化、跨期防护 |
| 财务关联 | 期末关账与GL期末协同 |

## 四、典型用例（6个）

### UC-01：采购入库完整流程
```
参与者：采购员、仓库管理员
前置条件：PO已审批，到货物料已检验
基本流程：
  1. 采购员在系统下达PO
  2. 物料到货，进入待检区
  3. 仓库管理员执行到货检验（QC）
  4. 检验通过，生成采购入库单
  5. 入库单审核 → 过账引擎执行MERGE
  6. 现存量增加（入库仓库×物料×批号）
  7. 可用量同步增加
  8. 在途量减少（PO关联释放）
扩展流程：
  - 批次管理：批号自动/手动分配
  - 效期管理：录入生产日期/有效期
  - 成本核算：采购成本计入GL
```

### UC-02：销售出库完整流程
```
参与者：销售员、仓库管理员、物控专员
前置条件：SO已审批，库存可用量充足
基本流程：
  1. 销售员下达SO
  2. 系统自动检查可用量
  3. 库存锁定（LockQty增加）
  4. 仓库管理员拣货出库
  5. 生成销售出库单
  6. 出库单审核 → 过账引擎执行MERGE
  7. 现存量减少（出库仓库×物料×批号）
  8. 锁定量释放（LockQty减少）
  9. 可用量减少
扩展流程：
  - FEFO策略：按批次效期先进先出
  - 序列号管理：部分物料需逐件扫描
  - 批次追溯：记录出库批次信息
异常流程：
  - 可用量不足：提示物控专员补货或分批发货
```

### UC-03：生产投料（MTO场景）
```
参与者：生产计划员、仓库管理员
前置条件：MO已下达，物料齐套
基本流程：
  1. 生产计划员下达MO
  2. 系统展开BOM，需求物料清单
  3. 预留量增加（ReserveQty）
  4. 仓库管理员按工单领料
  5. 生成领料单
  6. 领料单审核 → 过账引擎执行MERGE
  7. 现存量减少
  8. 预留量释放
  9. 完工产品入库
扩展流程：
  - 超额领料：需额外审批流程
  - 补料/退料：生成补料单/退料单
  - 在制品（WIP）：工序级物料占用
```

### UC-04：盘点与账实核对
```
参与者：仓库管理员、审计人员
前置条件：期末关账已完成或盘点半成品
基本流程：
  1. 审计人员制定盘点计划
  2. 仓库管理员执行实地盘点
  3. 记录账面数量 vs 实盘数量
  4. 系统生成盘点差异清单
  5. 盘点确认后生成盘点损溢单
  6. 损溢单审核 → 库存调整记账
扩展流程：
  - 抽盘 vs 全盘：部分物料盘点策略
  - 冻结盘点：盘点期间禁止出入库
  - 账实差异追溯：查询库存变动明细
核心风险：
  ⚠️ 反证#3：盘点差异处理后未追溯原账目变更
```

### UC-05：负库存校验与控制
```
参与者：物控专员、仓库管理员
前置条件：库存校验开关已配置
基本流程：
  1. 出库单录入
  2. 系统检查可用量（AvailQty）
  3. 如果 出库量 > 可用量：
     - 强控模式：拒绝保存，提示可用量不足
     - 弱控模式：允许保存，生成预警
  4. 记录负库存日志（StockCheckNegative）
扩展流程：
  - 事后追溯：查看负库存产生的时间链
  - 批次级负库存：某批次数量不足但总量足够
核心风险：
  ⚠️ 反证#1：批次过期后未及时处理导致表面负库存
```

### UC-06：期末关账与库存结转
```
参与者：财务会计、账套管理员
前置条件：当期所有出入库单据已审核
基本流程：
  1. 财务人员发起期末关账
  2. 系统检查是否有未审核单据
  3. 生成期末库存快照
  4. 库存账期固化（不能再修改历史期间数据）
  5. 触发GL期末关账协同
  6. 生成期末库存报表
扩展流程：
  - 关账前检查：负库存/在途量/锁定量检查
  - 反关账：特殊情况下需授权反关账
  - 期初结转：自动带入下期期初余额
```

## 五、业务切面与账类系统映射

### 5.1 Stock账类与GL/CB账类的角色对比

| 维度 | GL总账 | CB现金银行 | Stock库存 |
|---|---|---|---|
| 日常记账人 | 会计 | 出纳 | 仓库管理员 |
| 业务触发者 | 业务单据 | 收付款单 | 入出库单 |
| 账本视图 | 科目账 | 账户账 | 物料账（多维度） |
| 期末关账 | GL期末 | CB无需关账 | Stock期末 |
| 凭证联动 | 自生成 | 自生成 | 同步生成GL |

### 5.2 Stock五量模型与GL三列差异的同构映射

| GL三列 | Stock五量 | 同构性 |
|---|---|---|
| FCNAMOUNT（业务数） | 现存量（StockQty） | ✅ 同构 |
| FGLAMOUNT（凭证数） | 锁定量（LockQty） | ⚠️ 部分同构 |
| FBALAMOUNT（账面数） | 可用量（AvailQty） | ✅ 同构 |

**关键洞察**：Stock的五量模型比GL三列更复杂，但本质都是**多状态机转换**。差异在于：GL的三个量由同一事务驱动（借贷必相等），而Stock的五个量可能由不同事务独立驱动（需验证U-02）。
