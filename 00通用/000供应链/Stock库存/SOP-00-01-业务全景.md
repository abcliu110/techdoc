## 二、能力矩阵

| 锁定管理 | 核心 | SO/MO锁定的创建和释放 | SO/MO |

## 三、业务边界

### 3.1 边界定义

| 边界类型 | 边界内容 |
|---|---|
| 上游边界 | 采购入库单（PO到货）、生产完工入库（MO完工） |
| 下游边界 | 销售出库单（SO发货）、生产投料单（MO投料） |
| 平行边界 | GL总账、AR应收、AP应付、QC质量 |
| 外部边界 | 供应商（批号来源）、客户（追溯终点） |

## 四、关键角色

| 角色 | 主要操作 | 关注报表 | 权限级别 |
|---|---|---|---|
| 仓库管理员 | 入库验收、出库拣货、盘点、移库 | 库存台账、批次明细 | 日常操作 |
| 物控专员（MC） | 安全库存、MRP、欠料分析、预留 | 可用量分析、锁定期明细 | 计划控制 |
| 生产计划员 | MO投料、BOM展开、产能分析 | 工单物料清单、齐套率 | 生产管理 |
| 采购员 | PO下达、到货检验、入库确认 | 在途物料、到货及时率 | 采购管理 |
| 财务会计 | 库存成本核算、凭证生成、期末关账 | 库存台账（财务视图）、成本报表 | 财务复核 |
| 审计人员 | 账实核对、批次追溯、锁定释放审计 | 全面库存台账、批次追溯链 | 只读审计 |

## 五、与周边模块的协作

| 周边模块 | 协作方向 | 协作内容 |
|---|---|---|
| GL总账 | 双向 | 库存账→GL凭证；GL可追溯库存日记账 |
| AP应付 | 单向→ | 采购入库触发AP应付单生成 |
| AR应收 | 单向→ | 销售出库触发AR应收单生成 |
| PO采购 | 单向← | PO到货后生成采购入库单 |
| MO生产 | 双向 | MO投料消耗库存；MO完工入库增加库存 |
| SO销售 | 单向← | SO审核锁定库存；SO发货生成销售出库单 |
| QC质量 | 单向→ | 检验影响入库；批次效期关联QC |
| CM资金 | 单向← | CM使用库存信息 |

## 六、启用前提

| 前置条件 | 说明 |
|---|---|
| 基础资料 | 仓库、物料、计量单位已完成配置 |
| 批次策略 | 批次管理策略已配置（是否启用批号/效期） |
| 五量配置 | 五量模型的计算公式已配置 |
| 凭证模板 | 库存凭证模板已配置（入库/出库/调拨） |
| 期初余额 | 启用时库存余额已录入 |
| GL协同 | GL模块已启用，科目映射已配置 |
