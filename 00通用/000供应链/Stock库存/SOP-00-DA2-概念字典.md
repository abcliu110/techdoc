## 一、概念字典概述

Stock库存模块的概念字典从账类系统视角出发，定义了Stock区别于其他财务模块的**独有概念**（ST-01至ST-09），以及与财务账类共享的**通用概念**（CG-01至CG-04）。总计13个核心概念。

---

## 二、Stock独有概念（9个）

### ST-01：库存行（StockLine）
| 属性 | 内容 |
|---|---|
| 定义 | 库存账本的最小记账单元，由15个维度唯一定义 |
| 维度 | 组织ID + 仓库ID + 物料ID + 批号 + 序列号 + 单位 + 辅助属性 + 保管者 + 项目 + 用途 + 颜色 + 规格 + 客户 + 供应商 + 有效期 |
| 账类类比 | GL的科目账页，但维度更多 |
| 源码对应 | T_STK_INVENTORY（15维键） |
| 关键特性 | 相同维度合并，不同维度分开记账 |

### ST-02：现存量（StockQty）
| 属性 | 内容 |
|---|---|
| 定义 | 仓库中当前实际持有的物料数量 |
| 计算公式 | 现存量 = 历史入库累计 - 历史出库累计 |
| 账类类比 | GL的账面余额（FBALAMOUNT） |
| 行为规则 | BR-ST-101：现存量不能为负（强控） |
| 异常场景 | ⚠️ 批次过期后未处理导致表面为负（反证#1） |

### ST-03：锁定量（LockQty）
| 属性 | 内容 |
|---|---|
| 定义 | 因销售订单（SO）、生产工单（MO）等被锁定的库存量 |
| 触发来源 | SO/MO审核通过后自动锁定 |
| 释放条件 | SO/MO取消/关闭，或关联出库单审核 |
| 账类类比 | 无直接GL对应，但类似"银行承兑汇票保证金冻结" |
| 异常场景 | ⚠️ 订单关闭后锁定未自动释放（反证#2） |

### ST-04：可用量（AvailQty）
| 属性 | 内容 |
|---|---|
| 定义 | 当前可用于出库的库存量 |
| 计算公式 | 可用量 = 现存量 - 锁定量 - 预留量 |
| 业务意义 | 销售出库/领料的依据 |
| 行为规则 | BR-ST-201：出库量不能超过可用量 |
| 实时性 | 需验证是否在同一事务中计算（U-02） |

### ST-05：预留量（ReserveQty）
| 属性 | 内容 |
|---|---|
| 定义 | 预留给特定用途但尚未实际锁定的库存量 |
| 与LockQty区别 | 预留是计划层面，锁定是执行层面 |
| 触发来源 | 物控专员手动预留，或MRP自动预留 |
| 释放条件 | 预留取消或转化为锁定/出库 |

### ST-06：在途量（TransitQty）
| 属性 | 内容 |
|---|---|
| 定义 | 已提交但尚未到达仓库的物料数量 |
| 典型场景 | 采购在途（PO已下达但未到货验收入库） |
| 账类类比 | 类似CB的"在途资金"概念 |
| 管理意义 | 物控专员用于判断何时补货 |

### ST-07：批次（Batch）
| 属性 | 内容 |
|---|---|
| 定义 | 同一物料的相同来源单位，按生产日期/入库时间分组 |
| 核心属性 | 批号、生产日期、有效期、供应商来源 |
| 策略 | FEFO（先进先出）/FIFO/FEFO效期优先 |
| 账类意义 | 批次是库存账本的时间轴维度，类似GL的会计期间 |
| 效期管理 | 有效期预警、过期批次隔离 |

### ST-08：过账引擎（PostingEngine）
| 属性 | 内容 |
|---|---|
| 定义 | 负责将业务单据转化为库存账目变更的核心机制 |
| 核心组件 | OperationController + 7策略子类 |
| 原子操作 | MERGE（合并更新同一库存行） |
| 账类类比 | GL的过账引擎，但Stock维度更多 |
| 事务性 | 需验证MERGE与GL事务的差异（U-01） |

### ST-09：期末关账（PeriodClose）
| 属性 | 内容 |
|---|---|
| 定义 | 库存账期的固化操作，防止跨期数据修改 |
| 与GL协同 | Stock期末关账触发GL期末协同 |
| 反关账 | 特殊情况下需授权反关账（BR-ST-302） |
| 账类类比 | GL期末结账（期末结转） |

## 三、与财务账类共享的通用概念（4个）

### CG-01：账本（Ledger）
| 属性 | 内容 |
|---|---|
| 定义 | 记录资产/负债/权益变化的系统性账册 |
| Stock实现 | T_STK_INVENTORY（库存台账） |
| GL实现 | T_BD_ACCOUNTBOOK（科目账） |
| CB实现 | T_CN_BANKJOURNAL（银行日记账） |

### CG-02：过账（Posting）
| 属性 | 内容 |
|---|---|
| 定义 | 将业务事件转化为账目变更的动作 |
| Stock实现 | 过账引擎执行MERGE |
| GL实现 | 凭证审核后过账 |

### CG-03：凭证（Voucher）
| 属性 | 内容 |
|---|---|
| 定义 | 账目变更的正式记录凭证 |
| Stock实现 | 库存账凭证（同步生成GL凭证） |
| GL实现 | GL凭证（科目账的记账依据） |

### CG-04：期末结转（PeriodClosing）
| 属性 | 内容 |
|---|---|
| 定义 | 期末将本期发生额结转至下期的操作 |
| Stock实现 | Stock期末关账 |
| GL实现 | GL期间结账 |
