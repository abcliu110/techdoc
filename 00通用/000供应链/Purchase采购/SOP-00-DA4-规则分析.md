## 一、业务规则（BR-Pur系列）

| BR-Pur-202 | 数量限制 | 入库数量不能超过订单未执行数量 | 强 |

## 二、状态机分析

### 2.1 采购订单状态机

```
                    ┌─────────────────┐
                    │   创建(Draft)   │
                    └────────┬────────┘
                             │ 提交/审核
                             ▼
                    ┌─────────────────┐
          ┌────────▶│   已审核(Audit) │
          │         └────────┬────────┘
          │                  │
          │          ┌───────┴───────┐
          │          │               │
          │          ▼               ▼
          │   ┌───────────┐  ┌───────────┐
          │   │ 执行中    │  │  已关闭   │
          │   │(Partially)│  │ (Close)   │
          │   └───────────┘  └───────────┘
          │          │
          │          │ 全额入库/手动关闭
          │          ▼
          │   ┌───────────┐
          │   │  已完成   │
    反审核│   │ (Finished)│
          │   └───────────┘
          │
          │    取消(Cancel)
          └──────────────────────▶ [结束]
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 创建(Draft) | 订单录入未审核 | 提交、删除 |
| 已审核(Audit) | 订单审核通过 | 反审核、变更、关闭 |
| 执行中(Partially) | 部分入库 | 继续入库、关闭 |
| 已关闭(Close) | 订单完成/终止 | - |
| 已完成(Finished) | 全额执行完毕 | 反审核 |

## 三、异常场景

### 3.1 采购异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 到货不足 | 供应商送货数量少于订单数量 | 按实收数量入库，订单部分执行 |
| 到货超量 | 供应商送货数量超过订单数量 | 超出部分需审批或拒收 |
| 质检不合格 | 物料质量不符合标准 | 退料处理，不入库 |
| 价格差异 | 发票价格与订单价格不一致 | 需审批确认 |

### 3.2 财务异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 发票金额差异 | 发票金额≠入库金额 | 价税调整或重新开票 |
| 币种不一致 | 付款币种≠应付币种 | 汇率换算或原路退回 |
| 重复付款 | 同一应付被多次付款 | 追回多付金额或抵下次付款 |

## 四、决策分析

### 4.1 关键决策点

| DEC编号 | 决策点 | 选项 | 选择 |
|---|---|---|---|
| DEC-Pur-01 | 比价策略 | A=SVM询价，B=直接采购 | A+B（可配置） |
| DEC-Pur-02 | 入库成本计价 | A=订单单价，B=实际单价 | A |
| DEC-Pur-03 | 应付生成时机 | A=入库审核时，B=发票确认时 | A+B |
| DEC-Pur-04 | 发票校验方式 | A=严格匹配，B=允许差异 | B |
| DEC-Pur-05 | GL凭证生成时机 | A=同步生成，B=异步生成 | A |

### 4.2 决策表

| 场景 | DEC-01 | DEC-02 | DEC-03 | DEC-04 |
|---|---|---|---|---|
