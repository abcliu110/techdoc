# 典型业务故事 — K3Cloud Purchase采购

## 故事一：标准SVM采购流程

### 背景
某公司需要采购一批生产物料，需要通过SVM询报价流程选择最优供应商。

### 角色
- 采购员：发起询价、评估报价、选择供应商
- 供应商：接收询价、提交报价
- 仓库员：收料、入库

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 步骤1：采购申请                                                   │
├──────────────────────────────────────────────────────────────────┤
│ 采购员根据生产需求创建采购申请单                                  │
│ 申请物料：原材料A 1000kg、原材料B 500kg                          │
│ 申请原因：生产计划需求                                            │
│ 期望交货：2026-08-15                                             │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤2：SVM询价                                                     │
├──────────────────────────────────────────────────────────────────┤
│ 采购员选择启用SVM询报价流程                                       │
│ 创建询价单：                                                       │
│   - 物料：原材料A 1000kg                                         │
│   - 物料：原材料B 500kg                                           │
│ 选择3家候选供应商                                                 │
│ 发送询价单给供应商                                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤3：供应商报价                                                  │
├──────────────────────────────────────────────────────────────────┤
│ 供应商A报价：原材料A ¥50/kg、原材料B ¥30/kg                       │
│ 供应商B报价：原材料A ¥48/kg、原材料B ¥32/kg                       │
│ 供应商C报价：原材料A ¥52/kg、原材料B ¥28/kg                       │
│ 采购员收集3家供应商报价                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤4：比价分析                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 采购员进入比价分析界面                                             │
│ 系统自动计算：                                                     │
│   - 供应商A总价：50×1000 + 30×500 = ¥65,000                      │
│   - 供应商B总价：48×1000 + 32×500 = ¥64,000                      │
│   - 供应商C总价：52×1000 + 28×500 = ¥64,000                      │
│ 综合评估：价格50%、质量30%、交期20%                               │
│ 选择供应商B（综合最优）                                           │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤5：生成订单                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 根据比价结果自动生成采购订单                                       │
│ 订单信息：                                                         │
│   - 供应商：供应商B                                                │
│   - 物料：原材料A 1000kg @ ¥48/kg                                 │
│   - 物料：原材料B 500kg @ ¥32/kg                                  │
│   - 订单总金额：¥64,000                                            │
│ 提交审核                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤6：供应商送货                                                  │
├──────────────────────────────────────────────────────────────────┤
│ 供应商按期送货                                                     │
│ 仓库员收到货物，进行收料登记                                       │
│ 如需质检，送质检部门检验                                          │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤7：采购入库                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 仓库员创建入库单，关联采购订单                                     │
│ 入库信息：                                                         │
│   - 物料：原材料A 1000kg                                          │
│   - 物料：原材料B 500kg                                           │
│   - 成本单价：订单单价                                             │
│ 提交审核                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 步骤8：审核入库（自动触发）                                        │
├──────────────────────────────────────────────────────────────────┤
│ 入库审核时系统自动执行：                                           │
│   1. 增加库存（原材料A +1000kg、原材料B +500kg）                   │
│   2. 生成应付单（金额：¥64,000）                                   │
│   3. 生成GL凭证（借：库存科目、贷：应付科目）                       │
│ 入库完成                                                            │
└──────────────────────────────────────────────────────────────────┘
```

## 故事二：到货不足场景

### 背景
供应商送货数量少于订单数量，需要部分入库。

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 订单信息                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 订单号：PO-2026-08001                                             │
│ 供应商：供应商A                                                    │
│ 物料：原材料A 1000kg                                              │
│ 订单金额：¥50,000                                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 供应商送货                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 供应商实际送货：原材料A 800kg（少200kg）                           │
│ 仓库员核实送货数量，发现与订单不符                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 创建入库单                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 仓库员按实际送货数量创建入库单                                     │
│ 入库数量：原材料A 800kg（不是1000kg）                             │
│ 备注：到货不足，少200kg                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 入库审核                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 入库审核时系统执行：                                               │
│   1. 增加库存：原材料A +800kg（不是1000kg）                       │
│   2. 生成应付单：¥40,000（800kg × ¥50/kg）                        │
│   3. 生成GL凭证                                                   │
│ 订单状态变为"部分执行"                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 后续处理                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 采购员与供应商协商补货或取消剩余订单                               │
│ 供应商补货后再次入库                                               │
│ 或采购员修改订单数量                                               │
└──────────────────────────────────────────────────────────────────┘
```

## 故事三：采购退料场景

### 背景
采购入库后发现物料质量问题，需要退料。

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 入库完成                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 入库单：PI-2026-08001                                             │
│ 物料：原材料A 1000kg @ ¥50/kg                                     │
│ 应付单：¥50,000（已生成）                                         │
│ GL凭证：已生成                                                    │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 质检发现质量问题                                                    │
├──────────────────────────────────────────────────────────────────┤
│ 质检部门检测发现原材料A质量不合格                                  │
│ 通知仓库和采购部门                                                 │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 创建退料单                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 仓库员创建退料单                                                   │
│ 退料数量：原材料A 1000kg                                          │
│ 退料原因：质量不合格                                               │
│ 关联原入库单                                                       │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 退料审核（自动触发）                                               │
├──────────────────────────────────────────────────────────────────┤
│ 退料审核时系统自动执行：                                           │
│   1. 减少库存：原材料A -1000kg（红字出库）                        │
│   2. 应付红冲：生成应付红字 -¥50,000                               │
│   3. GL凭证：生成红字凭证对冲原凭证                                │
│ 退料完成                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 后续处理                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 采购员与供应商协商退货或换货                                       │
│ 如换货：重新入库                                                   │
│ 如退货：退款处理                                                   │
└──────────────────────────────────────────────────────────────────┘
```

## 故事四：发票差异处理

### 背景
供应商开具的发票金额与应付单金额不一致。

### 流程

```
┌──────────────────────────────────────────────────────────────────┐
│ 入库完成                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 入库单金额：¥64,000（含税）                                       │
│ 应付单金额：¥64,000                                               │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 收到发票                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 供应商开具增值税发票                                               │
│ 发票金额：¥65,000（含税）                                         │
│ 差异：¥1,000（供应商开票错误）                                    │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 发票校验                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 财务人员进行发票校验                                               │
│ 系统自动检测差异：发票¥65,000 vs 应付¥64,000                      │
│ 差异¥1,000超过容差阈值                                            │
│ 系统提示：差异需审批                                               │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 审批流程                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 系统创建差异审批流程                                               │
│ 采购经理审批：确认差异原因（供应商开票错误）                        │
│ 财务经理审批：确认可接受                                            │
│ 审批通过                                                            │
└──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────────┐
│ 发票确认                                                          │
├──────────────────────────────────────────────────────────────────┤
│ 审批通过后，财务确认发票                                           │
│ 系统更新应付单金额为¥65,000                                        │
│ 或要求供应商重新开具正确发票                                       │
│ 继续付款流程                                                        │
└──────────────────────────────────────────────────────────────────┘
```
