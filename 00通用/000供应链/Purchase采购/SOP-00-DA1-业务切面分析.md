| 供应商 | 报价/交货 | 报价确认、发货 | 询价单、报价单 |

## 二、业务分类切面

### 2.1 业务分类矩阵

| 分类维度 | 类型 | 核心特征 |
|---|---|---|
| 采购方式 | 标准采购 | 申请→订单→入库 |
| 采购方式 | SVM询价采购 | 申请→询价→报价→比价→订单 |
| 采购方式 | 计划采购 | MRP运算→自动生成申请 |
| 采购方式 | 紧急采购 | 直接下单，跳过申请 |
| 交付方式 | 一步到货 | 到货直接入库 |
| 交付方式 | 两步收料 | 到货→收料→质检→入库 |
| 结算方式 | 先款后货 | 预付款→发货→入库 |
| 结算方式 | 先货后款 | 入库→发票→付款 |
| 结算方式 | 月结 | 期末统一结算 |

### 2.2 业务分类详情

#### 标准采购流程
```
采购申请 → 采购订单 → 收料通知 → 采购入库 → 采购发票
```

#### SVM询报价流程
```
采购申请 → 询价单 → 多供应商报价 → 比价分析 → 采购订单
```

#### MRP计划采购
```
MRP运算 → 采购建议 → 采购申请（自动） → 采购订单
```

## 四、切面分析结论

### 4.1 核心业务对象识别

| BO | 业务对象 | 生命周期 | 关联用例 |
|---|---|---|---|
| BO-01 | 采购申请 | 创建→审核→转单/关闭 | UC-01 |
| BO-02 | 询价单 | 创建→发送→报价收集→关闭 | UC-02 |
| BO-03 | 报价单 | 创建→报价→比价 | UC-02 |
| BO-04 | 采购订单 | 创建→审核→执行→关闭 | UC-03, UC-07 |
| BO-05 | 收料单 | 创建→收料→质检→确认 | UC-04 |
| BO-06 | 采购入库 | 创建→审核→过账 | UC-04 |
| BO-07 | 采购退料 | 创建→审核→过账 | UC-08 |
| BO-08 | 应付单 | 创建→核销/红冲 | UC-05 |

### 4.2 业务边界

- **上游**：MRP运算、库存不足预警、手工申请
- **下游**：库存（Stock）、应付（AP）、GL凭证
- **平行**：销售（Sal）、生产（MO）、质量（QC）
