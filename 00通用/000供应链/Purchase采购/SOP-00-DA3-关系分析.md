## 三、关系详细契约

### 3.1 REL-04：比价→订单

```
契约名称：比价结果转订单
前置条件：比价已完成、最优供应商已确认
后置条件：采购订单创建、比价状态变为"已转单"
数据映射：
  - 供应商 → 供应商
  - 物料明细 → 物料明细
  - 单价 → 单价（最优报价）
  - 交货日期 → 交货日期
约束：
  - 转单后比价不能修改
  - 订单金额不能大于最优报价
```

### 3.2 REL-07：收料→入库

```
契约名称：收料后入库
前置条件：收料已确认、质检通过
后置条件：入库单创建、库存增加
数据映射：
  - 供应商 → 供应商
  - 物料编码 → FMATERIALID
  - 实收数量 → FQTY
  - 仓库 → FSTOCKID
约束：
  - 入库数量不能大于收料数量
  - 批次物料需分配批号
```

### 3.3 REL-10：入库→应付

```
契约名称：入库生成应付单
前置条件：入库已审核
后置条件：应付单创建、待付款增加
数据映射：
  - 供应商 → FSUPPLIERID
  - 入库金额 → FALLAMOUNT
  - 币种 → FCURRENCYID
  - 到期日 → FREDATE（按账期计算）
约束：
  - 应付金额基于入库含税金额
  - 发票金额与应付金额可差异（发票校验）
```

## 四、路径分析

### 4.1 核心业务路径

```
路径P-01：SVM标准采购链路
申请 → 询价 → 报价 → 比价 → 订单 → 收料 → 入库 → 应付 → 付款

路径长度：9步
涉及BO：申请、询价、报价、比价、订单、收料、入库、应付、付款
退出点：任意步骤可退出（询价无响应/订单取消/入库拒收）

路径P-02：紧急采购链路
申请 → 订单 → 入库（跳过SVM询价）

路径P-03：退料链路
入库 → 退料 → 应付红冲 → 退款

路径P-04：MRP计划采购链路
MRP运算 → 申请（自动） → 订单 → 入库
```

## 五、DA3分析结论

**关系清单**：14个关系
- 操作关系：5个
- 结构关系：4个
- 轨迹关系：5个

**核心路径**：4条
- P-01：SVM标准采购完整链路（9步）
- P-02：紧急采购链路
- P-03：退料链路
- P-04：MRP计划采购链路

**进入DA4的输入**：
- 3个关键契约需定义业务规则
- 路径P-01/P-03为主路径
- REL-07（收料→入库）和REL-10（入库→应付）为关键轨迹
