## 二、采购链流转（配置驱动）

### 2.1 完整业务流程

```
采购申请 → 采购订单 → 收料通知 → 采购入库 → 采购发票
    ↑
    └── SVM：申请→询价→报价→比价（唯一代码化部分）
```

### 2.2 配置驱动特点

**关键发现**：采购链"申请→订单→收料→入库→发票"**零转换插件代码**，靠元数据ConvertRule配置。

| 转换环节 | 实现方式 | 代码化程度 |
|---|---|---|
| 申请→订单 | ConvertRule配置 | 零代码 |
| 订单→收料 | ConvertRule配置 | 零代码 |
| 收料→入库 | ConvertRule配置 | 零代码 |
| 入库→发票 | ConvertRule配置 | 零代码 |
| SVM：申请→询价 | SVM模块 | 有代码 |
| SVM：询价→报价 | SVM模块 | 有代码 |
| SVM：报价→比价 | SVM模块 | 有代码 |

### 2.3 SVM供应商协同（唯一代码化部分）

| 转换类型 | 插件名 | 说明 |
|---|---|---|
| 申请→询价 | PurReqToInquiryBill | 采购申请转询价单 |
| 询价→报价 | InquiryToQuoteBill | 询价单转报价单 |
| 报价→比价 | InquiryBillToComparePrice | 报价单转比价单 |

## 三、核心机制

### 3.1 过账引擎（与Stock/Sal共享）

- **OperationController** + 7策略子类
- 入库过账：采购入库单审核→MERGE INTO T_STK_INVENTORY
- 与Stock/Sal共用同一套库存更新机制

### 3.2 采购定价

- **PurchaseService**：价格表/比价/配额（4,722行巨型类）
- 价格策略：供应商价格、协议价、比价结果
- SVM询报价：多供应商比价最优选择

### 3.3 与Stock的集成

- 采购入库触发库存增加
- 采购价格影响库存成本
- 批次管理：入库时生成批号

## 八、DA0侦察结论

**核心发现**：
1. Purchase采购是配置驱动子域（159文件/58,863行）
2. 采购链"申请→订单→收料→入库"零代码，靠ConvertRule配置
3. SVM是唯一代码化的采购环节（询价→报价→比价）
4. 与Stock/AP/GL形成完整的"采购→入库→应付→凭证"链路

**DA1切面选择**：
- 采购申请生命周期
- 采购订单与入库联动
- 应付生成与付款闭环
- SVM询报价流程

**DA2概念切分**：
- 采购主体：供应商/申请/订单/收料/入库/发票
- 财务主体：应付/付款/凭证
- 库存主体：入库/批次

**执行路径**：路径A（核心抽象内进化）
