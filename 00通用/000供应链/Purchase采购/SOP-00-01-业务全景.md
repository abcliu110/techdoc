# 业务全景 — K3Cloud Purchase采购

## 一、业务定位

### 1.1 在供应链中的位置

```
┌─────────────────────────────────────────────────────────────┐
│                      供应链（Supply Chain）                    │
├─────────────┬─────────────┬─────────────┬──────────────────┤
│   销售模块   │   采购模块   │   库存模块   │    财务模块      │
│    (Sal)    │  (Purchase) │   (Stock)   │   (GL/AP/AR)    │
├─────────────┼─────────────┼─────────────┼──────────────────┤
│   销售订单   │   采购申请   │             │                 │
│      ↓      │      ↓      │             │                 │
│   库存预留   │   SVM询价   │             │                 │
│      ↓      │      ↓      │             │                 │
│   销售出库   │   采购订单   │             │                 │
│      ↓      │      ↓      │             │                 │
│   应收生成   │   采购入库   │ ──▶ 库存   │ ──▶ 应付生成     │
│      ↓      │      ↓      │             │      ↓          │
│   GL凭证    │   GL凭证    │             │    GL凭证       │
└─────────────┴─────────────┴─────────────┴──────────────────┘
```

### 1.2 采购核心职责

| 职责 | 说明 |
|---|---|
| 供应商管理 | 供应商档案、配额管理、绩效评估 |
| 询报价管理 | SVM询价、报价、比价、供应商选择 |
| 采购执行 | 采购申请、采购订单、收料、入库 |
| 成本控制 | 采购价格管控、协议价管理 |
| 财务集成 | 入库触发应付、GL凭证生成 |

## 二、业务边界

### 2.1 采购范围

**包含**：
- 采购申请管理
- SVM询报价管理（唯一代码化部分）
- 采购订单管理
- 采购收料管理
- 采购入库管理
- 采购退料管理
- 采购价格管理

**不包含**：
- 供应商档案管理（属于基础数据）
- 物料档案管理（属于基础数据）
- 库存管理（属于Stock模块）
- 应付管理（属于AP模块）
- 付款管理（属于CB模块）

## 三、业务架构

### 3.1 采购子域划分

| 子域 | 说明 | 代码化程度 |
|---|---|---|
| 采购申请 | 采购需求发起 | 配置驱动 |
| SVM询报价 | 供应商协同（唯一代码化） | 代码驱动 |
| 采购订单 | 采购合同执行 | 配置驱动 |
| 采购收料 | 供应商送货接收 | 配置驱动 |
| 采购入库 | 物料入库确认 | 配置+代码 |
| 采购退料 | 不合格品退回 | 配置驱动 |

### 3.2 配置驱动 vs 代码驱动

| 环节 | 驱动方式 | 说明 |
|---|---|---|
| 申请→订单 | ConvertRule配置 | 标准线性转换 |
| 订单→收料 | ConvertRule配置 | 标准线性转换 |
| 收料→入库 | ConvertRule配置 | 标准线性转换 |
| 入库→发票 | ConvertRule配置 | 标准线性转换 |
| 申请→询价 | SVM代码 | 唯一代码化转换 |
| 询价→报价 | SVM代码 | 唯一代码化转换 |
| 报价→比价 | SVM代码 | 唯一代码化转换 |

## 四、业务能力

### 4.1 核心能力

| 能力 | 说明 |
|---|---|
| 多渠道采购 | 支持SVM询价、直接采购、MRP自动生成 |
| 供应商协同 | SVM询报价全流程管理 |
| 价格管控 | 协议价、价目表、价格审批 |
| 配额管理 | 按供应商配额分配订单 |
| 批次管理 | 批次物料入库生成批号 |
| 成本核算 | 入库成本按订单单价计算 |
| 财务集成 | 入库触发应付和GL凭证 |

### 4.2 关键业务规则

| 规则 | 约束级别 |
|---|---|
| 入库数量不能超过订单未执行数量 | 强 |
| 批次管理物料入库时必须生成批号 | 强 |
| 入库审核时自动生成应付单 | 强 |
| 应付金额=入库含税金额 | 强 |
| 入库审核时生成采购成本凭证 | 强 |

## 五、业务指标

| 指标 | 说明 |
|---|---|
| 采购订单执行率 | 已入库数量 / 订单数量 |
| SVM询报价成功率 | 成功报价数 / 询价数 |
| 供应商准时交货率 | 准时交货次数 / 总交货次数 |
| 采购成本偏差率 | 实际成本 / 计划成本 - 1 |
| 发票差异率 | 发票差异金额 / 应付金额 |

## 六、业务风险

| 风险 | 等级 | 说明 |
|---|---|---|
| 巨型类维护困难 | 高 | PurchaseService 4,722行 |
| 配置驱动黑盒 | 高 | 无法从源码学习完整逻辑 |
| SVM比价不透明 | 中 | 比价决策逻辑黑盒 |
| 发票差异处理复杂 | 中 | 需审批确认 |
| 供应商配额不透明 | 中 | 分配逻辑不透明 |
