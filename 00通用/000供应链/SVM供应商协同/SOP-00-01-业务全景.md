## 一、业务定位

### 1.1 SVM在供应链中的位置

```
┌─────────────────────────────────────────────────────────────┐
│                     供应链业务域                              │
├─────────────┬─────────────┬─────────────┬───────────────────┤
│   销售管理   │   采购管理   │   库存管理   │    财务管理       │
│   (Sal)     │  (Purchase) │   (Stock)   │    (AR/AP/GL)     │
├─────────────┼──────┬──────┼─────────────┼───────────────────┤
│             │ SVM  │ 核心 │             │                   │
│             │ 供应商│ 采购 │             │                   │
│             │ 协同  │ 链   │             │                   │
└─────────────┴──────┴──────┴─────────────┴───────────────────┘

SVM定位：
- 采购管理的子模块
- 采购链的唯一代码化环节
- 负责询价、比价、供应商选择
```

### 1.2 业务边界

| 边界 | 说明 |
|---|---|
| 入边界 | 接收采购申请，触发询价流程 |
| 出边界 | 输出最优供应商和价格，生成采购订单 |
| 协作边界 | 与供应商Portal集成，在线协同 |

## 二、业务能力

### 2.1 核心能力

| 能力 | 说明 |
|---|---|
| 询价管理 | 向多个供应商发起询价，支持模板询价 |
| 报价管理 | 收集供应商报价，支持在线报价和附件上传 |
| 比价分析 | 多维度比价分析，支持价格优先和综合评分 |
| 决策支持 | 提供最优供应商建议，辅助采购决策 |
| 订单生成 | 根据比价结果自动生成采购订单 |

### 2.2 支撑能力

| 能力 | 说明 |
|---|---|
| 供应商管理 | 维护供应商库，评估供应商资质 |
| 价格管理 | 历史价格追踪，价格走势分析 |
| 报表分析 | 询价汇总、供应商响应率、节支分析 |

## 三、业务流程

### 3.1 完整流程

```
采购申请 ──▶ 询价单 ──▶ 报价单(×N) ──▶ 比价单 ──▶ 采购订单
                │           │              │
                │           │              │
            选择供应商    供应商响应    比价分析
                │           │              │
                │           │              │
            发送询价      提交报价     选择最优
                │           │              │
                ▼           ▼              ▼
             等待报价   等待比价      生成订单
```

### 3.2 紧急采购流程

```
采购申请 ──▶ 采购订单（跳过SVM）
                ↑
        不经过询价比价
```

## 四、业务规则

### 4.1 核心规则

| 规则类型 | 规则数量 | 说明 |
|---|---|---|
| 询价规则 | 4条 | 来源、数量、日期、明细 |
| 报价规则 | 4条 | 时间、完整、有效期、成本 |
| 比价规则 | 4条 | 时机、策略、评分、锁定 |
| 订单规则 | 4条 | 来源、价格、数量、供应商 |

### 4.2 关键规则

```
规则1：至少邀请2个供应商
规则2：报价必须在截止日期前
规则3：至少2个有效报价才能比价
规则4：比价后不能修改报价
规则5：订单采用最优报价
```

## 六、状态机

### 6.1 单据状态

| 单据 | 状态数量 | 关键状态 |
|---|---|---|
| 询价单 | 6个 | 创建→发送→报价→转单/关闭→结束 |
| 报价单 | 5个 | 无报价→已报价→接受/拒绝→转单 |
| 比价单 | 5个 | 创建→比价中→完成→转单/作废 |

### 6.2 状态流转图

```
询价单：
创建 ──▶ 发送 ──┬──▶ 已报价 ──▶ 已转单 ──▶ 结束
                │
                └──▶ 关闭 ──▶ 结束

比价单：
创建 ──▶ 比价中 ──▶ 已完成 ──┬──▶ 已转单
                             │
                             └──▶ 已作废
```

## 九、业务价值

### 9.1 核心价值

| 价值 | 说明 |
|---|---|
| 阳光采购 | 多方比价，过程透明 |
| 成本优化 | 竞争机制，获取最优价格 |
| 决策科学 | 数据支撑，减少主观判断 |
| 效率提升 | 在线协同，减少人工沟通 |

### 9.2 量化指标

| 指标 | 说明 |
|---|---|
| 供应商响应率 | 响应询价/邀请询价的比例 |
| 比价节支率 | (预算价-最优价)/预算价 |
| 采购周期 | 从申请到订单的时间 |
