## 三、关系详细契约

### 3.1 REL-01：申请→询价

```
契约名称：采购申请转询价单
前置条件：采购申请已审核
后置条件：询价单创建、关联采购申请
数据映射：
  - 申请单号 → 源单号
  - 物料明细 → 询价明细
  - 需求数量 → 询价数量
  - 需求日期 → 期望交期
约束：
  - 一个申请只能转一个询价
  - 询价数量不能超过申请数量
```

### 3.2 REL-02：询价→报价

```
契约名称：询价单收集供应商报价
前置条件：询价单已发送、供应商已收到
后置条件：报价单创建、关联询价单
数据映射：
  - 询价物料 → 报价物料
  - 询价数量 → 报价数量
  - 期望单价 → 参考单价
约束：
  - 供应商只能在截止日期前报价
  - 报价必须针对同一询价单
```

### 3.3 REL-03：报价→比价

```
契约名称：多报价汇总比价分析
前置条件：至少两个供应商已报价
后置条件：比价单创建、关联所有报价单
数据映射：
  - 各供应商报价 → 比价明细行
  - 报价单价 → 对比价格
  - 交货期 → 交期对比
约束：
  - 比价必须在询价截止后执行
  - 比价单生成后不能修改
```

### 3.4 REL-04：比价→订单

```
契约名称：比价结果转采购订单
前置条件：比价已完成、最优供应商已确认
后置条件：采购订单创建、关联比价单
数据映射：
  - 最优供应商 → 订单供应商
  - 最优报价 → 订单单价
  - 询价数量 → 订单数量
约束：
  - 转单后比价单状态变为"已转单"
  - 订单金额不能大于最优报价金额
```

## 四、路径分析

### 4.1 核心业务路径

```
路径P-01：SVM标准询报价链路
采购申请 → 询价单 → 报价单(×N) → 比价单 → 采购订单

路径长度：5步
涉及BO：申请、询价、报价(多)、比价、订单
退出点：任意步骤可退出（无供应商响应/取消询价）
```
