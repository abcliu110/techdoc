## 二、SVM定位

### 2.1 在采购链中的位置

```
供应链采购链：
申请 → 询价 → 报价 → 比价 → 订单 → 收料 → 入库 → 应付 → 付款
          ↑                        ↑
          └── SVM核心区域 ──────────┘

配置驱动（零代码）vs 代码化：
- 申请→订单：ConvertRule配置 ❌
- 订单→收料：ConvertRule配置 ❌
- 收料→入库：ConvertRule配置 ❌
- 入库→发票：ConvertRule配置 ❌
- 申请→询价：SVM模块 ✅ 代码化
- 询价→报价：SVM模块 ✅ 代码化
- 报价→比价：SVM模块 ✅ 代码化
```

### 2.2 核心业务价值

| 价值点 | 说明 |
|---|---|
| 多供应商比价 | 支持同时向多个供应商询价，智能选择最优 |
| 采购决策支持 | 提供价格、交期、质量综合评分 |
| 供应链协同 | 与供应商在线协同报价，提高效率 |
| 成本优化 | 通过竞争机制获取最优采购价格 |

## 三、核心单据

### 3.1 SVM三大核心单据

| 单据 | 表名 | 功能 | 关键特征 |
|---|---|---|---|
| 询价单 | T_SVM_InquiryBill | 向供应商发起询价 | 多供应商、物料明细、截止日期 |
| 报价单 | T_SVM_QuoteBill | 供应商回复报价 | 供应商、价格、有效期、交货期 |
| 比价单 | T_SVM_ComparePrice | 多报价对比分析 | 综合评分、最优选择、决策依据 |

### 3.2 单据状态

**询价单状态**：
```
创建 → 已发送 → 已报价 → 已转单 → 已关闭
```

**报价单状态**：
```
创建 → 已报价 → 已接受/已拒绝 → 已转单
```

**比价单状态**：
```
创建 → 比价中 → 已完成 → 已转单/已作废
```

## 八、DA0侦察结论

**核心发现**：
1. SVM是采购链中唯一代码化的环节（申请→询价→报价→比价）
2. 包含3个核心单据：询价单、报价单、比价单
3. 提供多供应商比价决策支持
4. 代码规模约3,000行，是小型但关键的子域

**DA1切面选择**：
- 询价流程管理
- 多供应商报价协同
- 比价决策分析
- 订单生成机制

**DA2概念切分**：
- 询价主体：询价单、物料明细、供应商列表
- 报价主体：报价单、价格信息、交货期
- 比价主体：比价单、评分结果、最优选择

**执行路径**：路径A（核心抽象内进化）
