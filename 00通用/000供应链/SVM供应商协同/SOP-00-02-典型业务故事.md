## 故事一：标准询价比价采购

### 1.1 背景

某公司需要采购一批办公电脑（10台），采购员小王发起了一次标准的SVM询价比价流程。

### 1.2 业务场景

```
场景：采购办公电脑10台，预算¥50,000
参与者：采购员小王、供应商甲、供应商乙、供应商丙
```

### 1.3 执行步骤

**步骤1：创建询价单**

```
采购员小王：
- 选择物料：笔记本电脑×10
- 设置期望单价：¥5,000/台
- 设置期望交期：7天内
- 邀请供应商：甲、乙、丙
- 设置截止日期：3天后

系统响应：
- 生成询价单号：INQ-20240115-001
- 状态：创建
```

**步骤2：发送询价**

```
采购员小王：
- 确认询价内容无误
- 点击"发送询价"

系统响应：
- 状态变为：已发送
- 向甲、乙、丙发送询价通知
```

**步骤3：供应商报价**

```
供应商甲（1天后回复）：
- 报价：¥4,800/台，总价¥48,000
- 交期：5天
- 状态：已报价

供应商乙（2天后回复）：
- 报价：¥4,500/台，总价¥45,000
- 交期：7天
- 状态：已报价

供应商丙（未响应）：
- 状态：未回复
```

**步骤4：执行比价**

```
采购员小王：
- 查看比价单
- 选择"价格优先"策略

系统分析：
| 供应商 | 单价    | 总价    | 交期 | 价格分 | 综合分 |
|--------|---------|---------|------|--------|--------|
| 甲     | ¥4,800  | ¥48,000 | 5天  | 94分   | 92分   |
| 乙     | ¥4,500  | ¥45,000 | 7天  | 100分  | 95分   |

最优选择：供应商乙
最优价格：¥4,500/台
节省金额：¥5,000（相比预算）
```

**步骤5：生成订单**

```
采购员小王：
- 确认比价结果
- 点击"生成订单"

系统响应：
- 生成采购订单
- 订单号：PO-20240120-001
- 供应商：乙
- 单价：¥4,500/台
- 数量：10台
- 金额：¥45,000
```

### 1.4 业务结果

| 指标 | 数值 |
|---|---|
| 询价供应商 | 3家 |
| 响应供应商 | 2家 |
| 供应商响应率 | 67% |
| 预算价格 | ¥50,000 |
| 最优价格 | ¥45,000 |
| 节省金额 | ¥5,000 |
| 节支率 | 10% |

## 故事二：综合评分比价

### 2.1 背景

某公司采购一批精密设备，不仅考虑价格，还要考虑交期和供应商资质。

### 2.2 业务场景

```
场景：采购精密设备1套，预算¥200,000
评分权重：价格50%、交期30%、资质20%
参与者：采购员、采购主管
```

### 2.3 执行步骤

**步骤1：配置比价策略**

```
采购主管设置综合评分规则：
- 价格权重：50%
- 交期权重：30%
- 资质权重：20%

评分标准：
- 价格分 = (最低价/报价) × 100
- 交期分 = (最短交期/交期) × 100
- 资质分：优=100分、良=80分、中=60分
```

**步骤2：收集报价**

```
供应商A：
- 价格：¥180,000
- 交期：15天
- 资质：优

供应商B：
- 价格：¥165,000
- 交期：25天
- 资质：良

供应商C：
- 价格：¥195,000
- 交期：10天
- 资质：优
```

**步骤3：综合评分计算**

```
供应商A：
- 价格分 = (165,000/180,000) × 100 = 92分
- 交期分 = (10/15) × 100 = 67分
- 资质分 = 100分
- 综合分 = 92×50% + 67×30% + 100×20% = 46+20+20 = 86分

供应商B：
- 价格分 = (165,000/165,000) × 100 = 100分
- 交期分 = (10/25) × 100 = 40分
- 资质分 = 80分
- 综合分 = 100×50% + 40×30% + 80×20% = 50+12+16 = 78分

供应商C：
- 价格分 = (165,000/195,000) × 100 = 85分
- 交期分 = (10/10) × 100 = 100分
- 资质分 = 100分
- 综合分 = 85×50% + 100×30% + 100×20% = 43+30+20 = 93分
```

**步骤4：比价决策**

```
排序结果：
| 排名 | 供应商 | 价格分 | 交期分 | 资质分 | 综合分 |
|------|--------|--------|--------|--------|--------|
| 1    | C      | 85     | 100    | 100    | 93分   |
| 2    | A      | 92     | 67     | 100    | 86分   |
| 3    | B      | 100    | 40     | 80     | 78分   |

最优选择：供应商C（综合分最高）
虽然C价格不是最低，但综合得分最高
```

### 2.4 业务结果

```
选择供应商：C
选择理由：综合评分最高，交期最短，资质优秀
总成本：¥195,000
节支率：(200,000-195,000)/200,000 = 2.5%
```

## 故事三：紧急采购跳过SVM

### 3.1 背景

某客户急需一个配件，车间主任申请紧急采购，需要跳过SVM询价流程。

### 3.2 业务场景

```
场景：紧急采购配件1个
原因：产线故障，急需配件恢复生产
特殊处理：跳过SVM询价，直接下单
```

### 3.3 执行步骤

**步骤1：发起紧急采购申请**

```
车间主任：
- 申请物料：配件X
- 数量：1个
- 原因：产线故障紧急
- 勾选"紧急采购"

系统响应：
- 生成采购申请单
- 标记紧急标识
```

**步骤2：主管审批**

```
采购主管：
- 查看紧急原因

- 备注：跳过SVM询价

系统响应：
- 审批通过
- 跳过SVM询价环节
```

**步骤3：直接生成订单**

```
采购员：

系统响应：
- 生成采购订单
- 关联紧急采购申请
- 备注：紧急采购，跳过SVM
```

### 3.4 业务结果


## 故事四：无供应商响应

### 4.1 背景

某公司发起一次询价，但所有供应商都未在截止日期前响应报价。

### 4.2 业务场景

```
场景：采购特殊材料，向3个供应商询价
结果：截止日期到，无人响应
```

### 4.3 执行步骤

**步骤1：发送询价**

```
采购员发送询价：
- 物料：特殊材料X
- 数量：100kg
- 供应商：甲、乙、丙
- 截止日期：1月15日
```

**步骤2：等待报价**

```
截止日期前：
- 供应商甲：未响应
- 供应商乙：未响应
- 供应商丙：未响应
```

**步骤3：系统自动处理**

```
系统检测：
- 截止日期已过
- 有效报价数 = 0
- 无法执行比价

系统响应：
- 自动关闭询价单
- 状态变为：已关闭
- 发送通知给采购员
```

**步骤4：后续处理**

```
采购员：
- 分析无人响应原因
- 可能原因：
  1. 价格太低
  2. 交期太短
  3. 供应商无货

后续操作：
- 重新询价（调整条件）
- 寻找新供应商
- 或改为紧急直采
```

## 故事五：比价后价格锁定

### 5.1 背景

某公司完成比价，选择了最优供应商，但在转单前，供应商要求涨价。

### 5.2 业务场景

```
场景：比价完成，最优报价¥45,000
问题：供应商要求加价至¥48,000
```

### 5.3 执行步骤

**步骤1：比价完成**

```
系统比价结果：
| 供应商 | 报价    |
|--------|---------|
| 甲     | ¥45,000 | ← 最优
| 乙     | ¥48,000 |
| 丙     | ¥50,000 |

最优：供应商甲，¥45,000
```

**步骤2：供应商要求涨价**

```
供应商甲：
- 因原材料涨价
- 要求将价格从¥45,000调整为¥48,000
- 否则无法供货
```

**步骤3：采购决策**

```
采购员面临选择：
A. 接受涨价 ¥48,000
B. 拒绝，选择第二名供应商乙 ¥48,000
C. 重新询价

决策过程：
- 对比A和B：价格相同，但甲有比价记录
- 考虑：保持比价公正性
- 决策：选择B（供应商乙），按比价结果执行
```

**步骤4：生成订单**

```
系统响应：
- 选择第二名供应商乙
- 按比价价格¥48,000生成订单
- 记录决策原因：最优供应商拒绝，以第二名成交
```

### 5.4 业务结果

```
订单供应商：乙
订单价格：¥48,000（原比价最优价，但因甲拒绝）
决策依据：比价结果优先
备注：供应商甲拒绝，以第二名成交
```
