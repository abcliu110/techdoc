## 一、核心业务概念

### 1.1 询价相关概念

| 概念ID | 概念名称 | 定义 | 关键属性 |
|---|---|---|---|
| C-01 | 询价单 | 向供应商发起询价的正式单据 | 询价单号、询价主题、截止日期、询价状态 |
| C-02 | 询价明细 | 询价单中的物料明细行 | 物料编码、名称、规格、询价数量、期望单价、期望交期 |
| C-03 | 询价供应商 | 被邀请参与询价的供应商 | 供应商编码、名称、联系方式、发送状态、回复状态 |
| C-04 | 询价模板 | 常用询价单模板 | 模板名称、模板内容、适用范围 |

### 1.2 报价相关概念

| 概念ID | 概念名称 | 定义 | 关键属性 |
|---|---|---|---|
| C-05 | 报价单 | 供应商回复的正式报价 | 报价单号、供应商、报价日期、有效期、报价状态 |
| C-06 | 报价明细 | 报价单中的物料价格行 | 物料、报价单价、报价金额、含税/不含税、交货期 |
| C-07 | 报价有效期 | 报价的有效时间范围 | 开始日期、结束日期、是否自动延期 |
| C-08 | 报价附件 | 供应商上传的报价相关文件 | 文件名称、文件类型、文件大小、上传时间 |

### 1.3 比价相关概念

| 概念ID | 概念名称 | 定义 | 关键属性 |
|---|---|---|---|
| C-09 | 比价单 | 多供应商报价对比分析单据 | 比价单号、比价日期、比价状态、最优供应商 |
| C-10 | 比价明细 | 各供应商报价的对比行 | 物料、各供应商报价、价差、最优报价 |
| C-11 | 综合评分 | 多维度评价的综合得分 | 价格分、质量分、交期分、服务分、综合分 |
| C-12 | 最优选择 | 比价后的最优决策结果 | 最优供应商、最优价格、选择理由 |

## 四、概念定义详解

### 4.1 询价单（C-01）

**定义**：采购人员根据采购需求，向一个或多个供应商发起的正式询价请求单据。

**生命周期**：
```
创建 → 已发送 → 已报价 → 已转单 → 已关闭
```

**关键属性说明**：
| 属性 | 说明 |
|---|---|
| 询价单号 | 系统自动生成，唯一标识 |
| 询价主题 | 询价的简要描述 |
| 截止日期 | 供应商报价的截止时间 |
| 询价状态 | 记录当前所处阶段 |

### 4.2 报价单（C-05）

**定义**：供应商针对询价单提交的正式报价，包含价格、交期等关键商务信息。

**生命周期**：
```
创建 → 已报价 → 已接受/已拒绝 → 已转单
```

**关键属性说明**：
| 属性 | 说明 |
|---|---|
| 报价单号 | 供应商提交的报价编号 |
| 有效期 | 报价的有效时间窗口 |
| 报价单价 | 含税/不含税单价 |
| 交货期 | 承诺的交货时间 |

### 4.3 比价单（C-09）

**定义**：对多个供应商的报价进行对比分析的单据，包含价格比较、评分、最优选择等。

**生命周期**：
```
创建 → 比价中 → 已完成 → 已转单/已作废
```

**关键属性说明**：
| 属性 | 说明 |
|---|---|
| 价格分 | 根据价格竞争力的得分 |
| 交期分 | 根据交期合理性的得分 |
| 综合分 | 多维度加权平均得分 |

## 五、DA2分析结论

**概念清单**：共12个概念
- SVM核心概念：10个（C系列）
- 采购关联概念：2个（P系列）

**关键概念**：
- 询价单：发起比价的起点
- 报价单：供应商响应的载体
- 比价单：决策分析的载体

**进入DA3的输入**：
- 12个概念需建立关系网络
- 单据间的转换关系需明确定义
- 跨模块关系（与Purchase）需标注
