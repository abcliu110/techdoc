# 十分钟读懂SVM供应商协同

## 一句话理解SVM

**SVM = 采购前的"招标比价系统"，帮助企业找到最优供应商和最优价格。**

```
核心价值：把"领导说了算"变成"数据说了算"
```

---

## 二、SVM是什么

### 2.1 定位

SVM（Supplier Vendor Management）是采购链中**唯一代码化的环节**，负责：
- 向供应商发起询价
- 收集供应商报价
- 对比分析选最优

### 2.2 在采购链中的位置

```
申请 → 询价 → 报价 → 比价 → 订单 → 收料 → 入库 → 应付 → 付款
              ↑        ↑        ↑
              └────────┴────────┘
                   SVM核心区域
```

**重要发现**：采购链"申请→订单→收料→入库"都是**零代码配置**，只有SVM有代码。

---

## 三、三大核心单据

### 3.1 询价单

**做什么**：告诉供应商"我要买什么、买多少、什么时候要"

```
询价单 = 向多个供应商发起采购询问
```

| 关键信息 | 说明 |
|---|---|
| 询价物料 | 要采购的物料清单 |
| 询价数量 | 每个物料要多少 |
| 期望价格 | 预算价格（参考） |
| 截止日期 | 供应商报价截止时间 |
| 邀请供应商 | 至少邀请2个以上 |

### 3.2 报价单

**做什么**：供应商回复"我能供货、价格多少、什么时候能到"

```
报价单 = 供应商的正式供货承诺
```

| 关键信息 | 说明 |
|---|---|
| 供应商报价 | 单价、金额 |
| 有效期 | 价格有效期限 |
| 交货期 | 承诺的交货时间 |
| 附件 | 资质证明、规格说明 |

### 3.3 比价单

**做什么**：对比各供应商报价，找出最优选择

```
比价单 = 多供应商报价的"终极PK"
```

| 对比维度 | 说明 |
|---|---|
| 价格对比 | 谁的价格最低 |
| 交期对比 | 谁交得最快 |
| 综合评分 | 价格×权重 + 交期×权重 |

---

## 四、核心公式

### 4.1 比价公式

```
最优供应商 = MIN(供应商报价)  【价格优先策略】

或者

综合分 = 价格分 × 50% + 交期分 × 30% + 质量分 × 20%
最优供应商 = MAX(综合分)       【综合评分策略】
```

### 4.2 流程公式

```
1个采购申请
    ↓
1个询价单（向N个供应商发）
    ↓
N个报价单（供应商回复）
    ↓
1个比价单（汇总对比）
    ↓
1个采购订单（最优供应商）
```

## 五、典型场景

### 场景1：标准采购
```
采购员发起询价 → 3个供应商报价 → 比价选最优 → 生成订单
```

### 场景2：紧急采购
```
跳过SVM → 直接下单 → 询价比价以后补
```

---

## 六、关键规则

| 规则 | 内容 |
|---|---|
| 至少邀请2个供应商 | 保证比价有效性 |
| 报价必须在截止前 | 超时拒绝 |
| 比价后不能修改 | 保证公正性 |
| 转单采用最优报价 | 确保价格锁定 |

---

## 七、SVM的价值

| 价值 | 说明 |
|---|---|
| 透明公正 | 多方比价，阳光采购 |
| 成本优化 | 竞争机制，降低采购成本 |
| 决策支持 | 数据支撑，科学决策 |
| 历史追溯 | 记录可查，审计有据 |

## 九、记住这3点

1. **SVM是唯一有代码的采购环节** - 采购链的核心智能
2. **三单流程：询价→报价→比价** - 简单但关键
3. **比价选最优** - 让数据说话，而不是人说了算
