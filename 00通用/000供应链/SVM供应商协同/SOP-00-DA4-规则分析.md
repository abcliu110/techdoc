## 一、业务规则（BR-SVM系列）

### 1.1 询价规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-SVM-101 | 询价来源 | 询价单必须来源于采购申请或手动创建 | 强 |
| BR-SVM-102 | 供应商数量 | 单次询价至少邀请2个以上供应商 | 强 |
| BR-SVM-103 | 截止日期 | 询价截止日期必须晚于询价发送日期 | 强 |
| BR-SVM-104 | 物料明细 | 询价明细至少包含1行物料 | 强 |

### 1.2 报价规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-SVM-201 | 报价时间 | 报价必须在询价截止日期前提交 | 强 |
| BR-SVM-202 | 报价完整 | 报价必须包含所有询价物料的报价 | 强 |
| BR-SVM-203 | 报价有效期 | 报价有效期必须覆盖预期交货期 | 强 |
| BR-SVM-204 | 最低报价 | 报价金额不能低于成本价（需配置） | 弱 |

### 1.3 比价规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-SVM-301 | 比价时机 | 比价必须在有至少2个有效报价时执行 | 强 |
| BR-SVM-302 | 价格优先 | 默认选择最低价供应商（可配置评分规则） | 强 |
| BR-SVM-303 | 综合评分 | 支持按价格、质量、交期多维度评分 | 弱 |
| BR-SVM-304 | 比价锁定 | 比价完成后比价单不能修改 | 强 |

### 1.4 订单生成规则

| 规则ID | 规则名称 | 规则内容 | 约束级别 |
|---|---|---|---|
| BR-SVM-401 | 转单来源 | 订单必须关联比价单 | 强 |
| BR-SVM-402 | 价格锁定 | 订单价格采用比价最优报价 | 强 |
| BR-SVM-403 | 数量限制 | 订单数量不能超过询价数量 | 强 |
| BR-SVM-404 | 供应商锁定 | 订单供应商采用比价选择的最优供应商 | 强 |

## 二、状态机分析

### 2.1 询价单状态机

```
                    ┌─────────────────┐
                    │   创建(Draft)   │
                    └────────┬────────┘
                             │ 发送
                             ▼
                    ┌─────────────────┐
          ┌────────▶│  已发送(Sent)   │
          │         └────────┬────────┘
          │                  │
          │          ┌───────┴───────┐
          │          │               │
          │          ▼               ▼
          │   ┌───────────┐  ┌───────────┐
    撤回  │   │ 已报价    │  │  已关闭   │
          │   │(Received) │  │ (Closed)  │
          │   └───────────┘  └───────────┘
          │          │               │
          │          │        比价完成│
          │          ▼               ▼
          │   ┌───────────┐  ┌───────────┐
          │   │ 已转单    │  │  已结束   │
          │   │(Converted)│  │ (Finished)│
          │   └───────────┘  └───────────┘
          │
          │    取消(Cancel)
          └──────────────────────▶ [结束]
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 创建(Draft) | 询价单录入未发送 | 编辑、发送、删除 |
| 已发送(Sent) | 询价已发送给供应商 | 撤回、关闭 |
| 已报价(Received) | 有供应商已报价 | 执行比价 |
| 已转单(Converted) | 已生成采购订单 | - |
| 已关闭(Closed) | 询价关闭未成交 | 归档 |
| 已结束(Finished) | 流程正常结束 | 归档 |

### 2.2 报价单状态机

```
┌────────────┐   提交报价    ┌────────────┐   接受      ┌────────────┐
│   无报价   │─────────────▶│  已报价    │────────────▶│  已接受    │
└────────────┘              └─────┬──────┘              └─────┬──────┘
                                  │                           │
                                  │ 拒绝                      │ 转单完成
                                  ▼                           ▼
                            ┌───────────┐              ┌───────────┐
                            │  已拒绝   │              │  已转单   │
                            └───────────┘              └───────────┘
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 无报价 | 供应商未提交报价 | - |
| 已报价 | 报价已提交待审核 | 接受、拒绝 |
| 已接受 | 报价被采购员接受 | 转单 |
| 已拒绝 | 报价不符合要求 | - |
| 已转单 | 已生成采购订单 | - |

### 2.3 比价单状态机

```
┌────────────┐   创建        ┌────────────┐   完成      ┌────────────┐
│   创建     │─────────────▶│  比价中    │────────────▶│  已完成    │
└────────────┘              └─────┬──────┘              └─────┬──────┘
                                  │                           │
                                  │ 作废                      │ 转单
                                  ▼                           ▼
                            ┌───────────┐              ┌───────────┐
                            │  已作废   │              │  已转单   │
                            └───────────┘              └───────────┘
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 创建 | 比价单刚创建 | 编辑、删除 |
| 比价中 | 正在执行比价分析 | 完成比价 |
| 已完成 | 比价完成待决策 | 生成订单 |
| 已转单 | 已生成采购订单 | - |
| 已作废 | 比价单被作废 | - |

## 三、决策分析

| DEC编号 | 决策点 | 选项 | 选择 |
|---|---|---|---|
| DEC-SVM-01 | 比价策略 | A=价格优先，B=综合评分 | A+B（可配置） |
