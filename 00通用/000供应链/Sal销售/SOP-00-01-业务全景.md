### 1.2 核心价值

| 价值维度 | 具体说明 | 业务指标 |
|---|---|---|
| 销售闭环 | 报价→订单→出库→收款全链路管理 | 订单履行率>95% |
| 库存保障 | 订单审核锁定库存，保证可交付 | 锁定准确率>99% |
| 信用控制 | 客户信用额度实时管控 | 坏账率<0.5% |
| 财务协同 | 出库自动生成应收和凭证 | 应收准确率100% |
| 追溯能力 | 全链路销售追溯，满足合规要求 | 追溯覆盖率100% |

## 三、业务边界

### 3.1 边界定义

| 边界类型 | 边界内容 |
|---|---|
| 上游边界 | 商机（OP）、客户档案、价格策略 |
| 下游边界 | 库存（Stock）、应收（AR）、GL凭证 |
| 平行边界 | 采购（Purchase）、生产（MO）、质量（QC） |
| 外部边界 | 客户（收入来源）、物流商（配送） |

## 四、关键角色

| 角色 | 主要操作 | 关注报表 | 权限级别 |
|---|---|---|---|
| 销售员 | 报价/订单/发货 | 销售订单明细、订单执行进度 | 日常操作 |
| 销售主管 | 审核/价格审批 | 销售汇总、毛利分析 | 审批控制 |
| 仓库管理员 | 出库执行 | 销售出库汇总 | 执行层 |
| 财务会计 | 应收/收款 | 应收汇总、收款核销 | 财务复核 |
| 信用专员 | 信用控制 | 客户信用分析 | 信用控制 |
| 客户(B端) | 自助下单 | 订单状态查询 | 只读 |

## 五、与周边模块的协作

| 周边模块 | 协作方向 | 协作内容 |
|---|---|---|
| OP商机 | 单向← | 商机转化报价/订单 |
| Stock库存 | 双向 | 库存锁定、扣减出库 |
| AR应收 | 单向→ | 出库生成应收单 |
| GL总账 | 单向→ | 出库生成收入+成本凭证 |
| AP应付 | - | 无直接关联 |
| MO生产 | 单向→ | 生产领料触发销售出库 |
| QC质量 | 单向→ | 检验结果影响出库 |
| CM资金 | 单向→ | 收款影响资金余额 |

## 六、启用前提

| 前置条件 | 说明 |
|---|---|
| 基础资料 | 客户、物料、计量单位、仓库已完成配置 |
| 价格策略 | 价目表、价格政策已配置 |
| 信用管理 | 客户信用等级、信用额度已配置 |
| 付款条件 | 账期类型、付款条件已配置 |
| GL协同 | GL模块已启用，科目映射已配置 |
| 库存协同 | Stock模块已启用，库存策略已配置 |
