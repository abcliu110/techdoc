## 二、状态机分析

### 2.1 销售订单状态机

```
                    ┌─────────────────┐
                    │   创建(Draft)   │
                    └────────┬────────┘
                             │ 提交/审核
                             ▼
                    ┌─────────────────┐
          ┌────────▶│   已审核(Audit) │
          │         └────────┬────────┘
          │                  │
          │          ┌───────┴───────┐
          │          │               │
          │          ▼               ▼
          │   ┌───────────┐  ┌───────────┐
          │   │ 执行中    │  │  已关闭   │
          │   │(Partially)│  │ (Close)   │
          │   └───────────┘  └───────────┘
          │          │
          │          │ 全额出库/手动关闭
          │          ▼
          │   ┌───────────┐
          │   │  已完成   │
    反审核│   │ (Finished)│
          │   └───────────┘
          │
          │    取消(Cancel)
          └──────────────────────▶ [结束]
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 创建(Draft) | 订单录入未审核 | 提交、删除 |
| 已审核(Audit) | 订单审核通过 | 反审核、变更、关闭 |
| 执行中(Partially) | 部分出库 | 继续出库、关闭 |
| 已关闭(Close) | 订单完成/终止 | - |
| 已完成(Finished) | 全额执行完毕 | 反审核 |

### 2.2 库存锁定状态机

```
┌────────────┐   订单审核    ┌────────────┐
│   无锁定   │─────────────▶│   占用中   │
└────────────┘              └─────┬──────┘
       ▲                           │
       │                     ┌─────┴─────┐
       │                     │           │
  订单关闭/                 ▼           ▼
  出库完成/           ┌──────────┐ ┌──────────┐
  手动释放            │  部分占用 │ │  全部释放 │
                     └──────────┘ └──────────┘
```

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 无锁定 | 未创建锁定 | - |
| 占用中 | 锁定生效 | 部分释放、全额释放 |
| 部分占用 | 部分数量已出库 | 继续释放 |
| 全部释放 | 锁定数量全部释放 | - |

## 三、异常场景

### 3.1 订单变更异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 增行 | 订单审核后新增物料 | 反审核→增行→重新审核 |
| 减行 | 订单审核后删除物料 | 反审核→删行→重新审核 |
| 调价 | 订单审核后修改单价 | 需审批，记录调价历史 |
| 减量 | 订单审核后减少数量 | 反审核→修改→重新审核（锁定同步减少） |

### 3.2 库存异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 锁定不足 | 订单数量超过可用量 | 提示"库存不足"，分批执行 |
| 批次过期 | 批次物料已过期 | 禁止出库，需先处理批次 |
| 序列号无效 | 序列号已被占用/不存在 | 提示重新录入有效序列号 |

### 3.3 信用异常

| 场景 | 描述 | 处理方式 |
|---|---|---|
| 额度超限 | 订单金额超过可用信用 | 提示超信用额度，需审批或预收款 |
| 账期逾期 | 客户存在超期应收 | 禁止新单，优先催收 |
