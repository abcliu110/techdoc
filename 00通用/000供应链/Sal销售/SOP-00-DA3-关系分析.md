## 三、关系详细契约

### 3.1 REL-01：报价→订单

```
契约名称：报价转订单
前置条件：报价已审核、未过期
后置条件：订单创建、报价状态变为"已转单"
数据映射：
  - 客户 → 客户
  - 物料明细 → 物料明细
  - 单价 → 单价（可调整）
  - 折扣 → 折扣（可调整）
  - 交期 → 交期
约束：
  - 转单后报价不能修改
  - 订单金额可大于报价（调价需审批）
```

### 3.2 REL-05：订单→锁定

```
契约名称：订单审核创建库存锁定
前置条件：订单已审核、物料启用库存管理
后置条件：库存锁定记录创建、可用量减少
数据映射：
  - 订单号 → FSBILLNO
  - 物料编码 → FMATERIALID
  - 数量 → FQTY
  - 仓库 → FSTOCKID
约束：
  - 锁定量不能超过可用量
  - 锁定带有效期（FRESERVEDATE）
```

### 3.3 REL-08：出库→应收

```
契约名称：出库生成应收单
前置条件：出库已审核
后置条件：应收单创建、信用占用增加
数据映射：
  - 客户 → FCUSTOMERID
  - 出库金额 → FALLAMOUNT
  - 币种 → F CurrencyID
  - 到期日 → FREDATE（按账期计算）
约束：
  - 应收金额基于出库含税金额
  - 信用额度超限需审批
```

## 四、路径分析

### 4.1 核心业务路径

```
路径P-01：标准销售完整链路
商机 → 报价 → 订单 → 锁定 → 出库 → 应收 → 收款

路径长度：7步
涉及BO：商机、报价、订单、锁定、出库、应收、收款
退出点：任意步骤可退出（放弃商机/报价失效/订单关闭/出库取消）

路径P-02：两步出库链路
订单 → 发货通知 → 出库（跳过P-01中的直接出库）

路径P-03：退货链路
出库 → 退货 → 应收红冲 → 退款

路径P-04：跨组织销售链路
订单 → 锁定 → 出库(组织A) → 入库(组织B) → 内部交易
```

## 五、DA3分析结论

**关系清单**：12个关系
- 操作关系：4个
- 结构关系：3个
- 轨迹关系：5个

**核心路径**：4条
- P-01：标准销售完整链路（7步）
- P-02：两步出库链路
- P-03：退货链路
- P-04：跨组织销售链路

**进入DA4的输入**：
- 3个关键契约需定义业务规则
- 路径P-01/P-03为主路径
- REL-05（订单→锁定）和REL-08（出库→应收）为关键轨迹
