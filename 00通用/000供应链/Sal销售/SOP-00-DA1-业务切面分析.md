## 一、角色切面

### 1.1 核心角色

| 角色 | 职责 | 主要操作 | 关注对象 |
|---|---|---|---|
| 销售员 | 报价/订单/发货 | 报价、录单、发货确认 | 报价单、订单、出库单 |
| 销售主管 | 审核/价格审批 | 审核、折扣审批 | 所有销售单据 |
| 仓库管理员 | 出库执行 | 拣货、发货 | 销售出库单 |
| 财务会计 | 应收/收款 | 应收确认、收款核销 | 应收单、收款单 |
| 信用专员 | 信用控制 | 信用检查、额度调整 | 客户信用 |
| 客户 | 自助下单(B2B) | 下单、查询、退货申请 | 订单、退货单 |

## 二、业务分类切面

### 2.1 业务分类矩阵

| 分类维度 | 类型 | 核心特征 |
|---|---|---|
| 业务模式 | 标准销售 | 报价→订单→出库 |
| 业务模式 | 退货销售 | 出库→退货→退款 |
| 业务模式 | 跨组织销售 | 多组织间调拨销售 |
| 交付方式 | 一步出库 | 订单直接下推出库 |
| 交付方式 | 两步出库 | 发货通知→销售出库 |
| 结算方式 | 先款后货 | 预收款→发货 |
| 结算方式 | 先货后款 | 发货→应收→收款 |
| 结算方式 | 分期收款 | 按账期分批收款 |

### 2.2 业务分类详情

#### 标准销售流程
```
商机 → 报价 → 报价审核 → 销售订单 → 订单审核 → 库存锁定
    → 发货通知 → 发货审核 → 销售出库 → 应收单 → 收款核销
```

#### 退货销售流程
```
销售出库 → 退货申请 → 退货审核 → 销售退货 → 应收红冲 → 退款处理
```

## 四、切面分析结论

### 4.1 核心业务对象识别

| BO | 业务对象 | 生命周期 | 关联用例 |
|---|---|---|---|
| BO-01 | 销售报价 | 创建→审核→转订单/失效 | UC-01 |
| BO-02 | 销售订单 | 创建→审核→执行→关闭 | UC-02, UC-12 |
| BO-03 | 发货通知 | 创建→审核→下推出库 | UC-08 |
| BO-04 | 销售出库 | 创建→审核→过账 | UC-04 |
| BO-05 | 销售退货 | 创建→审核→过账 | UC-07 |
| BO-06 | 应收单 | 创建→核销/红冲 | UC-05 |
| BO-07 | 库存锁定 | 创建→占用→释放 | UC-03 |
| BO-08 | 客户信用 | 占用→释放→恢复 | UC-09 |

### 4.2 业务边界

- **上游**：商机（OP）、客户档案、价格策略
- **下游**：库存（Stock）、应收（AR）、GL凭证
- **平行**：采购（Purchase）、生产（MO）

1. 销售员/销售主管/财务/仓库形成完整角色链

3. 退货、变更、跨组织为扩展场景
