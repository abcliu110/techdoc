# 十分钟读懂Sal销售

## 一句话定位

**Sal销售** = 报价→订单→锁定→出库→应收→收款 的完整链路管理，是SCM中代码化最完整的子域。

---

## 五分钟速读

### 1. 销售模块做什么？

| 核心功能 | 说明 |
|---|---|
| 报价管理 | 向客户提供产品报价方案 |
| 订单管理 | 签订销售合同/订单 |
| 库存锁定 | 订单审核时锁定库存保证可交付 |
| 发货执行 | 按订单发货出库 |
| 应收管理 | 出库生成应收单 |
| 收款核销 | 收款后核销应收 |

### 2. 核心链路是什么？

```
商机 → 报价 → 订单 → 锁定 → 出库 → 应收 → 收款
   7步完成一笔销售业务
```

### 3. 关键数字

| 指标 | 数值 |
|---|---|
| 代码文件数 | 472 |
| 代码行数 | 114,436 |
| 转换插件数 | 21个 |
| 子域排名 | 第二大（仅次于Stock） |

---

## 七分钟理解

### 4. 四个关键决策点

| 决策点 | 选择 | 含义 |
|---|---|---|
| 锁定时机 | A=审核时 | 订单审核后才锁定库存 |
| 应收生成 | A=出库审核时 | 出库审核后才生成应收 |
| 价格来源 | A=价目表优先 | 先查价目表，再查历史价，最后标准价 |
| 信用检查 | A+B=订单+出库 | 订单审核检查额度，出库审核占用额度 |

### 5. 三张核心表

| 表名 | 作用 |
|---|---|
| T_SAL_ORDER | 销售订单表头 |
| T_SAL_ORDERENTRY | 订单分录（物料明细） |
| T_PLN_RESERVELINKENTRY | 库存锁定明细 |

### 6. 三个风险

| 风险 | 等级 | 说明 |
|---|---|---|
| 巨型类 | 高 | SaleOrderEdit 5,095行 |
| 双份插件 | 中 | App/ServicePlugIn各一份 |
| 僵尸锁定 | 中 | 订单关闭后锁定未释放 |

## 十分钟深入

### 7. 与其他模块的关系

| 模块 | 关系 |
|---|---|
| Stock库存 | 出库扣减库存、锁定控制可用量 |
| AR应收 | 出库生成应收单 |
| GL总账 | 出库生成收入+成本凭证 |
| OP商机 | 商机转化报价/订单 |
| QC质量 | 检验结果影响出库 |

### 8. 核心代码位置

```

```
