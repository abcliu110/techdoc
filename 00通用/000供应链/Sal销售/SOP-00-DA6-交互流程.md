## 一、服务架构

### 1.1 核心服务

| 服务名 | 命名空间 | 职责 |
|---|---|---|
| SaleService | Core/.../App.BusinessService | 销售核心服务 |
| SaleOrderService | BusinessPlugIn | 订单管理服务 |
| SaleOutStockService | ServicePlugIn | 出库服务 |
| SaleReturnService | ServicePlugIn | 退货服务 |
| DeliveryNoticeService | ServicePlugIn | 发货通知服务 |
| SaleQuotationService | ServicePlugIn | 报价服务 |

### 1.2 服务交互关系

```
┌────────────────────────────────────────────────────────────────┐
```

## 二、核心API

### 2.1 报价服务API

| API | 方法 | 说明 |
|---|---|---|
| ISaleQuotationService.Save | 保存报价 | 保存报价单 |
| ISaleQuotationService.Audit | 审核报价 | 审核通过 |
| ISaleQuotationService.UnAudit | 反审核报价 | 撤销审核 |
| ISaleQuotationService.ConvertToOrder | 转订单 | 报价转销售订单 |

### 2.2 订单服务API

| API | 方法 | 说明 |
|---|---|---|
| ISaleOrderService.Save | 保存订单 | 保存订单 |
| ISaleOrderService.Audit | 审核订单 | 审核+锁定+信用检查 |
| ISaleOrderService.UnAudit | 反审核订单 | 撤销+释放锁定 |
| ISaleOrderService.Close | 关闭订单 | 关闭+全释放锁定 |
| ISaleOrderService.Modify | 修改订单 | 反审核+修改+重审 |

### 2.3 出库服务API

| API | 方法 | 说明 |
|---|---|---|
| ISaleOutStockService.Save | 保存出库单 | 保存 |
| ISaleOutStockService.Audit | 审核出库 | 审核+扣减库存+生成应收 |
| ISaleOutStockService.UnAudit | 反审核出库 | 撤销+恢复库存+红冲应收 |
| ISaleOutStockService.Cancel | 取消出库 | 取消单据 |

### 2.4 退货服务API

| API | 方法 | 说明 |
|---|---|---|
| ISaleReturnService.Save | 保存退货单 | 保存 |
| ISaleReturnService.Audit | 审核退货 | 审核+退货入库+应收红冲 |
| ISaleReturnService.UnAudit | 反审核退货 | 撤销+退货出库 |

## 四、转换插件流程

## 五、DA6分析结论

**核心服务**：6个
- SaleService（调度）
- SaleOrderService（订单）
- SaleOutStockService（出库）
- SaleReturnService（退货）
- DeliveryNoticeService（发货）
- SaleQuotationService（报价）

**核心API**：18个
- 报价API：4个
- 订单API：5个
- 出库API：4个
- 退货API：4个

**关键时序**：
- 订单审核→锁定→信用
- 出库审核→扣库存→应收
- 退货审核→退货入库→红冲

**进入DA7的输入**：
- 需映射报表和服务到实现
- 需识别决策点实现
