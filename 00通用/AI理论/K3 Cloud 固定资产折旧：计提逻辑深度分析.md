## 一、折旧计提的本质

### 1.1 什么是折旧

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    折旧：固定资产价值转移的会计表达                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【物理事实】                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  固定资产在生产过程中逐渐磨损                                     │      │
│  │  → 价值逐渐减少                                                 │      │
│  │  → 但这价值减少无法精确计量                                     │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【会计处理】                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  折旧 = 人为设定的价值转移规则                                   │      │
│  │                                                                 │      │
│  │  不是物理测量，而是会计假设                                       │      │
│  │  目的是将资产成本系统地分摊到受益期间                           │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 折旧与期间的关系

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    折旧是期间的函数                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【关键问题】一张卡片，每月折旧多少？                                    │
│                                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  折旧额 = f(原值, 预计使用期间, 折旧方法)                        │      │
│  │                                                                 │      │
│  │       = f(卡片数据, 当前期间)                                      │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【每月的计算逻辑】                                                    │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  1. 读取卡片数据                                                │      │
│  │     • 原值、已提折旧期间、剩余使用期间                          │      │
│  │     • 当前期间、折旧方法                                         │      │
│  │                                                                 │      │
│  │  2. 计算当月折旧额                                              │      │
│  │     • 根据折旧方法计算                                          │      │
│  │                                                                 │      │
│  │  3. 更新卡片数据                                                │      │
│  │     • 累计折旧 += 当月折旧额                                     │      │
│  │     • 已提折旧期间 += 1                                         │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、折旧卡片的数据结构

### 2.1 卡片核心字段

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    FA折旧卡片：折旧计算的输入数据                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【原值相关】                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ FOriginalValue     │ 原值       │ 资产入账价值                 │      │
│  │ FDepreciationTotal │ 累计折旧   │ 已计提的折旧总额             │      │
│  │ FNetValue         │ 净值       │ 原值 - 累计折旧              │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【期间相关】                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ FDepreciationStart │ 开始日期   │ 开始计提折旧的日期         │      │
│  │ FDepreciationEnd   │ 结束日期   │ 折旧计提完毕的日期         │      │
│  │ FUsefulLife       │ 使用寿命   │ 总共计提多少个月           │      │
│  │ FPeriodsDepreced  │ 已提期间数 │ 已经计提了多少个月        │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【折旧方法相关】                                                      │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ FDepreciationMethod │ 折旧方法   │ 直线法/双倍余额递减等     │      │
│  │ FSalvageRate      │ 残值率    │ 预计残值/原值           │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 卡片状态与折旧

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    卡片状态决定是否折旧                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ 状态          │ 是否折旧    │ 条件                                │      │
│  ├───────────────┼────────────┼─────────────────────────────────────┤      │
│  │ 在用          │ ✓ 折旧     │ 开始日期 <= 当前日期              │      │

│  │ 折旧完成      │ ✗ 不折旧   │ 已提期间数 >= 使用寿命         │      │
│  │ 清理          │ ✗ 不折旧   │ 已处置，不再属于企业资产       │      │
│  │ 融资租入      │ ✓ 折旧     │ 同在用                           │      │
│  └───────────────┴────────────┴─────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 三、折旧计算逻辑

### 3.1 直线法计算

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    直线法：每月相同金额                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  月折旧额 = (原值 - 预计净残值) / 预计使用月数                    │      │
│  │                                                                 │      │
│  │  其中：净残值 = 原值 × 残值率                                      │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【计算示例】                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  卡片数据：                                                        │      │
│  │  • 原值：120,000 元                                               │      │
│  │  • 残值率：5%                                                    │      │
│  │  • 使用寿命：60 个月                                              │      │
│  │                                                                 │      │
│  │  计算过程：                                                        │      │
│  │  • 净残值 = 120,000 × 5% = 6,000 元                           │      │
│  │  • 应折旧总额 = 120,000 - 6,000 = 114,000 元                  │      │
│  │  • 月折旧额 = 114,000 / 60 = 1,900 元/月                     │      │
│  │                                                                 │      │
│  │  每月相同：1,900 元/月                                           │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【K3 Cloud计算逻辑】                                                  │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  1. 获取卡片原值 FOriginalValue                                  │      │
│  │  2. 计算净残值 = FOriginalValue × FSalvageRate                 │      │
│  │  3. 计算应折旧总额 = FOriginalValue - 净残值                    │      │
│  │  4. 计算剩余月数 = FUsefulLife - FPeriodsDepreced              │      │
│  │  5. 月折旧额 = 应折旧总额 / 剩余月数                            │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 双倍余额递减法计算

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    双倍余额递减法：前期多提，后期少提                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  年折旧率 = 2 / 预计使用年限 × 100%                            │      │
│  │  月折旧额 = 账面净值 × 年折旧率 / 12                             │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【计算示例】                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  卡片数据：                                                        │      │
│  │  • 原值：100,000 元                                              │      │
│  │  • 使用年限：5 年（60 个月）                                      │      │
│  │  • 年折旧率：2/5 × 100% = 40%                                 │      │
│  │                                                                 │      │
│  │  ┌─────────────────────────────────────────────────────────┐   │      │
│  │  │ 年度 │ 年初净值 │ 年折旧额 │ 年末净值 │ 月折旧额  │   │      │
│  │  ├─────────┼──────────┼───────────┼──────────┼──────────┤   │      │
│  │  │ 第1年 │ 100,000  │  40,000  │  60,000  │  3,333   │   │      │
│  │  │ 第2年 │  60,000  │  24,000  │  36,000  │  2,000   │   │      │
│  │  │ 第3年 │  36,000  │  14,400  │  21,600  │  1,200   │   │      │
│  │  │ 第4年 │  21,600  │   7,584  │  14,016  │    632   │   │      │
│  │  │ 第5年 │  14,016  │   5,606  │   8,410  │    467   │   │      │
│  │  └─────────────────────────────────────────────────────────┘   │      │
│  │                                                                 │      │
│  │  ⚠️ 最后两年改为直线法，避免净值小于残值                          │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【K3 Cloud计算逻辑】                                                  │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  1. 计算年折旧率 = 2 / 使用年限                                │      │
│  │  2. 计算当前账面净值 = FOriginalValue - FDepreciationTotal      │      │
│  │  3. 计算年折旧额 = 账面净值 × 年折旧率                         │      │
│  │  4. 计算月折旧额 = 年折旧额 / 12                               │      │
│  │  5. 最后两年判断：                                               │      │
│  │     • 如果剩余期间 <= 2年，改为直线法                          │      │
│  │     • 月折旧额 = 账面净值 / 剩余月数                          │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 年数总和法计算

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    年数总和法：加速折旧另一种形式                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  年折旧率 = (预计使用年限 - 已使用年限) / (使用年限 × 年数总和)  │      │
│  │  月折旧额 = (原值 - 净残值) × 年折旧率 / 12                      │      │
│  │                                                                 │      │
│  │  其中：年数总和 = n×(n+1)/2，n为使用年限                        │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【计算示例（5年）】                                                  │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  年数总和 = 5×6/2 = 15                                        │      │
│  │                                                                 │      │
│  │  ┌─────────────────────────────────────────────────────────┐   │      │
│  │  │ 年度 │ 折旧率  │ 年折旧额  │ 累计折旧  │ 账面净值  │   │      │
│  │  ├─────────┼─────────┼───────────┼───────────┼────────────┤   │      │
│  │  │ 第1年 │ 5/15    │ 38,000   │  38,000  │  62,000   │   │      │
│  │  │ 第2年 │ 4/15    │ 30,400   │  68,400  │  31,600   │   │      │
│  │  │ 第3年 │ 3/15    │ 22,800   │  91,200  │   8,800   │   │      │
│  │  │ 第4年 │ 2/15    │ 15,200   │ 106,400  │   3,600   │   │      │
│  │  │ 第5年 │ 1/15    │  7,600   │ 114,000  │   6,000   │   │      │
│  │  └─────────────────────────────────────────────────────────┘   │      │
│  │                                                                 │      │
│  │  （假设原值100,000，净残值6,000，应折旧94,000）                  │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 四、折旧计提流程

### 4.1 整体流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    折旧计提：从执行到凭证的完整流程                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【阶段一：数据准备】                                                   │
│                                                                              │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 1. 读取所有固定资产卡片                                          │  │
│    │    SELECT * FROM FA_Card WHERE FUseState = 1                    │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 2. 筛选当期应折旧卡片                                           │  │
│    │    • 状态 = 在用                                              │  │
│    │    • 开始日期 <= 当前日期                                      │  │
│    │    • 已提期间数 < 使用寿命                                    │  │
│    │    • 当期未计提                                                │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼                                          │
│  【阶段二：折旧计算】                                                   │
│                                                                              │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 3. 对每张卡片计算月折旧额                                       │  │
│    │                                                                 │  │
│    │    SWITCH FDepreciationMethod                                   │  │
│    │      CASE 直线法:                                               │  │
│    │        月折旧额 = (原值-净残值) / 剩余月数                      │  │
│    │      CASE 双倍余额递减法:                                        │  │
│    │        月折旧额 = 账面净值 × 2/使用年限 / 12                   │  │
│    │      CASE 工作量法:                                             │  │
│    │        月折旧额 = 单位工作量折旧额 × 当月工作量                  │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 4. 汇总折旧清单                                                │  │
│    │    • 按部门汇总                                                  │  │
│    │    • 按费用科目汇总                                              │  │
│    │    • 生成折旧汇总表                                              │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼                                          │
│  【阶段三：凭证生成】                                                   │
│                                                                              │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 5. 财务人员审核折旧清单                                         │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼ 审核时触发                               │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 6. 生成GL凭证                                                  │  │
│    │                                                                 │  │
│    │    借：管理费用-折旧费      X,XXX                              │  │
│    │        制造费用-折旧费      X,XXX                              │  │
│    │        销售费用-折旧费      X,XXX                              │  │
│    │    贷：累计折旧            XX,XXX                               │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                              │                                          │
│                              ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────┐  │
│    │ 7. 更新卡片数据                                                │  │
│    │    • FDepreciationTotal += 当月折旧额                           │  │
│    │    • FPeriodsDepreced += 1                                     │  │
│    │    • 记录折旧日志                                              │  │
│    └─────────────────────────────────────────────────────────────────┘  │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 折旧清单数据结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    折旧清单：折旧计算的输出数据                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【单张卡片折旧记录】                                                  │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ FAssetID          │ 资产ID                                        │      │
│  │ FAssetNumber     │ 资产编号                                      │      │
│  │ FAssetName       │ 资产名称                                      │      │
│  │ FDeptID         │ 使用部门ID                                     │      │
│  │ FOriginalValue   │ 原值：120,000                                  │      │
│  │ FDepreciationTotal│ 已提折旧：57,000                               │      │
│  │ FNetValue       │ 净值：63,000                                   │      │
│  │ FPeriodsDepreced│ 已提期间：30个月                               │      │
│  │ FUsefulLife     │ 使用寿命：60个月                               │      │
│  │ FDepreciationMethod│ 折旧方法：直线法                               │      │
│  │ FMonthDepreciation│ 当月折旧：1,900                               │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【折旧汇总（按部门）】                                               │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ 部门        │ 费用科目              │ 当月折旧    │ 累计折旧    │      │
│  ├─────────────┼──────────────────────┼─────────────┼─────────────┤      │
```

### 5.2 期间暂停折旧

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    场景：资产停用期间不折旧                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【问题】某资产5-7月停用，这期间是否折旧？                              │
│                                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  停用期间不折旧，恢复使用后继续计提                               │      │
│  │  ────────────────────────────────                                    │      │
│  │                                                                 │      │
│  │  时间线：                                                          │      │
│  │  1月 ─── 4月 ─── 5月 ─── 8月 ─── 12月                          │      │
│  │  在用    在用    停用    停用    在用                              │      │
│  │          折旧    ════    ════    折旧                            │      │
│  │                                                                 │      │
│  │  累计折旧期间：1+2+3+4 + 8+9+10+11+12 = 11个月               │      │
│  │  ⚠️ 停用的3个月不计入已提期间数                                    │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【K3 Cloud处理逻辑】                                                  │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  1. 停用时记录停用期间                                           │      │
│  │     FUseState = 2（停用）                                        │      │
│  │     FStopDate = 5月1日                                          │      │
│  │                                                                 │      │
│  │  2. 恢复使用时记录恢复日期                                       │      │
│  │     FUseState = 1（在用）                                        │      │
│  │     FResumeDate = 8月1日                                         │      │
│  │                                                                 │      │
│  │  3. 折旧计算时排除停用期间                                       │      │
│  │     剩余月数 = FUsefulLife - 有效已提期间数                       │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
```
