**固定资产模块（FA）的核心职责**：
- 固定资产卡片管理
- 折旧计提与计算
- 资产变动（增减值、报废、拆分、合并）
- 凭证生成

## 三、折旧计算方法

### 3.1 直线法（年限平均法）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    直线法：最常用的折旧方法                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【计算公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  月折旧额 = (原值 - 预计净残值) / 预计使用月数                   │      │
│  │                                                                 │      │
│  │  其中：                                                           │      │
│  │  • 预计净残值 = 原值 × 残值率                                    │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【示例】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  资产原值：100,000 元                                           │      │
│  │  残值率：5%                                                     │      │
│  │  使用年限：10 年（120 个月）                                    │      │
│  │                                                                 │      │
│  │  预计净残值 = 100,000 × 5% = 5,000 元                         │      │
│  │  月折旧额 = (100,000 - 5,000) / 120 = 791.67 元              │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【特点】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ • 每年折旧额相等                                                │      │
│  │ • 计算简单，易于理解                                            │      │
│  │ • 适用于使用情况稳定的资产                                      │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 工作量法

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    工作量法：按实际使用量计提折旧                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【计算公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  单位工作量折旧额 = (原值 - 预计净残值) / 预计总工作量             │      │
│  │                                                                 │      │
│  │  月折旧额 = 单位工作量折旧额 × 当月实际工作量                     │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【示例】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  资产原值：500,000 元                                           │      │
│  │  残值率：5%                                                     │      │
│  │  预计总工作量：500,000 公里                                     │      │
│  │                                                                 │      │
│  │  预计净残值 = 500,000 × 5% = 25,000 元                         │      │
│  │  单位工作量折旧额 = (500,000 - 25,000) / 500,000               │      │
│  │                    = 0.95 元/公里                               │      │
│  │                                                                 │      │
│  │  本月行驶 3,000 公里：                                           │      │
│  │  月折旧额 = 0.95 × 3,000 = 2,850 元                           │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【特点】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ • 折旧与使用量成正比                                            │      │
│  │ • 适用于使用量不均的资产（如车辆、机器）                       │      │
│  │ • 需要记录实际工作量                                            │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 双倍余额递减法

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    双倍余额递减法：加速折旧法之一                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【计算公式】                                                              │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  年折旧率 = 2 / 预计使用年限 × 100%                             │      │
│  │  月折旧额 = 年初账面净值 × 年折旧率 / 12                        │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【示例】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │                                                                 │      │
│  │  资产原值：100,000 元                                           │      │
│  │  使用年限：5 年                                                 │      │
│  │  年折旧率 = 2 / 5 × 100% = 40%                               │      │
│  │                                                                 │      │
│  │  第1年折旧：100,000 × 40% = 40,000 元                         │      │
│  │  第2年折旧：(100,000-40,000) × 40% = 24,000 元               │      │
│  │  第3年折旧：(60,000-24,000) × 40% = 14,400 元               │      │
│  │  第4年折旧：(36,000-14,400) × 40% = 8,640 元                 │      │
│  │  第5年折旧：(21,600-8,640) × 40% = 5,184 元                  │      │
│  │                                                                 │      │
│  │  ⚠️ 最后两年改为直线法，保证残值                                  │      │
│  │                                                                 │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【特点】                                                                │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ • 前期折旧多，后期折旧少                                        │      │
│  │ • 符合资产实际使用价值损耗规律                                  │      │
│  │ • 技术更新快的资产适用                                          │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 8.1 折旧凭证生成

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    场景：月末计提折旧                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【前置条件】                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ 1. 资产卡片状态为"在用"                                         │      │
│  │ 2. 资产已开始折旧（折旧开始日期 <= 当前日期）                  │      │
│  │ 3. 资产未提足折旧（累计折旧 < 原值-净残值）                  │      │
│  │ 4. 当前期间未计提过折旧                                        │      │
│  └─────────────────────────────────────────────────────────────────┘      │
│                                                                              │
│  【执行步骤】                                                           │
│  ┌─────────────────────────────────────────────────────────────────┐      │
│  │ 1. 在FA模块执行"计提折旧"操作                                 │      │
│  │ 2. 系统计算所有满足条件的资产的月折旧额                        │      │
│  │ 3. 生成折旧清单供财务人员审核                                 │      │
│  │ 4. 财务人员审核通过                                           │      │
│  │ 5. 系统自动生成GL凭证                                         │      │
```
