## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 一、核心问题：为什么可以用"买"来类比"租"？

### 1.1 问题的起源

承租人常有的困惑：

> 我只是租了2年，到期要还回去，凭什么要像"买"一样入表？

这个困惑的根源在于：**租赁和买，在经济实质上有相似性，但在法律形式上有差异**。

### 1.2 相似性 vs 差异性

| 维度 | 买（自购） | 融资租赁 | 相似/差异 |
|------|------------|----------|----------|
| 获得资产 | 获得使用权 | 获得使用权 | **相似** |
| 承担义务 | 欠银行钱 | 欠出租人钱 | **相似** |
| 定期还款 | 按月还款 | 按月付租 | **相似** |
| 资产消耗 | 折旧 | 折旧 | **相似** |
| 最终状态 | 拥有所有权 | 归还资产 | 差异 |
| 所有权 | 归自己 | 归出租人 | 差异 |
| 资产入账 | 原值 | 折现值 | 差异 |

**关键洞察**：相似性在"使用价值"，差异性在"法律权属"。

## 四、三个核心等式

### 4.1 等式一：资产 = 负债（入账时）

```
起租日：
  使用权资产 = 租赁负债 = 21.4万（折现值）
```

| 因果关系 | 说明 |
|----------|------|
| 因：获得资产使用权 | → 确认使用权资产 |
| 因：承担付款义务 | → 确认租赁负债 |
| 为什么相等？ | 借贷必相等 + 使用权价值 = 义务现值 |

### 4.2 等式二：租金 = 还本 + 付息（每月）

**❌ 常见错误理解**：
```
折旧 + 时间价值 = 租金
```

**✓ 正确理解**：
```
租金 = 还本 + 付息
```

**第1期数据验证**：

| 项目 | 计算 | 金额 | 性质 |
|------|------|------|------|
| 租金 | 实际支付 | **1.0000万** | 现金流 |
| 付息 | 期初余额 × 月利率 | **0.0872万** | 负债增加 |
| 还本 | 租金 - 付息 | **0.9128万** | 负债减少 |

**为什么折旧 ≠ 还本？**

| 项目 | 计算 | 特点 |
|------|------|------|
| 折旧 | 21.4万 ÷ 24期 | **固定**，每月 0.8917万 |
| 还本 | 租金 - 利息 | **递增**，第1期 0.9128万 → 最后期 ≈ 0 |

### 4.3 等式三：折旧 ≈ 净还本（累计）

**❌ 常见错误理解**：
```
每月：折旧 = 还本
```

**✓ 正确理解**：
```
每月：折旧 ≈ 净还本（月度不等，累计相等）
```

**第1期数据验证**：

| 项目 | 金额 |
|------|------|
| 折旧 | 0.8917万 |
| 净还本 = 租金 - 时间价值 | 1.0000 - 0.0872 = **0.9128万** |
| 差额 | 0.0211万 |

**月度 vs 累计对比**：

| 对比维度 | 折旧 | 净还本 | 关系 |
|----------|------|---------|------|
| 月度值 | 固定 0.8917万 | 递增 0.91→0万 | **不等** |
| 累计值 | 21.4万 | 21.4万 | **相等** |

**为什么累计相等？**
- 这是维持"资产 = 负债"平衡的要求
- 如果不相等，资产负债表就会失衡

## 五、折现率 vs 实际利率

### 5.1 基本概念对比

| 术语 | 用于 | 含义 | 本质 |
|------|------|------|------|
| **折现率** | 初始确认 | 将未来现金流折算成现值 | 已知未来→求现值 |
| **实际利率** | 后续计量 | 计算每期利息费用 | 已知现值→求未来值 |

**关键洞察**：两者是**同一个数值**的不同面孔。

### 5.2 结构关系图

```
┌─────────────────────────────────────────────────────────────────┐
│                   折现率 ↔ 实际利率 的结构关系                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   【第一步：折现（初始确认）】                                    │
│                                                                  │
│   未来现金流：1万 → 1万 → 1万 → ... → 1万                    │
│                        ↓                                          │
│                   ÷ (1 + r)^n                                  │
│                        ↓                                          │
│              现值 = 21.4万（租赁负债入账金额）                  │
│                        │                                          │
│                        │ ← 这里 r 叫「折现率」                  │
│                                                                  │
│   ─────────────────────────────────────────────────────         │
│                                                                  │
│   【第二步：计息（后续计量）】                                    │
│                                                                  │
│   期初负债：21.4万                                              │
│                        │                                          │
│                        │ × (1 + r)                              │
│                        ↓                                          │
│              期末本利和 = 21.4万 + 利息                         │
│                        │                                          │
│                        │ ← 这里 r 叫「实际利率」                  │
│                                                                  │
│   【结论】同一个 r，不同名字，互为逆运算                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 5.3 因果链条

```
┌─────────────────────────────────────────────────────────────────┐
│                    折现率 → 实际利率 的因果链                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   因：起租日确认租赁负债 = 未来租金的折现值                      │
│       21.4万 = Σ 1万 ÷ (1 + r)^n                              │
│                        │                                         │
│                        ↓（解方程求出 r）                         │
│   果：这个 r 被"记住"                                            │
│                        │                                         │
│                        ↓                                         │
│   每期利息 = 期初负债 × r                                       │
│                        │                                         │
│                        │ ← 后续计量时，r 叫「实际利率」          │
│                                                                  │
│   结论：r 不变，只是场景不同名字不同                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 5.4 为什么不能换用？

```
┌─────────────────────────────────────────────────────────────────┐
│              假设：折现率 ≠ 实际利率 → 逻辑矛盾                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   设：折现率 = 5%，实际利率 = 6%                              │
│                                                                  │
│   初始确认：                                                    │
│   租赁负债 = 1万÷1.05^1 + 1万÷1.05^2 + ... = 21.4万        │
│                                                                  │
│   第一年末计息（用6%）：                                        │
│   利息 = 21.4万 × 6% = 1.284万                               │
│   本利和 = 22.684万                                            │
│   付款后余额 = 21.684万                                        │
│                                                                  │
│   但如果用折现率反算：                                          │
│   理论利息 = 21.4万 × 5% = 1.07万  ← 与 1.284万 矛盾！      │
│                                                                  │
│   结论：必须是同一个 r，否则逻辑崩溃                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 5.5 一句话总结

> **折现率和实际利率是同一个数的两个面孔：折现率用于"已知未来求现值"，实际利率用于"已知现值求未来值"。两者因果相连——折现率决定初始金额，金额决定利息基础，利息影响余额，余额影响下一期利息，形成闭环。**

## 七、"分期付款买资产"类比的边界

### 7.1 可以用类比解释

```
✅ 为什么要入表（获得使用权=承担义务）
✅ 为什么要折旧（资产消耗需要补偿）
✅ 为什么有利息/时间价值（占用资金有成本）
✅ 为什么最终都归零（折旧提完=本金还完）
```

### 7.2 不应用类比解释

```
❌ 所有权归属（类比会误导）
❌ 合同终止条件（类比会混淆）
❌ 税收处理差异（完全不同）
```

### 7.3 类比揭示的共同结构

| 共同结构 | 说明 |
|----------|------|
| 资产 = 负债 | 入账时借贷平衡 |
| 租金 = 还本 + 付息 | 现金流分解 |
| 折旧 ≈ 净还本 | 累计平衡 |

## 九、一句话总结

> **"分期付款买资产"类比揭示了租赁入表的三个核心结构：资产=负债（入账平衡）、租金=还本+付息（现金流分解）、折旧≈净还本（累计平衡）。这个类比虽然忽略了法律权属的差异，但抓住了经济实质的相似性，是理解租赁会计的有效工具。**
