## 3. 核心计算执行顺序

> **重要**：以下三个步骤有严格的先后依赖顺序，不能打乱。

### 3.1 评审决策（2026-10-01）

| # | 问题 | 答案 | 设计决策 |
|---|------|------|---------|
| 1 | 存量租赁 | 以后可能需要 | **暂不实现**：预留字段，简化新租逻辑 |
| 2 | acctClass区分 | 内部需要区分 | 保留字段，用于区分本金类/费用类 |
| 3 | VAT抵扣 | 没有 | **简化**：统一使用含税金额计算资产折现 |
| 4 | 利息摊销模式 | **只做模式A** | 直接用公式计算日利率，不需要迭代 |
| 5 | 免租期利息 | 需要 | 免租期计算利息，负债余额增加 |

> **重要说明**：为什么不迭代计算日利率？
>
> 根据源码分析，星空迭代计算日利率的原因是：
> - 利息摊销模式 = B
> - 或 来源类型 ≠ A
>
> 我们的业务场景是**新租初始化测算**：
> - 用户输入年折现率 → 直接用公式计算日利率：`(1 + 年利率)^(1/365) - 1`
> - 不需要"反推"日利率
>
> 详细分析见：`租赁利息计算-模式A与模式B区别.md`

## 4. 核心算法详解

### 4.1 Step 1: 生成付款计划

**当前项目已有实现**：`RentContractApiImpl.genRentPaymentPeriodList()`

**功能**：
- 按计费周期生成各期付款日期
- 计算每期基准租金（含递增倍率）
- 计算免租金额
- 日摊算处理

**核心逻辑**：

| 计费方式 | 计算公式 |
|----------|----------|
| 30-固定金额 | `monthRent × 递增倍率` |
| 31-面积固定 | `rentPrice × calcRentArea × 递增倍率` |
| 32-面积+抽成 | `rentPrice × calcRentArea × 递增倍率`（标记抽成） |
| 33-纯抽成 | `0`（标记纯抽成） |
| 34-保底+超额 | `minRentAmt × 递增倍率`（标记超额） |

**递增倍率计算**：

```java
private BigDecimal calcIncreaseRate(int periodNo, Integer addPeriod, BigDecimal addRate) {
    if (addPeriod == null || addPeriod <= 0 || addRate == null || addRate.compareTo(BigDecimal.ZERO) == 0) {
        return BigDecimal.ONE;  // 不递增
    }
    long elapse = periodNo - 1;
    int times = (int) (elapse / addPeriod);
    if (times <= 0) {
        return BigDecimal.ONE;  // 首期不递增
    }
    BigDecimal rate = BigDecimal.ONE.add(addRate.divide(new BigDecimal(100), 4, RoundingMode.HALF_UP));
    return rate.pow(times);  // (1+addRate%)^times
}
```

### 4.2 Step 2: 计算每期折现值（fillPayPlan）

**星空代码位置**：`LeaseUtil.fillPayPlan()` (第412-456行)

> **评审决策**：新租场景简化实现
> - 折现起点统一使用 `rentStartDate`
> - 存量租赁逻辑预留（暂不实现）

#### 4.2.1 算法流程

```
for each 支付计划行 {
    // ===== 负债折现计算 =====
    // 简化：新租场景直接计算，不判断 acctClass 和日期
    liabDiscountDays = planPayDate - rentStartDate;
    liabDiscountFactor = (1 + dailyRate)^liabDiscountDays;
    liabPresentValue = unpaidRent / liabDiscountFactor;
    row.presentvalue = liabPresentValue;
    
    // ===== 资产折现计算 =====
    // 简化：统一使用含税金额（rent）
    assetDiscountDays = planPayDate - rentStartDate;
    assetDiscountFactor = (1 + dailyRate)^assetDiscountDays;
    assetPresentValue = rent / assetDiscountFactor;
    row.presentvalue2 = assetPresentValue;
}
```

#### 4.2.2 负债折现 vs 资产折现

| 对比项 | 负债折现 | 资产折现 |
|--------|---------|---------|
| **折现起点** | `rentStartDate`（新租） | `rentStartDate`（新租） |
| **折现分子** | `unpaidRent`（未付本金） | `rent`（含税金额） |
| **使用场景** | 计算租赁负债 | 计算使用权资产 |
| **数据写入** | `presentvalue` | `presentvalue2` |

### 4.3 Step 3: 汇总财务字段（calFinInfoFields）

**星空代码位置**：`LeaseUtil.calFinInfoFields()` (第458-523行)

> **评审决策**：简化实现
> - 统一使用含税金额计算资产折现
> - acctClass 区分仅用于跳过不参与折现的记录

#### 4.3.1 算法流程

```java
BigDecimal leaseLiabOri = ZERO;  // 负债原值
BigDecimal leaseLiab = ZERO;     // 负债现值
BigDecimal leaseAssets = ZERO;    // 使用权资产

for each 支付计划行 {
    // 跳过不参与折现的记录
    if (acctClass == "C") continue;

    // ===== 累加负债 =====
    leaseLiabOri += unpaidRent;
    leaseLiab += presentvalue;

    // ===== 计算使用权资产 =====
    // 简化：直接累加资产折现值 + 含税租金
    leaseAssets += presentvalue2 + rent;
}

// 写入主表
leaseContract.leaseliabori = leaseLiabOri;
leaseContract.leaseliab = leaseLiab;
leaseContract.leaseassets = leaseAssets;
```

#### 4.3.2 acctClass 会计分类

| acctClass | 名称 | 是否参与折现 | 计算 |
|-----------|------|-------------|------|
| A | 本金类 | ✅ 是 | 未付租金作为本金 |
| B | 费用类 | ✅ 是 | 服务费等 |
| C | 其他类 | ❌ 否 | 不计入 |

### 4.4 Step 4: 生成利息明细

**星空代码位置**：`InterestDetailGenerator.generateForNotExemptContract()` (第95-153行)

> **评审决策**：只做模式B（迭代计算实际日利率）

#### 4.4.1 算法流程

```java
// Step 1: 先计算日利率（模式B迭代计算）
BigDecimal dailyRate = RealDailyIntRateCalculator.calculate(leaseContract);

// Step 2: 构建付款Map
Map<String, BigDecimal> amountMap = buildPaymentMap(planEntries);

// Step 3: 按日循环计算
BigDecimal beginBalance = leaseContract.getLeaseliab();
Date rowDate = detailBeginDate;

while (rowDate <= detailEndDate) {
    BigDecimal dailyPay = amountMap[dateStr];  // 当日支付（免租期为0）
    BigDecimal dailyInt = (beginBalance - dailyPay) × dailyRate;  // 日利息
    BigDecimal endBalance = beginBalance - dailyPay + dailyInt;  // 期末余额

    // 保存明细行
    row.set(seq, date, beginBalance, dailyPay, dailyInt, endBalance);

    // 进入下一天
    beginBalance = endBalance;
    rowDate = rowDate + 1;
}
```

#### 4.4.2 核心公式

| 计算项 | 公式 |
|--------|------|
| 日利息 | `(期初余额 - 当日支付) × 日利率` |
| 期末余额 | `期初余额 - 当日支付 + 日利息` |

#### 4.4.3 日利率迭代计算（模式B）

**星空代码位置**：`RealDailyIntRateCalculator.calculate()` (第98-180行)

```
目标：找到使"利息总额" = "未确认融资费用"的日利率

未确认融资费用 = 负债原值 - 负债现值（固定值）

迭代过程：
1. 初始日利率 = 合同日利率
2. 计算当前日利率下的利息总额
3. if (利息总额 > 目标) → 减少利率 × 0.98
   if (利息总额 < 目标) → 增加利率 × 1.02
4. 重复直到收敛
```

```java
double notConfirmFinCost = leaseLiabOri - leaseLiab;
double dailyRate = initRate;

while (abs(difference) > tolerance) {
    double interestTotal = calculateInterestTotal(dailyRate);
    double difference = interestTotal - notConfirmFinCost;

    if (difference > 0) {
        dailyRate *= 0.98;  // 利息太多，减少利率
    } else {
        dailyRate *= 1.02;  // 利息太少，增加利率
    }
}
```

## 9. 公式速查表

| 计算项 | 公式 | 星空代码位置 |
|--------|------|-------------|
| 日利率（复利） | `(1+r)^(1/365)-1` | `LeaseUtil` |
| 负债折现因子 | `(1 + 日利率)^(付款日-初始确认日)` | `fillPayPlan()` |
| 负债现值 | `未付租金 / 负债折现因子` | `fillPayPlan()` |
| 资产折现因子 | `(1 + 日利率)^(付款日-租赁开始日)` | `fillPayPlan()` |
| 资产现值 | `租金 / 资产折现因子` | `fillPayPlan()` |
| 日利息 | `(期初余额-支付) × 日利率` | `InterestDetailGenerator` |
| 期末余额 | `期初余额 - 支付 + 利息` | `InterestDetailGenerator` |
