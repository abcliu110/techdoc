# 租赁资产业务逻辑总结

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 二、租赁合同生命周期

```
新增 → 保存 → 提交 → 审核 → 推送 → 生成财务卡片
  ↓
变更 → 保存 → 审核 → 推送 → 更新财务卡片
  ↓
终止 → 审核 → 生成结清单 → 更新余额 → 生成续租合同（如有）
```

## 三、核心单据的审核流程

- 日期合理性检查
- 付款规则检查

2. 计算使用权资产和租赁负债

| 金额变更 | 影响资产卡片 | A（重新推送） |

### 4.2 生成逻辑（LeaseUtil.generatePayPlan）

```java
// 遍历付款规则
for (PayRuleRow : payruleentryentity) {
    Date ruleStartDate = row.get("rule_startdate");
    Date ruleEndDate = row.get("rule_enddate");
    PayFrequency frequency = row.get("frequency");
    int intervalMonth = frequency.getIntervalMonth();

    // 按频率生成付款计划
    Date planDate = ruleStartDate;
    while (planDate <= ruleEndDate) {
        // 计算税额
        BigDecimal rent = row.get("amount");
        BigDecimal tax = row.get("rule_tax");
        BigDecimal rentNoTax = rent - tax;

        // 生成付款计划行
        createPayPlanRow(planDate, rent, tax, rentNoTax);

        // 下一期
        planDate = addMonth(planDate, intervalMonth);
    }
}
```

## 五、使用权资产与租赁负债计算

### 5.1 计算时机

- 租赁合同提交时
- 租赁变更单审核时
- 初始化租赁合同审核时

### 5.2 计算顺序（重要：负债现值是利息明细的前置条件）

```
┌─────────────────────────────────────────────────────────────────────┐
│  Step 1: fillPayPlan() - 填充支付计划折现信息                        │
│  └─ 计算每行的负债现值、资产现值                                     │
│                          ↓                                          │
│  Step 2: calFinInfoFields() - 计算并汇总财务字段                     │
│  └─ 汇总得到: leaseliab (负债现值)、leaseliabori (负债原值)         │
│                          ↓                                          │
│  Step 3: 利息明细生成（依赖 Step 2 的结果）                          │
│  └─ beginBalance 初始值 = leaseliab                                 │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.3 负债折现 vs 资产折现（为什么会有两个折现？）

根据租赁会计准则（IFRS 16 / CAS 21），使用权资产的计算也需要折现：

| 折现对象 | 对应科目 | 含义 |
|----------|---------|------|
| **负债折现** | 租赁负债 | 未来应付租金的现值 |
| **资产折现** | 使用权资产 | 未来应付租金的现值 |

**核心区别**：

| 对比项 | 负债折现 | 资产折现 |
|--------|---------|---------|
| 折现起点 | 初始确认日 | 租赁期开始日 |
| 计算结果 | 写入 `presentvalue` | 写入 `presentvalue2` |

**为什么折现起点不同？**

主要是因为**存量租赁**（系统切换前已存在的租赁）：

```
场景：2020年1月1日开始租，2024年1月1日系统切换

时间线：
2020-01-01          2024-01-01          2026-01-01
    │                   │                   │
    │←── 旧租赁期 ────→│←── 剩余租期 ────→│
    │                   │                   │
租赁期开始日          初始确认日            租赁结束日

┌─────────────────────────────────────────────────────────────┐
│ 负债折现起点: 2024-01-01 (初始确认日)                       │
│  → 折现天数 = 付款日 - 2024-01-01                         │
│                                                              │
│ 资产折现起点: 2020-01-01 (租赁期开始日)                     │
│  → 折现天数 = 付款日 - 2020-01-01                         │
└─────────────────────────────────────────────────────────────┘
```

**会计分录示例**：

```
新增租赁时：
  借：使用权资产      469,000
      未确认融资费用   31,000
    贷：租赁负债      500,000

每月付款时：
  借：租赁负债        20,000
    贷：银行存款      20,000

每月利息：
  借：财务费用        3,000
    贷：未确认融资费用  3,000
```

### 5.4 fillPayPlan - 填充支付计划折现信息

**位置**: `LeaseUtil.fillPayPlan()` (第412-456行)

```java
for (PayPlanRow : planEntry) {
    // ============ 负债折现计算 ============
    // 折现天数 = 计划付款日 - 初始确认日
    int liabDays = getDiffDays(initConfirmDate, planPayDate);
    
    // 折现因子 = (1 + 日利率)^折现天数
    BigDecimal liabFactor = BigDecimal.valueOf(Math.pow(1 + dailyRate.doubleValue(), liabDays));
    
    // 负债现值 = 未付租金 / 折现因子
    BigDecimal liabPV = unpaidRent.divide(liabFactor, 10, roundingMode);
    row.set("presentvalue", liabPV);
    
    // ============ 资产折现计算（仅方案A/C）============
    if (isCalLeaseAssetsForPayPlan(transitionPlan)) {
        int assetDays = getDiffDays(leaseTermStartDate, planPayDate);
        BigDecimal assetFactor = BigDecimal.valueOf(Math.pow(1 + dailyRate.doubleValue(), assetDays));
        BigDecimal assetPV = amountTemp.divide(assetFactor, 10, roundingMode);
        row.set("presentvalue2", assetPV);
    }
}
```

### 5.5 calFinInfoFields - 计算财务字段

**位置**: `LeaseUtil.calFinInfoFields()` (第458-523行)

```java
BigDecimal leaseLiabOri = ZERO;  // 负债原值
BigDecimal leaseLiab = ZERO;     // 负债现值
BigDecimal leaseAssets = ZERO;   // 使用权资产

for (PayPlanRow : planEntry) {
    // 跳过费用类（acctClass = "C"）
    String acctClass = payItem.getString("accountingclass");
    if ("C".equals(acctClass)) continue;

    // ============ 负债计算 ============
    // 负债原值：累加未付租金
    leaseLiabOri = leaseLiabOri.add(unpaidRent);
    
    // 负债现值：累加每行折现值
    leaseLiab = leaseLiab.add(row.getBigDecimal("presentvalue"));

    // ============ 使用权资产计算（按方案）============
    if (TransitionPlan.A 或 C) {
        leaseAssets += assetPV;
        if (acctClass == "B") {
            leaseAssets += deductible ? rentNoTax : rent;
        }
    } else {  // 方案B
        leaseAssets += liabPV;
        if (acctClass == "A") {
            leaseAssets += tax;
        } else if (acctClass == "B") {
            leaseAssets += rentNoTax;
        }
    }
}

// 方案A：计算累计折旧
if (TransitionPlan.A) {
    int totalMonths = getDiffMonths(leaseTermStartDate, leaseEndDate);
    int executedMonths = getDiffMonths(leaseTermStartDate, firstExecDate);
    assetsAccumDepre = leaseAssets * executedMonths / totalMonths;
}
```

### 5.6 负债现值计算公式

```
负债现值 = Σ(每期未付租金 ÷ (1 + 日利率)^折现天数)

其中：
- 折现天数 = 计划付款日 - 初始确认日
- 日利率 = 年折现率 / 365
- 未付租金：acctClass="A" 且 planPayDate >= initConfirmDate 的租金
```

### 5.7 计算结果

| 字段 | 说明 | 利息明细依赖 |
|------|------|-------------|
| `leaseassets` | 使用权资产原值 | ❌ 不依赖 |
| `leaseliabori` | 租赁负债原值 | ❌ 不依赖 |
| **`leaseliab`** | **租赁负债现值** | **✅ 是利息明细 beginBalance 的初始值** |
| `assetsaccumdepre` | 累计折旧（仅方案A） | ❌ 不依赖 |
| `noconfirmfincost` | 未确认融资费用（= leaseliabori - leaseliab） | ❌ 不依赖 |

## 六、利息明细生成

### 6.1 生成时机

- 租赁合同审核时
- 租赁变更单审核时
- 每月期末结账时

### 6.2 负债折现 vs 利息明细（核心区别）

| 对比项 | 负债折现（fillPayPlan） | 利息明细（InterestDetailGenerator） |
|--------|-------------------------|-------------------------------------|
| **计算粒度** | 每条支付计划行（付款日） | 每天 |
| **计算目的** | 得到资产负债表日的负债账面价值 | 跟踪每天的余额变化 |
| **计算公式** | `PV = 未付租金 / (1+日利率)^天数` | `利息 = (期初余额-支付) × 日利率` |
| **触发时机** | 合同提交时（一次性） | 合同审核时、每月结账 |
| **数据写入** | 写入 `payplanentryentity.presentvalue` | 写入 `fa_interest_detail` |

**为什么这样设计？**

- **负债折现**：只需要算一次，把未来要付的租金折现到初始确认日，得到一个"快照值"
- **利息明细**：负债每天都在计息，余额每天都在变化，需要按日跟踪

**举例说明**：

假设合同：租2年，月付2万，初始确认日2024-01-01，年利率5%

```
【负债折现】（只算付款日的折现）
┌─────────────────────────────────────────────────────────────┐
│ 2024-01-01 付款：PV = 20000 / (1+0.014%)^0 = 20000        │
│ 2024-02-01 付款：PV = 20000 / (1+0.014%)^31 = 19890       │
│ 2024-03-01 付款：PV = 20000 / (1+0.014%)^60 = 19760       │
│ ...                                                        │
│ 负债现值合计 = Σ(PV) = 469,000 (假设)                       │
└─────────────────────────────────────────────────────────────┘

【利息明细】（按天算，每天一条）
┌─────────────────────────────────────────────────────────────┐
│ 01-01: begin=469000, pay=0, interest=65.66, end=469065.66 │
│ 01-02: begin=469065.66, pay=0, interest=65.67, end=469131.33│
│ ...                                                        │
│ 01-31: begin=470000, pay=20000, interest=63.67, end=450063.67│
│ 02-01: begin=450063.67, pay=0, interest=63.01, end=450126.68│
│ ...                                                        │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 生成逻辑（InterestDetailGenerator）

```java
Date rowDate = beginDate;
while (rowDate <= endDate) {
    // 日利息 = 期初余额 × 日利率
    BigDecimal dailyInterest = beginBalance × dailyRate;

    // 日还本 = 支付 - 利息
    BigDecimal dailyPrincipal = dailyPay - dailyInterest;

    // 期末余额 = 期初 - 还本 + 利息
    BigDecimal endBalance = beginBalance - dailyPrincipal + dailyInterest;

    // 记录明细行
    createDetailRow(date, beginBalance, dailyPay, dailyInterest, endBalance);

    // 下一天
    beginBalance = endBalance;
    rowDate = rowDate + 1;
}
```

### 6.3 明细表结构

| 字段 | 说明 |
|------|------|
| `date` | 日期 |
| `beginbalance` | 期初余额 |
| `leaseliabpay` | 当日支付 |
| `leaseliabint` | 当日利息 |
| `endbalance` | 期末余额 |
| `amortizationperiod` | 摊销期间 |
| `latestdata` | 是否最新数据 |
| `sourcetype` | A-新增 / B-冲销 |

| 插件类 | 单据 | 职责 |
|--------|------|------|
| `LeaseContractEditPlugin` | 租赁合同 | 字段联动、默认值、校验 |
| `LeaseChangeEditPlugin` | 租赁变更单 | 变更字段处理 |
| `LeaseTerminationEditPlugin` | 租赁终止单 | 终止模式选择 |
| `FaLeaseInitEditPlugin` | 初始租赁 | 存量租赁初始化 |

### 9.2 操作插件 (OpPlugin)

| 插件类 | 操作 | 职责 |
|--------|------|------|
| `FaLeaseContractAuditOp` | 审核 | 生成卡片、利息明细、余额 |
| `FaLeaseContractInitAuditOp` | 初始审核 | 存量租赁处理 |
| `FaLeaseChangeBillAuditOp` | 变更审核 | 执行变更、更新数据 |
| `FaLeaseTerminationOp` | 终止审核 | 生成结清单、更新状态 |
| `FaGeneratePayPlanOp` | 生成付款计划 | 计算折现、生成计划 |
| `FaExemptRecordsSaveOp` | 豁免保存 | 保存豁免记录 |

### 9.3 业务处理器

| 处理器 | 职责 |
|--------|------|
| `LeaseContractGenerator` | 生成租赁合同 |
| `InterestDetailGenerator` | 生成利息明细 |
| `FaLeaseDebitBalanceGenerator` | 生成负债余额 |
| `LeaseTerminationHandler` | 处理合同终止 |
| `LeaseChangeHandler` | 处理合同变更 |
| `LeasePartTerCalculator` | 计算部分终止 |
