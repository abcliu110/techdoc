# 租赁负债三线速查卡

> 用途：培训、评审、对账时快速核对「主科目 — 备抵科目 — 净额」三条线。
> 完整推导见《从租户角度的租金入表逻辑》§3.3.7～§3.3.8；计算口径见《使用权资产与租赁负债计算详解》§7.4。
> 依据：CAS 21 第十七条（初始计量）、第五十三条（列报）；IFRS 16 §22–§38。

---

## 一、一条公式

```
主科目（贷） − 备抵科目（借） = 报表净额（账面价值）

租赁负债—租赁付款额（贷） − 租赁负债—未确认融资费用（借） = 租赁负债（现值）
```

## 二、一个最小例子（3 年、每年末付 100、折现率 8%）

```
现值 257.70 ｜ 付款合计 300.00 ｜ 未确认融资费用 42.30
```

| 时点 | 租赁付款额（贷） | 未确认融资费用（借） | 净额 | 本期利息 | 本期付款 |
|---|---:|---:|---:|---:|---:|
| 起租日 | 300.00 | 42.30 | **257.70** | — | — |
| 第 1 年末 | 200.00 | 21.68 | **178.32** | 20.62 | 100.00 |
| 第 2 年末 | 100.00 | 7.41 | **92.59** | 14.27 | 100.00 |
| 第 3 年末 | 0.00 | 0.00 | **0.00** | 7.41 | 100.00 |
| 合计 | | | | **42.30** | **300.00** |

（最小例子里尾差就已出现——这是「末期归零／封口」存在的根本原因。）

**四条线的变化方向（最容易记反）**

| 指标 | 方向 | 原因 |
|---|---|---|
| 负债**余额** | ↓ 递减到 0 | 逐期还本 |
| **当期利息** | ↓ 递减 | 利息 = 期初余额 × 利率 |
| **当期还本** | ↑ 递增 | 付款固定，利息少了本金就多 |
| **累计利息** | ↑ 递增至 = 未确认融资费用 | 逐期累加 |

> 一句话：**余额递减 → 当期利息递减 → 当期还本递增**；**累计利息递增**。
> 数字对照见《使用权资产与租赁负债计算详解》§7.6 Q3。


## 三、四种动作对三条线的影响

| 动作 | 分录 | 主科目 | 备抵科目 | 净额 |
|---|---|---|---|---|
| 起租日确认 | 借 使用权资产＋未确认融资费用 / 贷 租赁付款额＋银行存款 | +300.00 | +42.30 | +257.70 |
| 计提利息 | 借 财务费用 / 贷 未确认融资费用 | 不变 | −20.62 | **＋20.62** |
| 支付租金 | 借 租赁付款额 / 贷 银行存款 | −100.00 | 不变 | −100.00 |
| 计提折旧 | 借 管理费用 / 贷 使用权资产累计折旧 | 不变 | 不变 | 不影响负债 |
| 报表重分类 | 不记账（报表取数规则） | 不变 | 不变 | 按现值口径拆两段 |

## 四、三条反直觉（一句话版）

| 反直觉 | 一句话拆解 |
|---|---|
| 负债类科目却挂借方余额 | 它是负债侧的「累计折旧」：余额方向与主科目相反 |
| 计提利息反而让负债变大 | 贷记借方科目 → 备抵↓ → 净额↑；每期净额只减少「本金」（−P＋I＝−R） |
| 报表 ≠ 科目余额相加 | 净额列示；「一年内到期」按**现值口径**重分类，本金与备抵一起搬 |

**双方视角一句话**：融资费用是“**占用了对方的钱、为它付利息**”，不是“我方有钱没动、它生了利息”——
前者是负债侧的**成本**（别人的钱），后者是资产侧的**收益**（我方的钱），金额可能相等、**性质恰好相反**，会计上必须各记各的。

> 完整辨析（含“一次性付清要看时点”“租期末一次性付清费用最大”“存款消耗表＝摊销表”的对偶）见《使用权资产与租赁负债计算详解》§7.6 Q4。

**使用权资产的双视角**：它不是我方"自己长出来"的资产，而是**对方让渡使用收益后、落在我方账上的镜像**——
只开我方的账，看到的是一笔"自己贷自己"的分录；把对方账一并打开，才看到一笔**有出有进的交易**。

> 四个死结 → 四个答案、完整镜像表、复核红线见《使用权资产与租赁负债计算详解》§7.7。

**最白的一句**：就像分期买冰箱——东西搬进你家（资产），钱还没付完（负债）；租赁只是把"冰箱"换成了"未来 N 年的使用权"。**你多的＝对方少的**，账就平了。

> 白话入门 → 正式推导，见《使用权资产与租赁负债计算详解》**§7.7.0 → §7.7.1**。

## 五、期末验证（四条）

```
① 租赁负债账面价值   = 租赁付款额余额 − 未确认融资费用余额
② 使用权资产账面价值 = 使用权资产 − 使用权资产累计折旧
③ 累计已摊销利息     = 未确认融资费用期初余额 − 期末余额（＝累计财务费用）
④ 累计付款           = 租赁付款额期初余额 − 期末余额
```

## 六、常见错账（5 条）

| # | 错账 | 后果 |
|---|---|---|
| 1 | 把「未确认融资费用」当资产列报 | 资产虚增，负债净额虚增（重复计算） |
| 2 | 起租日漏记未确认融资费用，直接按总额贷记负债 | 负债虚增；摊销无处可去，末期挂残值 |
| 3 | 摊销时借记备抵科目（方向写反） | 净负债虚减，与测算表对不上 |
| 4 | 「一年内到期」按名义付款额重分类 | 流动负债虚增，流动比率/速动比率被静默拉低 |
| 5 | 只保存现值，附注时临时倒算原值 | 倒算口径错（含已确认利息），与「未折现付款额」不符 |

| 项目 | 归属 | 依据 |
|---|---|---|
| 偿还租赁负债**本金** | **筹资活动** | CAS 21 第五十三条 |
| 偿还租赁负债**利息** | **筹资活动**（CAS 下本金利息都进筹资） | CAS 21 第五十三条 |
| **起租日或之前支付的租金**（未进负债的部分） | **筹资活动** ⚠️ 反直觉 | 财政部会计司《租赁准则实施问答》2021-04 |
| **租赁保证金** | **筹资活动** | 同上 |
| 短期租赁 / 低价值资产租赁付款额（含其预付租金、保证金） | 经营活动 | CAS 21 第五十三条 |
| 未纳入租赁负债计量的可变租赁付款额 | 经营活动 | CAS 21 第五十三条 |

> **一句话**：中国口径下「**只要进了表的租赁，租金出去的钱一律进筹资**」；豁免的走经营。
> **别照搬 IFRS 模板**：IFRS 下起租日**之前的预付款**通常被列为**投资活动**，与我国口径不同（A 股报表以筹资为准）。
> 利息与折旧**不产生现金流**（利润表项目），在现金流量表补充资料中调节；起租日确认资产与负债属**非现金交易**，在负债变动附注中披露。

## 八、口径选择（一句话）

**推荐总额法**（主科目＋备抵科目）：附注要原值、审计要交叉验证、旧准则迁移天然同构、系统三个字段可互校（原值／未确认融资费用／现值）。
净额法在报表层等价，但「原值」与「累计利息」出了总账，须另建台账补上。

**别混淆（3 条）**：
1. 「总额法／净额法」是**科目设置**的选择；**报表一律按净额列示**（准则要求）——两者不是一回事，报表数字也完全相同。
2. 「一年内到期」重分类取的是**净额（现值）**，不是名义付款额，且本金与未确认融资费用要**一起搬**。
3. 收入准则里的「总额法／净额法」（主要责任人 vs 代理人）与此**同名不同义**。

> 完整对照（含逐期科目余额对照表、术语辨义）见《从租户角度的租金入表逻辑》§3.3.4。


## 九、同类工具速查：差额是什么

| 工具 | 主科目（名义额） | 调整科目（差额） | 差额含义 | 方向 |
|---|---|---|---|---|
| **租赁（新准则）** | 租赁负债—租赁付款额 | 租赁负债—未确认融资费用 | **= 总利息** | 借（恒为正） |
| 分期付款购买资产 | 长期应付款 | 未确认融资费用 2702 | = 总利息 | 借 |
| 旧准则融资租赁 | 长期应付款—应付融资租赁款 | 未确认融资费用 2702 | = 总利息 | 借 |
| **债券** | 应付债券—面值 | 应付债券—利息调整 | = 总利息 − 票面利息 | 折价→借；溢价→贷 |
| 长期借款（按合同利率付息） | 长期借款 | 无 | = 0 | — |
| 投资人镜像：债权投资 | 债权投资—成本（面值） | 债权投资—利息调整 | 同债券（镜像） | 溢价买入→借 |
| 投资人镜像：长期应收款 | 长期应收款 | 未实现融资收益 | = 总收益 | 贷（资产备抵） |

**一句话**：差额 = **时间价值总量 − 合同里已经明说的利息**。合同把利息藏在价款里（租赁、分期付款）→ 差额是**全部利息**；合同单列利息（债券票面利息）→ 差额只是**利息的调整项**。

**两个易混点**：
- 租赁差额**恒为正**（付款都在起租日之后）；债券差额**可正可负**（折价／溢价）。
- 债券的「面值 − 发行价」**不是**总融资成本：折价例（面值 1000、发行价 922.69、差额 77.31）的真实总利息是 **227.32** = 票面利息 150 ＋ 差额 77.31。

> 完整推导与验证见《使用权资产与租赁负债计算详解》§7.5～§7.6。
