## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 一、租赁是什么

### 1.1 租赁的本质

租赁，用大白话说就是：

> **用别人的东西，给自己办事，到期还回去。**

你租一间办公室，你没有买下这间办公室的所有权，但你获得了使用权。租期满后，办公室还是房东的。

这个"使用权"，在会计上值多少钱？这就是租赁会计准则要回答的核心问题。

### 1.2 租赁和买的根本区别

| | 买 | 租 |
|---|---|---|
| 所有权 | 归自己 | 归别人 |
| 资产负债表 | 买的资产入表 | 入表（新准则）/ 不入表（旧准则）|
| 付钱方式 | 一次性付清或贷款 | 定期付租金 |
| 义务 | 欠银行的钱 | 欠房东的租金 |

**核心区别只有一个：所有权归谁。** 买下来，所有权是自己的；租着用，所有权是人家的。会计处理的不同，都是从这个根本区别推导出来的。

## 二、为什么要入表

### 2.0 一个最难理解的问题：为什么未来的钱今天就要入表

这个问题是理解租赁入表最核心的认知门槛。

很多人到这里就想不通：

> 钱是一年后、两年后才付的。
> 凭什么今天就要在资产负债表上写一笔负债？

**关键在于区分两件事：义务发生的时间，和付钱的时间。**

```
签合同之前：你什么都不欠
签合同那一刻：你已经欠了房东未来5年的租金
一年后：付第一笔钱（只是还债，不是产生义务）

义务 = 签合同那天就发生了
付钱 = 一年后才发生
```

**资产负债表是"今天"的照片。"今天"你有了这个义务，资产负债表就要反映这个义务。**

类比银行贷款：

```
银行放款日：
  你账上多了50万
  你欠银行50万
  → 资产负债表：两边同时增加
  → 这是在放款日，不是在你还钱那天

一年后你还了10万：
  → 只是还债，不是义务发生
  → 资产负债表：负债减少10万

你是一年后才还钱，但银行的负债是在放款日就入表的。
因为义务发生在放款日，不是在还钱日。

租赁同理：
  起租日（义务发生）→ 使用权资产入表，租赁负债入表
  一年后付租金 → 只是还债，不是产生义务
```

**所以问题的关键不是"未来的钱为什么要入表"，而是"义务发生在什么时候"。义务发生在签合同日，不是在付钱日。**

### 2.1 不入表时的问题

旧租赁准则下，经营租赁不入表。租了 10 年的办公室，资产负债表上什么都看不出来。

看一个对比：

```
A 公司：租了办公楼 10 年，每年租金 100 万，折现约 870 万
  → 资产负债表：什么都不体现
  → 看起来"资产少，负债也少"

B 公司：自己建了办公楼，价值 1000 万，有银行贷款 600 万
  → 资产负债表：固定资产 +1000 万，银行贷款 +600 万
  → 看起来"资产多，负债也多"

但实际上：
  A 公司虽然资产负债表"轻"，但有一个隐形的义务：
  未来 10 年还要付 900 万的租金
  → 这个义务在旧准则下看不见

B 公司的资产负债表"重"，但所有资产和负债都看得到

旧准则下：A 公司的报表看起来比实际情况"健康"
→ 这是报表失真的问题
```

**不入表的核心问题：资产负债表不完整，没有反映企业的真实财务负担。**

### 2.2 入表解决的是什么问题

新租赁准则（CAS 21 / IFRS 16）的核心目标：**让资产负债表更真实。**

```
入表之后：
  A 公司租了 10 年办公楼：
  → 使用权资产 +870 万（资产）
  → 租赁负债 +870 万（负债）
  → 资产负债表上能看到：你占用了一项资产，欠了一笔钱

现在：
  → A 公司和 B 公司的报表终于可以横向比较了
  → 同样占用办公楼资源的两家公司，财务负担一目了然
```

**入表解决的是：报表的可比性，以及报表是否真实反映企业财务负担的问题。**

### 2.3 入表的本质是什么

入表，就是把一个**隐形的义务变成显形的负债**。

```
不入表时：
  未来 10 年要付 900 万租金
  → 这个义务存在，但没有进入资产负债表
  → 只在附注里披露

入表后：
  未来 10 年要付 900 万租金
  → 今天确认租赁负债 870 万（折现值）
  → 资产负债表上显形了这笔负债
```

**入表的本质：把"隐形义务"变成"显形负债"。**

## 三、什么情况下入表，什么情况下不入表

### 3.1 入表与不入表的总框架

新租赁准则下，租赁会计分为两类：

```
第一类：大多数租赁
  → 必须入表
  → 确认使用权资产 + 租赁负债

第二类：豁免不入表
  → 短期租赁（租赁期 ≤ 12 个月）
  → 低价值租赁
  → 继续按照旧准则处理，租金直接进利润表
```

### 3.2 豁免不入表的逻辑

**短期租赁（≤12个月）：**

```
逻辑：
  → 租期很短，义务很轻
  → 12 个月后可以选择不续租，义务自动消失
  → 资产负债表的负债，反映的是"当前已确定的义务"
  → 12 个月之后的义务，还不确定是否会发生
  → 不要求入表

实际处理：
  → 租金直接进利润表（营业成本或管理费用）
  → 资产负债表不变
```

**低价值租赁：**

```
逻辑：
  → 租的东西价值很低（如办公家具、小型设备）
  → 入不入表，对报表的影响微乎其微
  → 成本效益原则：为了这点金额专门做一套入表处理，不值得
  → 所以豁免不入表

什么是"低价值"？
  → 全新的单项资产，原值通常低于 5000 美元（IFRS 16 参考标准）
  → 注意：低价值是指"单项资产"，如果大量低价值资产合并，也需要入表
```

### 3.3 租赁 vs 服务合同的区分

这个区分非常重要，但经常被忽略：

```
租赁：
  → 合同让渡了"已识别资产的使用权"
  → 客户可以在特定时期内主导资产的使用方式和使用目的
  → 例：租办公室、租设备

服务合同：
  → 对方提供的是"服务"，不是"资产使用权"
  → 例：酒店住一晚（提供住宿服务，不是租了一间房的使用权）
  → 差旅住酒店、租车出行 → 属于服务合同，不适用租赁准则
  → 直接进费用，不存在入不入表的问题
```

### 3.4 入表判断的完整流程

```
第一步：这个合同是租赁吗？

判断标准：合同是否让渡了"已识别资产的使用权"？
  → 是 → 下一步
  → 否 → 服务合同，直接进费用，无需入表判断

第二步：是否属于豁免情况？

短期租赁（租赁期 ≤ 12 个月）？
  → 是 → 豁免，租金进费用，不入表
  → 否 → 下一步

低价值租赁（单项资产原值低于门槛）？
  → 是 → 豁免，租金进费用，不入表
  → 否 → 下一步

第三步：必须入表
  → 确认使用权资产 + 租赁负债
  → 在资产负债表上同时体现
```

### 3.5 一张表总结

| 场景 | 是否入表 | 会计处理 |
|------|---------|---------|
| 租办公室 3 年 | ✅ 入表 | 确认使用权资产 + 租赁负债 |
| 租办公楼 10 年 | ✅ 入表 | 确认使用权资产 + 租赁负债 |
| 租办公楼 12 个月 | ❌ 不入表 | 租金直接进费用 |
| 租打印机（低价值） | ❌ 不入表 | 租金直接进费用 |
| 酒店差旅住几天 | ❌ 不入表 | 属于服务合同，直接进费用 |
| 融资租赁（实质转移所有权） | ✅ 入表 | 同上，但处理细节不同 |

## 四、折现的算法

### 4.1 为什么要折现

**核心原因：资产负债表是一张"今天"的照片，上面的每个数字必须是站在"今天"这个时点的值。**

```
资产负债表拍的是"今天"的快照

快照上的每一个数字：
  → 银行存款：今天账上有多少
  → 应收账款：今天客户欠多少
  → 租赁负债：今天站在这个时点，未来要付的钱折现到今天是值多少

未来第 1 年要付的 10 万 ≠ 今天值 10 万
未来第 2 年要付的 10 万 ≠ 今天值 10 万
5 年合计要付 50 万 ≠ 今天值 50 万

为什么不相等？
→ 今天有 10 万，可以存银行，1 年后变成 10.5 万
→ 未来要付的 10 万，是 1 年后的钱
→ 所以未来的钱，要"打折"才等于今天的值
```

### 4.2 单笔钱的折现

```
一年后要付 10 万，今天值多少？

存款的视角：
  今天存 9.52 万进银行，利率 5%
  一年后 = 9.52 × 1.05 = 10 万

折现的视角（反过来）：
  今天值 = 10 万 ÷ (1 + 5%) = 9.52 万

这个过程叫"折现"，5% 叫"折现率"，9.52 万叫"现值"。
```

### 4.3 每年年末付 10 万，5 年，如何折现

**逐年折现：**

```
第1年末付10万 → 今天值  10万 ÷ (1.05)^1  = 9.524万
第2年末付10万 → 今天值  10万 ÷ (1.05)^2  = 9.071万
第3年末付10万 → 今天值  10万 ÷ (1.05)^3  = 8.639万
第4年末付10万 → 今天值  10万 ÷ (1.05)^4  = 8.228万
第5年末付10万 → 今天值  10万 ÷ (1.05)^5  = 7.835万

合计 = 9.524 + 9.071 + 8.639 + 8.228 + 7.835 = 43.297万
```

**50 万是未来要付的总额，43.3 万是站在今天这笔负债值多少。**

### 4.4 年金现值系数：一步算完

每年付的金额相同，不需要逐年折现，用一个系数一次性算出来：

```
年金现值系数 = [1 - (1 + r)^(-n)] / r

r = 折现率，n = 期数

r = 5%，n = 5 年代入：
  = [1 - (1.05)^(-5)] / 0.05
  = [1 - 0.7835] / 0.05
  = 0.2165 / 0.05
  = 4.3295

租赁负债 = 10万 × 4.3295 = 432,950 元
```

**常用系数速查：**

| 期数 | 折现率 5% | 折现率 6% | 折现率 8% |
|------|-----------|-----------|-----------|
| 1年  | 0.9524   | 0.9434   | 0.9259   |
| 2年  | 1.8594   | 1.8334   | 1.7833   |
| 3年  | 2.7232   | 2.6730   | 2.5771   |
| 4年  | 3.5460   | 3.4651   | 3.3121   |
| 5年  | 4.3295   | 4.2124   | 3.9927   |
| 10年 | 7.7217   | 7.3601   | 6.7101   |

### 4.5 折现率的确定

折现率用哪个，是实际操作中最关键的问题。

```
原则：折现率 = 承租人的增量借款利率

解释：
  → 不是用房东的利率
  → 而是"如果承租人自己去找银行借一笔期限相同的钱，利率是多少"
  → 这个利率综合了：信用等级 + 借款期限 + 担保条件

为什么用承租人的利率？
  → 租赁本质上是一种"融资行为"
  → 租设备 = 用别人的钱获得了资产使用权
  → 融资成本 = 承租人自己借钱的成本

关键规律：
  折现率越高 → 未来钱的"折扣"越大 → 租赁负债越小
  折现率越低 → 未来钱的"折扣"越小 → 租赁负债越大
```

### 4.6 租赁付款额现值的完整公式

租赁负债 = 租赁付款额的现值 - 无担保残值的现值

```
公式：
  租赁付款额的现值
    = 固定付款额现值
    + 取决于指数或比率的可变租赁付款额的现值
    + 购买选择权的行权价的现值（如适用）
    + 终止选择权的行权价的现值（如适用）
    + 担保余值的现值（如适用）
  - 无担保残值的现值

简化场景（无购买/终止选择权，无可变租金）：
  租赁负债 = 固定付款额现值 - 无担保残值现值

无担保残值 = 租赁期末资产的价值，减去出租人担保的部分
  → 大多数情况下 = 0
  → 所以租赁负债 ≈ 固定付款额现值
```

### 4.7 使用权资产的入账价值

使用权资产不是简单等于租赁负债，还要加减几项：

```
使用权资产 = 租赁负债的入账价值
            + 初始直接费用
            + 预付租金（如有）
            - 已收租赁激励（如有）

其中：
  初始直接费用 = 承租人为取得租赁使用权而支付的中介费、差旅费等
  预付租金 = 起租前提前支付的租金
  租赁激励 = 房东给的优惠（如免租期），要从使用权资产中扣除

例子：
  租赁负债 = 43.3 万
  初始直接费用 = 0.5 万（付给中介的佣金）
  预付租金 = 1.0 万（起租前预付了 1 万）
  已收激励 = 0
  ─────────────────────
  使用权资产 = 43.3 + 0.5 + 1.0 = 44.8 万
```

## 五、完整分录与测算

### 5.1 背景数据

```
租办公室 5 年
每年年末付 10 万
折现率 5%
无初始直接费用
无预付租金
无免租期
无残值担保
```

### 5.2 计算过程

```
第一步：计算租赁付款额现值（租赁负债）
  折现率 = 5%，期数 = 5
  年金现值系数 = 4.3295
  租赁负债 = 10万 × 4.3295 = 432,950 元

第二步：使用权资产
  使用权资产 = 432,950 + 0 + 0 = 432,950 元

第三步：折旧
  每年折旧 = 432,950 ÷ 5 = 86,590 元
```

### 5.3 起租日分录

```
借：使用权资产           432,950
    贷：租赁负债         432,950

借贷相等，资产负债表两边同时增加
```

### 5.4 第一年末分录

每年实际付 10 万，其中一部分是本金，一部分是利息。利息 = 期初租赁负债 × 折现率，本金 = 实付金额 - 利息。

```
利息 = 432,950 × 5% = 21,648 ≈ 21,650
本金 = 100,000 - 21,650 = 78,350
租赁负债减少 = 78,350（是本金，不是全额）

第一步：计提折旧
借：管理费用-折旧      86,590
    贷：使用权资产累计折旧   86,590

第二步：时间价值摊销（利息）
借：财务费用-利息      21,650
    贷：租赁负债           21,650

第三步：支付租金
借：租赁负债          100,000
    贷：银行存款         100,000

净结果：
  租赁负债变化 = +21,650（利息）- 100,000（付款）= -78,350
  使用权资产变化 = -86,590（折旧）

注意：负债净减少（78,350）≠ 资产减少（86,590）
原因：利息部分使负债增加，只有本金部分才与折旧对应
```

**关于折旧与还本的对应关系**：

| 每月动作 | 金额 | 影响的科目 |
|----------|------|------------|
| 折旧 | 86,590 | 减少使用权资产 |
| 时间价值（利息） | 21,650 | 增加租赁负债 |
| 支付租金 | 100,000 | 减少租赁负债 |
| **净还本** | **78,350** | 租赁负债净减少 |

**折旧（86,590）≠ 还本（78,350）**，这是因为还本中包含了时间价值的调整。实际上：

```
使用权资产的变化 = 折旧 = 86,590
租赁负债的变化   = 付息(+21,650) - 付款(-100,000) = -78,350

两者不相等，因为这是"分期付款买资产"：
  你付了10万，其中2.17万是利息，7.83万是本金
  但资产原值是43.3万，按5年折旧每月只摊86,590
  
  利息部分使你的债务增加，折旧使你的资产减少
  最终两者会同步归零（折旧5年提完，负债5年还清）
```

### 5.5 五年测算汇总


### 5.6 免租期的处理

免租期（租金为 0 的期间）如何处理：

```
场景：租5年，前2个月免租，之后每年年末付10万

处理方式：
  → 免租期内虽然没有付钱，但使用权已经生效
  → 免租期也要算租金，折现进去
  → 计算方式：把免租期折算成等额的租金，加到每年的付款中

或者更简单的方式：
  → 把总租期（60个月）看作一个整体
  → 免租期（2个月）的租金"金额"为0，但"时间"在租期内
  → 实际上相当于：把"免租优惠"折算成现金价值，从使用权资产中扣除

实操中，免租期的处理比较复杂，建议以合同约定的总付款额为基础，
按实际付款频率折现。
```

## 六、三大表的因果关系

### 6.1 起租日那一刻

```
资产负债表：
  借：使用权资产 +432,950（资产增加）
  贷：租赁负债   +432,950（负债增加）
  → 资产增加，负债增加，净资产不变

利润表：
  → 没有变化（还没有发生利息和折旧）

现金流量表：
  → 没有变化（还没有付钱）
```

### 6.2 每年末付租金时

**资产负债表的变化：**

```
使用权资产：每年减少 86,590（折旧）
租赁负债：每年减少 78,350 / 82,270 / 86,383 / 90,703 / 95,244（本金额）

注意：每年减少的金额不同
→ 折旧每年相同（直线法）
→ 本金每年不同（前期少后期多，因为利息在递减）
→ 所以租赁负债的减少是"前少后多"
```

**利润表的变化：**

```
每年：
  折旧费用 -86,590（固定不变）
  利息费用 -21,650 → -17,730 → -13,617 → -9,297 → -4,756（递减）
  合计    -108,240 → -104,320 → -100,207 → -95,887 → -91,346

第一年费用最高（利息+折旧最大）
最后一年费用最低
```

**现金流量表的变化：**

```
每年实际付 10 万：
→ IFRS 16 下：租赁付款属于筹资活动现金流
  → 筹资活动现金流出 -100,000

注：不同准则版本对"租金"的现金流分类略有不同，
IFRS 16 将经营租赁租金归入经营活动；
CAS 21 将租赁付款归入筹资活动。
实操中以企业适用的准则为准。
```

### 6.3 5 年后三张表的状态

```
5年后：

资产负债表：
  使用权资产 = 0（折旧提完）
  租赁负债 = 0（本金还完）
  → 资产负债表：干干净净，租赁业务消失了

利润表：
  累计影响了约 50 万的利润（利息 + 折旧）
  → 这 50 万是 5 年分摊下来的

现金流量表：
  累计流出了 50 万
  → 这是 5 年实际付出的真金白银

为什么租赁消失了，但实际付出了 50 万？
→ 原因是：折旧和利息把使用权资产和租赁负债逐步"消化"掉了
→ 这是入表后特有的现象：
  资产和负债从有到无，但现金持续流出
```

## 七、与物业租赁系统的关联

### 7.1 系统需要录入的核心字段

```
合同基本信息：
  → 合同编号、起租日、到期日、租赁面积、地址

租赁核心条款：
  → 租赁期限（总月数）
  → 免租期（月数）
  → 付款频率（年付 / 半年付 / 季付 / 月付）
  → 每期应付租金（含税/不含税）
  → 折现率（承租人增量借款利率）
  → 是否存在购买选择权
  → 是否存在终止选择权

其他计量项：
  → 初始直接费用（中介费、差旅费等）
  → 预付租金（起租前预付金额）
  → 租赁激励（房东优惠，如免租期）
  → 无担保残值
```

### 7.2 不同付款频率对折现的影响

付款频率不同，折现系数不同：

```
年付（每年年末付 10 万，5 年）：
  → 系数 = 4.3295
  → 租赁负债 = 432,950

半年付（每半年末付 5 万，10 期，利率需换算）：
  → 实际利率 = (1.05)^(1/2) - 1 ≈ 2.47%
  → 系数 = 8.5306
  → 租赁负债 = 5万 × 8.5306 = 426,530
  → 租赁负债比年付略小（因为付款更频繁了）

月付（每月末付 0.833 万，60 期，利率需换算）：
  → 实际利率 = (1.05)^(1/12) - 1 ≈ 0.407%
  → 系数 = 51.7256
  → 租赁负债 = 0.833万 × 51.7256 = 431,000
```

**付款越频繁，租赁负债越小。** 因为每次付得少，前期积累的利息就少，整体折现值略低。

### 7.3 系统计算的核心逻辑

```
第一步：确定付款频率，选用正确的期数和折算利率

第二步：计算租赁付款额现值
  = 每期租金 × 该付款频率对应的年金现值系数
  （或有购买/终止选择权的，单独折现后相加）

第三步：计算租赁负债
  = 租赁付款额现值 - 无担保残值现值

第四步：计算使用权资产
  = 租赁负债 + 初始直接费用 + 预付租金 - 已收租赁激励

第五步：计算折旧
  = 使用权资产 ÷ 租赁期限（月）

第六步：生成每年分期测算表
  → 每期付款日、应付本金、应付利息、剩余负债、账面价值
```

## 八、常见错误与辨析

### 错误一：混淆"付款额"和"本金"

```
错误理解：
  每年付 10 万 → 租赁负债每年减少 10 万
  → 5 年付 50 万 → 负债变 0

正确理解：
  每年付 10 万，其中一部分是利息，一部分是本金
  利息 = 期初负债 × 折现率（越来越少）
  本金 = 10 万 - 利息（越来越多）
  租赁负债每年减少的是"本金部分"，不是全额
  → 第1年只减 7.8 万，不是 10 万
```

### 错误二：折旧和利息混淆

```
折旧：使用权资产的消耗，进入利润表
利息：融资成本的体现，进入利润表

两者经常一起出现，但含义不同：
  第一年：折旧 8.6 万 + 利息 2.2 万 = 10.8 万
  → 折旧是资产消耗（资产端）
  → 利息是融资费用（负债端）
  → 两者的因果不同
```

### 错误三：把折旧等同于还本

```
错误理解：
  折旧 = 还本 = 本金减少
  → 每年折旧 8.6 万 = 每年还本 8.6 万
  → 但实际租金 10 万，本金只有 7.8 万

正确理解：
  折旧 = 资产的消耗（资产端）
  还本 = 实际付了多少本金（负债端）
  
  两者虽然金额接近，但含义不同：
  - 折旧 8.6 万：资产每月消耗的价值
  - 还本 7.8 万：你每月实际偿还的本金
  - 时间价值 2.2 万：负债增加的部分

  关系：
    租金 10 万 = 还本 7.8 万 + 付息 2.2 万
    资产减少 = 折旧 8.6 万（与还本不完全相等）
  
  最终两者同步归零：
    折旧 5 年 × 8.6 万 = 43 万（使用权资产提完）
    还本 5 年 × 7.8 万 ≈ 39 万 + 利息 4 万 = 43 万（负债还完）
```

### 错误四：把免租期当作"不用管"

```
免租期不意味着不入表。

免租期内：
  → 使用权已经生效，资产和负债已经入账
  → 免租期的租金，要折现后计入使用权资产和租赁负债
  → 只不过免租期内没有实际现金流流出

所以：
  → 免租期越长，使用权资产越大（相当于少付了租金，但负债要补上）
  → 免租期是一种"隐性折扣"，要折算后才能体现真实成本
```

## 九、一句话总结

```
入表的原因：
  → 不入表时，资产负债表看不见企业的租赁义务，报表失真
  → 入表后，把"隐形义务"变成"显形负债"，报表真实可比

不入表的情况：
  → 短期租赁（≤12 个月）和低价值租赁豁免
  → 两者之所以可以不入表：义务轻或金额小，不值得复杂处理

折现的原理：
  → 资产负债表是"今天"的照片
  → 未来要付的钱，要"打折"成今天的值才能入资产负债表
  → 打折的方式：每年金额 × 年金现值系数
  → 其中，本金还款 = 实付金额 - 利息，利息 = 期初负债 × 折现率

折旧与还本的关系：
  → 折旧是资产端：每月资产消耗多少
  → 还本是负债端：每月实际偿还多少本金
  → 两者金额接近但不等：差额由时间价值（利息）填补
  → 最终两者同步归零：折旧提完，负债也还清
```

## 十、折旧与还本的对应关系

> 本节基于 §五 的 5 年案例（每年年末付 10 万，折现率 5%，租赁负债 432,950）进行说明。

### 10.1 三者的对应关系

每年租金 10 万，分解为：

| 项目 | 金额 | 对应关系 |
|------|------|----------|
| 还本 | 7.8万 | 减少「租赁负债」 |
| 付息（时间价值） | 2.2万 | 增加「租赁负债」 |
| 折旧 | 8.6万 | 减少「使用权资产」 |

**关键真相**：

| 项目 | 性质 | 现金流出？ |
|------|------|------------|
| 折旧 8.6万 | **资产减少** | ❌ 无现金流出 |
| 时间价值 2.2万 | **负债增加** | ❌ 无现金流出 |
| 租金 10万 | **实际支付** | ✅ 真实现金流出 |

**折旧和时间价值不是"额外付出"，而是对租金这个单一现金流的结构性分解。**

### 10.2 为什么折旧 ≠ 还本？

```
租赁可以类比为"分期付款买资产"：

你向出租人"借"了 43.3 万（使用权资产的价值）

每年还款 10万 = 还本 7.8万 + 付息 2.2万
              ↑        ↑
            折旧    时间价值
            (减少本金)  (支付利息)
```

**折旧 ≠ 还本**（而非相等）的原因：

```
第1年：
  折旧 = 43.3万 ÷ 5 = 8.6万
  还本 = 10万 - 利息 2.2万 = 7.8万
  差额 = 0.8万

为什么不相等？
→ 还本 = 租金 - 利息，利息每年递减（2.2万 → 1.8万 → 1.4万 → 0.9万 → 0.5万）
→ 折旧是固定的 8.6万/年

本质：
  - 折旧：从资产消耗的角度（每年固定）
  - 还本：从现金流的角度（每年递增）
  - 两者最终同步归零：
    折旧 5年 × 8.6万 = 43万（使用权资产提完）
    还本 5年累计 ≈ 39万 + 利息 4万 = 43万（负债还完）
```
