# 租赁使用权资产与租赁负债计算详解

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

---

## 一、概述

本文档总结使用权资产（Right-of-Use Asset）和租赁负债（Lease Liability）的计算逻辑，基于 IFRS 16 租赁会计准则。

**IFRS 16** 是国际财务报告准则第16号，由国际会计准则理事会（IASB）制定，于2019年1月1日生效，取代了旧的 IAS 17 准则。

---

## 二、核心概念区分

| 项目 | 性质 | 报表位置 | 计算方法 |
|------|------|----------|----------|
| **使用权资产** | 资产 | 资产负债表-资产侧 | 折旧（通常直线法） |
| **租赁负债** | 负债 | 资产负债表-负债侧 | 利息法摊销 |

两者在初始确认时金额相等，后续各自独立变化。

---

## 三、为什么需要折现

### 3.1 货币的时间价值

**今天收到100元 ≠ 一年后收到100元**

今天的100元可以存入银行或投资，一年后变成 100 × (1 + 利率)。

### 3.2 折现公式

```
现值 = 未来值 ÷ (1 + 利率)^期数
```

**举例**：年利率5%，一年后应付租金105万
```
现值 = 105万 ÷ 1.05 = 100万
```

### 3.3 会计处理的意义

| 角度 | 说明 |
|------|------|
| 经济角度 | 今天握有100万，存一年得5万利息，正好等于105万 |
| 会计角度 | 资产负债表要求两边都用"当前时点"的价值 |
| 配比原则 | 利息费用（逐年递减）+ 折旧费用（通常均匀）= 每期总费用 |

## 四、租赁负债摊销计算

### 4.1 通用公式

```
1. 计算期利率：r = (1 + 年利率)^(1/年内期数) - 1

2. 计算期初负债：
   PV = PMT × [1 - (1+r)^(-n)] ÷ r
   其中 PMT = 每期支付额，n = 总期数

3. 每期摊销：
   利息 = 期初本金 × r
   还本 = 支付额 - 利息
   期末本金 = 期初本金 - 还本

4. 循环计算直到本金为0
```

### 4.2 按年付示例

**场景**：租期2年，年末付54万，年利率5%

#### 期初负债计算
```
期初负债 = 54万 ÷ 1.05 + 54万 ÷ 1.05²
         = 51.43万 + 49.00万
         = 100.43万
```

#### 摊销明细

| 年份 | 期初本金 | 利息(5%) | 支付 | 还本 | 期末本金 |
|------|----------|----------|------|------|----------|
| 第1年 | 100.43万 | 5.02万 | 54万 | 48.98万 | 51.45万 |
| 第2年 | 51.45万 | 2.57万 | 54万 | 51.43万 | ≈ 0 |

### 4.3 按季度付示例

**场景**：租期2年，季度末付13.5万（54万÷4），年利率5%

#### 参数
| 项目 | 数值 |
|------|------|
| 季租金 | 13.5万 |
| 季利率 | (1+5%)^(1/4) - 1 ≈ 1.232% |
| 总期数 | 8期 |

#### 期初负债
```
PV = 13.5万 × [1 - (1.01232)^(-8)] ÷ 0.01232
PV ≈ 102.20万
```

#### 摊销明细

| 季度 | 期初本金 | 利息(1.232%) | 支付 | 还本 | 期末本金 |
|------|----------|--------------|------|------|----------|
| Q1 | 102.20万 | 1.26万 | 13.5万 | 12.24万 | 89.96万 |
| Q2 | 89.96万 | 1.11万 | 13.5万 | 12.39万 | 77.57万 |
| Q3 | 77.57万 | 0.96万 | 13.5万 | 12.54万 | 65.03万 |
| Q4 | 65.03万 | 0.80万 | 13.5万 | 12.70万 | 52.33万 |

### 4.4 按月付示例

**场景**：租期2年，月付4.5万（54万÷12），年利率5%

#### 参数
| 项目 | 数值 |
|------|------|
| 月租金 | 4.5万 |
| 月利率 | (1+5%)^(1/12) - 1 ≈ 0.4074% |
| 总期数 | 24期 |

#### 期初负债
```
PV = 4.5万 × [1 - (1.004074)^(-24)] ÷ 0.004074
PV ≈ 102.68万
```

### 4.5 2年一付示例

**场景**：租期2年，2年末一次性付108万，年利率5%

#### 期初负债
```
期初负债 = 108万 ÷ (1 + 5%)² = 97.96万
```

#### 摊销明细

| 年份 | 期初本金 | 利息(5%) | 支付 | 还本 | 期末本金 |
|------|----------|----------|------|------|----------|
| 第1年 | 97.96万 | 4.90万 | 0 | 0 | 102.86万 |
| 第2年 | 102.86万 | 5.14万 | 108万 | 102.86万 | 0 |

## 六、规律总结

### 6.1 支付频率的影响

```
支付越频繁 → 期初负债越高 → 每期利息越低 → 还本越快
支付越稀疏 → 期初负债越低 → 利息滚存越多 → 总利息越高
```

### 6.2 核心规律

| 现象 | 原因 |
|------|------|
| 月付期初负债最高 | 付款最频繁，本金基数最大 |
| 2年一付期初负债最低 | 只有1次支付，折现次数最少 |
| 总利息随支付频率增加而减少 | 每期还本更及时，本金减少更快 |

## 七、使用权资产 vs 租赁负债

### 7.1 租赁负债摊销（利息法）

- 随还款本金减少，利息逐年递减
- 前几年利息占比高，本金还得慢

### 7.2 使用权资产折旧（直线法）

- 通常使用直线法
- 每年折旧 = 原值 ÷ 使用年限

**举例**：使用权资产原值100.43万，折旧2年
| 年份 | 期初资产 | 折旧 | 期末资产 |
|------|----------|------|----------|
| 第1年 | 100.43万 | 50.20万 | 50.20万 |
| 第2年 | 50.20万 | 50.20万 | ≈ 0 |

### 7.3 对利润表的影响

| 年份 | 利息费用（负债侧） | 折旧费用（资产侧） | 费用合计 |
|------|-------------------|-------------------|----------|
| 第1年 | 5.02万 | 50.20万 | 55.22万 |
| 第2年 | 2.57万 | 50.20万 | 52.77万 |

**费用前高后低**，符合"前期费用大、后期小"的预期。

### 7.4 专题：未确认融资费用——利息池与恒等式

> 租赁负债的摊销需要一个“总利息靶子”，这个靶子就是**未确认融资费用**。
> 名字的三层含义、两种列示方式（净额法/总额法）与起租日分录，见同目录《从租户角度的租金入表逻辑》§3.3。

#### 7.4.1 定义式

```
未确认融资费用 = 付款合计 − 租赁负债现值
```

在起租日随初始确认**一次算出**，之后逐期摊销（借：财务费用 / 贷：未确认融资费用），租期末恰好归零。

#### 7.4.2 恒等式：Σ逐日利息 ≡ 未确认融资费用

折现率（实际利率）的定义就是“使未来付款现值恰好等于负债入账价值的利率”，于是：

```
负债现值       = Σ 付款 / (1+r)^t
未确认融资费用 = Σ 付款 − Σ 付款/(1+r)^t
              = Σ 现值 × ((1+r)^t − 1)
              = 逐日利息累计（每天“期初余额 × 日利率”，从第 1 天累计到最后一天）
```

**这是恒等式，不是经验规律**——只要“计息用的利率”与“折现用的利率”是同一个 r，两者必然相等。

| 反例 | 后果 |
|---|---|
| 折现用增量借款利率、计息用另一个利率 | Σ利息 ≠ 未确认融资费用，租期末负债无法归零，池子里挂着永不摊销的残值 |
| 逐日利息在“每天”就取 2 位小数（先舍入再进余额链） | 累计值与池子出现 0.03 元级偏差，必须靠“尾差封口”拉回 |

#### 7.4.3 数值验证（租期 1 年、每月末付 ¥1,000、年折现率 4.5% 复利）

```
日利率 r = (1.045)^(1/365) − 1 = 0.0001206015
负债现值       = ¥11,720.75
付款合计       = ¥12,000.00
未确认融资费用 = ¥12,000.00 − ¥11,720.75 = ¥279.25
```

| 检查项 | 结果 |
|---|---|
| 逐日“期初余额 × 日利率”累计（保留 10 位） | ¥279.25 ✅ 与池子严格相等 |
| 逐期摊销额之和 | ¥279.25 ✅ |
| 末期负债余额 | 0.00 ✅ |

> **精度提示**：另一组样例（季付 ¥3,400 × 4 期、年率 6%：现值 13,117.21、池子 482.79）显示——
> 逐日**取整**累计得 482.82（多 0.03，必须封口修正）；逐日保留 10 位、仅行级取 2 位则天然守恒得 482.79。
> **这是不同实现分道扬镳的关键点**：一个靠“尾差封口”，一个靠“高精度 + 末期归零”。

#### 7.4.4 工程上为什么“一开始就算”

| 用途 | 说明 |
|---|---|
| **总预算** | 整个租期的利息被它框住，后续每期只是“消耗池子”，不再重新定义 |
| **校验和** | 任何时点比较“累计已提利息 vs 池子”即可定位误差（上例：482.82 vs 482.79 → 差 0.03 → 必须封口） |
| **起租日即出报表** | 资产负债表与附注（未折现付款额到期分析）在起租日就要呈现，不能等期末再倒推 |
| **反解利率的目标函数** | 实际利率未知时（存量合同/非新签场景），需解方程 `Σ(逐日余额 × r) = 未确认融资费用`——等式右边必须先有值，“实际日利率”迭代才有靶子 |

#### 7.4.5 什么时候不需要它

| 场景 | 处理 | 原因 |
|---|---|---|
| **短期租赁（≤12 个月）** | 不折现、不挂负债、不设该科目；租金按直线法直接进费用 | 成本效益原则——利息仍然存在（示例：12 × ¥1,000、4.5% → 现值 ¥11,720.75、利息 ¥279.25），只是允许不单独核算 |
| **低价值资产租赁** | 同上 | 按“全新资产价值”判断（实务量级约 5 万元） |
| **IFRS 16 净额列报** | 表内只列现值、不单设科目 | **列报差异，不是计量差异**；概念上等价于 future finance charges |

#### 7.4.6 概念与数据落地的对应

| 概念 | 数据落地（示例：本项目测算表） |
|---|---|
| 付款合计（原值） | 租赁负债原值字段（lease_liab_ori） |
| 负债现值 | 租赁负债现值字段（lease_liab） |
| 未确认融资费用 | unconfirmed_cost = Σ租金 − Σ现值 |
| 摊销 | 逐日利息累计 + 尾差处理（末期归零 / 封口） |


#### 7.4.7 科目视角（简版）

> 概念的落地终点是**科目余额**与**报表净额**。完整科目表、借贷流水、新旧科目对照见《从租户角度的租金入表逻辑》§3.3.7，这里只给三行流水。

```
① 起租日：  借 使用权资产（现值）＋ 借 租赁负债—未确认融资费用（差额）
            贷 租赁负债—租赁付款额（付款总额）

② 每期末：  借 财务费用—利息费用
            贷 租赁负债—未确认融资费用      ← 利息池"消耗"，借方余额变小
            借 管理费用—使用权资产折旧
            贷 使用权资产累计折旧

③ 付款日：  借 租赁负债—租赁付款额
            贷 银行存款
```

| 期末验证（科目口径） | 公式 |
|---|---|
| 租赁负债账面价值 | 租赁付款额（贷）− 未确认融资费用（借）＝**现值** |
| 使用权资产账面价值 | 使用权资产（借）− 使用权资产累计折旧（贷） |
| 累计已摊销利息 | 未确认融资费用期初余额 − 期末余额（＝累计财务费用） |

三个要点：

1. **"未确认融资费用"是负债类备抵科目，余额在借方**；它抵减"租赁付款额"，两者相抵才是报表列示的租赁负债。
2. **新准则下它是"租赁负债"的二级明细**（旧准则下是独立的 `2702 未确认融资费用` 一级科目，与 `2701 长期应付款` 成对使用）——层级变了，计量逻辑未变。
3. **报表按净额列示**，且"一年内到期"部分按**现值口径**重分类至"一年内到期的非流动负债"（本金与未确认融资费用需一并搬）。


**这三个要点为什么反直觉（速解）**

| 反直觉 | 一句话拆解 |
|---|---|
| 负债类科目却挂借方余额 | 它是负债侧的"累计折旧"：主科目（贷）＋备抵科目（借）＝净额 |
| 计提利息反而让负债变大 | 摊销是"贷"这个借方科目 → 备抵减少 → 净额增加；只有付款才减少负债，且只减少"本金" |
| 报表不是科目余额相加 | 净额列示；"一年内到期"按**现值口径**重分类（本金与未确认融资费用一起搬） |

> 完整拆解（含三条线对照表、最小数值例子、常见错账与对账要点）见《从租户角度的租金入表逻辑》§3.3.8；**总额法与净额法的完整对照**（分录对照、逐期科目余额对照、术语辨义）见同文档 §3.3.4。

### 7.5 差额的成因与同类工具对比（债券一样吗）

#### 7.5.1 准确表述：差额的成因是"时间"，不是"面值"

> 租赁合同**没有"面值"**这个概念（"面值"是债券/股票的专用词，指到期偿还的本金名义金额）。租赁的对应物是**租赁付款额（未折现的合同应付总额）**。

```
未确认融资费用 = 合同名义现金流总额 − 这些现金流的现值
```

但差额的真正成因是**时间**与**折现率**，而不是金额。同样 300 元的名义付款：

| 场景 | 名义额 | 现值 | 差额（未确认融资费用） |
|---|---:|---:|---:|
| 起租日一次性付清 | 300 | 300.00 | **0.00** |
| 分 3 年付（折现率 6%） | 300 | 267.30 | **32.70** |
| 分 3 年付（折现率 8%） | 300 | 257.70 | **42.30** |

金额一分没变，差额从 0 变到 42.30。数学上：

```
差额 = Σ 每笔付款 × (1 − 1/(1+r)^t)
                   └── 这笔钱"晚付 t 期"的时间价值 ──┘
```

三条推论：**① 全部现付 → 差额 0；② 付得越晚 → 差额越大；③ 折现率越高 → 差额越大**（折现率是差额的"放大器"）。且该差额恒等于**逐期按实际利率计提的利息合计**——这正是它叫"融资费用"的原因。

#### 7.5.2 债券：同一套骨架，一处关键差异

**相同处（摊余成本法骨架完全一致）**：按未来现金流现值入账 → 每期以"期初摊余成本 × 实际利率"计息 → 差额按实际利率摊销 → 期末差额归零、摊余成本 = 面值；科目结构同为「主科目 ＋ 调整（备抵）科目」。

**不同处：债券"单独付息"，租金"本息合并"。** 由此得到统一公式：

```
差额 = 总实际利息 − 合同里明说的名义（票面）利息

租赁：合同不单列利息（租金本身就是本金＋利息的合并）→ 名义利息 = 0
      ⇒ 差额 = 全部利息        （所以是完整的"利息池"）
债券：合同单独付票面利息
      ⇒ 差额 = 实际利息 − 票面利息  （只是"利息的调整项"，即折价/溢价）
```

**三种发行情形验证**（面值 1000、3 年、年付息一次、到期还本）：

| 发行情形 | 发行价 | 面值−发行价 | 票面利息合计 | 总实际利息 | 验证 |
|---|---:|---:|---:|---:|---|
| **折价**（票面 5% ＜ 市场 8%） | 922.69 | **＋77.31** | 150.00 | 227.32 | 150 ＋ 77.31 = 227.31 ✓ |
| **平价**（票面 = 市场 8%） | 1 000.00 | 0 | 240.00 | 240.00 | 240 ＋ 0 = 240 ✓ |
| **溢价**（票面 10% ＞ 市场 6%） | 1 106.92 | **−106.92** | 300.00 | 193.08 | 300 − 106.92 = 193.08 ✓ |

折价发行摊销表（摊余成本从**发行价**爬到**面值**）：

| 期 | 期初摊余 | 实际利息(8%) | 票面付息(5%) | 期末摊余 |
|---|---:|---:|---:|---:|
| 1 | 922.69 | 73.82 | 50.00 | 946.51 |
| 2 | 946.51 | 75.72 | 50.00 | 972.23 |
| 3 | 972.23 | 77.78 | 50.00 | **≈1 000.00** |

三个推论：

1. **差额方向可正可负**：折价发行记**借方**（借到的钱少了，未来要多付）；溢价发行记**贷方**（借到的钱多了，等于预收了未来高息的补偿）。而**租赁的差额永远是正、永远在借方**——付款总在起租日之后，现值必然小于名义总额。
2. **债券差额反映的是"利率偏离"**：票面利率比市场利率低多少，差额就有多大；平价发行时差额为 0。
3. **总实际利息才是真正的融资成本**：折价发行时企业实际承担 227.31，比票面利息 150 多 77.31——这就是"票面利率偏低"的代价，藏在发行价里。

#### 7.5.3 统一框架：同类工具一张表

| 工具 | 主科目（名义额） | 调整科目（差额） | 差额含义 | 方向 |
|---|---|---|---|---|
| **租赁（新准则）** | 租赁负债—租赁付款额 | 租赁负债—未确认融资费用 | **= 总利息** | 借（恒为正） |
| 分期付款购买资产 | 长期应付款 | 未确认融资费用 2702 | = 总利息 | 借 |
| 旧准则融资租赁 | 长期应付款—应付融资租赁款 | 未确认融资费用 2702 | = 总利息 | 借 |
| **债券** | 应付债券—面值 | 应付债券—利息调整 | = 总利息 − 票面利息 | 折价→借；溢价→贷 |
| 长期借款（按合同利率付息） | 长期借款 | 无 | = 0（合同利率 = 实际利率） | — |
| *投资人镜像*：债权投资 | 债权投资—成本（面值） | 债权投资—利息调整 | 同债券（镜像） | 溢价买入→借 |
| *投资人镜像*：长期应收款 | 长期应收款 | 未实现融资收益 | = 总收益 | **贷**（资产备抵） |

**一句话记忆**：

> **差额 = 时间价值总量 − 合同里已经明说的利息。**
> 合同把利息藏在价款里（租赁、分期付款）→ 差额就是**全部利息**；
> 合同把利息单列（债券票面利息）→ 差额只是**利息的调整项**。

#### 7.5.4 对系统实现的三点启示

| # | 启示 | 说明 |
|---|---|---|
| 1 | **折现率直接决定差额规模** | 同一份租金：6% → 差额 32.70，8% → 差额 42.30。折现率口径（增量借款利率 / 内含利率）必须写进需求，否则 `unconfirmed_cost` 与每期财务费用都会漂 |
| 2 | **三数互校有理论依据** | `原值 − 备抵 = 现值` 与 `Σ逐期利息 = 初始差额` 源于同一套摊余成本逻辑，不是巧合——可直接做成对账规则 |
| 3 | **引擎可复用** | 若将来扩展债券／分期付款业务，差别只在"合同是否单列利息"这一个开关；摊余成本引擎、尾差封口机制完全通用 |

> 三个数**必须都保留**：只存现值无法支撑“未折现付款额到期分析”的附注披露。

#### 7.6 七个高频问题（FAQ）

**Q1：未确认融资费用是"现值与面值的差额"引起的吗？**

方向对，但有两处要修正：

| 修正点 | 说明 |
|---|---|
| **租赁没有"面值"** | "面值"是债券／股票的专用词（到期偿还的本金名义金额）。租赁的对应概念是**租赁付款额**（未折现的合同应付总额） |
| **成因是"时间"，不是"金额"** | 同样 300 元名义付款：起租日一次性付清 → 差额 **0**；分 3 年付（8%）→ 差额 **42.30**（详见 §7.5.1）。准确表述：**差额 = Σ 每笔付款"晚付"的时间价值** |

**Q2：债券是一样的道理吗？**

骨架完全一样（摊余成本法：现值入账 → 期初摊余 × 实际利率计息 → 差额摊销 → 期末归零；同为「主科目 ＋ 调整科目」结构），**一处关键差异**：

```
差额 = 总实际利息 − 合同明说的名义（票面）利息
  租赁：合同不单列利息 → 差额 = 全部利息（完整的"利息池"）
  债券：合同单列票面利息 → 差额 = 利息的"调整项"（折价 / 溢价）
```

由此推出两个结论：

1. **债券差额可正可负**（折价记借方、溢价记贷方）；**租赁差额恒为正、恒在借方**（付款都在起租日之后，现值必然小于名义总额）。
2. **债券差额反映"利率偏离"，租赁差额反映"全部时间价值"**——同一个公式在两种合同结构下的**不同投影**。

> **关键提醒**：债券的「面值 − 发行价」**不是**它的总融资成本。以 §7.5.2 折价例：面值 1000、发行价 922.69、差额 77.31，但**总实际利息是 227.32**（＝票面利息 150 ＋ 差额 77.31）。
> 对应地，**租赁的未确认融资费用是完整的融资成本，而债券的差额只是其中一部分**——这是两者最容易混淆的一点。

**Q3："本金越来越少、利息越来越多"——这样理解对吗？**

**对一半，取决于说的是"余额/累计"还是"当期发生额"。**

| 口径 | 指标 | 趋势 | 判定 |
|---|---|---|---|
| **余额 / 累计** | 本金（负债）**余额** | 越来越少（还本 → 递减到 0） | ✓ 对 |
| **余额 / 累计** | **累计**已确认利息 | 越来越多（每期累加，期末 = 未确认融资费用） | ✓ 对 |
| **当期发生额** | **每期利息** | **越来越少**（利息 = 期初余额 × 利率，余额在降） | ✗ 与直觉相反 |
| **当期发生额** | **每期还本** | **越来越多**（付款额固定，利息少了，本金部分就多了） | ✗ 与直觉相反 |

**数值对照**（12 期 × ¥1,000、年率 4.5%、月利率 0.36748094%、现值 11,718.21）：

| 月 | 期初余额 | 本期利息 | 本期还本 | 期末余额 | 累计利息 |
|---|---:|---:|---:|---:|---:|
| 1 | 11,718.21 | **43.06** | **956.94** | 10,761.27 | 43.06 |
| 2 | 10,761.27 | 39.55 | 960.45 | 9,800.82 | 82.61 |
| 3 | 9,800.82 | 36.02 | 963.98 | 8,836.84 | 118.63 |
| … | | ↓ | ↑ | | ↑ |
| 11 | 1,989.03 | 7.31 | 992.69 | 996.34 | 278.13 |
| 12 | 996.34 | **3.66** | **996.34** | 0.00 | **281.79** |

（三条恒等式：Σ本期利息 = 未确认融资费用 281.79 ✓；Σ本期还本 = 现值 11,718.21 ✓；Σ付款 = 12,000 ✓）

**因果链只有一条**（记住这一句即可）：

```
付款额固定 → 先还利息（期初余额 × 利率）→ 余额↓ → 下期利息↓ → 留给本金的部分↑
           ⇒ 余额递减 · 当期利息递减 · 当期还本递增 · 累计利息递增
```

**两个相关感受的澄清**：
1. "前几年都在还利息"——那是**利息占付款额的比例**在前期最高（上例首月 4.3%、末期 0.37%）；比例与绝对额都在降，两者不矛盾。
2. "前期费用重"（§7.3）的根源就是**利息递减**：折旧平坦 ＋ 利息递减 = 合计前高后低。

**Q4：站在双方角度——"对方融资给我，我有一笔钱没动"这个理解对吗？**

方向对了，但有**一处前提说错、三处因果说反**。

| 你的说法 | 判定 | 修正 |
|---|---|---|
| 一次性付款 → 未来值＝现值 → 无融资费用 | ⚠️ **前提说错** | 只在**起租日付清**时成立。"一次性"不是关键，**付款时点**才是 |
| 相对于对方，是融资给你方、有融资利率 | ✅ **经济上对** | 但对方**会计上**只在融资租赁下才体现为利息收入（见（2）） |
| 我方"有一笔钱没动"，放到付款时才付 | ❌ **主体错位** | 我方得到的是**使用权（资产）**，不是一笔现金；"留着一笔钱"是虚构的 |
| "这笔钱是有利息的" | ❌ **方向说反** | 是**我方为占用这笔钱付利息**（成本），不是我方收利息（收益） |
| "留钱生息"直觉的**成立版本** | ✅ | 延付让我方**推迟筹资**——这才是获得的"融资"；若按同一利率运作，存款增值与融资费用**互为对偶**（见（4）） |

**（1）前提修正：决定融资费用的是"付款时点"，不是"一次性还是分期"**

付款总额都是 300（折现率 8%）：

| 付款安排 | 付款总额 | 现值 | **融资费用** |
|---|---:|---:|---:|
| **起租日一次性付清** | 300 | 300.00 | **0.00** |
| 第 1 年末一次性付清 | 300 | 277.78 | 22.22 |
| 分 3 年付，每年末 100 | 300 | 257.70 | 42.30 |
| **租期末一次性付清** | 300 | 238.15 | **61.85** ← 最大 |

**反直觉但重要**：租期末一次性付清的融资费用（61.85）**比分期付款（42.30）还大**——因为它把钱推迟得最久、金额最大。所以"一次性付款没有融资费用"这句话，**只在起租日当天付清时才成立**。

**（2）对方视角：经济上对，但两侧会计并不对称**

| | 承租人（我方） | 出租人（对方） |
|---|---|---|
| 会计模型 | **单一模型**：一律资本化、一律拆利息 | **仍分两类**：融资租赁 / 经营租赁 |
| "融资"科目 | 一定有：`租赁负债—未确认融资费用` | **仅融资租赁**：`未实现融资收益`（镜像科目，金额相同、方向相反） |
| 经营租赁下 | — | **不确认利息收入**，保留资产 ＋ 租金直线法确认收入 |

这解释了**为什么实务上常常拿不到"内含利率"**：对方的会计未必体现该收益率，因此准则允许承租人退而使用**增量借款利率**。

**（3）我方视角：三处因果说反了**

| 说法 | 判定 | 修正 |
|---|---|---|
| "我方有一笔钱没动" | ❌ | 我方得到的是**使用权（资产）**，不是一笔现金；付款总额从未进入我方账户。"留着一笔钱"是虚构的 |
| "因此这笔钱有利息" | ❌ 方向反了 | 是**我方为占用这笔钱付利息**（成本），不是我方收利息（收益） |
| "费用与账上现金有关" | ❌ | 融资费用的确认**与我方账上有没有钱无关**——哪怕钱全花光甚至亏掉，财务费用照样按摊余成本法逐期确认（权责发生制 vs 收付实现制） |
| 延付让我方获得什么 | ✅ | **不必现在筹资**（融资需求被推迟到未来）——**这才是我方获得的"融资"**，代价即融资费用 |

**（4）但那个直觉有一个"成立版本"，而且有个漂亮的对偶**

若真把"本该现在付出去的钱"留出来，按**同一利率**运作，用本息去支付租金：

| 时点 | 存款余额（期初） | 本期增值(8%) | 取出付款 | 期末余额 |
|---|---:|---:|---:|---:|
| 第 1 年末 | 257.70 | 20.62 | 100 | 178.32 |
| 第 2 年末 | 178.32 | 14.27 | 100 | 92.59 |
| 第 3 年末 | 92.59 | 7.41 | 100 | **0.00** |

**存款累计增值 42.30 ＝ 租赁负债累计利息 42.30，逐期余额也完全相同。**

关键观察：**这张"存款消耗表"与租赁负债摊销表是同一张表**（257.70 → 178.32 → 92.59 → 0，利息 20.62／14.27／7.41）。

由此得到那个"有条件的真理"：

> 若把这笔钱按**同一利率**运作，它赚的利息**恰好等于**融资费用——两者互为对偶。
> 这正是"延期付款 = 融资"的数学本质：**折现率就是让"延期"变得公平的那个利率**。

**（5）为什么会计上不把它们对冲掉**

| 事项 | 科目 | 性质 |
|---|---|---|
| 负债随时间增长 | **财务费用—利息费用** | 负债侧的**成本** |
| 我方自己的钱去投资/存款 | **利息收入／投资收益** | 资产侧的**收益** |
| 我方自己的钱用于经营 | 经营收益（ROIC） | 另一回事 |

三条硬规则：

1. **不能对冲**（除准则明确允许）——赚多赚少与应付多少利息无关；
2. 会计用的利率是**租赁内含利率／增量借款利率**，**不是我方自己的投资回报率**。实际回报可能高于或低于它；高于则净受益、低于则净受损，但**账上的财务费用一分不减**；
3. 这正是"租赁是一项融资安排"的分量所在：它把"时间"明确定价了。

**一句话**：

> 不是"我们有一笔钱没动、它生了利息"，而是"**我们占用了对方的钱、要为它付利息**"。
> 前者是资产侧的收益（我方自己的钱），后者是负债侧的成本（别人的钱）——**金额可能相等，性质恰好相反**，会计上必须各记各的。

**Q5：如果所有租金在起租日一次性付清，使用权资产还有折旧吗？**

**有——而且折旧是"最多"的一种情形。**

**（1）关键：折旧的对象是"权利"，不是"欠款"**

付款只解决了负债，动不了折旧：

| 项目 | 金额 |
|---|---:|
| 使用权资产（＝全部已付租金） | **300.00** |
| 租赁负债 | **0**（不欠钱了） |
| 未确认融资费用 | **0**（没有利息可摊） |
| 年折旧（300 ÷ 3） | **100.00** |
| 财务费用（利息） | **0** |

**分录**：起租日 `借 使用权资产 300 ／ 贷 银行存款 300`；此后每月 `借 管理费用—折旧 ／ 贷 使用权资产累计折旧` **照提**。

**反直觉点**：报表上会是「**有资产、没负债**」（使用权资产 300、租赁负债 0）——完全正常，因为负债对应的"未付款"已经为零。

**类比**：预付一整年健身房年卡——钱当天付清，但每个月的会费仍要按月摊成费用；预付三年房租同理，"住三年的权利"每年消耗三分之一。

**（2）四种付款安排：总租金都是 300，只改时点**

| 付款安排 | 使用权资产 | **折旧合计** | **利息合计** | 费用形状 |
|---|---:|---:|---:|---|
| **起租日一次性付清** | 300.00 | **300.00** | **0.00** | 平的：100／100／100 |
| 第 1 年末一次付清 | 277.78 | 277.78 | 22.22 | — |
| 三年分期（每年末 100） | 257.70 | 257.70 | 42.30 | 前高后低：106.52／100.17／93.31 |
| 第 3 年末一次性付清 | 238.15 | 238.15 | 61.85 | 前低后高：98.43／99.96／101.60 |

**恒等式（恒成立）**：

> **折旧合计 ＋ 利息合计 ＝ 总租金**

300 ＋ 0 ＝ 300｜257.70 ＋ 42.30 ＝ 300｜238.15 ＋ 61.85 ＝ 300 ✓

**所以**：付款时点改变的**只是"这 300 里多少算折旧、多少算利息"**，以及**费用的形状**；**既不取消折旧，也不改变总额**。

> 通俗版：**早付钱 → 折旧多、利息少、费用平摊；晚付钱 → 折旧少、利息多、费用往后压。**

**（3）什么时候才真的"没有折旧"？**

只有两种情况，且都是因为**压根不进表**：

| 情形 | 处理 | 有没有折旧 |
|---|---|---|
| 短期租赁豁免（≤12 个月） | 租金直线法进费用 | ❌ 无（未确认使用权资产） |
| 低价值租赁豁免（全新价值 < 4 万） | 同上 | ❌ 无 |
| 一次性付清租金（正常租赁） | 进表 | ✅ **有，且折旧最多** |

（另见 §7.7 Q4"付款时点决定融资费用"；两者是同一件事的两面：**时点决定折旧与利息的配比，但不改变总额**。）

**Q6：那这笔钱在现金流量表里怎么放？（很多人会答错）**

**先给结论**：**中国口径下，租金出去的钱（含起租日一次性付清的）几乎都进「筹资活动」**——不是"投资活动"。这一点与直觉相反，也与国际口径不同。

**（1）完整分类表（中国口径）**

| 付款性质 | 现金流量表归属 | 依据 |
|---|---|---|
| 偿还租赁负债**本金** | **筹资活动** | CAS 21 第五十三条 |
| 偿还租赁负债**利息** | **筹资活动**（注意：CAS 下本金利息**都**进筹资） | CAS 21 第五十三条 |
| **起租日或之前支付的租金**（未计入租赁负债的部分） | **筹资活动** | 财政部会计司《租赁准则实施问答》（2021 年 4 月） |
| **租赁保证金** | **筹资活动**（同上口径） | 同上 |
| 短期租赁／低价值租赁的付款（含其预付租金、保证金） | **经营活动** | CAS 21 第五十三条 |

**（2）为什么进筹资？——"融资视角"**

新准则把租赁看成**一次融资**：企业相当于**先借入一笔钱（筹资流入）→ 再用这笔钱买下使用权（投资流出）**。

> 分期 3×100 的例子：3 年共 300 ≈ "借来的本金"，其中 42.30 ≈ "利息"——**两笔都是融资性质**。

但我国现金流量表**不允许用"模拟现流"**（不体现"一进一出"两笔），所以最终只体现为**一笔筹资流出**。

**（3）三个最容易错的地方**

| # | 常见错误 | 正确理解 |
|---|---|---|
| 1 | "取得资产 = 投资活动"，所以预付租金进投资 | ❌ 我国明确走**筹资**（实施问答） |
| 2 | 拿国际所模板照搬：IFRS 下**起租日前的预付款**通常列**投资活动**（属于"取得长期资产"） | ⚠️ **口径差异**：IFRS 分歧且有政策选择；**A 股／CAS 报表以筹资为准** |
| 3 | 只把"利息"放筹资、本金放经营 | ❌ CAS 下**本金＋利息一起进筹资** |

> **一句话记法**：**中国口径 = "只要能进表的租赁，租金出去的钱一律筹资"**；豁免的走经营；**投资活动基本没有租赁的位置**（除非按 IFRS 口径）。

**（4）三个场景对照（以总租金 300 为例）**

| 场景 | 经营活动 | 投资活动 | 筹资活动 |
|---|---:|---:|---:|
| 起租日一次性付清 300（正常租赁） | 0 | 0 | **−300** |
| 三年分期，每年末 100 | 0 | 0 | **−300**（按年） |
| 短期租赁豁免（12 个月，付 300） | **−300** | 0 | 0 |

**（5）配套两点**

- **利息与折旧不产生现金流**：它们进利润表，但在现金流量表**补充资料（间接法调节）中要加回／单列**。
- **非现金交易要披露**：起租日确认使用权资产与租赁负债属于**非现金交易**（"筹资活动"下的负债变动附注），现金支付的部分才进现金流量表正表。
- **出租人侧**：准则与应用指南未明确，实务通常把**收到的租金**列**经营活动流入**（经营租赁）。

**Q7：合同里"租金"和"物业费"混在一起，怎么处理？（合同分拆）**

**依据**：CAS 21 第九条、第十条。承租人**有权按"租赁资产类别"选择**是否分拆；出租人**必须分拆**。

**（1）两种选择**

| 选择 | 做法 | 适用 |
|---|---|---|
| **默认：分拆** | 租赁部分按 CAS 21；非租赁部分（物业、安保、保洁、维保、水电服务）按其他准则，**当期费用化** | 服务金额大、或想让负债与经营现金流更"干净" |
| **简化：不分拆** | 承租人按**租赁资产类别**选择，把服务费与租金**合并作为一项租赁** | 服务金额不重要、或单独价格难以获得 |

> 三个限制：① **只能按"资产类别"整体选，不能逐份合同挑**；② 符合 CAS 22 分拆条件的**嵌入衍生工具不得合并**；③ **出租人没有这个选择权**（必须分拆，按 CAS 14 分摊对价）。
> **分拆时的对价分摊**：按各租赁部分与非租赁部分的**相对单独价格**比例分摊（单独价格 = 出租人或类似供应商**单独收取**的价格）。
> **特别提醒**：**车位**若是"已识别资产"且承租人能控制其使用，则**其本身就是一项租赁**，不是服务费。

**（2）两种口径的后果（合同：租金 100／年 ＋ 物业 20／年，共 120／年，3 年，8%）**

| 对比项 | ① 分拆 | ② 不分拆 |
|---|---:|---:|
| 计入租赁付款额 | 100/年 | **120/年** |
| 租赁负债 / 使用权资产 | 257.70 | **309.25**（+51.55，+20%） |
| 年折旧 | 85.90 | 103.08 |
| 第 1 年利息 | 20.62 | 24.74 |
| 服务费处理 | 当期费用 20 | 已资本化（并入折旧） |
| **第 1 年费用合计** | **126.52** | **127.82**（前移 +1.30） |
| 三年费用总额 | 360.00 | 360.00（**总额不变**） |
| **现金流量表** | 租金→**筹资**；服务费→**经营** | **全部 120/年→筹资** |

> 不分拆的三重影响：**① 杠杆上升**（负债 +20%）；**② 费用前移**；**③ 经营现金流"净额"被改变**（服务费从经营活动被搬到筹资活动）。

**（3）系统落地提示**

若系统要实现分拆，需要一个**"合同成分"概念**：租赁成分（进租赁负债与使用权资产）／非租赁成分（当期费用），并按**相对单独价格**做对价分摊；分拆与否应作为**合同级或资产类别级的政策开关**，且**全公司口径一致、保留变更留痕**。

### 7.7 方法论专题：为什么必须站在交易对手的角度看使用权资产

#### 7.7.0 大白话版：先看这个（30 秒看懂）

**把"租赁"当成"买东西"，就通了。**

你分期买一台冰箱：

- 冰箱搬进你家 → 你多了一样**东西**
- 钱还没给完 → 你欠了**一笔债**
- **一个交易、两个结果**——谁都不觉得奇怪

**租赁一模一样，只是你买的不是冰箱，而是"未来 5 年住这套房的权利"。**

- 这项权利也是"东西"，只是**看不见摸不着**
- 付款方式也是**分期**（就是房租）

**那为什么只看我方会想不通？**

因为你自己账上只会写两行："我多了样东西，我又多了笔债。"

于是你一定会想：**"这两行都是我自己写的，这不就是自己给自己记账吗？"**
—— 你找不到那个"东西"从哪来。**因为它不在你家，在房东家。**

**看房东那一侧，一秒就通了：**

房东原本有"这套房未来 5 年的使用利益"，现在**这份利益交给你了**。

> **你多了什么，房东就少了什么。**
> **一出一进，账就平了 —— 不是凭空冒出来，是搬了个家。**

就像买冰箱：看得见冰箱从商店搬到你家，你不会问"这冰箱哪来的"。
租赁只是**搬的东西**从"冰箱"换成了"住 5 年的权利"——**搬的还是东西，只是这东西看不见。**

**一个很好用的检验办法**：

> 任何一笔账，都应该能在**对方那里找到"对家"**。
> 找不到对家的那笔账，才叫真的凭空产生。

**顺便回答"房东为什么愿意"**：对他来说这不是"租房"，是**"放贷"**——他把房子的使用价值"借"给你用 5 年，**收的利息就藏在房租里**。
所以你的房租其实分两笔：**一部分还本金，一部分付利息**（这就是 §7.4 那份"利息池"的来历）。

**但是别停在"搬了个家"这一层——下面用同一个小例子，把它走完一遍。**

**例子**：房东说，这套房未来 3 年的使用权，**一次性付清只要 257.70**；分期的话，**每年末付 100，一共 300**。你选了分期。
多出来的 **42.30**，就是你为"分期"付出的代价。

---

**第 1 步｜起租日（拿到钥匙那天）：你账上多了两样东西**

| 你得到 | 你欠下 |
|---|---|
| **未来 3 年的居住权**，值 **257.70** | **未来 3 年要付 300** |

但注意：**300 里有 42.30 是"以后才会发生的利息"，现在还没发生**。会计上不能把它当欠款算进去，也不能丢掉，于是**单独挂在一个格子里**，叫「**未确认融资费用**」。

```
你要付的钱（总额）        300.00
减：还没发生的利息        − 42.30
＝ 你现在真正欠的本金      257.70   ← 和你拿到手的居住权一样多
```

> 一句话：**你得到多少，就欠多少（本金）**；那 42.30 是"以后要付的利息"，先寄存着。

---

**第 2 步｜第一年过去：钱"长大"了**

你欠着人家的钱，一年下来这笔钱会"长大"：

```
257.70 × 8% = 20.62   ← 这就是你第一年的利息费用
```

你付出去 100，它被分成两半用：

```
付利息 20.62  ＋  还本金 79.38  =  100
```

年末你还欠：`257.70 ＋ 20.62 − 100 = 178.32`

---

**第 3 步｜三年走完：同一套算法**

| 年 | 年初还欠 | 利息（×8%） | 付款 | 其中付息 | 其中还本 | 年末还欠 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 257.70 | **20.62** | 100 | 20.62 | 79.38 | **178.32** |
| 2 | 178.32 | **14.27** | 100 | 14.27 | 85.73 | **92.59** |
| 3 | 92.59 | **7.41** | 100 | 7.41 | 92.59 | **0.00** |
| 合计 | | **42.30** | **300** | | | |

**注意两个方向**：欠的钱越来越少（257.70→178.32→92.59→0），**利息也越来越少**（20.62→14.27→7.41）——因为利息是按"年初还欠多少"算的。**欠得少，利息就少。**

---

**第 4 步｜回头看起租日那个 42.30：一分不差**

```
20.62 ＋ 14.27 ＋ 7.41 = 42.30   ✓
```

起租日"寄存"的那 42.30，**就是三年利息的总和**。它每期放一点出来变成当期利息，最后放光。

> 这就是「**利息池**」：起租日一次性注满，逐期放水，期末见底。（§7.4 讲的恒等式，说的就是这件事。）

---

**第 5 步｜居住权也在消耗：折旧**

未来 3 年的居住权，一年用掉三分之一：

```
257.70 ÷ 3 = 85.90   ← 每年折旧（"居住权用掉了一部分"）
```

冰箱用一年会旧一点；"住 3 年的权利"过一年，也就少了一年。

---

**第 6 步｜你每年在利润表上花掉多少**

> **注意（读表前必看）：这里的"费用"和"掏出去的钱"不是一回事。** 第 1 年你付了 100，但当年费用是 **106.52** —— 因为那 100 里只有 **20.62** 是利息（算费用），另 **79.38** 是还债（**不算**费用）；而折旧 **85.90** 算费用、却**不用付钱**。完整拆解见第 9 步「啊哈 ③」。

| 年 | 折旧 | 利息 | 合计 |
|---|---:|---:|---:|
| 1 | 85.90 | 20.62 | **106.52** |
| 2 | 85.90 | 14.27 | **100.17** |
| 3 | 85.90 | 7.41 | **93.31** |
| 合计 | **257.70** | **42.30** | **300.00** |

**这一步最妙**：你三年总共掏出去 300，而这 300 **分毫不差**地变成了三年的费用——只是被拆成「**本金 257.70（折旧）＋ 利息 42.30**」，而且**前高后低**（第一年最重）。


---

**第 7 步｜现在看房东那边——这才是"深入"的关键**

**如果房东那边算「融资租赁」**（实质上等于把房分期卖给你），两边几乎是**照镜子**：

| | 你 | 房东 |
|---|---|---|
| 房子未来 3 年的使用利益 | **多了** | **少了**（让渡给你了） |
| 债权／欠款 | 欠 **300**（现值 **257.70**） | 手上有"未来收 300"的债权（现值 **257.70**） |
| 利息 | 费用 **20.62／14.27／7.41** | 收入 **20.62／14.27／7.41** |
| 房子本身 | 确认"居住权"，每年折旧 **85.90** | 房子已转出，**不再折旧** |

> **你账上每一项，房东那边都有一项跟它对应。** 你的资产＝他让渡出去的东西；你的欠款＝他的债权；你的利息费用＝他的利息收入。

**但如果是「经营租赁」**（大多数商铺／办公室都是）——会出现一个更有意思的现象：

| | 你（承租人） | 房东（出租人） |
|---|---|---|
| 拆不拆利息 | **拆**：本金＋利息分得很细 | **不拆**：每年就确认 **100** 的租金收入，账上看不到那个 8% |
| 房子 | 确认使用权资产、计提折旧 | **房子还是他的**，他继续计提折旧 |
| 利率 | 用 8% 算利息 | **账上根本不体现这个 8%** |

> **同一笔交易，两边的"拆法"不一样。**
> 所以你想要的"真实利率"，**往往不在房东账上** —— 这就是为什么准则允许你自己估一个（叫「**增量借款利率**」）来算。
> 也说明：**只看我方账，你永远不知道这个利率从哪来；看了对方账，才发现对方根本没拆。**

---

**第 8 步｜所以"只站我方"为什么是死胡同**

只看你自己账上：有 257.70 的资产、300 的欠款、42.30 的"寄存"。

你会问：**这 257.70 的资产是哪来的？** —— 你自己账上**没有答案**。
答案在房东那句"一次性付清只要 257.70"里：**他愿意少收 42.30，是因为他换到了"未来 3 年稳定收租"。**

---

**一句话收尾**

> 你多付的 42.30，不是"多花的冤枉钱"，而是**借用房东的钱 3 年、付给他的租金**；
> 你的资产、欠款、利息，**每一项都能在房东账上找到对家**——
> **这就是为什么必须两边一起看。**


**第 9 步｜再深一层：三个"啊哈"**

**啊哈 ①：那 42.30 不是"利息费用"，是你实实在在买的一项服务**

起租日你其实做了**两笔采购**，只是房东把它合成了一张欠条：

| 你买到了什么 | 价格 |
|---|---:|
| 未来 3 年的使用权 | 257.70 |
| **"可以分 3 年慢慢付"这项服务** | **42.30** |
| 合计（写成一张欠条） | **300.00** |

> **「未确认融资费用」就是第二笔采购的货款。**

它逐期"交货"：每期交付一点，变成当期财务费用（20.62／14.27／7.41）。
所以它**不是凭空多出来的费用**，而是**你确实向房东买过的东西**——房东提供的融资服务。

---

**啊哈 ②：资产和负债为什么会分叉？因为准则给它们发了两把尺子**

起租日两边一样（都是 257.70），期末两边也一样（都是 0）。中间的差异从哪来？

| 年末 | 资产余额（**直线法**） | 负债余额（**实际利率法**） | 差 |
|---|---:|---:|---:|
| 起租日 | 257.70 | 257.70 | 0 |
| 第 1 年 | 171.80 | **178.32** | −6.52 |
| 第 2 年 | 85.90 | **92.59** | −6.69 |
| 第 3 年 | 0.00 | 0.00 | 0 |

因为：**资产用"直线法"（每年固定消耗 85.90）**，**负债用"实际利率法"（前期利息多、还本少）**。

**做个思想实验：给资产也发同一把尺子**——每期"用掉" ＝ 付款 − 当期的利息：

| 年 | 付款 | 利息 | 消耗（＝付款−利息） | 资产余额 | 负债余额 |
|---|---:|---:|---:|---:|---:|
| 1 | 100 | 20.62 | 79.38 | → **178.32** | → **178.32** |
| 2 | 100 | 14.27 | 85.73 | → **92.59** | → **92.59** |
| 3 | 100 | 7.41 | 92.59 | → **0.00** | → **0.00** |

**两列完全相等，一分不差。**

> 这说明：**资产和负债中间分叉，不是经济实质不同，而是"给它们发了两把不同的尺子"。**
> （实务上准则用直线法，所以会分叉——这是理解 §7.3「前高后低」的钥匙，不是让你去改账。）

---

**啊哈 ③：租赁不改变你的总费用，只改变它的"形状"**

> **读表前先记住一句话：付款 ≠ 费用。**（这一条不过，下面这张表一定看不懂）
>
> - 你付的 **100** 里，只有 **20.62** 是"付利息" → **算费用**；另外 **79.38** 是"还债" → **不算费用**（只是欠条变短了）
> - 另有一笔 **85.90** 的折旧 → **算费用，但一分钱也不用付**

| 年 | 现金付出 | 会计费用 | 差 |
|---|---:|---:|---:|
| 1 | 100 | **106.52** | +6.52（先多认） |
| 2 | 100 | **100.17** | +0.17 |
| 3 | 100 | **93.31** | −6.69（后少认） |
| **合计** | **300.00** | **300.00** | **0** |


**为什么会多出来？把上面那 100 拆开看：**

**那 100 到底去哪了（以第 1 年为例）**

```
你付出的 100
├─ 79.38 → 还债（欠条 257.70 → 178.32）…… 【不是费用】
└─ 20.62 → 付利息 ………………………………… 【是费用】
```

- **还债不是费用**：欠条变短是"负债减少"，不是"钱花掉了"。如同还房贷本金——开销早在借款那天记过了。
- **另有一笔费用，不花一分钱**：你买的"3 年居住权"每年在消耗，`257.70 ÷ 3 = 85.90`，这就是折旧。

| | 金额 | 走不走现金 |
|---|---:|---|
| 利息 | 20.62 | ✅ 在那 100 里 |
| **折旧** | **85.90** | ❌ **不走现金** |
| **当年费用** | **106.52** | 比 100 多 6.52 |

> 所以那 100 **只含了一部分费用**（利息 20.62）；折旧 85.90 **根本不在那 100 里**。

**一个恒等式看穿三年**：

> **费用 − 现金 ＝ 折旧 − 还本**

| 年 | 折旧 | 还本 | 费用 − 现金 |
|---|---:|---:|---:|
| 1 | 85.90 | 79.38 | **+6.52**（折旧跑得快） |
| 2 | 85.90 | 85.73 | **+0.17**（快追平） |
| 3 | 85.90 | 92.59 | **−6.69**（还本反超） |
| 合计 | **257.70** | **257.70** | **0** |

**前期折旧（85.90）比还本（79.38）跑得快 → 费用超过现金；后期还本反超 → 费用低于现金；三年合计完全追平。**
这与"啊哈 ② 两把尺子"是同一件事：**资产按自己的节奏消耗，债务按自己的节奏偿还**，两者节奏不同，中间就会错开。

**两句生活类比，记住就不会再混**：

- **买冰箱**：今天花现金 3000 把冰箱搬回家 → **当天的费用是 0**（冰箱是资产，以后每年折旧才是费用）。
- **发工资**：员工干了一个月、工资下月才发 → **费用已经发生，钱还没付**。

> **付钱那天不一定有费用；有费用那天不一定付钱。**
> 这就是会计按"什么时候真正发生"记账，而不是按"钱包进出"记账。

> 一句话：**租赁不改变总成本，只把成本往前搬**——而房东那边，是把**收入**往前搬。
> **两边都改形状、都不改总量。**

> **一句话结论**：使用权资产不是一个"内部生成"的科目，而是一个**镜像项**——它的**存在理由、金额依据、存续期限**都写在**交易对手那一侧**的账上或合约里。只开我方的账，等于只开了一半的账。

#### 7.7.1 只站我方视角：一条走不通的路

起租日那笔分录（本系统示例合同 PROP-2024-001）：

```
借：使用权资产—办公楼              ¥2,106,906
    租赁负债—未确认融资费用          ¥210,843
  贷：租赁负债—租赁付款额                 ¥2,282,749
      银行存款（初始直接费用）               ¥35,000
```

如果**只**看我方这一侧，会立刻撞上四个问题，而且在**我方账内永远解不开**：

| # | 死结 | 为什么在我方账内无解 |
|---|---|---|
| 1 | 设备还在对方手上，我方没有实物，**凭什么确认"资产"**？ | 资产的三要素（控制、未来经济利益、可计量）在本方账上找不到来源 |
| 2 | 金额 **¥2,106,906 从哪来**？ | 现值依赖折现率，而折现率的依据（内含利率）是**对方的报酬率**，不写在我方账上 |
| 3 | 资产和负债**同时增加，是不是"自己给自己记了一笔"**？ | 净额一看更懵：资产 2,106,906 vs 负债净额 2,071,906，**不相等**（差 ¥35,000 初始直接费用） |
| 4 | 我方没有实物，**为什么要计提折旧**？ | 折旧的对象不是实物，是**权利**；而权利的存续期由**对方的让渡期／合约条款**界定 |

> **方法论**：复式记账的本质是"**每一笔分录都能在交易对手处找到镜像**"。找不到镜像的分录，才是真的"凭空产生"。使用权资产恰恰是**最典型的镜像项**——它的答案不在我方账内。

#### 7.7.2 站到对方一侧：租赁的本质是一次"权利让渡"

一句话：**对方把"未来 N 年的使用收益"这一束权利让渡给我方，我方用"未来 N 年的租金支付义务"把它换进来。**

- 对方原本持有**完整资产** → 其中包含"未来 N 年的使用收益"
- 租赁 = 把这束未来收益**转让**给我方（换取租金的债权）
- 所以：**对方让渡出去 → 我方取得进来**。**有出才有进，不是凭空产生**

**最有力的对照：换个交易标的想一想。**

如果对方是把设备**直接卖**给我方（而不是租），双方一样要记账、一样镜像，可谁都不会问"资产凭空产生吗"——因为看得见**实物在搬家**。

> 租赁只是把"搬家的标的"从**实物**换成了**使用权**：**搬的仍然是东西，只是这东西是一项权利。**

#### 7.7.3 一笔交易、两本账：完整镜像表

以本系统示例合同 PROP-2024-001（现值 ¥2,071,906、付款额合计 ¥2,282,749、初始直接费用 ¥35,000）：

| 交易要素 | 出租人（对方） | 承租人（我方） |
|---|---|---|
| 让渡的使用收益 | 付出 → **减少** | 取得 → **增加**：使用权资产 **2,106,906** |
| 对价债权／债务 | 应收融资租赁款 **2,071,906**（借） | 租赁负债 **2,071,906**（贷） |
| 未实现的利息 | **未实现融资收益**（贷，备抵） | **未确认融资费用**（借，备抵） |
| 期间利息 | 利息收入（前高后低） | 财务费用—利息费用（同额、同节奏） |
| 标的资产本体 | 融资租赁：转出；经营租赁：保留并计提折旧 | 不确认实物，确认使用权资产并计提折旧 |
| 现金流 | 收租金 2,282,749 | 付租金 2,282,749 |

> **镜像的严格条件**：出租人的应收融资租赁款 = **租赁收款额现值 ＋ 未担保余值现值**，其内含利率使该现值等于「标的资产公允价值 ＋ 出租人初始直接费用」。**只有双方使用同一利率、且无未担保余值时**，两侧数字才逐项相等。
> 另注意：我方的 **¥35,000 初始直接费用在对方侧没有对应项**——这正是"镜像"**不等于**"完全相同"的例子。

#### 7.7.4 对方视角一次性解开我方视角的四个死结

| 我方视角的死结 | 对方视角的答案 |
|---|---|
| ① 资产从哪来 | 对方**让渡**了未来 N 年的使用收益；我方取得的权利是**独占的**（可排斥他人使用）→ 满足资产定义（控制 ＋ 未来经济利益） |
| ② 金额从哪来 | 该让渡的**对价**在起租日按时间价值折现 = 现值。**折现率不是我方单方面定的，是对方的交易条件** |
| ③ 为什么不是"自我循环" | 资产侧回答"**我拿到了什么**"（使用权）；负债侧回答"**我拿什么换的**"（租金义务）。**有得有失 → 有借有贷** |
| ④ 折旧从哪来 | 折旧的对象是**权利的消耗**；权利存续期由对方的让渡期／合约条款界定（租期 vs 剩余使用寿命） |

#### 7.7.5 更精彩的一点：对方的分类**不决定**我方的确认

| 对方的会计分类 | 对方怎么做 | 我方怎么做 |
|---|---|---|
| 融资租赁 | 终止确认资产，确认**应收融资租赁款**，确认利息收入 | 确认使用权资产与租赁负债（与对方应收款镜像） |
| **经营租赁** | **不出表**：继续确认资产、计提折旧、按直线法确认租金收入 | **仍然确认使用权资产与租赁负债** |

看第二行：对方不出表、不确认利息收入，**但我方照样入表**。这正说明——

> **我方的确认依据是"使用权是否已被让渡"，不是"对方把它归为哪一类"。**

这条顺带解释了两件事：

1. 为什么 CAS 21／IFRS 16 对承租人采用**单一模型**——它与出租方的分类**脱钩**；
2. 为什么实务上**很难拿到"内含利率"**——对方（尤其经营租赁）的账上根本不体现这个收益率 → 准则允许承租人退而使用**增量借款利率**（见 §7.6 Q4）。

#### 7.7.6 可操作的复核红线

> **任何一笔使用权资产，都应当能在交易对手的账上（或合约里）找到它的"出处"。**

找不到出处时，按顺序问四个问题：

1. **对方到底让渡了什么？** —— 标的、期限、独占性（有没有共用、限制用途）
2. **对价是多少、什么时候付？** —— 决定付款额与现值
3. **对方为什么愿意接受这个价格？** —— 校验内含利率／增量借款利率的合理性
4. **有没有附加条款改变让渡的实质？** —— 返租、回购、续租／终止选择权、担保余值

#### 7.7.7 一句话

> 使用权资产不是我方"自己长出来的"资产，而是**对方让渡使用收益之后、落在我方账上的镜像**。
> 只开我方的账，看到的是一笔**自己贷自己的分录**；把对方的账一并打开，看到的是一笔**有出有进的交易**。
> **死胡同的出口，在对方的账上。**

## 八、IFRS 16 简介

### 8.1 准则发展

| 时间 | 准则 | 说明 |
|------|------|------|
| 1982年 | IAS 17 | 旧租赁准则，区分经营租赁和融资租赁 |
| 2016年1月 | IFRS 16 发布 | 取消经营租赁区分 |
| 2019年1月1日 | IFRS 16 生效 | 对大多数企业强制适用 |

### 8.2 主要变化

| 项目 | IAS 17（旧） | IFRS 16（新） |
|------|--------------|---------------|
| 经营租赁 | 不进报表，只在附注披露 | 确认使用权资产和租赁负债 |
| 融资租赁 | 进报表 | 被 IFRS 16 合并处理 |
| 承租人视角 | 区分两类 | 统一处理 |
| 出租人视角 | 基本保持不变 | 变化较小 |

### 8.3 初始确认公式

```
使用权资产 = 租赁负债
           + 预付租金
           - 已享受的租金优惠（如免租期）
           + 初始直接费用
           + 复原成本估计
```

> **四块砖逐块详解**：§8.4 第一块（租赁负债现值）｜§8.5 第二块（已付租金与租赁激励）｜§8.6 第三块（初始直接费用）｜§8.7 第四块（复原成本）。
> **利息怎么算**：§8.8——四块砖背后有几条负债，就有几条利息线。
> **为什么四块加起来 ≠ 租赁负债**：§8.9——资产按"全部代价"、负债只记"还欠着的"。
> **折旧和负债是否同时消耗完**：§8.11——不同步；只在两个端点重合，中间必然分叉（含可检验恒等式）。
> **一边归零、另一边还在**：§8.12——五种正常情形（付清／行权／豁免／减值／转租）＋三种错账＋系统三条监控规则。
> **复原成本现值与租赁负债现值为什么算法不同**：§8.13——折现是同一把尺子；差的是现金流形状（单笔 vs 分期）、金额来源与折现率。
> **复原也要折现吗**：§8.14——要，除非货币时间价值影响不重大；含"重大性"三个尺度、折现与不折现的对照、三个易错点。
> **资产怎么"变成"费用**：§8.15——折旧只是四条出口之一（折旧／摊销／折耗／结转成本，外加减值／处置两个一次性出口）；折现后"进资产 ↔ 走利息"两段路。

### 8.4 第一块砖 · 租赁负债现值：为什么按现值，而不是合同上要付的总额？

**一句话**：资产要按「取得使用权付出的**经济代价**」计量，而未来的租金必须**折回今天**才是代价——这就是现值。合同总额 2,282,749 里有 **210,843 是"还没发生的时间价值"**，不属于今天的资产成本。

**三步机理**（PROP-2024-001：20 期租金、折现率 5%）：

1. **折**：未来每期租金按折现率折回起租日 → 加总 **2,071,906**（＝① 砖，进使用权资产）；
2. **留差**：合同总额 − 现值 ＝ **210,843** → 记成备抵科目 `租赁负债—未确认融资费用`（＝**整个租期的利息"池子"**）；
3. **消耗**：租期内逐期从"池子"里转入 `财务费用—利息费用`（实际利率法）——负债**净额**随之长大（利息滚入），付款时再冲减。

**数字自证**：2,282,749 − 2,071,906 ＝ **210,843**，它正是租期利息费用的**合计**（"池子恒等式"）。与图二平衡式一致：**2,106,906（资产）＋ 210,843（池子）＝ 2,282,749（付款总额）＋ 35,000（初始直接费用）**。

**如果误按总额入资产**：

| 同一份合同 | 正确：资产按现值 | 错误：资产按总额 |
|---|---:|---:|
| 使用权资产 | 2,106,906 | 2,317,749 |
| 月折旧（60 期平摊） | 35,115 | 38,629（虚增 3,514/月） |
| 租期利息合计 | 210,843 | 210,843（照旧要确认） |
| **租期费用合计** | **2,317,749** | **2,528,592**（多计 210,843） |

> 错在：把"未来的利息"先当成本存进资产 → 它随折旧再进一次费用，而租期内利息又按实际利率法进一次 → **同一个 210,843 被计了两遍**。

**顺带解开一个疑惑**：起租日资产 2,106,906 vs 负债净额 2,071,906，差 **35,000** 不是错——那是第三块（初始直接费用）。忽略第二、三、四块时，"资产 ＝ 负债"才成立。

### 8.5 第二块砖 · 已付租金与租赁激励：为什么不折现、为什么要减？

**两条规则**：① 起租日**或之前**已付的租金 → 按**实付金额**直接加，**不折现**；② 已享受的租赁激励 → **减**（不是加）。

**为什么已付的不折现**：折现的作用是把"未来的钱"换算成"今天的钱"；起租日（或之前）付掉的钱**本来就是今天的钱**——折现因子 ＝ 1，折了等于没折。准则也要求按**实际支付金额**计入资产成本。

> 还有一层：已付的钱**不进租赁负债**——义务已经清掉了，再进负债就等于"把付过的钱又欠一遍"。

**为什么激励要减**：激励是出租人"还给你"的部分，**实质降低了取得使用权的净代价**。它有两种形态：

| 形态 | 例子 | 怎么处理 |
|---|---|---|
| **现金／补贴** | 装修补贴、搬迁补助 5,000 | 收到时 **借 银行存款 ／ 贷 使用权资产**（直接冲减资产） |
| **让利／免租** | 免租期（本项目合同 2024-07～09） | **不单独做账**：付款计划里这几个月就是不排钱（不进负债） |

**免租期的一个准则变化**：旧准则（经营租赁）下免租期这类激励要在租期内**直线摊销**；新准则**不再单独处理**——它就是"这几个月的付款额 ＝ 0"，好处体现在更低的付款总额与负债上。本项目这 3 个月**只计息、不提现金**，所以图二 ⑰ 卡的月度表里"免租期利息反而在涨"。

**准则应用指南算例**（起租日付首期 50,000、剩余 9 期 × 50,000、折现率 5%、初始直接费用 20,000、收到激励 5,000）：

| 组成 | 金额 |
|---|---:|
| ① 剩余 9 期租金现值（450,000 按 5% 折现） | 355,391 |
| ② 起租日已付第 1 期（**不折现**） | +50,000 |
| ③ 初始直接费用 | +20,000 |
| ④ 已收到的激励 | −5,000 |
| **＝ 使用权资产** | **420,391** |

**三个坑**：① 把起租日已付的租金**也塞进负债去折现**（＝把付过的钱又欠一遍：负债虚增、资产重复）；② 激励**方向记反**（误加进资产，虚增 2 倍）；③ 起租日**之前**预付的租金，一直挂在"预付账款"忘了转到使用权资产。

> 图解版见同目录《一图看懂_使用权资产全生命周期.html》第 ② 卡「四块砖」（含"四块砖逐个说清楚"对照表与第一～第四块逐块详解）。

### 8.6 第三块砖 · 初始直接费用：为什么要资本化

**资本化是什么意思**：把一笔支出**先记成"资产"**，以后再分期转成费用。它不改变"什么时候掏钱"，改变的是这笔钱**在哪几期进利润表**——先挂在资产上，随利益被一点一点用掉，再逐期转成费用（对使用权资产，就是跟着 60 个月折旧进管理费用）。**不是"不认费用"，而是"晚点认、分期认"。**

一句话判据：**资产 ＝ 还没用完的成本；费用 ＝ 已经用完的成本。**

**为什么必须资本化（三条理由）**：

1. **它买的是"未来整个租期（60 个月）的使用权"，不是"当月的服务"**——佣金、律师费是为了把这份 5 年合同签下来；**利益跨 60 个月，成本就摊 60 个月**（配比）。
2. **不签这份合同，这笔钱就不会发生**（**增量成本**）——它与租金同属"取得使用权的代价"：租金按"折旧 ＋ 利息"摊，它也按"折旧"摊。
3. **准则明文规定**——CAS 21 第十六条将"初始直接费用"列为使用权资产成本的组成部分（应用指南科目说明：借记"使用权资产"、贷记"银行存款"）。

**同一笔 35,000 的两种走法**：

| 对比 | 资本化（正确） | 费用化（错误） |
|---|---:|---:|
| 起租日 | 使用权资产 +35,000 | 管理费用 35,000（立刻出表） |
| 第 1 年损益 | −7,000（折旧 35,000÷5） | **−35,000** |
| 第 2–5 年每年 | −7,000 | 0 |
| 5 年累计 | −35,000 | −35,000（**总额一样**） |
| 折旧基数 | 2,106,906（含） | 2,071,906（偏小） |
| 资产负债率 | 正常 | **虚高**（资产少 35,000） |

> 费用化的后果：**费用被前移**——起租当年利润被独吞一块（−35,000 vs −7,000），后 4 年反而虚高（无折旧可提）；资产偏小、负债不动，**资产负债率与 ROE 都被扭曲**，且与"权利在逐月消耗"的事实不配比。

**资本化的边界**：判据只有一句——**"不签这份合同，这笔钱还会不会发生？"** 不会 → 资本化（佣金、律师费）；会 → 当期费用（差旅费、内部员工工时不因这单而增减）。印花税实务上有"随合同成本资本化"与"计入税金及附加"两种做法，本项目按前者、并保持全公司一致。

**系统落地**：35,000 应作为**合同层字段**进入使用权资产原值并参与折旧基数；否则"使用权资产 2,106,906 ＝ 租赁负债 2,071,906 ＋ 35,000"这条勾稽就断了（见 §7.7.1 第 3 条死结与附·系统落地"三数互校"）。

### 8.7 第四块砖 · 复原成本：四块砖里最容易被忽略的一块

**一句话**：承租人为「拆卸及移除租赁资产、复原租赁资产所在场地、或将租赁资产恢复至租赁条款约定状态」预计将发生的成本，按**现值**计入**使用权资产**，同时贷记**预计负债**（2801）——**不是**租赁负债。

**依据**：CAS 21 第十六条第（四）项；计量按**《企业会计准则第 13 号——或有事项》**（现值为最佳估计）；**为生产存货而发生的，适用存货准则（CAS 1），不进使用权资产**。实务中最常见的场景是**装修租入**（合同约定退租时恢复原状）。

**判断三条件**（同时满足才确认）：① 合同或法律**要求**拆卸／恢复；② 义务**由本次租赁产生**（已构成现时义务）；③ 金额**能可靠估计**（不能可靠估计 → 不确认，但须在附注中说明）。

**为什么记的是现值（34,029），而不是将来要付的 50,000？**

起租日只认**现值**：34,029 ＝ 50,000 ÷ 1.08⁵，资产侧加 34,029、负债侧加 34,029——**同一天、同金额、都是现值**。差额 **15,971** 不是漏记，而是**时间价值**：随时间推移**逐年以贴息补上**（借 财务费用 ／ 贷 预计负债），到第 5 年末正好把预计负债顶到 50,000。它属于**融资性质**的费用，**不资本化进使用权资产**，各期进损益。

依据：CAS 13 第六条——货币时间价值影响重大的，应按未来现金流出的折现值确定最佳估计数；CAS 13 应用指南——预计负债通常等于未来应支付金额，但与现值相差较大的，应按未来应支付金额的现值确定（弃置费用即典型例子）。

**与租赁负债的对照（两副"外壳"、同一个内核）**：

| 对照 | 租赁负债（欠出租人） | 预计负债（将来付施工方） |
|---|---|---|
| 起租日贷方金额 | **总额** 2,282,749（租赁付款额） | **现值** 34,029 |
| 有备抵科目吗 | 有：`未确认融资费用` 210,843（借） | **没有**——直接按现值立账 |
| 报表列示 | 租赁付款额 − 未确认融资费用 ＝ 净额 | 账面余额本身就是"现值滚存"数 |
| 时间价值进损益的路径 | 摊销未确认融资费用 → 财务费用 | 贴息 → 财务费用 |
| 什么时候掏钱 | 租期内逐期付 | 期满一次付 |

> 两条负债、两副外壳，**内核一样：起租日只认现值，差额在租期内以财务费用消耗完**。外壳不同源自科目设置——应用指南为租赁负债设了"租赁付款额／未确认融资费用"两个明细（总额 ＋ 备抵），复原义务没有这种明细设置。折现率口径：反映货币时间价值与相关风险的折现率，实务常与租赁折现率取同一口径（本例 8%）。
**账务三段**（租期 5 年、预计第 5 年末支出 50,000、折现率 8%；现值 50,000 ÷ 1.08⁵ ＝ 34,029）：

| 时点 | 分录 | 金额 |
|---|---|---|
| 起租日 | 借：使用权资产 ／ 贷：预计负债 | 34,029 |
| 每期末 | 借：财务费用—利息费用 ／ 贷：预计负债 | 2,722 → 2,940 → 3,175 → 3,429 → 3,705 |
| 第 5 年末 | 借：预计负债 ／ 贷：银行存款 | 50,000（实际与预计有差 → 差额调当期损益） |

**预计负债滚存表**：

| 年度 | 期初预计负债 | 当年贴息（财务费用） | 期末预计负债 |
|---|---:|---:|---:|
| 起租日 | — | — | 34,029 |
| 第 1 年 | 34,029 | 2,722 | 36,751 |
| 第 2 年 | 36,751 | 2,940 | 39,691 |
| 第 3 年 | 39,691 | 3,175 | 42,866 |
| 第 4 年 | 42,866 | 3,429 | 46,295 |
| 第 5 年 | 46,295 | 3,705 | **50,000** |

**恒等式**：折旧（本金 34,029，按租期 5 年、每年 6,805.80）＋ 财务费用（贴息 15,971）＝ 未来实际支出 **50,000**——与租赁的「**折旧 ＋ 利息 ＝ 总租金**」是同一个骨架。

**估计变动**：预计负债**减少** → 以资产账面价值为限扣减资产成本，超出部分计入当期损益；**增加** → 增加资产成本（参照固定资产弃置费用的处理原则）。此外，**每个资产负债表日都应复核**该项预计负债（CAS 13 第十二条），有确凿证据表明账面价值不能反映当前最佳估计数的，按当前最佳估计数调整。

**三个常见坑**：① 把复原成本当租金计入**租赁负债**（错：租赁负债＝欠出租人的租金，预计负债＝将来付给施工方的复原费，两条义务、两个对方）；② 起租日不计、实际拆除那年一次进费用（资产少一块、费用跨期错配）；③ 忘了每期**贴息**（预计负债停在现值，到期不够付）。

**与「装修支出」分开记**：装修支出本身 → `长期待摊费用—租入固定资产改良支出`（按租期孰短摊销，**不进使用权资产**）；「退租时把装修拆掉」的成本 → 复原成本（进使用权资产、贷预计负债）。

### 8.8 四块砖都进使用权资产，利息怎么算：两条利息线

**关键**：利息**不是算在资产上，而是算在负债上**。资产侧只有**一条折旧线**（把四块砖一起摊掉）；利息要看每块砖**背后还有没有"欠着的钱"**。

| 砖 | 背后有钱欠着吗 | 有没有利息 |
|---|---|---|
| ① 租赁负债现值 | 欠出租人（分期付） | **有**：租赁负债利息（＝池子 94,609） |
| ② 已付租金 | 不欠了（起租日已付清） | **无** |
| ③ 初始直接费用 | 不欠了（已付现结清） | **无** |
| ④ 复原成本现值 | 欠（将来付给施工方）→ 预计负债 | **有**：预计负债贴息（＝38,609） |

**两条利息线各自滚动**（都按实际利率法，但余额口径不同）：

- ① 的余额 ＝ **租赁付款额 − 未确认融资费用**（净额）→ 利息 **借 财务费用 ／ 贷 未确认融资费用**
- ④ 的余额 ＝ **预计负债**（现值滚存数）→ 贴息 **借 财务费用 ／ 贷 预计负债**

**接着 §8.6 的算例，把 ④ 也加上**（租期 10 年、第 10 年末复原支出 100,000、折现率 5% → 现值 100,000 ÷ 1.05¹⁰ ＝ 61,391）：

| 构件 | 金额 | 说明 |
|---|---:|---|
| ① 租赁负债现值 | 355,391 | 剩余 9 期×50,000 按 5% 折现 |
| ② 起租日已付租金 | 50,000 | 不折现，直接加 |
| ③ 初始直接费用 | 20,000 | 已付现 |
| ② 扣减：租赁激励 | −5,000 | 收到即冲减资产 |
| **④ 复原成本现值** | **61,391** | 贷：预计负债（新增的这块） |
| **＝ 使用权资产（折旧基数）** | **481,782** | 年折旧 ＝ 481,782 ÷ 10 ＝ 48,178.20 |

| 年度 | ① 租赁负债净额 | ① 利息 | ④ 预计负债 | ④ 贴息 | 两条线合计 |
|---|---:|---:|---:|---:|---:|

**恒等式（推广版"折旧 ＋ 利息 ＝ 总付出"）**：折旧 **481,782** ＋ 租赁负债利息 **94,609** ＋ 预计负债贴息 **38,609** ＝ **615,000** ＝ 现金总流出（租金 500,000 ＋ 初始直接费用 20,000 − 激励 5,000 ＋ 复原支出 100,000）。**四块砖一个不多、一个不少，全部在租期内转成费用。**

**三个提醒**：① 这两笔利息**都不进使用权资产**（资产只有折旧线）；仅当使用权资产用于建造"符合资本化条件的资产"时，利息才可改记 `在建工程`；② 两条线利率**可以不同**——④ 用反映其自身风险的折现率，实务上常与 ① 取同一口径（本例 5%）；③ ④ 的贴息**必须记"预计负债"**，不能塞进"未确认融资费用"科目——那个科目只属于租赁负债。

### 8.9 四块砖加起来为什么不等于租赁负债

**因为它俩是两种口径**：准则对**资产**用"**成本（全部代价）**"口径（CAS 21 第十六条：四项之和），对**负债**用"**现时义务**"口径（第十七条：起租日尚未支付的租赁付款额的现值）。四块砖里只有 **①** 对应租赁负债——②③ 已付清、④ 形成的是**预计负债**。**所以"资产 ≠ 租赁负债"是常态，不是错账。**

**把"钱从哪来"列清楚**（本系统合同 PROP-2024-001）：

| 使用权资产的钱从哪来 | 金额 | 性质 |
|---|---:|---|
| 租赁负债（欠出租人，①） | 2,071,906 | 负债科目：租赁负债 |
| 预计负债（欠施工方，④） | — | 负债科目：预计负债 |
| 已付现金（②③ 净额） | 35,000 | 自己的钱：银行存款（已流出） |
| **＝ 使用权资产** | **2,106,906** | **资产 ＝ 各项来源之和** |

换成"四块全用"的算例同样成立：**355,391（租赁负债）＋ 61,391（预计负债）＋ 65,000（已付现金净额）＝ 481,782（使用权资产）**。

**拿买房一对就懂**：房价 300 万 ＝ 首付 100 万（自己的钱）＋ 房贷 200 万。**房子记 300 万、贷款只记 200 万**——差 100 万是你已经付出的，没人会说"账错了"。租赁只是把"首付"换成"已付租金＋初始直接费用"，把"另一笔借款"换成"预计负债"。

**什么时候才"资产 ＝ 负债"**：当 ②③④ 全为 0（不预付、无初始直接费用、无复原义务）时——图一的最小例子（3 年×100、8%）正是这种特例（两边都是 257.70）。现实中很少见。

**最后用分录验一遍**（本系统合同）：借方 使用权资产 2,106,906 ＋ 未确认融资费用 210,843 ＝ 2,317,749；贷方 租赁付款额 2,282,749 ＋ 银行存款 35,000 ＝ 2,317,749——**借贷相等，账是平的**。要检查的等式是"借方 ＝ 贷方"，不是"资产 ＝ 负债"。

### 8.10 附：为什么把四要素比作"砖"

比喻要同时说清三件事，才配得上"砖"这个字：

| 比喻要素 | 会计上的对应 |
|---|---|
| **可数** | 成本由四个有名有姓的部件组成，不是"啪"地一个数（CAS 21 第十六条逐项列示） |
| **可加** | 成本 ＝ 四块相加（加法关系） |
| **砌成一体** | 入账后合成"一面墙"＝ 使用权资产，**不再分家** |

**比喻自带的三条推论（正好都是易错点）**：

1. **缺一块，墙就残缺**——漏记初始直接费用 → 折旧基数变小、资产负债率虚高；
2. **砌进墙里就不再单独存在**——资产侧只有**一条折旧线**，不分块折旧（对比负债侧：**两条利息线**，因为两笔义务还在，见 §8.8）；
3. **砖本身不生息**——利息只来自"还欠着的义务"：已付的 ②③ 不生息，欠着的 ①④ 才生息。

**边界（别用过头）**：② 的租赁激励是"**负砖**"（把墙削薄一块）；④ 是"**预订的砖**"（按现值先记、将来才付款）；入账后这面墙还会被**侵蚀**（折旧）、**削薄**（减值）、**改造**（重新计量／租赁变更）——"砖"只负责讲**初始计量**这一层，再往后要换比喻（墙的消耗与改造）。

> 备选比喻为什么都不如"砖"：**拼图**——每块形状咬合、地位相同（这里 ① 是主体、②③④ 是配块，且还有负项）；**柱子**——并列支撑、互不叠加（成本却是相加关系）；**四笔钱**——太贴现金，丢掉了"合成一项资产"这层意思。

### 8.11 使用权资产的折旧与租赁负债的偿还，是同步的吗？

**结论：不同步。** 资产按**时间**消耗（折旧，通常直线法），负债按**钱**消耗（实际利率法：前期利息多、还本少，余额降得慢）。两条线只在**两个端点**上重合——**起租日**（且 ②③④＝0 时）与**租期结束全部结清**；中间任何时点都不相等。

**三条来源（为什么不齐）**：

| 来源 | 机理 | 本项目数字（PROP-2024-001） |
|---|---|---|
| ① 起点口径不同 | 资产含 ②③④，负债只有 ①（见 §8.9） | 起租日：资产 2,106,906 ＞ 负债 2,071,906，差 **35,000** |
| ② 消耗方法不同 | 资产直线（每月 35,115）；负债实际利率（利息滚入本金） | 第 1 个月末：负债 2,080,539 ＞ 资产 2,071,791，**头一个月即交叉** |
| ③ 非常规事件 | 减值、重新计量／租赁变更、能确定取得所有权（改按剩余使用寿命折旧） | 见 §9.2.4 及图解第 ⑥⑦⑧ 卡 |

**逐点对照（本系统合同 PROP-2024-001）**：

| 时点 | 使用权资产净额 | 租赁负债净额 | 负债 − 资产 |
|---|---:|---:|---:|
| 起租日 2024-07-01 | 2,106,906 | 2,071,906 | **−35,000** |
| 第 1 个月末 | 2,071,791 | 2,080,539 | **+8,748**（交叉） |
| 2024-12-31（6 个月） | 1,896,216 | 2,004,246 | +108,030 |
| 2025-06-30（12 个月） | 1,685,526 | 1,813,371 | +127,845 |
| 租期末（全部结清） | 0 | 0 | 0 |

一年下来：资产净额降 **421,380**（直线），负债净额只降 **258,535**（＝付款 360,000 − 利息 101,465）——**同一年，两条线走了完全不同的距离**。

**可检验恒等式**：任一月末　**负债净额 − 资产净额 ＝ 累计折旧 − 累计还本 −（②③④中未进租赁负债的部分）**

- 12 个月末：421,380 − 258,535 − 35,000 ＝ **127,845** ✓（＝ 1,813,371 − 1,685,526）
- 最小例子（②③④＝0，3 年×100、8%）：第 1 年末 85.90 − 79.38 ＝ **6.52** ✓（＝ 178.32 − 171.80）；第 2 年末 171.80 − 165.11 ＝ **6.69** ✓；第 3 年末两边同时归零。

**这个差额不是"噪声"——它就是"费用前置"的度量**：任一时点 **累计已前置的费用 ＝ 累计折旧 ＋ 累计利息 − 累计付款**（＝费用比现金多认了多少）。12 个月末：421,380 ＋ 101,465 − 360,000 ＝ **162,845**，再减去未进租赁负债的 ③（35,000）＝ **127,845**，正是两条线的账面差额；最小例子第 1 年末 106.52 − 100 ＝ **6.52** ✓、第 2 年末 206.69 − 200 ＝ **6.69** ✓。

**反过来说**：若强行让资产也按"付款 − 利息"消耗（两条线恒等），每期费用就会恒等于每期租金（100／100／100）——会计退化成"收付实现制"，租赁的融资特征（费用前高后低）随之消失。**所以"不同步"不是缺陷，正是它承载信息的地方。**

**什么时候才真的算"怪"（三条自检）**：

| # | 现象 | 指向的问题 |
|---|---|---|
| 1 | 起租日差额 ≠ −（②③④） | 漏记／错记砖（初始直接费用、复原成本、已付租金） |
| 2 | 任一时点 负债净额 − 资产净额 ≠ 累计（折旧＋利息−付款）−（②③④） | 折旧或利息算错（含起提月、舍入口径不统一） |
| 3 | 租期末两边不能同时归零 | 少提折旧、尾差未封口、漏做终止结清 |

（减值、重新计量属"已知调整项"，校验时先剔除，否则会误报。）

**为什么准则不要求"同步"**：资产是「**权利**」，按 CAS 4 的折旧规则在租期内直线消耗（CAS 21 第二十条、第二十一条）；负债是「**义务**」，按 CAS 21 用现值计量、实际利率法摊销。两把尺子量的是两件事——"权利还剩多少" vs "还欠多少"。硬把两条线绑成一条，资产就不再代表"权利"了。

**边界（什么时候连终点都不重合）**：

1. **能合理确定租期届满取得所有权**（含合理确定行使购买选择权）→ 资产按**剩余使用寿命**折旧 → 租期结束时**负债已归零、资产还在**；
2. **提前终止／购买选择权行权** → 负债终止确认，资产同步处置或转为固定资产；
3. **减值** → 资产单边下台阶（负债不动，且不得转回）；
4. **租赁变更／重新计量** → 资产与负债**同步调整一次**（调整额＝负债变动额），但随后的消耗仍不同步。

**对账红线**：**不要用"资产净额 ＝ 负债净额"做校验**（这是最常见的误判）。正确做法：① 各自构成式——资产净额 ＝ 原值 − 累计折旧 − 减值准备；负债净额 ＝ 租赁付款额余额 − 未确认融资费用余额；② 用上面的恒等式交叉验；③ 期末**尾差封口**——本例 2,106,906 ÷ 60 ＝ 35,115.1，按 35,115 提 60 期只有 2,106,900，**差 6 元**须在最后一期调整，否则资产永远归不了零（负债侧同理）。

**买房同理**：房子按 30 年直线折旧、房贷按等额本息还——第 10 年房子账面还剩 2/3，贷款可能只剩一半。**各走各的表，谁也不影响谁。**

### 8.12 一边归零、另一边还在：五种正常情形与三种错账

**结论：会。** 让资产消失的事由（用完／减值／处置／转固）与让负债消失的事由（还清／豁免／终止／转固）**本来就不是同一件事**，所以"单边"是常态而非错误；只有**没有事由的单边残留**才是错账。

**① 负债没了、资产还在（义务已清，权利还在用）**

| 路径 | 依据 | 账面表现 |
|---|---|---|
| **起租日或之前一次性付清**（或提前清偿） | CAS 21 第十七条：负债＝**尚未支付**的付款额现值 → 没有未付款就没有负债 | 租赁负债 0、未确认融资费用 0；资产照旧折旧、不再有财务费用 |
| **能合理确定取得所有权**（含合理确定行权）→ 按**剩余使用寿命**折旧 | CAS 21 第二十一条 | 租期结束时负债已归零，资产继续折旧到使用寿命末 |
| **行使购买选择权／租期届满前买下资产** | CAS 21；财会〔2022〕32 号年报通知：终止确认使用权资产与租赁负债，**差额调整固定资产成本**（没有购买选择权的提前购买也照此办） | 租赁负债 0，资产转为"固定资产"继续折旧 |
| **出租人豁免剩余租金** | 定性为**租赁变更** → CAS 21 第二十八条（先调资产、资产不足部分入损益）；定性为**债务重组** → CAS 12 | 负债被清掉；资产按变更被调减（可能调到零，见下表） |

**② 资产没了、负债还在（权利不在了，义务照旧）**

| 路径 | 依据 | 账面表现 |
|---|---|---|
| **减值**（门店关停、市价大跌、资产毁损） | CAS 21 第二十二条 → 按 CAS 8 处理；应用指南：减值准备**一旦计提不得转回**，此后按**减后账面价值**继续折旧（例 40：账面 30,000 → 年折旧 6,000） | 资产可被减到 0；**负债照旧计息、照旧付款** |
| **重新计量把资产冲光了**（负债调减额超出资产可承受范围） | CAS 21 第二十七条：**资产已调减至零、负债仍需进一步调减的，剩余金额计入当期损益** | 资产 0，负债仍有余额，继续付息付款 |
| **转租赁（中间出租人，转出为融资租赁）** | 应用指南 §九（一）：终止确认转出去的**使用权资产**、确认转租赁投资净额，**但原租赁的租赁负债保留在表上** | 原"使用权资产"消失（换成"应收融资租赁款"），原租赁负债照旧；两条线都要确认收益／费用 |
| **实物灭失但合同不可撤销**（拆除、火灾） | 走减值路径；**付款义务不因资产灭失自动消失**，除非同步终止确认 | 资产 0，负债照旧 |

**什么才叫错账（无事由的单边残留）**：

1. 终止／退还时**只结转一边**（负债清了、资产余额挂着，或反过来）；
2. 报废、拆除就以为"账也没了"（除非同步终止确认）；
3. 行权后没把资产转固（资产继续按短租期折旧到 0，提前归零）；
4. 免债**只冲负债、不按变更调资产**。

**系统监控三条规则（建议配置）**：

| # | 规则 | 触发即报错 |
|---|---|---|
| 1 | 任一合同出现"资产净额 ＝ 0 而负债净额 ＞ 0"或反之 | 必须挂着**事由代码**（减值／付清／行权／豁免／转租／终止），无代码即异常 |
| 2 | 减值后：资产净额 ≥ 0，此后折旧基数＝减后净额，负债不动 | 折旧仍在按原值计提 → 报错 |
| 3 | 终止时资产与负债**必须同时归零**，终止损益一次性入账 | 任一非零即拦截 |

**一句话**：资产的尽头是「**减值／处置／转固**」，负债的尽头是「**还清／豁免／终止**」——各有各的尽头，不必同步。

### 8.13 复原成本现值与租赁负债现值，为什么"算法不一样"？——是因为它一次性吗

**结论**：**折现的尺子完全一样，不一样的是要量的东西。** 现值永远只有一个公式 PV ＝ Σ 各期现金流 ÷ (1+r)ᵗ；"一次性"只是**现金流形状**，不是折现原理。

| 形状 | 谁是这样 | 算法 | 现值 |
|---|---|---|---|
| **多期、分期** | ① 租赁负债（PROP-2024-001：20 期季付） | 逐笔折现再加总（年金公式是快捷算法；本例 (P/A,5%,9)） | 355,391 |
| **期末一笔** | ④ 复原成本（第 5 年末 50,000、8%） | 单笔折现 ＝ F ÷ (1+r)ⁿ | 34,029 |

**换个形状，算法跟着换**（同一把尺子）：

| 情形 | 现值 | 说明 |
|---|---:|---|
| 复原费：第 5 年末**一次性** 50,000（8%） | 34,029 | 50,000 ÷ 1.08⁵ |
| 同样的 50,000 改成 **5 年每年末 10,000** | 39,927 | 10,000 × 年金现值系数（8%，5 期）——**钱更早出去，现值更大**（差 5,898） |
| 租金：**第 3 年末一次性付清**（总租 300、8%） | 238.15 | 租赁负债也退化成"单笔折现"＝ 300 ÷ 1.08³——**证明决定算法的是现金流形状，不是"租赁还是复原"** |

**真正不一样的是另外四处（都与折现无关）**：

| # | 差异点 | 租赁负债 ① | 预计负债（复原成本）④ |
|---|---|---|---|
| 1 | **金额来源** | 合同确定（或按指数／比率确定） | **最佳估计数**（CAS 13 第五条：连续范围取中间值、单个项目取最可能金额、多个项目按概率加权） |
| 2 | **折现率** | 首选租赁内含利率，否则承租人增量借款利率（CAS 21 第十七条） | 反映货币时间价值与该负债特有风险的利率（CAS 13 第六条：**货币时间价值影响重大的，应折现后确定最佳估计数**）；实务常与租赁同口径 |
| 3 | **账怎么立** | **总额法**：贷"租赁付款额"总额 2,282,749 ＋ 借"未确认融资费用"备抵 210,843 → 净额＝现值 | **直接按现值立账** 34,029，**没有备抵科目** |
| 4 | **中途动不动** | 每期**付款冲减**（余额先涨后降） | 中途**不付款、只贴息**（34,029 单调爬到 50,000），期满一次清偿 |

**顺带解释"两条利息线"为什么差这么大**：同一年，① 利息 **17,770**（355,391 × 5%）vs ④ 贴息 **3,070**（61,391 × 5%）——**本金小、而且到期才还本，利息自然少**；两条线合计 94,609 ＋ 38,609 ＝ 133,218。

**三个易错点**：

1. **先看付款计划表，再选公式**——把 ④ 硬套年金、把 ① 当成单笔都会算错；
2. 两处**折现率口径混用**（一个含税一个不含税、一个年率一个季率）——不是算法错，是参数错，必须全系统统一并在附注说明；
3. 复原义务的**发生时点未必在租期末**（如退租后 3 个月才拆）——n 可以是**小数年**，别硬套"整年折现"。

**可检验判据（三条都应落回各自的未来现金流）**：

- 34,029 ＋ 15,971 ＝ **50,000**（复原支出）
- 61,391 ＋ 38,609 ＝ **100,000**（10 年期末复原支出）
- 355,391 ＋ 94,609 ＝ **450,000**（＝ 9 期 × 50,000）

三条都成立 → 折现是一把尺子，差的只是**形状与参数**。

### 8.14 复原成本也要折现吗？——折现的判据与边界

**要，除非货币时间价值影响不重大。** 依据链条：CAS 21 第十六条第（四）项把复原成本交给 CAS 13 计量 → **CAS 13 第六条：确定最佳估计数时应综合考虑风险、不确定性和货币时间价值；货币时间价值影响重大的，应当通过对未来现金流出折现后确定最佳估计数**。CAS 13 应用指南：预计负债通常按未来应支付金额确定，**但与现值相差较大的，应按现值**（弃置费用即典型例子）；固定资产弃置费用（CAS 4 第十三条）走同一逻辑。折现率：反映当前市场货币时间价值与该负债特有风险的**税前**利率（定义可参照 CAS 8 第十三条；实务常与租赁折现率取同一口径）。

**"影响重不重大"怎么量**（同一笔 50,000）：

| 时点／利率 | 现值 | 不折现 − 现值 | 结论 |
|---|---:|---:|---|
| 第 5 年末、8% | 34,029 | 15,971（31.94%） | **必须折现** |
| 第 10 年末、5% | 61,391 | 38,609（38.61%） | **必须折现** |
| 半年后、8%（n ＝ 0.5） | 48,112 | 1,888（3.8%） | 影响不重大时可简化；为口径一致仍建议折现 |

**关键澄清：折现与否改变的是"跨期分布"，不是"总额"**——两种做法五年费用合计都是 50,000，差别在资产起点和每期费用：

| 做法 | 起租日资产 | 年折旧 | 贴息（财务费用） | 5 年费用合计 |
|---|---:|---:|---:|---:|
| **折现（正确）** | 34,029 | 6,805.80 | 2,722 → 3,705（合 15,971） | **50,000** |
| 不折现（错） | 50,000（**虚增 15,971**） | 10,000（**每年多 3,194.20**） | 0 | 50,000 |

**费用形状也跟着不同**：折现法每年 ＝ 折旧 6,805.80 ＋ 贴息递增 → **9,527.80／9,745.80／9,980.80／10,234.80／10,510.80**（**前低后高**）；不折现法是平的 10,000／年。**方向提醒**：租赁负债利息**递减**（前高后低），复原负债贴息**递增**（前低后高）——两条利息线方向相反，别记反。

**三个易错点**：

1. **忘了贴息**——预计负债停在 34,029，第 5 年不够付 50,000；
2. **折现率乱用**（存款利率／含税利率／与租赁口径混用）——须用反映该负债特有风险的税前利率，并保持全系统一致；
3. **时点跨期与估计变更**——义务发生在租期结束后（如退租 3 个月后才拆，n ＝ 5.25）、或金额估计变了，都要按 CAS 13 第十二条在资产负债表日复核、按当前最佳估计数的现值调整（增加 → 增加资产成本；减少 → 以资产账面价值为限扣减、超出部分进当期损益）。

**一句话**：只要货币时间价值影响重大，就要折现——"复原"这个词没有豁免权；折出来的差（贴息）在租期内逐期进财务费用，与租赁利息一样，**不进资产、不资本化**。

### 8.15 资产怎么"变成"费用？——折旧只是其中一条出口

**核心口径：资产 ＝ 还没用完的成本；费用 ＝ 已经用完的成本。** 折旧／摊销／折耗／结转成本都是把成本从资产负债表"搬"到利润表，区别只在**按什么尺子搬、搬到哪个科目**。

#### 一、先回答：折现之后，那 34,029 走了两条路

| 路径 | 金额 | 出口（借方科目） |
|---|---:|---|
| **资产侧**：进使用权资产 → 随资产折旧 | 34,029 | 管理费用（折旧 6,805.80／年 × 5） |
| **负债侧**：从不进资产，只作时间价值 | 15,971 | 财务费用（贴息 2,722 → 3,705） |
| **合计 ＝ 将来真正付出去的现金** | **50,000** | —— |

所以"折现后只靠折旧转费用"**只对一半**：**现值 34,029** 确实进资产、靠折旧转费用；**折现差额 15,971 从不进资产**，它自己走财务费用。第 1 年费用 9,527.80 ＝ 折旧 6,805.80 ＋ 贴息 2,722。

**进资产的比例就是现值率**（1 ÷ (1+r)ⁿ）：

| 义务（未来现金） | 进资产 → 折旧 | 走利息 → 损益 |
|---|---:|---:|
| 复原 5 年 · 8%（50,000） | 34,029 · 68.06% | 15,971 · 31.94% |
| 复原 10 年 · 5%（100,000） | 61,391 · 61.39% | 38,609 · 38.61% |
| 租赁 20 期（2,282,749） | 2,071,906 · 90.76% | 210,843 · 9.24% |

规律：**利率越高、期限越长 → 进资产的比例越小、当利息进损益的比例越大**。租赁负债的折现差额叫"未确认融资费用"，复原负债的叫"贴息"——**名字不同、性质相同**，都不进资产（见 §8.8 两条利息线）。

#### 二、再回答：还有哪些"资产 → 费用"的转换

**四条道 ＋ 两个一次性出口**：

| 转换机制 | 适用对象（举例） | 驱动尺子 | 去向科目（借方） | 能否反向 |
|---|---|---|---|---|
| **折旧** | 固定资产、**使用权资产**、投资性房地产（成本模式）、生产性生物资产 | 时间（直线／加速／工作量） | 制造费用／管理费用／销售费用／研发支出 → 最终营业成本 | 不可逆（估计变更只调未来） |
| **摊销** | 无形资产（专利、软件、土地使用权）、长期待摊费用（改建支出）、合同履约成本 | 时间或产量 | 管理费用／销售费用／营业成本 | 不可逆 |
| **折耗** | 油气资产（矿区权益、井及相关设施）、消耗性生物资产 | 产量 | 生产成本／营业成本 | 不可逆 |
| **结转成本** | 存货（原材料、库存商品） | 销量 | 主营业务成本 | 不可逆 |
| **实际利率法** | 债权投资（利息调整）、应付债券（溢折价）、**租赁负债（未确认融资费用）**、应收融资租赁款（未实现融资收益） | 利率（时间价值） | 投资收益／财务费用／租赁收入 | —— |
| **减值**（一次性） | 几乎全部资产（含使用权资产） | 可收回金额 ＜ 账面价值 | 资产减值损失 | **不得转回**（存货、应收款项等除外） |
| **处置／终止确认**（一次性） | 全部资产 | 卖出、退回、报废 | 资产处置损益／固定资产清理／营业外支出 | —— |

**三个反例要点**：① **商誉**不摊销、只做减值测试——它没有"折旧"这条路；② **投资性房地产采用公允价值模式**时**不提折旧**（成本模式才提）；③ **预计负债（复原）不折旧**——它是负债，出口只有"贴息 → 财务费用"和"清偿 → 冲减负债"。

**另有两条容易被忽略的出口**：**递延所得税资产**转回时进**所得税费用**；**商誉**只能走减值。镜像同样成立——**负债也有出口**：贴息 → 财务费用、递延收益摊销 → 其他收益、合同负债 → 收入、预计负债清偿 → 冲减负债。

#### 三、使用权资产自己的四个出口

| 出口 | 依据／要点 |
|---|---|
| **① 折旧**（每期） | 时间驱动；三问见本图解 ⑤ 卡 |
| **② 减值**（一次性） | CAS 21 第二十二条 → CAS 8；**计提后不得转回**，之后按减后价值继续折旧 |
| **③ 重计量冲减** | CAS 21 第二十七条：先调资产；**资产已调到零、负债仍需调减的，余额进当期损益** |
| **④ 变更／终止** | 第二十八条按比例结转，差额进**资产处置损益**；提前购买按财会〔2022〕32号，差额**调固定资产成本** |

"负债先没／资产先没"的单边残留四种正常情形，见 §8.12。

#### 四、系统落地

1. 每类资产建**出口台账**：`asset_id / outlet`（折旧·摊销·折耗·减值·处置）`/ driver`（时间·产量·销量·利率）`/ rate_or_qty / target_account / reversal_allowed`；
2. **三条硬校验**：① 期末资产净值 ≥ 0（折旧／摊销不得超额）；② 出口累计 ＋ 期末账面 ＝ 初始成本；③ **贴息／未确认融资费用不得资本化进资产**——否则"资产虚增 ＋ 费用前置"双重错账（若把 15,971 也砌进墙，折旧基数就变成 50,000，每年多 3,194.20）；
3. 减值标记与"不得转回"联动；公允价值模式的投资性房地产自动关闭折旧任务。

**四个易错点**：① 以为"一切资产都靠折旧转费用"——存货靠**结转**、金融资产靠**利率或处置**、商誉**只减值**；② 把预计负债的**贴息**资本化进资产；③ 把**减值**当折旧；④ 只盯折旧、忘了"两段路"，对不上 50,000 ＝ 34,029 ＋ 15,971，误以为少记。

## 九、中国现行租赁会计准则（CAS 21）

### 9.1 准则体系

| 准则编号 | 名称 | 发布/修订时间 | 生效时间 |
|----------|------|--------------|----------|
| **CAS 21** | 企业会计准则第21号——租赁 | 2018年修订 | 2021年1月1日 |

**现行 CAS 21（2018年修订）与 IFRS 16 基本趋同**，在中国大陆上市公司强制执行。

---

### 9.2 承租方会计处理对比

#### 9.2.1 相同点

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 确认模型 | 单一模型（取消经营/融资租赁区分） | 单一模型 |
| 使用权资产确认 | 确认 | 确认 |
| 租赁负债确认 | 确认（折现值） | 确认（折现值） |
| 短期租赁豁免 | ≤12个月，可豁免 | ≤12个月，**可选择**豁免 |
| 低价值租赁豁免 | 可豁免 | 可豁免 |

#### 9.2.2 差异点

| 差异点 | IFRS 16 | CAS 21（中国） |
|--------|---------|---------------|
| 短期租赁处理 | 必须披露选择 | 企业可自行选择是否豁免 |
| 披露详细程度 | 较详细 | 略有简化 |
| 折现率选择 | 承租人增量借款利率或内含利率 | 基本相同 |

#### 9.2.3 承租方初始确认公式

```
使用权资产 = 租赁负债
           + 预付租金
           - 已享受的租金优惠（如免租期）
           + 初始直接费用
           + 复原成本估计

租赁负债 = 未来租金付款额的折现值
```

#### 9.2.4 承租方后续计量

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 租赁负债 | 按实际利率法摊销 | 按实际利率法摊销 |
| 使用权资产 | 通常直线法折旧 | 通常直线法折旧 |
| 利息费用 | 逐年递减 | 逐年递减 |
| 折旧费用 | 每年相等 | 每年相等 |

---

### 9.3 出租方会计处理对比

#### 9.3.1 相同点

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 融资租赁确认 | 终止确认租赁资产，确认应收款项 | 确认应收融资租赁款，转销资产 |
| 经营租赁处理 | 租金收入当期确认 | 租金收入当期确认 |
| 融资租赁收益 | 利息收入随时间确认 | 利息收入随时间确认 |

#### 9.3.2 差异点

| 差异点 | IFRS 16 | CAS 21（中国） |
|--------|---------|---------------|
| 融资租赁分类 | 5种测试指标 | 5种测试指标，基本相同 |
| 销售类型测试 | 有明确的销售/融资测试 | 基本相同 |
| 转租赁处理 | 分为融资转租赁和经营转租赁 | 分类处理相同 |
| 披露要求 | 较详细 | 略有简化 |

#### 9.3.3 出租方会计处理

**融资租赁（IFRS 16 & CAS 21 相同）**：

| 项目 | 会计处理 |
|------|----------|
| 初始确认 | 终止确认租赁资产，确认应收融资租赁款 |
| 应收款项金额 | 担保余值 + 未担保余值之和的现值 |
| 利息收入 | 按实际利率法确认（逐年递减） |
| 资产折旧 | 不计提（已转出） |

**经营租赁（IFRS 16 & CAS 21 相同）**：

| 项目 | 会计处理 |
|------|----------|
| 租赁资产 | 继续在资产负债表确认 |
| 租金收入 | 按直线法或其他系统方法确认 |
| 资产折旧 | 按资产折旧政策计提折旧 |

## 十、总结

1. **折现是核心**：将未来租金折算为现值，确保资产负债表平衡
2. **租赁负债用利息法**：利息逐年递减，本金偿还逐年增加
3. **使用权资产用直线法折旧**：每年金额相等
4. **支付频率影响期初负债**：越频繁，期初负债越高，总利息越低
5. **IFRS 16 是现行国际准则**：统一了租赁的会计处理
6. **中国 CAS 21 与 IFRS 16 基本趋同**：承租方和出租方会计处理大体一致
7. **主要差异在豁免选择权和披露要求**：中国准则给予企业更多灵活性
