# 租赁使用权资产与租赁负债计算详解

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

---

## 一、概述

本文档总结使用权资产（Right-of-Use Asset）和租赁负债（Lease Liability）的计算逻辑，基于 IFRS 16 租赁会计准则。

**IFRS 16** 是国际财务报告准则第16号，由国际会计准则理事会（IASB）制定，于2019年1月1日生效，取代了旧的 IAS 17 准则。

---

## 二、核心概念区分

| 项目 | 性质 | 报表位置 | 计算方法 |
|------|------|----------|----------|
| **使用权资产** | 资产 | 资产负债表-资产侧 | 折旧（通常直线法） |
| **租赁负债** | 负债 | 资产负债表-负债侧 | 利息法摊销 |

两者在初始确认时金额相等，后续各自独立变化。

---

## 三、为什么需要折现

### 3.1 货币的时间价值

**今天收到100元 ≠ 一年后收到100元**

今天的100元可以存入银行或投资，一年后变成 100 × (1 + 利率)。

### 3.2 折现公式

```
现值 = 未来值 ÷ (1 + 利率)^期数
```

**举例**：年利率5%，一年后应付租金105万
```
现值 = 105万 ÷ 1.05 = 100万
```

### 3.3 会计处理的意义

| 角度 | 说明 |
|------|------|
| 经济角度 | 今天握有100万，存一年得5万利息，正好等于105万 |
| 会计角度 | 资产负债表要求两边都用"当前时点"的价值 |
| 配比原则 | 利息费用（逐年递减）+ 折旧费用（通常均匀）= 每期总费用 |

## 四、租赁负债摊销计算

### 4.1 通用公式

```
1. 计算期利率：r = (1 + 年利率)^(1/年内期数) - 1

2. 计算期初负债：
   PV = PMT × [1 - (1+r)^(-n)] ÷ r
   其中 PMT = 每期支付额，n = 总期数

3. 每期摊销：
   利息 = 期初本金 × r
   还本 = 支付额 - 利息
   期末本金 = 期初本金 - 还本

4. 循环计算直到本金为0
```

### 4.2 按年付示例

**场景**：租期2年，年末付54万，年利率5%

#### 期初负债计算
```
期初负债 = 54万 ÷ 1.05 + 54万 ÷ 1.05²
         = 51.43万 + 49.00万
         = 100.43万
```

#### 摊销明细

| 年份 | 期初本金 | 利息(5%) | 支付 | 还本 | 期末本金 |
|------|----------|----------|------|------|----------|
| 第1年 | 100.43万 | 5.02万 | 54万 | 48.98万 | 51.45万 |
| 第2年 | 51.45万 | 2.57万 | 54万 | 51.43万 | ≈ 0 |

### 4.3 按季度付示例

**场景**：租期2年，季度末付13.5万（54万÷4），年利率5%

#### 参数
| 项目 | 数值 |
|------|------|
| 季租金 | 13.5万 |
| 季利率 | (1+5%)^(1/4) - 1 ≈ 1.232% |
| 总期数 | 8期 |

#### 期初负债
```
PV = 13.5万 × [1 - (1.01232)^(-8)] ÷ 0.01232
PV ≈ 102.20万
```

#### 摊销明细

| 季度 | 期初本金 | 利息(1.232%) | 支付 | 还本 | 期末本金 |
|------|----------|--------------|------|------|----------|
| Q1 | 102.20万 | 1.26万 | 13.5万 | 12.24万 | 89.96万 |
| Q2 | 89.96万 | 1.11万 | 13.5万 | 12.39万 | 77.57万 |
| Q3 | 77.57万 | 0.96万 | 13.5万 | 12.54万 | 65.03万 |
| Q4 | 65.03万 | 0.80万 | 13.5万 | 12.70万 | 52.33万 |

### 4.4 按月付示例

**场景**：租期2年，月付4.5万（54万÷12），年利率5%

#### 参数
| 项目 | 数值 |
|------|------|
| 月租金 | 4.5万 |
| 月利率 | (1+5%)^(1/12) - 1 ≈ 0.4074% |
| 总期数 | 24期 |

#### 期初负债
```
PV = 4.5万 × [1 - (1.004074)^(-24)] ÷ 0.004074
PV ≈ 102.68万
```

### 4.5 2年一付示例

**场景**：租期2年，2年末一次性付108万，年利率5%

#### 期初负债
```
期初负债 = 108万 ÷ (1 + 5%)² = 97.96万
```

#### 摊销明细

| 年份 | 期初本金 | 利息(5%) | 支付 | 还本 | 期末本金 |
|------|----------|----------|------|------|----------|
| 第1年 | 97.96万 | 4.90万 | 0 | 0 | 102.86万 |
| 第2年 | 102.86万 | 5.14万 | 108万 | 102.86万 | 0 |

## 六、规律总结

### 6.1 支付频率的影响

```
支付越频繁 → 期初负债越高 → 每期利息越低 → 还本越快
支付越稀疏 → 期初负债越低 → 利息滚存越多 → 总利息越高
```

### 6.2 核心规律

| 现象 | 原因 |
|------|------|
| 月付期初负债最高 | 付款最频繁，本金基数最大 |
| 2年一付期初负债最低 | 只有1次支付，折现次数最少 |
| 总利息随支付频率增加而减少 | 每期还本更及时，本金减少更快 |

## 七、使用权资产 vs 租赁负债

### 7.1 租赁负债摊销（利息法）

- 随还款本金减少，利息逐年递减
- 前几年利息占比高，本金还得慢

### 7.2 使用权资产折旧（直线法）

- 通常使用直线法
- 每年折旧 = 原值 ÷ 使用年限

**举例**：使用权资产原值100.43万，折旧2年
| 年份 | 期初资产 | 折旧 | 期末资产 |
|------|----------|------|----------|
| 第1年 | 100.43万 | 50.20万 | 50.20万 |
| 第2年 | 50.20万 | 50.20万 | ≈ 0 |

### 7.3 对利润表的影响

| 年份 | 利息费用（负债侧） | 折旧费用（资产侧） | 费用合计 |
|------|-------------------|-------------------|----------|
| 第1年 | 5.02万 | 50.20万 | 55.22万 |
| 第2年 | 2.57万 | 50.20万 | 52.77万 |

**费用前高后低**，符合"前期费用大、后期小"的预期。

## 八、IFRS 16 简介

### 8.1 准则发展

| 时间 | 准则 | 说明 |
|------|------|------|
| 1982年 | IAS 17 | 旧租赁准则，区分经营租赁和融资租赁 |
| 2016年1月 | IFRS 16 发布 | 取消经营租赁区分 |
| 2019年1月1日 | IFRS 16 生效 | 对大多数企业强制适用 |

### 8.2 主要变化

| 项目 | IAS 17（旧） | IFRS 16（新） |
|------|--------------|---------------|
| 经营租赁 | 不进报表，只在附注披露 | 确认使用权资产和租赁负债 |
| 融资租赁 | 进报表 | 被 IFRS 16 合并处理 |
| 承租人视角 | 区分两类 | 统一处理 |
| 出租人视角 | 基本保持不变 | 变化较小 |

### 8.3 初始确认公式

```
使用权资产 = 租赁负债
           + 预付租金
           - 已享受的租金优惠（如免租期）
           + 初始直接费用
           + 复原成本估计
```

## 九、中国现行租赁会计准则（CAS 21）

### 9.1 准则体系

| 准则编号 | 名称 | 发布/修订时间 | 生效时间 |
|----------|------|--------------|----------|
| **CAS 21** | 企业会计准则第21号——租赁 | 2018年修订 | 2021年1月1日 |

**现行 CAS 21（2018年修订）与 IFRS 16 基本趋同**，在中国大陆上市公司强制执行。

---

### 9.2 承租方会计处理对比

#### 9.2.1 相同点

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 确认模型 | 单一模型（取消经营/融资租赁区分） | 单一模型 |
| 使用权资产确认 | 确认 | 确认 |
| 租赁负债确认 | 确认（折现值） | 确认（折现值） |
| 短期租赁豁免 | ≤12个月，可豁免 | ≤12个月，**可选择**豁免 |
| 低价值租赁豁免 | 可豁免 | 可豁免 |

#### 9.2.2 差异点

| 差异点 | IFRS 16 | CAS 21（中国） |
|--------|---------|---------------|
| 短期租赁处理 | 必须披露选择 | 企业可自行选择是否豁免 |
| 披露详细程度 | 较详细 | 略有简化 |
| 折现率选择 | 承租人增量借款利率或内含利率 | 基本相同 |

#### 9.2.3 承租方初始确认公式

```
使用权资产 = 租赁负债
           + 预付租金
           - 已享受的租金优惠（如免租期）
           + 初始直接费用
           + 复原成本估计

租赁负债 = 未来租金付款额的折现值
```

#### 9.2.4 承租方后续计量

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 租赁负债 | 按实际利率法摊销 | 按实际利率法摊销 |
| 使用权资产 | 通常直线法折旧 | 通常直线法折旧 |
| 利息费用 | 逐年递减 | 逐年递减 |
| 折旧费用 | 每年相等 | 每年相等 |

---

### 9.3 出租方会计处理对比

#### 9.3.1 相同点

| 项目 | IFRS 16 | CAS 21 |
|------|---------|--------|
| 融资租赁确认 | 终止确认租赁资产，确认应收款项 | 确认应收融资租赁款，转销资产 |
| 经营租赁处理 | 租金收入当期确认 | 租金收入当期确认 |
| 融资租赁收益 | 利息收入随时间确认 | 利息收入随时间确认 |

#### 9.3.2 差异点

| 差异点 | IFRS 16 | CAS 21（中国） |
|--------|---------|---------------|
| 融资租赁分类 | 5种测试指标 | 5种测试指标，基本相同 |
| 销售类型测试 | 有明确的销售/融资测试 | 基本相同 |
| 转租赁处理 | 分为融资转租赁和经营转租赁 | 分类处理相同 |
| 披露要求 | 较详细 | 略有简化 |

#### 9.3.3 出租方会计处理

**融资租赁（IFRS 16 & CAS 21 相同）**：

| 项目 | 会计处理 |
|------|----------|
| 初始确认 | 终止确认租赁资产，确认应收融资租赁款 |
| 应收款项金额 | 担保余值 + 未担保余值之和的现值 |
| 利息收入 | 按实际利率法确认（逐年递减） |
| 资产折旧 | 不计提（已转出） |

**经营租赁（IFRS 16 & CAS 21 相同）**：

| 项目 | 会计处理 |
|------|----------|
| 租赁资产 | 继续在资产负债表确认 |
| 租金收入 | 按直线法或其他系统方法确认 |
| 资产折旧 | 按资产折旧政策计提折旧 |

## 十、总结

1. **折现是核心**：将未来租金折算为现值，确保资产负债表平衡
2. **租赁负债用利息法**：利息逐年递减，本金偿还逐年增加
3. **使用权资产用直线法折旧**：每年金额相等
4. **支付频率影响期初负债**：越频繁，期初负债越高，总利息越低
5. **IFRS 16 是现行国际准则**：统一了租赁的会计处理
6. **中国 CAS 21 与 IFRS 16 基本趋同**：承租方和出租方会计处理大体一致
7. **主要差异在豁免选择权和披露要求**：中国准则给予企业更多灵活性
