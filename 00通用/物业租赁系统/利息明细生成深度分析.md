## 一、为什么要生成利息明细？

### 1.1 财务核算的核心需求

利息明细是租赁负债摊销的核心依据，用于：

| 用途 | 说明 |
|------|------|
| **利息费用计提** | 每天的利息费用 = 期初余额 × 日利率 |
| **财务账务处理** | 每月末根据累计利息做凭证 |
| **负债变动追踪** | 跟踪租赁负债的还本付息情况 |
| **期间报表** | 生成各期的利息支出报表 |

### 1.3 利息计算的财务原理

```
┌─────────────────────────────────────────────────────────────────┐
│                      租赁负债摊销原理                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【核心公式】                                                    │
│                                                                  │
│  期初余额 = 上期末余额                                           │
│  当日利息 = (期初余额 - 当日支付) × 日利率                        │
│  期末余额 = 期初余额 - 当日支付 + 当日利息                        │
│                                                                  │
│  【示例】                                                        │
│  假设: 日利率 = 0.000137 (年化5%)                              │
│                                                                  │
│  日期       期初余额    支付     利息计算        期末余额         │
│  ──────── ────────── ──────── ────────────── ──────────       │
│  01-01    1,000,000   0       1,000,000×0.000137 = 137       │
│                                          = 137     1,000,137    │
│                                                                  │
│  01-02    1,000,137   0       (1,000,137-0)×0.000137 = 137    │
│                                          = 137     1,000,274    │
│                                                                  │
│  01-31    1,000,410   250,000 (1,000,410-250,000)×0.000137    │
│                                          = 103    = 750,513     │
│                                                                  │
│  【累计效应】                                                    │
│  - 每日利息累加形成"未确认融资费用"                              │
│  - 每日支付累加形成"已还本金额"                                  │
│  - 期初余额 - 累计利息 + 累计还本 = 期末余额                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 三、核心计算逻辑详解

### 3.1 获取支付金额Map

```java
private void getLeaseLiabPayAmountMapForNotExemptContract(
    DynamicObject leaseContract,
    Map<String, BigDecimal> allAmountMap) {

    // 遍历支付计划
    for (DynamicObject row : planEntry) {
        // 只处理本金类(A)付款项
        if (!"A".equals(acctClass)) continue;

        // 只处理 计划日期 >= 起始日期 的行
        if (planPayDate < detailBeginDate) continue;

        BigDecimal amount = row.getBigDecimal("unpaidrent");

        // 根据利息摊销模式决定处理方式
        if (schema == "A") {
            // 模式A: 直接按付款日期记录

        } else {
            // 模式B: 按月摊销

        }
    }
}
```

### 3.3 利息计算核心逻辑

```java
// 生成每日明细行
Date rowDate = detailBeginDate;
while (rowDate <= detailEndDate) {
    // 1. 期初余额
    row.beginbalance = beginBalance;

    // 2. 当日支付
    String dateStr = formatDate(rowDate);
    BigDecimal leaseLiabPay = amountMap[dateStr] ?: 0;

    // 3. 计算利息
    // 关键公式: 当日利息 = (期初余额 - 当日支付) × 日利率
    if (is最后付款日) {
        // 最后一天: 利息 = 未确认融资费用 - 已累计利息
        // 目的: 确保利息总额精确等于未确认融资费用
        leaseLiabInt = notConfirmFinCost - sumInterest;
    } else {
        // 普通日: 利息 = (期初余额 - 当日支付) × 日利率
        leaseLiabInt = (beginBalance - leaseLiabPay) × dailyRate;
    }

    // 4. 期末余额
    endBalance = beginBalance - leaseLiabPay + leaseLiabInt;

    // 5. 累计利息
    sumInterest += leaseLiabInt;

    // 6. 下一日
    beginBalance = endBalance;
    rowDate = addDay(rowDate, 1);
}
```

### 4.2 模式B：迭代计算原理

**问题**：为什么需要迭代？

**答案**：确保 Σ(每日利息) = 未确认融资费用

```
┌─────────────────────────────────────────────────────────────────┐
│                      迭代计算原理                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【已知条件】                                                    │
│  - 负债原值: leaseliabori                                       │
│  - 负债现值: leaseliab                                          │
│  - 未确认融资费用 = leaseliabori - leaseliab (固定值)            │
│  - 每日支付金额: amountMap (固定值)                              │
│                                                                  │
│  【目标】                                                        │
│  找到日利率 r，使得:                                            │
│    Σ(每日利息) = 未确认融资费用                                  │
│                                                                  │
│  【约束】                                                        │
│  每日利息 = (期初余额 - 当日支付) × r                           │
│  - 日利率↑ → 每日利息↑ → 利息总额↑                               │
│  - 日利率↓ → 每日利息↓ → 利息总额↓                               │
│                                                                  │
│  【算法】                                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  1. 取初始日利率 r₀ = 合同日利率                        │   │
│  │  2. 计算利息总额 I₀ = Σ(每日利息)                       │   │
│  │  3. 比较 I₀ 与 目标                                      │   │
│  │     - 若 I₀ > 目标 → 减少日利率                         │   │
│  │     - 若 I₀ < 目标 → 增加日利率                         │   │
│  │  4. 重复直到收敛                                         │   │
│  │  5. 线性插值获得精确值                                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.3 迭代算法详细步骤

```java
public BigDecimal calculate() {
    // Step 1: 初始化
    BigDecimal dailyDiscountRate = 合同.dailydiscountrate;
    BigDecimal rate = dailyDiscountRate / 100;
    double notConfirmFinCost = getNotConfirmFinCost();

    // Step 2: 计算初始利息总额
    double interestTotal = calculateInterestTotal(rate.doubleValue());
    double difference = interestTotal - notConfirmFinCost;

    // Step 3: 二分查找
    double lastPositiveRate = rate;   // 利息过多的日利率
    double lastNegativeRate = rate;   // 利息不足的日利率

    if (difference > 0) {  // 利息过多
        // 减少日利率
        while (difference > 0) {
            rate *= 0.98;  // 减少2%
            interestTotal = calculateInterestTotal(rate);
            difference = interestTotal - notConfirmFinCost;
        }
    } else {  // 利息不足
        // 增加日利率
        while (difference < 0) {
            rate *= 1.02;  // 增加2%
            interestTotal = calculateInterestTotal(rate);
            difference = interestTotal - notConfirmFinCost;
        }
    }

    // Step 4: 线性插值
    // 在 lastPositiveRate 和 lastNegativeRate 之间线性插值
    double finalRate = interpolate(lastPositiveRate, lastNegativeRate);

    return finalRate;
}
```

### 4.4 利息总额计算

```java
private double calculateInterestTotal(double r) {
    double lastEndBalance = 0;
    double interestTotal = 0;

    for each 每日记录 {
        if (i == 0) {
            lastEndBalance = 期初余额;  // = leaseliab
        }

        // 当日利息 = (上期末余额 - 当日支付) × 日利率
        double dailyInterest = (lastEndBalance - 当日支付) × r;

        // 四舍五入到分(2位小数)
        dailyInterest = Math.round(dailyInterest × 100) / 100;

        // 累加
        interestTotal += dailyInterest;

        // 更新余额
        lastEndBalance = lastEndBalance - 当日支付 + dailyInterest;
    }

    return interestTotal;
}
```

```java
private DynamicObject generateForExemptContract(DynamicObject leaseContract) {
    // 豁免合同特点: 租赁负债 = 0，使用权资产 = 0
    // 但仍需记录付款计划用于租金结算

    // Step 1: 获取付款金额Map (仅本金类A)
    getLeaseLiabPayAmountMapForExemptContract(leaseContract, amountMap);

    // Step 2: 按日遍历
    Date rowDate = detailBeginDate;
    while (rowDate <= detailEndDate) {
        // 如果当天有付款
        if (amountMap.contains(当天日期)) {
            // 利息 = 0
            row.leaseliabint = 0;
            row.beginbalance = 0;
            row.endbalance = 0;
            // 但记录支付金额
            row.leaseliabpay = 当日支付;
        }
        rowDate = addDay(rowDate, 1);
    }
}
```

**特点**：
- 日利率 = 0
- 所有余额 = 0
- 只记录付款日期和金额
- 用于租金结算，但不产生利息

## 九、与负债余额的关系

### 9.1 负债余额生成

```java
// FaLeaseDebitBalanceGenerator
public Map genLeaseDebitBalance() {
    // 1. 按期间分组
    Map<periodId, List<detailRows>> = groupByPeriod(interestDetail);

    // 2. 遍历期间计算累计值
    for each periodId (按期间排序) {
        // 本期汇总
        BigDecimal periodInterest = sum(detailRows.leaseliabint);
        BigDecimal periodPay = sum(detailRows.leaseliabpay);

        // 累计值 = 上期累计 + 本期
        BigDecimal totalInterest = previousTotal + periodInterest;
        BigDecimal totalPay = previousTotal + periodPay;

        // 生成余额记录
        createDebitBalance(periodId, totalInterest, totalPay);
    }
}
```

## 十、关键公式汇总

### 10.1 利息计算公式

```
┌─────────────────────────────────────────────────────────────────┐
│                      利息计算核心公式                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【每日利息】                                                    │
│  日利息 = (期初余额 - 当日支付) × 日利率                          │
│                                                                  │
│  【期末余额】                                                    │
│  期末余额 = 期初余额 - 当日支付 + 日利息                          │
│                                                                  │
│  【利息总额】                                                    │
│  Σ(日利息) = 未确认融资费用                                      │
│              = 负债原值 - 负债现值                                │
│                                                                  │
│  【最后一天利息（特殊处理）】                                      │
│  最后一天利息 = 未确认融资费用 - 已累计利息                        │
│                                                                  │
│  【日利率】                                                      │
│  复利公式: (1 + 年利率)^(1/365) - 1                              │
│  单利公式: 年利率 / 365                                          │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 10.2 关键数值对照

| 名称 | 公式 | 示例 |
|------|------|------|
| 负债原值 | Σ(未付本金) | 120万 |
| 负债现值 | Σ(本金现值) | 100万 |
| 未确认融资费用 | 负债原值 - 负债现值 | 20万 |
| 利息总额 | Σ(每日利息) | 20万 |
| 累计还本 | Σ(每日支付) | 100万 |
