## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

|------|------|------|

| 状态 | 值 | 说明 |
|------|------|------|

| 类型 | 值 | 说明 |

## 三、主单据：租赁合同 (fa_lease_contract)

### 3.1 单据结构

```
租赁合同
├── 基本信息

│   ├── 组织 (org)

│   ├── 资产名称 (assetname)
│   └── 资产数量 (assetqtycreate)
├── 租赁信息
│   ├── 出租方 (leaser)
│   ├── 租赁开始日期 (leasestartdate)
│   ├── 租赁结束日期 (leaseenddate)

│   ├── 初始确认日期 (initconfirmdate)

└── 关联信息
    ├── 付款规则明细 (payruleentryentity)
    ├── 支付计划明细 (payplanentryentity)
    ├── 终止记录 (terminationentry)
    ├── 变更记录 (leasechangeentry)
    ├── 部分终止记录 (leasepartterentry)
    └── 租金结算列表 (rentsettlelistap)
```

### 3.2 生命周期状态流转

```
新增(A) → 保存 → 提交 → 审核 → 推送 → 生成卡片
   ↓
变更(C) ← 变更单审核 → 更新卡片（推送状态A）
   ↓
部分终止(D) ← 部分终止单审核 → 更新卡片
   ↓
终止(B) ← 终止单审核 → 生成结清单 → 结束
```

### 3.3 操作流程

| 操作 | 表单插件 | 操作插件 | 说明 |
|------|----------|----------|------|
| 保存 | `LeaseContractEditPlugin` | - | 自动计算字段 |
| 提交 | - | `FaAbstractLeaseContractSubmitOp` | 校验、生成支付计划 |
| 审核 | - | `FaLeaseContractAuditOp` | 生成卡片、利息明细、余额 |
| 删除 | - | `FaLeaseContractDeleteOp` | 校验状态 |

**源码对应** (`FaLeaseContractSubmitOp`):

```java
// Step 1: beforeExecuteOperationTransaction
public void beforeExecuteOperationTransaction(BeforeOperationArgs e) {
    Map<Long, Date> leaseInitCurPeriodDateMap = this.getLeaseInitCurPeriodDate(e.getDataEntities());
    for (DynamicObject leaseContract : e.getDataEntities()) {
        Date initConFirmDate = leaseContract.getDate("initconfirmdate");
        Date curPeriodBeginDate = leaseInitCurPeriodDateMap.get(orgId);
        Date accountDate = curPeriodBeginDate.after(initConFirmDate)
            ? curPeriodBeginDate : initConFirmDate;
        leaseContract.set("accountdate", accountDate);
    }
}

// Step 2: beginOperationTransaction (继承自父类)
public void beginOperationTransaction(BeginOperationTransactionArgs e) {
    for (DynamicObject leaseContract : e.getDataEntities()) {
        LeaseUtil.generatePayPlan(leaseContract);
        this.calLeaseContractAmount(leaseContract);
        this.setRentSettleStatus(leaseContract);
    }
}
```

### 4.3 校验器 (Validator)

校验器负责数据合法性校验，在操作执行前检查数据是否满足业务规则。

#### 4.3.1 变更单校验器 (LeaseChangeBillValidator)

**校验项**:

| 方法 | 校验内容 |
|------|----------|
| `validateMustInput` | 必填字段校验 |
| `validateBefContract` | 变更前合同校验（状态、金额等） |
| `validateChangeItems` | 变更项合法性校验 |
| `validateEffectiveDate` | 生效日期合理性校验 |
| `validateForPartTer` | 部分终止专项校验 |

**部分终止金额不变判断**:
```java
// 判断变更后金额是否实质变化
checkAmountFields(bill) {
    变更后资产原值 = 原资产原值 - 结清资产原值
    变更后负债原值 = 原负债原值 - 结清负债原值
    变更后负债现值 = 原负债现值 - 结清负债现值

    if (资产原值不变 && 负债原值不变 && 负债现值不变) {
        return true;  // 金额不变
    }
    return false; // 金额有变化
}
```

## 六、核心算法详解

### 6.1 生成支付计划 (LeaseUtil.generatePayPlan)

**算法流程**:

```
┌─────────────────────────────────────────────────────────────────┐
│  LeaseUtil.generatePayPlan()                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  输入: 付款规则明细 (payruleentryentity)                        │
│  输出: 支付计划明细 (payplanentryentity)                         │
│                                                                  │
│  for each 付款规则行 {                                          │
│      frequency = 付款频率                                       │
│      intervalMonth = 根据频率计算月间隔                          │
│      planStart = 当前规则开始日期                               │
│                                                                  │
│      while (planStart <= ruleEndDate) {                         │
│          // Step 1: 计算计划付款日期                             │
│          planPayDate = calPlanPayDate(...)                       │
│                                                                  │
│          // Step 2: 计算金额                                   │
│          rent = amount                                          │
│          tax = ruleTax                                         │
│          rentNoTax = rent - tax                                │
│                                                                  │
│          // Step 3: 计算未付租金                                │
│          // 条件: acctClass="A" 且 planPayDate >= initConfirmDate │
│          if (acctClass=="A" && planPayDate>=initConfirmDate) {   │
│              unpaidRent = deductible ? rentNoTax : rent          │
│          } else {                                              │
│              unpaidRent = 0                                    │
│          }                                                      │
│                                                                  │
│          // Step 4: 添加计划行                                   │
│          planRow = {planPayDate, rent, tax, rentNoTax, unpaidRent}│
│                                                                  │
│          planStart = addMonth(planStart, intervalMonth)          │
│      }                                                          │
│  }                                                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 6.2 填充折现信息 (LeaseUtil.fillPayPlan)

**算法流程**:

```
┌─────────────────────────────────────────────────────────────────┐
│  LeaseUtil.fillPayPlan()                                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  for each 支付计划行 {                                          │
│      dailyRate = dailydiscountrate / 100                        │
│                                                                  │
│      // 负债折现（从初始确认日到付款日）                          │
│      if (acctClass=="A" && planPayDate>=initConfirmDate) {       │
│          liabDays = daysBetween(initConfirmDate, planPayDate)      │
│          liabFactor = (1 + dailyRate)^liabDays                  │
│          liabPV = unpaidRent / liabFactor                        │
│      } else {                                                  │
│          liabPV = 0                                            │
│      }                                                          │
│                                                                  │
│      // 资产折现（从租赁期开始日到付款日，仅方案A/C）             │
│      if (方案A/C && acctClass=="A" && planPayDate>=leaseStart) {  │
│          assetDays = daysBetween(leaseStart, planPayDate)         │
│          assetFactor = (1 + dailyRate)^assetDays                │
│          assetPV = (deductible ? rentNoTax : rent) / assetFactor │
│      } else {                                                  │
│          assetPV = 0                                            │
│      }                                                          │
│                                                                  │
│      // 存储折现结果                                           │
│      row.presentvalue = liabPV                                  │
│      row.presentvalue2 = assetPV                               │
│  }                                                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 6.3 计算财务字段 (LeaseUtil.calFinInfoFields)

**算法流程**:

```
┌─────────────────────────────────────────────────────────────────┐
│  LeaseUtil.calFinInfoFields()                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  leaseLiabOri = 0;  // 负债原值                                │
│  leaseLiab = 0;     // 负债现值                                │
│  leaseAssets = 0;    // 使用权资产                              │
│                                                                  │
│  for each 支付计划行 {                                          │
│      acctClass = payItem.accountingclass                        │
│      if (acctClass == "C") continue;  // 跳过费用类             │
│                                                                  │
│      // 累加负债                                                │
│      leaseLiabOri += unpaidRent;                               │
│      leaseLiab += liabPV;                                      │
│                                                                  │
│      // 计算使用权资产                                           │
│      if (方案A/C) {                                            │
│          leaseAssets += assetPV;                               │
│          if (acctClass=="B") {                                  │
│              leaseAssets += (deductible?rentNoTax:rent);        │
│          }                                                      │
│      } else {  // 方案B                                       │
│          leaseAssets += liabPV;                                │
│          if (acctClass=="A") {                                 │
│              leaseAssets += tax;                               │
│          } else if (acctClass=="B") {                          │
│              leaseAssets += rentNoTax;                         │
│          }                                                      │
│      }                                                          │
│  }                                                              │
│                                                                  │
│  // 方案A: 计算累计折旧                                         │
│  if (方案A) {                                                  │
│      totalMonths = monthsBetween(leaseStart, leaseEnd)            │
│      executedMonths = monthsBetween(leaseStart, firstExecDate)    │
│      assetsAccumDepre = leaseAssets * executedMonths / totalMonths│
│  }                                                              │
│                                                                  │
│  // 豁免合同: 全部设为0                                        │
│  if (isExempt) {                                               │
│      leaseLiab = leaseLiabOri = leaseAssets = 0                 │
│  }                                                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 6.4 利息明细生成 (InterestDetailGenerator)

**算法流程**:

```
┌─────────────────────────────────────────────────────────────────┐
│  InterestDetailGenerator.generate()                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  for each 租赁合同 {                                          │
│      if (isExempt) {                                          │
│          generateForExemptContract();  // 豁免合同              │
│      } else {                                                  │
│          generateForNotExemptContract();  // 非豁免合同         │
│      }                                                          │
│  }                                                              │
│                                                                  │
│  【非豁免合同处理】                                             │
│  ├─ Step 1: 获取基础数据                                       │
│  │   ├─ detailBeginDate = 新增?initConfirmDate:sysSwitchDate   │
│  │   ├─ detailEndDate = leaseEndDate                         │
│  │   ├─ beginBalance = leaseliab                              │
│  │   └─ amountMap = 从支付计划获取 {日期:支付金额}            │
│  │                                                            │
│  │  ├─ Step 2: 获取日利率                                     │
│  │  │   if (利息摊销模式=A && 来源类型=A) {                    │
│  │  │       return dailydiscountrate / 100;  // 模式A        │
│  │  │   } else {                                             │
│  │  │       return RealDailyIntRateCalculator.calculate(); // 模式B│
│  │  │   }                                                    │
│  │  │                                                            │
│  │  └─ Step 3: 按日生成利息明细                               │
│  │      rowDate = detailBeginDate                              │
│  │      while (rowDate <= detailEndDate) {                    │
│  │          beginBalance = (seq==1)?leaseliab:上期末余额      │
│  │          dailyPay = amountMap[date] ?: 0                  │
│  │          dailyInt = (beginBalance - dailyPay) × dailyRate   │
│  │          endBalance = beginBalance - dailyPay + dailyInt    │
│  │          record = {date, beginBalance, dailyPay, dailyInt,    │
│  │                     endBalance, period, latestdata, sourcetype}│
│  │          rowDate = rowDate + 1;                             │
│  │      }                                                      │
│  │                                                            │
│  └─ Step 4: 生成负债余额                                       │
│      FaLeaseDebitBalanceGenerator.genLeaseDebitBalance()         │
│      └─ 按会计期间分组汇总累计利息和累计支付                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

**日利率获取逻辑**:

```java
// getDailyRate() - 获取日利率
String schema = 系统参数("interest_amortize_schema", orgId, "A");
String sourceType = 合同.sourcetype;

if (schema=="A" && sourceType=="A") {
    // 模式A: 直接使用合同日利率
    return dailydiscountrate / 100;
} else {
    // 模式B: 迭代计算实际日利率
    return RealDailyIntRateCalculator.calculate();
}
```

### 6.5 实际日利率迭代计算 (RealDailyIntRateCalculator)

**迭代原理**:

```
┌─────────────────────────────────────────────────────────────────┐
│  RealDailyIntRateCalculator.calculate()                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  目标: 找到使"利息总额" = "未确认融资费用"的日利率              │
│                                                                  │
│  已知:                                                            │
│  - 未确认融资费用 = 负债原值 - 负债现值 (固定)                    │
│  - 日利率影响利息总额 (利率↑ → 利息↑)                          │
│                                                                  │
│  迭代过程:                                                        │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │  1. 初始日利率 = 合同日利率                            │ │
│  │  2. 计算利息总额                                      │ │
│  │  3. if (利息总额 > 目标) 减少日利率 *= 0.98           │ │
│  │     if (利息总额 < 目标) 增加日利率 *= 1.02             │ │
│  │  4. 重复2-3直到利息总额 ≈ 目标                        │ │
│  │  5. 线性插值获得精确值                                │ │
│  └─────────────────────────────────────────────────────────┘ │
│                                                                  │
│  利息总额计算:                                                    │
│  for (每天 until 最后付款日) {                                    │
│      利息 = (期初余额 - 当日支付) × 日利率                       │
│      期末余额 = 期初余额 - 当日支付 + 利息                       │
│      利息总额 += 利息                                           │
│  }                                                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 十三、变更联动字段

### 13.1 联动字段映射

| 变更字段 | 联动更新的字段 | 说明 |
|----------|----------------|------|
| `discountrate` | `dailydiscountrate` | 年折现率变更 → 自动重新计算日折现率 |
| `leaseenddate` | `leasemonths`, `depremonths` | 租赁结束日期变更 → 自动重新计算租赁月数和折旧月数 |

### 13.2 源码实现

```java
// LINKAGE_FIELDS - 变更字段联动更新
private static final Map<String, Set<String>> LINKAGE_FIELDS = new HashMap<>();

static {
    LINKAGE_FIELDS.put("discountrate", Set.of("dailydiscountrate"));
    LINKAGE_FIELDS.put("leaseenddate", Set.of("leasemonths", "depremonths"));
}

// 在doChange()中执行联动复制
for (String field : changeFields) {
    this.copyField(changeBakContract, leaseContract, field);
    Set<String> linkageFields = LINKAGE_FIELDS.get(field);
    if (linkageFields != null) {
        for (String linkageField : linkageFields) {
            this.copyField(changeBakContract, leaseContract, linkageField);
        }
    }
}
```
