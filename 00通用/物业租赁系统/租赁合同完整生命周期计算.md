# 租赁合同完整生命周期：IFRS 16 / CAS 21 算法详解

> 文档版本：v4.0
> 创建日期：2026-09-21
> 适用范围：IFRS 16（国际准则）、CAS 21（中国准则）
> 文档目的：从起租日到到期日，完整展示租赁合同的整个生命周期计算

---

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

---

## 一、准则概述

### 1.1 IFRS 16 与 CAS 21 核心差异

| 差异项 | IFRS 16 | CAS 21 |
|--------|---------|--------|
| 短期租赁豁免（≤12个月） | 必须简化处理 | 可自行选择 |
| 低价值租赁豁免 | 可豁免 | 可豁免 |
| 披露要求 | 较详细 | 略有简化 |

### 1.2 承租方会计处理（两准则核心相同）

| 项目 | 处理方式 |
|------|----------|
| 确认模型 | 单一模型（取消经营/融资租赁区分） |
| 使用权资产 | 确认，折旧通常直线法 |
| 租赁负债 | 确认（折现值），利息实际利率法 |
| 利息费用 | 逐年递减 |

---

## 二、核心公式

| 公式 | 用途 |
|------|------|
| `PV = PMT × [1-(1+r)^(-n)] / r` | 年金现值计算 |
| `月利率 = (1+年利率)^(1/12) - 1` | 月利率换算 |
| `利息 = 期初负债 × 期利率` | 利息计算 |
| `还本 = 支付 - 利息` | 还本计算 |
| `折旧 = 使用权资产 ÷ 租赁期` | 折旧计算 |

---

## 三、初始确认

### 3.1 公式

```
使用权资产 = 租赁负债 + 初始直接费用 + 预付租金 - 租赁激励
租赁负债 = 未来租金付款额的现值
```

## 八、三种付款方式对比汇总

### 8.1 核心数据对比

| 付款方式 | 期数 | 期利率 | 租赁负债 | 利息合计 | 利息占比 |
|----------|------|--------|----------|----------|----------|
| **月付** | 24期 | 0.4074% | **51.34万** | **2.66万** | 4.9% |
| **季付** | 8期 | 1.2272% | 51.14万 | 2.86万 | 5.3% |
| **年付** | 2期 | 5.0000% | 50.20万 | 3.80万 | 7.0% |

### 8.2 规律总结

```
支付越频繁：
├── 租赁负债越高（本金基数大）
├── 每期利息越低（还款更及时）
└── 总利息越低

支付越稀疏：
├── 租赁负债越低（折现次数少）
├── 利息滚存越多
└── 总利息越高
```

## 十、一句话总结

> **租赁会计的核心：起租日确认使用权资产=租赁负债，租赁期间折旧（直线法）+利息（实际利率法），到期日资产=0+负债=0。折旧累计=初始使用权资产，利息累计=时间成本，费用总计=租金支付，三者完美闭环。**
