## 〇、先承认问题：这是作者的问题

原稿配色只考虑了"好看、能区分业务语义"，**没有做对比度校验**：直接拿一批偏浅的中性色/彩色（Tailwind 400–500 号色）当底色并压白字，或用偏浅的灰字压在淡色底上。这些组合在正常显示器上就会"发飘"，在投影、亮度调低的笔记本、手机外屏上基本读不清。

不是显示器的问题，是配色未校验的问题。本次已全量审计 + 定向修复 + 逐项复算。

## 一、判定标准（WCAG 2.1）

| 内容类型 | 门槛 | 依据 |
|---|---|---|
| 正文小字（< 18pt，或粗体 < 14pt） | **≥ 4.5 : 1** | 1.4.3 Contrast (Minimum) |
| 大字号（≥ 18pt / 14pt 粗体） | ≥ 3 : 1 | 1.4.3 |
| 图形、图标、色块边界等非文字要素 | ≥ 3 : 1 | 1.4.11 Non-text Contrast |

计算式：相对亮度 L = 0.2126R + 0.7152G + 0.0722B（各通道先做 sRGB 线性化），对比度 = (L₁+0.05)/(L₂+0.05)。

**审计方法**：用脚本把每个"前景色 × 实际背景色"组合**逐一计算**（不靠肉眼、不靠印象），含 CSS 类、内联样式、SVG 文字 `fill` 三类来源。审计脚本见本文附录，可对任意新稿复跑。

## 四、修复原则与"故意没动"的边界

**改的原则（三类一起改，保证"同一标识同色"）：**
1. **文字色**——凡压在白卡、淡色卡上的灰字/彩字，加深；
2. **承载文字的底色**——凡要压白字的色块（砖条、占比条、池子），加深到白字 ≥ 4.5:1；利息池反向处理（改用浅绿底 + 深绿字，避免"绿底白字"这种先天不足）；
3. **与该文字构成同一标识的图形**（同一系列的折线、节点圆点、图例色块）——与文字同色，避免"线是这个橙、字是另一个橙"的观感错乱。

**故意没动（并说明理由）：**
- **网格线 `#eef2f6`、坐标轴 `#cbd5e1`、箭头连线与箭头标记 `#94a3b8`**：属纯装饰/结构线，不承载文字，1.4.11 对纯装饰不作要求；改动会破坏图的层次（网格线本就应该"退后"）。
- **暗色区块**（`#0f172a` 深底上的 `#e2e8f0 / #fdba74 / #93c5fd / #86efac / #94a3b8` 等）：实测 6.96–17.85:1，**本来就合格**，一动不动。
- **卡片描边 / 淡色边框**（`#e2e8f0`、`#cbd5e1`、`#bfdbfe` 等，实测 1.23–1.36:1）：属装饰分隔，非文字、非关键图形边界，未动。若日后要求"界线也要清晰"，可整体加深到 ≥ 3:1，属另一轮改动。
- **图二的 `--orange:#ea580c`、`--slate:#475569` 两个变量**：经检索**当前未被任何样式引用**（文字橙已一律走 `#c2410c`，橙底/橙边框走 `--orange-bg` / `--orange-bd`）。保留不删，避免无谓改动；后续若要清理死变量另开一轮。
- **同一语义在两个载体上保留一档明度差**：如"现金/还债"在折线与图例上为 `#64748b`，在白字占比条上为 `#475569`——白字需要更深的底，这是必要差异，不是不一致。

## 附录：对比度自检脚本（`contrast_audit.py`，与本说明同目录）

覆盖：① SVG `<text>` 文字色对白底；② 同一条 CSS 规则内的 `color` + `background`（自动展开 `var(--…)`）；③ 数据系列图形（`polyline` / `path` / `circle`）对白底。
不覆盖（需人工确认）：跨规则的继承底色（例：砖条的白字写在 `.brick`、底色写在 `.b3`）、深色区块上的浅色文字——这两类本次已逐条人工展开核对，结论见第二、三节。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""对比度自检脚本（WCAG 2.1）—— 支持 CSS 变量展开
用法：python contrast_audit.py 文件.html [更多文件...]
判定：正文小字 4.5:1；图形/非文字要素 3:1（脚本按 4.5 检查文字、按 3.0 检查折线/圆点类图形色）
输出：所有低于门槛的"前景色 × 背景色"组合；0 项即全部达标。
局限：跨 CSS 规则继承的背景需人工确认一次（脚本只能读到同一条规则里的 background）。
"""
import re, sys

def lum(h):
    h = h.lstrip('#')
    r, g, b = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)

def cr(a, b):
    la, lb = lum(a), lum(b)
    hi, lo = max(la, lb), min(la, lb)
    return round((hi + 0.05) / (lo + 0.05), 2)

def load(path):
    return open(path, encoding='utf-8').read().split('\n')

def vars_of(lines):
    v = {}
    for l in lines:
        for m in re.finditer(r'(--[\w-]+)\s*:\s*(#[0-9a-fA-F]{6})', l):
            v[m.group(1)] = m.group(2)
    return v

def expand(val, V):
    m = re.match(r'var\((--[\w-]+)\)', val)
    return V.get(m.group(1), '') if m else val

TOKEN = r'(?:var\(--[\w-]+\)|#[0-9a-fA-F]{6})'

def audit(path, t_text=4.5, t_graphic=3.0):
    lines = load(path); V = vars_of(lines); bad = []
    for i, line in enumerate(lines, 1):
        # 1) SVG 文字 fill（白底）
        for m in re.finditer(r'<text[^>]*fill="(#[0-9a-fA-F]{6})"[^>]*>(.*?)</text>', line):
            c = cr(m.group(1), '#ffffff')
            if c < t_text:
                bad.append((i, f"SVG文字 {m.group(1)} / #ffffff", c, re.sub(r'<[^>]+>', '', m.group(2))[:18]))
        # 2) 同一 CSS 规则内的 color + background（含变量展开）
        fg = re.search(r'(?:^|;)color:(' + TOKEN + r')', line)
        bg = re.search(r'background:(' + TOKEN + r')', line)
        if fg and bg:
            f, b = expand(fg.group(1), V), expand(bg.group(1), V)
            if f and b and not f.lower() in ('#ffffff', '#fff'):
                c = cr(f, b)
                if c < t_text:
                    bad.append((i, f"{f} / {b}", c, line.strip()[:60]))
        # 3) 数据系列图形（折线/路径/节点圆点）：对象为白底
        for m in re.finditer(r'<(polyline|path|circle)\b[^>]*?(?:stroke|fill)="(#[0-9a-fA-F]{6})"', line):
            if 'marker' in line:
                continue
            c = cr(m.group(2), '#ffffff')
            if c < t_graphic:
                bad.append((i, f"系列图形 {m.group(1)} {m.group(2)} / #ffffff", c, line.strip()[:60]))
                break
    print(f"=== {path} ===")
    for i, what, c, ctx in bad:
        print(f"  L{i:<5} {what} = {c}  {ctx}")
    print(f"  低于门槛项：{len(bad)}")
    return len(bad)

if __name__ == '__main__':
    files = sys.argv[1:] or ['一图看懂_使用权资产与租赁负债.html', '一图看懂_使用权资产全生命周期.html']
    total = sum(audit(f) for f in files)
    print(f"\n合计不合格项：{total}（0 即全部达标）")
```

## 后续约定
