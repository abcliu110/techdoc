# 校对规则清单（触发词化，按表执行）

校对的输出只有两种：**批注**（确定的错误，附修改建议）和**标黄**（存疑，让用户自己判断）。原文一字不改；表格内容红线见 SKILL.md。

## 一、批注类（确定错误）

**重复字**：连续相同的字/词——「的的」「了了」「是是」「进行进行」。排除合法叠词：常常、往往、渐渐、层层、种种、天天、人人、久久、缓缓、字面强调（如「很大很大」）。**重要排除**（实战踩过的坑）：「目的的」「标的的」（如"商业目的的安排""交易标的的价值"是合法结构，"的的"前一字为目/标时不报）；「为了了解/了结」中的「了了」不报。

**标点误用**：
- 中文语境用了半角标点：`,` `.` `;` `:` `?` `!` `()` → 应为全角（数字内的小数点和千分位逗号除外）
- 成对标点不配对：引号、括号、书名号缺一半
- 连续标点：「。。」「，，」「！！」
- 句末缺标点（段落末尾无。！？」）

**财务高频错别字**（可持续补充）：帐→账（会计科目一律用账）、摊消→摊销、记提→计提（计提坏账）、峻工→竣工、爆呆→暴呆、必竟→毕竟、以经→已经、按装→安装、定金/订金混用（提请确认）。

**数字格式错误**：
- 同列/同段小数位数不一致（「12.5%」和「12.50%」混用）
- 金额该有千分位没有、不该有的有了（判定见 SKILL.md 千分位规则）
- 「增长-3%」这类负增长表述 → 建议改「下降3%」

## 二、标黄类（存疑，让用户定夺）

**模糊限定词叠加**（出现 ≥2 个即标黄）：大概、可能、左右、上下、差不多、基本上、大约、估计、也许、应该（推测义）。
示例：「大概可能增长15%左右」命中 3 个 → 标黄并批注建议「预计增长约15%」。

**口径缺失模式**：
- 「增长/下降 x%」前后无「同比/环比/较预算/较上年」→ 标黄「未说明比较基期」
- 金额无单位（分不清元/万元）→ 标黄
- 「利润」未说明口径（毛利/净利/营业利润）且上下文推不出 → 标黄

**语病模式**：
- 「约…左右」「大约…上下」（语义重复）
- 「原因是…造成的」「目的是为了…」（句式杂糅）
- 超长句（整句 >80 字且无标点分隔）→ 标黄建议拆分

## 三、合计验算

表内出现「合计/总计」行时：明细数字去千分位转数值求和，与合计行比对，误差 >0.01 加批注：「合计与明细之和不符：明细合计 X，表载 Y，差异 Z」。百分比列、「—」空值列跳过验算。

## 四、执行顺序

先跑合计验算（最硬的错误），再扫批注类，最后扫标黄类。同一处命中多条规则只标一次，批注里合并说明。全文检查完在文档末尾加一条总批注：「校对完成：批注 X 处，标黄 Y 处，合计验算 Z 张表通过/发现问题」。
