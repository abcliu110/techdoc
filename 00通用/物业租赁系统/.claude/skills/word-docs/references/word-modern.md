适用：财务分析报告、经营分析、预算执行、制度/流程文件。所有硬性参数以 SKILL.md 为准，本文件补充结构和实现细节。

## 文档骨架

```
主标题（22pt 黑体加粗黑色居中，段前段后 0.5 行）
副题行（居中 10.5pt 灰色，如「财务部 · 2026年7月20日」）
一、核心结论（先行，3-5 条，每条一句话带关键数字）
二、正文分析（每节：结论句 → 数据表格 → 简短归因）
三、风险与建议
```

制度文件：标题 → 第一章 总则（目的、依据、适用范围）→ 分章条款（第X条）→ 附则（解释权、生效日期）。

## 实现要点

一律 `from docx_helpers import *`，用 `new_doc / h1 / h2 / body / table / landscape_section` 组装，不要手写样式。脚本已内置：仿宋+Palatino 分设、1.35 倍行距、段后 0、缩进 2 字符、autoSpace 关闭、页眉页脚、三线表全套。

生成文本时注意：

- 数字与中文之间不写空格：「4,286.35万元」「2026年6月」
- 正文日期「2026年6月」；表格日期「2026-06」
- 千分位只给金额和数量；手机号/编码/年份/文号不加
- 同比/环比写明基期；增减写「增长/下降x.x%」
- 关键结论放段首，数据作支撑

## 表格列宽算法

1. 数字列：按该列最长值（如 1,234,567.89）估宽（Palatino 10.5pt 约 0.19cm/字符）加 0.6cm 留白，保证不换行
2. 首列（科目/项目名）：按最长条目估宽（中文 10.5pt 约 0.37cm/字），个别超长条目可换行但不挤压数字列
3. 各列合计不超过版心宽（纵页 15.4cm）；超了先缩到 10pt，再不行 `landscape_section()` 转横页（横页版心 24.1cm）
4. 严禁出现一两个字折成两行的列
