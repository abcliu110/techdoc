# 公文风规范（通知 / 请示 / 函 / 报告）

依据《党政机关公文格式》(GB/T 9704) 的常用简化版，适合企业对内公文。

## 版面

- A4；页边距：上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm
- 正文 3 号仿宋（16pt，macOS 用 `STFangsong`，Windows 用 `仿宋_GB2312` 或 `仿宋`）
- 行距固定 28–30pt；首行缩进 2 字符（32pt）

## 结构与字体

| 元素 | 字体字号 | 对齐 |
|---|---|---|
| 标题 | 2 号小标宋/宋体加粗（22pt） | 居中 |
| 主送单位 | 3 号仿宋 16pt | 顶格，后接冒号 |
| 正文 | 3 号仿宋 16pt | 两端对齐 |
| 一级标题「一、」 | 3 号黑体 16pt | 缩进 2 字符 |
| 二级标题「（一）」 | 3 号楷体 16pt | 缩进 2 字符 |
| 三级标题「1.」 | 3 号仿宋加粗 | 缩进 2 字符 |
| 落款（单位、日期） | 3 号仿宋 | 右空 4 字符 |

- 标题格式：「关于××××的通知/请示/报告」；居中，可分两行，分行处语义完整
- 日期用汉字或阿拉伯数字全文一致，如「2026 年 7 月 20 日」
- 请示一文一事，结尾用「妥否，请批示。」；通知结尾常用「特此通知。」
- 公文不用点缀色，全文黑色；不加粗正文，不用花哨分隔线

## 附件

正文下空一行，顶格缩进 2 字符写「附件：1. ××××」，多个附件编号排列。
