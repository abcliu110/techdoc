# 财务文档规范（Eric 定制版）

这套规范是与 Eric 逐条讨论定稿的个人标准，**优先级高于任何通用排版习惯**。核心原则：美观的本质是一致；紧凑但不挤，正式但不呆板。

## 四个使用入口

1. **写新文档**：按下述规范直接生成。
2. **清洗排版**：用户扔来 AI 复制的内容或粘贴过的 Word，删除 `#`、`*`、反引号等 Markdown 符号、多余空格、连续空行；`#`→文档标题、`##`→「一、」、`###`→「（一）」，自动翻译成序号体系后按规范重排，输出成品。**自动编号一并落地**：Word 自动编号列表（numPr）转成文字编号写死在正文里（一、（一）1.（1）），复制导出永不错乱。
3. **格式统一**：别人发来的已排版 Word（字体杂、缩进乱、行距不一），先扫描全文段落结构（标题/正文/表格分类），再批量套用本规范重排。只动格式，文字内容一字不改；表格内容遵守下方红线。
4. **校对检查**：确定的错误（错别字、重复字如「的的」、标点误用）用 Word 批注给修改建议；存疑表述用黄色高亮，判定规则见 `references/proofread.md` 的触发词清单（模糊限定词叠加、口径缺失模式等），按清单执行不凭感觉。原文一律不直接改。表格合计行与明细自动验算，对不上加批注。python-docx ≥1.2 用 `doc.add_comment(runs=[...], text=..., author='word-docs 校对')`。

## 财务数据与口径红线（最高优先级，任何入口都适用）

- 处理用户已有文档时，**严禁自行增加、删除或修改表格里的任何内容**（数据、行列、表头文字都算）。发现疑似错误、缺行、需要补充或删减的内容，一律用批注说明建议，由用户自己动手改。格式（列宽、对齐、边框、底色）可以调，内容一个字不动。
- 不得凭空补充金额、日期、单位、比例、同比或环比。
- 不得把空白、缺失、未知自动改成 0。
- 不得静默修改正负号、百分比和单位。
- 计算结果注明计算口径；合计、同比、环比、占比需要验算。
- 分母为 0 时不得统一显示为 0；应根据实际情况显示「—」「N/A」或通过批注说明。
- 发现数值不一致时，只在修改日志和批注中说明，不擅自改动原始数据。
- **修改日志**：凡处理已有文档（清洗/格式统一/校对），交付时附一份修改说明——排版层面改了什么（字体、间距、编号转换等）、数据层面发现了什么问题（全部以批注呈现，未改动任何数值）。日志可写在交付消息里，问题多时另附文末总批注。

## 排版规格（定稿，勿改）

**页面**：A4 纵向；页边距上下 2.54cm、左右 2.8cm。页眉居中文档标题（9pt 灰 #808080，下加 0.5pt 细线 #BFBFBF）；页脚居中「第 X 页 共 Y 页」（PAGE/NUMPAGES 域代码）。列数多放不下的宽表，该页自动转横页。

**字体**（中西文必须分设，`w:eastAsia` 单独指定）：
- 正文：华文仿宋 `STFangsong`（Windows 用 `仿宋`），**数字也用仿宋**（不跟西文字体走）；仅纯英文单词用 `Palatino`（用 `write_text()` 自动拆分）
- 标题：黑体 `Heiti SC`（Windows 用 `黑体`）＋ `Arial`
- 所有标题一律黑色（#333333），不用彩色；正文 #333333；辅助信息灰 #808080

**正文段落**：**小四 12pt**（与 15pt 一级标题层差柔和）；行距 1.35 倍；**段后间距 0**；首行缩进 2 字符（24pt）；孤行控制开。
**数字与中文之间不留空格**（「4,286.35万元」直接相连），并在段落属性关闭 Word 自动间距：`autoSpaceDE=0`、`autoSpaceDN=0`。

**标题**：文档主标题 22pt 黑体加粗居中，**段前段后各 0.5 行（11pt）**——只有主标题留间距；一级 15pt（段前 6pt/段后 3pt）、二级 13pt（段前 4pt/段后 2pt）黑体加粗，层级标题间距压到很小，keep_with_next。层级序号：一、→（一）→ 1. →（1），连续不跳号，同级格式全文统一；**所有编号段落（含嵌套的（1）（2）级）一律只做首行缩进 2 字符，不加额外左缩进**。制度文件用 第一章/第X条。

**日期口径**：正文写「2026年6月」，表格写「2026-06」。

**文件命名**：「YYYYMMDD_文档名_v版本.docx」。

## 表格规格（投行风三线表）

- 三条横线：顶线 1.5pt、表头下线 0.75pt、底线 1.5pt；无竖线；表头**浅蓝 #DCE6F1** 底加粗（不用灰色）
- **必须写 tblGrid 列网格**（只设 cell.width 在 LibreOffice/部分 Word 下会失效），列宽按内容分配：数字列按最长金额定宽保证不换行，杜绝文字列一两个字被挤成两行
- 单元格**垂直居中**（vAlign center），行高 atLeast 420 twips，单元格段落 space 前后 0
- 数字列右对齐**且表头跟随右对齐**；首列左对齐；同列小数位一致
- 金额三位一逗＋两位小数，负数普通负号 -1,234.56；**千分位只用于金额和数量**（判断：带小数/带单位/表头含金额语义），手机号、编码、年份、文号一律不加
- 空值用「—」不写 0；合计行加粗＋上加 0.75pt 线＋**浅蓝 #DCE6F1 底**（与表头同色）
- 跨页：表头行重复（tblHeader）、单行不断开（cantSplit）、合计行不孤页
- 超过 10 行加 #F5F8FC 隔行浅底（浅蓝同色系）；短表纯三线
- 所有表编号「表 1：表题（单位：万元）」放表上方 10.5pt 黑体；口径说明放表下 9pt 灰色「注：…」
- 表格字号 10.5pt，中文黑体表头/仿宋表体，数字 Palatino

实现直接用 `scripts/docx_helpers.py`（含以上全部细节的成品函数），不要重写样式代码。

## 交付前自查

渲染 PDF 查看截图确认：无文字折行挤压、无孤行孤标题、序号连续、小数位统一、合计验算通过、中文未变方框（字体名平台差异）。暂不做：签批栏、金额大写、易错字表（用户以后要了再加）。
