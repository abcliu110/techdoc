## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 附录：折现率的选择

### 一、两种折现率

| 折现率类型 | 英文名称 | 视角 | 含义 |
|------------|----------|------|------|
| **租赁内含利率** | Implicit Rate | 出租人视角 | 使租赁收款额现值等于资产公允价值的利率 |
| **增量借款利率** | Incremental Borrowing Rate | 承租人视角 | 承租人为购买同类资产需要借入资金的利率 |

### 二、租赁内含利率详解

**定义**：出租人的隐含回报率，能使"资产价值 = 未来租金收款折现值"。

**通俗理解**：
```
┌─────────────────────────────────────────────────────────────────┐
│  想象你是出租人（房东）：                                       │
│                                                              │
│  你有一套价值1000万的房子，要租给租客5年。                    │
│  你决定每年收220万租金。                                      │
│                                                              │
│  检验：1000万 = 220万/(1+r)¹ + 220万/(1+r)² + ... + 220万/(1+r)⁵ │
│                                                              │
│  使上面等式成立的"r"，就是租赁内含利率 ≈ 5%                   │
└─────────────────────────────────────────────────────────────────┘
```

**特点**：
- 通常难以直接获取（出租人不一定会告诉你）
- 如果能可靠确定，准则要求优先使用

### 三、增量借款利率详解

**定义**：承租人为购买与租赁资产相似的资产，需要借入资金的利率。

**通俗理解**：
```
┌─────────────────────────────────────────────────────────────────┐
│  增量 = 新增借入的款项                                         │
│                                                              │
│  假设某公司已有银行贷款利率4%。                               │
│  如果公司要额外借钱买类似的设备，利率是多少？                  │
│  这个"额外借的钱"的利率 = 增量借款利率                       │
└─────────────────────────────────────────────────────────────────┘
```

**确定方法**：
- 参考同期银行贷款利率
- 考虑承租人的信用状况
- 考虑借款期限和抵押条件
- 考虑币种因素

### 四、两种利率的对比

| 对比项 | 租赁内含利率 | 增量借款利率 |
|--------|-------------|-------------|
| 视角 | 出租人 | 承租人 |
| 立场 | 出租人要多少回报 | 承租人借钱要付多少利息 |
| 获取难度 | 通常难以确定 | 容易确定 |
| 优先使用 | 是（如果能可靠确定） | 否 |
| 实际应用 | 很少使用 | 绝大多数情况使用 |

### 五、实际应用场景

**场景1：租赁一辆价值50万的车，租期3年**
- 如果知道出租人的期望回报率（如6%），用内含利率
- 如果不知道，用增量借款利率（如银行同期贷款利率5%）

**场景2：租金递增的租赁**
- 折现率全程不变（无论租金如何递增，利率不变）
- 递增的只是租金金额，不是利率

**场景3：系统实现**
```
增量借款利率（5%）
        ↓
    折现计算
        ↓
租赁负债现值 = Σ (每期租金 / (1+5%)^n)
```

### 六、准则要求

根据 IFRS 16 / CAS 21：

1. **优先使用内含利率**：如果承租人能确定租赁内含利率，应当使用该利率
2. **使用增量借款利率**：无法确定内含利率时，使用增量借款利率
3. **全程不变**：一旦确定，折现率在租赁期内保持不变
4. **增量租金的折现**：租金递增不影响折现率，只影响每期租金金额

## 二、入表的三步法

### 2.1 第一步：识别租赁合同

```
是否构成租赁？  →  存在"已识别资产"+"控制权转移"
                  ↓
                  是 → 进入第二步
                  否 → 按服务合同处理（如物业费、保洁费）
```

### 2.2 第二步：确认使用权资产（原值）

```
使用权资产原值 = 租赁负债初始金额
              + 租赁期开始日支付的租赁付款额
              + 初始直接费用（律师费、中介费等）
              - 租赁激励（出租人给予的现金奖励）
```

### 2.3 第三步：确认租赁负债（现值）

```
租赁负债 = Σ 各期租赁付款额 / (1 + 折现率)^n

其中：
- 折现率 = 租赁内含利率 或 承租人增量借款利率
- n = 各期付款日距起租日的期数
```

## 三、特殊场景的会计处理

### 3.1 免租期

**会计处理**：
1. 租赁负债按实际现金流时点折现（**不"分摊"**）
2. 使用权资产从起租日开始折旧（免租期内也计提）
3. 免租期租金为¥0，但账面负债仍按实际付款折现

### 3.2 租金递增

**会计处理**：
1. 递增前的固定租金 → 按实际付款时点折现
2. 递增后的租金 → **计入可变租赁付款额**，**不**入租赁负债
3. 每次递增时，**重新计量**租赁负债和使用权资产

### 3.3 短期租赁（≤12个月）的简化处理

```
借：管理费用—租赁费         XXX
    贷：银行存款                  XXX
```

**特点**：不入表（不确认使用权资产和租赁负债）

# 第三部分：备抵科目深层原理

## 六、核心矛盾：为什么有"贷方余额的资产科目"？

### 6.1 标准会计规则

| 科目类型 | 余额方向 |
|----------|----------|
| 资产 | 借方 |
| 负债 | 贷方 |
| 权益 | 贷方 |
| 费用 | 借方 |
| 收入 | 贷方 |

### 6.2 "累计折旧"的问题

**累计折旧：贷方余额**

```
按照标准规则：
  贷方余额 = 负债或权益

但累计折旧不是负债，不是权益
它记录的是"资产的消耗"

这就是矛盾：
  余额方向像负债
  本质却是资产的消耗
```

### 6.3 为什么必须存在这个矛盾？

**原因：历史信息需要保留**

| 需求 | 说明 |
|------|------|
| 知道原值 | 资产当初买成多少钱 |
| 知道消耗 | 资产已经折旧了多少 |
| 知道净值 | 资产现在还值多少 |

**如果不用备抵科目，直接减少资产**：

```
方案B（直接减）：
  使用权资产 = 500,000 - 21,394 = 478,606
  问题：看不出原值是多少

方案A（用备抵科目）：
  使用权资产 = 500,000（原值不动）
  累计折旧 = 21,394
  账面价值 = 478,606
  结果：原值、消耗、净值一目了然
```

## 七、为什么不能"直接借贷"？

### 7.1 分录对比

**方案A（现在用的）**：
```
借：管理费用    21,394
    贷：使用权资产累计折旧    21,394
```

**方案B（直接减少资产）**：
```
借：管理费用    21,394
    贷：使用权资产    21,394
```

### 7.2 方案B的问题

```
方案B执行后：
  使用权资产 = 500,000 - 21,394 = 478,606

  你能看出：
    - 原值是多少吗？ → 不能
    - 已经折旧了多少？ → 不能
    - 还剩多少？ → 能
```

### 7.3 方案A的优势

```
方案A执行后：
  使用权资产 = 500,000（原值不动）
  累计折旧 = 21,394
  账面价值 = 478,606

  你能看出：
    - 原值是多少？ → 500,000 ✓
    - 已经折旧了多少？ → 21,394 ✓
    - 还剩多少？ → 478,606 ✓
```

## 八、累计折旧的真实身份：计数器

### 8.1 分录示例：每期计提如何累加

**假设**：原值100,000，每月折旧1,000

**第1期末**：
```
分录：
  借：管理费用-折旧费      1,000
      贷：使用权资产累计折旧    1,000

账上结果：
  累计折旧余额：1,000
  账面价值：100,000 - 1,000 = 99,000
```

**第2期末**：
```
分录：
  借：管理费用-折旧费      1,000
      贷：使用权资产累计折旧    1,000

账上结果：
  累计折旧余额：1,000 + 1,000 = 2,000
  账面价值：100,000 - 2,000 = 98,000
```

### 8.2 累计折旧的变化过程

| 时间 | 计提金额 | 累计折旧余额 | 账面价值 |
|------|----------|--------------|-----------|
| 起租日 | - | 0 | 100,000 |
| 第1期末 | +1,000 | 1,000 | 99,000 |
| 第2期末 | +1,000 | 2,000 | 98,000 |
| 第3期末 | +1,000 | 3,000 | 97,000 |
| ... | ... | ... | ... |
| 第100期末 | +1,000 | 100,000 | 0 |

### 8.3 关键理解：贷方只增不减

**正常科目**：借贷都有发生
```
银行存款：
  借：存入 → 余额增加
  贷：取出 → 余额减少
  借贷平衡
```

**累计折旧**：只有贷方
```
累计折旧：
  贷：计提 → 余额增加（每月发生）
  借：无发生（永不发生）
  结果：只增不减
```

### 8.4 到期日（对冲清零）

```
第100期末：

对冲分录：
  借：使用权资产累计折旧    100,000
      贷：使用权资产          100,000

结果：
  使用权资产 = 0
  使用权资产累计折旧 = 0
```

### 8.5 矛盾汇总

| 矛盾 | 说明 |
|------|------|
| 矛盾1 | 贷方余额，却是资产类 |
| 矛盾2 | 只增不减，违反借贷规律 |
| 矛盾3 | 到期一次性清零 |

**结论**：累计折旧不是"正常"的会计科目，而是历史习惯留下的"计数器"。

# 第四部分：折旧、还本、租金的关系

## 九、租赁的本质分解

### 9.1 每月租金的分解

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   每月1万租金，分解为：                                     │
│                                                             │
│   ① 还本    ≈ 0.89万  ─→ 减少「租赁负债」               │
│      （第1期0.91万，逐期递减至0）                          │
│                                                             │
│   ② 付息    ≈ 0.11万  ─→ 增加「租赁负债」               │
│      （时间价值摊销，逐期递减至0）                          │
│                ↓                                             │
│            净效果：租赁负债净减少 ≈ 0.89万                   │
│                                                             │
│   ③ 折旧    = 0.89万  ─→ 减少「使用权资产」             │
│      （每月固定值）                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 9.2 三个概念的对应关系

| 项目 | 金额 | 性质 | 现金流出？ |
|------|------|------|------------|
| 折旧 | 0.89万/月（固定） | **资产减少** | ❌ 无现金流出 |
| 时间价值 | ≈0.11万/月（递减） | **负债增加** | ❌ 无现金流出 |
| 租金 | 1.00万/月（固定） | **实际支付** | ✅ 真实现金流出 |

### 9.3 为什么折旧 ≈ 还本？

**从会计平衡上**：

```
期初状态：
  使用权资产 = 21.4万
  租赁负债   = 21.4万

每月三笔分录的效果：
  ① 折旧 -0.89万  →  资产减少 0.89万
  ② 利息 +0.11万  →  负债增加 0.11万（时间价值摊销）
  ③ 付款 -1.00万  →  负债减少 1.00万

  资产净减少 = 0.89万
  负债净减少 = 1.00万 - 0.11万 = 0.89万 ✓

两者变化金额相等，这就是**折旧 ≈ 还本**的因果所在。
```

### 9.4 还本付息的类比

把租赁看作"分期付款买资产"：

```
你向出租人"借"了21.4万（使用权资产的价值）

每月还款 1万 = 还本 ≈0.89万 + 付息 ≈0.11万
            ↑        ↑
          折旧    时间价值
          (减少本金)  (支付利息)
```

## 十四、验证

### 14.1 负债验证

### 14.2 费用验证

```

实际租金支付总额 = 22,500 × 24 = 540,000
```

### 14.3 费用与付款的关系

| 项目 | 金额 | 说明 |
|------|------|------|
| 折旧累计 | 513,456 | 使用权资产消耗，进入利润表 |
| 时间价值累计 | 26,555 | 利息资本化，进入利润表 |
| 费用总计 | 540,011 | 折旧+时间价值 |
| 实际付款 | 540,000 | 用于偿还本金+利息 |
| **差额** | **≈0** | **完全对应** |

**为什么费用总计不等于24期租金（540,000）？**

因为最后一期只需支付剩余负债余额，不需要再付完整的22,500。具体来说：
- 第23期负债余额较小，只需支付余额清零
- 第24期也只需支付剩余部分
- 所以实际总付款略小于名义上的"24期租金"

## 十六、总结

### 16.1 一句话记忆

> **"一资一负一费用"**
> - **资**：使用权资产（资产负债表资产类）
> - **负**：租赁负债（资产负债表负债类）
> - **费用**：折旧 + 利息（利润表）

### 16.2 三大步骤

| 步骤 | 内容 |
|------|------|
| 1. 初始 | 确认使用权资产 + 租赁负债（现值） |
| 2. 后续 | 每月摊销利息 + 计提折旧 |
| 3. 终止 | 处置使用权资产，清偿租赁负债 |

### 16.3 报表列示

| 报表 | 列示科目 |
|------|----------|
| 资产负债表 | 使用权资产 + 租赁负债 |
| 利润表 | 折旧（费用）+ 利息（财务费用） |
| 现金流量表 | 租赁付款（筹资活动） |

### 16.4 三个关键关系

| 关系 | 说明 |
|------|------|
| 折旧 = 还本 | 资产减少 = 负债净减少 |
| 利息 = 负债增加 | 时间价值导致负债增加 |
| 租金 = 还本 + 利息 | 实际支付 = 本金减少 + 利息 |
