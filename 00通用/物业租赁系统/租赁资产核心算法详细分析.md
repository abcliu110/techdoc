# 租赁资产核心算法详细分析

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

### 2.3 第一步：填充支付计划（fillPayPlan）

**位置**：`LeaseUtil.fillPayPlan()` (第412-456行)

#### 2.3.0 负债折现 vs 资产折现（为什么会有两个折现？）

根据租赁会计准则（IFRS 16 / CAS 21），使用权资产的计算也需要折现：

| 折现对象 | 对应科目 | 含义 |
|----------|---------|------|
| **负债折现** | 租赁负债 | 未来应付租金的现值 |
| **资产折现** | 使用权资产 | 未来应付租金的现值 |

**核心区别**：

| 对比项 | 负债折现 | 资产折现 |
|--------|---------|---------|
| 折现起点 | 初始确认日 | 租赁期开始日 |
| 计算结果 | 写入 `presentvalue` | 写入 `presentvalue2` |

**为什么折现起点不同？**

主要是因为**存量租赁**（系统切换前已存在的租赁）：

```
场景：2020年1月1日开始租，2024年1月1日系统切换

时间线：
2020-01-01          2024-01-01          2026-01-01
    │                   │                   │
    │←── 旧租赁期 ────→│←── 剩余租期 ────→│
    │                   │                   │
租赁期开始日          初始确认日            租赁结束日

┌─────────────────────────────────────────────────────────────┐
│ 负债折现起点: 2024-01-01 (初始确认日)                       │
│  → 折现天数 = 付款日 - 2024-01-01                        │
│                                                              │
│ 资产折现起点: 2020-01-01 (租赁期开始日)                     │
│  → 折现天数 = 付款日 - 2020-01-01                        │
└─────────────────────────────────────────────────────────────┘
```

**会计分录示例**：

```
新增租赁时：
  借：使用权资产      469,000
      未确认融资费用   31,000
    贷：租赁负债      500,000

每月付款时：
  借：租赁负债        20,000
    贷：银行存款      20,000

每月利息：
  借：财务费用        3,000
    贷：未确认融资费用  3,000
```

#### 2.3.1 负债折现计算

```java
// 获取日折现率（从年利率转换）
BigDecimal dailyDiscountRate4Cal = dailyDiscountRate.divide(HUNDRED, 10, roundingMode);

// 对每条支付计划计算

    int liabDiscountDays = getDiffDays(initConfirmDate, planPayDate);

    BigDecimal liabDiscountFactor = (1 + dailyRate4Cal)^liabDiscountDays;

    // 负债现值 = 未付租金 / 折现因子
    BigDecimal liabPresentValue = unpaidRent / liabDiscountFactor;
}
```


### 2.6 关键公式总结

| 计算项 | 公式 |
|--------|------|
| 日利率 | `日利率 = 年利率 / 365` 或 `(1+年利率)^(1/365) - 1` |
| 负债折现因子 | `(1 + 日利率)^(付款日 - 初始确认日)` |
| 负债现值 | `未付租金 / 负债折现因子` |
| 资产折现因子 | `(1 + 日利率)^(付款日 - 租赁期开始日)` |
| 资产现值 | `租金 / 资产折现因子` |
| 累计折旧（方案A） | `资产原值 × 已执行月数 / 总月数` |

## 三、利息明细生成算法（按日实际利率法）

### 3.0 负债折现 vs 利息明细（核心区别）

| 对比项 | 负债折现（fillPayPlan） | 利息明细（InterestDetailGenerator） |
|--------|-------------------------|-------------------------------------|
| **计算粒度** | 每条支付计划行（付款日） | 每天 |
| **计算目的** | 得到资产负债表日的负债账面价值 | 跟踪每天的余额变化 |
| **计算公式** | `PV = 未付租金 / (1+日利率)^天数` | `利息 = (期初余额-支付) × 日利率` |
| **触发时机** | 合同提交时（一次性） | 合同审核时、每月结账 |
| **数据写入** | 写入 `payplanentryentity.presentvalue` | 写入 `fa_interest_detail` |

#### 3.3.2 实际日利率迭代计算（RealDailyIntRateCalculator）

**文件**：`RealDailyIntRateCalculator.java`

**核心思想**：已知负债现值和未来现金流，通过迭代找到使净现值为零的实际利率。

```java
public BigDecimal calculate() {
    // 未确认融资费用 = 负债原值 - 负债现值
    BigDecimal notConfirmFinCost = leaseLiabOri - leaseLiab;

    double dailyRate = initialDailyRate;

    // 二分迭代寻找使利息总额等于未确认融资费用的利率
    while (abs(difference) > tolerance) {
        if (difference > 0) {
            // 利息太多，减少利率
            dailyRate *= 0.98;
        } else {
            // 利息太少，增加利率
            dailyRate *= 1.01;
        }

        // 重新计算利息总额
        double interestTotal = calculateInterestTotal(dailyRate);
        difference = interestTotal - notConfirmFinCost;
    }

    return dailyRate;
}

// 计算给定利率下的利息总额
private double calculateInterestTotal(double r) {
    double interestTotal = 0;
    double balance = initialBalance;

    for (each day before last payment) {
        // 利息 = (期初余额 - 当日支付) × 日利率
        double intTemp = (balance - dailyPayment) * r;

        // 更新余额
        balance = balance - dailyPayment + intTemp;

        // 累加利息
        interestTotal += intTemp;
    }

    return interestTotal;
}
```

## 四、租赁负债余额生成算法（按期间汇总）

### 4.1 算法入口

**文件**：`FaLeaseDebitBalanceGenerator.java`
**方法**：`genLeaseDebitBalance()`

### 4.2 核心逻辑

```java
public Map<String, Object> genLeaseDebitBalance() {
    // Step 1: 按会计期间分组
    Map<Long, List<DetailRow>> periodMap = groupByPeriod(detailEntry);

    // Step 2: 计算每个期间的累计值
    for (Long periodId : sortedPeriodMap) {
        // 本期利息合计
        BigDecimal periodInterestSum = periodMap.get(periodId).sum(leaseliabint);

        // 本期支付合计
        BigDecimal periodPaySum = periodMap.get(periodId).sum(leaseliabpay);

        // 累计利息 = 上期累计利息 + 本期利息
        BigDecimal totalInterest = previousTotalInterest + periodInterestSum;

        // 累计支付 = 上期累计支付 + 本期支付
        BigDecimal totalPay = previousTotalPay + periodPaySum;

        // 创建余额记录
        LeaseDebitBalance balance = new LeaseDebitBalance();
        balance.amortizationPeriod = periodId;
        balance.interestBalance = totalInterest;      // 累计利息
        balance.leaseliaboribalance = totalPay;      // 累计还本
    }
}
```

## 七、公式速查表

| 计算项 | 代码方法 | 公式 |
|--------|----------|------|
| 日利率 | `getDailyRate()` | `(1 + 年利率)^(1/365) - 1` |
| 负债折现因子 | `fillPayPlan()` | `(1 + 日利率)^(付款日-初始确认日)` |
| 负债现值 | `fillPayPlan()` | `未付租金 / 折现因子` |
| 资产现值 | `fillPayPlan()` | `租金 / 折现因子` |
| 使用权资产 | `calFinInfoFields()` | `Σ资产现值` |
| 租赁负债现值 | `calFinInfoFields()` | `Σ负债现值` |
| 累计折旧(方案A) | `calFinInfoFields()` | `资产原值 × 已执行月数/总月数` |
| 日利息 | `generateForNotExemptContract()` | `(期初余额-支付) × 日利率` |
| 期末余额 | `generateForNotExemptContract()` | `期初余额 - 支付 + 利息` |
| 累计利息 | `genLeaseDebitBalance()` | `上期累计 + 本期利息` |
| 累计还本 | `genLeaseDebitBalance()` | `上期累计 + 本期支付` |
