# 原值与现值：会计结构的底层逻辑

> **目标**：从租赁案例提炼会计的底层结构规律，解释为什么需要"原值"和"现值"两个概念。

---

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 一、问题的提出

**从租赁出发的问题**：

```
租赁负债原值 = 未来应付总额（各期租金之和）
租赁负债现值 = 今天应付的金额（折现后的结果）
为什么要两个值？它们的结构关系是什么？
```

**追问**：这只是租赁的特殊情况吗？还是有更一般的规律？

---

## 二、会计的核心结构

### 2.1 复式记账的基本单元

**任何交易都有两个方向**：

```
借方（获得）= 贷方（付出）
```

**这意味着**：任何交易都是"等价交换"。

### 2.2 从复式记账到两个维度

复式记账告诉我们：任何交易都是"获得=付出"的等价交换。

但跨期合约有一个特殊问题：**今天拿到的东西（资产/权利），代价是未来分期支付的。**

于是产生了两个问题：

| 维度 | 问题 | 会计处理 |
|------|------|----------|
| **入账维度** | 今天账面记录多少？ | 原值 / 现值 |
| **受益维度** | 各期费用如何分配？ | 摊销 / 折旧 |

**注意**：入账维度和受益维度都涉及时间，但回答的问题不同：
- 入账维度回答：**今天**账面记多少（对未来金额折现）
- 受益维度回答：**各期**分摊多少（把时间成本分配到受益期间）

---

## 三、入账维度：今天账面记多少？

### 3.1 名义值 vs 现值

**任何跨越时间的合约都有两个值**：

```
名义值（原值）= 合约规定的未来应付总额（各期应付之和）
现值         = 名义值折现到今天的金额
```

### 3.2 现值 ≠ 名义值的原因

**因为货币有时间价值**：

```
今天的100万 ≠ 1年后的100万

今天的钱可以：
├── 存入银行获得利息
├── 投资获得回报
└── 承担风险获得补偿

所以：未来的钱需要"打折"才能和今天的钱比较
```

### 3.3 现值公式（年金型）

每期等额付款的现值公式：

```
现值 = 每期应付金额 × [1 - (1 + 利率)^(-期数)] / 利率

或者逐期折现后求和：
现值 = Σ 第n期应付金额 / (1 + 利率)^n
```

**注意**：公式 `现值 = 名义值 ÷ (1 + 利率)^期数` 仅适用于**一次性**未来付款，不适用于分期付款。

### 3.4 租赁具体例子

```
租赁合同：租期3年，每年年末支付租金40万
折现率：5%

名义值（原值）= 40 + 40 + 40 = 120万
现值         = 40/(1.05) + 40/(1.05)^2 + 40/(1.05)^3
             = 38.10 + 36.28 + 34.55
             = 108.93万

差额 = 120 - 108.93 = 11.07万（时间成本）

这笔差额就是"占用他人资金的时间代价"，
需要在3年中分期确认为利息费用。
```

## 四、受益维度：各期费用如何分配？

### 4.1 摊销的本质

**摊销 = 把总额分配到各受益期间**

```
受益期间 = 获得使用权的时间跨度
费用分配 = 总额 ÷ 受益期间
```

### 4.2 为什么要摊销？

**会计的配比原则**：费用需要和产生的收益在同一期间确认

```
如果一次性记费用：
├── 第1期：费用很大，利润很低
├── 第2期-第N期：没有费用，利润虚高
└── 不合理

摊销后：
├── 每期：费用和收益匹配
└── 合理反映各期经营成果
```

## 五、原值与现值的结构关系

### 5.1 三个值的含义

| 值 | 含义 | 作用 |
|------|------|------|
| **名义值（原值）** | 合约规定的未来应付总额 | 揭示义务完整性 |
| **现值** | 今天账面记录的金额（折现后） | 入账金额，确保报表平衡 |
| **差额** | 时间成本 = 原值 - 现值 | 在各期分期确认 |

### 5.2 正确的结构关系

**原值和现值是同一时点上的两个并列值，不是递进关系。差额是两者之差。**

```
                    ┌──────────────────────────────────┐
                    │          跨期合约                 │
                    │                                  │
                    │  同一时点，两个并列的值：          │
                    │                                  │
                    │  原值（未来应付总额）              │
                    │       ↕ 差 = 原值 - 现值          │
                    │  现值（今天应付的金额）            │
                    │                                  │
                    └──────────────────────────────────┘
                                        │
                    ┌───────────────────┴───────────────────┐
                    ↓                                       ↓
             差额（原值-现值）                        现值（入账金额）
             = 时间成本                               记录在资产负债表
                    │                                       │
                    │  在各受益期间分摊                    │
                    ↓                                       ↓
             各期利息/摊销费用                      随时间推进减少
             记录在利润表                           （接近零，不是原值）
```

### 5.3 折现和分摊的关系

**折现**和**分摊**是不同阶段的操作：

```
阶段一（入账时）：折现
  原值 ────折现────→ 现值（入账金额）
  → 把未来应付金额折算成今天的价值
  → 目的是确保报表平衡（入账金额 = 今天应付的金额）

阶段二（存续期）：分摊
  差额（原值-现值）──分摊──→ 各期利息费用
  → 把时间成本分配到各受益期间
  → 目的是实现期间配比

阶段三（付款时）：
  每期支付租金 = 本金偿还 + 利息费用
  → 本金偿还使租赁负债减少
  → 利息费用记入利润表
  → 现金流出，减少资产
  → 三者实为同一笔现金流出的三个记录角度
```

## 六、原值与现值的一般化规律

### 6.1 规律一：所有跨期合约都有原值和现值

**适用范围**：租赁、分期付款、债券、长期服务合同等

```
┌────────────────────────────────────────────────────┐
│                    跨期合约                           │
├────────────────────────────────────────────────────┤
│                                                    │
│   原值（名义值）  ←──── 差 = 原值-现值 ────→  现值 │
│       │                                        │   │
│       │   同一合约的两个并列值                  │   │
│       │   （不是递进，是同时间的两个视角）       │   │
│       ↓                                        ↓   │
│   未来应付总额                         今天应付金额   │
│   （各期之和）                         （折现结果）   │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 6.2 规律二：原值和现值的差额是时间成本

**为什么有时间成本？**

```
你今天获得了一项权利（使用权）

代价是什么？
├── 立即支付全部 → 现值 = 名义值 → 差额 = 0
└── 未来分期支付 → 现值 < 名义值 → 差额 > 0

差额 = 你占用他人资金的时间代价
```

### 6.3 规律三：差额需要分期确认

**差额如何分期？**

| 方法 | 计算 | 特点 |
|------|------|------|
| 直线法 | 差额÷期数 | 每期相同 |
| 实际利率法 | 余额×利率 | 前多后少 |

**补充：税务视角**。差额（时间成本）在税务上的处理可能与会计不同：
- **融资租赁**：税法要求按实际利率法确认利息，且租赁资产计提的折旧可税前抵扣，会计与税务的处理口径基本一致
- **经营租赁**：租金可在租赁期内均匀抵扣，无需确认租赁负债，税务处理相对简单
- 差异来源：会计和税务对"何时确认、确认多少"可能采用不同的方法和标准，产生暂时性差异，进而影响递延所得税

## 七、折旧与利息的统一结构

### 7.1 它们是同一件事的两个视角

**从资产视角看**：
```
使用权资产在消耗 → 价值减少 → 折旧费用
```

**从负债视角看**：
```
租赁负债在减少 → 余额变化 → 利息费用
```

### 7.2 统一的本质

**折旧和利息从不同角度描述了同一件事**：

```
从资产角度：使用权资产价值在消耗 → 折旧
从负债角度：租赁负债余额在减少 → 利息

两者描述的是同一个经济现实的两个不同视角。
```

**用具体数字验证**（接3.4租赁例子，利率5%）：

**说明**：本例中使用权资产采用直线法折旧（每期折旧 = 初始确认金额/期数），利息采用实际利率法（每期利息 = 期初负债余额×利率）。两种方法从不同角度描述价值消耗——折旧从资产消耗角度，利息从资金占用角度——口径不同，因此各期期末使用权资产和租赁负债余额不相等，这是正常的。

```
期初：使用权资产 = 108.93万，租赁负债 = 108.93万

第1年：
  利息费用 = 108.93 × 5% = 5.45万
  支付租金 = 40万
  本金偿还 = 40 - 5.45 = 34.55万
  期末租赁负债 = 108.93 - 34.55 = 74.38万

  折旧（直线法）= 108.93 / 3 = 36.31万
  期末使用权资产 = 108.93 - 36.31 = 72.62万

  → 期末使用权资产（72.62万）≠ 期末租赁负债（74.38万）
  → 这是因为折旧采用直线法、利息采用实际利率法，两者口径不同
  → 差额不是"未确认融资费用"，而是折旧与利息分摊方式不一致的自然结果

第2年：
  利息费用 = 74.38 × 5% = 3.72万
  支付租金 = 40万
  本金偿还 = 40 - 3.72 = 36.28万
  期末租赁负债 = 74.38 - 36.28 = 38.10万

  折旧 = 36.31万
  期末使用权资产 = 72.62 - 36.31 = 36.31万

第3年：
  利息费用 = 38.10 × 5% = 1.90万
  支付租金 = 40万
  本金偿还 = 40 - 1.90 = 38.10万
  期末租赁负债 = 0

  折旧 = 36.31万
  期末使用权资产 = 0
```

**观察**：
- 3年折旧合计 = 36.31 × 3 = 108.93万 = 初始使用权资产 ✓
- 3年利息合计 = 5.45 + 3.72 + 1.90 = 11.07万 = 原值-现值 = 时间成本 ✓

**折旧描述的是**：使用权资产的价值消耗了多少
**利息描述的是**：租赁负债的时间成本确认了多少

### 7.3 三年完整测算表

| 年份 | 期初余额 | 利息(5%) | 付款 | 还本 | 期末余额 |
|:----:|----------|-----------|------|------|----------|
| 1 | 108.93 | 5.45 | 40.00 | 34.55 | 74.38 |
| 2 | 74.38 | 3.72 | 40.00 | 36.28 | 38.10 |
| 3 | 38.10 | 1.90 | 40.00 | 38.10 | 0.00 |
| **合计** | - | **11.07** | **120.00** | **108.93** | - |

### 7.4 累计验证

| 验证项 | 计算 | 结果 | 结论 |
|--------|------|------|------|
| 折旧合计 | 36.31万 × 3年 | 108.93万 | ✅ 等于初始使用权资产 |
| 利息合计 | 5.45+3.72+1.90 | 11.07万 | ✅ 等于原值-现值 |
| 折旧+利息 | 108.93+11.07 | 120万 | ✅ 等于原值 |

**注意**：
- 单期：折旧 + 利息 ≠ 租金（第1年：36.31+5.45=41.76万 ≠ 40万）
- 累计：折旧 + 利息 = 原值（108.93+11.07=120万）

### 7.5 两者关系的准确表述

```
折旧和利息 = 从两个角度描述同一件事

折旧 = 使用权资产价值消耗了多少
利息 = 租赁负债时间成本确认了多少

两者共同揭示了：
  企业使用这项资产，完整付出了多少代价

它们不是"加起来等于什么"的关系
而是"从两个角度看同一个东西"的关系
```

## 八、一般化结论

### 8.1 会计结构的底层规律

**规律一：交易的等价性**

```
任何交易：借方 = 贷方
本质：获得 = 付出
```

**规律二：时间价值的普遍性**

```
任何跨期合约：名义值 ≠ 现值
原因：今天的1元 > 明天的1元
```

**规律三：费用的期间配比**

```
任何长期支出：总额需要分配到受益期间
目的：各期利润反映各期经营成果
```

### 8.2 原值和现值的一般定义

**原值**：
```
跨期合约的名义总额 = Σ 每期应付 × 期数
```

**现值**：
```
跨期合约的今天价值 = Σ 第t期应付金额 / (1 + r)^t
```

**差额**：
```
时间成本 = 原值 - 现值
```

## 九、一句话总结

**原值和现值是"跨期合约"在会计上的必然结构**：

```
原值 = 名义值（未来应付总额）→ 揭示义务完整性
现值 = 今天值（折现后）→ 入账金额，确保报表平衡
差额 = 时间成本（原值-现值）→ 在各期分期确认
```

**原值和现值是同一时点上的两个并列值，不是递进关系，差额是两者之差。折现是入账时的一次性操作，差额的分摊是后续各期的持续操作。**

**这个结构不只适用于租赁，而是所有跨期合约的共同规律。**
