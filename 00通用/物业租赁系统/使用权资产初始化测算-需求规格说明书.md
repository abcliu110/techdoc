## 1. 引言

### 1.1 目的

本文档旨在定义"使用权资产初始化测算"功能模块的业务需求、功能需求和非功能需求，作为后续系统设计和开发的依据。

### 1.2 业务场景

**本功能的业务场景**：**存量租赁初始化**

存量租赁是指系统切换前已存在的租赁合同，按照新租赁准则（IFRS 16 / CAS 21）要求，需要对这些老合同进行使用权资产的初始确认。

| 场景 | 说明 |
|------|------|
| 新增租赁合同 | 从零创建合同，同时完成使用权资产测算（本文档**不涉及**） |
| **存量租赁初始化** | **本文档核心场景**：对已存在的租赁合同进行首次使用权资产确认测算 |
| 租赁变更 | 合同条款变更后的重新测算（本文档**不涉及**） |

### 1.3 场景特点

| 特点 | 说明 |
|------|------|
| 合同已存在 | 租赁合同数据已录入系统（`dcfee_rent_contract` 表），无需新建 |
| 依赖现有数据 | 测算依赖合同基本信息、付款规则、租金信息等已有数据 |
| 初始确认日 | 通常为系统切换日，而非合同起租日 |
| 结果存储 | 测算结果写入专用表（如 `dcfee_right_of_use_asset`） |
| 可重新测算 | 支持对同一合同多次测算，保留测算历史 |

## 2. 业务概述

### 2.1 业务背景

根据《企业会计准则第21号——租赁》（新租赁准则），承租人需要在资产负债表中确认使用权资产和租赁负债。对于存量租赁（系统切换前已存在的租赁合同），需要进行初始化测算，确认初始计量金额。

### 2.2 业务目标

| 目标 | 说明 |
|------|------|
| 准确计量 | 按照新租赁准则要求，准确计算使用权资产原值和租赁负债 |
| 合规披露 | 生成符合会计准则的财务数据，支持资产负债表披露 |
| 利息摊销 | 按照实际利率法计算各期利息，实现租赁负债的摊销 |
| 折旧计提 | 支持使用权资产按期计提折旧 |

### 2.3 业务术语

| 术语 | 定义 |
|------|------|
| 使用权资产 | 承租人持有的在租赁期内使用租赁资产的权利 |
| 租赁负债 | 承租人尚未支付的租赁付款额的现值 |
| 折现率 | 用于将未来付款折算为现值的利率，通常为年利率 |
| 日利率 | 折现率转换为每日利率，用于按日计息 |
| 付款计划 | 约定各期租金支付的时间表和金额 |
| 未确认融资费用 | 租赁负债原值与现值之间的差额 |
| 累计折旧 | 使用权资产已计提的折旧总额 |

## 3. 业务规则

### 3.1 租赁期规则

| 规则 | 说明 |
|------|------|
| 租赁期定义 | 自租赁期开始日起至租赁结束日的完整期间 |
| 租赁期计算 | 按月计算，租赁结束日减去开始日的月份数 |
| 短期租赁豁免 | 租赁期 ≤ 12个月的租赁，可豁免确认使用权资产和租赁负债 |

### 3.2 付款频率规则

| 频率编码 | 频率名称 | 间隔月数 |
|----------|----------|----------|
| A | 月付 | 1 |
| B | 两月付 | 2 |
| C | 季付 | 3 |
| D | 半年付 | 6 |
| E | 年付 | 12 |
| F | 不定期 | -1 |

### 3.3 折现规则

| 规则 | 说明 |
|------|------|
| 折现基准日 | 初始确认日（首次确认使用权资产和租赁负债的日期） |
| 日利率计算 | `日利率 = (1 + 年利率)^(1/365) - 1` |
| 折现因子 | `(1 + 日利率)^折现天数` |
| 负债现值 | `未来付款金额 / 折现因子` |

### 3.4 付款项分类规则

| 分类编码 | 分类名称 | 会计处理 |
|----------|----------|----------|
| A | 本金类 | 计入租赁负债，影响使用权资产计算 |
| B | 费用类 | 如有增值税可抵扣，需区分含税/不含税处理 |
| C | 费用类（不计入） | 不计入使用权资产和租赁负债计算 |

### 4.4 数据处理需求

#### 4.4.1 核心计算逻辑

**折现计算**
```
负债折现因子 = (1 + 日利率)^(付款日 - 初始确认日)
负债现值 = 未付租金 / 负债折现因子

资产折现因子 = (1 + 日利率)^(付款日 - 租赁期开始日)
资产现值 = 租金 / 资产折现因子
```

**使用权资产计算**
```
使用权资产 = Σ(资产现值) + 预付款 + 首付款
```

**租赁负债计算**
```
租赁负债原值 = Σ(未付本金)
租赁负债现值 = Σ(负债现值)
```

**利息计算（按日实际利率法）**
```
日利息 = (期初余额 - 当日支付) × 日利率
期末余额 = 期初余额 - 当日支付 + 日利息
```

#### 4.4.2 计算精度要求

| 项目 | 精度要求 |
|------|----------|
| 利率计算 | 保留10位小数 |
| 金额计算 | 保留2位小数（四舍五入） |
| 折现因子 | 保留10位小数 |
| 利息明细 | 保留4位小数 |

## 8. 附录

### 8.1 财务函数速查

| 函数 | 公式 | 说明 |
|------|------|------|
| PV | `FV / (1+r)^n` | 未来值折现为现值 |
| FV | `PV × (1+r)^n` | 现值折算为未来值 |
| PMT | 分期付款额 | 每期等额支付金额 |
| NPER | 总期数 | 投资或贷款的期数 |
| RATE | 期利率 | 使NPV=0的折现率 |

### 8.2 核心公式

```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

### 8.3 准则差异（IFRS 16 vs CAS 21）

| 差异项 | IFRS 16 | CAS 21 |
|--------|---------|--------|
| 短期租赁豁免（≤12个月） | 必须简化处理 | 可自行选择 |
| 低价值租赁豁免 | 可豁免 | 可豁免 |
| 披露要求 | 较详细 | 略有简化 |

### 8.4 生命周期闭环验证规则

租赁会计的核心原则：从起租日到到期日，资产和负债必须完整闭环。

| 验证项 | 公式 | 说明 |
|--------|------|------|
| 期初：资产=负债 | 期初使用权资产 = 期初租赁负债 | 起租日一致 |
| 期末：资产=负债=0 | 期末使用权资产 = 期末租赁负债 = 0 | 到期日清零 |
| 折旧合计=使用权资产 | Σ累计折旧 = 初始使用权资产 | 折旧摊完 |
| 利息合计=时间成本 | Σ利息 = 租赁负债原值 - 现值 | 未确认融资费用摊销 |
| 费用总计=租金支付 | Σ(折旧+利息) = 总租金支付 | 费用完整覆盖 |

### 8.5 付款频率与利率换算

| 付款频率 | 期利率公式 | 说明 |
|----------|------------|------|
| 月付 | `(1+r)^(1/12)-1` | 折年率为月复利 |
| 季付 | `(1+r)^(1/4)-1` | 折年率为季复利 |
| 半年付 | `(1+r)^(1/2)-1` | 折年率为半年复利 |
| 年付 | `r` | 直接使用年利率 |

### 8.6 三种付款方式对比

| 付款方式 | 期数 | 期利率 | 租赁负债 | 利息合计 | 利息占比 |
|----------|------|--------|----------|----------|----------|
| **月付** | 24期 | 0.4074% | **51.34万** | **2.66万** | 4.9% |
| **季付** | 8期 | 1.2272% | 51.14万 | 2.86万 | 5.3% |
| **年付** | 2期 | 5.0000% | 50.20万 | 3.80万 | 7.0% |

**规律**：支付越频繁，租赁负债越高但总利息越低；支付越稀疏，租赁负债越低但总利息越高。
