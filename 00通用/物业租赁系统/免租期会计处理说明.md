# 免租期的会计处理 - CAS 21 / IFRS 16 解读

> 文档目的：澄清免租期在使用权资产测算中的正确处理方式
> 创建日期：2026-09-18
> 更新日期：2026-09-21

---

## 一、核心结论

**免租期不应该"分摊到每期租金"，而应该按实际现金流时点折现。**

原型HTML中的说法"免租期已分摊到每期租金中"是**不准确的**，容易误导。

---

## 二、CAS 21 / IFRS 16 对免租期的规定

### 2.1 租赁付款额的定义（CAS 21 第12条 / IFRS 16 第27条）

租赁付款额包括：
1. 固定付款额（扣除租赁激励相关金额）
2. 取决于指数或比率的可变租赁付款额
3. 购买选择权的行权价格
4. 行使终止租赁选择权需支付的款项
5. 根据担保余值预计应支付的款项

**关键点**：免租期属于"租赁激励"，应从固定付款额中扣除。

### 2.2 租赁激励的定义

租赁激励包括：
- 出租人向承租人支付的与租赁有关的款项
- 出租人为承租人偿付或承担的成本
- **免租期**（出租人放弃收取的租金）

### 2.3 会计处理原则

1. **租赁负债初始计量**（CAS 21 第13条 / IFRS 16第28条）：
   - 按未来租赁付款额的**现值**计量
   - 折现时使用租赁内含利率或承租人增量借款利率

2. **使用权资产初始计量**（CAS 21 第15条 / IFRS 16第24条）：
   - 租赁负债的初始计量金额
   - + 租赁期开始日或之前支付的租赁付款额
   - + 初始直接费用
   - - 租赁激励

3. **使用权资产折旧**（CAS 21 第20条 / IFRS 16第31条）：
   - **自租赁期开始日起计提折旧**
   - 即使处于免租期，折旧仍需计提

## 附录：财务函数对照表

| 缩写 | 全称 | 中文 | 含义 | 租赁场景示例 |
|------|------|------|------|-------------|
| **PV** | Present Value | 现值 | 未来的钱在今天的价值 | 租赁负债 = 未来各期租金的现值之和 |
| **FV** | Future Value | 未来值 | 现在的钱在将来的价值 | 100万存1年，年利率5%，FV=105万 |
| **PMT** | Payment | 付款额 | 每期支付的金额 | 月租金2.25万，PMT=22,500 |
| **NPER** | Number of Periods | 期数 | 总共多少期 | 租2年月付，NPER=24期 |
| **RATE** | Rate | 利率 | 每期利率 | 月利率 = (1+5%)^(1/12) - 1 ≈ 0.41% |
| **NPV** | Net Present Value | 净现值 | 现值减去初始投资 | NPV>0则投资可行 |
| **IRR** | Internal Rate of Return | 内部收益率 | 使NPV=0的折现率 | 租赁内含利率 |

**核心公式**：
```
现值 = 未来值 ÷ (1 + 利率)^期数
PV = FV / (1+r)^n

年金现值（每期金额固定）：
PV = PMT × [1 - (1+r)^(-n)] / r

利息 = 期初负债 × 期利率
还本 = 支付 - 利息
```

## 三、免租期的两种理解方式

### 方式1：免租期顺延首次付款日（✅ 推荐）

**业务理解**：
- 起租日：2024-07-01
- 免租期：3个月（2024-07-01 ~ 2024-09-30）
- 首次付款日：2024-12-31（免租期后第一个季度末）
- 后续付款：每季度末支付 ¥120,000

**付款时间表**：
| 期次 | 租赁期间 | 付款日 | 付款金额 |
|------|---------|--------|---------|
| 0 | 2024-07-01 ~ 2024-09-30 | - | ¥0（免租期） |
| 1 | 2024-10-01 ~ 2024-12-31 | 2024-12-31 | ¥120,000 |
| 2 | 2025-01-01 ~ 2025-03-31 | 2025-03-31 | ¥120,000 |
| ... | ... | ... | ... |

**折现计算**：
```
月利率 = (1+5%)^(1/12) - 1 = 0.4074%
季利率 = (1+5%)^(1/4) - 1 = 1.2272%

租赁负债 = ¥120,000 × [1-(1+1.2272%)^(-20)] / 1.2272%
         = ¥2,116,718
```

**会计分录（起租日 2024-07-01）**：
```
借：使用权资产  ¥2,116,718 + ¥35,000 = ¥2,151,718
  贷：租赁负债  ¥2,116,718
      银行存款  ¥35,000（初始直接费用）
```

**折旧处理**：
- 从2024-07-01开始计提折旧，不管是否处于免租期
- 月折旧额 = ¥2,151,718 / 60个月 = ¥35,862/月
- 2024-07-01 ~ 2024-09-30（免租期）仍需计提折旧 ¥35,862 × 3 = ¥107,586

---

### 方式2：免租期不顺延，但免租期内付款为0（⚠️ 容易误解）

**业务理解**：
- 起租日：2024-07-01
- 首次付款日：2024-09-30（首个季度末）
- 免租期：前3个月付款为0
- 第4个月起：每季度末支付 ¥120,000

**付款时间表**：
| 期次 | 租赁期间 | 付款日 | 付款金额 |
|------|---------|--------|---------|
| 1 | 2024-07-01 ~ 2024-09-30 | 2024-09-30 | ¥0（免租期） |
| 2 | 2024-10-01 ~ 2024-12-31 | 2024-12-31 | ¥120,000 |
| 3 | 2025-01-01 ~ 2025-03-31 | 2025-03-31 | ¥120,000 |
| ... | ... | ... | ... |

**折现计算**：
```
租赁负债 = ¥0 × (1+1.2272%)^(-1)  （第1期，免租）
         + ¥120,000 × (1+1.2272%)^(-2)  （第2期）
         + ¥120,000 × (1+1.2272%)^(-3)  （第3期）
         + ...
         = ¥1,998,173
```

---

### 方式3：免租期"分摊"到每期租金（❌ 错误理解）

**错误的理解**：
- 合同总租金 = ¥120,000 × 20期 = ¥2,400,000
- 免租期价值 = ¥120,000 × 1期 = ¥120,000
- 实际总租金 = ¥2,400,000 - ¥120,000 = ¥2,280,000
- 分摊到每期 = ¥2,280,000 / 20期 = ¥114,000

**为什么错误**：
1. **违反CAS 21的现金流折现原则**：
   - CAS 21要求按**实际付款时点**折现
   - 不能人为"平滑"租金到每期

2. **与合同条款不符**：
   - 合同约定每期¥120,000，不是¥114,000
   - 财务不能擅自修改合同条款

3. **无法解释后续计量**：
   - 每期实际支付¥120,000，但账上记¥114,000，差额¥6,000如何处理？
   - 会导致租赁负债余额与实际欠款不一致

## 四、两种方式对比

| 对比项 | 方式1（顺延付款日） | 方式2（首期为0） |
|--------|---------------------|-------------------|
| 首次付款日 | 2024-12-31 | 2024-09-30 |
| 付款期数 | 20期 | 20期 |
| 租赁负债 | ¥2,116,718 | ¥1,998,173 |
| 使用权资产 | ¥2,151,718 | ¥2,033,173 |
| 月折旧 | ¥35,862 | ¥33,886 |
| 利息（首期） | ¥8,984 | ¥7,955 |

**结论**：方式1的租赁负债更高，因为免租期延长了首次付款时间，融资时间更长。

## 五、原型图应该如何修正

### 当前原型的问题

1. **表格标题写"免租期已分摊到每期租金"是错误的**
   - 应该写"免租期顺延首次付款日"或"免租期内付款为0"

2. **第1期显示为2024-09-30付款¥120,000**
   - 如果这是免租期的最后一天，那应该付款为0
   - 如果免租期顺延，第1期应该是2024-12-31

3. **结果区显示"免租期折现价值 ¥32,400"容易误导**
   - 免租期的价值不应该单独显示
   - 应该说明"免租期导致首次付款延后X个月"

### 建议的修正方案

#### 方案A：明确免租期顺延（推荐）

**输入区增加字段**：
```
免租期处理方式：[ 顺延首次付款日 / 首期付款为0 ]
```

**如果选择"顺延首次付款日"**：
- 第1期起始日：2024-10-01（免租期后）
- 第1期付款日：2024-12-31
- 表格说明："免租期3个月（2024-07-01 ~ 2024-09-30），首次付款顺延至2024-12-31"

**如果选择"首期付款为0"**：
- 第1期起始日：2024-07-01
- 第1期付款日：2024-09-30
- 第1期付款金额：¥0
- 表格说明："第1期处于免租期，付款金额为0"

#### 方案B：删除误导性表述

删除以下内容：
- ❌ "免租期已分摊到每期租金中"
- ❌ "免租期折现价值 ¥32,400"

改为：
- ✅ "免租期3个月，首次付款顺延至2024-12-31"
- ✅ "免租期内使用权资产仍计提折旧 ¥107,586"

## 六、真实案例对比

### 案例：某公司租赁办公室

**合同条款**：
- 租期：5年（2024-07-01 ~ 2029-06-30）
- 月租金：¥10,000
- 免租期：前3个月（2024-07-01 ~ 2024-09-30）

**正确的会计处理**：

| 月份 | 实际付款 | 使用权资产折旧 | 利息费用 |
|------|---------|---------------|---------|
| 2024-07 | ¥0 | ¥3,000 | ¥1,200 |
| 2024-08 | ¥0 | ¥3,000 | ¥1,200 |
| 2024-09 | ¥0 | ¥3,000 | ¥1,200 |
| 2024-10 | ¥10,000 | ¥3,000 | ¥1,150 |
| 2024-11 | ¥10,000 | ¥3,000 | ¥1,100 |

**关键点**：
- 免租期内不付款，但仍计提折旧和利息
- 利息费用按租赁负债余额计算，逐月递减
- 不能把前3个月的¥30,000"分摊"到后57个月

## 七、总结与建议

### 会计准则要求

1. ✅ 免租期按**实际现金流时点**折现，不做"平滑"处理
2. ✅ 使用权资产从**起租日**开始折旧，不管是否免租
3. ✅ 免租期是租赁激励，影响使用权资产初始计量
4. ❌ 不能把免租期价值"分摊"到每期租金

### 原型修正建议

1. 删除"免租期已分摊到每期租金中"的错误表述
2. 增加"免租期处理方式"字段（顺延 vs 首期为0）
3. 分摊表第1期的处理要与免租期处理方式一致
4. 增加"免租期内仍需计提折旧"的提示
