# 复杂布局组件原型手册设计说明

## 目标

在一个可离线打开的 HTML 文档中，解释并演示 25 种布局类复杂 UI 组件。文档服务于产品设计、低代码平台设计、前端方案讨论和数据模型到界面模式的映射分析。

## 已确认设计

- 范围：第一阶段仅覆盖布局类 25 项，不加入表格、树、表单等后续类别。
- 结构：左侧固定目录，右侧一次聚焦一个组件，支持搜索、上一个、下一个和键盘导航。
- 内容模板：定义、数据模型、核心状态、交互原型、适用边界、关键不变量。
- 交互深度：每个组件至少实现一个能说明本质的关键交互，不扩展为完整页面设计器。
- 视觉方向：工业工程手册。炭黑导航、中性灰背景、琥珀色强调，强调信息密度和原型可读性。
- 技术边界：单个 HTML，原生 CSS 与 JavaScript，零外部依赖，双击即可运行。

## 原型分组

1. 空间划分：栅格、行列、Flex、分栏、分割面板、可调整尺寸面板。
2. 容器组织：停靠、标签页、折叠面板、卡片、瀑布流、嵌套容器。
3. 自由编排：仪表盘、拖拽网格、自由画布、可配置页面、多栏编辑器。
4. 响应适配：响应式布局、自适应断点、全屏/沉浸、主从分屏、侧边栏、抽屉。
5. 工作区管理：多窗口工作区、可保存工作区布局。

## 统一模型

布局组件统一抽象为：

```text
Layout = Container + Child[] + Constraint + State + Transition + Persistence?
```

- `Container`：可用空间与坐标上下文。
- `Child[]`：参与布局的内容节点。
- `Constraint`：尺寸、顺序、对齐、停靠、跨越、断点等约束。
- `State`：展开、选中、尺寸、位置、可见性等运行状态。
- `Transition`：点击、拖拽、缩放、切换视口等状态变化。
- `Persistence`：仅在工作区类组件中演示布局保存与恢复。

## 验收标准

- 25 个目录项与 25 个数据定义一一对应，无重复或缺失。
- 每项原型具有可见状态变化，且提供“重置原型”。
- 页面在桌面和移动视口均可浏览，无不可达内容或横向页面溢出。
- 键盘可切换目录，交互控件具有可见焦点。
- 文件不引用外部脚本、字体、样式或图片。
- UTF-8 中文无连续问号、替换字符或常见乱码片段。

## 已知边界

- 原型用于解释布局机制，不等于生产组件实现。
- 拖拽与缩放只覆盖代表性行为，不处理协作编辑、复杂撤销栈和服务端持久化。
- 移动端优先保证文档可读和交互可达，不强求在窄屏完整模拟桌面设计器。
