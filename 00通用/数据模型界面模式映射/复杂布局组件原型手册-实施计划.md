# 复杂布局组件原型手册实施计划

**目标：** 交付一个包含 25 个布局复杂组件关键交互原型的离线 HTML 手册。

**架构：** 单文件应用。静态 CSS 提供工程手册视觉和响应式外壳；JavaScript 数据数组保存 25 项说明；原型渲染函数按当前目录项生成演示；事件委托统一处理点击、输入、拖拽、键盘和持久化。

**技术栈：** HTML5、CSS3、原生 JavaScript、localStorage。

## 任务

- [ ] 建立静态验收脚本，先确认目标 HTML 缺失时检查失败。
- [ ] 实现文档外壳、25 项数据定义和统一详情模板。
- [ ] 为每项实现至少一个可见的关键交互与重置能力。
- [ ] 增加目录搜索、上一个/下一个、方向键导航和移动端目录。
- [ ] 验证离线结构、编码、桌面和移动端布局、控制台与关键交互。

## 验证命令

```powershell
node D:\tmp\verify-layout-prototypes.cjs <HTML绝对路径>
```

预期：输出 `PASS: 25 layout prototypes verified`，退出码为 `0`。
