# 复杂 UI 组件交互原型手册套件说明

## 本轮范围

本套件按用户指定范围覆盖原复杂组件清单的第 1-9 类与第 15-18 类，共 13 个类别、309 个组件原型。

第 10-14 类不在本轮请求范围内：

- 10. 日历、时间与项目管理类
- 11. 数据可视化类
- 12. 地图与空间类
- 13. 文件与素材管理类
- 14. 图片、音视频与三维类

## 统一结构

每篇文档均包含：

1. 左侧组件目录与搜索。
2. 组件定义与英文名称。
3. 统一模型、数据模型与核心状态。
4. 可操作的关键交互原型。
5. 适用边界与关键不变量。
6. 上一项、下一项、重置和键盘切换。
7. 移动端目录与局部原型画布滚动。

## 生产级交互规范

本套件现按“统一底线 + 风险分层”验收。它是高保真、可完整演示、可供产品/业务/研发联合评审的交互规范，不是可直接发布到业务系统的组件库。

统一底线适用于全部 309 项：

- 初始态呈现角色、任务、业务对象、决策规则和预期影响。
- 主路径执行组件自身的独立交互，并在主体区域呈现业务结果。
- 每项均可触发非理想场景，显示失败原因，并执行明确的恢复动作。
- 异常和恢复控件可由键盘到达和执行，重置后回到一致初态。
- 桌面与移动端均要求内容可达、无阻断溢出、无运行时错误和不安全文本注入。

风险分层在统一底线上增加要求：

- 布局、树、选择器、导航：上下文保持与返回路径。
- 表格、表单、查询：数据完整性、空态/失败、校验和版本冲突。
- 编辑器、低代码、流程：未保存内容、校验定位、撤销或版本恢复。
- 权限、协作：范围解释、拒绝原因、审计、冲突、离线重放和去重。
- 业务复合：至少三个对象、双职责、跨模块规则、事件时间线和补偿路径。

## 技术边界

- 每篇为独立 HTML，使用原生 CSS 和 JavaScript，无外部依赖。
- 原型用于说明组件本质、数据关系和状态变化，不替代生产组件库。
- 309 个清单条目分别登记 309 个显式 renderer；每项都有自己的初始数据、关键操作、可观察状态变化和重置结果。
- 只共享页面外壳、基础样式、安全 DOM 工具和生命周期管理，不共享会掩盖组件差异的行为级原型模板，也不存在默认或兜底 renderer。
- 后续新增类别时，应新增独立 HTML 并更新总索引，不把所有类别合并为一个超大运行文件。

## 构建与验证

源码位于 `prototype-suite/`，现有 13 册 HTML 和总索引是可独立打开的生成产物。

```powershell
# 校验 13 类 / 309 组件 / 309 renderer / 309 contract
node .\test-prototype-suite.mjs --static

# 生成 13 册与总索引
node .\build-prototype-suite.mjs

# 启动本地静态服务后执行 309 项浏览器回归
python .\prototype-suite\browser-regression.py --url http://127.0.0.1:8765 --viewport 1440x900
python .\prototype-suite\browser-regression.py --url http://127.0.0.1:8765 --viewport 390x844

# 重放已确认的安全、状态、历史导航和可访问性缺陷
python .\prototype-suite\confirmed-regressions.py

# 验证键盘异常/恢复路径及每类代表性主路径
python .\prototype-suite\keyboard-audit.py --url http://127.0.0.1:8765

# 生成代表性桌面/移动截图证据
python .\prototype-suite\capture-production-evidence.py --url http://127.0.0.1:8765
```
