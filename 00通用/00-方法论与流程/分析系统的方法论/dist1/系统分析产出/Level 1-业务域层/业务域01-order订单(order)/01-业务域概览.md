# 01-业务域概览

## 1. 业务域基本信息

| 属性 | 值 |
|------|-----|
| 业务域名称 | 订单(order) |
| 优先级 | P0 |
| 包含上下文数 | 5 |
| 核心概念 | 订单、订单明细、支付、退款、反结账 |

## 2. 包含的上下文

| 上下文名称 | 优先级 | 说明 |
|-----------|--------|------|
| order-订单创建 | P0 | 订单创建与明细管理 |
| order-订单查询 | P0 | 订单列表与详情查询 |
| order-订单支付 | P0 | 订单支付与找零 |
| order-订单退款 | P0 | 订单退款处理 |
| order-反结账 | P0 | 反结账与状态回退 |

## 3. 核心概念汇总

| 概念 | 说明 | 涉及上下文 |
|------|------|-----------|
| 订单主体 | 包含桌台、人数、备注等基本信息 | order-订单创建 |
| 订单明细 | 包含商品、做法、数量、单价等 | order-订单创建 |
| 支付信息 | 包含支付方式、金额、找零等 | order-订单支付 |
| 退款信息 | 包含退款原因、退款金额等 | order-订单退款 |

## 4. 跨上下文关系

| 上下文A | 上下文B | 关系 |
|---------|---------|------|
| order-订单创建 | order-订单支付 | 订单创建后进入支付 |
| order-订单支付 | order-订单退款 | 支付后可申请退款 |
| order-订单支付 | order-反结账 | 支付后可反结账 |
| order-订单创建 | order-订单查询 | 创建后可供查询 |
