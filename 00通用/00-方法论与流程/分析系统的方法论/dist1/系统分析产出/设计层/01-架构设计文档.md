### 1.2 上下文职责

| 限界上下文 | 核心职责 | 依赖上下文 |
|------------|---------|-----------|
| order | 订单全生命周期 | member, goods, promotion |
| print | 票据打印 | order |
| member | 会员管理 | - |
| goods | 商品管理 | - |
| kds | 厨房显示 | order |
| takeout | 外卖订单 | order, member |
| promotion | 促销规则 | order |
| table | 桌台管理 | order |

## 2. 架构模式

### 2.1 分层架构

```
┌─────────────────────────────────────────┐
│              表现层 (Presentation)            │
│         Electron Renderer Process           │
├─────────────────────────────────────────┤
│              应用层 (Application)            │
│            Service / UseCase              │
├─────────────────────────────────────────┤
│              领域层 (Domain)              │
│       Entity / Aggregate / DomainEvent     │
├─────────────────────────────────────────┤
│              基础设施层 (Infrastructure)    │
│         DAO / ExternalService / MQ         │
└─────────────────────────────────────────┘
```

### 2.2 六边形架构

```
                    ┌─────────────────┐
                    │   Input Ports   │
                    │  (Controller)   │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │                 │
                    │   Application   │
                    │    Service     │
                    │                 │
                    └────────┬────────┘
                             │
┌─────────────────┐    ┌──────▼──────┐    ┌─────────────────┐
│  PrintAdapter   │◄──►│   Domain    │◄──►│  MemberAdapter │
└─────────────────┘    │   Model    │    └─────────────────┘
                       │             │
┌─────────────────┐    │  Ports     │    ┌─────────────────┐
│  KdsAdapter    │◄──►│ (Interface)│───►│   OrderAdapter  │
└─────────────────┘    └────────────┘    └─────────────────┘
```

## 3. 核心聚合设计

### 3.1 Order聚合

```
Order (聚合根)
├── OrderDetail[] (实体)
├── OrderPay[] (实体)
├── OrderStatus (值对象)
└── OrderSale (值对象)
```

### 3.2 Member聚合

```
Member (聚合根)
├── MemberLevel (值对象)
├── MemberPoints (值对象)
└── MemberBalance (值对象)
```

## 4. 领域事件

| 事件 | 发布上下文 | 订阅上下文 | 事件数据 |
|------|----------|-----------|----------|
| OrderCreated | order | print, kds | {billNo, items} |
| OrderPaid | order | member | {billNo, points} |
| MemberRegistered | member | order | {memberId} |
| GoodsSoldOut | goods | order | {goodsId} |

## 5. 战术设计

### 5.1 实体生命周期

| 实体 | 创建 | 更新 | 删除 |
|------|------|------|------|
| Order | 点餐时 | 支付/加菜 | 30天后归档 |
| Member | 注册时 | 信息变更 | 注销 |

### 5.2 领域服务

| 领域服务 | 职责 | 限界上下文 |
|----------|------|-----------|
| OrderDomainService | 订单状态机 | order |
| PaymentDomainService | 支付策略 | order |
| DiscountDomainService | 促销计算 | promotion |

### 5.3 仓储接口

| 仓储 | 接口 | 实现 |
|------|------|------|
| OrderRepository | save(), findById(), findByBillNo() | OrderDao |
| MemberRepository | save(), findById(), findByPhone() | MemberDao |
