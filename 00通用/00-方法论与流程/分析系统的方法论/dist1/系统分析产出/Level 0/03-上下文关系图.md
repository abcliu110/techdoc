## 核心上下文依赖关系

### P0核心链路

| 序号 | 依赖关系 | 说明 | 代码位置 |
|------|---------|------|----------|
| 1 | base → goods | 基础数据支撑商品管理 | base配置商品参数 |
| 2 | goods → order | 商品加入订单 | OrderDetail关联Goods |
| 3 | order → print | 订单触发打印 | PrintService接收Order |
| 4 | order → member | 订单关联会员 | MemberDiscount |
| 5 | base → order | 员工/班次关联订单 | createdBy, shiftId |

### P1重要依赖

| 序号 | 依赖关系 | 说明 |
|------|---------|------|
| 6 | order → kds | 订单发送厨房 |
| 7 | kds → print | 厨房打印指令 |
| 8 | order → promotion | 促销规则应用 |
| 9 | order → takeout | 外卖订单创建 |
| 10 | goods → soldout | 商品库存联动沽清 |
| 11 | takeout → soldout | 外卖商品同步 |

### P2辅助依赖

| 序号 | 依赖关系 | 说明 |
|------|---------|------|
| 12 | order → table | 订单关联桌台 |
| 13 | order → book | 预订转为订单 |
| 14 | order → shiftDaily | 班次/日结汇总订单 |

## 上下文协作矩阵

| 上下文A | 上下文B | 协作类型 | 协作内容 |
|--------|---------|---------|---------|
| order | print | 调用 | 订单完成触发打印小票 |
| order | kds | 调用 | 订单创建推送厨房显示屏 |
| order | member | 查询/更新 | 查询会员信息，应用优惠 |
| order | promotion | 查询/应用 | 应用折扣、满减、优惠券 |
| order | takeout | 创建/同步 | 创建外卖订单，状态同步 |
| order | table | 关联 | 订单关联桌台信息 |
| order | soldout | 扣减 | 订单完成扣减库存 |
| goods | soldout | 监控 | 商品库存触发沽清 |
| goods | promotion | 参与 | 商品参与促销活动 |
| kds | print | 调用 | 厨房打印出品单 |
| member | promotion | 查询 | 会员优惠查询 |
| takeout | print | 调用 | 外卖小票打印 |
| base | 所有上下文 | 基础支撑 | 组织、员工、班次、配置 |

## 关键集成点

| 集成点 | 类型 | 涉及的上下文 |
|--------|------|-------------|
| 订单创建 | 业务聚合 | goods, member, promotion, base |
| 订单支付 | 业务聚合 | order, member, promotion |
| 打印触发 | 事件触发 | order, kds, takeout |
| 厨房协同 | 消息推送 | order → kds → print |
| 外卖同步 | 第三方对接 | takeout ↔ 美团/饿了么 |

## 系统边界

### 内部系统

- kaci-pos-localserver：核心业务服务
- kaci-pos-front：前端界面

### 外部系统

| 外部系统 | 接口类型 | 集成上下文 |
|----------|---------|-----------|
| 美团开放平台 | API/MQ | takeout-美团 |
| 饿了么开放平台 | API/MQ | takeout-饿了么 |
| 云端服务 | HTTP | base-配置同步 |
| 打印设备 | 串口/网络 | print-* |
