# 01-上下文概览

## 基本信息

| 属性 | 值 |
|------|-----|
| 上下文名称 | order-订单创建 |
| 上下文描述 | 订单创建与明细管理 |
| 优先级 | P0 |
| 所属业务域 | order-订单 |
| 代码路径 | com/shouqianba/localserver/order/ |

## 核心职责

1. 创建新订单（堂食/外卖/自提）
2. 管理订单明细（加菜、删菜、改数量）
3. 计算订单金额（原价、优惠、应付）
4. 关联会员信息和促销优惠

## 主要实体

| 实体名 | 类型 | 说明 |
|--------|------|------|
| OrderMasterDO | 聚合根 | 订单主体 |
| OrderDetailDO | 实体 | 订单明细 |
| OrderStatusDO | 值对象 | 订单状态 |
| OrderSaleDO | 值对象 | 销售信息 |
| OrderPay | 实体 | 支付记录 |
| OrderDetailPromotion | 实体 | 明细优惠 |

## 技术实现

| 组件 | 说明 |
|------|------|
| 数据库 | SQLite (ORMLite) |
| 持久化表 | tbl_order, tbl_order_detail, tbl_order_detail_promotion |
| 缓存 | PayMutexShare (支付互斥锁) |
| 通信 | Netty长连接 |

## 入口服务

- `OrderMasterService`: 订单主服务
- `OrderGiveService`: 赠送服务
- `BusinessQueryService`: 业务查询
