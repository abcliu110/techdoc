## 2. 对象详情

### 2.1 OrderMasterDO（订单聚合根）

#### 2.1.1 类型判定
| 判定项 | 结论 | 依据 |
|---------|------|------|
| 实体/值对象 | 实体(聚合根) | 有唯一标识billNo，有完整生命周期 |
| 聚合根/成员 | 聚合根 | 外部通过billNo引用，包含明细集合 |

#### 2.1.2 属性/字段
| 属性 | 类型 | 说明 | 约束 |
|------|------|------|------|
| billNo | String | 账单编号 | PK，唯一，非空 |
| orderNo | String | 订单编号 | 业务标识 |
| orderStatus | Integer | 订单状态 | OrderStatusEnum |
| orderTotalAmount | BigDecimal | 订单总额 | >= 0 |
| orderDiscountAmount | BigDecimal | 订单优惠金额 | 折扣优惠 |
| payDiscountAmount | BigDecimal | 支付优惠金额 | 满减/券优惠 |
| actualReceiptAmount | BigDecimal | 实收金额 | >= 0 |
| bizType | Integer | 业务类型 | 堂食/外卖/自提 |
| platformType | Integer | 平台类型 | 本地/美团/饿了么 |
| workDate | Long | 营业日 | 时间戳 |
| operatorId | Long | 操作员ID | 非空 |
| detailList | List<OrderDetailDO> | 订单明细 | 聚合边界内 |

#### 2.1.3 方法/操作
| 方法 | 输入 | 输出 | 业务含义 |
|------|------|------|----------|
| pay() | OrderPay | void | 现金支付 |
| cashPay() | OrderPay, changeAmount | void | 现金支付（含找零）|
| onlinePay() | OrderPay | void | 在线支付 |
| cancelPay() | OrderPay | OrderPay | 取消支付(反结账) |
| refund() | OrderPay | void | 退款 |
| getUnpaidAmount() | - | BigDecimal | 计算未付金额 |
| isPayed() | - | boolean | 是否已结账 |
| payComplete() | - | void | 支付完成 |

#### 2.1.4 生命周期
| 阶段 | 触发条件 | 操作 |
|------|----------|------|
| 创建 | 收银员开始点餐 | 新建OrderMasterDO，status=待结账 |
| 使用 | 添加/修改菜品 | 更新detailList |
| 结算 | 支付成功 | status=已结账，释放PayMutexShare锁 |
| 退款 | 发起退款 | status=已退款/已冲销 |
| 归档 | 日结后 | 状态变更或归档处理 |

#### 2.1.5 状态机
```
待结账(10) ──支付成功──▶ 已结账(20) ──退款──▶ 待退款(29)
    │                       │                      │
    │                       ▼                      ▼
    └──反结账──▶ 已结账 ◄──────── 已退款(30) ◄───┘
                            │
                            ▼
                      已冲销(40)
```

#### 2.1.6 关系/关联
| 类型 | 对象 | 说明 |
|------|------|------|
| has-many | OrderDetailDO | 一个订单包含多个明细 |
| has-many | OrderPay | 一个订单有多次支付记录 |
| has-one | OrderStatusDO | 订单有一个状态信息 |
| has-one | OrderSaleDO | 订单有一个销售汇总 |

## 3. 聚合边界

| 聚合根 | 包含对象 | 事务边界 |
|--------|-----------|----------|
| OrderMasterDO | OrderDetailDO, OrderStatusDO, OrderSaleDO | 订单操作原子性 |
