# 09-接口契约

## 1. 对外接口

### 1.1 订单创建
| 接口 | 说明 | 输入 | 输出 |
|------|------|------|------|
| 创建订单 | 新建订单 | OrderMasterDTO | billNo |
| 添加商品 | 添加商品明细 | goodsId, qty | detailId |
| 修改数量 | 修改商品数量 | detailId, qty | - |
| 删除商品 | 删除商品明细 | detailId | - |

### 1.2 订单支付
| 接口 | 说明 | 输入 | 输出 |
|------|------|------|------|
| 现金支付 | 现金收款 | payAmount, actualAmount | changeAmount |
| 在线支付 | 第三方支付 | payChannel, payAmount | payStatus |
| 取消支付 | 取消支付 | payId | - |

### 1.3 订单查询
| 接口 | 说明 | 输入 | 输出 |
|------|------|------|------|
| 查询订单 | 获取订单详情 | billNo | OrderMasterVO |
| 查询列表 | 获取订单列表 | queryCondition | List<OrderVO> |

## 2. 内部接口

| 接口 | 调用方 | 被调用方 | 说明 |
|------|--------|---------|------|
| getGoodsInfo | OrderMasterService | GoodsService | 获取商品信息 |
| getMemberDiscount | OrderMasterService | MemberService | 获取会员优惠 |
| applyPromotion | OrderMasterService | PromotionService | 应用促销活动 |
| triggerPrint | OrderMasterService | PrintService | 触发打印 |

## 3. 事件定义

| 事件名 | 触发条件 | 事件数据 |
|--------|----------|----------|
| OrderCreated | 订单创建成功 | {billNo, orderNo, orderTotalAmount} |
| OrderPaid | 订单支付成功 | {billNo, payAmount, payMethod} |
| OrderRefunded | 订单退款成功 | {billNo, refundAmount, reason} |
| OrderCancelled | 订单取消 | {billNo, reason} |

## 4. 第三方集成

| 平台 | 集成方式 | 主要接口 |
|------|---------|---------|
| 微信支付 | API | 扫码支付、退款 |
| 支付宝 | API | 扫码支付、退款 |
| 美团 | MQ | 订单同步 |
| 饿了么 | MQ | 订单同步 |
