# 07-规则依赖图

## 1. 规则依赖关系

### 1.1 依赖类型

| 依赖类型 | 含义 | 示例 |
|---------|------|------|
| 强依赖 | A必须先于B校验 | 未付金额计算→支付金额校验 |
| 弱依赖 | A和B顺序无关 | 找零计算→发票开具 |
| 条件依赖 | A在某条件下依赖B | 会员优惠叠加→有会员信息 |

### 1.2 依赖图

```
R01 订单号唯一 ──强依赖──► [订单创建前置]
        │
        ▼
R02 未付金额计算 ──强依赖──► R03 支付金额校验
        │
        ├──强依赖──► R04 优惠分摊
        │
        ▼
R05 状态流转 ──强依赖──► R08 反结账计数
        │
        ▼
R09 退款关联 ──强依赖──► R05 状态流转

R06 会员优惠叠加 ──条件依赖──► [会员登录]
        │
        ▼
R04 优惠分摊

R07 找零计算 ──弱依赖──► R03 支付金额校验
        │
        ▼
R10 发票开具
```

## 2. 规则冲突检测

### 2.1 冲突类型

| 冲突类型 | 示例 | 检测方法 |
|----------|------|----------|
| 支付方式冲突 | 先付+后付同时生效 | PayMutexShare锁 |
| 优惠互斥 | 满减↔折扣 | PayMutexShare锁 |
| 重复退款 | 同一订单多次退款 | 状态校验 |

| 执行顺序 | 规则 | 说明 |
|----------|------|------|
| 1 | R01 | 生成订单号 |
| 2 | R02 | 计算未付金额 |
| 3 | R06 | 判断会员优惠 |
| 4 | R04 | 分摊优惠 |
| 5 | R07 | 计算找零 |
