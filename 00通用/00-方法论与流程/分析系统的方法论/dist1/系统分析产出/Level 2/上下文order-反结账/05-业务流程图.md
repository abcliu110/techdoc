# 05-业务流程图

## 反结账流程

```
┌────────────────────────────────────────────────────────────────┐
│                        反结账流程                                  │
└────────────────────────────────────────────────────────────────┘

                              ┌─────────────┐
                              │  发起反结账  │
                              └──────┬──────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │  校验订单状态     │
                            │ 必须为已结账(20) │
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 恢复实收金额     │
                            │ actualReceipt -= │
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 恢复销售汇总     │
                            │ saleInfo.cancelPay│
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 回退支付优惠     │
                            │ payDiscountAmount -= │
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 回退明细优惠     │
                            │ cancelPayDiscount│
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 创建取消支付记录  │
                            │ OrderPay(type=2) │
                            │ payIndex = revCount+1 │
                            └────────┬────────┘
                                     │
                                     ▼
                            ┌─────────────────┐
                            │ 更新订单状态     │
                            │ → 待结账(10)    │
                            │ revCheckoutCount++ │
                            └─────────────────┘
```

## 状态流转（反结账）

```
已结账(20) ──cancelPay──► 待结账(10)
              │
              │ revCheckoutCount++
              │ payIndex = 原+1
```
