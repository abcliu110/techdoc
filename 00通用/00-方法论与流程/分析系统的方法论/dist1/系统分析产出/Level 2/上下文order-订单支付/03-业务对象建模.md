## 2. 对象详情

### 2.1 OrderPay（支付记录）

#### 2.1.1 类型判定
| 判定项 | 结论 | 依据 |
|---------|------|------|
| 实体/值对象 | 实体 | 有唯一标识payId，有生命周期 |

#### 2.1.2 属性/字段
| 属性 | 类型 | 说明 | 约束 |
|------|------|------|------|
| payId | Long | 支付记录ID | PK，唯一 |
| billNo | String | 账单编号 | FK到OrderMasterDO |
| payIndex | Integer | 支付序号 | 多次支付递增 |
| payAmount | BigDecimal | 应付金额 | >= 0 |
| actualReceiptAmount | BigDecimal | 实收金额 | >= 0 |
| payStatus | Integer | 支付状态 | 1-成功/2-中/3-失败 |
| payMethod | Integer | 支付方式 | PayMethodEnum |
| payMedia | Integer | 支付介质 | 1-扫码/2-刷卡/3-扫脸 |
| changeAmount | BigDecimal | 找零金额 | >= 0 |
| overAmount | BigDecimal | 超收金额 | >= 0 |
| promotionId | Long | 促销活动ID | 可空 |

#### 2.1.3 方法/操作
| 方法 | 输入 | 输出 | 业务含义 |
|------|------|------|----------|
| create() | 支付信息 | OrderPay | 创建支付记录 |
| cancel() | - | void | 取消支付 |

### 2.2 OrderSaleDO（销售汇总）

#### 2.2.1 属性/字段
| 属性 | 类型 | 说明 | 约束 |
|------|------|------|------|
| actualPayAmount | BigDecimal | 实付金额 | 累加 |
| changeAmount | BigDecimal | 找零 | >= 0 |
| overAmount | BigDecimal | 超收 | >= 0 |

#### 2.2.2 方法/操作
| 方法 | 输入 | 输出 | 业务含义 |
|------|------|------|----------|
| pay() | OrderPay, changeAmount | void | 累计实收 |
| cancelPay() | actualReceiptAmount | void | 取消支付 |
