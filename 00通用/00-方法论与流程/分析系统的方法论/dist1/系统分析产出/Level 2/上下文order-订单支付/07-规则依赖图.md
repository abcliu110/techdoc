# 07-规则依赖图

## 1. 规则依赖关系

### 1.1 依赖类型

| 依赖类型 | 含义 | 示例 |
|---------|------|------|
| 强依赖 | A必须先于B执行 | 未付金额校验→执行支付 |
| 顺序依赖 | A和B有固定顺序 | 收款→计算找零→找零→完成 |

### 1.2 依赖图

```
R05 支付序号递增 ──强依赖──► [执行支付]
        │
        ▼
R02 实收累加 ──强依赖──► R01 找零计算
        │
        ▼
R04 优惠分摊 ──强依赖──► R02 实收累加
        │
        ▼
R03 超收记录 ──顺序依赖──► R01 找零计算
```
