# 09-接口契约

## 1. 对外接口

### 1.1 支付接口
| 接口 | 说明 | 输入 | 输出 |
|------|------|------|------|
| cashPay | 现金支付 | payAmount, actualReceiptAmount | changeAmount |
| onlinePay | 在线支付 | payChannel, payAmount | payStatus |
| cardPay | 会员卡支付 | cardId, payAmount | balance |

### 1.2 查询接口
| 接口 | 说明 | 输入 | 输出 |
|------|------|------|------|
| getOrderPayList | 获取支付列表 | billNo | List<OrderPay> |
| getPayStatistics | 支付统计 | billNo | OrderPayStatisticsDTO |

## 2. 内部接口

| 接口 | 调用方 | 被调用方 | 说明 |
|------|--------|---------|------|
| payComplete | OrderMasterService | OrderStatusDO | 更新支付状态 |
| getUnpaidAmount | 支付服务 | OrderMasterDO | 获取未付金额 |

## 3. 事件定义

| 事件名 | 触发条件 | 事件数据 |
|--------|----------|----------|
| OrderPaid | 支付成功 | {billNo, payAmount, payMethod, changeAmount} |

## 4. 第三方集成

| 平台 | 集成方式 | 主要接口 |
|------|---------|---------|
| 微信支付 | API | 扫码支付 |
| 支付宝 | API | 扫码支付 |
