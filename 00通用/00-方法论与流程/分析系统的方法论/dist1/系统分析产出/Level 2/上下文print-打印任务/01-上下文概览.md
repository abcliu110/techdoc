# 01-上下文概览

## 基本信息

| 属性 | 值 |
|------|-----|
| 上下文名称 | print-打印任务 |
| 上下文描述 | 打印任务创建与分发 |
| 优先级 | P0 |
| 所属业务域 | print-打印 |
| 代码路径 | com/shouqianba/localserver/print/ |

## 核心职责

1. 创建打印任务（PrintJobInfo）
2. 选择打印机设备
3. 分发打印任务到对应打印机
4. 管理打印任务状态

## 主要实体

| 实体名 | 类型 | 说明 |
|--------|------|------|
| PrintJobInfo | 实体 | 打印任务（包含Printer和TemplateTicket） |
| OrgPrintJob | 实体 | 组织打印任务持久化 |
| PrintSet | 实体 | 打印机配置 |

## 打印类型（PrintTicketTypeEnum）

| 类型 | 说明 | 打印机策略 |
|------|------|-----------|
| PREPARE(8001) | 预结账单 | EatInDevicePrinterStrategyImpl |
| BILL(8002) | 结账单 | EatInDevicePrinterStrategyImpl |
| MAKE(10001) | 制作票 | MakeTicketPrinterStrategyImpl |
| TAKE_OUT_MERCHANT(9001) | 外卖单(商家联) | TakeOutMerchantDevicePrinterStrategyImpl |
| TAKE_OUT_CUSTOM(9002) | 外卖单(顾客联) | TakeOutDevicePrinterStrategyImpl |

## 入口服务

- `PrintService`：核心打印服务
- `OrgPrintJobService`：打印任务持久化
