# 03-架构设计

## 1. 系统架构概览

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    kaci-pos 餐饮POS系统                        │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │   order    │  │   print    │  │   member    │        │
│  │   订单     │  │   打印     │  │   会员     │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │   goods    │  │    kds      │  │  takeout    │        │
│  │   商品     │  │   厨房显示  │  │   外卖     │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  promotion │  │   table    │  │    base    │        │
│  │   促销     │  │   桌台     │  │   基础数据 │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
├─────────────────────────────────────────────────────────────┤
│                      Electron + Netty 架构                    │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 表现层 | Electron | 桌面应用框架 |
| 通信层 | Netty | TCP长连接 |
| 业务层 | Spring Boot | 业务逻辑处理 |
| 数据层 | SQLite/ORM | 本地持久化 |

## 2. 核心设计模式

### 2.1 聚合设计

| 聚合根 | 包含实体 | 核心方法 |
|--------|-----------|----------|
| OrderMasterDO | OrderDetailDO, OrderPay, OrderStatusDO | create(), pay(), refund(), cancelPay() |
| MemberDO | - | register(), recharge(), earnPoints() |

### 2.2 策略模式

| 策略接口 | 实现类 | 使用场景 |
|----------|--------|----------|
| PrinterStrategy | MakeTicketPrinterStrategyImpl | 厨房打印 |
| TicketPrintStrategy | BillTicketPrintStrategyImpl | 结账单打印 |

## 3. 跨业务域协作

### 3.1 核心流程协作

```
order创建订单 ──触发──▶ print打印制作票
                          │
                          ▼
                    kds显示制作
                          │
                          ▼
                    order支付 ──触发──▶ member积分
                          │
                          ▼
                    print结账单
```

### 3.2 事件流

| 事件 | 发布方 | 订阅方 | 说明 |
|------|--------|--------|------|
| OrderCreated | order | print, kds | 新订单创建 |
| OrderPaid | order | member | 订单支付，触发积分 |
| GoodsSoldOut | soldout | order | 商品沽清，限制点餐 |

## 4. 遗留系统风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 订单与桌台状态不同步 | 桌台占用但已结账 | 事务同步 |
| KDS与收银系统延迟 | 状态显示不一致 | WebSocket实时推送 |
| 促销规则冲突 | 重复优惠 | 明确互斥规则 |

## 5. 重构建议

| 优先级 | 建议 | 预期收益 |
|--------|------|----------|
| P0 | 抽取PrinterStrategy策略接口 | 解耦打印逻辑 |
| P1 | 统一状态码规范 | 消除歧义 |
| P2 | 外部化促销互斥规则 | 灵活配置 |
