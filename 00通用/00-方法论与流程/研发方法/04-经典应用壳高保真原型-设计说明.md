# 经典应用壳高保真原型设计说明

## 目标

新建独立 HTML，用六套不同的信息架构展示经典应用壳，不复用旧 `03` 文件，也不使用同一后台布局换色。

## 入选原型

1. Salesforce Lightning：应用切换、对象导航、列表视图、记录详情。
2. SAP Fiori：ShellBar、角色空间、业务磁贴、通知与搜索。
3. GitLab：全局导航、项目上下文、项目侧栏、Issue 与流水线。
4. Linear / Plane：工作空间、团队、项目、任务列表、右侧详情。
5. Teable：空间、数据库、表、视图、数据网格、记录面板。
6. Frappe：Workspace、模块入口、DocType、列表、表单和动作。

## 证据边界

- Salesforce 使用官方 Lightning Design System 可确认的应用壳结构。
- SAP 使用官方 SAPUI5 ShellBar Demo。
- GitLab 使用官方 Pajamas Navigation Sidebar 规范。
- Linear 使用官方概念模型，Plane 使用开源仓库和公开截图补充任务工作台结构。
- Teable 使用开源仓库和公开产品页面。
- Frappe 使用开源仓库、本地竞品知识库和公开截图。
- 原型使用中性业务数据，不复制商标资产，不声称像素级复刻具体版本。

## 展示方式

- 单页纵向排列六个完整桌面原型。
- 顶部目录可跳转到任一原型。
- 每个原型标注导航模型、固定上下文、主要动作和参考来源。
- 每套原型都展示真实内容，不使用空白占位色块。
- 原型内部提供最小交互：选中记录、切换视图、切换项目或应用。

## 验收标准

- 六套原型骨架明显不同。
- 1440px 桌面视口无溢出、遮挡和错误换行。
- 768px 窄屏可横向查看复杂数据壳，页面本身无横向溢出。
- 所有按钮、标签和记录文字可读。
- JavaScript 控制台无错误。
- 单文件可通过 `file://` 双击打开。
