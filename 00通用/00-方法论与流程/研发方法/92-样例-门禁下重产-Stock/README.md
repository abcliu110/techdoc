# 92-样例-门禁下重产 Stock

> **层级**：L2 样例（few-shot 参考，不是规则真源、不是项目事实）
> **来源**：对 `000供应链/Stock库存` 既有 SOP-00 全套的"门禁考试 + 门禁下重产"（2026-08-07）
> **演示目的**：当 AI 拿到 16 §1.3.0/1.3.1、L0 附录 J.2、21 §2.6、13-方法卡 §10 等门禁时，"合格产物"到底长什么样——尤其创造力/想象力/归纳这三格。
> **配套**：本目录两份样例 + 旧的 Stock 产物（对照用）

---

## 背景：这组样例是怎么来的

对 Stock 库存的**旧产物**（门禁出现前生成）做门禁考试，结果 8 条门禁 6 红 1 黄：

| 门禁 | 旧产物的违反 |
|---|---|
| 21 §2.6 对抗闸一 | V0-V7 声称 64/64 全绿，三条反证全部进"不影响通过"旁路 |
| 21 §2.6 对抗闸二 | U-01/U-02 威胁 CF-03/CF-02，但 CF 未临时降级；U-01 与 DA8 影响栏自相矛盾 |
| 16 §1.3.0 / G3 | 给"7 策略子类"直接贴"策略模式"标签（先命名后证据） |
| 16 §1.3.1 失真 | R-ST-09 用"模块化重构"回应 146K 行规模（技术变体冒充业务进化） |
| L0 J.2 验证树 | 对 L4 主张跑树：Q1"结论以模式名开头" → 是 → STOP |
| 16 G4 本质回指 | L5"账本/凭证/日记账"停在结构层，未到承重墙/正交轴（半过） |

然后按门禁**重产出**两格——本目录的 `01` 与 `02` 就是重产结果。它们要证明：**门禁既拦得住烂答案，也不至于把 AI 堵死到写不出来**（约束 vs 屠刀）。

## 这两份样例分别示范什么

- `01-架构归纳-承诺强度示范.md`：架构归纳格——从"锁定量/预留量两个字段 + 两条释放路径"溯因出"承诺强度两档"，解释为什么僵尸锁定必然会发生。演示 16 §1.3.1（S-M0-Δ-H-P-F-ΔH-CI(A)）+ L0 J.2 + G4 全过。
- `02-业务进化-承诺终态收敛示范.md`：业务进化格——把"补个关单自动解锁"（补丁）升到"释放=承诺终态收敛"（机制），含不做基线/候选光谱/竞争预测/最小实验/机制韧性/兼容回退。演示 13-方法卡 §10 + 非技术变体 + 21 §2.6。

## 怎么用（给 AI）

**作为 few-shot**：新任务做架构归纳/业务进化前，先读对应样例，把"门禁下的形貌"注入少样本；产出后对照 `01/02` 末尾的"门禁自审表"逐条自查，任一"否"即回炉，不许把字段填满当完成。

**作为对照**：把新产物与 `01/02` 并排，用"换领域检测"问一句：如果把这套东西换到订单/会员/支付，它还是不是一堆通用空话？若只剩空话，说明没沉到本系统机制上。

## 诚实代价声明

门禁不是免费力量：产出 `01/02` 每格都完整走了"惊讶→缺口→竞争→冒险预测→自我否证"一循环，这是轮次与上下文成本上升的来源。样例的意义是**把这个成本花的"值得"的样子固定下来**，而不是假装不需要付这个成本。
