# 数据血缘关系

## 1. 核心数据流

### 1.1 账单数据流

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              账单生命周期数据流                               │
└─────────────────────────────────────────────────────────────────────────────┘

[开台]
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ dwd_bill (创建)                                                              │
│   - lid: 雪花算法生成                                                         │
│   - mid, sid: 从登录上下文获取                                                 │
│   - order_no: 本地生成或云端下发                                               │
│   - status: 0 (开台)                                                         │
│   - created_time: 当前时间                                                    │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ├──▶ [pt_tbl] (更新状态为占用)
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ dwd_food (菜品明细 - 多条)                                                   │
│   - bill_id → dwd_bill.lid                                                  │
│   - dish_id → pt_dish.lid                                                   │
│   - amount = num × price                                                    │
│   - status: 0 (正常)                                                        │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ CalcOrderService.calc() (金额重算)                                          │
│   - 计算 total_amount = Σ(dwd_food.amount)                                  │
│   - 计算 discount_amount (优惠抵扣)                                         │
│   - 计算 real_amount = total_amount - discount_amount                      │
│   - 更新 dwd_bill.total_amount, discount_amount, real_amount                │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ dwd_pay (支付明细 - 多条)                                                    │
│   - bill_id → dwd_bill.lid                                                 │
│   - pay_amount: 各支付方式金额                                               │
│   - status: 0 → 1 (待支付 → 已支付)                                         │
│   - saas_order_no: 第三方订单号                                              │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ dwd_bill (更新)                                                              │
│   - status: 0 → 1 (开台 → 已结账)                                           │
│   - closed_time: 当前时间                                                    │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ├──▶ [sync_queue] (离线模式: 写入同步队列)
    │
    ├──▶ [nms4cloud] (在线模式: 实时上传)
    │
    └──▶ [pt_tbl] (更新状态为空闲)
```

### 1.2 菜品数据流

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              菜品生命周期数据流                                │
└─────────────────────────────────────────────────────────────────────────────┘

[云端菜品管理]
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ pt_dish (云端)                                                               │
│   - 菜品基础信息                                                             │
│   - lid: 雪花算法生成                                                        │
│   - status: 1 (上架)                                                        │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼ Canal 增量同步
┌─────────────────────────────────────────────────────────────────────────────┐
│ local_dish (门店本地)                                                        │
│   - 与云端 pt_dish 同步                                                      │
│   - tbl_name: "pt_dish"                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ dwd_food (菜品明细)                                                         │
│   - dish_id → local_dish.lid / pt_dish.lid                                 │
│   - price: 使用 local_dish.price                                            │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
[会员注册/导入]
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ biz_member (云端)                                                           │

└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼ Canal 增量同步
┌─────────────────────────────────────────────────────────────────────────────┐
│ local_member (门店本地)                                                      │
│   - 与云端 biz_member 同步                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 会员识别 (结账时)                                                            │
│   - 根据手机号/卡号查询                                                       │
│   - 应用会员价、积分抵扣                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 会员操作上报                                                                │
│   - 积分变动                                                                │
│   - 余额变动                                                                │
│   - 通过 sync_queue 或实时上报                                               │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.4 同步数据流

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              云端→门店同步                                    │
└─────────────────────────────────────────────────────────────────────────────┘

[云端 MySQL]
    │
    ▼ binlog
┌─────────────────────────────────────────────────────────────────────────────┐
│ Canal Server                                                                │
│   - 订阅 binlog                                                             │
│   - 解析增量事件                                                            │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼ TCP
┌─────────────────────────────────────────────────────────────────────────────┐
│ CanalWorker (pos5sync)                                                     │
│   - 解析 CanalEntry                                                        │
│   - 过滤表名和门店                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ Kafka (Topic: nms4cloud-pos5sync)                                          │
│   - 消息格式: mid, sid, lid, tbl_name, type, content                       │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ KafkaListenerForSync (门店POS)                                             │
│   - 消费消息                                                                │
│   - 路由到 IncrementalSyncDataService                                      │
└─────────────────────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ local_xxx (门店本地表)                                                       │
│   - INSERT: 新增记录                                                        │
│   - UPDATE: 更新记录                                                        │
│   - DELETE: 软删除                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 表间关联关系

### 2.1 账单领域关联

```
dwd_bill (1) ──┬── (*) dwd_food ──(dish_id)── pt_dish
               │
               └── (*) dwd_pay ──(bill_id)── dwd_bill
```

### 2.2 桌台领域关联

```
pt_tbl (1) ──(area_id)── (*) pt_tbl_area
  │
  └── (*) dwd_bill ──(tbl_id)── pt_tbl
```

### 2.3 菜品领域关联

```
pt_dish_type (1) ──(*) pt_dish
     │
pt_dish (1) ──(cook_id)── (*) pt_dish_cook ──(dish_id)── (*) pt_dish
     │
pt_dish (1) ──(taste_id)── (*) pt_dish_taste ──(dish_id)── (*) pt_dish
```

### 2.4 会员领域关联

```
biz_member (1) ──(*) pt_member_price ──(member_id)── biz_member
     │
biz_member (1) ──(*) biz_member_level ──(level_id)── biz_member
```

## 4. 数据聚合路径

### 4.1 账单金额聚合

```
dwd_bill.total_amount
    = Σ(dwd_food.amount)
    = Σ(dwd_food.num × dwd_food.price)
```

### 4.2 实收金额聚合

```
dwd_bill.real_amount
    = dwd_bill.total_amount
    - dwd_bill.discount_amount
```

### 4.3 支付金额聚合

```
Σ(dwd_pay.pay_amount) WHERE dwd_pay.status = 1
    = dwd_bill.real_amount
```
