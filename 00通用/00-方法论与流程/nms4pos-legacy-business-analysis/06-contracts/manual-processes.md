# 人工流程登记

## 1. 门店日常人工流程

### 1.1 开台流程（标准）

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 收银员 | 选择空闲桌台 | 显示桌台信息 | - |
| 2 | 收银员 | 点击"开台" | 创建账单 | 确认桌台 |
| 3 | 系统 | 自动设置人数 | 更新账单 | - |
| 4 | 完成 | - | 桌台状态变为占用 | - |

### 1.2 结账流程（标准）

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 收银员 | 点击"结账" | 调用 CalcOrderService | - |
| 2 | 系统 | 计算金额 | 显示应付/实收/找零 | - |
| 3 | 收银员 | 选择支付方式 | - | 选择支付方式 |
| 4 | 收银员 | 收取现金 | - | 确认金额 |
| 5 | 收银员 | 点击"确认结账" | 写入支付记录 | - |
| 6 | 系统 | 打印小票 | 调用打印服务 | - |
| 7 | 系统 | 更新账单状态 | status=1 | - |
| 8 | 系统 | 更新桌台状态 | 桌台空闲 | - |

### 1.3 退菜流程

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 收银员 | 选择要退的菜品 | 显示菜品信息 | 确认菜品 |
| 2 | 收银员 | 输入退菜数量 | - | 确认数量 |
| 3 | 收银员 | 点击"退菜" | 更新菜品状态 | - |
| 4 | 系统 | 重新计算金额 | 更新账单金额 | - |
| 5 | 收银员 | 确认修改 | 保存更改 | - |

## 2. 异常处理人工流程

### 2.1 支付失败处理

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 系统 | 检测支付失败 | 显示错误提示 | - |
| 2 | 收银员 | 确认支付失败 | - | 重试或换支付方式 |
| 3 | 收银员 | 选择重试或其他方式 | - | 确认选择 |
| 4 | 系统 | 执行新支付 | 更新支付记录 | - |
| 5 | 失败 | 多次失败 | - | 改用现金或挂账 |

### 2.2 离线数据同步失败处理

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 系统 | 检测同步失败 | 记录到 sync_queue | - |
| 2 | 系统 | 重试3次 | 每次间隔5秒 | - |
| 3 | 系统 | 仍失败 | 标记 sync_status=2 | - |
| 4 | 收银员 | 收到失败通知 | - | 检查网络 |
| 5 | 收银员 | 尝试手动同步 | - | 确认数据 |
| 6 | 失败 | 仍失败 | - | 联系技术支持 |

### 2.3 反结账处理

| 步骤 | 操作人 | 动作 | 系统行为 | 人工判断 |
|------|--------|------|----------|----------|
| 1 | 店长 | 选择要反结账的账单 | 显示账单信息 | 确认账单 |
| 2 | 店长 | 输入反结账原因 | - | 记录原因 |
| 3 | 店长 | 点击"反结账" | 校验时间和权限 | - |
| 4 | 系统 | 回滚支付记录 | 更新状态 | - |
| 5 | 系统 | 触发退款 | 原路退回 | - |
| 6 | 系统 | 恢复菜品明细 | status 恢复 | - |
| 7 | 系统 | 更新账单状态 | status=0 | - |

## 4. 人工确认节点

### 4.1 必须人工确认的场景

| 场景 | 确认内容 | 确认人 | 超时处理 |
|------|----------|--------|----------|
| 订单金额差异 | 差异金额 | 店长 | 拒绝操作 |
| 离线同步失败 | 数据完整性 | 技术支持 | 暂停营业 |
| 日结异常 | 报表数据 | 店长 | 推迟日结 |
| 大额退款 | 退款金额 | 管理员 | 需审批 |

### 4.2 人工确认记录

```sql
-- 人工确认记录表
CREATE TABLE manual_confirm (
    id BIGINT PRIMARY KEY,
    confirm_type VARCHAR(50),    -- 确认类型
    related_id BIGINT,           -- 关联ID
    confirm_content JSON,        -- 确认内容
    confirm_by BIGINT,           -- 确认人
    confirm_time DATETIME,       -- 确认时间
    result VARCHAR(20),          -- 确认结果
    remark VARCHAR(500)          -- 备注
);
```

## 5. 人工补偿机制

### 5.1 金额差异补偿

| 场景 | 补偿方式 | 审批人 |
|------|----------|--------|
| 计算误差 | 抹零处理 | 自动 |
| 系统错误 | 退还差额 | 店长 |
| 人为错误 | 退还/补收 | 店长+财务 |

### 5.2 数据不一致补偿

| 场景 | 补偿方式 | 审批人 |
|------|----------|--------|
| 离线数据丢失 | 补录数据 | 技术支持 |
| 同步冲突 | 以云端为准 | 技术支持 |
| 异常数据 | 人工修正 | 店长 |
