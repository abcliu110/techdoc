# SLICE-008：断网离线收银

> **切片目标**：还原断网情况下的离线收银机制及网络恢复后的数据同步
> **优先级**：P0
> **停止条件**：离线数据一致性可验证

## 1. 离线模式概述

### 1.1 离线模式定义

离线收银是指 POS 终端在**网络断开**的情况下，仍能正常进行收银操作的能力。这是餐饮 POS 系统的关键差异化能力，确保门店在网络故障时不停业。

### 1.2 离线模式触发条件

| 触发条件 | 说明 |
|----------|------|
| 网络断开 | 无法连接到云端服务 |
| 云端服务不可用 | nms4cloud-pos 服务宕机 |
| 门店自主切换 | 管理员手动切换到离线模式 |

### 1.3 离线能力范围

| 功能 | 离线支持 |
|------|----------|
| 开台 | ✅ 支持 |
| 点餐 | ✅ 支持 |
| 加菜/退菜 | ✅ 支持 |
| 结账 | ✅ 支持（本地记录） |
| 打印 | ✅ 支持（本地打印服务） |
| 会员识别 | ❌ 需联网（部分） |
| 微信/支付宝支付 | ⚠️ 部分支持（预授权） |
| 打印小票 | ✅ 支持 |

```sql

    id BIGINT PRIMARY KEY,
    operation_type VARCHAR(50),     -- INSERT/UPDATE/DELETE
```

## 4. 离线账单冲突处理

### 4.1 冲突场景

| 场景 | 描述 | 处理策略 |
|------|------|----------|
| 订单号冲突 | 离线生成的 order_no 与云端已存在 | 使用云端 order_no，本地记录标记为同步 |
| 数据不一致 | 同一订单在离线和云端有不同修改 | 以最后操作时间为准，保留变更记录 |
| 删除冲突 | 离线删除，云端有更新 | 以云端为准，通知用户 |

### 4.2 冲突解决算法

```java
// 冲突解决伪代码
public SyncResult resolveConflict(LocalRecord local, CloudRecord cloud) {
    if (local.lastModifiedTime > cloud.lastModifiedTime) {
        // 本地更新更新：采用本地变更
        return SyncResult.USE_LOCAL;
    } else {
        // 云端更新更新：采用云端变更
        return SyncResult.USE_CLOUD;
    }
}
```

## 6. 网络状态监控

### 6.1 心跳检测

```java
// 网络状态监控
public class NetworkMonitor {
    private static final int HEARTBEAT_INTERVAL = 5000;  // 5秒
    private static final int HEARTBEAT_TIMEOUT = 15000;   // 15秒
    
    public void start() {
        scheduledExecutor.scheduleAtFixedRate(
            this::checkNetwork,
            0, HEARTBEAT_INTERVAL, TimeUnit.MILLISECONDS
        );
    }
    
    private void checkNetwork() {
        boolean reachable = pingCloudServer();
        if (reachable) {
            networkStatus = NetworkStatus.ONLINE;
            if (lastStatus == NetworkStatus.OFFLINE) {
                onNetworkRecovered();  // 触发同步
            }
        } else {
            networkStatus = NetworkStatus.OFFLINE;
        }
        lastStatus = networkStatus;
    }
}
```

## 7. 离线同步策略

### 7.1 同步优先级

| 优先级 | 数据类型 | 说明 |
|--------|----------|------|
| 1 | 账单支付 | 涉及资金，优先同步 |
| 2 | 账单菜品 | 业务主数据 |
| 3 | 会员操作 | 会员积分等 |
| 4 | 其他 | 配置、日志等 |

### 7.2 同步重试机制

```java
// 同步重试配置
public class SyncConfig {
    private static final int MAX_RETRY = 3;
    private static final long RETRY_INTERVAL = 5000;  // 5秒
    
    public void syncWithRetry(SyncItem item) {
        for (int i = 0; i < MAX_RETRY; i++) {
            try {
                syncToCloud(item);
                return;  // 成功
            } catch (Exception e) {
                log.warn("同步失败，第{}次重试", i + 1);
                Thread.sleep(RETRY_INTERVAL);
            }
        }
        // 标记为失败，等待人工处理
        markSyncFailed(item);
    }
}
```
