## 2. 订单状态流转

```
┌─────────────┐
│ TO_BE_ORDERED │  待下单（创建账单后）
└──────┬──────┘
       │ 首次加菜
       ▼
┌─────────────┐
│  UNSETTLED  │  未结算（有待处理的菜品）
└──────┬──────┘
       │ 结账
       ▼
┌─────────────┐
│  SETTLED    │  已结算（等待支付完成）
└──────┬──────┘
       │ 支付成功
       ▼
┌─────────────┐
│   CLOSED    │  已结账（完成）
└─────────────┘

撤销流程:
┌─────────────┐     反结账      ┌─────────────┐
│   CLOSED    │ ──────────────→ │  UNSETTLED  │ (退菜模式)
└─────────────┘                 └─────────────┘
```

## 4. 金额计算公式

```
菜品金额 = Σ(菜品单价 × 数量 + 做法加价 × 数量)
应收金额 = 菜品金额 + 服务费 - 优惠券抵扣 - 活动优惠
实收金额 = 应收金额 - 抹零金额
多收金额 = 实付金额 - 应收金额（找零）
少收金额 = 应收金额 - 实付金额
```

## 8. 遗留问题

| 问题 | 描述 | 影响 | 验证方式 |
|------|------|------|----------|
| Q1 | 套餐组合计算规则不清晰 | 套餐点餐可能出错 | 需读 PtDishGroup 相关代码 |
| Q2 | 会员优惠与活动优惠的优先级 | 优惠计算可能不正确 | 需读 PromoteRuleUtil |
| Q3 | 并发加菜的锁竞争 | 高峰期可能性能问题 | 需压测验证 |
