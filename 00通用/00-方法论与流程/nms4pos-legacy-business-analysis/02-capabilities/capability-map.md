# nms4pos 业务能力地图

## 1. 能力域划分

按业务域 → 能力 → 业务操作三级结构组织：

### 1.1 收银核心域 (POS Core)

| 能力 | 业务操作 | 核心对象 | 重要性 |
|------|----------|----------|--------|
| **开台管理** | 开台、并台、转台、关台 | 桌台(pt_tbl)、账单(dwd_bill) | 核心 |
| **点餐管理** | 加菜、退菜、改菜、赠送 | 菜品明细(dwd_food) | 核心 |
| **结账管理** | 正常结账、挂账、赊账、预结 | 支付明细(dwd_pay) | 核心 |
| **账单管理** | 账单查询、反结账、作废 | 账单(dwd_bill) | 核心 |

## 2. 能力卡

### CAP-001 开台管理

- **业务域**：收银核心域
- **业务结果**：创建或关联一个账单，为后续点餐提供上下文
- **使用角色**：收银员、服务员
- **触发入口**：POS 桌面端桌台选择界面
- **核心对象**：桌台(pt_tbl)、账单(dwd_bill)
- **上游**：无
- **下游**：点餐、结账、KDS
- **重要性**：核心
- **当前证据**：CLAUDE.md、Controller 代码
- **已知变体**：快餐模式（不需开台直接点餐）
- **未知项**：开台与账单的绑定规则、并发处理

### CAP-002 点餐管理

- **业务域**：收银核心域
- **业务结果**：向账单添加菜品明细，记录菜品数量、价格、制作要求
- **使用角色**：收银员、服务员、顾客（自助）
- **触发入口**：POS 点餐界面、扫码点餐
- **核心对象**：菜品(pt_dish)、菜品明细(dwd_food)
- **上游**：开台、菜品数据
- **下游**：结账、KDS、打印
- **重要性**：核心
- **当前证据**：CLAUDE.md 核心流程说明
- **已知变体**：加菜、退菜、改数量、改做法、赠送
- **未知项**：套餐组合计算规则、做法互斥规则

### CAP-003 结账管理

- **业务域**：收银核心域
- **业务结果**：完成账单支付，记录支付明细，更新账单状态
- **使用角色**：收银员
- **触发入口**：POS 结账按钮
- **核心对象**：账单(dwd_bill)、支付明细(dwd_pay)
- **上游**：点餐、优惠
- **下游**：打印小票、会员积分
- **重要性**：核心
- **当前证据**：CLAUDE.md 核心流程说明
- **已知变体**：正常结账、挂账、赊账、部分支付
- **未知项**：多支付方式组合规则、找零处理

### CAP-004 会员识别与优惠

- **业务域**：会员域
- **业务结果**：识别会员身份，应用会员价、积分、储值
- **使用角色**：收银员、顾客
- **触发入口**：会员卡/手机号/刷脸识别
- **核心对象**：会员(biz_member)、会员价格
- **上游**：nms4cloud CRM
- **下游**：结账计算
- **重要性**：核心
- **当前证据**：CLAUDE.md、pos4cloud API
- **已知变体**：不同会员等级、不同优惠叠加规则
- **未知项**：会员价与活动优惠的优先级

### CAP-005 云端数据同步

- **业务域**：数据同步域
- **业务结果**：保持门店本地数据与云端数据一致
- **使用角色**：系统自动
- **触发入口**：定时任务、事件触发
- **核心对象**：同步状态、Canal 事件
- **上游**：本地数据变更
- **下游**：云端报表、数据分析
- **重要性**：核心
- **当前证据**：CLAUDE.md 项目结构
- **已知变体**：全量同步、增量同步、离线模式
- **未知项**：冲突解决策略、数据校验机制
