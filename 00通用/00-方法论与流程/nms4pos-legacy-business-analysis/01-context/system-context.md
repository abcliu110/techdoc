# 系统上下文与角色识别

## 1. 系统定位

### 1.1 系统是什么

**nms4pos** 是餐饮行业 POS（Point of Sale）收银系统的完整技术栈，包含：
- **后端**：Java/Spring Boot 微服务模块集合
- **前端**：React/Taro 多端应用（POS 桌面端、移动端）
- **定位**：支撑门店收银、订单管理、外卖对接、打印、KDS（厨房显示）等完整餐饮业务流程

### 1.2 系统为谁创造价值

| 角色 | 价值结果 | 使用入口 |
|------|----------|----------|
| 收银员 | 快速完成点餐、结账、打印小票 | POS 桌面端 |
| 门店管理员 | 管理菜品、桌台、员工、报表 | 商家后台 Web |
| 厨师 | 接收并完成 KDS 菜品制作任务 | KDS 显示端 |
| 顾客 | 自助点餐、扫码支付 | 微信小程序 |
| 外卖平台 | 接收并处理外卖订单 | 美团/饿了么对接接口 |
| 总部运营 | 多门店管理、数据分析 | 商家后台 Web |
| 运维人员 | 系统部署、监控、故障排查 | 监控面板 |

## 2. 外部系统依赖

| 外部系统 | 角色 | 交换内容 | 协议 |
|----------|------|----------|------|
| nms4cloud | 上游平台 | 会员、订单、支付、菜品基础数据 | Feign HTTP |
| MySQL | 数据存储 | 业务数据持久化 | JDBC |
| Redis | 缓存 | Session、分布式锁、热点数据 | Redis Protocol |
| Nacos | 配置中心 | 应用配置、服务发现 | HTTP |
| RocketMQ | 消息队列 | 异步消息、事件驱动 | MQ Protocol |
| ClickHouse | OLAP存储 | 报表数据聚合 | JDBC |
| 微信支付/支付宝 | 支付渠道 | 扫码支付、退款 | HTTP API |
| 美团/饿了么 | 外卖平台 | 外卖订单同步 | HTTP API |
| 打印机 | 硬件设备 | 小票打印指令 | USB/串口/TCP |

```
                                            [nms4cloud 主平台]
```
