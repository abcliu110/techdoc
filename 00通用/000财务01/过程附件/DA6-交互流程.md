> **模板加载记录**：已读取 `SOP-00-DA6-模板.md`（独立模板）。生成前门禁检查 4 项：核心场景≥3、参与者/前置/后置、时序覆盖正常+异常、API 带证据。

## 一、核心交互场景

### 场景一（P0·S1）：单据审核后生成并过账凭证
**参与者**：会计、复核、系统（BOS 平台+FIN 服务门面）
**前置**：单据已审核、期间未结、科目映射/模板可用
**后置**：凭证已过账、余额已更新、可报表读取

```
会计       单据/凭证生成服务      审核        过账(平台操作)     科目余额
 │ F7/生成凭证请求 │              │             │                │
 │───────────────▶│ 按模板校验借=贷 │             │                │
 │                │────────      │             │                │
 │◀───────────────│ 凭证(待审核)   │             │                │
 │ 提交审核 ──────▶│              │ 复核通过 ──▶ │                │
 │                │              │             │ 写分录+更新余额 │
 │                │              │             │───────────────▶│
 │◀───────────────│◀─────────────│◀────────────│ 已过账确认      │
异常分支：借贷不平→生成阶段拒绝；期间已结→过账拒绝(走改期提示)；重复→过账防重
```

### 场景二（P0·S2）：期末结账与期间封闭
**参与者**：会计/财务负责人、结账服务（服务端 GL；快照仅见期间查询门面与 AP/AR 关账插件）
**前置**：本期间结转完成、前序期间已结、期终试算平衡 ✅（机制推断）
**后置**：期间=已结，本期数据锁定，下期可开。

> ⚠️ 证据诚实（U-DA0-5）：快照内**未定位总账(GL)"结账/反结"写入口**（AdjustPeriodServiceHelper 仅为期间查询门面；AP/AR 的 CloseAccountRobotPlugIn 属往来关账）。本场景为**机制推断**（平台操作框架承载+期间状态概念由查询门面证实），写行为与锁实现待服务端补证。

```
会计                结转/结账服务              期间状态
 │ 结转请求 ───────▶│ 校验前序+生成结转凭证      │
 │                  │────────────────────────▶│ 期间→已结(锁期)
 │◀───────────────────────────────────────────│ 结账成功确认
异常：未结转→阻止；期终不平→阻止并提示对账；结账后又发现错→人工走 改期/反结(补偿)
```

### 场景三（P0·S3）：往来核销与对账调平
**参与者**：往来会计、核销服务（Match/CheckAccount）
**前置**：存在未核应收/应付与收付款
**后置**：往来已(部分)核销、差异可追溯

```
往来会计            核销匹配服务              往来户/核销表        对账服务
 │ 选择发票+收款 ──▶│ 校验未核余额(BR-04)     │                   │
 │                  │────────────────────────▶│ 未核余额减少        │
 │                  │ 对账比对影子 │          │                   │
 │                  │───────────────────────▶│  差异登记/调整单   │
 │◀──────────────────────────────────────────────────────────────│ 调平确认
异常：超额→拒绝；重复→防重；核销后撒销→反核销(冲)
```

## 二、API/操作面清单（服务门面，E-SRC: `FIN/01.Core/Kingdee.K3.FIN.ServiceHelper/Kingdee.K3.FIN.ServiceHelper/`）
