## 三、核心概念全景卡（SC-P0 概念 10 字段）

### BC-02 科目/分户账（账户）
```
① 身份：按"科目×核算维度×币别"的唯一余额账户；所属：核心业务域；别名：科目余额/账户
② 结构：期初+贷/借方发生额；按期间切片
③ 关系：被凭证分录增减(归因)；由结账固化(时序)；并入账套(结构)
④ 行为：过账即增减(SUM)，结账即冻结
⑤ 交互：过账(分录写入)、结账(锁定)、查询/报表(读)
⑥ 生命：期初建立→期间内随分录增减→期末结账固化期初→跨期
⑦ 实现：余额表(候选 T_BALANCE)+平台过账(OperationController)(E-SRC 机制级)
⑧ 失败：重复过账→余额重复；期间未锁→跨期污染；检测=对账/盘点余额
⑨ 证据：E-SRC 平台过账 + FIN 报表过滤；Schema 候选(U-DA0-1)
⑩ 未知：真实表结构/并发写机制(U-DA0-1/U-DA0-2)
```

### BC-03 会计凭证（记账事件）
```
① 身份：一次"借=贷"平衡的记账事实；核心业务域；别名：凭证/记账凭证
② 结构：头+分录(科目×方向×金额×辅助核算)
③ 关系：由单据经模板翻译生成(轨迹)；过账后驱动余额(轨迹)；被审核状态约束(规则)
④ 行为：编制→提交→审核→过账/作废
⑤ 交互：生成(单→凭证)、审核、过账、反审核
⑥ 生命：单据审核→F7/套打生成凭证→审核→过账→成为账簿事实；可红字冲销
⑦ 实现：VoucherGenerateService/BuildBusinessVoucher + 平台过账(E-SRC)
⑧ 失败：借贷不平/科目非法→拒绝；已结期间→禁止；重复过账→用过账标记防重
⑨ 证据：E-SRC VoucherGenerateService；运行表现未证(U-DA0-2)
⑩ 未知：过账并发/防重具体机制(U-DA0-3)
```

### BC-01 会计期间（时间轴格）
```
① 身份：记账的时间边界，按时序编号；支撑域(时间维度)；别名：会计期/账期
② 结构：年+期、状态(未结/已结/已反结)、上期/下期链接
③ 关系：容纳凭证与分录(结构-归属)；结账顺序约束(时序)；被改期通道破坏/恢复(轨迹)
④ 行为：开期→过账→结账→(反结/改期)
⑤ 交互：结账(锁期)、改期(重开通道)、结转(生成结转凭证)
⑥ 生命：期初开期→期间内记账→期末结转+结账锁期→历史固化；反结/改期=受控重开
⑦ 实现：AdjustPeriodServiceHelper/结账操作(E-SRC)；期间状态表(候选)
⑧ 失败：未结转就结账→账不平；期间冲突→强制禁止；改期权限滥用→审计风险
⑨ 证据：E-SRC AdjustPeriodServiceHelper
⑩ 未知：期间状态表结构/锁的实现(U-DA0-1)
```

### BC-04 往来户/债权债务（往来账户）
```
① 身份：对客户/供应商的应收/应付及其未核销余额；核心业务域
② 结构：往来对象×币别×单据(发票/收付款)
③ 关系：发票产生应收应付(轨迹)；核销抵减(轨迹)；对账差异由调整单修正(轨迹)
④ 行为：入账→核销→(反核销)、催收
⑤ 交互：核销匹配、对账、账龄查询
⑥ 生命：发票/收付款入账→账面往来→核销抵消(部分/全部)→差额转呆账或调整
⑦ 实现：MatchServiceHelper/CheckAccountBisServiceHelper(AgingAnalysisService)(E-SRC)
⑧ 失败：重复核销→需防重；超额核销→拒绝；对账差异→调整单闭环
⑨ 证据：E-SRC Match/CheckAccount/Aging 服务面
⑩ 未知：核销匹配数据模型与防重(U-DA0-1/U-DA0-2)
```
