# G0-B 问题基线（可演进基线）

> 来源：DA0 只读侦察（`DA0-侦察报告.md`）。模板来源：SOP-00 §5.2。引用 ID：DQ-*, SC-*, U-* 全局唯一以 `DA0`/本文件登记为准。

## 一、业务位置

- 分析对象处于**核心业务域**（财务 = 企业核算与资金的中枢），支撑能力来自 BOS 平台（元数据驱动运行时）。
- 位置图：
```
[采购/销售/生产/费用 业务单据]
        │ 财务单据/凭证触发
        ▼
[财务领域 FIN：凭证—账簿—期间—往来—资金]
        │ 按科目×期间归集
        ▼
[报表/对外披露/审计]
```

## 四、候选概念/关系/系统边界/权威源（候选，待 DA2/DA3 定稿）

- 核心候选维度：**会计科目账(科目)、账簿/账套、会计期间、单据→凭证、往来户(应收/应付)、核销单、对账单、币别/账簿折算、记账模板**（模板实现快照未定位 U-DA2-1）。
- 权威源候选：科目=科目表(元数据)、账簿=账套+期间、凭证=业务过账生成点、余额=分录入账聚合。
- 系统边界：财务域拥有"账簿事实的记账与封闭"；不拥有"业务事实的产生"(供应链/制造)与"资金实体的执行"(网银外)。
