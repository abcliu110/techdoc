# 十分钟读懂 · 金蝶 K3Cloud 财务域（000财务02）

## 一句话
财务域 = **时间盒(期间)上的守恒承诺机**：记录是手段，把一段时间的账目"冻结成不可逆的承诺"才是产品。

## 三重视图（记账—对账—披露 是一条链，不是三个系统）
```
业务单据 ──▶ 凭证(借=贷) ──▶ 过账 ──▶ 科目余额 ──▶ 期间(月末结账封箱)
   └─ 往来发票 ──▶ 核销(经核销单) ──▶ 未核余额 ──▶ 账龄/催收
                     └─▶ 对账 → 差异调平
   └─ 期间固化 ──▶ 报表/现金流/多账簿折算（怎么对外讲）
```

## 三个关键对象
- **期间（时间格子）**：记账的"封箱术"。开期→记账→月末结账封箱；审计发现错账经授权**改期/反结**重开再改。它是"历史与未来的门"。
- **凭证（翻译产物）**：业务事实→会计事实，借=贷；未结期可反审改，已结期走反结或红冲。
- **余额（聚合投影）**：按"科目×期间×核算维度"累积，期末校验"期初+入−出=期末"后固化。

## 四个设计决策（为什么长这样）
| 决策 | 为什么 |
|---|---|
| 凭证+余额+期间 三段式 | 可审计 + 可汇总 + 历史不可变 |
| 元数据+插件（零代码优先） | 百种单据配置化，改动不改程序 |
| 锁期可反结（受控补偿通道） | 默认防篡改，异常时能纠错（**写入口尚未定位 U-DA0-5**） |
| 核销经"核销单"中间载体 | 允许合并/部分/差异/审计追溯 |
