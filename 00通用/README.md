# 通用技术文档入口

> 状态：当前有效入口
> 更新：2026-07-19

本目录集中维护跨项目的方法论、知识库、数据模型和界面模型资料。具体项目的强制开发规则仍以项目自己的 `AGENTS.md`、README、架构文档和 ADR 为准；工作区级 AI 规则以 `D:\AGENTS.md` 及 `D:\agent-rules\` 为准。

```text
├── 00-方法论与流程/       跨领域分析方法、工作流和研发流程

├── 评审工作流/            评审流程与检查清单

├── 小程序相关/            小程序专项资料

```

## 使用入口

| 任务 | 首要入口 | 补充资料 |
|---|---|---|
| 系统化分析 | `系统化拆解方法论-AI执行版-v2.md` | 深入学习时再读 `深度学习与系统化拆解方法-v2.md` |
| 知识库建设 | `00-方法论与流程/` | `01-知识库/` |
| 数据或领域建模 | `02-数据模型模式/` | `数据模型界面模式映射/` |
| UI 模型与页面设计 | `03-界面模型模式/` | `PC后台相关/`、`小程序相关/` |
| 评审 | `评审工作流/` | 与目标项目直接相关的规范和测试证据 |

## 约束边界

- 本目录是通用参考资料，不替代具体项目的强制规则。
- 不存在的历史目录（例如 `工程规范/`、`新方案/`）不得作为当前加载入口。
- 引用文件前先验证路径存在；路径失效时不得按历史结构猜测替代位置。
- 涉及代码修改时，按 `D:\AGENTS.md` 的风险分级加载 `D:\agent-rules\`，并读取目标项目自己的入口规则。
- 竞品知识库的访问凭据必须通过环境变量提供，禁止写入文档或脚本源码。
