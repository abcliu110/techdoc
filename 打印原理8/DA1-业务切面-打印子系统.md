### 1.2 业务价值

| 价值维度 | 说明 |
|----------|------|
| **业务流程闭环** | 厨房联让后厨知道做什么，传菜联让服务员知道送到哪，顾客联让顾客有凭证 |
| **运营可视化** | 打印监控让管理者实时看到各打印机状态和任务积压 |
| **故障容错** | 主备打印机切换确保打印不中断 |
| **灵活配置** | 按部门/桌台/结账场景配置不同的打印规则 |

## 二、核心角色

| 角色 | 操作 | 接触系统 | 说明 |
|------|------|----------|------|
| **管理员** | 配置打印机、配置打印队列、配置部门打印映射 | 管理端 | 一次性配置，日常少操作 |
| **收银员** | 触发结账打印（系统自动） | 收银端 | 不直接操作打印，是业务的触发者 |
| **后厨人员** | 接收厨房联打印小票 | 打印机 | 打印内容的消费者 |
| **服务员** | 接收传菜联打印小票 | 打印机 | 打印内容的消费者 |
| **顾客** | 接收顾客联打印小票 | 打印机 | 打印内容的消费者 |
| **运维人员** | 监控打印任务、处理打印机故障 | 收银端监控面板 | 通过监控界面发现问题 |
| **系统** | 自动路由打印任务、执行打印 | 收银端 Worker | 无人参与的后台执行 |

## 三、业务分类

### 3.1 打印机管理

| 业务项 | 触发时机 | 说明 |
|--------|----------|------|
| 添加打印机 | 管理员首次配置 | 选择类型（USB/网口/云打印）、型号，填写连接参数 |
| 编辑打印机 | 连接参数变更、名称修改 | 不改变关联的打印任务 |
| 删除打印机 | 设备退役 | 检查是否被队列引用 |
| 打印机状态同步 | 实时 | 收银端 Worker 轮询打印机状态，上报给监控 |

### 3.2 打印队列管理

| 业务项 | 触发时机 | 说明 |
|--------|----------|------|
| 创建打印队列 | 按业务需求 | 队列名称、主打印机、备用打印机 |
| 配置主备打印机 | 可靠性要求 | 主打印机故障时自动切换到备用 |
| 队列绑定部门 | 业务配置 | 部门 → 队列 → 打印机三层路由 |
| 队列绑定 PC | 终端隔离 | 同一队列可在不同收银机显示不同打印机 |

### 3.3 打印任务管理

| 业务项 | 触发时机 | 说明 |
|--------|----------|------|
| 创建打印任务 | 结账完成 | 根据单据类型和用途生成多联打印任务 |
| 路由打印任务 | 任务创建时 | 根据菜品归属部门路由到对应队列 |
| 执行打印 | Worker 轮询 | 从队列取出任务，调用对应 Handler 打印 |
| 任务状态更新 | 打印成功/失败 | 更新状态、记录完成时间或失败原因 |
| 任务重试 | 打印失败后 | 休眠后重新尝试 |
| 任务放弃 | 超时 | 超过等待时间后标记为放弃 |

### 3.4 打印样式管理

| 业务项 | 触发时机 | 说明 |
|--------|----------|------|
| 配置打印样式 | 门店初始化/需求变更 | 按单据类型配置样式模板 |
| 配置样式明细 | 样式调整 | 配置行、列、内容、对齐、加粗等 |
| 配置打印条件 | 精细化控制 | 某些行只在特定条件下打印 |

## 四、核心用例

### UC-1：结账时生成打印任务

```
用例编号：UC-1
参与者：收银员（触发）、系统（执行）
前置条件：收银端已登录，有待结账单据
基本流程：
  1. 收银员完成结账操作
  2. 系统根据单据类型确定需要打印的联数（厨房联/传菜联/顾客联）
  3. 对每联打印：
     a. 根据菜品查找出品部门
     b. 根据出品部门查找打印队列
     c. 根据打印队列查找主打印机
     d. 创建打印任务，关联队列和打印机
  4. 打印任务进入队列等待执行
后置条件：打印任务已创建，等待 Worker 执行
异常处理：
  - 菜品未配置出品部门 → 跳过该菜品，打印日志警告
  - 出品部门未配置打印队列 → 跳过该菜品，打印日志警告
  - 主打印机故障 → 切换到备用打印机
  - 主备打印机都故障 → 任务进入等待队列，休眠后重试
证据：E-SRC: nms4pos/.../dal/entity/PosPrnJob.java
```

### UC-2：收银端执行打印

```
用例编号：UC-2
参与者：系统（PrinterWorker）
前置条件：有待执行的打印任务，打印机在线
基本流程：
  1. PrinterWorker 定时轮询自己的任务队列
  2. 取出一个打印任务
  3. 检查打印机状态：
     - 正常 → 继续执行
     - 故障 → 休眠 5 秒，放回队列
  4. 根据打印机类型选择 Handler：
     - 网口/串口/USB → PortHandler
     - 云打印（芯烨/佳博）→ XpCloudPrinter/JBCloudPrinter
     - 驱动打印 → GraphicsHandler
  5. Handler 调用对应的打印驱动/API 执行打印
  6. 打印成功 → 删除任务，记录完成时间
  7. 打印失败 → 休眠 10 秒，任务保留，稍后重试
后置条件：任务被成功打印或进入重试队列
异常处理：
  - 打印机忙碌 → 休眠等待
  - 打印内容过大 → 拆分打印
  - 网络超时（云打印）→ 重试
  - 驱动程序错误 → 记录错误，任务标记失败
证据：E-SRC: nms4pos/.../app/print/PrinterWorker.java
```

### UC-3：监控打印任务状态

```
用例编号：UC-3
参与者：运维人员（查看）、收银员（查看）
前置条件：运维人员打开打印监控面板
基本流程：
  1. 监控面板加载所有打印机的任务列表
  2. 每台打印机显示：
     - 正常：绿色，当前无积压任务
     - 积压：橙色，有等待中的任务
     - 故障：红色，打印机离线或持续失败
  3. 点击单个打印机可查看任务详情
  4. 运维人员可手动重试失败任务
后置条件：运维人员获得打印状态全貌
异常处理：
  - 打印机离线 → 显示红色离线状态
  - 任务积压过多 → 显示积压数量和等待时长
  - 任务持续失败 → 显示失败原因
证据：E-SRC: nms4pos-ui/.../PrintTaskMonitor/
```

### UC-4：配置部门打印路由

```
用例编号：UC-4
参与者：管理员
前置条件：已配置好打印机和打印队列
基本流程：
  1. 管理员进入部门配置
  2. 选择出品部门（后厨部门）
  3. 为部门绑定打印队列（一个部门 → 一个队列）
  4. 打印队列已配置主备打印机
  5. 后续该部门的菜品自动路由到对应队列
后置条件：部门打印路由配置完成
异常处理：
  - 打印队列未配置主打印机 → 提示配置不完整
  - 打印机故障 → 任务会切换到备用打印机
证据：E-SRC: nms4pos/.../dal/entity/PosDept.java (prn_queue 字段)
```

### UC-5：配置菜品-部门映射

```
用例编号：UC-5
参与者：管理员
前置条件：已有部门和菜品数据
基本流程：
  1. 管理员进入菜品-部门映射配置
  2. 选择菜品（或按菜类/桌台范围批量配置）
  3. 绑定到出品部门
  4. 后续结账时，该菜品的打印任务会路由到对应部门
后置条件：菜品打印路由配置完成
异常处理：
  - 菜品未绑定部门 → 无法路由，任务可能失败
  - 部门未绑定队列 → 无法路由，任务可能失败
证据：E-SRC: nms4pos/.../dal/entity/PosDishToPrnDept.java
```

## 五、业务规则汇总

| 规则编号 | 规则内容 | 约束级别 | 证据 |
|----------|----------|----------|------|
| BR-01 | 打印任务必须关联打印队列或打印机 | MUST | PosPrnJob.prnQueueLid/prnPrinterLid |
| BR-02 | 打印任务必须指定用途（厨房联/传菜联/顾客联） | MUST | PrnJobPurposeEnum |
| BR-03 | 打印任务必须指定单据类型 | MUST | PrnStyleTypeEnum |
| BR-04 | 打印队列的主打印机故障时自动切换到备用打印机 | MUST | PrinterWorker.java:56-61 |
| BR-05 | 打印失败后休眠 10 秒重试 | MUST | PrinterWorker.java:74 |
| BR-06 | 打印机故障时休眠 5 秒后重试 | MUST | PrinterWorker.java:59 |
| BR-07 | 菜品必须绑定出品部门才能路由打印 | SHOULD | PosDishToPrnDept |
| BR-08 | 部门必须绑定打印队列才能接收打印任务 | SHOULD | PosDept.prn_queue |
| BR-09 | 打印样式可配置行级打印条件 | MAY | PosPrnStyleItem.condition_ |
| BR-10 | 顾客联可按结账场景/桌台/区域/桌型过滤 | MAY | PosCustomerBillSetting |
