## 总论：一个词，一个宇宙

"run"是英语中义项最多的动词（约645个动词义项，超越set成为OED之最）。这不是偶然——它是人类认知系统用**一个身体体验**（跑步）去理解和表达**尽可能多的人类经验**的极致案例。

本分析的核心主张：**"run"的意义不是一张义项列表，而是一张以"持续动态+自主驱动"为认知核心的径向语义网络，其边界由力动态、语义韵、终结性和具身认知三重约束共同界定。**

### 维度一：语义——词的认知核心与径向范畴结构

#### 1.1 原型场景的认知建构

**理论支撑：径向范畴（Radial Category，Lakoff 1987）+ 场景语义学**

认知语言学对"run"语义分析的第一步，不是列出义项，而是重建它在大脑中激活的**感知场景（perceived scene）**：

> **原型场景** = 一个有意志的施事者（人/动物），以快于步行的速度，在水平地面上持续交替迈步前进，双脚交替离地，躯干前倾，重心前移，自身腿部驱动，无外力辅助。

这个场景不是随意的——它是人类最早、最深刻的身体体验之一。婴儿在学会跑步之前，已经无数次观察过他人跑步；跑步涉及重力感知、平衡系统、肌肉发力、呼吸加速等多感官协同。这种**多模态感知整合**（multisensory integration）使得"run"成为语言中感知密度最高的动词之一。

**场景要素及其替换可能性（这是多义的认知根源）：**

| 场景要素 | 原型值 | 可替换为 | 延伸义 |
|---------|-------|---------|-------|
| 施事（Agent） | 人/动物 | 机器 | run an engine |
| 施事（Agent） | 人/动物 | 液体 | The river runs |
| 施事（Agent） | 人/动物 | 组织/系统 | run a company |
| 施事（Agent） | 人/动物 | 身体状态 | run a fever |
| 动作（Motion） | 双脚交替离地前进 | 持续存在/进行 | Time runs out |
| 动力（Force） | 自身驱动 | 内在机制驱动 | The program runs |
| 介质（Medium） | 地面 | 时间轴 | The movie runs 2 hours |
| 方向（Direction） | 向前 | 四周/向外 | The vine runs across the wall |

#### 1.2 力动态（Force Dynamics）——"run"的深层认知约束

**理论支撑：Talmy（1988，2000）力动态理论**

Talmy的力动态理论揭示了语言中最被忽视但最普遍的语义维度：**每句话都在描述力之间的交互**。力动态有四种基本状态：

| 力交互类型 | run的体现 |
|-----------|---------|
| **施力 vs. 抗力** | The car **ran into** a wall. 施事（car）施力，撞上抗力（wall） |
| **施力 vs. 顺势** | He **runs** every morning. 施事主动施力，顺势前进 |
| **施力消除** | He **ran away**. 施事消除与对抗源的接触 |
| **力平衡** | The engine **runs**. 内部动力与阻力达成平衡，持续运转 |

**关键洞察**：run之所以能延伸出"管理/经营"义，正是因为"经营"本质上是"维持一个组织的力平衡运转"——企业需要持续施力以对抗各种阻力。这不是任意的隐喻，而是力动态结构的深层映射。

#### 1.3 义项间的认知关联：不是列表，是网络

**理论支撑：Kiyama & Shibuya (2023) *Research in Language* 历时研究**

基于语料库的历时研究揭示，run的645个义项并非平等分布，而是围绕三个**语义聚合中心（semantic clustering hubs）**组织：

```
聚合中心①：【人体运动】
  原型义（字面义）→ 逃离义 → 竞速义 → 冲刺义
  核心特征：双脚交替离地 + 速度 + 自主驱动

聚合中心②：【持续运转】
  机器运转 → 组织经营 → 程序运行 → 河流流淌
  核心特征：持续动态 + 内在动力 + 自主维持

聚合中心③：【事件展开】
  竞选义 → 风险承担义 → 时间流逝义 → 旅程义
  核心特征：在一段时间内持续参与某事 + 向前推进
```

### 维度二：搭配——超越"固定搭配"的认知约束

#### 2.1 搭配的语义韵（Semantic Prosody）深度

**理论支撑：语料库语言学语义韵理论（Sinclair，Partington）**

语义韵是语料库语言学最重要的发现之一：**一个词在长期使用中，会与特定情感色彩的词形成稳定的共现关系，从而"染上"某种语义氛围。**

"run"的语义韵并非中性，而是呈现**复杂的多重语义韵**：

| 搭配类型 | 语义韵 | 语感效果 |
|---------|-------|---------|
| run amok | **消极韵** | 失控发狂（amok=马来人语的"狂战士兵"） |
| run riot | **消极韵** | 失控蔓延；违法行为蔓延 |
| run rough | **消极韵** | 进展不顺利；出问题 |
| run short of | **中性偏消极** | 即将耗尽 |
| run a business | **中性韵** | 经营企业（中性，business本身是正面词） |
| run a race | **中性韵** | 参赛跑步（中性，race本身无情感色彩） |
| on the run | **中性偏积极** | 忙碌但充实（主动掌控感） |
| running on empty | **隐喻韵** | 精力耗尽（中性偏消极） |

**教学价值**：语义韵是母语者语感的重要组成部分，但传统教学几乎完全忽视它。学习者若只记忆"run=跑"，在遇到run amok时会产生强烈的认知冲击——"跑"怎么会变成"狂乱"？理解语义韵才能真正掌握一个词在真实语料中的使用规律。

#### 2.2 搭配的结构限制：介词的认知不可预测性

**理论支撑：idiomaticity研究（Moon 1997；Nunberg et al. 2018）**

短语动词的介词搭配是语言中最难预测的部分之一：

| 短语动词 | 核心语义 | 介词选择的认知逻辑 | 可预测性 |
|---------|---------|-----------------|---------|
| run **into** | 遭遇/碰撞 | into=进入/碰撞，激活"撞进障碍物"意象 | 部分可预测 |
| run **across** | 偶遇 | across=穿越/跨过，激活"偶然发现"意象 | 部分可预测 |
| run **up against** | 遭遇困难 | up=向上，against=对抗，激活"遭遇阻力" | 可预测 |
| run **out of** | 用完 | out=向外，of=脱离，激活"从容器流出"意象 | 可预测 |
| run **away** | 逃跑 | away=离开，激活"逃离源点" | 可预测 |
| run **out** | 耗尽（不及物） | 同上，但out为副词而非介词 | 可预测 |

**最核心的教学洞察**：run into vs. run across 在"偶遇"义上是近义词，但 **run into 额外携带"困难/冲击力"**（into的空间图式=进入某物内部，暗示碰撞和阻碍），而 run across 是中性的"发现"（across的空间图式=穿越某处，暗示路径和发现）。这一差异完全由 into vs. across 的空间图式差异决定。

### 维度三：语法——语义如何在句法中镜像自身

#### 3.1 终结性（Telicity）与界限性（Boundedness）

**理论支撑：Vendler（1957）四分法 + Talmy（2000）界限性理论**

动词的终结性决定了它描述的事件是否有内在终止点。这是理解"run"语法行为的核心钥匙：

**Vendler四分类对"run"的归属：**

| 动词类 | 特征 | "run"的归属 | 证据 |
|--------|------|------------|------|
| 活动动词（Activity） | 无内在终止点，可无限延续 | ✅ **run属于此类** | Can run for hours. |
| 达成动词（Accomplishment） | 有内在终止点，达成后即终止 | run a mile（有终点距离） | He ran a mile in 4 min. |
| 达成动词（Achievement） | 即时达成，无过程 | — | — |
| 状态动词（State） | 持续状态 | — | — |

**"run"的核心语法身份是活动动词（atelic）**——它的语义核心是"持续动态"，天然排斥内在终止点。但这不意味着它不能有终止点：**终止点由句法环境引入，而非动词本身提供**。

| 终止点来源 | 示例 | 说明 |
|-----------|------|------|
| 距离补语 | He **ran** five miles. | 距离=终止点（telic） |
| 时间补语 | The movie **runs** for two hours. | 时间=终止点（telic，但有争议） |
| 结果短语 | She **ran** into a tree. | 结果=终止点（telic） |
| 无补语 | The engine **runs**. | 无终止点（atelic） |

#### 3.2 双及物性（Lability/Ambitransitivity）

**理论支撑：Levin（1993）英语动词类别学**

"run"是典型的**双及物动词（labile/transitive alternation verb）**——同一个义项既可及物又不及物，意义高度相关：

| 形式 | 示例 | 认知解释 |
|------|------|---------|
| 不及物 | The engine **runs**. | 运转状态的持续（活动义） |
| 及物 | She **runs** the engine. | 对引擎施加力使其运转（使役义） |
| 不及物 | He **runs** every morning. | 自主运动行为 |
| 及物 | He **runs** three miles. | 以距离为目标的运动（有终点） |

**认知解释**：双及物现象说明"run"的核心语义"持续动态"不依赖宾语是否存在。无论宾语出现与否，施事维持持续动态的意象图式都是完整的。区别在于：宾语出现时，施事的"持续动态"被导向了一个具体的受影响对象。

#### 3.3 体貌交互（Aspectual Interaction）

**进行体与"run"的自然相容性：**

进行体（progressive）是检验活动动词的试金石。"run"与进行体高度相容：

- ✅ He **is running** now.
- ✅ The engine **is running** smoothly.
- ✅ We **are running** out of time.

进行体与"run"的组合还产生了一个微妙的**起始隐含义**（inceptive aspect）："正在run"往往暗示"刚开始run"或"正处于run的进行过程"——进行体天然带上了"这个动态正在进行"的当前性（current relevance）。

### 维度四：隐喻——具身认知的极致体现

#### 4.1 具身认知理论（Embodied Cognition）——为什么是"跑步"？

**理论支撑：Lakoff & Johnson（1999）*Philosophy in the Flesh*；Lakoff & Núñez（2000）*Where Mathematics Comes From***

具身认知的核心理论主张：**抽象概念不是凭空产生的，而是通过隐喻从身体体验中构建的**。身体不只是理解语言的工具，身体经验本身就是语言的根基。

"run"之所以能成为英语中义项最多的词，恰恰因为**跑步是人类最原始、最深刻的身体体验之一**：

- 每个有双腿的生命体都有跑步经验
- 跑步涉及重力、平衡、肌肉发力、呼吸、心跳加速——大量身体信号的同步整合
- 跑步有明确的速度感、节奏感、努力感——这些感知深刻铭刻在大脑中

这意味着"run"的每一个隐喻义，都不是随机的语言巧合，而是**身体经验的跨域映射（cross-domain mapping）**。

#### 4.2 隐喻映射的系统性：不是任意延伸，是认知经济性

**理论支撑：Lakoff & Johnson（1980）*Metaphors We Live By*；Kövecses（2005）*Metaphor in Culture***

隐喻不是修辞，而是思维的方式。"run"的隐喻延伸遵循严格的系统性：

```
【空间运动域】——人类最原始的认知域
        │
        │ ← 空间→时间映射
        ↓
【时间展开域】
  Time runs out.
  Summer is running fast.
        │
        │ ← 空间→组织映射
        ↓
【组织运转域】
  The company runs well.
  run a business / a campaign / a school
        │
        │ ← 空间→状态映射
        ↓
【身体状态域】
  run a fever / run a temperature
  Her eyes ran with tears.
```

**认知经济性原理**（Cognitive Economy，P6原则的深层机制）：人类倾向于用已有的具身场景描述新事物，而非创造新词。"run"从"跑步"到"经营"不是任意的比喻，而是因为**经营一家企业确实在很多方面像跑步**：需要持续发力、需要克服阻力、需要节奏和耐力、需要速度和方向感。

#### 4.3 神经科学的证据

近年来的神经影像学研究（Frontiers in Psychology, 2023 综述）发现，抽象概念的理解确实激活了与具身经验相关的脑区。这意味着理解"run a business"（经营企业）时，大脑可能部分激活了与实际跑步相关的运动皮层和感觉区域——这是隐喻的神经生物学基础。

### 维度五：英汉对比——汉语学习者的认知陷阱图谱

#### 5.1 "跑"的语义场边界与"run"的差异

**理论支撑：对比分析（Contrastive Analysis）+ 负迁移理论（Lado 1957；Selinker 1972）**

汉语"跑"与英语"run"的语义场边界存在系统性差异，这正是中国学习者L1负迁移的主要来源：

| 语义维度 | 汉语"跑" | 英语"run" | 迁移方向 |
|---------|---------|-----------|---------|
| 施事=生命体 | ✅ 严格要求 | ❌ 可延伸至机器/液体/组织 | 汉语→英语（正迁移限制） |
| 经营企业 | ❌ 不可能 | ✅ run a business | 汉语→英语（负迁移风险） |
| 运转/运行 | ⚠️ 部分可能（"机器跑起来了"） | ✅ run a machine | 部分正迁移 |
| 发烧 | ❌ 不可能 | ✅ run a fever | 汉语→英语（负迁移风险） |
| 流淌 | ❌ 不可能（用"流"） | ✅ The river runs | 汉语→英语（负迁移风险） |
| 竞选 | ❌ 不可能 | ✅ run for president | 汉语→英语（负迁移风险） |

**深层认知原因**：汉语"跑"的原型场景中"施事必须是生命体"这一约束在英语中不存在——英语"run"的隐喻延伸打破了生命体的边界，允许任何具有"持续动态"特征的事物成为施事。这反映了两种语言不同的**隐喻系统开放性**。

#### 5.2 汉语"跑+名词"与英语"run+名词"的搭配差异

据汉英对比研究（基于语料库）：

> "run + n. 的语义组合中没有'方式'成分，只有'run复合体'才接处所名词。汉语'跑+名'的语义组合则包括受事/承受对象、结果、时间、方式和处所。"

这意味着：**汉语"跑"的搭配比"run"丰富得多**，汉语学习者需要特别学习"run"作为**方式动词**的受限搭配。

#### 5.3 run vs. jog vs. sprint：速度语义的梯度缺失

汉语"跑"是对应三个不同速度等级的统称：

| 词 | 速度 | 典型语境 | 汉语表达 |
|----|------|---------|---------|
| jog | 慢跑（舒适节奏） | 健身/保持健康 | "慢跑"或直接"跑" |
| run | 中快速（跑步） | 体育运动/日常 | "跑" |
| sprint | 全力冲刺 | 比赛/紧急 | "冲刺/快跑" |

**负迁移的具体表现**：*She jogs every morning* 被翻译为"她每天早晨跑"，丢失了"以舒适节奏慢跑、保持健康"的语义。正确的理解需要建立 jog/run/sprint 的速度梯度感知。

#### 5.4 "run for office"的认知陷阱

这是最典型的负迁移陷阱之一：

- ❌ 字面直译：*为办公室奔跑*
- ✅ 真实含义：**竞选公职**

背后的认知障碍：汉语的"竞"字暗示了"竞争"，所以"竞选"是一个单独的动词。而英语的"run"从"奔跑"延伸为"参与一场竞争性赛跑"，再到"参加竞选"——这正是"选举是一场赛跑（ELECTION IS A RACE）"这一隐喻的具体体现。候选人（candidates）被框架化为赛跑者（runners），需要耐力（stamina），可能跌倒（stumble），最终有输赢。

### 维度六：语体——词的社会身份与语域分布

#### 6.1 语体光谱（Register Spectrum）的精确定位

**理论支撑：Martin Joos（1961）五层语体理论 + Biber & Finegan（1989）语域变异研究**

Martin Joos 将语体分为五层。"run"在各层的自然度分布：

| 语体层次 | 描述 | "run"的自然度 | 示例 |
|---------|------|------------|------|
| **Frozen（冻结体）** | 固定套语/仪式语言 | ❌ 不自然 | — |
| **Formal（正式体）** | 正式书面/学术 | ⚠️ 较少使用 | The application ran successfully on the server. |
| **Consultative（协商体）** | 专业讨论/半正式 | ✅ 可用 | In the normal run of events, this should not occur. |
| **Casual（随意体）** | 日常对话/非正式 | ✅✅ 最自然 | Let's go for a run tomorrow morning. |
| **Intimate（亲密体）** | 亲密关系/私下 | ✅✅ 可用 | Just run it by me one more time. |

**精确语体定位**：run 的主战场是 **Casual → Consultative 区间**（非正式到半正式），在日常口语和中等正式度的商务/新闻语篇中均表现活跃，但极少进入学术和法律语篇。

#### 6.2 语域差异（Register Variation）

**run 在不同语域中的分布特征：**

| 语域 | run 的典型搭配 | 语体说明 |
|------|------------|---------|
| 口语 | go for a run, run out of, run it by | 非正式，行动导向 |
| 新闻 | run a campaign, run for office, run into trouble | 中性，事件叙述 |
| 学术 | the program ran, the experiment ran | 正式，程序/实验报告 |
| 商务 | run a business, run a meeting, run operations | 中性偏正式 |
| 技术 | the server runs, the code runs | 技术语域，中性 |

#### 6.3 语体近义替换词矩阵

| 语义 | 非正式 | 中性 | 正式 |
|------|-------|------|------|
| 经营企业 | run a business | manage a company | administer the enterprise |
| 程序运行 | the app runs | the program executes | the system operates |
| 实施会议 | run a meeting | chair a meeting | convene a session |
| 竞选公职 | run for office | be a candidate | stand for election |

### 维度七：音韵——声音的认知信号（补充维度）

#### 7.1 音韵素（Phonestheme）的认知价值

**理论支撑：Sound Symbolism研究（Hinton et al. 1993；Dingemanse 2022）**

音韵素是"声音即符号"的语言学证据——某些音组合在跨语言层面稳定承载特定语义联想。

**run 的音节结构认知特征**：

| 特征 | 说明 | 认知价值 |
|------|------|---------|
| /rʌn/ 的 /r/ | 辅音r是卷舌近音，发音时舌头卷曲，气流部分受阻 | /r/ 音在英语中常与"力量、摩擦、阻滞"相关（gr-词族） |
| /rʌn/ 的 /ʌ/ | 短元音，发音短促有力 | 短元音传递"即时、干脆"的语感，与run的"快速"意象一致 |
| CVC结构 | 辅音+元音+辅音，单音节 | 简洁有力，符合run的核心语义 |
| 鼻音 /n/ | 词尾闭合，鼻音共鸣 | 鼻音在很多语言中与"完成、终止"相关（run的过去式ran=完成了的跑步）|

**gr- 音韵素词族补充**（与 run 共享"用力/持续"意象）：

| gr- 词 | 含义 | 共享意象 |
|--------|------|---------|
| grab | 猛然抓住 | 快速+用力 |
| grasp | 抓住；理解 | 用力+控制 |
| grind | 磨碎；折磨 | 持续摩擦 |
| growl | 低声咆哮 | 用力发声 |
| groan | 呻吟 | 痛苦/用力 |
| grip | 紧握 | 强力固定 |

## 第二部分：本体维度的深层解析

### 本体维度A：词源——词的历史身世与文明记忆

#### A.1 词源演变轨迹与历史事件

**run 的词源是英语史的一个微型标本**，展示了日耳曼语词在英语中的独特地位：

| 历史时期 | 语言 | 词形 | 核心事件 |
|---------|------|------|---------|
| 原始日耳曼语 | Proto-Germanic | ***\*rinnaną*** | 词根形成，含义=奔跑+流动 |
| 古英语 | Old English | *rinnan / irnan* | 进入英语，拼写未固定 |
| 中古英语 | Middle English | *rinnen / ronnen* | **关键事件**：鼻音化——n被插入词干 |
| 现代英语 | Modern English | **run** | 词形固化，过去式ran成为残留 |

#### A.2 最精彩的历史事件：鼻音化与不规则过去式ran

**逆删除（reanalysis）现象**：中古英语时期，run的过去分词形式是 *runne / runnen*（带鼻音）。受此影响，整个词干被重新分析（reanalysis），鼻音被固化为词干的一部分。于是：

- 过去式从预期的 *ranned*（类比walk→walked）变成了 **ran**
- ran 是历史上"删除了不应该在那里的-nen词尾"后留下的残留
- 这解释了为什么 **run/ran 是英语中最不规则却不规则的动词**——它们不符合任何规则，但形态高度稳定

**认知教学价值**：理解了这个历史，学习者就能把 ran 理解为一个"历史化石"——它保存了中古英语分词形式的一个片段。这个"为什么是不规则的"解释，比单纯记忆"run的不规则过去式是ran"深刻得多。

#### A.3 日耳曼语词 vs. 拉丁语词：run的文明史定位

run 是英语中**最纯正的日耳曼语词之一**——它从未被法语或拉丁语渗透。这与同一语义场的其他词形成对比：

| 语义 | 日耳曼语词 | 拉丁语词 | 语体差异 |
|------|-----------|---------|---------|
| 身体动作 | run | — | 核心口语词 |
| 行走 | walk | ambulate | run口语，ambulate学术 |
| 说 | say | utterance | say口语，utter正式 |
| 认为 | think | consider | think口语，consider正式 |
| 开始 | begin | commence | begin口语，commence正式 |

**文明史含义**：英语词汇系统中，日耳曼语词构成"核心口语层"（core oral vocabulary），拉丁语词构成"上层书面层"（high literary register）。run 属于前者——它是英语口语中最底层、最不可替代的词之一。

### 本体维度B：词素与词族——词的内部结构

#### B.1 run 的词素不可分析性

现代英语中，run 是一个**单一词素（single morpheme）**——它不能被进一步拆分为词根+词缀：

| 分析层次 | 说明 |
|---------|------|
| 词素层面 | run = 单一自由词根（free morpheme），不可拆 |
| 词素变体 | 无词素变体（不像receive/deceive中的-ceive共享词素） |
| 可分析性 | 不可结构分析，是原子性词素 |

这与 act（act=自由词根，可加-tion→action）、form（form=自由词根，可派生→formal）等词形成对比。

#### B.2 Bauer & Nation 词族层级模型

**理论支撑：Bauer & Nation（1993）词族层级理论**

词族层级模型将共享词根的词按派生复杂度分为6级：

| 层级 | 内容 | run的词族成员 | 派生复杂度 |
|------|------|-------------|-----------|
| **L1** 自由词根 | 仅词根本身 | **run** | 0（基线） |
| **L2** 规则屈折 | 添加规则变化 | runs / ran / running | 1（屈折） |
| **L3** 高产派生 | +高频透明后缀 | runner | 2（派生） |
| **L4** 常见派生 | +常见派生后缀 | runaway | 2（派生+复合） |
| **L5** 前缀派生 | +常见前缀 | over**run**, under**run** | 2-3 |
| **L6** 全部词缀 | +所有词缀 | long-**run**-ning | 3+ |

### 本体维度C：认知负荷与习得顺序

#### C.1 认知负荷的精确评估

**理论支撑：Craik & Lockhart（1972）加工深度理论 + Laufer & Hulstijn（2001）投入量假设**

认知负荷不是简单的"难/易"二元判断，而应从多个维度评估：

| 负荷维度 | 评估 | 说明 |
|---------|------|------|
| 具体性 | **低负荷** | "跑"是高度具体的身体体验，图像化容易 |
| 隐喻复杂度 | **中等负荷** | 基本义→隐喻义的延伸路径需要显性教学 |
| 搭配密度 | **高负荷** | run a/run into/run out等数百种搭配，难以穷举 |
| 多义性 | **极高负荷** | 645个义项，任何单一教学法都难以覆盖 |
| 不规则性 | **低负荷** | run本身规则（run/runs/running），ran/been少数不规则 |

#### C.2 Nation（2013）词汇知识框架中的"run"位置

| 知识类型 | 维度 | run的掌握标准 |
|---------|------|------------|
| 接收性 | 形式识别 | 听到 /rʌn/ 能识别为 run |
| 接收性 | 意义理解 | 在阅读中理解 run 的上下文义 |
| 接收性 | 语体感知 | 能区分 run / jog / sprint 的语体差异 |
| 产出性 | 形式产出 | 正确拼写 run / runs / ran / running |
| 产出性 | 意义产出 | 在口语/写作中正确选择 run 的义项 |
| 产出性 | 搭配产出 | 正确使用 run a business 等搭配 |
| 产出性 | 语体产出 | 在正式场合选择 manage/execute 替代 run |

**深度理解的分水岭**：知道"run=跑"对应 Nation VKS 的 L1-L2（浅层加工）。能够区分 run a business 和 manage a company 的语体差异，并正确运用，属于 L4-L5（深层加工）。

## 第四部分：教学法落地——深度学习的认知路径

### 4.1 六维认知学习路径（对应L3-L5深度加工）

```
第一步（L2→L3）：建立原型场景——从具身感知出发
  ↓
  观看/演示"人跑步"的动态画面
  引导描述：谁在跑？怎样跑？往哪跑？跑了多久？
  激活 run = "持续动态 + 自主驱动" 的核心意象

第二步（L3）：搭配固化——搭配是认知约束，不是任意规则
  ↓
  run a business ≠ do business（"持续运作+承担责任"图式）
  run into trouble ≠ meet with trouble（"撞进困难"意象）
  重点操练 run a + N 系列，体会"持续动态"图式的稳定投射

第三步（L4）：语法约束——终结性决定你能/不能怎么说
  ↓
  He ran for hours.（atelic，无终点）
  He ran to the store.（telic，距离=终点）
  Can you run it?（labile，双及物验证）

第四步（L5）：隐喻延伸——认知经济性的极致运用
  ↓
  施事替换：从人到机器，到组织，到身体状态
  每一步问：这里还有"跑步"的感觉吗？哪里像？哪里不像了？
  学习者自己发现：不变的是"持续动态"，变化的是施事的类型

第五步（L5）：英汉对比——L1负迁移的主动识别
  ↓
  "run a business" 中文为什么不说"跑企业"？
  汉语的"跑"有哪些边界是英语"run"没有的？
  反向迁移："跑"的哪些义项是英语没有的（竞速vs跑步的区分）
```

### 4.2 常见错误预警的认知根源

| 错误 | 正确形式 | 认知根源 | 干预策略 |
|------|---------|---------|---------|
| *He ran into my office yesterday.*（语义韵错误） | *He stopped by my office.* | run into 携带"碰撞/困难"韵律，在中性语境不自然 | 语料库例句展示 |
| *I will run a business in the interview.*（语体错误） | *I will manage a business.* | run 偏口语，面试属于协商体 | 正式场合词汇矩阵 |
| *The company ran into great success.*（隐喻冲突） | *The company achieved great success.* | run into 激活"困难/障碍"意象，与success冲突 | 隐喻语义兼容性分析 |
| *She runs three miles every morning.*（未达L3） | ✅ 正确，但需配语境 | 仅知道"跑"的字面义，不能自动推导健身语境 | 搭配场景化 |
| *The machine runs.* → *She runs the machine.*（未理解labile） | ✅ 两者均可但语义微妙不同 | 及物/不及物并非随意切换，意义有别 | 对比两个句子的施力方向 |
