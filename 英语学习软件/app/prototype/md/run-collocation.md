### 维度二：搭配——搭配是词的灵魂

#### 2.1 核心搭配的认知约束

"run"的搭配遵循严格的认知约束，不可以任意替换。搭配的学习，本质上是学习"在哪个场景下，哪种搭配形式是对的"。

**run + 名词（最核心搭配）**：

| 搭配 | 中文含义 | 认知约束 |
|------|---------|---------|
| run a business | 经营企业 | run隐含"持续运作 + 承担责任"，不同于 do business |
| run a race | 参加赛跑 | run隐含"竞速"，不同于walk a race |
| run a program | 运行程序 | run隐含"执行指令序列"，不同于use a program |
| run a fever | 发烧 | run隐含"体温持续上升"，body temperature rises steadily |
| run a risk | 冒险 | run隐含"主动踏入危险"，taking a risk actively |
| run an errand | 跑腿办事 | run隐含"短途快速移动"，not a casual stroll |

**关键洞察**：`run + 名词` 整体激活的是**"持续、主动、有目标的动态行为"图式**。这个图式是该搭配不可替代性的认知根源。

#### 2.2 run + 介词/副词的认知分野

| 搭配 | 含义 | 认知机制 |
|------|------|---------|
| run into | 撞上；遭遇困难 | run（冲）+ into（进入）= 冲进某物/某境况（意外遭遇） |
| run across | 偶遇；发现 | run（穿越）+ across（跨过）= 在空间中偶然发现 |
| run out of | 用完 | run（耗尽）+ out（向外）= 从内部持续向外流出直至空竭 |
| run over | 碾过；复习 | run（经过）+ over（在上方）= 从上方压过；或从上方扫过（review） |
| run through | 贯穿；快速浏览 | run（穿透）+ through（穿过）= 从一端穿透到另一端 |
| run away | 逃跑 | run（逃离）+ away（离开）= 快速离开（通常因恐惧或逃避） |

**run into vs. run across 的关键区别**：两者均可表示"偶遇"，但 **run into 额外携带"困难/危险/冲击力"**（物理碰撞的意象），而 run across 是中性的"发现"。这个差异来自 into vs. across 的空间图式差异。

#### 2.3 语体边界：run vs. manage vs. operate

| 场景 | 用词 | 语体 | 语感差异 |
|------|------|------|---------|
| 日常管理咖啡馆 | run a café | **neutral** | 最自然，任何场合均可用 |
| 企业运营管理 | manage a company | **neutral-formal** | 更正式，强调管理技能和责任 |
| 机械设备运转 | operate a machine | **neutral-formal** | 更正式，强调操作程序 |
| 突然遭遇问题 | run into trouble | **neutral** | 自然口语，into凸显"撞入困境" |
