### 维度四：隐喻——从身体到心灵的跨越

#### 4.1 概念隐喻理论框架（Lakoff & Johnson, 1980）

**核心主张**：隐喻不是修辞装饰，而是**思维的基本方式**。人类用具体的、具身的（embodied）、可感知的生活经验来理解和表达抽象概念。"run"的隐喻延伸是概念隐喻理论的经典示范。

#### 4.2 run 的隐喻映射网络

```
                          [原型空间域：人在地面上快速交替迈步行进]
                                      │
           ┌──────────────────────────┼──────────────────────────┐
           ↓                          ↓                          ↓
    【物理运动域】            【机器运转域】              【组织管理域】
    · run a race               · run an engine              · run a business
    · run for exercise         · run a program              · run a school
    · run upstairs             · run a temperature          · run a campaign
           │                          │                          │
           ↓                          ↓                          ↓
    【逃离/规避域】            【流体流动域】              【状态激活域】
    · run away (from danger)   · The river runs              · run a fever
    · run for it              · The nose runs               · run high
    · run out (of courage)    · The battery runs low        · run hot
           │                          │                          │
           ↓                          ↓                          ↓
    【路径延伸域】             【时间流逝域】              【风险承担域】
    · run along the wall       · Time runs out.              · run a risk
    · run through the forest   · The summer is running      · run the gauntlet
    · run across the field     · fast.                       · run a chance
```

#### 4.3 空间域 → 时间域的映射

这是"run"隐喻体系中最精妙的一层：**时间是空间中的运动物体**（TIME IS A MOVING OBJECT）这一根本性隐喻：

| 隐喻表达 | 空间域映射 | 时间域对应 |
|---------|-----------|---------|
| Time **runs** out. | 物体从容器中流出 | 时间用尽，从未来流到现在 |
| The deadline **is running** up. | 债务向上堆积 | 最后期限越来越近 |
| We're **running out of** time. | 容器内物体耗尽 | 可用时间即将耗尽 |
| The summer **ran** quickly. | 跑者快速移动 | 时间快速流逝 |

#### 4.4 run into 的隐喻意象

"run into trouble"之所以自然，是因为它同时激活了两层隐喻：
1. **困难是有形的障碍物**（DIFFICULTIES ARE OBSTACLES）
2. **困难的空间位置在人前方**（PROBLEMS LIE AHEAD）

"run into"因此比"meet with difficulty"更直觉——它用**物理碰撞**的具身经验激活了**遭遇困难**的抽象概念。
