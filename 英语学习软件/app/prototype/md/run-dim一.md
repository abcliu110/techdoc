### 维度一：语义——词是场景，不是标签

#### 1.1 原型场景分析

**原型理论（Prototype Theory，Rosch 1975）的核心主张**：一个词的众多义项并非平等并列，而是围绕一个**原型（prototype）**呈辐射状分布。判断一个用法是否属于该词义范畴，不是靠严格定义，而是靠与原型的**家族相似性（family resemblance）**。

"run"的原型场景是：

> **一个具有生命的施事者（人/动物），依靠自身腿部驱动，在水平地面上以快于步行的速度持续交替迈步前进，双脚交替离地，姿态为向前倾斜驱进。**

这个场景包含以下**场景要素（scene elements）**：

| 场景要素 | 描述 |
|---------|------|
| 施事（Agent） | 具有意志力的生命体（人、动物） |
| 动作（Motion） | 双脚交替离地、向前倾斜驱进 |
| 速度（Speed） | 快于走路，低于奔跑（相对参照） |
| 路径（Path） | 水平方向，有明确位移 |
| 动力（Force） | 施事自身腿部驱动，非外力 |
| 介质（Medium） | 地面（可延伸至水面，如游泳者冲出水面） |
| 姿态（Posture） | 躯干前倾，重心前移 |

**关键认知洞察**：原型场景的每一要素，都可能成为词义延伸的**替换点**。施事从人到机器（run an engine），到液体（the river runs），到抽象组织（run a business），到身体状态（run a fever）——延伸的机制是"施事替换"，核心特征"持续动态"被保留。

#### 1.2 义项间的认知关联

根据 Kiyma & Shibuya (2023) 在 *Research in Language* 上的历时研究，"run"的义项之间存在系统性的认知连接，而非任意的多义堆砌：

```
[原型场景：人/动物依靠自身腿部驱动，在地面上快速交替迈步前进]
        │
        │ ← 施事替换：人 → 动物
        ↓
  【逃离/奔跑类】
  run away / run for it / run off
  核心：速度 + 自主驱动 + 紧迫感
        │
        │ ← 施事替换：人 → 机器/液体
        ↓
  【运转/流淌类】
  run an engine / The river runs / run fast
  核心：持续动态 + 内在动力驱动
        │
        │ ← 施事替换：人 → 抽象组织/系统
        ↓
  【管理/运营类】
  run a business / run a school / run a meeting
  核心：持续运作 + 维持系统运转 + 承担责任
        │
        │ ← 施事替换：人 → 身体
        ↓
  【身体状态类】
  run a fever / run a temperature / run high
  核心：持续上升/超出正常值
        │
        │ ← 路径延伸：物理路径 → 时间/事件路径
        ↓
  【持续/经历类】
  run for office / run a campaign / run a risk
  核心：在一段时间内持续参与某事
```

#### 1.3 《牛津英语词典》的量化数据

据 Simon Winchester 和 Peter Gilliver（OED 编辑）的研究，**"run"作为动词拥有约645个独立义项**，超越此前位居首位的"set"（约200余义），成为 OED 中义项最多的单词。这一历史性超越可能与20-21世纪以来"run"的使用频率急剧增长有关——高频使用是义项增殖的温床（每一次新语境都可能催生新用法）。

**教学启示**：学习"run"不应从义项列表入手，而应从**原型场景 + 场景要素替换规则**入手——理解了"施事替换"机制，就能自主推导出新义项，而非逐一死记。
