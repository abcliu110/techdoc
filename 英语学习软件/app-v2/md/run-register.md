### 维度六：语体——词的社会身份

#### 6.1 run 的语体光谱位置

基于语料库数据（Collins COBUILD等），"run"的语体位置如下：

```
    口语/非正式                    中性                    正式/书面
         │                           │                        │
    go for a run              run a business           The application ran
    run out of money          run a program             successfully on
    run it by me again        run a meeting            the server.
    run in the park           run a campaign
    run a quick errand
```

**定位**：run 是**中低正式度**的核心通用词汇（informal → neutral），跨越口语到中性书面语，但**极少出现在高度正式的法律/学术文本中**。

#### 6.2 run 与语体相近词的对比

| 语体位置 | 同义替换词 | 语感差异 |
|---------|-----------|---------|
| 非正式 | have a run, go running | 更口语，强调运动体验 |
| 中性 | operate (机器), manage (组织) | 更正式，强调技能/责任 |
| 正式 | execute (程序), administer (机构) | 正式书面语 |
