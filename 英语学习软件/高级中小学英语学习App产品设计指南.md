N# 上篇：教学法设计
N
N## 设计原则总览
N
N本产品建立在以下设计原则之上，每条原则均有认知科学或语言学依据，并直接影响第二部分的产品设计。
N
N**原则 P1**：词是场景，不是标签（适用于具身词）。
N> 认知语言学核心发现：对于具身认知型词汇（身体动作词、空间关系词、感知动词），词的本质是对一个感知场景的压缩编码。学习这类词，是建立大脑中一个场景表征，而非记住一个词-义配对。
N> **适用范围说明**：功能词（介词、连词、助动词）、高度抽象词（democracy、justice）不适用场景策略——此类词汇更适合搭配学习和框架语义学。
N
N**原则 P2**：词义延伸有系统性，不是任意扩展。
N> 词的多义不是"一个词有多个无关意思"，而是同一个原型场景通过要素替换（施事/对象/路径/状态）延伸出多个义项。掌握延伸规律，就能推断新义项。
N
N**原则 P3**：深度理解从接收走向产出。
N> Nation (2013) 区分接收性知识（看得懂）和产出性知识（用得出）。深度理解=从接收向产出的迁移能力。两者相互促进，而非单向流水线。传统背词只到接收性L2，无法迁移。
N
N**原则 P4**：加工深度决定记忆深度。
N> Laufer & Hulstijn (2001) 的"投入量假设"：深度刻意加工（如生成性任务）显著优于浅层识别加工。Craik & Tulving (1975) 的加工深度实验为这一方向提供了早期实证支撑。L3（语境搭配）以上的刻意加工，才能将短时记忆转化为长时记忆。
N
N**原则 P5**：词义理解需要多维协同。
N> 理解一个词需要同时在语义、搭配、语法、隐喻、英汉对比、语体六个维度上建立连接。其中语义/搭配/隐喻兼有认知语言学依据；搭配/语体/英汉对比属于二语习得研究维度。单维度的词-义配对无法支撑真实语境中的准确使用。
N
N**原则 P6**：认知经济性影响词义延伸方向。
N> 人类倾向于用已有场景描述新事物，而非创造新词。延伸方向多遵循"相似性→因果性→类属性"三条路径。注意：认知经济性是描述性框架，不是严格预测模型——历史偶然性也会造成无法预测的延伸。
N
N**原则 P7**：词的选择是社会语用的决策。
N> 同一个意思，在口语/中性/书面三种语体中选择哪个词，是话语身份的表达。深度理解=知道这个词在语体光谱上的位置。
N
N**原则 P8**：先备关系决定学习路径。
N> 学习有顺序性：不知道light无法理解lighthouse，不知道there be无法理解there used to be。先备关系不是障碍，而是认知优化的机会。

N## 第一章 词义理解的多维理论
N
N### 1.1 场景语义学：词是压缩的场景
N
N#### 1.1.1 核心命题
N
N**每个词描述一个场景。**理解一个词，是激活大脑中一个可感知的场景表征。
N
N这不是比喻，而是认知语言学的核心发现。当大脑处理"run"这个词时，激活的不仅是"跑/v."的文字标签，而是一个人在地面上快速移动的动态画面——包含速度（快于走路）、姿态（双脚交替离地）、动力（自身腿部驱动）等感知要素。
N
N**设计含义（P1）：**词义学习的终极目标是让用户看到单词时脑中浮现场景，而非文字标签。产品中每个单词卡的默认展示应该是**原型场景图像或动画**，而不是中文释义。
N
N#### 1.1.2 场景的构成要素
N
N一个词激活的场景由若干**场景要素（scene elements）**构成：
N
N| 词 | 原型场景 | 核心场景要素 |
N|----|---------|------------|
N| run | 人在地面快速移动 | 施事（人）、动作（双脚交替离地）、路径（水平）、速度（快于走）、动力（自身驱动） |
N| grasp | 手指合拢抓住某物 | 施事（手/手指）、动作（合拢→包裹→固定）、对象（具体物体） |
N| break | 完整物体结构破坏 | 施事（施加力）、动作（结构断裂）、结果（整体→碎片/分离） |
N| in | 物体在容器内部 | 内部（inside）、边界（boundary）、包含（containment） |
N
N#### 1.1.3 场景要素替换：词义延伸的机制
N
N词的多义本质是**场景要素的替换**——保留运动核心特征，替换施事、对象或介质：
N
N**run的场景延伸网络：**
N
N```
N[原型场景：人在地面快速移动（含奔跑与逃离两种情况）]
N           │
N  ┌────────┼────────────┐
N  ↓        ↓            ↓
N【逃离/逃跑】【持续运转】【抽象组织/状态】
Nrun away   run a car   run a business
Nrun off    run engine  run a school
Nrun into   run fast   run a risk
Nthe woods              run a fever
N           ↓            ↓
N        施事替换：    施事替换：
N        机器/液体     抽象组织
N        代替人         代替人
N        共同特征：    共同特征：
N        持续运转       持续运作
N```
N
N**grasp的场景延伸网络：**
N
N```
N[原型场景：手指接触物体后合拢固定]
N           │
N  ┌────────┼────────────┐
N  ↓        ↓            ↓
N【物理抓握】  【理解力】   【权力/控制】
Ngrasp the   grasp the   grasp power
Nball        idea        grasp at a chance
Ngrasp       grasp the   grasp at straws
Nsomething   point
N           ↓            ↓
N        施事替换：    施事替换：
N        手指→思维     抓握→掌控
N        动作序列：    动作序列：
N        接触→合拢    抓住→不放手
N        →包裹→固定    →控制
N```
N
N**break的场景延伸网络：**
N
N```
N[原型场景：完整物体→结构破坏→碎片或分离]
N           │
N  ┌────────┼────────────┐
N  ↓        ↓            ↓
N【物理破坏】【规则违反】【状态中断】
Nbreak glass  break the law  break silence
Nbreak a leg  break a promise break a habit
Nbreak ice    break rules   break a record
N           ↓
N        施事替换：
N        施加力→结构断裂
N        边界突破
N```
N
N**设计含义（P2）：**义项学习路径 = 先还原原型场景 → 再理解要素替换方向。产品在展示多义词各义项时，应按"原型→延伸"的路径组织，而非罗列无关联的释义。
N
N#### 1.1.4 场景延伸的三条路径
N
N词义从原型向外的延伸，遵循三条可预测的路径：
N
N| 延伸路径 | 机制 | run 的例子 |
N|---------|------|---------|
N| **相似性延伸** | 新场景与原型在结构上相似 | machine runs（机器运转）与run（跑）共享"持续动态"特征 |
N| **因果性延伸** | 新场景是原型场景的因果结果 | run a risk（导致风险的行为）=执行跑的动作→导致风险 |
N| **类属性延伸** | 新场景共享原型的类别特征 | run a temperature（发烧）呈现"run"的特征：上升+持续 |
N
N> **说明**：上述三条路径是简化教学模型。真实词义延伸机制更复杂，还包括转喻（metonymy）延伸（如"喝一杯"中"一杯"代指酒），以及隐喻-转喻互动（如"break the ice"同时涉及空间隐喻和转喻）。高中段可适当引入转喻概念。
N
N#### 1.1.5 认知经济性原理
N
N人类为什么用"抓住"（身体动作）描述"理解"（认知行为）？原因只有一个：**认知经济性**。
N
N```
N新事物出现 → 方案A：大脑创造全新场景表征 → 认知成本极高
N          → 方案B：用已有场景描述新事物 → 认知成本低 ✓
N
N人类默认选择方案B。
N这就是为什么几乎所有语言的隐喻系统都高度相似：
N  → 上=好/积极，下=坏/消极（权力、情绪、地位都如此）
N  → 身体体验是人类最深层的认知基础
N```
N
N**设计含义（P6）：**产品应优先展示词的**身体体验型场景**（跑、抓、推、拉），再由此推及抽象义项。这符合人类认知的自然顺序。
N
N### 1.2 框架语义学：词激活的知识包
N
N#### 1.2.1 核心思想
N
N理解一个词，不是理解它的定义，而是**激活一个预先存在于大脑中的知识框架**（Fillmore, 1977）。
N
N**场景语义学 vs 框架语义学：**
N
N| | 场景语义学 | 框架语义学 |
N|--|----------|----------|
N| 核心单位 | 可感知场景（perceived scene） | 百科知识框架（knowledge frame） |
N| 激活内容 | 视觉/动作/空间意象 | 角色、关系、脚本 |
N| 解释力 | "为什么是这个形状" | "为什么激活这些角色" |
N| 对应关系 | 场景要素替换 | 框架角色替换 |
N| 互补价值 | 身体感知根源 | 社会知识网络 |
N
N两者互补——**场景**解释词义的身体感知根源，**框架**解释词义激活的社会知识结构。
N
N#### 1.2.2 典型框架：BUY 框架
N
N```
NBUY 框架（商业交易事件）
N┌─────────────────────────────────┐
N│        COMMERCIAL EVENT            │
N│                                    │
N│   BUYER ←─── 金钱 ───→ SELLER   │
N│     │                │              │
N│     ↓                ↓              │
N│  买到某物         失去某物        │
N│                                    │
N│  [物品：GOODS] [价格：PRICE]      │
N│  [地点：PLACE] [时间：TRANSACTION] │
N└─────────────────────────────────┘
N```
N
Nbuy 的各义项，都是在这个框架中替换不同角色：
N
N| 义项 | BUYER | GOODS | 框架替换说明 |
N|------|-------|-------|------------|
N| buy a book | 人 | 书籍 | 完整商业交易 |
N| buy time | 人 | 时间 | 时间被当作商品 |
N| buy an idea | 人 | 想法 | 想法被当作商品 |
N| buy trouble | 人 | 麻烦 | 麻烦被当作可交易的东西 |
N
N#### 1.2.3 典型框架：GIVE 框架
N
N```
NGIVE 框架（给予事件）
N┌─────────────────────────────────────┐
N│        GIVE EVENT                      │
N│                                        │
N│   GIVER ──── GIFT ───→ RECIPIENT    │
N│                                        │
N│   [原因：REASON] [方式：MEANS]        │
N│   [地点：PLACE] [时间：TIME]           │
N└─────────────────────────────────────┘
N```
N
Ngive 的多义（give a book / give a lecture / give a smile / give trouble / give in / give up），全部共享"给予"框架——只是Gift的类型不同。
N
N### 1.3 词源学：词的历史身世
N
N#### 1.3.1 核心思想
N
N知道一个词的起源，往往能同时理解它的多个义项。**词源是时间的切片**——把词义在历史时间轴上串联成故事线。
N
N```
N传统背词（无效）：
N  candidate → 候选人 → 记忆
N  ↑ 候选人和white有什么关系？不知道
N
N词源学习（有效）：
N  candidate = 拉丁语candidatus = 穿白袍的人
N  古罗马竞选者穿涂白粉的托加袍（toga candida）以示公开透明、易于辨识
N       ↓
N  公开透明 → 纯洁无私 → 适合担任公职
N       ↓
N  候选人是"公开透明之人"
N       ↓
N  义项之间的历史脉络打通了
N```
N
N更多词源示例：
N
N**disaster（灾难）**：`dis-`（远离）+ `aster`（星星）= 星星偏离轨道 → 星象凶兆 → 灾难。这是极佳的隐喻案例，展示古人如何从"天象"投射到"人间不幸"。
N
N**ambition（雄心/野心）**：`amb-`（周围）+ `ire`（走）= 四处奔走（拉票）→ 追求公职的野心 → 雄心壮志。词源同时解释了为什么ambition有褒义（雄心）和贬义（野心）双重色彩。
N
N> **教学价值说明**：词源知识对**已具备一定词汇量（≥3000词）的高中段学习者**有较好的辅助理解效果。对初中及以下学段、希腊/拉丁语基础薄弱的学生效果有限。产品应将词源故事定位为**锦上添花**，而非核心学习路径。
N
N**设计含义（P1）：**词源故事帮助把零散义项串联成有意义的叙事线。产品可在单词详情页提供词源故事模块（优先覆盖高中核心词约200-300个）。
N
N#### 1.3.2 高频词源的分类体系
N
N| 来源 | 领域 | 代表词例 |
N|------|------|---------|
N| 希腊语 | 科学/哲学/医学 | biology, philosophy, democracy, geography, thermometer |
N| 拉丁语 | 法律/宗教/行政 | campus, salary, agenda, candidate, manuscript |
N| 法语 | 文化/餐饮/文学 | restaurant, memoir, entrepreneur, rendezvous |
N| 日耳曼语 | 核心/日常/身体 | lord, woman, Thursday, Wednesday |
N
N#### 1.3.3 词根前缀的系统性
N
N词源学为词根词缀提供**历史维度的理解**，而非机械记忆：
N
N| 前缀 | 来源 | 含义 | 词例 |
N|------|------|------|------|
N| de- | 拉丁语否定 | 否定/去除 | deactivate, demilitarize, disinfect |
N| e-/ex- | 拉丁语向外 | 向外/离开 | eject, exhale, emigrate, excavate |
N| uni- | 拉丁语一 | 一 | uniform, universe, unicorn |
N| bi- | 拉丁语二 | 二 | bicycle, bilingual, binoculars |
N
N### 1.4 韵律与音义：词的声音也有含义
N
N#### 1.4.1 核心发现
N
N英语中存在**音义组合（phonestheme）**——某些音组合带有系统性情感或语义联想倾向。这是单词的"声音心理学"，是学生完全未知的认知盲区。
N
N```
N传统观点（语言符号任意性）：
N  dog → 狗 ← 音和义之间没有联系
N
N认知语言学观点（声音有理据性）：
N  英语中部分音组合（phonestheme）存在统计性语义倾向：
N  sl- 组：slip, slide, slither, sloppy, slick 等词共享"滑/负面"倾向
N  gr- 组：grab, grasp, grind, growl, grunt 等词共享"力量/抓取"倾向
N
N  但：音义组合是"统计性倾向"，而非严格语义规则。
N  例如 great / green / ghost 中的 gr- 并不符合"力量"倾向，
N  列表选择性地只选了符合预期的词，这是确认偏误。
N```
N
N> **重要说明**：音义组合是有趣的**语言学习启发工具**，不是可靠的词义预测规则。产品使用中应明确标注为"语言趣味现象"，不得作为词义推断的可靠依据。
N
N#### 1.4.2 音义组合的系统性
N
N| 音开头 | 语义联想倾向 | 代表词（已剔除争议词） |
N|--------|------------|----------------|
N| sl- | 贬义/滑腻/负面 | slip, slide, slither, sloppy, slick |
N| gr- | 力量/抓取/摩擦 | grab, grasp, grind, growl, grunt |
N| fl- | 轻盈/飞行/流动 | fly, float, flutter, flicker, flow |
N| sn- | 负面/嗅觉/蛇类 | sniff, snore, sneak, snake, snarl |
N| cr- | 力量/挤压/破碎 | crash, crush, crack, crumble, crisp |
N| wr- | 扭曲/困扰 | writhe, wrestle, wrench, wrap, wreckage |
N| -ump | 沉闷/笨重/圆形 | bump, thump, lump, slump, plump |
N
N**教学价值：**
N1. 听到一个未知词时，通过音义组合**预判情感方向**（仅作参考，不是规则）
N2. 同音义组的词一起学，有助于减少拼写混淆
N3. 写作时根据情感色彩选择音义词（作为辅助手段）
N
N**使用边界：**
N- 适用于高中段作为**拓展趣味模块**，不设强制过关标准
N- 不适用于小学和初中段（认知负担过重，且缺乏实证）
N- 不作为词义推断的主要依据
N

N### 1.5 隐喻映射：空间到抽象的跨越
N
N#### 1.5.1 核心思想
N
N介词和其他核心词的多义，核心机制是**空间域到抽象域的隐喻映射**。这是认知语言学（Lakoff & Johnson, 1980）的核心发现。
N
N```
N空间域 ──────────────────────────────→ 抽象域
N  │                                     │
Non the table ────────────────────────→ on Monday
N  "接触表面"                             "日历上的接触点"
N  │                                     │
Nin the box ──────────────────────────→ in 2024
N  "容器内部"                             "年份的内部/范围内"
N  │                                     │
Nat the door ──────────────────────────→ at 3 o'clock
N  "精确空间点"                           "时间轴的精确一点"
N```
N
N#### 1.5.2 IN 的隐喻辐射网络
N
N```
N                    [容器内部]
N                    in the box
N                         │
N        ┌──────────────┼──────────────┐
N        ↓              ↓              ↓
N   [空间范围]    [时间区域]      [状态包含]
N  in the city    in the morning   in danger
N  in the world   in 2024        in trouble
N        │              ↓              ↓
N   [衣着/穿戴]    [方式/形式]    [原因/依据]
N   in uniform    in English      in response to
N   in red        in a hurry     in honor of
N```
N
N**设计含义（P5）：**产品中的介词学习模块，应从空间图式出发，沿隐喻路径展开，而非逐一孤立的语法规则。
N
N### 1.6 理解深度模型：四阶段与L1-L5
N
N#### 1.6.1 分析≠理解
N
N六维框架（语义/搭配/语法/隐喻/英汉对比/短语动词）是**解构工具**，把一个词拆成六个面来观察。但拆开看≠真正理解。
N
N```
N六维全知道 ≠ 能在真实语境中准确使用
N```
N
N#### 1.6.2 深度理解的四阶段
N
N| 阶段 | 名称 | 行为 |
N|------|------|------|
N| 第一 | 接触层 | 在真实语境中遇到生词，凭语感判断"感觉对/不对" |
N| 第二 | 加工层 | 刻意加工（由浅到深分为L1-L5） |
N| 第三 | 固化层 | 间隔复习+生成性练习转化为内化知识 |
N| 第四 | 迁移层 | 在从未见过的新语境中正确使用 |
N
N**大多数背词软件只做L2（词-义配对），L3-L5才是深度理解的分水岭。**
N
N#### 1.6.3 L1-L5加工深度
N
N| 深度 | 类型 | 说明 | 产品对应 |
N|------|------|------|---------|
N| L1 | 形式注意 | 注意到拼写或发音 | 词汇浏览 |
N| L2 | 形式+意义 | 查词典，记住了"跑" | 单词卡（释义展示） |
N| L3 | **语境搭配** | 记住run a business而非run business | **搭配练习** |
N| L4 | **使用限制** | 知道run用于具体情境，不用于抽象计划 | **语境选择题** |
N| L5 | **多义网络+语体** | 能在15+义项中准确选取，区分口语/书面 | **多义辨析题+语体写作** |
N
N#### 1.6.4 接收性知识↔产出性知识
N
NPaul Nation (2013) 区分了两类词汇知识：**VKS（Vocabulary Knowledge Scale）**是 Wesche & Paribakht (1996) 开发的五级自评量表，两者不是同一成果。
N
N| | 接收性（Receptive） | 产出性（Productive） |
N|--|--------------------|----------------------|
N| 形式 | 听到/看到能识别 | 能正确拼写和发音 |
N| 意义 | 能匹配释义 | 能回忆出释义 |
N| 使用 | 能理解语境中的用法 | **能生成正确搭配和句型** |
N
N```
N接收性知识 ←────────────→ 产出性知识
N（看得懂）                 （用得出）
N    ↑                        ↑
N    │    理解深度           │
N    │    在于从左           │
N    │    向右移动           │
N    └────────────────────┘
N
N深度理解 = 能否从左向右迁移
N```
N
N#### 1.6.5 四象限理解模型
N
N| | **高语境化** | **低语境化** |
N|--|-----------|-----------|
N| **高迁移** | **象限IV：深度内化** 能从未见过的新语境中正确使用 | **象限III：机械记忆** 知道意思但无法迁移 |
N| **低迁移** | **象限II：语境理解** 在真实情境中理解含义 | **象限I：浮光掠影** 偶遇后模糊感知 |
N
N**产品设计目标**：让用户从象限I→II→III→IV螺旋上升，而非停留在I/III。

N## 第三章 学习路径设计
N
N### 3.1 三维整合模型
N
N理解一个词需要同时在三个维度上建立认知：
N
N| 维度 | 核心问题 | 学习内容 |
N|------|---------|---------|
N| **形式之维** | 这个词长什么样/怎么发音？ | 发音→音标→音素→拼读规则→词素分解 |
N| **意义之维** | 这个词描述了什么场景？ | 原型场景→多义派生链→隐喻映射网络 |
N| **使用之维** | 这个词怎么用才对？ | 搭配约束+句法约束+语体约束+情感约束 |
N
N**三维整合路径：**
N1. 从形式出发（发音+拼写激活形式表征）
N2. 进入意义（原型场景激活语义网络）
N3. 固化为使用（搭配+语体+情感的多维使用约束）
N
N### 3.2 L1-L5深度加工路径
N
N每进入更深一层，记忆留存率显著提高（Craik & Tulving, 1975；Laufer & Hulstijn, 2001）：
N
N```
NL1 形式注意 ──→ 浅层加工，留存有限（~15-25%，参考Craik & Tulving 1975）
NL2 形式+意义 ──→ 中层加工，留存有所提升（~40-50%）
NL3 语境搭配 ──→ 深层加工，留存显著提升 ★★★ 分水岭
NL4 使用限制 ──→ 更深层加工
NL5 多义+语体 ──→ 最深层加工（生成性产出，接近70-80%上限）
N```
N
N> **数据说明**：具体百分比数值因研究情境不同差异较大，此处为区间估计值，定性趋势（深度越深留存越高）有充分实证支撑。L1-L5的精确留存率对比尚无大规模二语习得专项研究，产品设计中应以此定性趋势为依据，而非精确数字。
N
N**产品功能设计含义（P4）：**产品必须设计L3及以上的练习题型（搭配选择、语境填空、语体判断、造句），而非仅提供L2的单词卡浏览。
N
N### 3.3 认知路径的四步设计
N
N```
N第一步：建立空间/感知图式
N  → on = 接触面 / in = 容器内部
N  → run = 人在地面快速移动的画面
N
N第二步：空间/感知图式 → 时间/状态隐喻
N  → on Monday / in danger / run a business
N
N第三步：固化搭配与语体约束
N  → depend on / good at / run a business（不是run business）
N  → formal vs informal语体判断
N
N第四步：多义网络的内化与迁移
N  → 能在新语境中自主选择正确义项和语体
N  → FSRS调度保证间隔提取
N```
N

N## 第五章 学习闭环设计
N
N### 5.1 核心学习闭环
N
N产品建立"测评→学习→练习→复习→测评"的完整学习闭环，每个环节均以上篇设计原则为依据：
N
N```
N         ┌─────────────────────────────┐
N         │          测评              │
N         │   [VKS自评 + 水平测试]     │
N         │        ↓                  │
N         └──────────┬────────────────┘
N                    ↓
N         ┌─────────────────────────────┐
N         │          学习              │
N         │   [原型场景 + 多维输入]     │ [P1][P2][P5]
N         │        ↓                  │
N         └──────────┬────────────────┘
N                    ↓
N         ┌─────────────────────────────┐
N         │          练习              │
N         │   [L3-L5深度加工练习]      │ [P3][P4][P5]
N         │        ↓                  │
N         └──────────┬────────────────┘
N                    ↓
N         ┌─────────────────────────────┐
N         │          复习              │
N         │   [FSRS间隔调度+主动回忆]   │ [P3][P4]
N         │        ↓                  │
N         └──────────┬────────────────┘
N                    ↓
N              [回到测评阶段]
N```
N
N### 5.2 测评模块
N
N**功能规格：**
N- VKS冷启动：用户首次使用时通过VKS五级自评快速定级（1=没见过→5=会用）；局限性：K-12学生会系统性高估词汇量，结果仅供参考
N- 水平测试：基于CEFR分级词表的能力测试，输出词汇量和CEFR等级报告
N- 阶段复评：FSRS积累30天数据后，触发VKS复评，更新能力画像
N
N**设计依据：**
N- VKS冷启动避免用户从零开始，节省学习时间 `[P3]`
N- 测评结果直接决定初始推荐词表范围 `[P8]`
N
N### 5.3 学习模块
N
N**功能规格：**
N- **原型场景卡**：每个单词展示原型场景图像/动画（适用于具身词），附英文释义，附词源故事（高中段）
N- **适用边界**：功能词、抽象词不适用场景策略，改为框架图或对比示例
N- **多维输入**：发音（英/美双音频）、音标（双版本）、词素分解、搭配示例、语体标注
N- **i+1例句筛选标准（按学段梯度配置）：**
N- 小学段：≥0.95（词汇量有限，严格标准）
N- 初中段：≥0.90（词汇覆盖扩张）
N- 高中段：≥0.85（强调语境推理能力）
N- 辅助指标：语境丰富度（句子是否有足够语境线索支持推断），不单纯依赖词汇覆盖率
N- **学习路径**：按先备关系（P8）拓扑排序，确保先学先备词再学衍生词
N
N**原型场景卡设计规范（P1）：**
N- 适用词类：具体名词、动作动词优先；抽象词（justice/democracy）、功能词（the/of/and）、高频语法词不适用场景策略，改为框架图或对比示例
N- 生产策略：AI辅助生成初稿→人工审核（初中及以上）；专业设计团队制作（小学低年级优先）
N- 产品路线图建议：初期覆盖小学段核心词约500个，中期扩展至初高中核心词约1500个，后期覆盖全部词表
N
N**场景语义学落地（P1）：**
N- 义项展示：按"原型场景→要素替换→延伸义"的路径组织，而非平铺释义
N- 多义词学习：先还原原型场景，再通过动画或图示展示场景要素如何替换
N
N**六维落地（P5）：**
N- 每个单词详情页聚合六个维度的信息：搭配、语法、隐喻、英汉对比、语体、音韵
N- 用户可选择维度深入学习，而非被迫浏览全部维度
N
N### 5.4 练习模块
N
N**功能规格：**
N- **L3练习（识别性）**：搭配选择（给定动词选正确介词；给定形容词选正确搭配）
N- **L3练习（产出性）**：给定场景描述，让用户自行输入正确搭配；L3过关标准：连续N次正确产出
N- **L4练习**：语境选义（给定句子，从多个义项中选正确项）、语体判断（从多个语体中选择正确词）
N- **L5练习**：造句（给定场景描述，用户用目标词造句）、多义连线（图→义项映射）、隐喻连线（物理场景→抽象隐喻句）
N- **AI辅助写作评测框架**：采用三维评分——①搭配准确性（搭配是否规范）；②语体适当性（是否符合当前语体要求）；③句法合法性（句子是否合乎语法）。采用三档反馈（基本准确/接近/需改进），而非二元判定。错误反馈包含解释+正确形式，而非仅标注错误。
N
N**深度加工设计依据（P4）：**
N- 练习模块优先提供L3-L5练习
N- 单词卡浏览（对应L1-L2）作为辅助入口，不作为主要学习路径
N- 每完成一轮练习，系统记录加工深度，优先推送未达L3的词汇
N
N### 5.5 复习模块
N
N**功能规格：**
N- **FSRS调度**：基于可提取性（retrievability）计算下次复习时间，稳定性和难度由首次答题结果自动计算
N- **多种复习类型**：FSRS调度三种复习形式——①提取性复习（展示单词/场景强制主动回忆，适用于form/meaning匹配）；②生成性复习（搭配填空/造句，适用于L3-L5知识）；③多模态复习（听音/看图/跟读，适用于小学低年级）
N- **技能维度**：每个词按form_recognition/spelling/meaning_recall/usage/sound_recognition分技能调度
N
N**FSRS参数配置（按学段）：**
N- 小学1-4年级：**儿童适配模式**，最小复习间隔不低于24小时，避免碎片化；采用半引导回忆（展示首字母或图片提示）；每日复习量设上限（如≤30词）；初始stability=0.05
N- 小学5-6年级：FSRS全功能，最小复习间隔12小时；初始stability=0.08
N- 初中阶段：初始stability=0.1
N- 高中阶段：初始stability=0.15
N
N**设计依据（P3）：**
N- 复习触发时机 = retrievability降至90%以下（FSRS默认目标值，非固定间隔）
N- 主动回忆（recall）比再看一遍（re-reading）留存率高（Craik & Tulving, 1975）——但重读配合语境对巩固语义理解仍有价值，两者组合使用效果更佳
N

N### 6.1 模块总览
N
N| 模块 | 功能定位 | 核心场景 |
N|------|---------|---------|

## 第七章 内容体系设计

### 7.1 词汇内容分层

按学段划分核心词表范围：

| 学段 | 核心词表规模 | 来源 |
|------|------------|------|
| 小学1-2年级 | ~500词 | 课标核心词 |
| 小学3-4年级 | ~1000词 | 课标+拓展 |
| 小学5-6年级 | ~2000词 | 初中衔接 |
| 初中 | ~3500词 | 课标+中考 |
| 高中 | ~5500词 | 课标+高考 |

### 7.2 词义内容的六维标注要求

每个核心词入库时需完成六维标注（搭配、语法、隐喻、英汉对比、语体、音韵）。MVP阶段优先完成搭配和语法两维，其余作为后续迭代内容。

### 7.3 例句的i+1标准

i+1例句筛选标准（按学段梯度配置）：
- 小学段：≥0.95（词汇量有限，严格标准）
- 初中段：≥0.90（词汇覆盖扩张）
- 高中段：≥0.85（强调语境推理能力）
- 辅助指标：语境丰富度，不单纯依赖词汇覆盖率

### 7.4 内容优先级排序

**第一阶段（MVP）：**
- 小学段核心词约500个：原型场景卡+搭配+例句
- FSRS调度基础设施

**第二阶段：**
- 扩展至初高中核心词约1500个
- 隐喻+语体维度

**第三阶段：**
- 覆盖全部词表
- 词源故事（高中约200-300个核心词）
