## 5. API端点汇总

### 5.1 打印管理接口

| 模块 | 接口路径 | 方法 | 说明 |
|------|----------|------|------|
| Printer | `/api/pos/prn/printer` | CRUD | 打印机管理 |
| Queue | `/api/pos/prn/queue` | CRUD | 打印队列管理 |
| Style | `/api/pos/prn/style` | CRUD | 打印样式管理 |
| CustomerSetting | `/api/pos/prn/customer-setting` | CRUD | 顾客联设置 |
| WaiterSetting | `/api/pos/prn/waiter-setting` | CRUD | 传菜联设置 |

### 5.2 打印操作接口

| 模块 | 接口路径 | 方法 | 说明 |
|------|----------|------|------|
| Print | `/api/pos/prn/job/reprint` | POST | 重新打印 |
| Print | `/api/pos/prn/job/batch-reprint` | POST | 批量重打 |
| Print | `/api/pos/prn/job/{lid}` | GET | 查询任务状态 |
| Print | `/api/pos/prn/job/cancel` | POST | 取消任务 |
