## 2. 高频问题

### 2.1 问题1：打印任务创建失败

**错误码**：PRINT_JOB_001

**现象**：
- 调用打印接口返回失败
- 业务日志显示"创建打印任务失败"
- pos_prn_job表无对应记录

**排查步骤**：

```
1. 检查MySQL连接
   └──> mysql -h {host} -P {port} -u {user} -p
       └──> SELECT COUNT(*) FROM pos_prn_job;

2. 检查.jobs目录权限
   └──> ls -la {job-dir}
       └──> 确认目录存在且可写

3. 检查磁盘空间
   └──> df -h
       └──> 确认可用空间充足

4. 查看错误日志
   └──> grep "创建打印任务失败" app.log
       └──> 定位具体异常
```

**根因与解决方案**：

| 根因 | 解决方案 |
|------|----------|
| MySQL连接池满 | 增大连接池配置 |
| .jobs目录不存在 | 创建目录并授权 |
| 磁盘空间不足 | 清理磁盘或迁移目录 |
| 事务超时 | 优化事务或增大超时时间 |

### 2.2 问题2：打印机不打印

**错误码**：PRINT_EXEC_001

**现象**：
- 任务状态一直是PENDING
- 无物理纸张输出
- 打印机指示灯正常

**排查步骤**：

```
1. 检查打印机状态
   └──> GET /api/pos/prn/printer/{lid}
       └──> 确认status=HEALTHY

2. 检查打印机连接
   └──> telnet {ip} {port}
       └──> 确认网络可达

3. 检查打印队列
   └──> 查看Redis: pos_printer:status:{printerLid}
       └──> 确认不是FAULT

4. 检查Worker线程
   └──> /actuator/health
       └──> 确认printWorker=RUNNING
```

**根因与解决方案**：

| 根因 | 解决方案 |
|------|----------|
| 打印机离线 | 检查电源和网络 |
| IP/端口配置错误 | 修改打印机配置 |
| Worker线程阻塞 | 重启应用 |
| 打印驱动异常 | 重启驱动服务 |

---

### 2.3 问题3：打印内容乱码

**错误码**：PRINT_QUALITY_001

**现象**：
- 打印出奇怪字符
- 中文显示为方框或问号
- 金额数字显示异常

**排查步骤**：

```
1. 检查字符编码配置
   └──> 确认应用启动参数: -Dfile.encoding=UTF-8

2. 检查打印机字符集
   └──> 打印机配置 → 字符集 → GBK/UTF-8

3. 检查模板内容
   └──> 数据库: pos_prn_style_row.display_condition
       └──> 确认JSON中的文字编码

4. 检查驱动配置
   └──> EscPosRenderService中配置的CHARSET
```

**根因与解决方案**：

| 根因 | 解决方案 |
|------|----------|
| 应用编码非UTF-8 | 设置-Dfile.encoding=UTF-8 |
| 打印机编码不匹配 | 调整打印机字符集 |
| 模板JSON编码错误 | 重新导入模板 |
| 驱动编码配置错误 | 修改Driver实现 |

### 2.4 问题4：云打印失败

**错误码**：PRINT_CLOUD_001

**现象**：
- 云打印机无响应
- 任务状态显示失败
- failure_reason包含"云服务"关键字

**排查步骤**：

```
1. 检查云平台状态
   └──> 访问芯烨/佳博开发者平台
       └──> 确认API可用

2. 检查设备绑定
   └──> 确认打印机SN和KEY正确
       └──> 确认设备在线

3. 检查网络连通性
   └──> curl -v https://api.xyprint.com
       └──> 确认能访问云平台

4. 检查回调配置
   └──> 确认回调地址可达
       └──> 确认回调接口正常
```

**根因与解决方案**：

| 根因 | 解决方案 |
|------|----------|
| SN/KEY错误 | 核对并修改配置 |
| 设备离线 | 检查设备网络 |
| 云平台故障 | 等待恢复或切换备机 |
| 回调地址不通 | 检查防火墙和白名单 |

---

### 2.5 问题5：打印速度慢

**错误码**：PRINT_PERF_001

**现象**：
- 任务从创建到完成超过5秒
- 高峰期任务堆积
- Worker线程持续繁忙

**排查步骤**：

```
1. 检查任务排队情况
   └──> /actuator/health
       └──> 查看queueSize

2. 检查Worker线程数
   └──> 配置: pos.print.worker-pool-size
       └──> 确认线程数合理

3. 检查打印机响应时间
   └──> 分别测试不同类型打印机
       └──> 对比响应时间

4. 检查网络延迟
   └──> ping {printer-ip}
       └──> 确认网络延迟<5ms
```

**根因与解决方案**：

| 根因 | 解决方案 |
|------|----------|
| Worker线程不足 | 增大worker-pool-size |
| 串口打印机串行 | 减少串口打印机数量 |
| 网络延迟高 | 检查网络质量 |
| 云打印API慢 | 增大超时或换服务商 |

## 6. 应急处理

### 6.1 紧急止血

| 场景 | 紧急处理 | 后续动作 |
|------|----------|----------|
| 大量打印失败 | 切换到本地队列 | 排查云打印服务 |
| 磁盘空间不足 | 清理.del文件 | 迁移目录或扩容 |
| Worker线程卡死 | 重启应用 | 分析卡死原因 |
| 数据库连接满 | 重启应用 | 优化SQL或扩容 |

### 6.2 手动恢复

```bash
# 1. 停止应用
./stop.sh

# 2. 备份.jobs目录
cp -r jobs jobs.bak.$(date +%Y%m%d)

# 3. 清理.del文件
find jobs -name "*.del" -delete

# 4. 重启应用
./start.sh

# 5. 检查恢复情况
curl http://localhost:8080/actuator/health
```
