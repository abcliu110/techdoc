## 2. nms4pos 内部模块依赖

### 2.1 模块依赖树

```
nms4pos-pos (打印主模块)
├── nms4pos-common            # 公共工具类
├── nms4pos-dwd               # 业务实体 (DwdBill, DwdFood, DwdPay)
├── nms4pos-pt                # 基础数据 (PtTbl, PtTblArea, PtTblType)
├── nms4pos-device            # 设备管理 (PosDev)
├── nms4pos-checkout          # 结账服务
└── nms4pos-printer-driver-*  # 打印机驱动插件
```

### 2.2 核心依赖

| 依赖模块 | 依赖内容 | 说明 |
|----------|----------|------|
| nms4pos-dwd | DwdBill, DwdFood, DwdPay | 打印内容数据源 |
| nms4pos-pt | PtTbl, PtTblArea, PtTblType | 队列匹配维度 |
| nms4pos-device | PosDev | PC设备关联 |
| nms4pos-common | SnowflakeIdGenerator | 雪花ID生成 |
| nms4pos-common | JetCache | 缓存注解 |

## 8. 依赖冲突风险

### 8.1 版本不一致风险

| 风险项 | 影响 | 规避措施 |
|--------|------|----------|
| MyBatis版本差异 | SQL执行差异 | 统一依赖管理 |
| Jackson版本差异 | JSON序列化不一致 | 统一starter管理 |
| 枚举值不一致 | 打印类型解析错误 | 共享枚举模块 |

### 8.2 依赖传递风险

```
nms4pos-pos
    │
    ├──> nms4pos-dwd (业务实体)
    │       │
    │       └──> nms4pos-common
    │
    └──> nms4pos-printer-driver-net
            │
            └──> 第三方网络库
```

**风险**：第三方库可能引入不兼容版本
**规避**：驱动模块使用provided依赖

## 9. 部署依赖

### 9.1 启动顺序

```
1. MySQL (打印配置表)
2. Redis (状态缓存)
3. nms4cloud (基础服务)
4. nms4pos (打印执行)
```

### 9.2 健康检查依赖

| 组件 | 检查项 | 失败影响 |
|------|--------|----------|
| MySQL | 连接可用 | 无法创建/查询任务 |
| Redis | 连接可用 | 打印计数失效、状态缓存失效 |
| 打印机 | TCP连接 | NET打印失败 |
