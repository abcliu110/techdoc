## 5. 跨模块边界

### 5.1 模块边界定义

| 边界 | 左侧模块 | 右侧模块 | 交互方式 |
|------|----------|----------|----------|
| 业务→打印 | DwdFoodOpsService | PrintJobGenerator | 方法调用 |
| 打印→持久化 | PrintJobGenerator | PosPrnJobServicePlus | 方法调用 |
| 队列→Worker | PosPrnQueueServicePlus | PrinterWorkerService | 线程池提交 |
| Worker→驱动 | PrinterWorker | PrinterDriverManager | 接口调用 |

### 5.2 接口契约

```
PrintJobGenerator.generateKitchenJob(foods, billInfo)
        │
        ├── 输入: List<DwdFood>, BillInfoDTO
        ├── 处理: 创建打印任务，渲染内容
        └── 输出: List<Long> (任务lid列表)

PosPrnJobServicePlus.create(jobCreateDTO)
        │
        ├── 输入: PosPrnJobCreateDTO
        ├── 处理: DB插入 + .job文件写入
        └── 输出: Long (任务lid)

PosPrnQueueServicePlus.dispatchJob(jobLid)
        │
        ├── 输入: Long (任务lid)
        ├── 处理: 选择打印机，分发任务
        └── 输出: void
```

### 6.2 异步任务

| 任务 | 提交方 | 执行方 | 说明 |

| initJob | PrintUtil | JobTaskHandle | 内容初始化 |

## 7. 异常传播关系

```
PrinterDriver.print() 失败
        │
        ├──> PrinterWorker.handleError()
        │           │
        │           ├──> 更新状态为FAILED
        │           ├──> 记录failureReason
        │           └──> 触发PrinterWorkerService重试
        │
        └──> PrinterWorkerService.addPrinterStatus(FAULT)
                    │
                    └──> PosPrnQueueServicePlus 选择备打印机
```
