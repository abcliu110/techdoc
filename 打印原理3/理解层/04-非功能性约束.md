# 04-非功能性约束：打印功能质量属性

> **分析范围**：打印功能
> **版本**：v1.0
> **日期**：2026-08-03

---

## 1. 性能约束

### 1.1 响应时间约束

| 操作 | SLA | 说明 |
|------|-----|------|
| 打印任务创建 | ≤100ms | 从调用到DB+文件写入完成 |
| 内容初始化 | ≤200ms | 模板加载+数据渲染 |
| 任务分发 | ≤50ms | 选择打印机+提交Worker |
| 本地打印(NET) | ≤500ms | 从提交到打印完成 |
| 串口打印 | ≤1s | 考虑串口波特率限制 |
| 云打印 | ≤3s | HTTP API + 第三方处理 |

### 1.2 吞吐量约束

| 场景 | 目标QPS | 说明 |
|------|---------|------|
| 点菜打印 | ≥50/s | 高峰并发 |
| 结账打印 | ≥20/s | 结账操作 |
| 总体吞吐 | ≥100/min | 单店持续打印能力 |

### 1.3 资源约束

| 资源 | 约束 | 说明 |
|------|------|------|
| CPU | Worker线程池 ≤5 | 避免过度占用 |
| 内存 | .job文件队列 ≤1000 | 控制内存队列大小 |
| 磁盘 | .job目录 ≤1GB | 超过触发告警 |
| 网络 | TCP连接池 ≤20 | 避免端口耗尽 |

## 2. 可用性约束

### 2.1 可用性指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | ≥99.5% | 全年停机 ≤43.8小时 |
| 打印成功率 | ≥99% | 成功/总任务 |
| 故障恢复时间 | ≤2min | 从故障到自动恢复 |

### 2.2 容错能力

| 故障场景 | 处理方式 | 恢复时间 |
|----------|----------|----------|
| 单打印机故障 | 自动切换备机 | <10s |
| 多打印机故障 | 延迟重试45分钟 | 45min内持续重试 |
| 网络中断(云打印) | 本地缓存+重试 | 网络恢复后 |
| 进程重启 | .job文件恢复 | 启动后自动扫描 |

### 2.3 降级策略

| 降级条件 | 降级动作 | 影响 |
|----------|----------|------|
| Worker线程满 | 任务排队 | 打印延迟增加 |
| Redis不可用 | 禁用计数/缓存 | 不影响核心打印 |
| 云打印超时 | 降级为本地打印 | 需配置本地队列 |

## 3. 可靠性约束

### 3.1 数据可靠性

| 数据 | 持久化方式 | 可靠性保证 |
|------|------------|------------|
| 打印任务 | MySQL + .job文件 | 双写保证 |
| 打印计数 | Redis + 定期同步DB | 异步同步 |
| 打印机状态 | Redis + 内存 | 内存优先 |

### 3.2 幂等性约束

| 操作 | 幂等方式 | 说明 |
|------|----------|------|
| 任务创建 | bizBillId + type防重 | 同一单据同一类型只创建一次 |
| 重打 | 创建新任务 | 保持原任务记录 |
| 取消 | 标记deleted | 软删除 |

### 3.3 故障恢复

```
故障检测 → 状态标记 → 备机切换 → 重试执行
    │           │           │           │
    ▼           ▼           ▼           ▼
 PrinterWorker  Redis    队列分发    新Worker
```

## 6. 可扩展性约束

### 6.1 新增打印机类型

```
扩展点: PrinterDriver接口
        │
        ├──> NetPrinterDriver (已实现)
        ├──> ComPrinterDriver (已实现)
        ├──> UsbPrinterDriver (已实现)
        ├──> CloudPrinterDriver (已实现)
        │
        └──> NewPrinterDriver (扩展)
                │
                └──> 实现print(byte[])方法即可

### 6.2 新增打印票据类型

```
步骤:
1. 在PrnStyleTypeEnum添加类型
2. 在pos_prn_style_row配置模板
3. 在PrintJobGenerator添加generateXxx()方法
