## 1. 分析对象定位

### 1.1 业务位置

打印功能属于 **POS 系统的核心业务能力**，服务于餐饮/零售门店的收银结账场景。

### 1.2 功能类型

| 能力 | 说明 |
|---|---|
| 核心业务能力 | 打印小票、厨房票、结账单据 |
| 支撑业务能力 | 打印样式配置、打印机管理 |
| 平台能力 | 打印队列管理、重打印机制 |

---

## 2. 业务结果族全景

### 2.1 打印类型

| 打印类型 | 触发场景 | 接收角色 |
|---|---|---|
| 顾客小票 | 结账完成后 | 顾客 |
| 厨房打印 | 点单/加菜时 | 后厨 |
| 结账单 | 交接班时 | 收银员/店长 |
| 电子发票 | 开票请求 | 顾客/税务系统 |
| 外卖小票 | 接单时 | 后厨/打包员 |

### 2.2 打印配置

| 配置项 | 说明 |
|---|---|
| 打印机管理 | 添加/配置/启用/禁用打印机 |
| 打印模板 | 行样式、列样式、打印项配置 |
| 打印队列 | 队列分配、优先级、切换规则 |
| 部门关联 | 菜品与打印机关联、部门与打印机关联 |
