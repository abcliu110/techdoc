## 五、会员积分计算机制

### 积分计算原理

积分计算基于会员等级的积分倍率进行计算，具体公式如下：

```
实付金额 × 等级积分倍率 = 获得积分
```

### 积分计算业务场景

1. **日常消费场景**：
   - 会员在门店消费时，系统自动计算积分
   - 例如：普通会员消费100元，积分为100×1.0=100积分
   - 银卡会员消费100元，积分为100×1.2=120积分

2. **特殊活动场景**：
   - 节假日活动期间，系统可临时调整积分倍率
   - 例如：春节活动期间，所有会员积分翻倍

### 积分计算实现细节

在系统内部，积分计算通过以下机制实现：

1. **积分规则引擎**：使用积分规则引擎进行计算，支持复杂的积分倍率规则
2. **会员等级配置**：每个会员等级都配置了相应的积分倍率
3. **实时计算**：积分在消费时实时计算并入账
4. **数据持久化**：积分变动记录保存到数据库，支持查询和追溯

### 积分计算流程图

```
会员消费 → 识别会员身份 → 获取会员等级信息 → 获取积分倍率
    ↓
计算积分 = 实付金额 × 积分倍率 → 积分入账 → 更新会员积分余额
```

### 积分计算配置示例

| 会员等级 | 积分倍率 | 消费100元获得积分 | 备注 |
|----------|----------|------------------|------|
| V1 普通   | 1.0倍    | 100积分          | 基准等级 |
| V2 银卡   | 1.2倍    | 120积分          | 常规会员 |
| V3 金卡   | 1.5倍    | 150积分          | 高级会员 |
| V4 钻石   | 2.0倍    | 200积分          | VIP会员 |

### 积分计算代码逻辑

积分计算的核心逻辑位于`com.shouqianba.kaci.scrm.promotion.sdk.member.PointRuleCalr`类中，主要实现步骤：

1. 获取会员等级信息和积分规则
2. 根据消费金额和等级倍率计算积分
3. 处理特殊规则（如生日积分、活动积分等）
4. 返回最终积分计算结果

## 六、储值套餐生命周期管理

### 储值套餐状态管理

储值套餐在整个生命周期中会经历以下状态变化：

1. **创建状态**：套餐创建完成后处于待生效状态
2. **生效状态**：套餐在生效日期后自动变为生效状态
3. **停用状态**：套餐在结束日期后自动变为停用状态
4. **删除状态**：管理员手动删除套餐后进入删除状态

### 状态转换业务场景

1. **自动生效场景**：
   - 活动开始当天，系统自动将待生效套餐设为生效状态
   - 适用于促销活动、节假日特惠等场景

2. **自动停用场景**：
   - 活动结束后，系统自动将生效套餐设为停用状态
   - 适用于限时促销、季节性活动等场景

### 生命周期管理策略

#### 1. 自动化管理
- 系统定时任务每小时检查一次所有套餐状态
- 套餐创建/修改时即时验证状态
- 系统启动时批量检查所有套餐状态

#### 2. 人工干预
- 管理员可手动将停用套餐重新启用
- 管理员可手动删除已过期套餐
- 管理员可设置套餐的生效时间

### 生命周期管理数据支撑

| 状态 | 状态码 | 说明 | 业务影响 |
|------|--------|------|----------|
| 待生效 | 0 | 套餐创建后初始状态 | 无法购买 |
| 生效中 | 1 | 已到生效时间 | 可正常购买 |
| 已停用 | 2 | 已到结束时间 | 不可购买 |
| 已删除 | 3 | 已被手动删除 | 无法恢复 |

## 七、会员等级升降级机制

### 等级升降级触发条件

会员等级的升降级完全由系统自动触发，基于以下条件：

#### 升级条件
1. **成长值达标**：会员消费产生的成长值达到下一等级的门槛
2. **自动升级**：系统在会员消费时实时计算并判定升级
3. **即时生效**：升级后立即生效，不影响当前交易

#### 降级条件
1. **降级周期**：按照预设的降级周期（如自然年/滚动周年）进行核算
2. **成长值不足**：在降级周期结束时，会员的成长值低于当前等级门槛
3. **自动降级**：系统自动执行降级操作

### 升降级业务场景

1. **升级场景**：
   - 会员消费金额达到升级门槛
   - 会员在活动期间消费获得额外成长值
   - 会员参与积分活动获得成长值

2. **降级场景**：
   - 会员在一年内未产生消费
   - 会员在降级周期内成长值未达标
   - 会员等级调整策略变更

### 等级升降级监控指标

| 监控指标 | 目标值 | 说明 |
|----------|--------|------|
| 升级成功率 | ≥95% | 系统正确识别升级条件 |
| 降级准确率 | ≥90% | 系统正确识别降级条件 |
| 升降级及时性 | ≤5分钟 | 等级变更通知及时性 |
| 用户满意度 | ≥85% | 用户对等级变更的满意度 |
