# 02-典型故事

## 故事1：结账单打印的完整旅程

### 背景
顾客在前台完成结账，需要打印一张结账单小票。

### 用户视角
1. 收银员点击"结账"按钮
2. 系统处理结账逻辑
3. 小票打印机"嗞嗞嗞"打印出结账单
4. 顾客拿走小票离开

### 系统视角

```
┌─────────────────────────────────────────────────────────────────┐
│ Step 1: 结账完成，业务系统创建打印任务                            │
├─────────────────────────────────────────────────────────────────┤
│ 业务系统                                                        │
│     │                                                          │
│     ├─ 创建 PosPrnJob                                          │
│     │     type = CheckOut                                       │
│     │     bizBillId = order_12345                              │
│     │     prnQueueLid = 收银台队列_001                         │
│     │     purpose = FOR_CUSTOMER (楼面联)                       │
│     │                                                          │
│     └─ 发送MQ消息到 ActiveMQ 主题                               │
│           topic = pos_prn_job                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 2: MQ监听器接收消息，初始化任务                            │
├─────────────────────────────────────────────────────────────────┤
│ PrintJobActiveMQListener.onMessage()                            │
│     │                                                          │
│     ├─ 创建 PosPrnJob 记录到 MySQL                             │
│     │                                                          │
│     └─ 调用 initJob(jobLid)                                    │
│           │                                                    │
│           ├─ 从Redis加载任务数据                               │
│           │                                                    │
│           ├─ 加载打印样式模板                                   │
│           │     styleType = CheckOut                           │
│           │     ├─ Row 1: 门店名称 (居中/大字)                │
│           │     ├─ Row 2: 日期时间 (居中/小字)                │
│           │     ├─ Row 3: 分隔线                              │
│           │     ├─ Row 4: 菜品明细 (左对齐)                    │
│           │     ├─ Row 5: 分隔线                              │
│           │     ├─ Row 6: 合计金额 (居中/大字)                │
│           │     ├─ Row 7: 支付方式                            │
│           │     └─ Row 8: 二维码                               │
│           │                                                    │
│           ├─ 填充数据源                                         │
│           │     ${门店名称} → "XX餐厅"                         │
│           │     ${日期时间} → "2024-01-15 14:30:25"            │
│           │     ${菜品明细} → "宫保鸡丁 x1  28.00"             │
│           │     ...                                            │
│           │                                                    │
│           └─ 保存到Redis                                       │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 3: 任务分发器选择打印机                                    │
├─────────────────────────────────────────────────────────────────┤
│ PrintDispatchMpScHandler                                         │
│     │                                                          │
│     ├─ 根据 prnQueueLid 获取 PosPrnQueue                       │
│     │     name = "收银台队列_001"                               │
│     │     primaryPrinter = "101,102"  (逗号分隔)                │
│     │     standbyPrinter = "103"                               │
│     │                                                          │
│     ├─ 解析主打印机列表                                         │
│     │     Set<Long> = {101, 102}                               │
│     │                                                          │
│     ├─ 查询打印机状态                                           │
│     │     Printer 101: NORMAL (健康)                           │
│     │     Printer 102: FAULT (故障)                            │
│     │                                                          │
│     ├─ 过滤故障打印机                                           │
│     │     List<Pair<Long>> = {(101, 1)}                        │
│     │                                                          │
│     ├─ 随机负载均衡选择                                         │
│     │     selected = Printer 101                               │
│     │                                                          │
│     └─ 调用 PrintUtil.handle(dispatchJob)                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 4: PrinterWorker执行打印                                    │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker (Printer=101, Type=OPOS_NET)                      │
│     │                                                          │
│     ├─ 检查打印机状态                                           │

│     ├─ 渲染打印内容                                            │

│     │     │     {type=Text, content="2024-01-15 14:30", ...}, │
│     │     │     {type=Line, ...},                             │
│     │     │     {type=Text, content="宫保鸡丁 x1  28.00",...}, │
│     │     │     ...                                            │
│     │     │     {type=QRCode, content="支付链接", ...}         │
│     │     │   ]                                                │
│     │     │                                                    │
│     │     └─ printCount = 1                                   │
│     │                                                          │
│     ├─ 调用 PortHandler.handle(Prn_PrintJob)                   │
│     │     │                                                    │
│     │     ├─ 建立TCP连接到打印机 (192.168.1.101:9100)        │
│     │     │                                                    │
│     │     ├─ 发送ESC/POS指令                                  │
│     │     │     ESC @ (初始化)                                 │
│     │     │     ESC a 1 (居中)                                 │
│     │     │     GS ! 11 (大字号)                               │
│     │     │     "XX餐厅" + LF                                  │
│     │     │     ...                                            │
│     │     │     GS v 0 (切纸)                                  │
│     │     │                                                    │
│     │     └─ 关闭连接                                          │
│     │                                                          │
│     └─ 返回 true (打印成功)                                     │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ Step 5: 任务归档                                               │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker                                                   │
│     │                                                          │
│     └─ handle() 返回 true                                       │
│           │                                                    │
│           ├─ PosPrnJobServicePlus.removeFromFile()             │
│           │     从Redis删除任务数据                             │
│           │                                                    │
│           └─ PosPrnJob.print = true                           │
│                 更新MySQL，标记为已打印                          │
└─────────────────────────────────────────────────────────────────┘
```

### 完成时间
- 理想情况：< 1秒
- 包含网络打印延迟：< 3秒

## 故事2：打印机故障的惊魂一刻

### 背景
后厨打印机突然故障，但餐厅还在营业。

### 用户视角
1. 服务员点击"打印催菜单"
2. 催菜单"意外"地在另一台打印机上打印出来了
3. 厨师正常收到了催菜单
4. 收银系统显示"打印机A故障，已切换到打印机B"

### 系统视角

```
┌─────────────────────────────────────────────────────────────────┐
│ 故障检测                                                        │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker (Printer=201, 后厨打印机A)                         │
│     │                                                          │
│     ├─ getStatus() 轮询检查                                     │
│     │                                                          │
│     └─ 发现打印机返回 FAULT 状态                                │
│           │                                                    │
│           ├─ log.error("打印机【后厨A】处于故障状态")           │
│           │                                                    │
│           └─ redirect() 重定向任务                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 任务重定向                                                      │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker.redirect()                                        │
│     │                                                          │
│     ├─ 获取队列中的Pending任务                                   │
│     │     dispatchJobList = [催菜单_001, 点菜单_002, ...]       │
│     │                                                          │
│     ├─ 查询转发规则                                             │
│     │     PosPrnPrinterTransfer                                 │
│     │       sourcePrinterLid = 201 (后厨A)                     │
│     │       targetPrinterLid = 202 (后厨B)                     │
│     │                                                          │
│     ├─ 验证目标打印机状态                                       │
│     │     Printer 202: NORMAL ✓                                │
│     │                                                          │
│     ├─ 重新分发任务                                            │
│     │     PrintUtil.dispatchJob(催菜单_001)                    │
│     │     → 分发到 Printer 202 (后厨B)                        │
│     │                                                          │
│     └─ 移除原队列中的任务                                       │
│           it.remove()                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 备用打印机接收任务                                              │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker (Printer=202, 后厨打印机B)                        │
│     │                                                          │
│     ├─ 接收到催菜单_001                                         │
│     │                                                          │
│     ├─ 正常处理并打印                                           │
│     │                                                          │
│     └─ 返回 true                                               │
│           │                                                    │
│           └─ 归档任务                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 运维通知                                                        │
├─────────────────────────────────────────────────────────────────┤
│ 系统日志 (可能被监控系统采集)                                    │
│     │                                                          │
│     ├─ ERROR: 打印机【后厨A】处于故障状态                       │
│     │                                                          │
│     └─ ERROR: 打印机【后厨A】重新分发打印任务                   │
│                                                                  │
│ 可能的告警渠道                                                   │
│     ├─ 企业微信/钉钉通知                                        │
│     ├─ 短信通知                                                 │
│     └─ 邮件通知                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 业务影响
- **零中断**：顾客和厨师无感知
- **日志记录**：便于事后复盘
- **需要人工**：故障打印机需要运维人员修复

## 故事3：云打印的跨地域奇迹

### 背景
连锁店总部需要统一打印各门店的小票，但门店打印机不在身边。

### 用户视角
1. 门店A完成结账
2. 小票从云端打印出来了
3. 顾客拿走小票（和本地打印无异）

### 系统视角

```
┌─────────────────────────────────────────────────────────────────┐
│ 云打印流程                                                       │
├─────────────────────────────────────────────────────────────────┤
│ 业务系统 (门店A)                                                 │
│     │                                                          │
│     ├─ 创建打印任务                                             │
│     │     prnQueueLid = 云打印队列                             │
│     │                                                          │
│     └─ 正常分发流程                                             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PrinterWorker (Printer=云打印机001, Type=XY_CLOUD)              │
├─────────────────────────────────────────────────────────────────┤
│     │                                                          │
│     ├─ handler = XpCloudPrinter                                │
│     │                                                          │
│     └─ handle(Prn_PrintJob)                                   │
│           │                                                    │
│           ├─ 渲染打印内容为位图                                 │
│           │     Bitmap = render(Prn_PrintJob)                  │
│           │     width = 80mm                                   │
│           │     height = 动态计算                               │
│           │                                                          │
│           ├─ 调用芯燚云API                                       │
│           │     POST https://open.xinyi.com/api/print          │
│           │     {                                                │
│           │       "device_no": "XY_001",                        │
│           │       "content": base64(Bitmap),                    │
│           │       "copies": 1                                   │
│           │     }                                                │
│           │                                                          │
│           ├─ 等待云端返回                                       │
│           │     {                                                │
│           │       "code": 0,                                    │
│           │       "msg": "success"                               │
│           │     }                                                │
│           │                                                          │
│           └─ 返回 true                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 芯燚云服务端                                                    │
├─────────────────────────────────────────────────────────────────┤
│     │                                                          │
│     ├─ 接收打印请求                                             │
│     │                                                          │
│     ├─ 查找设备                                                 │
│     │     device_no = XY_001 → 绑定的门店打印机                 │
│     │                                                          │
│     ├─ 转发到门店打印机                                         │
│     │                                                          │
│     └─ 返回结果                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 技术优势
- **无需本地部署**：不依赖门店本地打印机
- **统一管理**：总部可查看所有打印记录
- **跨地域**：支持异地打印

### 潜在问题
- **网络依赖**：断网则无法打印
- **延迟增加**：比本地打印多一次网络通信
- **成本**：云服务商可能收费

## 故事4：标签打印的特殊待遇

### 背景
奶茶店需要打印食品标签，贴在杯子上。

### 用户视角
1. 员工点击"打印标签"
2. 标签打印机"咔咔咔"打印出一张标签贴纸
3. 员工把标签贴在奶茶杯上

### 系统视角

```
┌─────────────────────────────────────────────────────────────────┐
│ 标签打印流程                                                     │
├─────────────────────────────────────────────────────────────────┤
│ 业务系统                                                        │
│     │                                                          │
│     ├─ 创建打印任务                                             │
│     │     type = FoodLabel                                      │
│     │     prnQueueLid = 标签打印队列                            │
│     │                                                          │
│     └─ 发送MQ消息                                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PrinterWorker (Printer=标签机, Type=NET, Model=GP_3150TFN)      │
├─────────────────────────────────────────────────────────────────┤
│     │                                                          │
│     ├─ handler = JBTagPrinter (特殊处理器)                     │
│     │                                                          │
│     └─ handle(Prn_PrintJob)                                   │
│           │                                                    │
│           ├─ 加载标签模板                                       │
│           │     标签尺寸: 40mm × 30mm                         │
│           │     ├─ 品名 (大字居中)                             │
│           │     ├─ 规格 (小字)                                 │
│           │     ├─ 日期 (条形码)                               │
│           │     └─ 二维码 (追溯信息)                           │
│           │                                                          │
│           ├─ 渲染为标签格式                                     │
│           │     特殊指令: GS v 0 (标签模式)                     │
│           │                                                          │
│           ├─ 发送到底层驱动                                     │
│           │     通过OPOS协议或专用驱动                           │
│           │                                                          │
│           └─ 切纸                                               │
│                 自动切刀切断标签                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 与普通票据的区别

| 特性 | 普通票据 | 标签打印 |
|---|---|---|
| 纸张 | 热敏纸 (80mm宽) | 标签纸 (40x30mm) |
| 打印机 | 热敏小票机 | 标签打印机 |
| 处理器 | PortHandler | JBTagPrinter/XYTagPrinter |
| 切纸 | 全切 | 定位切 |
| 内容 | 文本为主 | 含条形码/二维码 |

## 故事5：深夜的补打请求

### 背景
顾客结账后发现自己需要再要一张小票，服务员帮他补打。

### 用户视角
1. 服务员点击"补打小票"
2. 系统识别这是补打
3. 打印出小票（带红色提示：此单为补打单）
4. 顾客拿走小票

### 系统视角

```
┌─────────────────────────────────────────────────────────────────┐
│ 补打流程                                                        │
├─────────────────────────────────────────────────────────────────┤
│ 业务系统                                                        │
│     │                                                          │
│     ├─ 查询原打印任务                                           │
│     │     PosPrnJob                                            │
│     │       bizBillId = order_12345                            │
│     │       prnCount = 1  (之前已打印1次)                       │
│     │                                                          │
│     ├─ 创建补打任务                                             │
│     │     PosPrnJob                                            │
│     │       bizBillId = order_12345                             │
│     │       prnCount = 2  (本次为第2次打印)                     │
│     │       type = OldBill  (重打票据类型)                     │
│     │                                                          │
│     └─ 发送MQ消息                                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PrinterWorker 渲染补打内容                                      │
├─────────────────────────────────────────────────────────────────┤
│ PrinterWorker.buildPrintJob()                                  │
│     │                                                          │
│     ├─ 检测 prnCount > 0                                        │
│     │                                                          │
│     ├─ 正常渲染内容                                            │
│     │     (与正常打印相同)                                      │
│     │                                                          │
│     └─ 追加补打提示行                                          │
│           │                                                    │
│           Prn_PrintJobItem                                     │
│           │                                                    │
│           ├─ contentType = Text                                 │
│           ├─ fontColor = Red (红色!)                            │
│           ├─ bold = true                                       │
│           ├─ content = "注：此单为补打单，如果之前已经收到过，可以忽略"│

│           └─ align = LEFT                                      │

                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 打印输出                                                        │
├─────────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────────┐    │
│ │                     XX餐厅                               │    │
│ │                  2024-01-15 14:30                       │    │
│ │  ─────────────────────────────────────────────────────  │    │
│ │  宫保鸡丁                                    28.00      │    │
│ │  青椒肉丝                                    32.00      │    │
│ │  米饭 x2                                     4.00      │    │
│ │  ─────────────────────────────────────────────────────  │    │
│ │                   合计: 64.00                           │    │
│ │  ─────────────────────────────────────────────────────  │    │
│ │              [支付二维码]                               │    │
│ │  ─────────────────────────────────────────────────────  │    │
│ │  注：此单为补打单，如果之前已经收到过，可以忽略  ←红色!   │    │
│ └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```
