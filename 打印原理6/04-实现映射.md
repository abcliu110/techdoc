## 一、仓库与模块映射

## 五、流程实现映射

### 5.1 任务创建流程

```
业务系统
    ↓ 发送MQ消息
PrintJobActiveMQListener.onMessage()
    ↓
PosPrnJobMapper.insert()
    ↓
PosPrnJobServicePlus.keepToFile() → Redis
```

### 5.2 任务初始化流程

```
PrintJobActiveMQListener.initJob(jobLid)
    ↓
PrintInitMpScHandler.put(jobLid) → 内存队列
    ↓
PosPrnQueueServicePlus.initJob()
    ├── getFromFile() → 从Redis加载
    ├── get(styleType) → 加载样式模板
    ├── PrintJobInitUtil.convert() → 数据填充
    └── keepToFile() → 重新保存
    ↓
PrintUtil.dispatchJob()
```

### 5.3 任务分发流程

```
PrintDispatchMpScHandler.put(dispatchJob)
    ↓
PosPrnQueueServicePlus.dispatchJob()
    ├── get(queueLid) → 获取队列
    ├── parsePrimaryPrinters() → 解析主打印机
    ├── resolveTargets() → 应用转发规则
    ├── selectHealthyPrinters() → 过滤故障
    ├── RandomLoadBalanceUtil.random() → 负载均衡
    └── PrintUtil.handle() → 提交到打印机
```

### 5.4 打印执行流程

```
PrinterWorker.run() (虚拟线程)
    ├── getStatus() → 检查状态
    │   ├── FAULT → redirect() → 重发
    │   └── NORMAL → 继续
    ├── getFromFile() → 加载任务
    ├── handlePrintJob() → 渲染内容
    │   ├── 遍历rows
    │   ├── 遍历cols
    │   ├── 条件判断
    │   └── 补打提示
    └── handler.handle() → 执行打印
        ├── GraphicsHandler
        ├── PortHandler
        ├── XpCloudPrinter
        └── JBCloudPrinter
```
