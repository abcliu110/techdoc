# 00-十分钟读懂打印模块

## 一句话定义

打印模块负责将业务单据（点菜单/结账单等）可靠地打印到物理打印机或云打印服务，支持主备冗余和故障自动切换。

## 核心架构

```
业务系统 → MQ消息 → 打印任务 → 分发器 → 打印机Worker → 物理打印机/云API
                        ↑
                   打印队列（主备打印机）
```

## 三个关键概念

| 概念 | 作用 | 类比 |
|---|---|---|
| **打印队列** | 定义哪些打印机可以打印哪种票据 | 路由表 |
| **打印任务** | 一次打印请求，包含内容和上下文 | 快递包裹 |
| **打印机** | 实际执行打印的设备 | 快递员 |

## 四个核心能力

1. **主备切换**：主打印机故障自动切换到备用打印机
2. **故障重定向**：可配置源打印机→目标打印机的映射规则
3. **超时重试**：打印机不可用时自动等待重试（2秒间隔）
4. **云打印支持**：支持芯燚云、精打云等云打印服务

## 五类打印机

| 类型 | 协议 | 场景 |
|---|---|---|
| `NET` | 网口 | 局域网打印机 |
| `COM` | 串口 | 老式收银机 |
| `USB` | USB | 即插即用 |
| `Driver` | Windows驱动 | 通用打印机 |
| `Cloud` | HTTP API | 云打印服务 |

## 六步打印流程

1. **创建**：业务系统发送MQ消息，创建打印任务记录
2. **初始化**：加载打印样式模板，填充数据源
3. **分发**：根据打印队列选择健康的打印机
4. **执行**：PrinterWorker渲染内容并调用驱动/API
5. **反馈**：成功则删除任务，失败则重试
6. **归档**：30天后自动清理历史任务

## 七大打印类型家族

| 家族 | 典型票据 | 数量 |
|---|---|---|
| 前台票据 | 点菜单/结账单/总单 | ~25种 |
| 厨房票据 | 催菜单/退菜单/起菜单 | ~10种 |
| 报表票据 | 交班单/营业报表/销售报表 | ~10种 |
| 会员票据 | 充值/消费/发卡明细 | ~15种 |
| 仓储票据 | 采购/销售/盘点单 | ~50种 |
| 云打印 | 标签/小票 | 2种 |
| 辅助票据 | 钱箱弹出/短信通知 | ~10种 |

---

**一句话总结**：打印模块是一个基于内存队列的可靠打印分发系统，通过主备冗余和故障重定向保证打印的可用性。
