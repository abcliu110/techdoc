组件库级治理：从实验到退役

“通过测试”只获得候选资格；稳定发布还必须经过真实消费验证、可回滚验证和版本兼容审查。

ExperimentalAPI 可变；不得进入关键生产流程；必须显式导入实验入口。
Alpha契约成形；内部演示与失败注入完成；不承诺升级兼容。
Beta代表性项目试用；兼容策略启用；收集运行证据和迁移成本。
Stable认证通过、责任人明确、支持矩阵与回滚完成；遵守语义化版本。
Deprecated保留运行能力；提供替代 API、迁移文档、开发期告警和截止版本。
Retired只能在已公告的主版本删除；提供 codemod 或可执行迁移清单。

版本与兼容规则

Patch缺陷修复，不改变公开类型、DOM 语义、焦点顺序、默认行为或视觉尺寸契约。
Minor向后兼容的新能力；默认关闭或不改变旧用法；必须附迁移影响报告。
Major允许破坏性修改，但必须完成弃用周期、消费方扫描、迁移工具和回滚方案。
0.x 阶段每次发布仍按破坏性变更显式标记；不得用“未到 1.0”规避兼容说明。
双包联动`tokens` 与 `ui` 独立发布但记录兼容矩阵；不允许隐式要求未声明的令牌版本。

稳定版晋级时钟

候选产物锁定源码、依赖、证据和产物哈希。
预发布安装到隔离样例与代表性消费项目。
观察窗R1 可短窗；R2 至少一个真实迭代；R3 完成灰度及回滚演练。
晋级只提升同一不可变产物，不重新构建。
维度稳定发布硬条件违反后的动作
正确性强制测试与契约映射全部通过；无未解释回归。阻断或撤回版本。
无障碍WCAG 2.2 AA 范围内零严重/高危；关键路径人工复核通过。阻断晋级；已发布则按严重度热修或撤回。
兼容性公开 API、类型、DOM/焦点及令牌兼容报告无未声明破坏。重分类版本；错误发布必须撤回并重发。
性能包体积、交互延迟、长任务与大数据场景符合已登记预算。禁止用全局豁免；优化或拆分入口。
供应链无已知高危漏洞；许可证合规；产物具完整性和来源记录。冻结发布，替换/升级依赖并重新认证。
全库发布冻结：发现跨租户/越权、敏感信息泄露、错误版本破坏兼容、产物来源不可信、关键业务数据风险、同类缺陷可能波及多个组件，立即冻结全部晋级，完成影响扫描后才能解冻。
撤回优先级：先阻止新安装与晋级，再发布已验证的回退/修复版本，随后通知已知消费方；禁止直接删除仍被项目锁定的版本，也禁止在事故中临时重新构建未经验证的产物。
