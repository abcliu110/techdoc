B / C：原型复杂度

决定拆分粒度、演示场景数量、测试组合和实施批次。B 是任务真实组件；C 是跨模块或跨系统复合交互。

R1 / R2 / R3：生产风险

依据最坏失败后果分级，决定评审角色、证据深度、灰度策略与回滚要求。发布门禁看这一轴。

等级R1 局部可逆R2 业务状态R3 关键业务
判定 R1
失败只影响当前视图或本地临时状态，可立即撤销，不触达敏感数据。		 R2
涉及异步提交、持久化编辑、批量选择或并发刷新；错误会导致工作丢失或业务状态不一致，但可补偿。		 R3
涉及权限、多租户、金额、库存、订单、支付、不可逆批量操作或跨系统一致性。
附加门禁 组件契约评审、交互/A11y/视觉回归、包安装验证。 R1 全部 + 集成测试、竞态/重复提交、草稿恢复、失败注入、性能预算。 R2 全部 + 领域评审、权限与租户验证、幂等并发、审计、灰度/回滚演练、跨系统契约测试。
发布权限 组件责任人完成证据后合入。 组件责任人 + 组件库维护者双审。 组件库维护者 + 业务领域责任人批准；缺任一项不得发布。
分级规则：按最高命中项定级；无法证明是低风险时向上取级。C 不自动等于 R3，B 也可能是 R3，例如外观简单的“确认扣款”按钮。
