生产级 React 组件库：边界与发布链路

一个仓库，两类可发布资产，一个演示入口；旧 HTML 套件继续作为行为验收基线。

309 项 HTML 交互规范

保留组件 ID、状态、主流程、异常恢复、键盘与响应式契约。

角色：需求与回归基线，不进入 npm 运行时。

契约清单与迁移映射

旧 ID → React 导出名 → Story → 自动化用例 → 发布批次。

→

@company/ui

唯一面向业务项目的组件包，支持根导出与子路径导出。

包含 React 组件、样式、类型、受控状态 API 与无障碍语义。

@company/tokens

颜色、排版、间距、密度、动效、层级与暗色主题变量。

只被 UI 包和消费方依赖，不反向依赖任何组件。

→

apps/docs 规范演示站

真实业务场景、Props、状态矩阵、异常恢复、无障碍与迁移说明。

只消费发布包公开 API，不允许走源码后门。

质量与发布设施

单元、交互、无障碍、视觉回归、响应式、包产物与类型测试。

依赖单向tokens → ui → docs / consumer，禁止反向引用。
契约可追溯每个旧组件 ID 必须映射到 React API、Story 和测试证据。
发布即质量门禁任何批次只有在类型、交互、A11y、视觉与包安装验证通过后才可发布。

分批路线

0.1 基线 + 业务切片令牌、基础控件、弹层、表单、表格、树与代表性复合组件。
0.2 数据与选择高级表格、树表、选择器、虚拟化与异步数据状态。
0.3 编辑器与流程规则、查询、流程、布局及其他复杂设计器。
0.x 全量覆盖30 个 C 级跨系统组件、309 项契约覆盖与稳定版准入。
