# 汉字学习 App 设计文档

> 版本：v1.0
> 日期：2026-10-04
> 目标用户：K12 学生（高中及以下）
> 学习模式：任务驱动 + 自由探索
> 平台：Flutter（移动端 + 桌面端）
> 数据：本地存储，无需账号

---

## 一、产品定位

### 1.1 核心目标

帮助 K12 学生高效认识汉字，深刻理解汉字构造逻辑与语义演变。

### 1.2 两大学习模式

| 模式 | 定位 | 入口 |
|------|------|------|
| **任务驱动** | 主学习路径：每日任务、进度追踪、作业辅助 | 首页 |
| **自由探索** | 辅助工具：查询、字源分析、深度学习 | 底部导航 |

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 字频优先 | 高频字优先学习，覆盖日常90%使用 |
| 形声规律 | 利用形声字构造规律，批量学习 |
| 语境嵌入 | 字→词→句→文递进理解 |
| 本义追溯 | 从字源理解汉字，加深记忆 |
| 本地优先 | 所有数据本地存储，无需网络 |

## 二、功能模块

### 2.1 P0 核心功能

#### 2.1.1 每日任务

| 功能 | 说明 |
|------|------|
| 字频测试 | 初始测评确定用户当前字量水平（0-500/500-1000/1000-2000/2000-3500） |
| 智能推荐 | 根据水平推荐每日学习任务，优先高频字、形声字、字族 |
| 进度追踪 | 今日任务/本周任务/总体进度可视化 |
| 学习记录 | 记录每日学习时长、已学字数、正确率 |
| 任务数量 | 用户可自定义每日学习字数（默认15字/天） |

#### 2.1.2 字卡学习

| 功能 | 说明 |
|------|------|
| 形声规律展示 | 形旁+声旁的构造分析，同声旁字族关联 |
| 字族学习 | 以声旁为纽带，批量学习5-10个相关字 |
| 例词展示 | 每个字配3-5个常用词，体现不同义项 |
| 例句巩固 | 语境学习，字在句中的具体用法 |
| 层级递进 | 字→词→句→篇，从简单到复杂 |

#### 2.1.3 自由查询

| 功能 | 说明 |
|------|------|
| 汉字检索 | 按拼音、部首、笔画数、字频检索 |
| 六书分析 | 显示该字所属六书类别及构造逻辑 |
| 本义追溯 | 甲骨文/金文/小篆字形演变，现代义项 |
| 字源图片 | 历代字形图片对照（甲骨文→金文→小篆→隶书→楷书） |
| 形近字区分 | 形似字对比，避免混淆（如"末/未"、"己/已/巳"） |

### 2.2 P1 功能

#### 2.2.1 书写练习

| 功能 | 说明 |
|------|------|
| 笔画动画 | 展示正确笔顺，支持慢放、重播 |
| 描红练习 | 在虚字框内描红，强化肌肉记忆 |
| 听写训练 | 听发音写汉字，检测掌握程度 |
| 书写评分 | 笔画顺序正确性评分 |

#### 2.2.2 复习巩固

| 功能 | 说明 |
|------|------|
| 间隔重复 | 基于艾宾浩斯遗忘曲线，智能安排复习时间 |
| 错字本 | 自动收录错字，专项复习 |
| 掌握度标记 | 用户可自评"认识/模糊/不认识"，调整复习优先级 |
| 复习提醒 | 本地推送，提醒复习已学汉字 |

### 2.3 P2 功能

#### 2.3.1 成就系统

| 功能 | 说明 |
|------|------|
| 等级徽章 | 按累计字数划分等级（识字达人→汉字专家→国学大师） |
| 学习天数 | 连续学习天数统计 |
| 字数统计 | 已掌握字数、今日新学字数 |
| 成就解锁 | 达成特定目标解锁成就徽章 |

#### 2.3.2 家长模式（可选开启）

| 功能 | 说明 |
|------|------|
| 学习报告 | 每日/每周学习数据统计 |
| 目标设置 | 家长设定每日学习目标 |
| 使用限制 | 可设置每日使用时长限制 |

## 四、核心页面流程

### 4.1 首次启动流程

```
启动App → 字频测试（5分钟） → 确定初始等级 → 生成每日任务 → 进入首页
```

字频测试题目示例：
- 显示汉字，选择正确拼音
- 显示拼音，选择正确汉字
- 显示词语，选择包含的正确汉字

### 4.2 每日任务流程

```
首页 → 查看今日任务 → 选择一个字开始学习 → 字卡展示 → 学习检测 → 完成打卡 → 任务进度更新
```

### 4.3 字卡学习流程

```
字卡展示（形+音）→ 点击查看义项 → 查看形声规律/字族 → 查看例词 → 查看例句 → 点击"记住了"/"再想想" → 下一个
```

### 4.4 自由查询流程

```
底部导航→查询 → 输入汉字/拼音/部首 → 搜索结果 → 查看详情 → 六书分析/字源图片/形近字/例词
```

### 4.5 复习流程

```
复习提醒 → 查看待复习字列表 → 选择一个字 → 测试认读 → 正确/错误 → 更新状态 → 下一个
```

## 六、技术方案

### 6.1 技术栈

| 组件 | 技术选型 | 理由 |
|------|----------|------|
| 跨平台框架 | Flutter 3.x | 一次开发覆盖 iOS/Android/Windows/Mac/Web |
| 状态管理 | Riverpod | 轻量、编译时安全、易于测试 |
| 本地数据库 | SQLite（sqflite/drift） | 结构化数据存储，支持复杂查询 |
| 本地存储 | SharedPreferences | 轻量配置存储 |
| 汉字数据 | 内嵌 SQLite 数据库 | 离线可用，无网络依赖 |
| 字体 | Noto Sans CJK SC | 覆盖所有汉字字形 |
| 音频 | audioplayers | 汉字发音、听写功能 |
| 动画 | flutter_svg + Lottie | 笔画动画 |

### 6.3 字库数据结构

字库数据以 SQLite 内嵌方式提供，包含：

| 数据表 | 数据量 | 说明 |
|--------|--------|------|
| characters | 6000+ | 所有汉字，含字频/六书/字源等 |
| character_families | 200+ | 常用字族 |
| word_examples | 20000+ | 例词例句 |
| radical_index | 200+ | 部首索引 |
| stroke_order | 3500 | 笔画顺序数据 |

字库数据来源：
- 3500 常用字表（GB/T 2312-1980）
- 课标字表（小学/初中/高中）
- 说文解字字源数据
- 开放汉字字源数据库（免费资源）

### 6.4 复习算法

采用简化的间隔重复算法（类 SM-2）：

```
初始间隔：1天
复习间隔 = 上次间隔 × 难度系数
难度系数：0.5（忘记）/ 1.0（模糊）/ 2.0（记住）

最大间隔：30天
超过30天按30天计算
```
