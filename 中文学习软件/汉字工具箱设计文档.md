# 汉字工具箱 - 设计文档

> 版本：v1.0
> 日期：2026-10-05
> 定位：工具型汉字查询应用，像《新华字典》一样实用

---

## 一、产品定位

### 1.1 目标用户画像

| 用户类型 | 核心需求 | 优先功能 |
|----------|----------|----------|
| 内容创作者（作家、编辑） | 快速查字、了解字义 | 快速查询、字详情、收藏 |
| 汉字文化爱好者 | 字源探索、字族关联 | 字源探索、字族图谱 |
| 家长/教师 | 辅导讲解、辨析易混字 | 形近对比、六书字典 |
| 学生 | 预习复习、了解字词用法 | 快速查询、字详情 |

> 核心定位：成人语言工作者首选的汉字工具，强调"随用随走"的无压使用模式。

### 1.2 与学习版的区别

| 维度 | 学习版 | 工具版（本文档） |
|------|--------|------------------|
| 目标 | 学会多少字 | 快速查到信息 |
| 心态 | 有学习压力 | 无压力，随用随走 |
| 使用频率 | 定期打开 | 随时可用 |
| 核心价值 | 记忆+复习 | 查找+理解 |
| 用户 | 学生 | **成人语言工作者为主** |
| 商业化 | 课程/会员 | 付费字库/高级功能 |

### 1.3 核心用户场景

| 场景 | 用户 | 需求 |
|------|------|------|
| 读书看报 | 成人 | 遇到不认识或不确定的字，查一下 |
| 写作创作 | 写作者 | 找一个合适的字，了解用法 |
| 汉字研究 | 爱好者 | 探索字源、字族、六书分类 |
| 辅导作业 | 家长 | 给孩子讲解字词，需要详细解释 |
| 语文学习 | 学生 | 预习复习，了解字词用法 |

### 1.4 商业化初步规划

| 盈利模式 | 可行性 | 说明 |
|----------|--------|------|
| 付费字库解锁 | 高 | 扩展字库（3500+字）、专业字源包 |
| 会员制 | 中 | 解锁高级功能如字源视频、深度讲解 |
| 广告 | 低 | 工具类应用广告变现效果一般 |

> MVP阶段保持免费，验证用户价值后再考虑商业化。

### 2.2 功能详情

#### 模块1：六书字典

按六书分类浏览汉字，体现汉字构造逻辑。

| 分类 | 说明 | 示例字 |
|------|------|--------|
| **象形** | 画物象之形，建立形-物联结 | 日、月、山、水、人、口 |
| **指事** | 符号指示抽象概念 | 上、下、本、末、刃、甘 |
| **会意** | 两形或多形合体表意 | 明、武、休、众、森 |
| **形声** | 形旁+声旁，批量学习核心 | 江、河、晴、清、情 |
| **转注** | 同义字互训 | 考=老、顶=巅 |
| **假借** | 同音字借用 | 莫→暮、其→箕 |

**交互**：
- 点击分类 → 展示该分类下的汉字列表
- 点击汉字 → 进入详情页
- 展示每个分类的造字逻辑说明

#### 模块2：字族图谱

以声旁为核心，展示同族字。

```

├─────────────────────────────────────────────────────────────┤
│  声旁：青 (qīng)                                          │
│  读音一致性：较高（多数字读 qīng，个别读近似音）            │
│                                                             │
│  字族成员：                                                  │
│  ┌───┬───┬───┬───┬───┬───┬───┬───┬───┐                   │
│  │清 │情 │晴 │请 │睛 │精 │静 │靖 │倩 │                   │
│  └───┴───┴───┴───┴───┴───┴───┴───┴───┘                   │
│                                                             │
│  形旁义类分析：                                              │
│  ┌──────────────────────────────────────────────┐          │
│  │ 氵(三点水)  清 → 与水有关：清洁、清澈        │          │
│  │ 忄(竖心旁)  情 → 与心理有关：情感、心情      │          │
│  │ 日(日字旁)  晴 → 与天气有关：晴天、晴朗      │          │
│  │ 讠(言字旁)  请 → 与言语有关：请求、请教      │          │

**交互**：
- 选择声旁 → 展示完整字族
- 点击任一字 → 进入详情页
- 支持字族扩展：查看更多同族字
- 展示声旁读音一致性等级

#### 模块3：部首索引

按部首分类查找汉字，同时展示部首的义类。

| 部首 | 义类 | 示例字 |
|------|------|--------|
| 氵/水 | 液体、流动、清洗 | 江、河、湖、海、泪、洗 |
| 木 | 树木、植物 | 林、森、根、枝、叶、桌 |
| 扌 | 手部动作 | 打、拍、推、拉、抢、拾 |
| 口 | 口部、言语 | 吃、喝、唱、喊、叫、吹 |
| 忄/心 | 心理活动 | 思、念、想、情、爱、恨 |
| 讠 | 言语相关 | 说、话、语、请、谢、讲 |

**交互**：
- 浏览部首列表 → 选择部首
- 展示该部首下的所有汉字
- 点击汉字 → 进入详情页

#### 模块4：主题词场

按生活/知识主题分类，展示相关汉字。

| 主题 | 说明 | 汉字示例 |
|------|------|----------|
| **人体** | 身体部位 | 头、目、耳、口、手、足、心 |
| **自然** | 自然现象 | 日、月、水、火、山、风、雨 |
| **数字** | 数字相关 | 一、二、三、十、百、千、万 |
| **方位** | 方向位置 | 上、下、左、右、前、后 |
| **时间** | 时间概念 | 昨、今、明、旦、暮、早、晚 |
| **色彩** | 颜色相关 | 红、黄、蓝、绿、白、黑 |
| **情感** | 心理情感 | 喜、怒、哀、乐、爱、恨、思 |
| **动作** | 行为动作 | 走、跑、跳、飞、游、坐、立 |
| **家庭** | 亲属关系 | 父、母、兄、弟、姐、妹、儿 |
| **建筑** | 建筑相关 | 房、门、窗、墙、屋、梁、柱 |

**交互**：
- 选择主题 → 展示该主题下的汉字
- 点击汉字 → 进入详情页
- 展示主题相关的常用词组

#### 模块5：字源探索

展示汉字的字源演变历程。

| 内容 | 说明 |
|------|------|
| 甲骨文 | 殷商时期刻在龟甲兽骨上的文字 |
| 金文 | 西周青铜器上的铭文 |
| 小篆 | 秦统一六国后的标准字体 |
| 隶书 | 汉代通行的字体 |
| 楷书 | 现代标准字体 |

**示例：休字演变**
```
甲骨文：像人倚靠在树旁休息
   ↓
金文：加了"木"字，更明确表示是树
   ↓
小篆：人+木，结构固定
   ↓
隶书：笔画化，更易书写
   ↓
楷书：现代"休"字
```

**交互**：
- 点击字源 → 展示历代字形图片
- 展示说文解字原文+现代注释
- 展示造字故事

#### 模块6：形近对比

对比易混淆的形近字。

| 对比组 | 区别 | 口诀 |
|--------|------|------|
| 末/未 | 横画位置不同 | 长横在上是"末"，短横在上是"未" |
| 己/已/巳 | 开口不同 | 己开，巳闭，半开半闭就是"已" |
| 土/士 | 横画位置不同 | 土有底，士无底 |
| 晴/清/情/请 | 形旁不同 | 日边晴，水边清，心情感，请请教 |
| 大/太/犬 | 多一点位置不同 | 大无点，太有点，犬有捺点 |
| 辨/辩/辫/瓣 | 中间部件不同 | 辨分辨，言语辩，丝旁辫，花瓣瓣 |

**交互**：
- 选择对比组 → 展示详细对比
- 展示每个字的详细解释
- 展示区分口诀和示例

#### 模块7：快速查询

传统字典式查询功能。

| 查询方式 | 说明 |
|----------|------|
| 汉字查询 | 输入单个汉字 |
| 拼音查询 | 输入拼音首字母或全拼 |
| 部首查询 | 选择部首后数笔画 |
| 笔画查询 | 直接按笔画数查找 |
| 模糊查询 | 支持部分匹配 |

#### 模块8：我的收藏

用户个人数据管理。

| 功能 | 说明 |
|------|------|
| 收藏的字 | 标记重要或常查的字 |
| 查询历史 | 自动记录最近查询 |
| 学习笔记 | 用户自定义笔记 |

```

│    Character    │
├─────────────────┤

│ sixBook         │  六书分类
│ phonetic        │  声旁
│ semantic        │  形旁
│ originMeanings  │  本义
│ extendedMeanings│  引申义列表
│ originJiaguwen  │  甲骨文
│ originJinwen    │  金文
│ originXiaozhuan │  小篆
│ originLishu     │  隶书
│ shuowenNote     │  说文解字注释
│ note            │  备注
└─────────────────┘

┌─────────────────┐
│   WordExample   │
├─────────────────┤
│ id              │
│ characterId     │
│ word            │  词语
│ meaning         │  释义
│ exampleSentence │  例句

└─────────────────┘

┌─────────────────────────┐

├─────────────────────────┤

**多音字处理方案**：

- 查询时展示所有读音，由用户选择
- 词组例句按具体读音关联

### 5.2 离线资源策略

## 七、与理论文档的结合

### 7.1 六书体系

按文档中的六书分类理论实现：
- 象形 ~5%：日、月、山、水
- 指事 ~2%：上、下、本、末
- 会意 ~10%：明、休、武
- 形声 ~80-90%：江、河、晴
- 转注 ~1%：考、老
- 假借 ~2%：莫、暮

### 7.2 形声字体系

强调形旁表义、声旁表音的核心规律：
- 形旁分类展示（氵=水相关、忄=心理相关）
- 声旁字族关联
- 声旁表音一致性说明

### 7.3 字族学习法

按文档的字族学习策略设计：
- 记住一个声旁 → 推导一串读音
- 记住形旁义类 → 理解每个字含义
- 批量展示同族字

### 7.4 本义追溯

按文档的引申义理论实现：
- 本义 → 引申义 演变链可视化
- 说文解字原文引用
- 历代字形演变展示

### 7.5 语境学习

每个汉字提供：
- 常见组词（2-5个）
- 例句（1-3句）
- 语境中的用法说明
