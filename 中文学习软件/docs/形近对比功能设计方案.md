# 汉字学习软件「形近对比」功能设计方案

## 一、概述

### 1.1 功能定位

「形近对比」是帮助学习者区分易混淆汉字的核心功能，通过字形对比、笔画差异高亮、组词对比等方式，强化对形近字的辨识能力。

### 1.2 设计目标

- 快速识别：一眼看出差异位置
- 深刻记忆：通过对比强化区分印象
- 实际应用：组词对比帮助理解用法差异
- 练习巩固：内置测试入口检验学习效果

```dart
class SimilarCharGroup extends Equatable {
  final int id;
  final String groupName;        // 如 "己-已-巳"

  final List<SimilarChar> chars; // 组成成员
  final String difficultyLevel;  // 难度等级：easy/medium/hard
```

## 四、差异高亮展示方式

### 4.1 笔画级高亮（核心展示）

采用**颜色叠加 + 动画闪烁**的方式标识差异区域：

```
┌────────────────────────────────────────┐
│                                        │
│     ┌───┐    ┌───┐    ┌───┐          │
│     │ 己│    │ 已│    │ 巳│          │
│     │jǐ │    │yǐ │    │sì │          │
│     └───┘    └───┘    └───┘          │
│                                        │
│     【己】      【已】      【巳】     │
│     竖不出头    竖半出头    竖全封口   │
│     ▓▓▓▓       ▓▓▓▓       ▓▓▓▓        │
│       ↑         ↑         ↑           │
│     (口开口    (口半开    (口闭合     │
│      朝右)      朝右)      )           │
│                                        │
└────────────────────────────────────────┘
```

**高亮规则：**
- **橙色脉冲**：差异笔画，使用 `Color(0xFFFF6B00)` 带 0.3s 脉冲动画
- **红色标注线**：从差异笔画拉出标注线
- **文字说明**：简洁的差异描述（不超过10字）

### 4.2 叠加对比模式

支持将两个字叠加在一起显示，相同部分变灰色，不同部分高亮：

```
          叠加对比
    ┌──────────────────┐
    │    己 vs 已       │
    │   ┌────────┐     │
    │   │己 已   │     │  ← 叠加后字形
    │   │░▒██░░░│     │  ← 灰色=相同，红色=差异
    │   └────────┘     │
    │                  │
    │  相同: 全部      │
    │  差异: 竖笔位置  │
    └──────────────────┘
```

```sql
CREATE TABLE similar_char_groups (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  group_name TEXT NOT NULL,           -- 如 "己-已-巳"
  description TEXT,                   -- 差异描述
  difficulty TEXT DEFAULT 'easy',     -- easy/medium/hard
  category TEXT,                      -- 笔画差异/位置差异/部件差异
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 形近字组成员表
CREATE TABLE similar_chars (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  group_id INTEGER NOT NULL,
  character TEXT NOT NULL,
  pinyin TEXT NOT NULL,
  explanation TEXT,
  example_words TEXT,                 -- JSON数组，例词列表
  highlight_info TEXT,                -- 高亮位置信息
  FOREIGN KEY (group_id) REFERENCES similar_char_groups(id)
);

-- 用户收藏表（扩展）
CREATE TABLE user_favorites (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER DEFAULT 1,
  favorite_type TEXT NOT NULL,        -- 'char' / 'group' / 'similar'
  target_id INTEGER NOT NULL,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 形近字练习记录表
CREATE TABLE similar_practice_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  group_id INTEGER NOT NULL,
  practice_mode TEXT NOT NULL,        -- 'identify' / 'fill' / 'find'
  score INTEGER NOT NULL,
  total INTEGER NOT NULL,
  wrong_chars TEXT,                   -- JSON数组，答错的字
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);
```

## 十二、总结

### 设计亮点

1. **直观差异高亮**：通过颜色+动画让差异一目了然
2. **多维度对比**：字形、笔画、组词三维度全面对比
3. **记忆口诀**：每组形近字配有记忆口诀，便于长期记忆
4. **练习闭环**：从学习到练习到反馈的完整学习闭环
5. **进度追踪**：记录用户练习数据，针对性推荐薄弱点
