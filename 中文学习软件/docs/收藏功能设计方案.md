# 汉字学习软件 - 收藏功能设计方案

## 一、功能概述

收藏功能允许用户收藏感兴趣的汉字，便于后续复习和学习进度追踪。

### 核心功能
1. 收藏按钮（心形）- 在搜索结果、汉字详情页等位置显示
2. 收藏列表页面 - 展示所有收藏的汉字
3. 分类收藏 - 按主题、按难度筛选
4. 学习进度追踪 - 显示收藏汉字的学习状态分布
5. 复习提醒 - 标记需要复习的收藏汉字

## 二、数据模型设计

### 2.1 数据库表结构

```sql
-- 收藏表
CREATE TABLE favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    character_id INTEGER NOT NULL UNIQUE,  -- 汉字ID
    collected_at TEXT NOT NULL,             -- 收藏时间
    note TEXT,                              -- 备注（可选）
    tags TEXT,                              -- 自定义标签，逗号分隔
    FOREIGN KEY (character_id) REFERENCES characters(id)
);

-- 收藏标签表（支持多标签）
CREATE TABLE favorite_tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    favorite_id INTEGER NOT NULL,
    tag_name TEXT NOT NULL,
    FOREIGN KEY (favorite_id) REFERENCES favorites(id)
);
```

### 2.2 Dart 数据模型

```dart
// Favorite 实体
class Favorite extends Equatable {
  final int id;
  final int characterId;
  final String collectedAt;     // ISO8601格式
  final String? note;           // 备注
  final List<String> tags;       // 自定义标签
}

// 收藏统计
class FavoriteStats {
  final int totalCount;         // 总收藏数
  final int notLearnedCount;    // 未学习数
  final int learningCount;      // 学习中数
  final int masteredCount;       // 已掌握数
  final int level1Count;        // 一级难度数
  final int level2Count;        // 二级难度数
  final int level3Count;        // 三级难度数
  final int level4Count;        // 四级难度数

  double get masteryRate => totalCount > 0 ? masteredCount / totalCount : 0.0;
}

// 收藏筛选条件
class FavoriteFilter {
  final List<int> levels;       // 难度等级筛选
  final List<String> statuses;   // 学习状态筛选
  final String? themeId;         // 主题词场筛选
  final FavoriteSortOrder sortOrder;  // 排序方式
}

// 排序方式枚举
enum FavoriteSortOrder {
  collectedDesc('最新收藏'),
  collectedAsc('最早收藏'),
  pinyin('按拼音'),
  levelAsc('难度低→高'),
  levelDesc('难度高→低'),
  strokesAsc('笔画少→多'),
  strokesDesc('笔画多→少');
}
```

## 七、使用示例

### 7.1 在汉字详情页使用收藏按钮

```dart
import '../../favorites/widgets/favorite_button.dart';

// 在 AppBar actions 中添加
actions: [
  Padding(
    padding: const EdgeInsets.only(right: 8),
    child: FavoriteButton(
      characterId: widget.character.id,
      size: 28,
    ),
  ),
],
```

### 7.2 在收藏列表页面获取收藏数据

```dart
// 使用 Provider 获取收藏列表
final state = ref.watch(favoriteListProvider);

// 刷新收藏列表
ref.read(favoriteListProvider.notifier).refresh();

// 按难度筛选
ref.read(favoriteListProvider.notifier).filterByLevels([1, 2]);

// 按学习状态筛选
ref.read(favoriteListProvider.notifier).filterByStatuses(['1', '2']);

// 更新排序
ref.read(favoriteListProvider.notifier).updateSortOrder(
  FavoriteSortOrder.pinyin,
);
```

### 7.3 获取单个汉字的收藏状态

```dart
// 检查某个汉字是否已收藏
final state = ref.watch(characterFavoriteProvider(charId));
if (state.isFavorited) {
  // 已收藏
}

// 切换收藏状态
final newStatus = await ref.read(
  characterFavoriteProvider(charId).notifier,
).toggle();
```
