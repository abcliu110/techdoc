## 3. 可操作元素

### 3.1 心形收藏按钮

| 属性 | 说明 |
|-----|------|
| 元素ID | `favorite-btn-{characterId}` |
| 位置 | 汉字卡片右上角 / 汉字详情页 |

| 内容 | 可滚动的汉字卡片列表 |
| 空状态 | 无收藏时显示「暂无收藏」提示 |

## 4. 状态定义

### 4.1 收藏按钮状态

| 状态 | 视觉表现 | 可访问性属性 |
|-----|---------|-------------|
| 未收藏（默认） | 空心灰色心形 `Icons.favorite_border` | `aria-pressed="false"` |
| 已收藏 | 实心红色心形 `Icons.favorite` 颜色 `#E53935` | `aria-pressed="true"` |
| 点击中（过渡） | 缩放动画 0.8x -> 1.0x，150ms | 禁用点击防抖 |
| 收藏失败 | 显示 SnackBar 提示「收藏失败，请重试」 | 无障碍提示 |

### 4.2 收藏列表状态

| 状态 | 视觉表现 |
|-----|---------|
| 有数据 | 显示汉字卡片网格/列表 |
| 空数据 | 显示空状态插图 + 「暂无收藏」文字 + 「去收藏」按钮 |
| 加载中 | 显示骨架屏或加载指示器 |
| 筛选无结果 | 显示「没有符合条件的收藏」 |

## 5. 交互流程与状态转换

### 5.1 收藏操作状态机

```
场景：用户收藏一个汉字

初始状态 [未收藏]
  │
  └─ 点击心形按钮
        │
        ├─ 存储成功 → [已收藏] 立即显示实心红色
        │                   └─ 轻微缩放动画 + 震动反馈（可选）
        │
        └─ 存储失败 → [未收藏] 显示错误提示，可重试
```

### 5.2 取消收藏状态机

```
场景：用户取消收藏一个汉字

已收藏状态 [已收藏]
  │
  └─ 点击心形按钮
        │
        ├─ 取消成功 → [未收藏] 立即显示空心虚线
        │                   └─ 轻微缩放动画
        │
        └─ 取消失败 → [已收藏] 显示错误提示，保持原状态
```

### 5.3 完整收藏流程

```
用户进入汉字列表页
  │
  └─ 看到汉字卡片
        │
        ├─ 点击卡片 → 进入详情页（可在此处收藏）
        │
        └─ 点击心形按钮 → 即时收藏/取消
              │
              └─ 显示 SnackBar 确认
                    ├─ 「已收藏」
                    └─ 「已取消收藏」
```

### 5.4 收藏列表流程

```
用户点击收藏入口
  │
  └─ 进入收藏列表页
        │
        ├─ 显示全部收藏
        │     ├─ 点击筛选 → 按条件过滤
        │     └─ 点击汉字卡片 → 进入详情页
        │
        └─ 无收藏 → 显示空状态页
              └─ 点击「去收藏」→ 返回首页
```

## 9. 边界情况处理

### 9.1 网络/存储异常

| 场景 | 处理方式 |
|-----|---------|
| 收藏操作失败 | 保持当前UI状态，显示错误提示，不自动重试 |
| 收藏列表加载失败 | 显示错误页 + 重试按钮 |
| 数据不一致 | 下次进入时从数据库重新加载 |

### 9.2 重复操作

| 场景 | 处理方式 |
|-----|---------|
| 快速连续点击 | 使用防抖机制，150ms内只响应一次 |
| 网络延迟时的状态 | 以服务器返回结果为准 |

### 9.3 数据清理

| 场景 | 处理方式 |
|-----|---------|
| 汉字数据被删除 | 收藏列表自动过滤掉不存在的汉字 |
