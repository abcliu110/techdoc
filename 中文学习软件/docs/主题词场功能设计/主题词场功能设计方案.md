# 汉字学习软件 - 主题词场功能设计

## 一、设计目标

主题词场功能旨在按语义主题对汉字进行分类组织，帮助用户通过**主题联想**的方式学习和记忆汉字。每个主题关联相关汉字，汉字又关联该主题下的词汇，形成"主题 -> 汉字 -> 词汇"的三层语义网络。

## 三、数据模型设计

### 3.1 主题模型 (Theme)

```dart
/// 主题实体
class Theme extends Equatable {
  final String id;           // 主题ID，如 'nature'
  final String name;         // 主题名称，如 '自然'
  final String icon;         // 图标名称
  final String color;        // 主题色，如 '#4CAF50'
  final String description;  // 主题描述
  final int order;          // 排序序号

  const Theme({
    required this.id,
    required this.name,
    required this.icon,
    required this.color,
    required this.description,
    required this.order,
  });
}
```

### 3.2 汉字-主题关联表

数据库新增表：

```sql
CREATE TABLE character_themes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  character_id INTEGER NOT NULL,
  theme_id TEXT NOT NULL,
  weight INTEGER DEFAULT 1,  -- 关联权重，越高越核心
  UNIQUE(character_id, theme_id)
);

CREATE INDEX idx_character_themes_char ON character_themes(character_id);
CREATE INDEX idx_character_themes_theme ON character_themes(theme_id);
```

### 3.3 主题词汇表

```sql
CREATE TABLE theme_words (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  theme_id TEXT NOT NULL,
  word TEXT NOT NULL,           -- 词汇
  pinyin TEXT NOT NULL,         -- 拼音
  meaning TEXT,                 -- 释义
  example TEXT,                 -- 例句
  character_id INTEGER,         -- 关联的核心汉字ID
  UNIQUE(theme_id, word)
);

CREATE INDEX idx_theme_words_theme ON theme_words(theme_id);
```

## 六、用户交互流程

### 6.1 主流程

```
1. 首页 -> 点击"主题词场"
   ↓
2. 主题选择页 (默认显示全部12个主题)
   ↓
3. 点击主题卡片 -> 进入主题详情页
   ↓
4. 浏览汉字网格 -> 点击汉字 -> 弹出汉字详情BottomSheet
   ↓
5. 向下滚动 -> 查看主题词汇
   ↓
6. 点击词汇 -> 展开详细信息 (释义+例句)
```

### 6.2 搜索流程

```
1. 在主题选择页搜索框输入 "自然"
   ↓
2. 实时过滤 -> 显示匹配的主题
   ↓
3. 如果输入的是汉字名 (如 "日")：
   - 搜索包含该汉字的主题
   - 显示 "日字相关主题：自然、时间"
   ↓
4. 点击搜索结果 -> 跳转对应主题详情
```

### 6.3 学习流程

```
1. 主题详情页 -> 点击"开始学习"按钮
   ↓
2. 进入主题学习模式：
   - 逐字展示 (汉字 + 拼音 + 释义)
   - 左右滑动切换
   ↓
3. 点击汉字卡片 -> 查看详细信息
   ↓
4. 学习完成 -> 标记已学 + 更新进度
```

## 七、状态管理方案

### 7.1 Provider 架构

```dart
// 主题列表状态
final themeListProvider = StateNotifierProvider<ThemeListNotifier, ThemeListState>

// 当前选中的主题
final selectedThemeProvider = StateProvider<Theme?>

// 主题汉字列表
final themeCharactersProvider = FutureProvider.family<List<Character>, String>

// 主题词汇列表
final themeWordsProvider = FutureProvider.family<List<ThemeWord>, String>

// 主题内搜索
final themeSearchProvider = StateProvider<String>

// 子分类Tab选中
final subCategoryProvider = StateProvider<String?>
```

### 7.2 状态类定义

```dart
/// 主题列表状态
class ThemeListState {
  final List<Theme> themes;
  final bool isLoading;
  final String? error;
  final String searchQuery;
}

/// 主题详情状态
class ThemeDetailState {
  final Theme? currentTheme;
  final List<Character> characters;
  final List<ThemeWord> words;
  final String? selectedSubCategory;
  final bool isLoading;
}
```

### 7.3 状态流转

```
ThemeListState:
  isLoading: false -> true -> false
  themes: [] -> [Theme, ...] (加载完成后)
  searchQuery: "" -> "自然" (搜索时实时更新)

ThemeDetailState:
  currentTheme: null -> Theme (选中后)
  characters: [] -> [Character, ...] (加载后)
  selectedSubCategory: null -> "天文" (Tab切换)
```

## 十一、设计亮点

### 11.1 语义联想记忆
通过主题关联，帮助用户建立"汉字 <-> 语义 <-> 场景"的联想记忆网络。

### 11.2 多维度分类
汉字可归属多个主题，符合汉字一词多义、一字多用的特点。

### 11.3 词汇扩展
每个主题不仅展示汉字，还提供主题相关词汇，帮助用户学以致用。

### 11.4 学习模式支持
支持主题内的系统性学习，按子分类逐层深入。
