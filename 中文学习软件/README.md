# 汉字学习软件

基于 Flutter 和 Riverpod 的汉字学习应用，帮助 K12 学生高效认识汉字，深刻理解汉字构造逻辑与语义演变。

## 功能特性

### 核心功能
- **字卡学习**：按每日任务学习新汉字，包含形声规律、本义引申义展示
- **自由查询**：支持按汉字、拼音、部首、笔画、六书分类查询
- **复习巩固**：基于间隔重复算法，智能安排复习计划
- **书写练习**：在田字格中练习汉字书写

### 特色功能
- **六书分类展示**：象形、指事、会意、形声、转注、假借
- **形声规律可视化**：形旁+声旁=合成字，清晰展示造字逻辑
- **字族学习**：以声旁为纽带，批量学习相关汉字
- **本义与引申义**：展示汉字从古至今的语义演变
- **例词例句**：每个汉字配有常用词语和例句

## 技术架构

- **状态管理**：Riverpod
- **本地存储**：SQLite（支持 Web、移动端、桌面端）
- **架构模式**：Clean Architecture（数据层/业务层/表现层）

## 数据模型

### 汉字 (Character)
- 基本信息：汉字、拼音、部首、笔画、字频、等级
- 六书分类：象形/指事/会意/形声/转注/假借
- 形声信息：形旁、声旁
- 字源信息：甲骨文、金文、小篆
- 语义信息：本义、引申义列表
- 来源标记：课内、通用、中考、高考等

### 例词 (WordExample)
- 词语、释义、例句

### 字族 (CharacterFamily)
- 声旁、成员汉字列表

### 用户进度 (UserProgress)
- 学习状态、复习日期、下次复习时间、正确/错误次数

## 数据库表

- `characters`：汉字数据
- `user_progress`：用户学习进度
- `character_families`：字族信息
- `family_members`：字族成员关系
- `word_examples`：例词数据
- `daily_tasks`：每日任务
- `user_settings`：用户设置
- `user_level`：用户等级

## 学习方法

1. **形声规律**：形声字占汉字80%以上，记住一个声旁可学习一串相关汉字
2. **字族学习**：以"青"为声旁的字（清、情、晴、请、睛、精、静）共享读音特征
3. **间隔重复**：根据遗忘曲线安排复习，加深记忆
4. **书写练习**：手写练习有助于加深对汉字结构的理解
