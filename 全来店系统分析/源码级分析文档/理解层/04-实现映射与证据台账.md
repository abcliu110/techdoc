## 一、核心实现锚点

### 1.1 订单核心链路

```
收银员点击"落单"
    │
    ▼
POST /order/placeOrder
    ├── PlaceOrderHandler.doRequest()
    │       E-SRC: service/order/web/handler/order/PlaceOrderHandler.java:21
    │
    ├── PlaceOrderService.placeOrder(PlaceOrderRequest)
    │       E-SRC: service/order/PlaceOrderService.java:51
    │       ├── 1. 获取订单：orderMasterService.getOrderMaster(billNo)
    │       ├── 2. 校验估清：soldOutOccupyService.checkSoldOut()
    │       ├── 3. 校验重复：checkRepeatGoods()
    │       ├── 4. 促销重算：executePromotionService.executePromotion()
    │       ├── 5. 事务更新（LocalServerTransactionManager.execTransaction()）
    │       └── 6. 估清占用：soldOutOccupyHandle()
    │
    ├── DownOrderService.downOrder()
    │       E-SRC: service/order/DownOrderService.java:61
    │       ├── 更新明细落单状态：ldStatus=1
    │       ├── 创建 KDS 制作单：KdsMakeCreateManager.create()
    │       └── 打印厨房小票
    │
    └── WebSocket推送：tp_order_refresh（延迟500ms）
            E-SRC: common/websocket/WebSocketPushService.java
```

### 1.2 支付链路

```
收银员选择"微信支付"
    │
    ▼
POST /pay/scanCardPay
    ├── PayScanCardHandler.doRequest()
    │
    ├── BasePayService.payComplete()
    │       E-SRC: service/pay/extension/BasePayService.java
    │       ├── 1. 分布式加锁：LockUtil.lock("order_lock_" + billNo)
    │       ├── 2. 检查未付金额：unpaidAmount > 0?
    │       ├── 3. 记录支付流水：OrderPay创建
    │       ├── 4. 自动结账检查：autoCheckout()
    │       └── 5. 保存订单
    │
    └── autoCheckout() 逻辑
            ├── 未付金额 = 0?
            ├── 无进行中支付?
            ├── 堂食无未落单商品?
            └── 全部满足 → payComplete() → ORDER_YJZ
```

### 1.3 小程序点餐链路

```
顾客在小程序点击"提交订单"
    │
    ▼
WebSocket: SUBMIT_ORDER 消息
    ├── LocalServerClientMsgDataListener.recvData()
    │       E-SRC: service/order/wxApplet/LocalServerClientMsgDataListener.java:50
    │
    ├── AppletOrderHandleService.handleOrder()
    │       E-SRC: service/order/wxApplet/AppletOrderHandleService.java:98
    │
    ├── PlaceOrderService.placeOrder()（复用）
    │
    └── WebSocket推送：tp_order_refresh → 小程序
            延迟500ms
```
