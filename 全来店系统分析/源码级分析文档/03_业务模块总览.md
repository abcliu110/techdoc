## 2. 订单模块 (`service/order/`)

### 2.1 核心服务

| 服务 | 类 | 职责 |
|------|---|------|
| 加菜 | `PlaceOrderService.java` | 商品加单、促销重算、打印厨房小票 |
| 落单 | `DownOrderService.java` | 将商品标记为已出品 |
| 反结账 | `RevCheckoutService.java` | 恢复已结账订单到待结账 |
| 撤单 | `RevokeOrderService.java` | 整单取消，退款+退支付 |
| 全额退款 | `WholeOrderRefundService.java` | 结账后退款 |
| 部分退款 | `PartialRefundService.java` | 按商品或按金额退款 |
| 查询订单 | `GetOrderService.java` | 获取订单详情 |
| 换菜 | `ReplaceOrderGoodsService.java` | 套餐换菜 |
| 打包 | `PackGoodsService.java` | 临时套餐打包 |
| 占桌 | `OrderTableExclusiveService.java` | 桌台独占控制 |

### 2.2 订单状态流转

```
未结单(ORDER_WJD)
    ↓ 开台/加菜
待结账(ORDER_DJZ)
    ↓ 结账
已结账(ORDER_YJZ)
    ↓ 反结账
待结账(ORDER_DJZ) ←──→ 已结账(ORDER_YJZ)
    ↓ 撤单              ↓ 全额退款
已取消(ORDER_YQX)    已退单/已退款
    ↓ 作废
已作废(ORDER_YZF)
```

### 2.3 关键业务规则

1. **加菜限制**: 已落单菜品不能重复加单（`0101010149`）
2. **正餐结账限制**: 所有菜品必须已落单才允许结账（`0101010954`）
3. **反结账时间限制**: 结账后超过 12 小时（可配置）不允许反结账
4. **跨日反结账**: 默认不允许跨营业日反结账

## 3. 支付模块 (`service/pay/`)

### 3.1 支付方式分类

| 分类 | 方式 | 说明 |
|------|------|------|
| 离线支付 | 现金、银行卡、手动补录、押金、其他 | 不需要联网验证 |
| 在线支付 | 扫码支付（微信/支付宝/银联）| 需要联网验证 |
| 会员支付 | 会员储值卡、礼品卡 | 余额扣减 |
| 促销支付 | 账单优惠、优惠券、抵用券 | 优惠抵充 |
| 第三方 | 外卖平台挂账 | 美团/饿了么 |

### 3.2 支付流程

```
发起支付请求
    ↓
分布式锁 LockUtil.lock(billNo)
    ↓
校验未付金额 > 0
    ↓
校验无进行中的支付 (payStatus=PAYMENT)
    ↓
设置支付科目 (PaySubject)
    ↓
事务:
    ├── 执行支付 orderPayment()
    ├── 自动结账 checkPayComplete()?
    └── 保存订单 saveOrder()
    ↓
打印结账单
    ↓
刷新订单金额 (WebSocket tp_pay_complete)
    ↓
释放锁 LockUtil.unlock()
```

### 3.3 自动结账逻辑

| 配置 | 值 | 行为 |
|------|---|------|
| `AFTER_PAY_AUTO_FINISH_CHECKOUT` | 0 | DCF 挂账模式，不自动结账 |
| | 1 | 全部自动结账 |
| | 2 | 仅扫码支付自动结账 |

堂食正餐特殊检查: 必须所有菜品 `ldStatus=1` 才允许自动结账。

## 4. 促销模块 (`service/promotion/`)

### 4.1 促销类型

| 类型 | 执行位置 | 示例 |
|------|---------|------|
| POS本地促销 | 本地计算 | 单品折扣、整单折扣、抹零 |
| 云端促销 | 调用 SDK 计算 | 满减、买赠、第M件N折 |
| 优惠券 | 本地+云端 | 折扣券、代金券、特价券 |

### 4.2 促销计算时机

1. **加菜时** (`placeOrder`) — 促销跟随商品
2. **结账时** (`checkout`) — 促销跟随订单
3. **手动执行** (`ExecutePromotionHandler`)

### 4.3 促销执行流程

```
ExecutePromotionService.executePromotion()
    │
    ├── 初始化上下文 (商品映射、套餐映射、标签映射)
    │
    ├── 处理退货商品
    │
    ├── 处理赠送商品
    │
    ├── 重置商品价格
    │   └── 套餐组合优惠分摊
    │
    ├── 调用云端促销 SDK 计算 (PromotionCalrService.calr)
    │
    ├── 设置促销金额到商品明细
    │
    ├── 处理 POS 本地折扣 (单品折扣、整单折扣)
    │
    ├── 系统券预处理
    │
    └── 保存订单 (含优惠信息)
```

## 5. 会员模块 (`service/member/`)

### 5.1 会员卡类型

| 类型 | 说明 | 特点 |
|------|------|------|
| 储值卡 | 普通会员卡 | 储值、积分、折扣 |
| 权益卡 | 购买后享受权益 | 独立于储值 |
| 礼品卡 | 用于赠送 | 独立消费流程 |

### 5.2 核心流程

- **开卡**: 录入信息 → 选择方案 → 支付卡费 → 创建会员
- **充值**: 查询卡信息 → 选择充值金额 → 支付 → 更新余额
- **消费**: 验证卡/密码 → 验证余额 → 扣减余额 → 计算积分
- **积分**: 消费累计积分 → 查询积分 → 积分兑换

## 6. 桌台模块 (`service/table/`)

### 6.1 桌台状态

| 状态 | 含义 | 可操作 |
|------|------|--------|
| FREE | 空闲 | 开台、预订 |
| OCCUPIED | 已占用 | 加菜、结账 |
| PRESETTLEMENT | 预结账 | 反结账、结账 |
| PRECLEAR | 预清台 | 清台 |
| BOOKED | 已预订 | 接待、开台 |

### 6.2 桌台操作

| 操作 | 说明 |
|------|------|
| 开台 | 创建订单，占用桌台 |
| 占桌 | 独占模式保护 |
| 并台 | 合并两个桌台为一个订单 |
| 联台 | 多个桌台共享主桌订单 |
| 拆台 | 临时桌拆分为独立桌台 |
| 换台 | 订单转移到其他桌台 |
| 清台 | 清理桌台，恢复空闲 |

## 7. 其他业务模块

### 7.1 打印模块 (`print/`)

策略模式实现:
- `ReceiptSettingContextHandlerSelector` — 小票模板选择
- `TemplateRowContextHandlerSelector` — 行处理器选择
- 打印类型: 结账单、厨房小票(KDS)、预订单、发票

### 7.2 KDS 模块 (`kds/`)

后厨显示屏:
- 分单策略 (按区域/商品分组)
- 泳道模式
- 制作完成标记
- 叫号通知

### 7.3 外卖/配送模块 (`takeout/` / `delivery/`)

- 外卖订单管理 (美团/饿了么/自配送)
- 配送状态跟踪
- 接单/拒单

### 7.4 预订模块 (`book/`)

- 预约订座
- 订金管理
- 预订单处理

### 7.5 小程序模块 (`service/order/wxApplet/`)

- 小程序开台
- 小程序加菜
- 小程序支付轮询
- 叫起通知

### 7.6 其他模块

| 模块 | 说明 |
|------|------|
| `cashPledge` | 餐位押金、自助餐押金 |
| `wine` | 酒水寄存/提取 |
| `soldout` | 估清设置 |
| `groupBuying` | 团购验券 |
| `shiftDaily` | 班结/日结 |
| `invoice` | 发票开具/红冲 |

## 8. 模块间依赖关系

```
开台 ──────────────────→ 桌台占用
    │
    ├──→ 订单创建 ───→ 加菜 ───→ 促销计算 ───→ 订单变更
    │                            │
    │              ┌──────────────┼──────────────┐
    │              ↓              ↓              ↓
    │           打印(KDS)      打印(结账)     打印(厨房)
    │              │
    │              └──→ 落单 ──→ 估清占用
    │
    ├──→ 结账 ───────→ 支付处理
    │                      │
    │              ┌───────┼───────┐
    │              ↓       ↓       ↓
    │           现金    扫码    会员卡
    │                            │
    │                            └──→ 积分累计
    │
    ├──→ 退款 ───────→ 支付取消 ──→ 退款处理
    │                            │
    │                            └──→ 积分回退
    │
    ├──→ 反结账 ───→ 状态恢复 ──→ 桌台恢复
    │
    └──→ 撤单 ───────→ 整单退款 ──→ 桌台清空

预订 ───→ 订金支付 ───→ 预订确认
    │
    └──→ 到店开台 ───→ 订金核销

外卖 ───→ 外卖平台接单 ───→ 制作 ───→ 配送
```
