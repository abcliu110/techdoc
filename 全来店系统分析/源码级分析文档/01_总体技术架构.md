## 3. 通信层架构

### 3.1 HTTP 请求处理流程

```
HTTP 请求 (POST /order/placeOrder)
    │
    ▼
PosServerChannelHandler.channelRead0()
    │
    ├── 判断: TextWebSocketFrame → processWebSocket()
    │                   或
    │         FullHttpRequest → processHttpRequest()
    │
    ▼
processHttpRequest():
    │
    ├── OPTIONS 预检 → 直接返回
    │
    ├── /ping → 返回机构信息
    │
    ├── 机构未注册检查 → 返回 CS001
    │
    ├── 从 registry 查找 Handler
    │   └── 未找到 → 懒加载注册
    │
    ▼
ThreadPoolConfig.asyncProcessThreadPool.execute():
    │
    ├── OperateRecordProcessor 记录操作日志
    │
    └── BaseRequestHandler.doRequest():
            │
            ├── 参数解析
            ├── 参数校验
            ├── 业务处理
            └── 返回响应
```

### 3.2 Handler 注册机制

- **时机**: `PosServerRunner.start()` 时调用 `initRequestHandler()`
- **方式**: 硬编码 `List<Class<? extends BaseRequestHandler>>`，按顺序 add
- **数量**: ~400 个 Handler
- **懒加载**: 首次请求时动态注册 (`initRequestHandler(requestInfo)`)

源码: `PosServerRunner.java:464` → `PosServerRunner.java:495` (getAllHandlers())

### 3.3 WebSocket 通信

- **协议**: Socket.IO (基于 WebSocket)
- **作用**: 小程序点餐实时通知
- **Topic**:
  - `tp_order_refresh` — 订单变更通知
  - `tp_pay_complete` — 支付完成通知

源码: `LocalServerClientMsgDataListener.java:50`

## 6. 启动流程

```java
// PosServerApplication.main()
1. 解析命令行参数 (dataPath, hostType, serverPort)
2. 设置系统属性 (dataPath, logDirectory, platformType)
3. 初始化日志 (LogConfig.initialize())
4. PosServerRunner.start()
   ├── 创建 DatabaseHelper (MySQL/SQLite)
   ├── 初始化数据库连接
   ├── SaasIniPropertiesInitHelper.init()
   ├── MessagesProperties.initMessageProperties()
   ├── initRequestHandler() — 注册 ~400 个 Handler
   ├── InterceptorRegistry.init()
   ├── ScheduleTask.init() — 定时任务
   ├── OrgBaseInfoInitHelper.init()
   └── PosServer.start() — 启动 Netty HTTP Server
```
