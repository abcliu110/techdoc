## 一、业务因果叙事（删除类名后仍可读）

### 场景：中午高峰，服务员小王在 3 号桌为 4 位客人加菜

中午 12 点，3 号桌服务员小王拿着点菜用的手持设备走过来，顾客刚确认了加的菜。小王点击"落单"，系统开始工作：

**第一步：系统查找这张桌的当前订单。**
账单号是 `billNo=TB003-20260830-001`，对应 3 号桌的未结订单。如果账单不存在，说明桌台状态异常，系统直接报错，不允许加菜。

**第二步：系统检查这些菜能否加。**
- 如果菜品设置了"估清"（当天只卖 20 份，已卖完），系统直接拒绝，提示"该菜品已估清"
- 如果同一道菜之前已经落过单（ldStatus=1），系统拒绝重复加单，防止同一道菜算两次钱
- 如果是套餐，系统检查套餐内的子菜品是否齐全

**第三步：系统重新计算这次加菜的优惠。**
加菜后订单总金额可能变化，系统调用促销引擎重新计算：
- 是否有满减活动（满100减20）？
- 是否有折扣券可用？
- 套餐是否有组合优惠？
优惠金额被重新分摊到每个菜品。

**第四步：数据库更新，落单状态锁定。**
系统在一个数据库事务内完成所有更新：
- 更新菜品明细的落单状态为"已落单"（ldStatus=1）
- 更新订单状态为"待结账"（ORDER_DJZ）
- 更新桌台状态为"待结账"（PRESETTLEMENT）
- 更新估清库存（如果启用了估清，这些菜被预占）

**第五步：厨房开始准备。**
系统打印厨房小票，KDS 屏幕上出现 3 号桌的新制作单，厨师看到后开始做菜。

**第六步：云端同步。**
系统异步将订单数据上传到云端服务器，作为备份。如果上传失败，会记录到 fail_task_records 表，等会儿重试。

### BR-ORDER-001：估清检查

| 属性 | 内容 |
|---|---|
| 规则表述 | 加菜时，如果商品的可用库存 ≤ 0，系统拒绝加菜 |
| 约束级别 | MUST |

## 五、失败恢复手册

### 场景一：估清检查失败

```
表现：用户点击"落单"后系统弹出"该菜品已估清"
原因：商品设置了每日估清数量，当日可售数量已用完
影响：订单中没有这道菜，不会进入后续流程

处理步骤：
1. 用户看到提示"该菜品今日已售完"
2. 用户决定换菜或去掉该菜品
3. 用户重新点击"落单"
4. 系统跳过估清检查的这道菜，继续处理其他菜品
5. 若所有菜品均估清，则整单无法落单
```

### 场景二：已落单商品被再次添加

```
表现：系统弹出"xxx已落单，不能重复添加"
原因：同一道菜在订单中已经被标记为已落单（ldStatus=1），用户试图再次加同一道菜
影响：订单中不会出现重复菜品，金额不会虚增

处理步骤：
1. 用户看到提示后决定是否修改数量或换菜
2. 如果需要修改数量，用户点击"改数量"重新修改
3. 如果菜品可以合并（未落单），系统会合并数量
```

### 场景三：促销计算超时

```
表现：加菜后优惠金额显示为 0 或未更新
原因：云端促销 SDK 调用超时
影响：顾客无法享受应得的优惠，可能导致客诉

处理步骤：
1. 系统自动降级到 POS 本地促销计算（type=1~4）
2. 本地促销可能比云端促销力度小
3. 如果本地促销也失败，则不加优惠
4. 异常记录到日志，运维可排查
```

### 场景四：订单上传云端失败

```
表现：加菜成功，但云端备份失败
原因：网络中断或云端服务不可用
影响：本地数据正常，云端数据可能不一致

处理步骤：
1. 系统记录失败任务到 fail_task_records 表
2. 定时任务（每日日结前）会重试所有失败任务
3. 如果日结前仍未成功，则这笔订单数据可能在云端缺失
4. 日结时会触发 soldOutSyncDailySettlementService 同步估清数据
5. 运维可手动在 fail_task_records 表中查看失败记录
```

### 场景五：打印机离线

```
表现：厨房小票未打印，KDS 屏幕无新制作单
原因：打印机离线、断纸、网络故障
影响：厨房不知道有新单，可能导致出菜延迟

处理步骤：
1. 系统检测打印机状态（PrintService 中的错误处理）
2. 如果打印机离线，系统抛出异常但不影响订单核心流程
3. 收银员应联系运维人员检查打印机
4. 修复后可在"打印管理"中重新打印厨房小票
```

## 六、快餐模式特殊处理

| 差异点 | 堂食模式 | 快餐模式 |
|---|---|---|
| 桌台绑定 | 更新桌台状态（OCCUPIED→PRESETTLEMENT） | 不更新桌台状态（无桌台概念） |
| 桌台号 | 使用真实 tableCode | 使用 billNo 后4位作为 tableCode |
| 厨房小票 | 必须打印 | 不打印 |
| 估清占用 | 正常占用 | 正常占用 |
| 促销计算 | 正常计算 | 正常计算 |
