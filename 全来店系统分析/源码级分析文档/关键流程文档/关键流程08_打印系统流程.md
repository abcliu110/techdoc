## 一、业务因果叙事

### 场景：顾客结账后，打印机吐出结账单

晚上 8 点，3 号桌顾客结完账，收银员小王点击"结账"。系统完成了以下操作后，触发打印：

- 订单状态变为"已结账"
- 支付记录生成
- 小票打印机吐出顾客联

系统是怎么知道"用哪台打印机"和"打印什么内容"的呢？

答案在 PrintTicketTypeEnum——它是一个"超级枚举"，每个枚举实例同时持有三个策略对象：打印机策略、票据构建策略、模板生成器。

---

## 二、"超级枚举"路由

```java
// 源码：print/enums/PrintTicketTypeEnum.java
// E-SRC: print/enums/PrintTicketTypeEnum.java

public enum PrintTicketTypeEnum {
    PREPARE(8001, "预结单") {
        public PrinterStrategy getPrinterStrategy() {
            return new EatInDevicePrinterStrategyImpl();
        }
        public TicketPrintStrategy getPrintDataStrategy() {
            return new BillTicketPrintStrategyImpl();
        }
    },
    MAKE(Integer.valueOf(10001), "制作单") {
        public PrinterStrategy getPrinterStrategy() {
            return new MakeTicketPrinterStrategyImpl();
        }
        public TicketPrintStrategy getPrintDataStrategy() {
            return new MakeTicketPrintStrategyImpl();
        }
    },
    // ...
}
```

路由是 O(1) 的——给定票据类型，直接调用枚举实例的方法即可找到对应策略，不需要 if-else 或 Map 查找。

## 四、失败恢复手册

### 场景一：打印机缺纸

```
表现：小票打印机吐出半张纸后停止
原因：纸张用尽或卡纸
影响：顾客联未完整打印

处理步骤：
1. 收银员在"打印管理"中重新打印结账单
2. 运维人员补充纸张
```

### 场景二：打印机离线

```
表现：打印队列中的任务全部堆积
原因：打印机断电或网络断开
影响：所有票据无法打印

处理步骤：
1. 检查打印机电源和网络连接
2. 在"设备管理"中重新连接打印机
3. 重试所有待打印任务
```
