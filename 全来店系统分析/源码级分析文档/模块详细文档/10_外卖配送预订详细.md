# 外卖/预订/配送模块详细文档

## 1. 模块概述

外卖模块管理第三方外卖平台订单（美团/饿了么），预订模块管理预约订座，配送模块管理自配送和平台配送。

**源码路径**: `takeout/` + `book/` + `delivery/`

---

### 2.2 枚举定义

#### TakeoutListTypeEnum (订单列表类型)

| code | 名称 | 说明 |

## 5. 关键发现

### 发现1: 外卖订单通过 MQTT 实时接收

第三方平台（美团/饿了么）通过 MQTT 推送订单消息，POS 本地服务订阅主题接收：
```java
// TakeoutOrderHandleService
mqttClient.subscribe("takeout/order", message -> {
    handleOrder(JSON.parseObject(message));
});
```

### 发现2: 预订开台与普通开台是不同路径

```java
// BookOrderOpenTableService — 预订到店开台
// 自动核销订金
// 绑定预订信息到订单

// OpenTableService — 普通开台
// 不涉及订金
```

### 发现3: 配送支持自配送和平台配送两种模式

```java
// DeliveryTypeEnum
SELF(0)    // 自配送，商家自行安排骑手
PLATFORM(1) // 平台配送，接入美团/饿了么配送
```
第三方配送价格通过 `ThirdDeliveryPriceListService` 获取。
