### 2.2 请求分发 (PosServerChannelHandler)

```java
// PosServerChannelHandler.channelRead0()
@Override
public void channelRead0(ChannelHandlerContext ctx, Object msg) {
    if (msg instanceof FullHttpRequest) {
        processHttpRequest(ctx, (FullHttpRequest) msg);
    }
    else if (msg instanceof TextWebSocketFrame) {
        processWebSocket(ctx, (TextWebSocketFrame) msg);
    }
}

private void processHttpRequest(ChannelHandlerContext ctx, FullHttpRequest request) {
    String uri = request.uri();

    // OPTIONS 预检 → 直接返回
    if (HttpMethod.OPTIONS.equals(request.method())) return;

    // /ping → 返回机构信息
    if ("/ping".equals(uri)) { ... return; }

    // 机构未注册检查
    if (!whiteList.contains(uri)) {
        if (!registered) return forbidden();
    }

    // 查找 Handler
    RequestInfo requestInfo = new RequestInfo(uri, method);
    BaseRequestHandler handler = registry.find(requestInfo);
    if (handler == null) {
        // 懒加载注册
        PosServerRunner.initRequestHandler(requestInfo);
        handler = registry.find(requestInfo);
    }

    // 异步处理
    ThreadPoolConfig.asyncProcessThreadPool.execute(() -> {
        handler.doRequest(ctx, request);
    });
}
```

public static <T> T execTransaction(Supplier<T> action) {
    if (isSQLite) {
        // SQLite: 手动同步锁
        synchronized (CommonBaseDaoImpl.class) {
            return TransactionManager.callInTransaction(conn, action);
        }
    } else {
        // MySQL: ORM 事务
        return TransactionManager.callInTransaction(conn, action);
    }

### 4.3 Bean 容器

```java
// PosContext — 手动 Bean 管理
public class PosContext {
    private static Map<String, Object> beans = new ConcurrentHashMap<>();

    public static <T> T getBean(Class<T> clazz) {
        String key = clazz.getName();
        if (!beans.containsKey(key)) {
            synchronized (clazz) {
                if (!beans.containsKey(key)) {
                    T instance = clazz.getDeclaredConstructor().newInstance();
                    injectFields(instance);  // 反射注入依赖
                    beans.put(key, instance);
                }
            }
        }
        return (T) beans.get(key);
    }
}
```

## 7. 关键发现

### 发现1: Handler 懒加载 + 3秒延迟

首次请求时才动态注册 Handler，且注册前有 3 秒延迟等待系统初始化。

### 发现2: SQLite 嵌套事务通过 ThreadLocal 跟踪深度

```java
// 深度 > 0 时跳过全局锁
if (transactionDepth.get() > 0) {
    return callable.call();
}
synchronized (CommonBaseDaoImpl.class) { ... }
```

### 发现3: RequestContext 通过 ThreadLocal 隔离用户上下文

```java
public class RequestContext {
    private static ThreadLocal<UserInfo> user;
    private static ThreadLocal<DeviceInfo> device;

    public static UserInfo getUser() {
        return user.get() == null ? defaultUser : user.get();
    }
}
```

异常情况返回默认用户("自助收银")，保证系统不崩溃。
