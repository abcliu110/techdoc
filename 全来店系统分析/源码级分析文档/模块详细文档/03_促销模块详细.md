# 促销模块详细文档

## 1. 模块概述

促销模块管理 KACI POS 的所有促销优惠计算，包括本地促销和云端促销的双层计算架构。

**源码路径**: `service/promotion/`

## 6. 组合优惠分摊

```java
// CombineAmountService.apportionCombinationDiscount()

// 套餐组合优惠按价格比例分摊
public void apportionCombinationDiscount(
        OrderDetail combineHead,
        List<OrderDetail> combineList,
        ExecutePromotionContext context) {

    // 计算子商品总金额
    BigDecimal totalAmount = combineList.stream()
        .map(d -> d.getSalesPrice().multiply(d.getGoodsQty()))
        .reduce(BigDecimal.ZERO, BigDecimal::add);

    // 计算组合减免金额
    BigDecimal discountAmount =
        combineHead.getSalesPrice().multiply(combineHead.getGoodsQty())
            .subtract(combineHead.getGoodsPayAmount());

    for (OrderDetail detail : combineList) {
        if (detail.getIsRefundGoods() == YES) continue;  // 跳过退款商品

        // 按价格比例分摊
        BigDecimal proportion =
            detailAmount.divide(totalAmount, 4, RoundingMode.HALF_UP);
        BigDecimal apportionAmount =
            discountAmount.multiply(proportion);

        detail.setGoodsDiscountAmount(
            detail.getGoodsDiscountAmount().add(apportionAmount));
    }
}
```

## 8. 优惠金额流向

```
orderTotalAmount (订单总金额)
    │
    ├── goodsDiscountAmount ────────── 商品级优惠
    │                                   单品折扣/特价/组合优惠
    │
    ├── orderDiscountAmount ────────── 订单级优惠
    │   (isJoinReceived = NO)         抹零/整单折扣
    │
    └── payDiscountAmount ──────────── 支付优惠
        (isJoinReceived = YES)        优惠券/积分抵扣

actualReceiptAmount (实收金额)
    └── orderTotalAmount - orderDiscountAmount - payDiscountAmount
```

## 9. 关键发现

### 发现1: 双层促销计算架构

- **POS 本地促销** (type 1-4): 直接在本地计算，无需云端参与
- **云端促销** (type > 1000): 调用 `promotionSdkClient.calr()` 执行 QLExpress 规则引擎

```java
// BaseExecutePromotionService.execute()
if (CollectionUtils.isNotEmpty(promotionList)) {
    calrEntity = this.promotionCalrService.calr(...);  // 云端计算
}
if (!posDiscountList.isEmpty()) {
    this.posDiscount(request, posDiscountList, context); // 本地计算
}
```

### 发现2: 优惠分摊的双策略

```java
// 根据子商品总金额是否为0选择分摊方式
if (combineSaleAmount.compareTo(BigDecimal.ZERO) == 0) {
    apportionCombineByGoodsQty();   // 按数量分摊
} else {
    apportionCombineByGoodsPrice(); // 按价格比例分摊
}
```

### 发现3: 促销计算上下文的多层映射

上下文对象包含三层商品映射：
- `goodsMap` — 普通商品
- `combineGoodsMap` — 套餐子商品（key = 套餐头ID）
- `tagGoodsMap` — 标签/做法商品（key = 做法ID）

支持多层嵌套: 套餐 → 套餐明细 → 标签
