# 前端Electron详细文档

## 1. 模块概述

Electron 前端采用主进程 + 渲染进程分离架构，通过 IPC 通信集成硬件驱动。

**源码路径**: `kaci-pos-front/`

```javascript
// 硬件 API 暴露到渲染进程
electron.contextBridge.exposeInMainWorld("iccard", {
  iccardInit(port),
  iccardRead(),
  iccardInitRead(port),
  iccardClose()
});

electron.contextBridge.exposeInMainWorld("rfcard", {
  rfcardInit(port, baud, block, readerType),  // 支持 acr122u / urf-r330

  rfcardBeep()

  generalSerialportFlashDiscRead()
});

electron.contextBridge.exposeInMainWorld("scale", {
  initSerialport(port, baud)
});
```

| IC 卡 (4442) | koffi FFI | 直接调用 | SZN4442 |
| RFID 卡 | koffi FFI + nfc-pcsc | DLL | ACR122U / URF-R330 |

| 刷卡碟 (讯盘) | koffi FFI | XunPanRFIDlib.dll | XunPan |
| 刷卡碟 (易创达) | serialport | 串口协议 | |
| 电子秤 | serialport | 串口协议 | |

### 4.2 IC 卡读取

```javascript
class ICCardReader {
  async readCardData(offset, length) {
    const buffer = Buffer.alloc(length);
    const result = this.MWIC.srd_4442(this.icdev, offset, length, bufferPtr);
```

### 4.3 副屏支持

```javascript
function createSecondaryWindow() {
  // 检测外接显示器
  const displays = electron.screen.getAllDisplays();
  const external = displays.find(d => d.bounds.x !== 0 || d.bounds.y !== 0);

  if (external) {
    // 创建副屏窗口
    const subWin = new BrowserWindow({
      x: external.bounds.x,
      y: external.bounds.y,
      fullscreen: true
    });
  }
}
```

## 8. 关键发现

### 发现1: 完整硬件驱动封装

主进程直接封装了多种读卡器驱动，通过统一的 IPC API 暴露给渲染进程，无需在渲染进程中直接操作硬件。

### 发现2: 加密本地存储 + MAC 绑定

设备信息通过 `electron-store` 加密存储，MAC 地址用于设备绑定，确保每个设备独立配置。

### 发现3: 双屏异显支持

自动检测外接显示器，创建全屏副屏窗口，支持双屏异显（主屏点餐 + 副屏广告）。
