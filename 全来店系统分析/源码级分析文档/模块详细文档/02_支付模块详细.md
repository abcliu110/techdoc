# 支付模块详细文档

## 1. 模块概述

支付模块管理 KACI POS 的所有支付行为，支持现金、扫码、会员卡、优惠券等多种支付方式。

**源码路径**: `service/pay/`

## 5. 支付流程 (BasePayService)

```java
// BasePayService.pay() 核心流程
public PayResponse pay(final T request) throws Exception {
    // 1. 分布式加锁
    LockUtil.lock(request.getBillNo());

    // 2. 获取订单
    final OrderMasterDO orderMaster =
        this.orderDomainService.getOrderMasterDO(request.getBillNo());

    // 3. 校验未付金额
    this.checkUnpaidAmount(orderMaster);
    if (unpaidAmount <= 0) {
        throw new BusinessException("0101010614");
    }

    // 4. 校验无进行中支付
    this.checkOrderPay(orderMaster);
    if (hasPayingPay) {
        throw new BusinessException("0101010910");
    }

    // 5. 设置支付科目
    this.setPaySubject(request);

    // 6. 事务处理
    final PayResponse response = LocalServerTransactionManager.execTransaction(() -> {
        final PayResponse payResponse = this.orderPayment(request, orderMaster);
        this.autoCheckout(orderMaster, request.getPaySubjectGroupCode());
        this.saveOrder(orderMaster);
        return payResponse;
    });

    // 7. 打印结账单
    this.print(request, orderMaster);

    // 8. 释放锁
    LockUtil.unlock(request.getBillNo());

    return response;
}
```

## 6. 自动结账逻辑

```java
// BasePayService.autoCheckout()
protected void autoCheckout(OrderMasterDO orderMaster, String paySubjectGroupCode) {
    String autoCheckout = BizBaseUtil.getOrgParamValue(
        OrgParamEnum.AFTER_PAY_AUTO_FINISH_CHECKOUT.getCode());

    // AFTER_PAY_AUTO_FINISH_CHECKOUT:
    // "0"  = DCF 挂账模式，不自动结账
    // "1"  = 全部自动结账
    // "2"  = 仅扫码支付自动结账
    // FAST_GOODS = 快餐全部自动结账

    if (isMatch(autoCheckout, orderMaster, paySubjectGroupCode)) {
        if (checkPayComplete(orderMaster, true)) {
            orderMaster.payComplete();
            followUpService.calculateObtainedPoint(orderMaster);
        }
    }
}
```

## 7. 支付完成检查

```java
// BasePayService.checkPayComplete()
public boolean checkPayComplete(OrderMasterDO orderMaster, boolean autoCheckout) {
    // 1. 检查未付金额
    if (unpaidAmount != 0) return false;

    // 2. 检查异常金额
    if (totalAmount == 0 &&
        (actualReceipt != 0 || discount != 0 || payDiscount != 0))
        return false;

    // 3. 检查无进行中支付
    if (hasPayingPay()) return false;

    // 4. 堂食正餐特殊检查
    if (isMealType(orderMaster)) {
        if (hasUnLdGoods()) {
            if (autoCheckout) return false;
            throw BusinessException("0101010954");
            // "堂食订单存在未落单商品，不允许结账"
        }
    }

    return true;
}
```

## 8. 支付取消逻辑 (PayCancelService)

PayCancelService 根据支付科目选择器分发到对应的取消处理：

```java
// PayCancelService.cancel() 分发逻辑
public PayCancelResponse cancel(PayCancelRequest request) {
    String paySubjectGroupCode = request.getPaySubjectGroupCode();

    // 1. 整单优惠不可取消
    if (MARKETING && promotionId == -1) throw "0101010912";

    // 2. 部分优惠取消 → BILL_DISCOUNT.cancel()
    if (promotionId > 0 && promotionId != 2) {
        return paySelector.select(BILL_DISCOUNT).cancel(request);
    }

    // 3. 抹零取消 → CASH.cancel()
    if (ROUNDING_AMOUNT || MANUAL_ROUND_DOWN) {
        return paySelector.select(CASH).cancel(request);
    }

    // 4. 离线支付取消 → 对应支付.cancel()
    if (CASH || BANK_CARD || OTHER_WAY || VOUCHER_KEY ||
        POSTPONE_PAYMENT || CASH_PLEDGE || MANUAL_SUPPLEMENT) {
        request.setPayId(null);  // 不查原支付记录
        return paySelector.select(paySubjectGroupCode).cancel(request);
    }

    // 5. 扫码支付取消
    if (SCAN_CARD_PAY) return scanCardService.cancel(request);

    // 6. 会员卡/礼品卡取消
    if (MEMBERSHIP_CARD) {
        if (GIFT_CARD) return giftCardTradeService.cardConsumeRollback(request);
        return memberCardTradeService.cardConsumeRollback(request);
    }

    // 7. 平台券取消
    if (VOUCHER) {
        if (SYSTEM_VOUCHER || OFFLINE_GROUP_BUYING)
            return paySelector.select(BILL_DISCOUNT).cancel(request);
        return platformCouponService.couponConsumeCancel(request);
    }
}
```

## 9. PaySelector — 策略模式

```java
// PaySelector.java — 支付方式选择器
public class PaySelector {
    private Map<String, PayInterface> map = new HashMap<>();

    public PaySelector() {
        map.put("cash", PosContext.getBean(CashPayService.class));
        map.put("bankCard", PosContext.getBean(BankCardPayService.class));
        map.put("scanCardPay", PosContext.getBean(ScanCardService.class));
        map.put("membershipCard", PosContext.getBean(MemberPayService.class));
        // ... 其他支付方式
    }

    public PayInterface select(String paySubjectGroupCode) {
        return map.get(paySubjectGroupCode.toLowerCase());
    }
}
```

调用方只需：
```java
this.paySelector.select(categoryCode).pay(request);
```

## 10. 离线支付 — 现金找零

```java
// OfflinePayService.orderPayment()
@Override
protected PayResponse orderPayment(final T request, final OrderMasterDO orderMaster) {
    // 1. 抹零处理
    this.roundingAmount(orderMaster, request.getPayAmount(), ...);

    // 2. 计算找零
    BigDecimal changeAmount = BigDecimal.ZERO;
    if (payAmount.compareTo(unpaidAmount) > 0) {
        changeAmount = payAmount.subtract(unpaidAmount);
        payAmount = unpaidAmount;
    }

    // 3. 记录找零
    orderMaster.cashPay(orderPay, changeAmount);
}

// CashPayService 额外校验
if (request.getPayAmount().compareTo(orderMaster.getUnpaidAmount()) > 0) {
    throw new BusinessException("0101010903");
    // 现金支付不能超过未付金额
}
```

| `0101010614` | 订单已支付完成 | `unpaidAmount <= 0` |

## 13. 关键发现

### 发现1: PaySelector 策略模式实现支付方式解耦

所有支付方式通过 `PaySelector` 统一选择，调用方无需关心具体实现：
```java
paySelector.select(categoryCode).pay(request);
```
新增支付方式只需在 `PaySelector` 中注册，无需修改调用方代码。

### 发现2: 离线支付不走原支付记录

离线支付取消时 `request.setPayId(null)`，不查询原支付记录，直接标记退款：
```java
// PayCancelService 第48行
request.setPayId(null);
return paySelector.select(paySubjectGroupCode).cancel(request);
```
这是因为离线支付（如现金、银行卡）没有云端流水记录，无需逆操作。

### 发现3: 支付状态与订单状态的双轨设计

```
支付状态 (PayStatus): SUCCESS / PAYMENT / FAILED
订单状态 (OrderStatus): ORDER_DJZ / ORDER_YJZ / ORDER_YQX
```
两者独立管理，`payComplete()` 同时更新两者：
```java
orderMaster.payComplete(); // → isPay=1, orderStatus=ORDER_YJZ
```
这允许处理"支付成功但订单状态未更新"等边界场景。
