# 02_数据模型总览

## 1. 核心实体 (DAO/PO)

共 **138 个 PO 类**，位于 `dao/po/` 目录。

### 1.1 订单核心实体

```
OrderMasterDO (订单主表) ← 聚合根
├── OrderDetailDO (订单明细)
├── OrderStatusDO (订单状态)
├── OrderSaleDO (订单销售信息)
├── OrderPayDO (订单支付记录)
└── OrderRefundDO (订单退款记录)
```

## 4. 双轨优惠金额体系

OrderMasterDO 中存在两套独立的优惠金额体系，通过 `isJoinReceived` 字段区分：

```
订单总金额 (orderTotalAmount)
    │
    ├── 订单优惠 (orderDiscountAmount) ─── isJoinReceived=NO 不计入实收
    │   └── 抹零、整单折扣等
    │
    ├── 支付优惠 (payDiscountAmount) ───── isJoinReceived=YES 计入实收
    │   └── 优惠券、积分抵扣等
    │
    └── 实收金额 (actualReceiptAmount) = 订单总金额 - 订单优惠 - 支付优惠
```

### 金额计算公式

```
未付金额 (unpaidAmount) = orderTotalAmount - orderDiscountAmount - payDiscountAmount - actualReceiptAmount

结账条件: unpaidAmount <= 0 且 无进行中的支付 (payStatus=PAYMENT)
```
