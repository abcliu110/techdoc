## V3.1 验证项: 订单状态枚举值 (ORDER_WJD/DJZ/YJZ/YQX)

### 验证项描述
验证 DA4 中声称的订单状态枚举值是否在源码中存在

### 源码验证步骤
1. 读取 `OrderStatusEnum.java` 源码文件
2. 对比 DA4 附录 9.1 中的枚举值列表

### 源码证据
**文件**: `kaci-pos-localserver/src/com/shouqianba/localserver/biz/common/enums/order/OrderStatusEnum.java`

```java
public enum OrderStatusEnum implements IIntegerEnum {
    ORDER_DJZ(Integer.valueOf(10), "待结账"),    // 10
    ORDER_YJZ(Integer.valueOf(20), "已结账"),    // 20
    ORDER_DTD(Integer.valueOf(29), "待退单"),    // 29
    ORDER_YTD(Integer.valueOf(30), "已退单"),    // 30
    ORDER_YCX(Integer.valueOf(40), "已冲销"),    // 40
    ORDER_YQX(Integer.valueOf(50), "已取消");   // 50
}
```

### 发现 (反例/矛盾)

| DA4 声称 | 源码实际 | 状态 |
|----------|----------|------|
| ORDER_DJZ (值10) | ORDER_DJZ (值10) | 存在 |
| ORDER_YJZ (值20) | ORDER_YJZ (值20) | 存在 |
| ORDER_YQX (值50) | ORDER_YQX (值50) | 存在 |
| ORDER_WJD | **不存在** | **反例** |
| ORDER_YTD | ORDER_YTD (值30) | 存在 |
| ORDER_DTD | ORDER_DTD (值29) | 存在 |
| ORDER_YCX | ORDER_YCX (值40) | 存在 |

**反例发现**: DA4 第 28-39 页状态机图中标注了 `ORDER_WJD`(未结单) 状态，但源码中实际不存在此枚举值。源码中对应状态为 `ORDER_DJZ`(待结账)。

### 结论
**失败** - DA4 状态机图中引入了不存在的 `ORDER_WJD` 枚举值，应为 `ORDER_DJZ`

## V3.4 验证项: DA4 声称存在但源码中找不到的规则

### 验证项描述
寻找 DA4 声称存在但源码中无法找到对应实现的规则

### 源码验证步骤
1. 扫描 DA4 中所有规则 BR-* 条目
2. 在源码中搜索对应实现

### 发现 (反例/矛盾)

**反例 1: BR-005a 规则描述不准确**

DA4 声称 (第 242 行):
> BR-005a | 加菜后更新桌台为已预结 | `PlaceOrderService.java:89-91` | 非快餐订单

源码证据:
```java
// PlaceOrderService.java L89-91
if (!isFastGoods) {
    super.updateTableStatus(orderSale, orderMaster);  // 调用父类方法
}
```

但 `updateTableStatus` 实际设置的是 `PRESETTLEMENT`(待结账) 而非 `TOSETTLEMENT`(已预结):

```java
// OrderService.java L380-405
void updateTableStatus(final OrderSale orderSale, final OrderMaster orderMaster) throws SQLException {
    // ...
    if (!TableStatusEnum.TOSETTLEMENT.getCode().equals(tableInfo.getTableStatus())) {
        tableInfo.setTableStatus(TableStatusEnum.PRESETTLEMENT.getCode());  // L403
        this.tableInfoService.updateByTableId(tableInfo);
    }
}
```

**矛盾**: DA4 声称"加菜后更新桌台为**已预结**(TOSETTLEMENT)"，实际代码设置为**待结账**(PRESETTLEMENT)。

### 结论
**失败** - BR-005a 规则描述存在严重偏差
