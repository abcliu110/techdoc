## V2-6：反例发现

### 验证项：DA2 中是否有关于 isJoinReceived 的多义性描述

**DA2 声称**：isJoinReceived 用于"是否计入实收"。

**源码验证**：

```
E-SRC验证：
$ grep -B2 -A2 "isJoinReceived" OrderPay.java | head -30
// 用于判断是否计入实收金额
if (pay.isJoinReceived() == 1) {
    actualReceipt += pay.getPayAmount();
}
// 用于判断是否参与找零计算
if (pay.isJoinReceived() == 1) {
    roundingAmount += pay.getPayAmount();
}
```

**发现**：❌ **失败**。DA2 只描述了"是否计入实收"一个语义，但源码中同时存在"是否参与找零计算"的第二个语义。两个语义混用。

**结论**：**失败** — 需要修正 DA2 的描述，isJoinReceived 是多义字段。
