## 一、业务规则（BR）

### 1.1 任务生命周期规则

| 编号 | 规则描述 | 约束级别 | 实现位置 | 违反后果 | 证据 |
|------|---------|---------|---------|---------|------|
| BR-01 | 打印任务lid由IdWorkerPlus生成，全局唯一，时间有序 | MUST | PosPrnJobServicePlus.create() | 任务创建失败，无法唯一标识 | E-001:79 |
| BR-02 | 打印任务必须关联有效的打印队列或打印机 | MUST | PosPrnJobServicePlus.create() | 任务创建失败，抛出BizException | E-001:805 |
| BR-03 | 仅SUCCESS状态的任务可以重打 | MUST | PosPrnJobServicePlus.reprint() | 拒绝重打，返回错误 | E-001:929-931 |
| BR-04 | 仅FAILED状态的任务可以删除 | MUST | PosPrnJobServicePlus.delete() | 拒绝删除，返回错误 | E-001:978-979 |
| BR-05 | 打印任务文件按日期存储，路径：{appDir}/jobs/{date}/{lid}.job | MUST | PosPrnJobServicePlus.keepToFile() | 文件无法定位，打印失败 | E-001:79 |
| BR-06 | 打印次数存储在Redis，Key格式：pos_service:pos_prn_job:count:{lid} | MUST | PosPrnJobServicePlus.incrPrnCount() | 打印次数无法统计 | E-001:1072 |
| BR-07 | 打印次数Redis过期时间15分钟 | MUST | Redis TTL配置 | 计数不准确，历史数据残留 | E-001:142 |
| BR-08 | 打印任务详情文件过期后改名为.del文件 | MUST | keepToFile() | 磁盘空间浪费，无法自动清理 | E-001:79-80 |
| BR-09 | 打印任务查询默认支持30天范围 | SHOULD | PrintJobActiveMQListener | 历史任务无法查询 | E-009:47-52 |
| BR-10 | 打印队列支持主备打印机failover | MUST | PrinterWorkerService | 主打印机故障时任务丢失 | E-001:54-59 |
| BR-11 | 打印机转移表支持动态重路由 | SHOULD | PosPrnPrinterTransfer查询 | 临时路由调整无法生效 | E-001:1042 |

## 五、配置约束

### 5.1 打印队列配置结构

```
PosPrnQueue
├── lid: Long (主键)
├── mid: Long (商户ID) ─────────────────┐
├── sid: Long (门店ID) ─────────────────┤─ 隔离边界
├── name: String (队列名称)              │
├── pcLid: Long (PC终端ID)              │
├── primaryPrinter: String (逗号分隔) ──→ PosPrnPrinter.lid[]
└── standbyPrinter: String (逗号分隔) ─→ PosPrnPrinter.lid[]
```

### 5.2 打印机配置结构

```
PosPrnPrinter
├── lid: Long (主键)
├── mid: Long (商户ID) ─────────────────┐
├── sid: Long (门店ID) ─────────────────┤─ 隔离边界
├── name: String (打印机名称)
├── pcLid: Long (PC终端ID)
├── type: PrinterTypeEnum ──────────────┐
│   ├── DRIVER: extraInfoDriver         │
│   ├── NET: extraInfoNet (IP/端口)     │─ 类型决定扩展信息结构
│   ├── COM: extraInfoCom (波特率)      │
│   └── USB/LPT: extraInfo             │
└── model: PrinterModelEnum ───────────→ PrinterBrand映射
```

### 5.3 打印机转移配置结构

```
PosPrnPrinterTransfer
├── sourcePrinterLid: Long ───→ PosPrnPrinter.lid (源)
├── targetPrinterLid: Long ───→ PosPrnPrinter.lid (目标)
├── mid: Long ─────────────────┐
└── sid: Long ────────────────┴─ 同一商户+门店生效
```

### 5.4 打印样式配置结构

```
PosPrnStyleRow
├── mid: Long
├── sid: Long
├── styleType: Integer ───┐
│                        ├── 组合唯一
├── rowIndex: Integer
├── colIndex: Integer
├── content: String (支持{@fieldName}替换)
└── style: String (字体样式)

PosPrnStyleCol
├── mid: Long
├── sid: Long
├── styleType: Integer ───┐
│                        ├── 组合唯一
├── colIndex: Integer
└── width: Integer
```

## 六、异常与恢复责任矩阵

### 6.1 硬件层异常

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|----------|----------|----------|-------------|-------------|----------|
| 打印机纸用尽 | 打印机缺纸检测 | 否 | 收银员/后厨 | 添加纸张，按键恢复 | 运维→店长 |
| 打印机卡纸 | 打印超时检测 | 否 | 收银员/后厨 | 打开机盖，取出纸张 | 运维→店长 |
| 打印机故障（FAULT） | 状态上报/发送失败 | 自动切换备用 | 运维 | 维修或更换打印机 | 店长→采购 |
| 打印机断电 | 心跳检测超时 | 否 | 运维 | 恢复电源，重新开机 | 店长→IT |

### 6.2 网络层异常

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|----------|----------|----------|-------------|-------------|----------|
| 网口打印机断线 | TCP连接失败/超时 | 否 | 运维 | 检查网线/网络配置 | 运维→网络 |
| ActiveMQ不可用 | 连接异常/重连失败 | 否 | 运维 | 检查MQ服务状态 | 运维→IT |
| Kafka不可用（云打印） | 连接异常 | 否 | 运维 | 检查Kafka服务 | 运维→IT |

### 6.3 协议层异常

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|----------|----------|----------|-------------|-------------|----------|
| ESC/POS指令不支持 | 打印机无响应/错误响应 | 否 | 运维 | 更换兼容打印机/升级固件 | 店长→采购 |
| GBK编码乱码 | 字符集不匹配 | 否 | 运维 | 配置正确字符集 | 运维→IT |
| 纸张宽度不匹配 | 打印内容错位/截断 | 否 | 运维 | 更换纸张/调整样式 | 运维 |
| 二维码生成失败 | ESC/POS指令错误 | 否 | 运维 | 检查打印机型号支持 | 运维→IT |

### 6.4 系统层异常

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|----------|----------|----------|-------------|-------------|----------|
| 打印任务文件不存在 | 文件读取返回null | 否 | 收银员/店长 | 重新创建打印任务（重打） | 运维 |
| 数据库写入失败 | 事务回滚/异常捕获 | 否 | 运维 | 检查数据库连接 | 运维→DBA |
| Redis不可用 | 连接异常 | 回退到DB计数 | 运维 | 检查Redis服务 | 运维→IT |
| 打印队列配置缺失 | 查询返回null | 否 | 店长 | 配置打印队列 | 运维 |
| 打印样式未配置 | 样式加载返回null | 否 | 店长/运维 | 配置打印样式 | 运维 |
| 消息队列消息丢失 | 任务状态PENDING但未分发 | 45分钟超时标记FAILED | 运维 | 检查MQ日志，补发消息 | 运维→IT |
| 重复打印（Virtual Thread竞争） | 锁竞争/超时 | 否 | 运维 | 观察日志，分析原因 | 运维 |

### 6.5 业务层异常

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
