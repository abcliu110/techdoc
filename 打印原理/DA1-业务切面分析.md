## 四、核心用例

### UC-1：创建打印任务

```
用例编号：UC-1
参与者：收银员、后厨系统、WMS系统
前置条件：存在有效的打印队列配置
基本流程：
  1. 业务系统调用PosPrnJobServicePlus.create()
  2. 生成lid（IdWorkerPlus）
  3. 保存任务到pos_prn_job表（status=PENDING）
  4. 序列化任务内容到.job文件
  5. 发布PrintTaskCreated消息到ActiveMQ
  6. 返回任务lid给调用方
后置条件：打印任务已创建，等待分发
异常处理：
  - 队列不存在：抛出BizException
  - 数据库写入失败：事务回滚
```

### UC-2：分发打印任务

```
用例编号：UC-2
参与者：PrintJobActiveMQListener、PrinterWorkerService
前置条件：存在PENDING状态的打印任务
基本流程：
  1. ActiveMQ监听器消费消息
  2. PrintInitMpScHandler.put(jobLid) 初始化
  3. PrintDispatchMpScHandler.put(dispatchJob) 分发
  4. 根据prnQueueLid查找打印队列
  5. 选择主打印机（失败则选备用）
  6. 调用PrinterWorkerService.handlePrnJob()
  7. 更新任务状态
后置条件：任务已分发给打印机执行
异常处理：
  - 打印机故障：自动切换备用打印机
  - 消息处理失败：重试或标记FAILED
```

### UC-3：执行本地打印

```
用例编号：UC-3
参与者：PrinterWorkerServiceLocalImpl、DriverHandler
前置条件：任务已分发到本地打印机
基本流程：
  1. 根据打印机类型选择Handler
  2. DriverHandler处理Windows驱动打印
  3. 读取.job文件获取打印内容
  4. 应用打印样式模板
  5. 生成打印指令（ESC/POS或GDI）
  6. 发送到物理打印机
  7. 轮询打印机状态确认完成
  8. 更新pos_prn_job.print=true, status=SUCCESS
后置条件：打印任务执行完成
异常处理：
  - 打印机超时：标记FAILED，更新failureReason
  - 文件不存在：标记FAILED，提示"文件已清理"
```

### UC-4：重打打印任务

```
用例编号：UC-4
参与者：收银员、管理员
前置条件：存在SUCCESS状态的打印任务
基本流程：
  1. 用户发起重打请求
  2. PosPrnJobServicePlus.reprint() 校验状态
  3. 读取原任务.job文件内容
  4. 复制任务数据创建新任务
  5. 发布PrintTaskReprinted消息
  6. 正常分发执行
后置条件：生成新的打印任务（lid不同）
异常处理：
  - 原任务文件不存在：抛出异常
  - 原任务非SUCCESS状态：拒绝重打
```

### UC-5：WMS云端打印

```
用例编号：UC-5
参与者：WMS系统、仓库管理员
前置条件：存在WMS单据数据
基本流程：
  1. WMS调用pos4cloud Feign接口
  2. WmsPrintRenderService.render() 处理
  3. 根据styleTypeCode加载打印样式模板
  4. 合并数据源到模板生成渲染行
  5. EscPosRenderService生成ESC/POS字节流
  6. 返回Base64编码的ESC/POS数据
  7. 调用方发送到云打印机
后置条件：返回渲染好的打印数据
异常处理：
  - 样式未配置：抛出BizException
  - 数据源缺失：部分渲染，返回空
```

### UC-6：打印任务状态查询

```
用例编号：UC-6
参与者：收银员、店长、运维人员
前置条件：存在打印任务
基本流程：
  1. 用户打开打印监控页面
  2. 查询pos_prn_job表（按mid/sid/lid过滤）
  3. resolveEffectiveStatus() 计算实时状态
  4. 结合Redis打印次数和文件存在性
  5. 返回任务列表和状态
后置条件：展示任务列表和实时状态
异常处理：
  - 文件已清理：显示"详情不可查"
  - 数据库异常：返回错误信息
```

### UC-7：删除打印任务

```
用例编号：UC-7
参与者：收银员、店长
前置条件：存在FAILED状态的打印任务
基本流程：
  1. 用户选择删除任务
  2. PosPrnJobServicePlus.delete() 校验
  3. 仅允许删除FAILED状态任务
  4. 从pos_prn_job表物理删除
  5. 发布PrintTaskDeleted消息
后置条件：任务从数据库移除
异常处理：
  - 非FAILED状态：拒绝删除
  - 批量删除数量不匹配：事务回滚
```

## 五、业务规则汇总

| 规则编号 | 规则内容 | 约束级别 | 证据 |
|---------|---------|---------|------|
| BR-01 | 打印任务lid由IdWorkerPlus生成，全局唯一 | MUST | E-001:79 |
| BR-02 | 打印任务必须关联有效的打印队列或打印机 | MUST | E-001:805 |
| BR-03 | 仅SUCCESS状态的任务可以重打 | MUST | E-001:929-931 |
| BR-04 | 仅FAILED状态的任务可以删除 | MUST | E-001:978-979 |
| BR-05 | 打印任务文件按日期存储，路径：{appDir}/jobs/{date}/{lid}.job | MUST | E-001:100 |
| BR-06 | 打印次数存储在Redis，Key格式：pos_service:pos_prn_job:count:{lid} | MUST | E-001:1072-1074 |
| BR-07 | 打印次数Redis过期时间15分钟 | MUST | E-001:142 |
| BR-08 | 打印任务详情文件过期后改名为.del文件 | MUST | E-001:79-80 |
| BR-09 | 打印任务查询默认支持30天范围 | SHOULD | E-009:47-52 |
| BR-10 | 打印队列支持主备打印机failover | MUST | E-004:54-59 |
| BR-11 | 打印机转移表支持动态重路由 | SHOULD | E-001:1042-1058 |
| BR-12 | 消息推送在事务提交后执行 | MUST | E-001:1114-1125 |
| BR-13 | 打印状态由print字段和status字段共同决定 | MUST | E-001:993-1012 |
| BR-14 | WMS打印仅支持GBK字符集 | MUST | E-010:65-67 |
| BR-15 | WMS打印支持58mm和80mm两种纸宽 | MUST | E-010:93-95 |
| BR-16 | 打印样式模板按mid/sid/styleType加载 | MUST | E-010:49-53 |
| BR-17 | 云打印PrinterWorkerServiceOnlineImpl为空实现 | MUST | E-015:26 |

```
                    ┌─────────────┐
                    │   PENDING   │ ◄── create()
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           ↓               ↓               ↓
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ SUCCESS  │    │  FAILED  │    │ (超时)   │
    │ 打印成功  │    │ 打印失败  │    │  FAILED  │
    └──────────┘    └────┬─────┘    └──────────┘
           ▲             │
           │             │
           └───── reprint() ──────┘
                        │
                        ↓ (创建新任务)
                   PENDING
```

## 八、数据流

### 8.1 打印任务数据流

```
[业务系统]
    │
    │ create(PosPrnJobCreateDTO)
    ↓
[pos_prn_job表] ── insert ──→ lid生成
    │
    │ 同时
    ↓
[.job文件] ── JSON序列化 ──→ 打印内容
    │
    ↓
[Redis] ── 计数初始化 ──→ count:{lid}=0
    │
    ↓
[ActiveMQ] ── Publish ──→ PrintTaskCreated
    │
    ↓
[PrintJobActiveMQListener] ── Consume
    │
    ↓
[PrinterWorkerService] ── handle
    │
    ├──→ [本地打印] DriverHandler → 物理打印机
    │                     ↓
    │              mark SUCCESS
    │
    └──→ [云打印] WmsPrintRenderService → ESC/POS Base64
```
