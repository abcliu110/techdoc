### 2.3 间接路径分析要点

#### BP-01 路径详解：业务单据 → 打印任务 → 打印队列 → 打印机

**为什么需要经过中间对象**：
1. **职责分离**：业务单据只负责发起打印，不关心打印机细节；打印队列负责路由决策
2. **配置简化**：只需为每个打印场景配置队列，而不是每种业务单据配打印机
3. **故障转移**：队列层实现主备切换，业务单据无需感知打印机故障

**如果直接关联（业务单据 → 打印机）会怎样**：
- 新增/更换打印机需修改所有关联业务单据配置
- 无法实现按场景分组（如后厨单、前台单）
- 打印机故障时无自动切换机制

**中间对象职责**：
- 打印任务：封装打印请求，记录业务上下文
- 打印队列：路由决策与容错（主备切换）

### REL-09：打印任务 → 打印队列 → 打印机（3跳间接路径，核心路径）

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-09: 打印任务 ↔ 打印机（通过打印队列间接关联，3跳）           │
├─────────────────────────────────────────────────────────────────┤
│ 【关系定义】                                                     │
│   类型：N:1（通过中间对象间接关联，运行时动态路由）              │
│   关联路径：间接（3跳），必须经过打印队列                        │
│                                                                 │
│ 【关联路径】（共 3 跳）                                          │
│   打印任务 ──指定──▶ 打印队列 ──包含──▶ 主备打印机 ──健康检查──▶ 目标打印机 │
│       │                │                 │                        │
│   prnQueueLid    primaryPrinter    PrinterStatus=NORMAL          │
│                           standbyPrinter                          │
│                                                                 │
│ 【为什么需要经过中间对象】（业务原因，至少 2 条）                │
│   1. 职责分离：业务系统只需指定"打印到哪个队列"，不关心具体      │
│      哪台打印机；队列负责路由决策，打印机细节对业务透明          │
│   2. 配置简化：只需为每个打印场景配置一个队列，而不是每种业务   │
│      配置具体打印机；新增/更换打印机只需修改队列配置             │
│   3. 故障转移：队列层实现主备切换；如果任务直连打印机，         │
│      打印机故障时无法自动切换，需要业务系统感知并处理            │
│   4. 自然分组：同一队列的打印机可以按业务分组（前台/后厨），    │
│      不同类型的打印自动路由到对应打印机                         │
│                                                                 │
│ 【如果直接关联（打印任务 → 打印机）会怎样】                      │
│   新增/更换打印机需修改所有关联任务配置；                       │
│   无法实现主备切换；打印机故障时业务系统需感知并重试；          │
│   跨业务共享打印机困难                                           │
│                                                                 │
│ 【中间对象职责】                                                │
│   打印队列：路由决策（选择哪台打印机）                          │
│             容错（主备切换）                                    │
│             抽象（业务不感知打印机细节）                        │
│                                                                 │
│ 【级联行为】                                                    │
│   删除打印任务 → 不影响队列和打印机                             │
│   删除打印队列 → 该队列下的任务无法分发（历史任务标记FAILED）   │
│   删除主打印机 → 队列自动切换到备用打印机                       │
│   删除备用打印机 → 队列只剩主打印机，容错能力降低               │
│                                                                 │
│ 【异常场景】                                                    │
│   场景1：打印任务未指定队列 → 任务创建失败（BR-02）             │
│   场景2：队列未配置主打印机 → 任务标记FAILED                    │
│   场景3：队列主打印机故障 → 2秒后自动切换到备用                 │
│   场景4：主备都故障 → 任务标记FAILED，failureReason记录        │
│   场景5：主备都忙碌（BUSY） → 任务阻塞等待                      │
│   场景6：打印机转移规则命中 → 使用转移目标替代原打印机          │
│                                                                 │
│ 【代码位置】                                                    │
│   后端：PrintJobActiveMQListener（E-009）                       │
│   后端：E-001:54-59（主备选择逻辑）                             │
│   后端：E-001:1042-1058（转移规则查询）                         │
│                                                                 │
│ 【证据】                                                        │
│   E-SRC: E-001:54-59（主备failover）                            │
│   E-SRC: E-001:805（队列存在性校验）                            │
│   E-SRC: E-001:1042-1058（打印机转移）                          │
│   E-SRC: E-004（PosPrnQueue实体）                               │
│   E-SRC: E-003（PosPrnPrinter实体）                             │
└─────────────────────────────────────────────────────────────────┘
```
