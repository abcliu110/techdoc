### 2.3 隐性契约（对象间间接路径）

> 最有价值的部分：直接路径外的间接依赖，演进时最容易破坏

| 编号 | 隐性契约 | 追溯链 | 风险 |
|------|---------|--------|------|
| EVO-T-13 | **任务状态由双字段共同决定**：print 字段与 status 字段组合出有效状态（BR-13），任何单字段改动都会破坏状态语义 | DA4 BR-13 → E-001:993-1012 | 状态机演进（加状态/改字段）必须双字段同步 |
| EVO-T-14 | **重打依赖文件生命周期**：重打必须读 .job 文件（BR-15），而文件 30 天后物理删除 → 超过 30 天的 SUCCESS 任务实际无法重打 | DA4 BR-15 + BR-08/RR-05 间接链 | 重打时限与文件保留策略耦合，是隐含的 30 天业务边界 |
| EVO-T-15 | **主备列表顺序即优先级**：逗号顺序决定 failover 优先级，配置编辑顺序影响路由结果 | E-001:54-59 选择逻辑 | 配置层并发修改顺序导致路由漂移 |
| EVO-T-16 | **转移规则先于队列路由**：转移表生效时任务重定向，绕过队列主备逻辑 | DA3 OR-06 + OR-05 路径 | 两套路由机制并存，规则优先级是隐性契约 |

## §3 进化方案（EVO-E-*）

> 每个 P0/P1 缺陷给出候选方案（含"不做"），附兼容五查、验证设计、迁移与回滚

### EVO-E-01：云打印能力补齐（对应 EVO-D-01，P0）

| 项 | 内容 |
|----|------|
| 候选 | ① 完整实现 OnlineImpl：消息转发云端打印通道（跨端打印）② **下线声明**：移除 Online 入口，三套改两套（推荐，成本最低）③ 保留空实现 + 显式"未交付"标注（现状） |
| 五查 | 数据：无影响；接口：无外部契约（内部实现类）；消息：①需新增/复用 MQ 链路；定时：无；配置：需云打印开关 |
| 验证 | ②可 A-B：下线前后业务行为对比（无调用方即为安全）；①需影子模式 |
| 迁移/回滚 | ②回滚=恢复入口；①分阶段灰度 |
| 建议 | 先取证：确认无调用方引用 OnlineImpl（E-015 范围），再定 ①/② |

### EVO-E-02：BUSY 状态超时与恢复（对应 EVO-D-02，P1）

| 项 | 内容 |
|----|------|
| 候选 | ① BUSY 设置超时（如 N 分钟），超时转 FAULT 并告警 + 人工确认恢复（推荐）② 增加打印机心跳上报，失联自动降级 |
| 五查 | 数据：状态枚举新增过渡值需兼容（枚举演进走扩展不改删）；接口：状态查询接口返回新增值需前端兼容；消息：无；定时：①需新增超时扫描任务；配置：超时参数可配置 |
| 验证 | 影子：超时逻辑开关灰度，观察告警误报率 |
| 迁移/回滚 | 功能开关控制，可随时关闭 |

### EVO-E-03：消息消费幂等（对应 EVO-D-03，P1）

| 项 | 内容 |
|----|------|
| 候选 | ① 消费时先查任务状态/打印计数（Redis 计数已存在，可复用为幂等键）② 消息去重表（业务 ID 唯一索引） |
| 五查 | 数据：无新增表（②需建表）；接口：无；消息：消费逻辑内加检查；定时：无；配置：无 |
| 验证 | ①可 A-B：重复投递测试场景对比 |
| 迁移/回滚 | 逻辑内加检查，可开关 |

### EVO-E-04：打印机状态持久化（对应 EVO-D-04，P1）

| 项 | 内容 |
|----|------|
| 候选 | ① status 字段落库（pos_prn_printer 表补列），启动时从 DB 恢复 ② 保持内存态 + 状态上报事件流（代价高） |
| 五查 | 数据：表结构变更需兼容存量行（默认值）；接口：状态查询语义不变；消息：状态变更事件（②需新链路）；定时：无；配置：无 |
| 验证 | ①可影子：双写对比（内存态 vs DB 态）一致性 |
| 迁移/回滚 | ①补列默认值，可回退 |

### EVO-E-05：主备逗号分隔演进评估（对应 EVO-D-06，P2）

| 项 | 内容 |
|----|------|
| 候选 | ① 保持现状（推荐近期）：记录触发条件（并发配置编辑、备机数量>N、按状态过滤查询）② 演进为关联表/JSON 数组：高兼容成本，需迁移存量逗号数据 |
| 五查 | 数据：存量逗号字符串迁移；接口：配置读写接口契约变化；消息：无；定时：无；配置：配置结构变化 |
| 验证 | ②必须影子：新旧存储并行，对比路由结果一致 |
| 迁移/回滚 | ②两阶段迁移（双写→切换→清理），回滚=回切旧存储 |
| 建议 | 触发条件未到前保持；触发条件到达时按本方案启动演进 |

### EVO-E-06：重打 30 天边界显性化（对应 EVO-T-14 隐性契约，P2）

| 项 | 内容 |
|----|------|
| 候选 | ① 显式声明重打时限 = 文件保留期（30 天），超期提示"已过期不可重打"（推荐，最小改动）② 延长文件保留/重打从 DB 重建内容（成本高） |
| 五查 | 数据：无；接口：重打接口返回明确错误码；消息：无；定时：无；配置：文件保留期参数 |
| 验证 | ① A-B：超期重打前后行为对比 |
| 迁移/回滚 | ①逻辑内加判断 |
