# 03 - 失败恢复

> **文档目的**：全面理解打印系统在各种异常场景下的行为和恢复机制
> **读者定位**：运维人员、SRE、需要处理打印故障的开发者

---

## 一、异常分类

### 1.1 硬件层异常

| 异常类型 | 错误码 | 典型原因 | 用户感知 |
|----------|--------|----------|----------|
| 设备离线 | `PRINTER_OFFLINE` | 打印机断电、网络断开 | 告警 + 重试 |
| 设备忙 | `PRINTER_BUSY` | 打印机正在处理上一任务 | 等待后重试 |
| 纸张用尽 | `PAPER_EMPTY` | 纸卷用完 | 告警 + 暂停该队列 |
| 卡纸 | `PAPER_JAM` | 纸张卡住 | 人工介入 |
| 打印头过热 | `HEAD_OVERHEAT` | 连续打印过长 | 暂停 + 冷却 |

### 1.2 网络层异常

| 异常类型 | 错误码 | 典型原因 | 用户感知 |
|----------|--------|----------|----------|
| 网络超时 | `NETWORK_TIMEOUT` | 网络抖动 | 重试 |
| 连接被拒 | `CONNECTION_REFUSED` | 打印机服务未启动 | 告警 + 重试 |
| 连接重置 | `CONNECTION_RESET` | 网络中间设备断开 | 重试 |

### 1.3 协议层异常

| 异常类型 | 错误码 | 典型原因 | 用户感知 |
|----------|--------|----------|----------|
| 协议错误 | `PROTOCOL_ERROR` | 指令格式错误 | 降级处理 |
| 数据超限 | `DATA_OVERFLOW` | 数据超过纸张宽度 | 分页或告警 |
| 编码错误 | `ENCODING_ERROR` | 字符编码不支持 | 替换或跳过 |

### 1.4 系统层异常

| 异常类型 | 错误码 | 典型原因 | 用户感知 |
|----------|--------|----------|----------|
| 磁盘空间不足 | `DISK_FULL` | 任务文件堆积 | 紧急清理 |
| Redis不可用 | `REDIS_UNAVAILABLE` | Redis服务故障 | 降级到纯文件模式 |
| Handler未找到 | `HANDLER_NOT_FOUND` | 未知打印机型号 | 使用默认Handler |

## 二、重试机制

### 2.1 重试策略参数

| 参数 | 默认值 | 可配置 | 说明 |
|------|--------|--------|------|
| 最大重试次数 | 3 | 是 | 超过后标记失败 |
| 第1次重试延迟 | 1分钟 | 是 | 指数退避起点 |
| 第2次重试延迟 | 2分钟 | 是 | 第1次×2 |
| 第3次重试延迟 | 4分钟 | 是 | 第2次×2 |
| 重试超时 | 10分钟 | 是 | 超过后标记失败 |

### 2.2 重试流程图

### 2.3 重试代码实现

```java
// PosPrnJobServicePlus.markFailed()
public void markFailed(long lid, String errorMsg) {
    PrintJobEntity entity = getFromFile(lid);
    entity.setJobStatus(JobStatus.FAILED);
    entity.setErrorMsg(errorMsg);
    entity.setRetryCount(entity.getRetryCount() + 1);

    // 指数退避计算
    if (entity.getRetryCount() < entity.getMaxRetries()) {
        long backoffMs = calculateBackoff(entity.getRetryCount());
        scheduleRetry(entity, backoffMs);
    } else {
        entity.setJobStatus(JobStatus.FAILED);
    }

    keepToFile(entity);
}

// 指数退避计算
private long calculateBackoff(int retryCount) {
    // 1min, 2min, 4min...
    return (long) Math.pow(2, retryCount) * 60 * 1000;
}
```

## 三、归档机制

### 3.1 归档规则

| 规则 | 说明 |
|------|------|
| 归档触发 | 失败任务创建后 24 小时 |
| 归档操作 | 移动到归档目录 |
| 归档保留 | 通常保留 7-30 天 |
| 彻底删除 | 由运维手动或定时任务清理 |

## 四、降级策略

### 4.1 降级场景与策略

| 降级场景 | 降级策略 | 影响 |
|----------|----------|------|
| 特定Handler异常 | 降级到DefaultHandler | 使用通用ESC/POS |
| Redis不可用 | 纯文件模式 | 计数功能暂不可用 |
| 样式不存在 | 使用系统默认样式 | 使用预置模板 |
| 网络打印机不可达 | 本地缓存任务 | 恢复后重试 |
| 未知打印机型号 | DefaultHandler | 尝试通用协议 |

### 4.2 Handler降级链

```
OposPrinterHandler
       │
       ▼ (失败)
EscPrinterHandler
       │
       ▼ (失败)
DefaultPrinterHandler
       │
       ▼ (失败)
标记失败 + 告警
```

## 五、监控与告警

### 5.1 监控指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| 打印失败率 | > 5% | 警告 |
| 队列积压数 | > 100 | 警告 |
| 重试次数 > 2 的任务数 | > 10 | 警告 |
| 磁盘使用率 | > 80% | 严重 |
| 打印机离线数 | > 0 | 警告 |

### 5.2 告警通知

| 告警类型 | 通知方式 |
|----------|----------|
| 打印机离线 | 前台提示 + 日志 |
| 纸张用尽 | 前台弹窗 + 声音 |
| 队列积压 | 监控面板 |
| 磁盘空间不足 | 告警 + 自动清理 |

## 六、故障恢复手册

### 场景一：打印机离线

```
1. 检查打印机电源
2. 检查网络连接（网络打印机）
3. 检查USB/串口线（本地打印机）
4. 重新配置打印机IP
5. 测试打印
```

### 场景二：打印任务丢失

```
1. 检查队列状态
2. 查看任务日志
3. 如果文件存在，手动重打
4. 如果文件不存在，确认是否归档
```

### 场景三：大量打印失败

```
1. 检查网络状况
2. 检查打印机状态
3. 查看错误日志
4. 确认是否是特定打印机问题
5. 考虑降级或切换备用打印机
```

## 7. 恢复责任矩阵

| 失败场景 | 检测方式 | 自动恢复 | 人工介入角色 | 人工介入动作 | 升级路径 |
|----------|----------|----------|-------------|-------------|----------|
| 打印机缺纸 | Worker 检测到打印失败 | 自动重试 3 次（指数退避） | 收银员 / 服务员 | 更换纸张 → 在 PrintMgr 页面点击"重打" | 无备用打印机时通知管理员 |
| 打印机卡纸 | Worker 检测到打印失败 | 自动重试 3 次 | 收银员 / 服务员 | 手动取出卡纸 → 清理滚轮 → 重打 | 频繁卡纸通知管理员维修 |
| 打印机离线 | Worker 检测到网络超时 | 主备自动切换 | 管理员 | 检查打印机网络/电源 → 确认 IP 配置正确 | 主备都离线时通知运维 |
| 打印机故障 | Worker 检测到设备无响应 | 主备自动切换 | 管理员 | 修复打印机硬件 → 测试打印 | 硬件损坏时联系供应商 |
| 任务超时（30 分钟） | 定时检测任务状态 | 强制标记 FAILED | 收银员 | 确认打印机状态 → 手动重打 | 重复超时通知管理员 |
| 队列超时（45 分钟） | 定时检测任务状态 | 强制标记 FAILED | 管理员 | 检查 Worker 进程是否运行 → 重启 Worker | Worker 频繁崩溃通知开发 |
| 云打印失败 | HTTP 请求超时 | 降级到本地打印 | 无（自动降级） | 无需介入 | 自动降级，记录降级日志 |
| 模板缺失 | 渲染时找不到模板 | 使用默认模板 | 管理员 | 在 PrintMgr 配置正确模板 | 无默认模板时通知开发 |
| 数据源为空 | 渲染时数据为空 | 打印内容部分缺失 | 管理员 | 检查数据源配置 → 修复数据 | 数据源长期异常通知开发 |

> **详细失败维度请参见 `05-对象全景卡.md` 每个核心实体的⑧失败维度**，此处不重复。
