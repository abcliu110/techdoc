## 二、关键实现

### 2.1 任务创建（PosPrnJobServicePlus.create）

```java
// 文件: nms4cloud-pos2plugin/nms4cloud-pos2plugin-biz/src/main/java/.../PosPrnJobServicePlus.java
public void create(PrintJobDTO job) {
    // 1. 生成任务ID (雪花算法)
    long lid = idGenerator.nextId();

    // 2. 构建任务实体
    PrintJobEntity entity = buildEntity(job, lid);

    // 3. 文件存储 (可靠性保障)
    //    路径: /print_jobs/{mid}/{sid}/{lid}.json
    keepToFile(entity);

    // 4. Redis计数 (性能优化)
    //    Key: prn:count:{queueLid}
    //    TTL: 15分钟
    String redisKey = "prn:count:" + job.getQueueLid();
    Long count = redisTemplate.opsForValue().increment(redisKey);
    if (count == 1) {
        redisTemplate.expire(redisKey, 15, TimeUnit.MINUTES);
    }

    // 5. 发布事件 (状态同步)
    applicationEventPublisher.publishEvent(
        new PrintTaskCreatedEvent(this, entity)
    );
}
```

### 2.2 Handler工厂（PrintHandlerFactory）

```java
// 文件: nms4cloud-pos2plugin/nms4cloud-pos2plugin-biz/src/main/java/.../PrintHandlerFactory.java
public static PrinterHandler getHandler(PrinterModelEnum model) {
    return switch (model) {
        case TSPL_TSC -> new TsplPrinterHandler();
        case ZPL_HIPPO -> new ZplPrinterHandler();
        case ESC -> new EscPrinterHandler();
        case OPOS_HIOPOS -> new OposPrinterHandler();
        case HP_PCL -> new PclPrinterHandler();
        case PDF -> new PdfPrinterHandler();
        default -> new DefaultPrinterHandler();
    };
}
```

### 2.3 虚拟线程调度（PrintScheduler）

```java
// 文件: nms4cloud-pos2plugin/nms4cloud-pos2plugin-biz/src/main/java/.../PrintScheduler.java
public class PrintScheduler {
    // Java 21 Virtual Thread
    private final ExecutorService virtualThreadPool =
        Executors.newVirtualThreadPerTaskExecutor();

    public void submit(PrintJobEntity job) {
        virtualThreadPool.submit(() -> {
            try {
                // 每个任务一个虚拟线程
                // 阻塞I/O不占用平台线程
                executeJob(job);
            } catch (Exception e) {
                markFailed(job.getLid(), e.getMessage());
            }
        });
    }

    private void executeJob(PrintJobEntity job) {
        // 1. 获取打印机
        Printer printer = printerService.getByLid(job.getPrinterLid());

        // 2. 获取Handler
        PrinterHandler handler = PrintHandlerFactory.getHandler(printer.getModel());

        // 3. 获取样式
        PrintStyle style = styleService.getByLid(job.getPrnStyleLid());

        // 4. 渲染模板
        String data = styleEngine.render(style, job.getPrintData());

        // 5. 执行打印
        handler.execute(data, printer);
    }
}
```

## 三、协议实现差异

### 3.1 七种Handler对比

| Handler | 协议 | 指令示例 | 适用场景 |
|---------|------|----------|----------|
| TsplPrinterHandler | TSPL | `SIZE 60,40\nGAP 2,0\nTEXT...` | 标签打印（芯烨/TSC） |
| ZplPrinterHandler | ZPL | `^XA^FO50,50^ADN,36,20^FD...^XZ` | 标签打印（斑马） |
| EscPrinterHandler | ESC/POS | `ESC @, ESC !, GS v 0` | 票据打印（佳博/爱普生） |
| OposPrinterHandler | OPOS | JNA调用COM对象 | 热敏票据（汉印） |
| PclPrinterHandler | PCL | HP PCL 5 命令 | 办公打印（HP） |
| PdfPrinterHandler | PDF | 生成PDF文件 | 虚拟打印 |
| DefaultPrinterHandler | ESC/POS | 通用ESC/POS | 降级方案 |

### 3.2 TSPL协议示例

```
SIZE 60,40          # 纸张尺寸 60mm x 40mm
GAP 2,0             # 标签间距 2mm
CLS                 # 清除缓冲区
CODEPAGE UTF-8      # 编码设置

# 文本
TEXT 24,24,"3",0,"Hello World"

# 条码
BARCODE 50,100,"128",50,1,0,2,2,"12345678"

# 二维码
QRCODE 100,100,M,4,A,0,"https://example.com"

PRINT 1             # 执行打印
```

### 3.3 ZPL协议示例

```
^XA                  # 开始格式
^CI28                # UTF-8编码

# 文本
^FO50,50^ADN,24,20^FDHello World^FS

# 条码
^FO50,100^BY2^BCN,100,Y,N,N^FD12345678^FS

# 二维码
^FO100,100^BQN,2,4^FDLA,https://example.com^FS

^XZ                  # 结束格式
```

## 四、数据存储

### 4.1 文件存储结构

```
/print_jobs/
└── {mid}/              # 商户ID
    └── {sid}/          # 门店ID
        ├── {lid}.json  # 打印任务文件
        ├── {lid}.json  # ...
        └── archive/    # 归档目录
            └── {lid}.json
```

### 4.3 Redis键设计

| 键模式 | 类型 | TTL | 说明 |
