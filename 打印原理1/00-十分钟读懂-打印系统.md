# 00 - 十分钟读懂打印系统

> **适用场景**：快速建立全局认知，适合新成员 onboarding 或紧急接入时的速览
> **阅读时长**：约 10 分钟
> **前置知识**：无需，但建议了解 POS 基本业务概念

---

## 一句话定义

**打印系统是 POS 的「出票工厂」**：接收收银员或后台的打印指令，从云端获取样式模板，将业务数据渲染为打印机指令，最终驱动硬件输出票据。

## 三个关键概念

### 1. 打印任务（PrintJob）

打印系统的「工单」。

```
一个打印任务包含：
├── 打印内容：订单数据（JSON）
├── 目标设备：打印机ID
├── 使用模板：样式ID
├── 队列归属：打印队列ID
└── 生命周期：待打印 → 打印中 → 完成/失败
```

**关键设计**：任务数据存储在文件中（`/print_jobs/{mid}/{sid}/{lid}.json`），Redis 记录计数（TTL 15分钟）。文件保证断电不丢，Redis 保证高速计数。

### 2. 打印样式（PrintStyle）

打印系统的「模具」。

```
样式 = 样式项列表
样式项 = 打印元素（文本、图片、条码、二维码、表格等）
```

**关键设计**：样式与协议解耦。同一个样式，在芯烨打印机上输出 TSPL 指令，在斑马打印机上输出 ZPL 指令。协议转换由 Handler 自动完成。

### 3. Handler（协议处理器）

打印系统的「翻译官」。

| Handler | 对应打印机 | 协议 | 典型品牌 |
|---------|-----------|------|----------|
| TsplPrinterHandler | 标签打印机 | TSPL | 芯烨、TSC |
| ZplPrinterHandler | 标签打印机 | ZPL | 斑马、Zebra |
| EscPrinterHandler | 票据打印机 | ESC/POS | 佳博、爱普生 |
| OposPrinterHandler | 热敏票据机 | OPOS | 汉印 |
| PclPrinterHandler | 办公打印机 | PCL | HP |
| PdfPrinterHandler | 虚拟打印 | PDF | - |
| DefaultPrinterHandler | 通用票据 | ESC/POS | 降级方案 |

## 核心流程

### 场景：结账时打印小票

```
收银员点击「结账」
       │
       ▼
┌─────────────────┐
│ CloseMpScHandler │ ← 结账业务处理器
└────────┬────────┘
         │ 创建打印任务
         ▼
┌─────────────────┐
│ PosPrnJobService│ ← 任务生成服务
│ ① 生成任务ID    │
│ ② 写入文件      │ ← 可靠性保障
│ ③ Redis计数    │ ← 性能优化
│ ④ 发布事件     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ PrintScheduler  │ ← 虚拟线程调度器
│ 每个任务一个    │
│ Virtual Thread  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ PrintHandler    │ ← 协议转换
│ 样式 → TSPL/ZPL/│
│ ESC/OPOS/PCL    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│    打印机       │ ← 硬件输出
│ 纸从机器出来    │
└─────────────────┘
```

**关键点**：
1. **异步执行**：收银员点击结账后，任务立即创建返回，打印在后台进行，不阻塞收银
2. **虚拟线程**：Java 21 虚拟线程，100 个任务同时打印只需要很少的线程资源
3. **协议解耦**：业务代码不关心打印机类型，Handler 负责协议适配

## 异常与恢复

打印系统内置多层保护：

| 层级 | 机制 | 说明 |
|------|------|------|
| 文件持久化 | JSON 文件存储 | 断电不丢任务 |
| 重试机制 | 指数退避 1min→2min→4min | 最大 3 次重试 |
| 失败归档 | 24小时后自动清理 | 释放存储空间 |
| 降级策略 | 特定协议失败时降级到 ESC/POS | 保障基本可用 |

## 快速问答

| 问题 | 答案 |
|------|------|
| 打印任务存在哪里？ | 文件系统 + Redis（双保险） |
| 支持哪些打印机？ | 7 种协议：TSPL/ZPL/ESC/OPOS/PCL/PDF/默认 |
| 打印机离线怎么办？ | 重试 3 次，每次间隔翻倍（1→2→4分钟） |
| 如何添加新票据类型？ | 在枚举中添加类型值，配置样式模板 |
| 打印卡住了怎么办？ | 查看队列积压、检查打印机状态、重打任务 |
