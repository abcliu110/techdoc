## 二、关联关系详细契约

### REL-01：菜品 ↔ 出品部门

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-01: 菜品 ↔ 出品部门                                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 【关系定义】                                                    │
│   类型：N:1（多对一）                                           │
│   方向：菜品 指向 出品部门                                      │
│                                                                 │
│ 【字段连接】                                                    │
│   菜品表.dishId → 菜品表.kitchenArea (枚举值)                   │
│                                                                 │
│ 【出品部门枚举】                                                │
│   FOR_PRN       → 出品部（一菜一单，打印到后厨）                │
│   FOR_SERVE     → 传菜间（多菜一单，汇总打印）                  │
│   FOR_PREPARATION → 配菜间（KDS配菜）                          │
│   FOR_COOK      → 制作间（KDS制作）                            │
│   FOR_PROFIT    → 利润部门（报表统计）                          │
│   (其他枚举值)   → 无打印关联                                   │
│                                                                 │
│ 【建立时机】                                                    │
│   菜品创建/编辑时指定 kitchenArea                               │
│   └─ 配置入口：商品管理 → 菜品资料 → 厨房区域字段               │
│                                                                 │
│ 【约束条件】                                                    │
│   ✓ 必填：新增菜品时必须选择出品部门                            │
│   ✓ 有效性：kitchenArea 必须在枚举值范围内                      │
│   ✓ 互斥：一个菜品只能属于一个出品部门                          │
│                                                                 │
│ 【使用方式】                                                    │
│   落单时按 kitchenArea 分组菜品                                 │
│   └─ 宫保鸡丁(kitchenArea=FOR_PRN) → 组A                       │
│   └─ 叉烧(kitchenArea=FOR_SERVE)   → 组B                       │
│                                                                 │
│ 【修改影响】                                                    │
│   修改菜品的 kitchenArea：                                      │
│   - 不影响历史订单                                              │
│   - 只影响修改后的新订单                                        │
│                                                                 │
│   删除菜品：                                                    │
│   - 历史订单保留菜品快照，不受影响                              │
│                                                                 │
│ 【代码位置】                                                    │
│   前端：商品管理页面 kitchenArea 选择器                         │
│   后端：DishService.getKitchenArea()                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### REL-02：出品部门 ↔ 打印队列

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-02: 出品部门 ↔ 打印队列                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 【关系定义】                                                    │
│   类型：1:1（一一对应）                                         │
│   方向：出品部门 指向 打印队列                                  │
│                                                                 │
│ 【字段连接】                                                    │
│   打印队列表.queueLid → 通过配置表关联出品部门                  │
│   (或：打印队列表.kitchenArea = 出品部门枚举)                   │
│                                                                 │
│ 【建立方式】                                                    │
│   方式一：在打印队列配置中指定 kitchenArea                       │
│   方式二：每个出品部门自动对应一个队列                          │
│                                                                 │
│ 【建立时机】                                                    │
│   初始化门店时自动创建 4 个队列（FOR_PRN/FOR_SERVE/             │
│   FOR_PREPARATION/FOR_COOK），或手动在 PrintMgr → 打印队列      │
│   页面配置                                                      │
│                                                                 │
│ 【约束条件】                                                    │
│   ✓ 唯一性：一个出品部门只能绑定一个队列                        │
│   ✓ 存在性：删除队列前需先解除关联                              │
│   ✓ 兼容性：不同门店可有不同的部门→队列映射                     │
│                                                                 │
│ 【使用方式】                                                    │
│   落单分组后，按 kitchenArea 查找对应队列                       │
│   └─ 组A(kitchenArea=FOR_PRN) → 查找 queueLid WHERE kitchenArea=FOR_PRN │
│                                                                 │
│ 【修改影响】                                                    │
│   修改队列的 kitchenArea：                                      │
│   - 影响后续该部门的菜品打印路由                                │
│   - 历史任务不受影响                                            │
│                                                                 │
│   删除队列：                                                    │
│   - 该部门的菜品将无法找到打印队列                              │
│   - 需要先将该部门的菜品重新分配到其他队列                      │
│                                                                 │
│ 【代码位置】                                                    │
│   后端：KitchenDisplayService.getQueueByKitchenArea()           │
│   前端：PrintMgr/PosPrnQueuePage                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### REL-03：打印队列 ↔ 打印机

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-03: 打印队列 ↔ 打印机                                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 【关系定义】                                                    │
│   类型：1:N（一对多）                                           │
│   方向：打印队列 指向 打印机                                    │
│                                                                 │
│ 【字段连接】                                                    │
│   打印机表.queueLid → 打印队列表.queueLid                       │
│                                                                 │
│ 【建立时机】                                                    │
│   方式一：创建打印机时指定 queueLid                              │
│   方式二：在打印队列页面"添加打印机"                            │
│                                                                 │
│ 【约束条件】                                                    │
│   ✓ 主备规则：一个队列只能有一台主打印机                        │
│   ✓ 备用规则：备用打印机可多台                                  │
│   ✓ 设备状态：打印机状态=在线才能分配任务                       │
│   ✓ 类型匹配：票据打印机(票据类型)只能加入票据队列              │
│   ✓ 类型匹配：标签打印机(标签类型)只能加入标签队列              │
│                                                                 │
│ 【使用方式】                                                    │
│   任务分发时按以下优先级选择打印机：                            │
│                                                                 │
│   1. 检查主打印机状态                                           │
│      ├─ 在线 → 使用主打印机                                    │
│      └─ 离线 → 继续检查                                        │
│                                                                 │
│   2. 遍历备用打印机                                             │
│      ├─ 第一台在线 → 使用该备用打印机                          │
│      └─ 全部离线 → 任务等待或报错                              │
│                                                                 │
│ 【打印流程】                                                    │
│   PrintScheduler.submit(job)                                    │
│       │                                                         │
│       ▼                                                         │
│   获取 job.queueLid                                             │
│       │                                                         │
│       ▼                                                         │
│   查询 PrintQueue.printerLids                                   │
│       │                                                         │
│       ▼                                                         │
│   遍历打印机列表（主→备）                                       │
│       │                                                         │
│       ├── 主打印机在线 → handler.execute(printer)              │
│       │                                                         │
│       └── 主打印机离线 → 尝试备用打印机                        │
│                                                                 │
│ 【修改影响】                                                    │
│   添加打印机到队列：                                            │
│   - 新打印机立即可接收任务                                      │
│                                                                 │
│   删除打印机（主）：                                            │
│   - 队列自动提升第一台备用打印机为主打印机                      │
│   - 历史任务不受影响                                            │
│                                                                 │
│   删除打印机（备）：                                            │
│   - 队列 printerLids 列表移除该打印机                          │
│   - 历史任务不受影响                                            │
│                                                                 │
│   设置打印机离线：                                              │
│   - 队列自动切换到备用打印机                                    │
│   - 离线打印机不参与任务分发                                    │
│                                                                 │
│ 【级联行为】                                                    │
│   队列删除：打印机.queueLid 置空，打印机变为"未分配"状态        │
│   打印机删除：自动从队列的 printerLids 移除                     │
│                                                                 │
│ 【代码位置】                                                    │
│   后端：PrintScheduler.getAvailablePrinter()                    │
│   后端：PosPrnQueueService.addPrinter()                         │
│   前端：PrintMgr/PosPrnQueuePage → 添加打印机弹窗               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### REL-04：菜品 ↔ 打印机（间接关联）

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-04: 菜品 ↔ 打印机                                           │
├─────────────────────────────────────────────────────────────────┤
│
│ 【关系定义】
│   类型：N:1（多对一，通过中间对象间接关联）
│   方向：菜品 指向 打印机
│   关系性质：运行时动态路由，非静态绑定
│
│ 【为什么要经过中间对象】（业务约束 - 强制要求）
│   菜品不直接绑定打印机，而是通过出品部门→打印队列→打印机路由。
│
│   业务原因：
│   1. 简化配置：只需为每个出品部门配置一个队列，而不是为每道菜单独配置打印机
│   2. 自动分组：同部门的菜品自动分发到同一打印机，无需手动关联
│   3. 动态调整：调整打印机配置时，只需修改队列层面，不影响菜品设置
│   4. 厨打语义：菜品归属部门决定了出品位置，部门→打印机映射是自然的业务边界
│
│   如果直接关联（A→C）：每道菜都需要单独指定打印机，新增/更换打印机时
│   需要修改所有相关菜品配置，无法利用"部门"这个自然业务分组
│
│ 【关联路径】（共 3 跳）
│   菜品.kitchenArea ──→ 出品部门枚举值
│           │
│           ▼
│   出品部门 ──→ 打印队列（1:1 映射）
│           │
│           ▼
│   打印队列.printerLids ──→ 打印机（1:N，主+备）
│
│ 【字段连接】
│   菜品表.kitchenArea (枚举) ──→ 打印队列表.kitchenArea
│   打印队列表.queueLid ──→ 打印机表.queueLid
│
│ 【建立时机】
│   这是一个"配置时建立 + 运行时路由"的关系：
│
│   配置时建立（3步）：
│   1. 菜品创建时：指定 kitchenArea → 菜品与出品部门关联建立
│   2. 队列配置时：在队列配置中指定对应 kitchenArea → 出品部门与队列关联建立
│   3. 队列配置时：添加打印机到队列 → 队列与打印机关联建立
│
│   运行时路由（动态）：
│   落单/结账时：根据菜品的 kitchenArea 查找对应队列，再取可用打印机
│
│ 【约束条件】
│   ✓ 路径完整性：3跳路径中任何一跳断开则无法关联
│     - 菜品未配置 kitchenArea → 无法路由
│     - kitchenArea 未配置队列 → 无法路由
│     - 队列无可用打印机 → 任务等待或失败
│   ✓ 部门语义：kitchenArea 枚举值决定了出品位置，不能随意映射
│
│ 【使用方式】
│   结账完成 → CloseMpScHandler.closeBill()
│       │
│       ▼
│   获取订单菜品列表
│       │
│       ▼
│   遍历菜品，按 kitchenArea 分组
│       │
│       ▼
│   每个分组：
│       │
│       ├── 获取 kitchenArea 对应的队列
│       │   └─ 查询 WHERE kitchenArea = ?
│       │
│       ├── 获取队列的可用打印机（主→备）
│       │   └─ 检查打印机状态，优先使用主打印机
│       │
│       └── 创建 PrintJob(printerLid=打印机.lid)
│
│ 【修改影响】
│   修改菜品的 kitchenArea：
│   - 影响该菜品在新订单中的打印目标
│   - 历史订单不受影响（任务已创建，使用快照）
│
│   修改队列配置（部门→队列映射）：
│   - 影响该部门菜品在新订单中的打印目标
│
│   修改队列的打印机列表：
│   - 影响主备切换行为
│   - 新任务使用新的打印机
│
│ 【异常场景】
│   场景1：菜品未配置 kitchenArea
│   └─ 无法找到打印队列，任务创建失败或跳过
│
│   场景2：队列无可用打印机
│   └─ 任务状态设为 PENDING，等待打印机恢复
│
│   场景3：打印机离线，自动切换到备用
│   └─ 用户可能看到菜品打到不同打印机
│
│ 【级联行为】
│   删除菜品：历史订单保留菜品快照，无影响
│   删除出品部门配置：菜品无法路由，需重新配置
│   删除队列：菜品找到不队列，无法打印
│   删除打印机：队列自动切换到备用
│
│ 【代码位置】
│   后端：KitchenDisplayService.dispatchToPrinter()
│   后端：CloseMpScHandler.createKitchenPrintJob()
│   前端：PrintMgr/PosPrnQueuePage（部门→队列配置）
│
└─────────────────────────────────────────────────────────────────┘
```

### REL-05：订单 ↔ 打印机（间接关联）

```
┌─────────────────────────────────────────────────────────────────┐
│ REL-05: 订单 ↔ 打印机                                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 【关系定义】                                                    │
│   类型：N:1（多对一，通过中间对象间接关联）                      │
│   方向：订单 指向 打印机                                        │
│                                                                 │
│ 【关联路径】                                                    │
│   订单 → 菜品 → 出品部门 → 打印队列 → 打印机                   │
│   (共 4 跳)                                                     │
│                                                                 │
│   订单.orderId                                                  │
│       │                                                         │
│       ▼                                                         │
│   订单菜品列表 → 菜品.kitchenArea                               │
│       │                                                         │
│       ▼                                                         │
│   出品部门 → 打印队列.queueLid                                  │
│       │                                                         │
│       ▼                                                         │
│   打印队列.printerLids → 打印机.printerLid                      │
│                                                                 │
│ 【特殊情况】                                                    │
│   一个订单可能有多个菜品 → 关联多个打印机                       │
│   └─ 订单A包含：宫保鸡丁(FOR_PRN) + 叉烧(FOR_SERVE)             │

│                                                                 │
│ 【建立时机】                                                    │
│   结账完成时动态建立（见 REL-04 的使用方式）                    │
│                                                                 │
│ 【约束条件】                                                    │
│   ✓ 菜品完整性：订单必须包含至少一个菜品才能打印                │
│   ✓ 路径完整性：所有菜品的打印路径必须完整（3跳不断）           │
│                                                                 │
│ 【使用方式】                                                    │
│   1. 结账客单打印：                                             │
│      └─ 使用 PrintStyle.defaultPrinterLid（直接关联）          │
│                                                                 │
│   2. 厨打票据打印：                                             │
│      └─ 按菜品分组，每组找对应打印机（间接关联）                │
```

| 对象A | 对象B | 关联字段A | 关联字段B | 中间对象 |

### 3.3 删除操作影响矩阵

| 删除对象 | 受影响的关联 | 影响描述 | 处理方式 |
|----------|-------------|----------|----------|
| 菜品 | → 订单 | 历史订单保留菜品快照 | 无需处理 |
| 出品部门 | → 打印队列 | 队列失去部门映射 | 需重新配置映射 |
| 打印队列 | → 打印机 | 打印机 queueLid 置空 | 打印机变为未分配 |
| 打印机 | → 打印任务 | 任务 printerLid 指向空 | 任务执行失败 |
| 打印机 | → 打印样式 | 样式 printerLid 置空 | 新任务走分组路由 |
| 打印样式 | → 打印任务 | 任务 prnStyleLid 指向空 | 任务渲染失败 |
| 设备 | → 打印机 | 打印机 devId 置空 | 失去设备管理能力 |
| 门店 | → 打印队列 | 队列 sid 置空或删除 | 需先删除队列 |
