## 2. 核心设计

### 2.1 异步队列设计

**设计决策**：使用内存队列 + 数据库持久化

**优点**：
- 高性能：内存队列读写快
- 可靠性：数据库持久化保证不丢失
- 简单：无需额外中间件

**缺点**：
- 单机限制：队列不能跨机器
- 重启丢失：进程重启后队列清空（但 DB 可恢复）

```java
// BlockQueueHandler 核心实现
public abstract class BlockQueueHandler<T> implements Runnable {
  private final LinkedBlockingQueue<T> blockingQueue = new LinkedBlockingQueue<>();

  @Override
  public void run() {
    while (!stopped) {
      try {
        T t = blockingQueue.take();  // 阻塞等待
        runInner(t);
      } catch (Throwable ex) {
        sleep(Duration.ofSeconds(5));
      }
    }
  }

  // 延迟放入，支持重试
  public void put(T t, long delayMillis, long timeoutNanos) {
    if (delayMillis > 0) {
      // 延迟放入实现...
    }
  }
}
```

### 2.2 工厂模式设计

**设计决策**：Handler 工厂模式

**优点**：
- 扩展性好：新增打印机类型只需添加 Handler
- 职责分离：每种打印机有独立实现
- 策略模式：运行时选择具体策略

```java
// HandlerFactory
public class HandlerFactory {
  public static PrinterHandler getHandler(int type, int model) {
    switch (type) {
      case PrinterTypeEnum.DRIVER:
        return new DriverHandler();
      case PrinterTypeEnum.NET:
      case PrinterTypeEnum.COM:
        return new PortHandler();
      case PrinterTypeEnum.USB:
      case PrinterTypeEnum.LPT:
        return new UsbLptHandler();
      case PrinterTypeEnum.JB_CLOUD:
        return new JBCloudPrinter();
      case PrinterTypeEnum.XY_CLOUD:
        return new XpCloudPrinter();
      default:
        throw new IllegalArgumentException("Unknown printer type");
    }
  }
}
```

### 2.3 状态机设计

**设计决策**：简单三状态机

```
PENDING(1) → SUCCESS(2)
PENDING(1) → FAILED(3) → 重试 → PENDING(1)
PENDING(1) → 超时 → 归档
```

**优点**：
- 简单清晰
- 易于实现和维护

**缺点**：
- 无中间状态（打印中、排队中）
- 无法追踪详细进度

## 5. 关键代码

### 5.1 PrinterWorker 核心逻辑

```java
@Override
protected void runInner(PosPrnJob job) {
  // 1. 超时检查
  if (Duration.between(jobDate, LocalDateTime.now()).toMinutes() > 30) {
    archiveFailed(mid, sid, jobLid, "Print task timeout");
    return;
  }

  // 2. 获取打印机
  PosPrnPrinter printer = getPrinter(lid);

  // 3. 检查打印机状态
  PrinterStatusEnum status = getPrinterStatus(printer);
  if (status == FAULT) {
    redirectToStandbyPrinter(job);
    return;
  }

  // 4. 执行打印
  PrinterHandler handler = HandlerFactory.getHandler(printer.getType());
  boolean success = handler.print(job.getContent(), printer.getExtraInfo());

  // 5. 结果处理
  if (success) {
    updateStatus(SUCCESS);
  } else {
    // 失败延迟10秒重试
    put(dispatchJob, 10 * 1000, 0);
  }
}
```

// PrintJobGenerator 核心方法
public void generateCustomerJob(Long mid, Long sid, Bill bill) {

## 6. 设计权衡

### 6.1 内存队列 vs 消息队列

| 选项 | 优点 | 缺点 | 选择原因 |
|------|------|------|----------|
| 内存队列 | 性能高、无额外依赖 | 重启丢失、单机 | 打印是本地操作，引入 MQ 过度设计 |
| 消息队列 | 可靠、分布式 | 需要运维、增加复杂度 | - |

### 6.2 三状态 vs 多状态

| 选项 | 优点 | 缺点 | 选择原因 |
|------|------|------|----------|
| 三状态 | 简单 | 进度不透明 | 打印操作快速，中间状态价值不大 |
| 多状态 | 进度清晰 | 复杂度高 | - |

### 6.3 单 Handler vs 多 Handler

| 选项 | 优点 | 缺点 | 选择原因 |
|------|------|------|----------|
| 多 Handler | 扩展性好 | 类多 | 打印机类型多，差异大 |
| 单 Handler | 类少 | if-else 多 | - |

## 7. 扩展点

### 7.1 新增打印机类型

1. 定义枚举值（如 `HAN_YIN = 9`）
2. 实现 `HanYinHandler implements PrinterHandler`
3. 在 `HandlerFactory.getHandler()` 添加 case
4. 在数据库配置新打印机

### 7.2 新增打印样式

1. 在 `PrnStyleTypeEnum` 添加枚举值
2. 在 `PrintJobGenerator` 添加生成方法
3. 配置打印样式表 `pos_prn_style`

### 7.3 打印前预览

- 扩展点：在 `PrinterWorker.runInner()` 前添加预览逻辑
- 可通过 AOP 或模板方法模式实现
