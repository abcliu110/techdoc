# 02 - 典型故事

> 典型使用场景 · 故事化说明
> 最后更新：2026-08-04

## 故事一：正常结账打印

### 场景描述

顾客在餐厅用餐完毕，收银员为其结账。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  17:30 收银员小李点击"结账"                                                    │
│       ↓                                                                     │
│  系统计算订单金额：原价 258 元，优惠 20 元，实收 238 元                          │
│       ↓                                                                     │
│  顾客使用微信支付 238 元                                                       │
│       ↓                                                                     │
│  支付成功，系统生成结账单打印任务                                               │
│       ↓                                                                     │
│  打印任务放入队列，PrinterWorker 立即消费                                      │
│       ↓                                                                     │
│  打印机正常，打印完成                                                          │
│       ↓                                                                     │
│  17:30:05 顾客拿到小票，结账完成                                               │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| bill_id | "ORD2026080417300001" |
| type_ | 26 (CheckOut) |
| status | SUCCESS(2) |
| finish_time | 2026-08-04 17:30:05 |
| 耗时 | 5 秒 |

## 故事二：打印机纸了

### 场景描述

顾客结账时，打印机缺纸。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  12:00 午餐高峰期                                                             │
│       ↓                                                                     │
│  收银员小王点击"结账"，顾客扫码支付                                            │
│       ↓                                                                     │
│  打印任务创建成功                                                             │
│       ↓                                                                     │
│  PrinterWorker 取到任务，执行打印                                             │
│       ↓                                                                     │
│  ❌ 打印机报错：缺纸（Paper Out）                                              │
│       ↓                                                                     │
│  打印失败，任务延迟 10 秒后放回队列                                            │
│       ↓                                                                     │
│  收银员发现打印机缺纸，装上纸                                                   │
│       ↓                                                                     │
│  10 秒后 PrinterWorker 重试                                                  │
│       ↓                                                                     │
│  ✅ 打印成功                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| status | SUCCESS(2)（最终成功） |
| 重试次数 | 2 |
| 总耗时 | 约 15 秒 |

### 用户体验

- 顾客等待时间增加约 10-15 秒
- 如果打印机长时间故障，会导致多次重试

## 故事三：主打印机坏了

### 场景描述

主打印机硬件故障，系统自动切换到备用打印机。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  19:00 晚市高峰                                                               │
│       ↓                                                                     │
│  收银员点击"结账"                                                             │
│       ↓                                                                     │
│  打印任务创建                                                                 │
│       ↓                                                                     │
│  PrinterWorker 检查主打印机状态                                               │
│       ↓                                                                     │
│  ⚠️ 主打印机状态：FAULT（故障）                                                │
│       ↓                                                                     │
│  系统查询打印队列的 standby_printer                                           │
│       ↓                                                                     │
│  找到备用打印机，切换过去                                                       │
│       ↓                                                                     │
│  ✅ 备用打印机打印成功                                                         │
│       ↓                                                                     │
│  系统记录：故障打印机需维护                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| 主打印机状态 | FAULT |
| 备用打印机 | 自动切换 |
| 打印结果 | SUCCESS |

### 用户体验

- 对收银员透明：无感知自动切换
- 顾客无感知：小票正常打印
- 需要后续维护主打印机

## 故事四：任务超时被放弃

### 场景描述

打印任务排队时间过长，超过 30 分钟阈值。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  08:00 早餐时段，门店开业                                                       │
│       ↓                                                                     │
│  收银台开始营业                                                                │
│       ↓                                                                     │
│  11:30 午餐高峰，大量订单                                                       │
│       ↓                                                                     │
│  打印队列堆积，部分任务等待时间较长                                              │
│       ↓                                                                     │
│  12:05 某任务的创建时间已达 30 分钟                                            │
│       ↓                                                                     │
│  PrinterWorker 处理该任务                                                     │
│       ↓                                                                     │
│  ⚠️ 检测到超时（> 30 分钟）                                                    │
│       ↓                                                                     │
│  系统执行 archiveFailed，任务归档                                              │
│       ↓                                                                     │
│  任务不再处理，收银员需手动重打                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| 任务创建时间 | 11:35 |
| 当前时间 | 12:05 |
| 超时阈值 | 30 分钟 |
| 处理结果 | archiveFailed |
| 归档原因 | "Print task timeout" |

### 用户体验

- 顾客可能已经离开，打印内容可能已过时
- 收银员需要主动发现并手动重打
- 建议增加超时告警

## 故事五：重打小票

### 场景描述

顾客结账后需要重新打印小票。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  17:30 顾客结账，打印小票                                                       │
│       ↓                                                                     │
│  17:35 顾客返回：小票模糊，需要重打                                              │
│       ↓                                                                     │
│  收银员在系统中找到原打印任务                                                   │
│       ↓                                                                     │
│  点击"重打"按钮                                                               │
│       ↓                                                                     │
│  POST /api/pos4cloud/pos_prn_job/reprint                                     │
│       ↓                                                                     │
│  系统创建新打印任务（复制原任务 content）                                        │
│       ↓                                                                     │
│  新任务状态 PENDING，放入打印队列                                               │
│       ↓                                                                     │
│  PrinterWorker 消费新任务                                                     │
│       ↓                                                                     │
│  ✅ 新小票打印完成                                                             │
│       ↓                                                                     │
│  系统更新原任务打印次数 +1                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| 原任务 lid | 123456789 |
| 新任务状态 | PENDING |
| 原任务打印次数 | +1 |

### 用户体验

- 重打流程简单，一键完成
- 新任务独立于原任务
- 可追溯重打记录

## 故事六：云打印机打印

### 场景描述

门店使用佳博云打印机，通过网络远程打印。

### 故事线

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  门店配置佳博云打印机                                                          │
│  extra_info: { "cloudSn": "JB123456", "cloudKey": "xxx" }                    │
│       ↓                                                                     │
│  收银员结账                                                                    │
│       ↓                                                                     │
│  生成打印任务                                                                  │
│       ↓                                                                     │
│  PrinterWorker 选择 JBCloudPrinter                                           │
│       ↓                                                                     │
│  调用佳博云打印 API                                                           │
│       ↓                                                                     │
│  API 调用成功，云打印机出纸                                                     │
│       ↓                                                                     │
│  ✅ 打印完成                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 关键数据

| 字段 | 值 |
|------|-----|
| 打印机类型 | JB_CLOUD (7) |
| Handler | JBCloudPrinter |
| 连接方式 | HTTPS API |

### 用户体验

- 无需本地连接打印机
- 支持远程门店
- 网络不稳定时可能打印延迟
