## 1. 业务背景

打印系统是餐饮 POS 系统的核心功能之一，负责将电子订单转化为纸质凭证。它连接了前台收银、厨房制作、顾客服务等多个业务环节。

### 1.1 业务目标

- **凭证提供**：为顾客、厨房、财务提供纸质凭证
- **效率提升**：减少人工传递，提高上菜速度
- **数据留存**：打印记录可追溯、可审计

### 1.2 业务范围

| 范围 | 说明 |
|------|------|
| 收银凭证 | 结账单、支付凭证 |
| 后厨通知 | 点菜单、厨房标签 |
| 会员凭证 | 充值小票、积分凭证 |
| 财务凭证 | 交班单、日报表 |

## 2. 核心业务实体

### 2.1 打印任务（PosPrnJob）

打印任务是最核心的实体，代表一次打印请求。

**关键属性**：

| 属性 | 说明 | 示例 |
|------|------|------|
| bill_id | 关联的业务单据 | 订单号 "ORD202401010001" |
| printer | 指定打印机 | 打印机 LID（可选） |
| type_ | 打印样式类型 | 10-点菜单, 26-结账单 |
| content | 打印内容 | JSON 格式的渲染数据 |
| finish_time | 完成时间 | 打印成功时记录 |

**状态流转**：

```
PENDING(1) → SUCCESS(2)  // 打印成功
PENDING(1) → FAILED(3)   // 打印失败，可重试
```

### 2.2 打印机（PosPrnPrinter）

打印机是执行打印的物理或云端设备。

**连接类型**：

| 类型 | 代码 | 说明 | 典型场景 |
|------|------|------|----------|
| DRIVER | 1 | Windows 驱动 | Windows 收银机 |
| NET | 2 | 网口打印 | 网络打印机 |
| COM | 3 | 串口打印 | 传统打印机 |
| USB | 4 | USB 打印 | USB 连接打印机 |
| LPT | 5 | 并口打印 | 老式打印机 |
| XY_CLOUD | 6 | 芯烨云打印 | 云打印机 |
| JB_CLOUD | 7 | 佳博云打印 | 云打印机 |

### 2.3 打印队列（PosPrnQueue）

打印队列管理一组打印机，实现主备切换。

```
┌─────────────────────────────────────────────────────┐
│                  打印队列                             │
├─────────────────────────────────────────────────────┤
│  primary_printer: [打印机A, 打印机B]  // 主打印机     │
│  standby_printer: [打印机C]          // 备用打印机    │
└─────────────────────────────────────────────────────┘
```

**工作规则**：
- 优先使用主打印机
- 主打印机故障时自动切换到备用打印机
- 备用打印机也可配置多个

### 2.4 打印样式（PosPrnStyle）

打印样式定义打印内容的布局模板。

**样式类型示例**：

| 类型 | 代码 | 说明 | 联次 |
|------|------|------|------|
| OrderMenu | 10 | 点菜单 | 厨房联/传菜联 |
| CheckOut | 26 | 结账单 | 顾客联 |
| FoodLabel | 52 | 标签单 | 菜品标签 |
| ShiftReport | 29 | 交班单 | 财务联 |
| MemberSavingBill | 39 | 会员充值单 | 顾客联 |

## 3. 打印场景

### 3.1 结账打印

**场景**：顾客结账时打印小票

**流程**：
1. 收银员点击"结账"
2. 系统计算金额、处理支付
3. 生成结账单打印任务
4. 打印小票给顾客

**打印内容**：
- 门店信息
- 订单号、时间
- 菜品明细
- 金额明细
- 支付信息
- 找零信息

### 3.2 厨房打印

**场景**：顾客点餐后通知厨房

**流程**：
1. 收银员完成点餐
2. 系统生成厨房打印任务
3. 厨房打印机打印点菜单
4. 厨师接单制作

**打印内容**：
- 桌号/包间
- 菜品明细
- 做法要求
- 特殊说明
- 点餐时间

### 3.3 标签打印

**场景**：打印菜品标签

**流程**：
1. 厨房完成菜品制作
2. 系统生成标签打印任务
3. 标签打印机打印
4. 贴在菜品上

**打印内容**：
- 菜品名称
- 桌号
- 制作时间
- 叫起标识

### 3.4 三联打印

典型餐饮场景的三联打印：

```
┌─────────────────────────────────────────────────────────────────┐
│                        三联打印                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第一联：厨房联                                                   │
│  ├── 收银时间                                                     │
│  ├── 桌号/包间                                                    │
│  ├── 菜品明细+做法                                                 │
│  └── 备注说明                                                     │
│                                                                 │
│  第二联：传菜联                                                   │
│  ├── 桌号/包间                                                    │
│  ├── 菜品明细                                                     │
│  ├── 叫起标识                                                     │
│  └── 点餐时间                                                     │
│                                                                 │
│  第三联：顾客联                                                   │
│  ├── 门店信息                                                     │
│  ├── 订单号                                                       │
│  ├── 菜品明细                                                     │
│  ├── 金额明细                                                     │
│  └── 支付信息                                                     │
│                                                                 │
```

## 4. 业务规则

### 4.1 打印触发规则

| 业务事件 | 打印类型 | 说明 |
|---------|---------|------|
| 点餐完成 | OrderMenu | 生成厨房联 |
| 结账完成 | CheckOut | 生成顾客联 |
| 会员充值 | MemberSavingBill | 生成充值凭证 |
| 交班操作 | ShiftReport | 生成交班单 |

### 4.2 打印机分配规则

1. **指定打印机**：任务可指定特定打印机（通过 printer 字段）
2. **队列分配**：未指定时按打印类型从对应队列获取
3. **主备切换**：主打印机故障时自动切换

### 4.3 重打规则

| 条件 | 重打行为 |
|------|---------|
| 打印失败 | 可重打 |
| 打印成功 | 可重打（生成新任务） |
| 任务超时 | 归档后不可重打 |

## 5. 业务指标

### 5.1 打印任务指标

| 指标 | 说明 | 正常范围 |
|------|------|----------|
| 待打印数 | PENDING 状态任务数 | < 100 |
| 失败率 | FAILED 任务占比 | < 5% |
| 平均打印时长 | 创建到完成时间 | < 5 秒 |
| 超时率 | 超时归档任务占比 | < 1% |

### 5.2 打印机指标

| 指标 | 说明 | 正常范围 |
|------|------|----------|
| 在线率 | 正常状态打印机占比 | > 95% |
| 故障率 | FAULT 状态次数 | < 2% |
| 故障恢复时长 | 故障到恢复平均时间 | < 30 分钟 |
