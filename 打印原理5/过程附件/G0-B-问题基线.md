## 2. 已知业务问题

### 2.1 高频问题清单

| 问题编号 | 问题描述 | 严重程度 | 备注 |
|---------|---------|---------|------|
| QB-001 | 打印机离线导致打印任务堆积 | 高 | 门店常见投诉 |
| QB-002 | 厨房联未打印导致漏单 | 高 | 影响厨房出餐效率 |
| QB-003 | 打印任务状态不同步（DB vs 文件） | 中 | 双存储机制可能导致不一致 |
| QB-004 | 主打印机故障后备用打印机未自动切换 | 中 | 需要验证 PrinterWorker 逻辑 |
| QB-005 | 重打任务与新任务冲突 | 低 | 重打逻辑待分析 |

### 2.2 问题分类

**打印机设备问题：**
- 硬件连接异常（USB/串口/网口）
- 驱动程序问题（Windows 驱动模式）
- 云打印机网络不通
- 纸张/碳带用尽

**任务管理问题：**
- 任务堆积（队列满）
- 任务丢失（文件+DB 双存储不一致）
- 状态同步延迟
- 重打逻辑复杂

**样式配置问题：**
- 条件打印配置错误
- 汇总规则不生效
- 联数配置与实际需求不符

## 3. 性能与扩展性问题

### 3.1 已知的性能瓶颈

| 瓶颈点 | 描述 | 影响 |
|--------|------|------|
| BlockQueueHandler | 使用 `LinkedBlockingQueue`，队列满时打印任务被丢弃 | 任务丢失风险 |
| 串口打印速度 | 9600 波特率限制 | 高峰期打印延迟 |
| 云打印 API 轮询 | 佳博/芯烨云打印机需轮询状态 | 网络开销 |

### 3.2 扩展性限制

| 限制点 | 描述 |
|--------|------|
| 打印机型号硬编码 | PrinterWorker 中按 model 硬编码 Handler |
| 样式系统无版本管理 | 样式变更即时生效，无法回滚 |

## 4. 技术债务

### 4.1 代码层面

| 债务项 | 位置 | 说明 |
|--------|------|------|
| Handler 类过长 | `DriverHandler.java` 834 行 | 违反 400 行软限制 |
| 魔法值 | `PrinterModelEnum` 映射 | `GP_3150TFN`、`XP_T202UA` 等 |
| 重复代码 | 多个云打印机 Handler | JBCloudPrinter、XpCloudPrinter 逻辑相似 |
| 注释缺失 | `PortHandler.java` 切纸方法 | TODO 标记未实现 |

### 4.2 架构层面

| 债务项 | 说明 |
|--------|------|
| pos2plugin vs pos10printer | 打印 Handler 在两处存在，需要合并 |
| 文件 + DB 双存储 | 增加复杂度，需要维护一致性 |
| 条件判断语法 | `{@fieldName} > 5` 类 DSL，需要文档化 |

## 5. 安全与合规

### 5.1 敏感数据风险

| 数据类型 | 风险 | 缓解措施 |
|---------|------|---------|
| 顾客小票信息 | 包含订单金额、消费明细 | 打印机日志脱敏 |
| 会员手机号 | 短信打印凭证 | API 传输加密 |

### 5.2 合规要求

- 打印内容需符合《网络安全法》个人信息保护要求
- 餐饮小票需保留电子记录（电子发票）
