## 2. 切面划分

### 2.1 切面总览

| 切面 ID | 切面名称 | 核心职责 | 入口类 |
|---------|---------|---------|--------|
| SC-001 | 任务生成 | 根据业务事件生成打印任务 | PrintJobGenerator |
| SC-002 | 任务管理 | 任务的持久化、查询、重打 | PosPrnJobServicePlus |

| SC-006 | 状态监控 | 打印机状态、任务状态监控 | PrintJobMonitor |

## 3. SC-001：任务生成切面

### 3.1 切面描述

**职责：** 将业务事件（点餐、结账、退菜等）转化为打印任务

**触发点：**
- 菜品加单（加菜）
- 订单结账
- 菜品退菜
- 菜品催菜
- 换品操作
- 转台操作

### 3.2 核心方法

| 方法 | 触发场景 | 输出 |
|------|---------|------|
| `generateCustomerJob()` | 结账完成 | 顾客联（小票） |
| `generateKitchenJob()` | 菜品提交 | 厨房联（后厨打印） |
| `generateWaiterJob()` | 菜品划菜完成 | 传菜联（传菜员） |

### 3.3 三联打印体系

**BR-001：三联打印机制**

```
┌──────────────────────────────────────────────────────────────────┐
│                         订单事件                                   │
└──────────────────────────────────────────────────────────────────┘
                              │
         ┌────────────────────┼────────────────────┐
         ↓                    ↓                    ↓
    [厨房联打印]          [传菜联打印]           [顾客联打印]
    FOR_KITCHEN          FOR_DISH_DELIVERER    FOR_CUSTOMER
         │                    │                    │
         ↓                    ↓                    ↓
    厨房打印机            传菜打印机            收银台打印机
```

**关键业务规则：**
1. 每联可配置不同打印份数
2. 厨房联根据菜品部门分发
3. 传菜联在划菜后触发
4. 顾客联在结账时触发

### 3.4 打印份数计算

| 联类型 | 方法 | 影响因素 |
|--------|------|---------|
| 顾客联 | `getNumOfCustomer()` | 结账单配置 |
| 厨房联 | `getNumOfKitchen()` | 菜品数量、做法 |
| 传菜联 | `getNumOfWaiter()` | 部门数量 |

## 4. SC-002：任务管理切面

### 4.1 切面描述

**职责：** 打印任务的持久化、状态管理、查询和重打

### 4.2 核心方法

| 方法 | 功能 | 关键行为 |
|------|------|---------|
| `create()` | 创建任务 | DB INSERT + 文件缓存 |
| `keepToFile()` | 文件存储 | JSON 持久化到本地 |
| `getFromFile()` | 文件读取 | 从本地恢复任务 |
| `markFailed()` | 标记失败 | 更新状态 + 记录原因 |
| `reprint()` | 重打 | 状态回退 + 重新入队 |

### 4.3 双存储机制

**INV-001：打印任务双存储不变量**

```
任务创建时：
  ✓ DB INSERT 成功
  ✓ File write 成功
  → 否则抛出异常

任务查询时：
  → 先查 DB 记录
  → 再从文件加载详细内容

任务删除时：
  ✓ DB DELETE (软删除)
  ✓ File DELETE
```

**关键发现：**
- `print` 字段存储在文件中，不直接存在 DB
- 文件路径推测：`{dataDir}/print_jobs/{lid}.json`

## 5. SC-003：任务分发切面

### 5.1 切面描述

**职责：** 将任务从服务层分发到打印机执行层

### 5.2 核心组件

| 组件 | 类 | 职责 |
|------|---|------|
| 任务队列 | `BlockQueueHandler` | 阻塞队列，任务按 FIFO 执行 |
| 分发器 | `PrinterWorker` | 按打印机类型选择 Handler |
| 状态机 | `PrinterWorker.runInner()` | 状态检查 → 执行 → 失败重试 |

### 5.3 任务分发流程

```
PrinterWorker.put(jobLid)
    ↓
BlockQueueHandler.offer(jobLid)
    ↓
[队列满?] → YES → 记录错误日志，任务丢弃
    ↓ NO
PrinterWorker.run() [后台线程]
    ↓
jobLid = blockingQueue.take() [阻塞等待]
    ↓
PrinterWorker.runInner(jobLid)
    ├→ getStatus() [检查打印机状态]
    │   └→ NORMAL? → NO → sleep(5s) → put(jobLid) 循环
    ├→ get(jobLid) [获取任务数据]
    ├→ handler.handle(job) [执行打印]
    └→ rmv(jobLid) [删除任务]
        └→ 失败 → sleep(10s) → put(jobLid) 重试
```

## 6. SC-004：样式渲染切面

### 6.1 切面描述

**职责：** 将打印样式定义动态渲染为实际打印内容

### 6.2 渲染要素

| 要素 | 说明 | 实现 |
|------|------|------|
| 文本内容 | 固定文本 + 变量替换 | `{@fieldName}` 语法 |
| 条件显示 | 满足条件才显示 | `displayCondition` 字段 |
| 循环分组 | 列表数据循环输出 | `GroupStart/GroupEnd` |
| 样式控制 | 字体、颜色、对齐 | `bold/italic/color/align` |

### 6.3 参数替换机制

**BR-002：参数替换语法**

```
语法：{@fieldName} 或 {$fieldName}
示例：
  {@tableName}     → 当前桌台名
  {@totalAmount}   → 订单总金额
  {@foodList}      → 菜品列表
```

**实现位置：** `PrintJobHandlerBase.replaceStrWithParas()`

### 6.4 条件判断 DSL

**BR-003：条件表达式语法**

```
格式：param operator value
示例：
  {@isVip} = 1           → VIP 会员才显示
  {@totalAmount} > 100    → 金额大于100才显示
  {@foodCount} <> 0       → 菜品数量不为0
```

**支持操作符：** `>`, `=`, `<>`, `<`
**支持类型：** String, Integer, BigDecimal, Boolean

## 10. 切面分析结论

| 切面 ID | 切面名称 | 关键发现 |
|---------|---------|---------|
| SC-001 | 任务生成 | 三联打印体系，按用途分离 |
| SC-002 | 任务管理 | DB+文件双存储，需维护一致性 |
| SC-003 | 任务分发 | BlockQueueHandler 队列满时任务丢失 |
| SC-004 | 样式渲染 | 条件 DSL 支持嵌套和循环 |
| SC-005 | 设备交互 | 8种 Handler，覆盖主流打印机 |
| SC-006 | 状态监控 | 三层监控（打印机/任务/队列） |
