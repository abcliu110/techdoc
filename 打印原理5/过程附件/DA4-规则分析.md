## 2. 任务生成规则

### 2.1 三联打印规则

**BR-001：自动三联打印规则**

| 规则 ID | 规则描述 | 触发条件 |
|---------|---------|---------|
| BR-001-1 | 厨房联自动生成 | 菜品提交时 |
| BR-001-2 | 传菜联自动生成 | 划菜完成时 |
| BR-001-3 | 顾客联自动生成 | 结账成功时 |

**份数规则：**

| 联类型 | 默认份数 | 可配置 |
|--------|---------|--------|
| 厨房联 | 1份/部门 | ✅ |
| 传菜联 | 1份/部门 | ✅ |
| 顾客联 | 1份 | ✅ |

### 2.2 任务分配规则

**BR-002：打印机分配规则**

```
IF prnPrinterLid != null THEN
    → 直接使用指定的打印机
ELSE IF prnQueueLid != null THEN
    → 从队列中选择主打印机
    → 主打印机故障时切换到备用打印机
ELSE
    → 使用默认打印机
```

**BR-003：主备切换规则**

```
1. 选择 primaryPrinter 列表中的第一台
2. 如果主打印机状态 != NORMAL
3. 则尝试 standbyPrinter 列表
4. 如果都不可用，任务进入等待队列
5. 定期重试直到成功或超时
```

## 3. 状态流转规则

### 3.1 任务状态流转

**INV-001：任务状态机**

```
                    ┌─────────────────┐
                    │                 │
                    │    PENDING      │
                    │   (待打印)       │
                    │                 │
                    └────────┬────────┘
                             │
           ┌─────────────────┼─────────────────┐
           │                 │                 │
           ↓                 ↓                 ↓
   ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
   │    SUCCESS    │  │    FAILED     │  │    PENDING    │
   │   (成功)      │  │   (失败)       │  │   (重试中)    │
   └───────────────┘  └───────────────┘  └───────────────┘
                              │                 ↑
                              │                 │
                              └───── 重打 ──────┘
```

**状态说明：**

| 状态 | Code | 进入条件 | 退出条件 |
|------|------|---------|---------|
| PENDING | 1 | 创建任务 / 重打 | 打印执行 |
| SUCCESS | 2 | 打印成功 | - |
| FAILED | 3 | 打印失败 | 重打 |

### 3.2 打印机状态流转

**INV-002：打印机状态机**

```
                ┌─────────────────┐
                │    NORMAL       │
                │   (正常)        │
                └────────┬────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        ↓                ↓                ↓
  ┌───────────┐    ┌───────────┐    ┌───────────┐
  │   FAULT   │    │   BUSY    │    │  NORMAL   │
  │  (故障)   │    │  (忙碌)   │    │  (正常)   │
  └───────────┘    └───────────┘    └───────────┘
        │                │                │
        └────────────────┴────────────────┘
                    状态恢复或人工介入
```

## 4. 样式渲染规则

### 4.1 参数替换规则

**BR-004：变量替换语法**

```
语法：{@variableName}  或  {$variableName}
替换时机：打印内容渲染时
替换来源：allParas / tmpParas
```

### 4.2 条件显示规则

**BR-005：条件表达式语法**

```
格式：param operator value
示例：
  {@isVip} = 1           → VIP会员
  {@totalAmount} > 100    → 金额>100
  {@count} <> 0           → 数量≠0
  {@name} = 'VIP'         → 字符串相等
```

**操作符支持：**

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `>` | 大于 | `{@amount} > 100` |
| `=` | 等于 | `{@type} = 1` |
| `<>` | 不等于 | `{@status} <> 0` |
| `<` | 小于 | `{@count} < 5` |

### 4.3 循环分组规则

**BR-006：列表循环语法**

```
GroupStart → [循环内容] → LoopEnd
支持嵌套：
  GroupStart
    ├→ 固定内容
    ├→ LoopStart → [循环项] → LoopEnd
    └→ GroupEnd
```

## 5. 重打规则

### 5.1 重打触发条件

**BR-007：允许重打的条件**

| 原始状态 | 重打后状态 | 说明 |
|---------|-----------|------|
| SUCCESS | PENDING | 重新入队 |
| FAILED | PENDING | 重新入队 |

**BR-008：重打限制**

```
IF 当前存在同一 bizBillId 的 PENDING 任务 THEN
    → 禁止重打（防止重复打印）
```

### 5.2 重打行为

```
重打操作：
1. 创建新的打印任务
2. 状态设为 PENDING
3. 重新入队执行
4. 原任务保留（不删除）
```

## 6. 失败处理规则

### 6.1 失败重试规则

**BR-009：打印失败重试**

```
重试策略：
1. 首次失败后 sleep(10秒)
2. 重新入队等待执行
3. 连续失败达到上限后标记 FAILED
4. 记录失败原因到 failureReason 字段
```

### 6.2 失败记录规则

**BR-010：失败原因记录**

```java
markFailed(jobLid, reason):
  1. 更新任务状态 = FAILED
  2. 记录 failureReason = reason
  3. 记录 updated_time
```

## 7. 打印分发规则

### 7.1 队列选择规则

**BR-011：队列选择优先级**

```
1. 优先使用任务指定的 prnQueueLid
2. 其次使用业务类型对应的默认队列
3. 最后使用系统默认队列
```

### 7.2 打印机选择规则

**BR-012：打印机选择逻辑**

```
PrinterWorker.runInner():
1. 检查打印机状态
   ├→ NORMAL  → 继续执行
   ├→ FAULT   → sleep(5s) → 重新入队
   └→ BUSY    → 等待
2. 获取任务数据
3. 调用 handler.handle(job)
4. 成功 → 删除任务
5. 失败 → sleep(10s) → 重新入队
```

## 8. 不变量清单

| 不变量 ID | 描述 | 验证方式 |
|-----------|------|---------|
| INV-001 | 任务状态只能是 PENDING/SUCCESS/FAILED 之一 | 枚举约束 |
| INV-002 | 打印机状态只能是 NORMAL/FAULT/BUSY 之一 | 枚举约束 |
| INV-003 | 任务 lid 全局唯一 | 雪花算法 |
| INV-004 | 打印内容不为空时才能执行打印 | 前置校验 |
| INV-005 | 文件存储与 DB 记录必须同时成功或失败 | 事务保证 |
| INV-006 | 任务只有在 PENDING 状态才能被分发 | 状态校验 |

## 9. 规则冲突与边界

### 9.1 潜在冲突

| 冲突场景 | 处理方式 |
|---------|---------|
| 主备打印机同时故障 | 任务堆积，等待恢复 |
| 重打时原任务还在执行 | 禁止重打 |
| 队列满时新任务到达 | 任务丢弃，记录错误日志 |

### 9.2 边界条件

| 边界场景 | 处理方式 |
|---------|---------|
| 无可用打印机 | 任务进入等待，轮询重试 |
| 打印内容过长 | 裁剪或换行处理 |
| 参数值为 null | 显示为空格 |
| 条件表达式格式错误 | 跳过该行，记录日志 |
