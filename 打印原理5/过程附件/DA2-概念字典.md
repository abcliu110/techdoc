## 2. 核心业务概念

### 2.1 打印任务（Print Job）

**BC-001：打印任务**

| 属性 | 说明 |
|------|------|
| 定义 | 从业务事件触发的一次打印动作 |
| 生命周期 | PENDING → SUCCESS/FAILED |
| 组成 | 任务元数据 + 打印内容 + 样式配置 |
| 存储 | DB（任务元数据）+ File（详细内容） |

**状态机：**
```
PENDING ──[打印成功]──→ SUCCESS
    │
    └──[打印失败]──→ FAILED
         │
         └──[重打]──→ PENDING（循环）
```

### 2.2 打印联（Print Purpose）

**BC-002：打印联**

| 概念 | 说明 | 触发时机 |
|------|------|---------|
| 厨房联 | 后厨制作凭证 | 菜品提交 |
| 传菜联 | 传菜员划菜凭证 | 划菜完成 |
| 顾客联 | 顾客收银小票 | 结账完成 |

**关系：** 一个业务事件（如结账）可能同时触发多联打印

### 2.3 打印样式（Print Style）

**BC-003：打印样式**

| 属性 | 说明 |
|------|------|
| 定义 | 打印内容的布局、格式、条件配置 |
| 粒度 | 样式类型（PrnStyleTypeEnum）→ 样式行（PosPrnStyleRow） |
| 配置方式 | 后台管理界面配置 |

**样式类型分类：**

| 分类 | 示例 | 说明 |
|------|------|------|
| 订单类 | OrderMenu, CheckOut | 点餐、结账相关 |
| 厨房类 | FoodLabel, HurryMenu | 后厨制作相关 |
| 报表类 | ShiftReport, YingYeReport | 统计报表 |
| 会员类 | MemberSavingBill, SMS_* | 会员相关 |
| WMS类 | WMS_ST_BILL_* | 仓储单据 |

### 2.4 打印队列（Print Queue）

**BC-004：打印队列**

| 属性 | 说明 |
|------|------|
| 定义 | 关联到同一业务场景的打印机组 |
| 核心属性 | primaryPrinter（主）、standbyPrinter（备） |
| 用途 | 实现打印机的冗余备份 |

**关键设计：** 主备打印机以逗号分隔字符串存储（LID 列表）

### 2.5 打印机（Printer）

**BC-005：打印机**

| 属性 | 说明 |
|------|------|
| 定义 | 物理或虚拟的打印设备 |
| 连接类型 | Driver / NET / COM / USB / LPT / Cloud |
| 状态 | NORMAL / FAULT / BUSY |

## 3. 业务操作概念

### 3.1 打印触发事件

| 事件 | 说明 | 触发联 |
|------|------|--------|
| 加菜 | 新增菜品 | 厨房联 |
| 退菜 | 取消菜品 | 退菜单 |
| 催菜 | 催促制作 | 催菜单 |
| 结账 | 完成支付 | 顾客联 |
| 划菜 | 菜品完成 | 传菜联 |
| 换品 | 更换菜品 | 换品单 |
| 转台 | 菜品转桌 | 转台单 |

### 3.2 打印操作

| 操作 | 说明 | 业务影响 |
|------|------|---------|
| 重打 | 重新执行已完成的打印任务 | 生成新任务 |
| 补打 | 补充打印遗漏的联 | 新任务 |
| 撤销 | 取消待打印任务 | 软删除任务 |

## 4. 数据概念

### 4.1 任务数据

| 概念 | 说明 | 字段 |
|------|------|------|
| 业务单据 ID | 关联的订单/账单 | bizBillId |
| 样式类型 | 打印样式分类 | type_ |
| 用途 | 打印联类型 | purpose |
| 打印份数 | 实际打印份数 | prnCount |
| 打印时间 | 实际打印时间 | printAt |
| 失败原因 | 打印失败原因 | failureReason |

### 4.2 样式数据

| 概念 | 说明 | 字段 |
|------|------|------|
| 数据源 ID | 样式关联的数据源 | dsId |
| 显示条件 | 控制行是否显示 | displayCondition |
| 条件操作符 | 条件比较方式 | conditionOperator |
| 条件值 | 条件比较的目标值 | conditionValue |
| 汇总标识 | 是否为汇总行 | summarize |

### 4.3 设备数据

| 概念 | 说明 | 字段 |
|------|------|------|
| 打印机类型 | 连接方式 | type |
| 打印机型号 | 具体型号 | model |
| 驱动名称 | Windows 驱动名 | extraInfoDriver.driver |
| 串口配置 | 波特率等 | extraInfoCom.baudRate |
| 网络配置 | IP 地址等 | extraInfoNet |

## 5. 枚举概念映射

### 5.1 任务状态枚举（PrnJobStatusEnum）

| 枚举值 | Code | 说明 | 业务含义 |
|--------|------|------|---------|
| PENDING | 1 | 待打印 | 任务已创建，等待执行 |

| FAILED | 3 | 失败 | 打印异常 |

## 7. 术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 打印任务 | Print Job | 一次打印动作的抽象 |
| 打印联 | Print Purpose | 同一业务的多种打印用途 |
| 打印样式 | Print Style | 打印内容的格式配置 |
| 打印队列 | Print Queue | 打印机组的抽象 |
| 打印机 | Printer | 物理打印设备 |
| 任务分发 | Task Dispatch | 从服务到打印机的任务路由 |
| 样式渲染 | Style Render | 动态内容替换和条件判断 |
| 条件打印 | Conditional Print | 满足条件才打印 |
| 重打 | Reprint | 重新执行已完成的任务 |
| 云打印 | Cloud Print | 通过云服务商远程打印 |
