# 数学学习软件测试与验收方案

## 1. 测试层级

### 单元测试

覆盖评分、星级、步骤状态机、提示策略、错误诊断、成就条件和内容校验。

### 集成测试

覆盖应用用例与数据库仓储的交互、事务、迁移和幂等结算。

### 组件测试

覆盖交互组件的输入、反馈、禁用、重置、键盘和无障碍行为。

### 端到端测试

覆盖新用户初始化、选择思想、完成学习、刷新恢复、查看报告、进入复习和成就解锁。

## 2. 关键验收场景

1. 学生完成一个单元并关闭应用，重新打开后进度和证据仍存在。
2. 同一提交按钮快速点击多次，只生成一次有效结算。
3. 数据库在结算中失败时，系统不显示完成，并可重试恢复。
4. 学生答对但无法解释时，报告将其标记为程序性掌握而非迁移掌握。
5. 学生在新情境中使用同一思想成功，能力画像获得迁移证据。
6. 错误答案触发针对性提示和补救活动，不只显示“错误”。
7. 内容缺少正确答案、步骤 ID 重复或类型不匹配时，内容校验失败。
8. 新增步骤渲染器后，旧页面和旧知识点无需修改即可继续工作。

## 3. 内容验收

每个学习单元必须有核心思想、目标、正例、反例、边界、迁移任务、常见误解和评价证据；数学专家和教研专家审核通过后才能发布。

## 4. 质量门禁

```text
typecheck 通过
lint 通过
内容校验通过
领域测试通过
集成测试通过
主流程端到端测试通过
生产构建通过
```

任何 P0 数据一致性问题、错误内容或无法恢复的学习流程问题都阻止发布。
