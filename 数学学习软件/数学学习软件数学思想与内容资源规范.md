# 数学学习软件数学思想与内容资源规范

## 1. 内容资源的最小单位

每个学习单元必须声明：

```text
id
version
适用年级
所属领域
核心数学思想
关联思想
学习目标
前置经验
情境
活动序列
提示序列
正例
反例
边界案例
常见错误
迁移任务
反思问题
评价证据
```

## 2. 数学思想标签

思想标签应使用受控词表，不允许同义词泛滥。核心标签包括抽象、数形结合、分类、归纳、演绎、转化、化归、整体部分、单位统一、方程、函数、估算、建模、逆向、反例、验证和推理。

## 3. 内容质量要求

- 每个结论至少有一个直观来源和一个符号表达。
- 每个重要概念至少包含正例、反例和边界。
- 每个算法都必须说明意义、条件和可迁移范围。
- 不能只提供标准答案，必须提供解释路径。
- 迁移任务不能只是替换数字，至少改变情境、表示或问题结构之一。
- 提示必须逐级减少思考负担，而不是直接给答案。

## 4. 内容审核清单

数学专家审核正确性、概念边界和反例；教研专家审核学习目标、认知负荷和年龄适配；产品专家审核交互可理解性；技术人员审核 schema、渲染和评分可实现性。

## 5. 版本规则

内容修改必须增加版本号。学习记录保存内容版本。已开始的会话固定使用开始时的版本，避免中途内容变化导致结果不可解释。
