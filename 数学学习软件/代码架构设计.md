## 一、现状分析

### 1.1 当前架构概述

项目采用 React + TypeScript + Vite 技术栈，基于"理解六步法"教学框架构建数学学习软件。

│   ├── ConcreteStep.tsx      # 具象操作步骤
│   ├── AlgebraConcreteStep.tsx # 代数具象操作步骤
│   ├── PictorialStep.tsx      # 图示表达步骤
│   ├── SymbolicStep.tsx       # 符号表示步骤
│   ├── ApplicationStep.tsx    # 灵活应用步骤
│   ├── ReflectionStep.tsx     # 反思内化步骤
│   ├── SplitCircle.tsx        # 饼图可视化组件
│   └── BoxGuess.tsx           # 猜数游戏组件

## 二、核心问题分析

### 2.1 问题一：步骤组件与可视化组件紧耦合

**现状问题：**

```typescript
// ConcreteStep.tsx - 硬编码使用 SplitCircle
const SplitCircle = (
  denominator={denominator}
  interactive={true}
  onSplitComplete={handleSplitComplete}
/>
```

```typescript
// AlgebraConcreteStep.tsx - 硬编码使用 BoxGuess
<BoxGuess
  targetNumber={targetNumber}
  expression={`x + ${first} = ${result}`}
  onComplete={handleBoxComplete}
/>
```

**问题本质：**
- `ConcreteStep` 只支持 `SplitCircle` 可视化
- `AlgebraConcreteStep` 只支持 `BoxGuess` 可视化
- 未来需要 `GridFill`（面积图）、`BalanceScale`（方程天平）等新可视化时，需要继续添加专用组件

**影响：**
- 组件数量随可视化类型线性增长
- 无法复用同一种可视化于不同知识点

### 2.2 问题二：数据无法声明所需可视化

**现状问题：**

```typescript
// fraction-basics.ts - 数据中无法指定可视化类型
content: {
  type: 'concrete',
  scenario: { ... },
  interaction: {
    kind: 'split',  // 只能声明交互类型
    target: '把披萨平均分成2等份'
  }
}
```

**问题本质：**
- `kind: 'split'` 只是一种语义标记
- 组件内部通过硬编码逻辑决定使用哪个可视化组件
- 数据配置无法控制最终渲染的可视化类型

**影响：**
- 非程序员无法通过修改数据来使用不同的可视化
- 新增可视化需要同时修改组件代码

### 2.3 问题三：岛屿注册需要手动维护

**现状问题：**

```typescript
// index.ts - 手动导入和注册
import { fractionBasicsKnowledgePoint } from './fraction-basics';
import { algebraBasicsKnowledgePoint } from './algebra-basics';
import { chickenRabbitKnowledgePoint } from './chicken-rabbit-new';

export const numberIsland: Island = {
  points: [
    fractionBasicsKnowledgePoint,
    algebraBasicsKnowledgePoint,
    // ... 手动添加
  ]
};
```

**问题本质：**
- 每新增一个知识点文件，需要修改 `index.ts`
- 无法自动发现和加载新的知识点模块
- 知识点文件分布在多个子文件中

**影响：**
- 添加新知识点需要修改基础设施代码
- 容易遗漏注册步骤
- 不利于团队协作（可能产生冲突）

### 2.4 问题四：步骤渲染的 switch 语句膨胀

**现状问题：**

```typescript
// Learn.tsx - renderStep 函数
const renderStep = () => {
  switch (currentStep.type) {
    case 'concrete':
      return isAlgebra
        ? <AlgebraConcreteStep {...stepProps} />
        : <ConcreteStep {...stepProps} />;
    case 'pictorial':
      return <PictorialStep {...stepProps} />;
    case 'verbal':
      return <VerbalStep {...stepProps} />;
    case 'symbolic':
      return <SymbolicStep {...stepProps} />;
    case 'application':
      return <ApplicationStep {...stepProps} />;
    case 'reflection':
      return <ReflectionStep {...stepProps} />;
    default:
      return <div>未知步骤类型</div>;
  }
};
```

**问题本质：**
- 所有步骤类型集中在一个 switch 中
- 未来新增步骤类型或变体时，函数会持续膨胀
- `isAlgebra` 这种临时判断说明已有类型的内部分支

**影响：**
- 代码可维护性下降
- 不支持步骤类型的插件化扩展

### 2.5 问题五：步骤组件 Props 接口不统一

**现状问题：**

```typescript
// 7个步骤组件，Props 接口各异
interface ConcreteStepProps { content: ConcreteContent; step; onComplete; onHint; }
interface PictorialStepProps { content: PictorialContent; step; onComplete; onHint; }
// ...
// ApplicationStep 内部还有额外逻辑
const currentVariant = content.variants[currentVariantIndex];
```

**问题本质：**
- 虽然 Props 结构相似，但类型各不相同
- 无法统一管理不同步骤的渲染逻辑
- `application` 步骤内部需要管理多题目状态

**影响：**
- 难以构建通用的步骤包装器
- 状态管理逻辑分散在各个组件中

## 三、架构设计目标

### 3.1 设计原则

1. **数据驱动**：可视化组件由数据配置声明，而非硬编码
2. **插件化**：新增知识点或可视化类型无需修改核心代码
3. **类型安全**：TypeScript 类型系统完整覆盖所有场景
4. **渐进增强**：保持向后兼容，支持渐进迁移

### 3.2 架构愿景

### 4.1 可视化组件注册表模式

**设计思路：**

将可视化组件从硬编码改为注册表模式，数据文件通过 `visualType` 字段声明所需的可视化组件。

**注册表实现：**

```typescript
// src/components/visualizations/registry.ts

import type { VisualizationComponent, VisualizationProps } from './types';

/**
 * 可视化组件注册表
 * 使用单例模式，支持运行时注册
 */
class VisualizationRegistry {
  private registry: Map<string, VisualizationComponent> = new Map();
  
  /**
   * 注册可视化组件
   */
  register<P extends VisualizationConfig>(
    component: VisualizationComponent<P>
  ): void {
    if (this.registry.has(component.type)) {
      console.warn(`[VisualizationRegistry] 组件 ${component.type} 已被注册，将被覆盖`);
    }
    this.registry.set(component.type, component as VisualizationComponent);
  }
  
  /**
   * 获取可视化组件
   */
  get(type: string): VisualizationComponent | undefined {
    return this.registry.get(type);
  }
  
  /**
   * 检查组件是否存在
   */
  has(type: string): boolean {
    return this.registry.has(type);
  }
  
  /**
   * 获取所有已注册的组件类型
   */
  getRegisteredTypes(): string[] {
    return Array.from(this.registry.keys());
  }
  
  /**
   * 根据类型渲染组件
   */
  render<P extends VisualizationConfig>(
    type: string,
    props: Omit<VisualizationProps<P>, 'visualType'>
  ): React.ReactElement | null {
    const component = this.get(type);
    if (!component) {
      console.error(`[VisualizationRegistry] 未找到可视化组件: ${type}`);
      return null;
    }
    
    return React.createElement(component.Component, {
      ...props,
      visualType: type
    } as VisualizationProps<P>);
  }
}

// 导出单例
export const visualizationRegistry = new VisualizationRegistry();

// 便捷的注册装饰器
export function registerVisualization<P extends VisualizationConfig>(
  type: string,
  defaultConfig?: Partial<P>
) {
  return function <C extends VisualizationComponent<P>>(
    Component: C
  ): C {
    Component.type = type;
    Component.defaultConfig = defaultConfig;
    visualizationRegistry.register(Component);
    return Component;
  };
}
```

### 4.2 统一步骤渲染器模式

**设计思路：**

将 `Learn.tsx` 中的 switch 语句重构为注册表模式，支持步骤类型的插件化扩展。

**核心接口：**

import type { StepType, StepContent } from '../../data/math/types';
import type { StepRenderer, StepRendererProps } from './types';

/**
 * 步骤渲染器注册表
 */
class StepRendererRegistry {
  private registry: Map<StepType, StepRenderer> = new Map();
  
  register<C extends StepContent>(
    renderer: StepRenderer<C>
  ): void {
    if (this.registry.has(renderer.stepType)) {
      console.warn(`[StepRendererRegistry] ${renderer.stepType} 已被注册`);
    }
    this.registry.set(renderer.stepType, renderer as StepRenderer);
  }
  
  get(type: StepType): StepRenderer | undefined {
    return this.registry.get(type);
  }

    return this.registry.has(type);

  /**
   * 根据步骤类型获取渲染组件

  getRendererComponent(type: StepType): StepRenderer['Component'] | undefined {
    const renderer = this.get(type);
    return renderer?.Component;

  /**
   * 获取所有已注册的步骤类型
   */
  getRegisteredTypes(): StepType[] {
    return Array.from(this.registry.keys());
  }
}

**统一步骤容器：**

```typescript
// src/components/steps/renderer/StepContainer.tsx

import React, { useMemo } from 'react';
import type { StepContent, LearningStep, StepResult } from '../../data/math/types';
import type { StepRendererProps } from './types';
import { stepRendererRegistry } from './registry';
import { useStepController } from '../StepContainer';
import './StepContainer.css';

interface UnifiedStepContainerProps {
  step: LearningStep;
  content: StepContent;
  stepIndex: number;
  totalSteps: number;
  onComplete: (result: StepResult) => void;
  onHint?: () => void;
}

/**
 * 统一步骤容器
 * 根据步骤类型自动选择对应的渲染组件
 */
export const UnifiedStepContainer: React.FC<UnifiedStepContainerProps> = ({
  step,
  content,
  stepIndex,
  totalSteps,
  onComplete,
  onHint
}) => {
  // 获取步骤控制器
  const stepController = useStepController(step, onComplete, onHint);
  
  // 根据步骤类型查找渲染器
  const RendererComponent = useMemo(() => {
    return stepRendererRegistry.getRendererComponent(step.type);
  }, [step.type]);
  
  // 渲染器不存在时的降级处理
  if (!RendererComponent) {
    return (
      <div className="step-renderer-not-found">
        <h3>未找到步骤渲染器</h3>
        <p>步骤类型: {step.type}</p>
        <p>步骤名称: {step.name}</p>
      </div>
    );
  }
  
  // 准备渲染器 Props
  const rendererProps: StepRendererProps = {
    step,
    content,
    onComplete,
    onHint,
    stepIndex,
    totalSteps,
    adaptive: {
      hintLevels: step.adaptive?.hintLevels || [],
      hintsUsed: stepController.hintsUsed,
      onUseHint: stepController.handleHint
    }
  };
  
  return (
    <div className={`step-container step-type-${step.type}`}>
      {/* 步骤头部 */}
      <div className="step-header">
        <span className="step-icon">{getStepIcon(step.type)}</span>
        <span className="step-name">{step.name}</span>
        <span className="step-progress">{stepIndex + 1} / {totalSteps}</span>
      </div>
      
      {/* 步骤内容 */}
      <div className="step-content">
        <RendererComponent {...rendererProps} />
      </div>
      
      {/* 反馈消息 */}
      {stepController.showFeedback && (
        <div className={`step-feedback ${stepController.feedbackType}`}>
          {stepController.feedbackMessage}
        </div>
      )}
      
      {/* 当前提示 */}
      {stepController.currentHint && (
        <div className="step-hint">
          <span className="hint-icon">💡</span>
          <span className="hint-text">{stepController.currentHint}</span>
        </div>
      )}
    </div>
  );
};

function getStepIcon(type: string): string {
  const icons: Record<string, string> = {
    concrete: '🎮',
    pictorial: '🎨',
    verbal: '💬',
    symbolic: '🔢',
    application: '🧩',
    reflection: '🤔'
  };
  return icons[type] || '📖';
}

export default UnifiedStepContainer;
```

 * 具象操作步骤渲染器
 * 支持通过 visualType 配置选择不同的可视化组件
 */
export const ConcreteStepRenderer: React.FC<StepRendererProps<ConcreteContent>> = ({
  step,
  content,
  onComplete,
  adaptive
}) => {
  const [taskComplete, setTaskComplete] = useState(false);
  
  // 从 interaction 中提取可视化配置
  const visualConfig = useMemo(() => {
    const { interaction } = content;
    
    // 根据 kind 确定默认可视化类型
    let defaultVisualType = 'split-circle';
    let defaultConfig: any = {};
    
    switch (interaction.kind) {
      case 'split':
        // 从 target 中提取分割份数
        const match = interaction.target.match(/\d+/);
        defaultVisualType = 'split-circle';
        defaultConfig = {
          denominator: match ? parseInt(match[0]) : 2
        };
        break;
      case 'tap':
        defaultVisualType = 'box-guess';
        break;
      // 其他交互类型...
    }
    
    // 支持数据文件覆盖配置
    return {
      visualType: (step as any).visualType || defaultVisualType,
      config: { ...defaultConfig, ...(step as any).visualConfig }
    };
  }, [content, step]);
  
  // 处理可视化交互完成
  const handleVisualInteraction = useCallback((event) => {
    if (event.type === 'complete') {
      setTaskComplete(true);
    }
  }, []);
  
  // 完成步骤
  const handleNext = useCallback(() => {
    onComplete({
      stepId: step.id,
      completed: true,
      attempts: 1,
      hintsUsed: adaptive?.hintsUsed || 0,
      completedAt: new Date()
    });
  }, [step.id, adaptive, onComplete]);
  
  return (
    <div className="concrete-step">
      {/* 场景介绍 */}
      <div className="scenario-card">
        <span className="scenario-emoji">{content.scenario.emoji}</span>
        <div className="scenario-content">
          <h3 className="scenario-title">{content.scenario.title}</h3>
          <p className="scenario-desc">{content.scenario.description}</p>
        </div>
      </div>
      
      {/* 任务说明 */}
      <div className="task-card">
        <div className="task-label">🎯 任务</div>
        <p className="task-instruction">{content.interaction.target}</p>
      </div>
      
      {/* 可视化区域 - 使用注册表动态渲染 */}
      <div className="visual-area">
        {visualizationRegistry.render(
          visualConfig.visualType,
          {
            config: visualConfig.config,
            onInteraction: handleVisualInteraction,
            readonly: false
          }
        )}
      </div>
      
      {/* 操作按钮 */}
      <div className="action-buttons">
        {adaptive?.hintLevels && adaptive.hintsUsed < adaptive.hintLevels.length && (
          <button className="btn-hint" onClick={adaptive.onUseHint}>
            💡 提示 ({adaptive.hintLevels.length - adaptive.hintsUsed})
          </button>
        )}
        
        <button
          className="btn-primary"
          onClick={handleNext}
          disabled={!taskComplete}
        >
          {taskComplete ? '✓ 完成 →' : '完成后再继续'}
        </button>
      </div>
    </div>
  );
};

// 导出渲染器定义
export const concreteStepRenderer: StepRenderer<ConcreteContent> = {
  stepType: 'concrete',
  Component: ConcreteStepRenderer,
  validateContent: (content): content is ConcreteContent => content.type === 'concrete'
};

// src/data/math/kps/index.ts

import type { KnowledgePoint, LearningStep } from '../types';

/**
 * 知识点元信息
 */
export interface KnowledgePointMeta {
  /** 知识点 ID */
  id: string;
  
  /** 知识点名称 */
  name: string;
  
  /** 所属岛屿 */
  island: 'number' | 'shape' | 'logic';
  
  /** 年级 */
  grade: number;
  
  /** 难度等级 */
  level: number;
  
  /** 先修知识点 */
  prerequisites: string[];
  
  /** 完整知识点数据 */
  data?: KnowledgePoint;
  
  /** 懒加载函数 */
  loader?: () => Promise<KnowledgePoint>;
}

/**
 * 知识点注册表
 */
class KnowledgePointRegistry {
  private metaMap: Map<string, KnowledgePointMeta> = new Map();
  private dataCache: Map<string, KnowledgePoint> = new Map();
  
  /**
   * 注册知识点
   */
  register(meta: KnowledgePointMeta): void {
    if (this.metaMap.has(meta.id)) {
      console.warn(`[KnowledgePointRegistry] 知识点 ${meta.id} 已存在`);
    }
    this.metaMap.set(meta.id, meta);
  }
  
  /**
   * 注册知识点（便捷方法）
   */
  registerPoint(point: KnowledgePoint): void {
    this.register({
      id: point.id,
      name: point.name,
      island: point.island,
      grade: point.grade,
      level: point.level,
      prerequisites: point.prerequisites,
      data: point
    });
  }
  
  /**
   * 获取知识点元信息
   */
  getMeta(id: string): KnowledgePointMeta | undefined {
    return this.metaMap.get(id);
  }
  
  /**
   * 异步加载知识点数据
   */
  async load(id: string): Promise<KnowledgePoint | undefined> {
    // 缓存命中
    if (this.dataCache.has(id)) {
      return this.dataCache.get(id);
    }
    
    const meta = this.metaMap.get(id);
    if (!meta) return undefined;
    
    // 如果有懒加载函数
    if (meta.loader) {
      const data = await meta.loader();
      this.dataCache.set(id, data);
      return data;
    }
    
    // 返回已缓存的数据
    return meta.data;
  }
  
  /**
   * 同步获取知识点数据（需要先加载）
   */
  get(id: string): KnowledgePoint | undefined {
    const meta = this.metaMap.get(id);
    return meta?.data;
  }
  
  /**
   * 获取所有知识点
   */
  getAll(): KnowledgePointMeta[] {
    return Array.from(this.metaMap.values());
  }
  
  /**
   * 按岛屿获取知识点
   */
  getByIsland(islandId: 'number' | 'shape' | 'logic'): KnowledgePointMeta[] {
    return this.getAll().filter(kp => kp.island === islandId);
  }
  
  /**
   * 获取岛屿列表
   */
  getIslands(): Array<{ id: string; name: string; points: KnowledgePointMeta[] }> {
    const islands = ['number', 'shape', 'logic'] as const;
    const islandNames: Record<string, string> = {
      number: '数与运算',
      shape: '图形探索',
      logic: '逻辑挑战'
    };
    
    return islands.map(id => ({
      id,
      name: islandNames[id],
      points: this.getByIsland(id)
    }));
  }
}

export const kpRegistry = new KnowledgePointRegistry();

/**
 * 动态导入所有知识点文件
 * 支持代码分割和按需加载
 */
export async function loadAllKnowledgePoints(): Promise<void> {
  // 知识点文件的懒加载映射
  const lazyLoaders: Record<string, () => Promise<any>> = {
    'fraction-basics': () => import('./fraction-basics'),
    'algebra-basics': () => import('./algebra-basics'),
    'chicken-rabbit-new': () => import('./chicken-rabbit-new'),
    'fraction-comparison-new': () => import('./fraction-comparison-new')
  };
  
  for (const [id, loader] of Object.entries(lazyLoaders)) {
    if (!kpRegistry.getMeta(id)?.data) {
      const module = await loader();
      kpRegistry.registerPoint(module[`${id.replace(/-/g, '')}KnowledgePoint`]);
    }
  }
}

 * 根据 ID 获取知识点（异步版本）
 */

  id: string
): Promise<KnowledgePoint | undefined> {

 * 知识点导出钩子
 */
export function useKnowledgePoint(id: string): {
  data: KnowledgePoint | undefined;
  loading: boolean;
  error: Error | undefined;
} {
  const [data, setData] = useState<KnowledgePoint | undefined>();
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<Error>();

import React, { useState, useCallback, useMemo } from 'react';

interface GridFillProps {

  config: GridFillConfig;
  onInteraction?: (event: any) => void;
  readonly?: boolean;
}

export const GridFill: React.FC<GridFillProps> = ({
  config,
  onInteraction,
  readonly = false
}) => {
  const { rows, columns, fillMode = 'horizontal', targetCells = [] } = config;
  const [filledCells, setFilledCells] = useState<Set<string>>(new Set());
  
  // 网格尺寸
  const cellSize = 40;
  const gap = 2;
  
  // 处理单元格点击
  const handleCellClick = useCallback((row: number, col: number) => {
    if (readonly) return;
    
    const key = `${row}-${col}`;
    setFilledCells(prev => {
      const next = new Set(prev);
      if (next.has(key)) {
        next.delete(key);
      } else {
        next.add(key);
      }
      return next;
    });
  }, [readonly]);
  
  // 检查是否完成
  const isComplete = useMemo(() => {
    if (targetCells.length === 0) {
      // 如果没有指定目标，填充任意单元格即可
      return filledCells.size > 0;
    }
    // 检查是否填充了所有目标单元格
    return targetCells.every(cell => filledCells.has(`${cell.row}-cell.col`));
  }, [filledCells, targetCells]);
  
  // 触发完成事件
  React.useEffect(() => {
    if (isComplete && !readonly) {
      onInteraction?.({
        type: 'complete',
        payload: { filledCells: Array.from(filledCells) },
        timestamp: Date.now()
      });
    }
  }, [isComplete, readonly, filledCells, onInteraction]);
  
  return (
    <div className="grid-fill-container">
      <svg
        width={columns * (cellSize + gap)}
        height={rows * (cellSize + gap)}
        className="grid-fill-svg"
      >
        {Array.from({ length: rows }).map((_, row) =>
          Array.from({ length: columns }).map((_, col) => {
            const key = `${row}-${col}`;
            const isFilled = filledCells.has(key);
            const isTarget = targetCells.some(
              cell => cell.row === row && cell.col === col
            );
            
            return (
              <g key={key} onClick={() => handleCellClick(row, col)}>
                <rect
                  x={col * (cellSize + gap)}
                  y={row * (cellSize + gap)}
                  width={cellSize}
                  height={cellSize}
                  rx={4}
                  className={`grid-cell ${isFilled ? 'filled' : ''} ${
                    isTarget && !isFilled ? 'target' : ''
                  }`}
                  style={{ cursor: readonly ? 'default' : 'pointer' }}
                />
                {isFilled && (
                  <text
                    x={col * (cellSize + gap) + cellSize / 2}
                    y={row * (cellSize + gap) + cellSize / 2}
                    textAnchor="middle"
                    dominantBaseline="middle"
                    className="cell-label"
                  >
                    ✓
                  </text>
                )}
              </g>
            );
          })
        )}
      </svg>
      
      {/* 进度指示 */}
      <div className="grid-progress">
        已填充: {filledCells.size} / {rows * columns}
      </div>
    </div>
  );
};

export default GridFill;

### 7.2 天平组件 (BalanceScale)

```typescript
// src/components/visualizations/BalanceScale.tsx

import React, { useState, useCallback } from 'react';
import type { BalanceScaleConfig } from './types';

interface BalanceScaleProps {
  visualType: 'balance-scale';
  config: BalanceScaleConfig;
  onInteraction?: (event: any) => void;
  readonly?: boolean;
}

export const BalanceScale: React.FC<BalanceScaleProps> = ({
  config,
  onInteraction,
  readonly = false
}) => {
  const { leftItems, rightItems, scaleType, availableWeights = [1, 2, 5, 10] } = config;
  const [selectedWeight, setSelectedWeight] = useState<number | null>(null);
  const [userLeftItems, setUserLeftItems] = useState<typeof leftItems>([]);
  const [userRightItems, setUserRightItems] = useState<typeof rightItems>([]);
  
  // 计算总重量
  const calcTotal = (items: typeof leftItems) =>
    items.reduce((sum, item) => sum + item.value, 0);
  
  const leftTotal = calcTotal([...leftItems, ...userLeftItems]);
  const rightTotal = calcTotal([...rightItems, ...userRightItems]);
  
  // 计算倾斜角度
  const tiltAngle = (leftTotal - rightTotal) * 2; // 每单位重量倾斜 2 度
  
  // 处理放置砝码
  const handlePlaceWeight = useCallback((side: 'left' | 'right') => {
    if (selectedWeight === null) return;
    
    const newItem = { type: 'weight' as const, value: selectedWeight };
    if (side === 'left') {
      setUserLeftItems(prev => [...prev, newItem]);
    } else {
      setUserRightItems(prev => [...prev, newItem]);
    }
    setSelectedWeight(null);
  }, [selectedWeight]);
  
  return (
    <div className="balance-scale-container">
      {/* 天平支架和横杆 */}
      <svg width="400" height="200" className="balance-svg">
        {/* 支架 */}
        <line x1="200" y1="20" x2="200" y2="180" stroke="#666" strokeWidth="4" />
        <line x1="50" y1="180" x2="350" y2="180" stroke="#666" strokeWidth="4" />
        
        {/* 横杆（带倾斜） */}
        <g transform={`rotate(${tiltAngle}, 200, 50)`}>
          <line x1="50" y1="50" x2="350" y2="50" stroke="#333" strokeWidth="3" />
          
          {/* 左边托盘 */}
          <line x1="50" y1="50" x2="50" y2="80" stroke="#333" strokeWidth="2" />
          <line x1="30" y1="80" x2="70" y2="80" stroke="#333" strokeWidth="2" />
          
          {/* 右边托盘 */}
          <line x1="350" y1="50" x2="350" y2="80" stroke="#333" strokeWidth="2" />
          <line x1="330" y1="80" x2="370" y2="80" stroke="#333" strokeWidth="2" />
        </g>
      </svg>
      
      {/* 可选砝码 */}
      {!readonly && (
        <div className="weight-selector">
          <span>选择砝码:</span>
          {availableWeights.map(weight => (
            <button
              key={weight}
              className={`weight-btn ${selectedWeight === weight ? 'selected' : ''}`}
              onClick={() => setSelectedWeight(weight)}
            >
              {weight}kg
            </button>
          ))}
        </div>
      )}
      
      {/* 放置按钮 */}
      {selectedWeight !== null && !readonly && (
        <div className="place-buttons">
          <button onClick={() => handlePlaceWeight('left')}>放到左边</button>
          <button onClick={() => handlePlaceWeight('right')}>放到右边</button>
        </div>
      )}
    </div>
  );
};

export default BalanceScale;
```

## 十、总结

### 10.1 架构优势

1. **可视化组件可插拔**：新增可视化类型只需注册，无需修改其他代码
2. **数据驱动渲染**：非程序员可以通过配置使用不同的可视化
3. **知识点自动化**：新增知识点文件后自动被发现和加载
4. **类型安全**：TypeScript 类型系统完整覆盖所有场景
5. **代码分割**：支持知识点和可视化组件的按需加载
