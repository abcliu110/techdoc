# 六步法扩展设计

> 数学学习软件 math-explorer · 知识点六步设计大纲

---

## 设计理念

理解六步法的核心是"具象 → 图示 → 语言 → 符号 → 应用 → 反思"：
- **具象操作** - 用身体（手、眼）感知真实物体
- **图示表达** - 把感知结果用图形表示出来
- **语言描述** - 用自然语言说出自己的理解
- **符号表示** - 用数字/符号精确表达
- **灵活应用** - 在不同场景中运用所学
- **反思内化** - 回顾总结，形成知识结构

**基本信息**

| 属性 | 值 |

| 前置知识 | 分数的初步认识（fraction-basics-new） |
| 课时估计 | 25分钟 |

**核心目标**

1. 掌握"同分母比分子"的比较方法
2. 掌握"同分子比分母"的比较方法
3. 理解"分数单位"概念：分母越大，每一份越小

---

### Step 1：具象操作 — 摆一摆，比一比

**类型：** `concrete`  
**名称：** 披萨比大小  
**交互方式：** `drag` — 拖拽阴影区域重叠比较

**场景设计**

```
🍕 场景：小明有两个一样大的披萨
- 第一个披萨的 1/2 被小明拿了
- 第二个披萨的 1/3 被小明拿了
- 问：哪个披萨被拿走的更多？

🎯 任务：把两个阴影拖到同一个位置比一比
```

**交互流程**

1. 屏幕显示两个相同大小的圆形（代表两个一样大的披萨）
2. 圆形A显示1/2阴影（1/2被涂色）
3. 圆形B显示1/3阴影（1/3被涂色）
4. 学生可以拖动阴影区域到重叠位置
5. 系统实时高亮重叠部分，直观显示1/2 > 1/3

**表示形式**

| 形式 | 内容 |
|------|------|
| 实物 | 两个一样大的圆形披萨 |
| 图形 | 涂色/未涂色扇形区域 |
| 语言 | "一半" vs "三分之一" |

**完成条件**

```typescript
{
  type: 'interactive',
  config: {
    requiredDrag: true,    // 完成拖拽操作
    tolerance: 0.1          // 重叠误差允许10%
  }
}
```

**自适应提示**

1. 💡 提示：把两个阴影区域重叠在一起
2. 💡 提示：涂色部分越多，说明拿走的越多
3. 💡 提示：1/2 比 1/3 大，因为分得越少，每份越大

**核心目标**

1. 理解"假设法"的数学思想
2. 掌握"四步法"：假设全鸡 → 算腿差 → 求兔数 → 验算
3. 能够将方法迁移到其他"两样东西、两种差"的问题

---

### Step 1：具象操作 — 圈一圈，数一数

**类型：** `concrete`  
**名称：** 农场分组  
**交互方式：** `drag` — 拖拽动物到围栏

**场景设计**

```
🐔🐰 场景：农场的鸡和兔混在一起了！

管理员说：总共看到 8 个头
小朋友数了数：一共有 26 条腿

🎯 任务：把鸡和兔分到两个围栏里

提示：每只动物都要有头，每只鸡2条腿，每只兔4条腿
```

**交互流程**

1. 屏幕显示 8 个圆形"头"（预先排列成 2 行 4 列）
2. 左侧有鸡的图标（🐔），右侧有兔的图标（🐰）
3. 学生拖拽动物图标放到"头"下面
4. 系统实时计算：
   - 当前鸡的数量 × 2 + 当前兔的数量 × 4
   - 与目标 26 条腿对比
5. 提供"快速假设"按钮：一键假设全鸡或全兔

**可视化辅助**

```
当前状态：
🐔🐔🐔🐔🐔🐔🐔🐔  （8个头）
🐔🐔🐔🐔         （5只鸡 → 10条腿）
🐰🐰🐰           （3只兔 → 12条腿）
───────────────
总计：8个头，22条腿

目标：26条腿
差距：还差4条腿 🔺
```

**完成条件**

```typescript
{
  type: 'interactive',
  config: {
    requiredCorrect: true,  // 必须正确分配
    allowHint: true         // 允许使用提示
  }
}
```

**自适应提示**

1. 💡 提示：先假设全部是鸡，算算有多少腿
2. 💡 提示：全部是鸡的话，有 8×2=16 条腿
3. 💡 提示：实际有 26 条腿，还差 26-16=10 条腿
4. 💡 提示：每把 1 只鸡换成兔，腿数增加 2 条
5. 💡 提示：需要换 10÷2=5 只兔子

2. 推导出"长 × 宽"的面积公式
3. 能计算简单长方形的面积

---

### Step 1：具象操作 — 铺一铺，数一数

**名称：** 铺地砖  
**交互方式：** `tap` — 点击填充格子

**场景设计**

```

📊 进度：已铺 0/15 块
```

**交互流程**

**可视化效果**


**完成条件**


**自适应提示**

## 设计总结

### 三个知识点的设计亮点

| 知识点 | Step1 核心交互 | Step5 特色练习 |
|--------|---------------|---------------|
| 分数比较 | 拖拽阴影重叠 | 混合陷阱题（同分子 vs 同分母） |
| 鸡兔同笼 | 拖拽动物到围栏 | 换角色（汽车 vs 摩托） |
| 长方形面积 | 点击铺满格子 | 逆向求边长、单位换算 |

### 新增交互组件需求

| 组件名 | 功能 | 用于 |
|--------|------|------|
| `FractionCompare` | 两个分数的条形图拖拽比较 | 分数比较 Step1 |
| `BarChartSort` | 条形图排序 | 分数比较 Step2 |
| `AnimalPen` | 动物围栏拖拽场景 | 鸡兔同笼 Step1 |
| `GridFill` | 格子点击填充 | 长方形面积 Step1 |
| `AreaGrid` | 面积计算格子图 | 长方形面积 Step2 |

### 实现优先级建议

1. **第一阶段（高优先级）**  
   - 长方形面积 — 交互最简单，易于实现
   - 复用现有的 `SplitCircle` 思路，改造成 `GridFill`

2. **第二阶段（中优先级）**
   - 分数比较 — 需要新增条形图组件
   - 可以复用 `FractionCompare` 做分数四则运算等扩展

3. **第三阶段（低优先级）**
   - 鸡兔同笼 — 交互最复杂，需要状态管理
   - 可以做成可配置的"两样东西比较"通用场景
