# 能力主线与深度理解设计方案

> 定位：本文档是产品设计的**顶层文档**，回答两个根本问题——
> ① 小学初中最重要的数学能力是什么？② 如何让学生深度理解（而非记住）这些能力对应的概念？
> 并给出从「知识点主线」到「能力主线」的产品重构框架。
> 与前序文档的关系：《深度分析报告》诊断了"实现没深度"的问题；本文档定义"深度应该是什么"。

---

## 一、小初最重要的数学能力：5+2 框架

依据 2022 版义务教育数学课程标准的核心素养（"三会"总纲、11 个核心词），结合认知发展规律（皮亚杰：具体运算→形式运算，5-6 年级为转换窗口期），筛选出**地基级能力 5 项 + 贯穿性能力 2 项**：

### 1.1 地基级能力

| 能力 | 本质 | 为什么最重要 | 关键期 |
|------|------|-------------|--------|
| **数感与算理** | 理解"为什么这么算"，能估算、能灵活选策略 | 一切能力的地基；`1/2+1/3=2/5` 式错误全是算理缺失而非粗心 | 1-4 年级 |
| **符号意识 / 代数思维** | 从"算出答案"到"表达关系"；字母=变化的量 | 小初衔接分水岭；初中数学崩盘多源于此转换未完成 | 5-7 年级 |
| **推理能力** | 合情推理（归纳、类比）→ 演绎推理（证明） | 数学区别于所有学科的核心；小学重说理、初中重证明 | 3-9 年级 |
| **几何直观** | 把抽象问题翻译成图，数形双向互译 | 其他四种能力的"公共工具" | 2-6 年级 |
| **模型观念** | 识别关系 → 建立表达 → 求解 → 回代检验 | 应用题困难的根源不是计算，是建不出模型 | 4-9 年级 |

### 1.2 贯穿性能力

- **元认知**：能监控"我是真懂还是假懂"。决定所有学习的效率上限。
- **数学表达**：能把自己想的说清楚、写明白（费曼标准）。表达是理解的试金石。

### 1.3 一个关键判断

这 5+2 项能力的共同特征是：**它们都是"关系性理解"（relational understanding），不是"工具性理解"（instrumental understanding）**（Skemp, 1976）。

- 工具性理解：会套规则——"分数加法要通分"（不知为何）
- 关系性理解：理解结构——"不同单位的量不能直接相加，所以先统一单位"

传统刷题产品训练的是前者；本产品的全部设计应指向后者。**检验任何功能就问一句：它产生的是关系性理解还是工具性理解？**

## 二、深度理解如何发生：六机制循环

认知科学共识：理解不是接收，是建构。深度理解产生于以下循环，**每一环都必须有学生的主动产出，否则该环节形同虚设**：

```
① 具象操作（产出：操作）──→ ② 猜想（产出：假设）──→ ③ 验证与认知冲突（产出：修正）
        ↑                                                        │
        │                                                        ▼
⑥ 反思内化（产出：监控）←── ⑤ 输出表达（产出：表达）←── ④ 变式迁移（产出：迁移）
```

| 环节 | 机制 | 理论依据 | 缺失的后果 |
|------|------|---------|-----------|
| ① 具象操作 | 具身认知、CPA 序列（具体→形象→抽象） | Bruner / 新加坡数学 | 直接给符号，学生无认知脚手架 |
| ② 猜想 | 归纳推理训练：观察特例→提出假设 | Polya《数学与猜想》 | 学生只是观众，思维不发生 |
| ③ 验证与认知冲突 | 暴露迷思概念（misconception）→ 证伪/证实 → 概念重构 | Posner 概念转变理论 | 错误直觉未被撼动，新知被旧知同化 |
| ④ 变式迁移 | 概念性变式（非标准例、反例）+ 过程性变式 | 顾泠沅变式教学 | 只会标准题型，换形式就崩 |
| ⑤ 输出表达 | 费曼技巧：讲出来、写出来、教别人 | 生成效应（generation effect） | "以为懂了"的假性理解 |
| ⑥ 反思内化 | 元认知监控：我哪里懂、哪里不懂 | Flavell 元认知理论 | 无法自我修正，依赖外部纠错 |

### 2.1 与现有"六步法"的关系

现有六步法（具象→图示→语言→符号→应用→反思）是这个循环的**骨架**，但缺两环：

- **缺"猜想"**：现有流程从操作直接到表征，学生从未被要求"先猜猜看"；
- **缺"认知冲突"**：现有流程全是正向讲解，从未设计"让学生先暴露错误直觉再推翻"。

**这两环恰是思维真正发生的地方。** 加上前两轮评审发现的"各环节无产出验证"，构成深度缺失的完整因果链：

```
环节缺产出验证（评审发现） + 环节缺猜想与冲突（本框架）= 学生全程旁观 = 没有深度
```

## 三、意图扩展：从「知识点主线」到「能力主线」

### 3.1 设计原点反转

| | 现状（知识点主线） | 目标（能力主线） |
|---|---|---|
| 设计起点 | 要教哪个知识点 | 要培养哪种能力 |
| 内容组织 | 知识点的先后顺序 | 能力的行为指标进阶 |
| 交互设计 | 有什么组件就用什么 | 该能力需要什么机制就建什么 |
| 过关标准 | 题做对 | 行为指标被观测到 |
| 知识点的角色 | 目的本身 | 能力的载体 |

### 3.2 能力-行为-机制-验证映射表（产品核心配置）

| 能力 | 可观测行为 | 训练机制（交互） | 验证标准（过关） |
|------|-----------|----------------|----------------|
| 数感与算理 | 先估算再精算；能讲清算理；能换算法 | 认知冲突（先暴露 2/5 式错误再推翻）+ 一题多解 | 非常规变式题 ≥80%；能口述算理 |
| 符号意识 | 用字母表达关系；文字↔符号双向互译 | 猜数游戏→天平建模→双向互译，不给方程模板 | 独立列方程并解释每项现实意义 |
| 推理能力 | 会说"因为所以"；能举反例；补全推理链 | 猜想-验证循环；反例挑战；说理填空 | 写出完整推理链；指出错误推理断点 |
| 几何直观 | 主动画图分析数量关系 | 数形互译：先画图再列式，图错式错可对照 | 新情境下能自主选图、画图 |
| 模型观念 | 识别关系→建表达→回代检验 | 真实情境建模；强制追问"答案合理吗" | 解决非常规应用题（非套题型） |
| 元认知 | 能准确自评理解度；能说出卡点 | 学后自评 + 变式验证对照（自评 vs 实测） | 自评与实测一致（校准度） |
| 数学表达 | 用自己的话讲清概念与方法 | 语言步恢复真实输入 + 关键词/逻辑校验 | 表达覆盖关键逻辑节点 |

### 3.3 对现有系统的落地映射

| 框架层 | 落地点 | 对应评审结论 |
|--------|--------|-------------|
| 验证标准 → 数据层 | `completionCriteria` 已声明，补一个消费它的校验器 | P0-⑥（评审 9.4） |
| 机制 → 交互层 | 新增「猜想-验证」「认知冲突」两种步骤类型（stepType 扩展为 8 种） | P2（评审 §七） |
| 行为指标 → 内容层 | 每个知识点数据增加 `abilityTargets: [{ ability, behavior, evidence }]`，声明本课训练哪项能力的哪个行为 | 新增 |
| 能力 → 报告层 | 能力雷达图的数据源从"答题正确率+自评"改为"行为指标达成证据" | 修复评审 3.2 数据污染 |

### 3.4 内容优先级建议（按能力 × 学段）

1. **第一波（MVP 修正）**：数感与算理 —— 分数概念/分数运算（三年级起点），理由：迷思概念最典型、可视化最成熟、现有内容可改造。
2. **第二波**：符号意识 —— 用字母表示数 → 一元一次方程（5-6 年级小初衔接，现有 algebra/equation 内容直接升级）。
3. **第三波**：推理能力 —— 找规律升级为「猜想-验证」专题；鸡兔同笼升级为「假设法推理链」专题。
4. **第四波**：几何直观 + 模型观念 —— 图形岛重建（当前 4 个知识点全部不可学，直接按新框架写）。

## 四、验证"深度"的统一标尺

任何知识点学完后，用「五能」验收（对应《如何促进学生深度理解》§6.2，此处与能力行为指标挂钩）：

| 维度 | 检验问题 | 对应机制环 |
|------|---------|-----------|
| 能说 | 能用自己的话解释概念/算理 | ⑤ 输出表达 |
| 能画 | 能用图形表征数量关系 | ①④ 操作与迁移 |
| 能算 | 变式题、非常规题正确 | ④ 变式迁移 |
| 能用 | 能解决真实情境问题 | 模型观念 |
| 能教 | 能讲给同伴听并回答追问 | ⑤ 输出表达（最高标准） |

**产品化的关键**：每一"能"都必须对应一个**可观测、可校验的交互事件**写进 `completionCriteria`，并由校验器强制执行——否则"深度"永远停留在文档里（这正是前两轮评审的核心发现）。

---

## 五、总结：三句话

1. **最重要的能力**：数感算理（地基）、符号意识（分水岭）、推理、几何直观、模型观念（支柱），元认知与表达（贯穿）。
2. **深度理解的机制**：理解=建构=六机制循环，每环必须有学生产出；现有六步法缺"猜想"与"认知冲突"两环，且全环节无产出验证。
3. **产品的重构方向**：以能力为设计原点，知识点做载体；用「能力→行为→机制→验证」四层配置驱动内容生产，用校验器强制验证落地。
